# markview - 다국어 유사 상표 검색 서비스 (경력 2)

MarkView 서비스 개발 및 고도화(2025.06 ~ 2025.10, 2026.02 ~ 2026.05). 검색 알고리즘 설계, 성능 개선, 운영 자동화.
읽는 순서는 03(검색 설계가 토대) -> 01(성능 개선) -> 02(운영 자동화)가 시간 흐름이고, 문서 번호는 경력기술서 순서(최신순)를 따른다.

- 각 문서: 핵심 요약 / 문제 상황 / 해결 과정(도식 포함) / 결과 (01은 회고 포함)
- 복습은 도식만 보고 본문 논리를 재산출 -> 본문으로 확인 순서로 한다.
