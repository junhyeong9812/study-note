# 다국어 유사 상표 검색 시스템 설계 및 개발

> 소속 경력: MarkView 서비스 개발 및 고도화 - 변리사 대상 글로벌 다국어 유사 상표 검색 서비스 (한국, 중국, 일본, 미국, 유럽) - 검색 알고리즘 설계, 검색 성능 개선, 데이터 모니터링/무중단 배포 시스템 구축
> 이 서비스는 5개 지역(한국, 중국, 일본, 미국, 유럽) 대상입니다. 11개국 확장분(단일 통합 인덱스, 어댑터, k6 부하테스트)은 "한국지식재산보호원 K-브랜드 지킴이 - 해외 상표 무단선점 경보 서비스 개발" 경력에 해당합니다.

## 한 줄 요약

변리사가 거절 위험이 있는 유사 상표를 찾도록 유사성을 형태, 발음, 도치로 나눠 Lucene 커스텀 필터와 규칙 기반 G2P로 구현해 발음 변환 정확도 26%를 96%로 올리고, 국가별 어댑터와 단일 통합 인덱스로 11개국까지 확장해 변리사 실서비스에 채택됐습니다.

## 문제 상황

이 시스템의 주 사용자는 변리사입니다.\
변리사는 의뢰받은 상표를 출원하기 전에 유사한 상표가 이미 존재하는지 사전 조사하는데, 유사 상표가 있으면 심사 단계에서 의견제출통지서와 함께 출원이 거절되기 때문입니다.\
따라서 **"유사 상표를 더 정확하고 빠르게 찾는 것"이 변리사 업무 효율과 직결**되는 핵심 문제였습니다.

## 해결 과정

세 번의 판단으로 진행했습니다. 도메인 기준을 먼저 세우고, 풀 수 있는 영역에 자원을 집중하고, 국가는 어댑터로 흡수했습니다.

**판단 1. 도메인 기준을 먼저 세운다**\
변리사 판단 기준과 실제 거절 데이터로 유사성의 종류를 정한 뒤 구현했습니다.

1. **[유사성 세 유형 정의](해결과정/01_유사성_세_유형_정의/post.md)**\
   변리사 대표의 실무 기준과 의견제출통지서 데이터로 유사성을 형태(자모 생김새), 발음, 도치(음절 순서) 세 유형으로 정의하고 한/영 교차를 가장 큰 난관으로 특정
2. **[형태, 도치, 발음 분리 구현](해결과정/02_형태_도치_발음_분리_구현/post.md)**\
   자모 분리 정규화 커스텀 토큰 필터를 Lucene API로 구현해 ES 플러그인으로 탑재, 도치는 회전 토큰 constant score, 발음은 G2P로 한/영을 같은 기준에서 비교, 복합 케이스는 음소 변환 + 도치 매칭

**판단 2. 풀 수 있는 영역에 집중한다**\
검출 실패를 원인별로 나눠 한계선 밖은 분리하고, 안쪽은 규칙으로 직접 구현했습니다.

3. **[한계선 분리](해결과정/03_한계선_분리/post.md)**\
   검출 실패를 원인별로 나눠 음차, 도치, 부분매칭은 개선 대상으로, 체리블라썸-벚꽃 같은 의미 번역은 임베딩 영역으로 한계선 밖에 두고 자원을 집중
4. **[자체 G2P 변환기](해결과정/04_자체_G2P_변환기/post.md)**\
   오픈소스 g2p-en의 한글 표기 정확도 26%(검증셋 50단어)를 원인 분석 후 영어 발음 패턴 약 30개를 추린 룰 기반 변환기로 대체해 96%, 확장셋 121단어 94.2%, fuzzy 확대는 노이즈 때문에 배제

**판단 3. 국가는 어댑터로 흡수한다**\
언어별 변환은 색인 시에 미리 하고 검색 시 변환을 최소화했습니다.

5. **[다국가 확장 어댑터](해결과정/05_다국가_확장_어댑터/post.md)**\
   미국 G2P, 중국 병음, 일본 로마자와 형태소 분석, 유럽 23개 언어는 계열 단위로 정규화 어댑터를 두고 단일 통합 인덱스에 자국어, 영어, 한국어 번역 필드를 1:N 변형으로 미리 저장

선택하지 않은 방법: fuzzy 허용 오차 확대(535만 건에서 무관 후보 폭증), 오픈소스 g2p-en 개선(영어권 화자 기준 발음이라 근본 원인), 의미 번역 검출(임베딩 영역, 한계선 밖으로 분리).

## 결과

의견제출통지서 기준으로 정제한 **28,407쌍 테스트셋에서 약 62.7% 검출률**(top-100)을 기록했고(2026년 G2P 고도화 반영 후 측정 기준), **대표(변리사)가 기존 경쟁사 검색과 직접 비교해 낫다고 평가**했으며, **여러 변리사가 실제 서비스를 채택해 사용**하고 있습니다.\
사용 피드백도 대표를 통해 받아 성능 개선에 반영했습니다.
