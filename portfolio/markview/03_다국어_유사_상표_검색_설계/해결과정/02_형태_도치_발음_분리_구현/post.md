# 2. 자모 분리 정규화 커스텀 토큰 필터를 Lucene API로 구현해 ES 플러그인으로 탑재, 도치는 회전 토큰 constant score, 발음은 G2P로 한/영을 같은 기준에서 비교, 복합 케이스는 음소 변환 + 도치 매칭

### 유사 상표 검색 - 유사성 세 유형과 한/영 교차 처리

```text
     * 기준 소스: 변리사(대표) 판단 기준 + 실제 의견제출통지서 데이터
     +--------------------------------------------------------------------------------------------------------------------------------------------------+
     | 입력 상표명  예) 우드스프링                                                                                                                      |
     +--------------------------------------------------------------------------------------------------------------------------------------------------+
                                                                               |
                       +------------------------------------+------------------+-----------------+-------------------------------------+
                       |                                    |                                    |                                     |
     +-----------------v------------------++----------------v------------------++----------------v-----------------+ +-----------------v----------------+
     | 형태 유사                          || 발음 유사                         || 도치 유사                        | | 한/영 교차                       |
     | 자모 분해, 정규화                  || 한글 -> 음소(G2P)                 || 음절/토큰 순서 뒤집기            | | 발음 필드 + 도치 매칭 동시 적용  |
     | ㅏ/ㅑ, ㅁ/ㅂ 등 생김새 비슷한 글자 || 영문과 같은 기준  에펠라 = effera || 양아지 = 아지양                  | | 우드스프링 = springwood          |
     | -> 형태 필드                       || -> 발음 필드                      || -> 도치 필드                     | |                                  |
     +------------------------------------++-----------------------------------++----------------------------------+ +----------------------------------+

     * 상표명 하나 -> 세 유형의 필드로 분리 저장 (Lucene 커스텀 토큰 필터 플러그인 + ES 튜닝)
     * 가장 큰 난관 = 한국어/영어 발음 간 유사성 + 한글, 영문 표기가 교차하는 케이스
```

도식 39. 유사성 세 유형과 한/영 교차 처리 - 상표명 하나를 형태, 발음, 도치 필드로 분리 저장

형태 유사는 자모 분리, 유사 자모 그룹핑 전처리를 거치고, 한국어 상표의 자모를 분리, 정규화하는 **커스텀 토큰 필터를 Lucene API로 직접 구현해 플러그인(.jar)으로 빌드한 뒤 Elasticsearch에 탑재**했습니다.\
도치 유사는 **문자열을 순차 회전시킨 토큰의 term 매칭에 constant score로 가중치를 고정**했고, 발음 유사는 한국어 발음 변형을 정의하고 영어는 **자체 룰 기반 G2P 변환**으로 일관되게 변형해 **한글과 영어 발음을 같은 기준 위에서 비교**하게 했습니다(G2P 구현은 아래 절).

3가지 케이스로 상표명을 분리한 데이터 필드를 구성했고, '우드스프링 - springwood'처럼 한/영 표기가 섞이고 어순까지 바뀐 복합 케이스는, **한글을 소리 단위(음소)로 변환해 영문과 같은 기준으로 맞춘 뒤 도치 토큰 매칭을 함께 적용**해 처리했습니다.\
**도메인 정의부터 유사성 기준 설계, Lucene 플러그인 개발과 Elasticsearch 튜닝, 다국어 발음 변환 파이프라인까지 단독으로 진행**했습니다.\
기본 프로토타입(데이터 수집, 가공 파이프라인 설계와 적재, 검색, 테스트)은 2025.06~09에 개발했고, 재입사 후 2026.02부터 G2P 개발과 성능 개선 등 고도화를 이어갔습니다.
