# 3. 검출 실패를 원인별로 나눠 음차, 도치, 부분매칭은 개선 대상으로, 체리블라썸-벚꽃 같은 의미 번역은 임베딩 영역으로 한계선 밖에 두고 자원을 집중

### 한계선의 명시적 분리 - 검출 실패 사례를 원인별로 나눔

```text
                                               +---------------------------------------------------------------+
                                               | 검출하지 못한 사례 전수 -> 원인별 분류                        |
                                               +---------------------------------------------------------------+
                                                                               |
                                           +-----------------------------------+-----------------------------------+
                                           |                                                                       |
           +-------------------------------v--------------------------------+      +-------------------------------v--------------------------------+
           | 현재 접근으로 풀 수 있는 영역                                  |      | 도달할 수 없는 영역                                            |
           | 음차(소리 옮김) / 도치(순서 바뀜) / 부분 매칭(일부 겹침)       |      | 의미 번역 관계  체리블라썸 = 벚꽃                              |
           | -> 어휘, 발음 규칙으로 개선 가능                               |      | 문자도 발음도 겹치지 않음 - 심사관은 관념의 유사로 거절        |
           | -> 자원 집중                                                   |      | -> 의미 기반 검색(임베딩)의 영역, 한계선으로 분리              |
           |                                                                |      |                                                                |
           |                                                                |      |                                                                |
           |                                                                |      |                                                                |
           +----------------------------------------------------------------+      +----------------------------------------------------------------+
```

도식 40. 검출 실패 사례의 원인별 분리 - 개선 가능 영역에 자원 집중, 의미 번역은 한계선 밖

검출하지 못한 사례를 원인별로 나눠, **현재 접근으로 풀 수 있는 영역(음차, 도치, 부분매칭)과 도달할 수 없는 영역을 구분**했습니다.\
후자는 체리블라썸 - 벚꽃처럼 문자도 발음도 겹치지 않지만 심사관이 관념의 유사로 거절한 의미 번역 관계로, **의미 기반 검색(임베딩)의 영역이라 한계선으로 분리**해 두고 어휘, 발음으로 **실제 개선 가능한 구간에 자원을 집중**했습니다.
