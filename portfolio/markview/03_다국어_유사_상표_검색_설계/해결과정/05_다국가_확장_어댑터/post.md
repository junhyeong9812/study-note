# 5. 미국 G2P, 중국 병음, 일본 로마자와 형태소 분석, 유럽 23개 언어는 계열 단위로 정규화 어댑터를 두고 단일 통합 인덱스에 자국어, 영어, 한국어 번역 필드를 1:N 변형으로 미리 저장

### 다국가 확장 - 국가별 정규화 어댑터와 단일 통합 인덱스

```text
                                                   +----------------------------------------------+      +----------------------------------------------+
     +------------------------------------+        | 국가별 정규화 어댑터                         |      | 단일 통합 인덱스                             |
     | 원천 상표 데이터                   |        | US: 자체 G2P 변환                            |      | 문서 1건 = 상표명 + 검색 필드                |
     | 미국 (US) / 중국 (CN)              |        | CN: 병음 데이터                              |      | 자국어 / 영어 / 한국어 번역 필드             |
     | 일본 (JP) / 유럽 23개 언어         |        | JP: 로마자 + 형태소 분석기                   |      | 각 필드 1:N 변형으로 미리 저장               |
     | ... 11개국                         |--------> EU: 계열 단위 (라틴/게르만/슬라브)          -|------> -> 검색 시 변환 최소화                       |
     |                                    |        | 공통: 상표명 + 검색 필드만 추출              |      |                                              |
     |                                    |        |                                              |      |                                              |
     |                                    |        |                                              |      |                                              |
     +------------------------------------+        +----------------------------------------------+      +----------------------------------------------+

     * 검색 시: 출원인 국가로 언어 1차 추정 -> 언어별 필드 레이어에 점수 차등 -> 추정이 빗나가도 누락 없음

     * 4개국 -> 11개국 확장 = 국가별 개별 인덱스 없이 어댑터 추가만으로 흡수 (K-브랜드 지킴이 text-server, 2026-07-27 대국민 배포)
```

도식 42. 국가별 정규화 어댑터와 단일 통합 인덱스 - 변환은 색인 시, 검색 시 변환 최소화

언어마다 음운 체계와 문자 구조가 달라, **미국은 자체 G2P 변환, 중국은 병음 데이터, 일본은 로마자 표기와 형태소 분석기, 유럽 23개 언어는 계열(라틴, 게르만, 슬라브 등) 단위**로 처리했습니다.\
출원인 국가로 언어를 1차 추정하되 추정이 빗나가도 누락되지 않도록, **언어별 검색 필드를 레이어로 분리하고 점수에 차이**를 두었습니다.

현재 이 검색 엔진은 한국지식재산보호원 "해외 상표 무단선점 시스템"의 **검색 서버(text-server)로 채택되어 2026-07-27 대국민 서비스 K-브랜드 지킴이로 배포**됐으며, 발주처 요구에 따른 4개국 -> 11개국 확장은 국가별 개별 인덱스 대신 **단일 통합 인덱스로 흡수**했습니다.\
11개국 인덱스의 상표명과 검색에 필요한 필드만 통합 인덱스로 가져오고, **자국어 필드, 영어 필드, 한국어 번역 필드로 분리해 각 필드를 1:N 변형으로 미리 저장**함으로써 **실제 검색 시 변환 과정을 최소화**했습니다.
