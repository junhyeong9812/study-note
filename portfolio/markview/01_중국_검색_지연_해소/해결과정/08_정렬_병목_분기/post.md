# 8. 정렬 병목 분리 측정(정렬 5~6초, 미정렬 1.5초) 후 중국 한정 2차 분기: 지정 시 수행, 미지정 시 500만 건 기준 생략 또는 기본 정렬

### 정렬 분기 (중국 한정) - 정렬 지정은 존중, 미지정이면 결과 규모로 2차 분기

도식 33. 정렬 분기 (중국 한정) - 정렬 지정은 수행, 미지정이면 결과 500만 건 기준으로 생략/기본 정렬 2차 분기

남은 병목은 정렬이었습니다.\
**대량 결과에 정렬을 적용하면 5~6초, 정렬을 빼면 1.5초**로 측정돼 **정렬 단계가 지배적**임을 확인했습니다.\
정렬 정책은 국가마다 달라 이 분기는 **중국에 한정해 설계**했습니다.\
**사용자가 정렬 기준을 지정하면 전체 정렬 비용을 감수하고 그대로 수행**하고, 지정하지 않았을 때는 **결과 건수를 카운트해 500만 건 미만이면 기본 정렬을 수행, 500만 건 이상이면 정렬을 생략**하도록 2중으로 분기했습니다.\
생략해도 **상표명 검색은 유사도 score 순으로 반환**되고, 상표명 검색이 500만 건을 넘는 경우는 사실상 없어 사용성 손실 없이 대량 조회의 정렬 비용만 제거됩니다.

### 500만 건 기준의 근거

결과 건수를 바꿔 가며 잰 결과, **480만~490만 건까지는 정렬을 포함해도 빠르게 처리**됐습니다.\
**500만 건을 넘기면서부터 정렬 과정의 CPU 사용량과 IO 처리가 서버 CPU 용량을 넘어 대기가 생기기 시작**했고, 그 지점부터 응답이 급격히 길어졌습니다.\
서버 증설로 풀 수도 있었지만 회사가 추가 비용을 쓰지 않는 방향이었으므로, 그 경계인 500만 건을 기준으로 정렬을 가르는 정책으로 대응했습니다.
