# 2. 검색 서버가 단일 인스턴스라 무중단 배포가 없고 장애 시 수동 재구동

> 데이터 모니터링/무중단 배포 시스템 구축 - 문제 상황 2/2. [사례로 돌아가기](../../) | [이전 1](../01_관측_없는_서버_2대/post.md)

검색 서버는 Control 서버의 **단일 인스턴스**였습니다.\
무중단 배포 구조가 없어 **배포는 곧 서비스 중단**이었고,\
장애가 나면 사람이 접속해 **수동으로 재구동**해야 했습니다.\
관측이 없는 상태(문제 1)와 겹쳐, 장애를 알아채는 것도 복구하는 것도 전부 사람의 손에 달려 있었습니다.
