# 4. 인증 직후 만료 오발화를 서버 로그 0건으로 프론트에 귀속, 남은시간 0인 낡은 프레임이 원인이라 매 렌더 만료 시각 도출로 수정하고 회귀 테스트가 실패 모드를 재현하는지 확인

### 실버그 - 인증 직후 "만료" 오발화: 프론트 렌더 타이밍

```text
     렌더 흐름 (문제)
     +---------------------------+   +---------------------------+   +---------------------------+  +---------------------------+   +---------------------------+
     | 인증 성공                 |   | 렌더 1                    |   | 렌더 2 - 낡은 프레임      |  | 만료 감시 오발화          |   | 증상                      |
     | 검증 API 정상 응답        |   | 남은시간 미확정           |   | 남은시간 0으로 1회 렌더   |  | 0을 만료로 판정           |   | "인증 시간 만료" 알림     |
     |                           |---> (만료 감시 대기)          |---> (확정값 반영 직전)        |-->                           |---> 첫 화면으로 복귀          |
     |                           |   |                           |   |                           |  |                           |   |                           |
     +---------------------------+   +---------------------------+   +---------------------------+  +---------------------------+   +---------------------------+
                                                                     <- 문제 지점: 남은시간을 상태로 보관



     귀속과 수정
     +----------------------------------+   +----------------------------------+   +----------------------------------+  +----------------------------------+
     | 서버 로그 실측                   |   | 프론트로 귀속                    |   | 수정                             |  | 회귀 테스트                      |
     | 토큰, OTP 오류 0건               |   | 다른 가설(보관 키)은             |   | 남은시간을 상태로 들지 않고      |  | 구버전에서 2건 실패 재현         |
     | 응답 전부 정상                   |---> 부작용만 확인돼 기각             |---> 매 렌더 만료 시각에서 도출      -|--> 신버전 전부 통과                 |
     |                                  |   |                                  |   |                                  |  |                                  |
     +----------------------------------+   +----------------------------------+   +----------------------------------+  +----------------------------------+
```

도식 19. 실버그 - 남은시간 0인 낡은 프레임 1회가 만료 감시를 오발화, 수정은 매 렌더 만료 시각 도출

기능 테스트 중 인증에 성공한 직후 "인증 시간이 만료되었습니다"가 뜨고 첫 화면으로 되돌아가는 문제를 발견했습니다.\
서버 로그를 실측하니 **토큰과 OTP 오류가 0건**이고 검증, 조회 응답이 전부 정상이어서 **원인을 서버가 아니라 프론트로 귀속**했습니다.\
원인은 **카운트다운 훅의 렌더 타이밍**이었습니다.\
남은시간이 미확정에서 확정값으로 바뀌는 렌더에 남은시간 0인 낡은 프레임이 한 번 끼어 만료 감시가 오발화한 것입니다.\
**남은시간을 상태로 들지 않고 매 렌더마다 만료 시각에서 도출**하도록 바꿔 그 틈을 없앴고, 검토했던 다른 가설(토큰 보관 키 문제)은 검증 결과 부작용만 확인돼 기각했습니다.\
회귀 테스트는 **구버전에 먼저 걸어 2건이 실제로 실패하는 것을 확인**한 뒤 신버전에서 전부 통과시켜, 테스트가 실패 모드를 실제로 재현하는지 확인했습니다.
