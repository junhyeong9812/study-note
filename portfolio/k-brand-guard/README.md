# k-brand-guard - 해외 상표 무단선점 경보 서비스 (경력 1)

한국지식재산보호원 K-브랜드 지킴이. 2026-07-27 대국민 배포. 프로젝트 리딩, 아키텍처/DB 설계, 인증/인가, 검색 서버, 동기화/발송 파이프라인.
읽는 순서는 01(전체 구조) -> 02(파이프라인) -> 03(인증) -> 04(리팩토링) -> 05(부하 실험)가 자연스럽다.

- 각 문서: 핵심 요약 / 문제 상황 / 해결 과정(도식 포함) / 결과 (04, 05는 회고 포함)
- 복습은 도식만 보고 본문 논리를 재산출 -> 본문으로 확인 순서로 한다.
