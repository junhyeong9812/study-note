# 7. 실제 데이터 기반 모듈 테스트를 더해 577개에서 668개로, 암묵적 필드 규칙을 타입과 테스트로 고정하며 규칙 이탈 21건 중 결함 19건 발견

> text-server 리팩토링 - 해결 과정 7/7. [사례로 돌아가기](../../post.md) | [이전 6단계](../06_정책_추상화/post.md)

모듈이 나뉜 뒤에는 각 모듈의 비즈니스 규칙을 실제 데이터 기반으로 테스트에 추가해 **테스트 수를 577개에서 668개로** 늘렸습니다.\
이 과정에서 문서화되지 않은 채 암묵적으로 쓰이던 필드 규칙을 타입과 테스트로 고정하며 **규칙을 벗어난 필드 21건**을 찾아냈고, 그중 **19건은 숨어 있던 결함으로 판정**했습니다.\
동작 보존 원칙에 따라 수정은 별도 동작 변경 작업으로 분리했습니다.

### 근거 (기록) - 577과 668

- 577은 데이터 운영 모듈 리팩토링을 마친 시점의 전체 테스트 실행 기록(577/577 통과, 0 실패)입니다.
- 668은 ES 타입 통일 첫 국가 파일럿을 마친 시점의 전체 테스트 실행 기록(668 실행, 실패 0, 라이브 DB 필요 테스트 2건 건너뜀)입니다.
- 사이 시계열은 577 -> 605 -> 613 -> 634 -> 668이고, 이후 작업에서 862까지 늘었습니다. 커밋 메시지에는 숫자가 없고 작업 문서에만 있습니다.
