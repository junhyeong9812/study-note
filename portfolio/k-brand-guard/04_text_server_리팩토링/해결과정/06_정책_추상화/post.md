# 6. 상태 전이 9개의 트랜잭션 골격을 함수형 인자 메서드 하나로, 흩어진 분기를 결과 enum과 분류 enum으로, 국가 enum은 정책 판정 지점까지만 적용하고 저장 계층은 문자열 유지

**상태 전이 메서드 9개가 반복하던 트랜잭션 골격을 함수형 인자를 받는 메서드 하나로 통합**하고, 백그라운드 루프의 다중 catch에 흩어져 있던 분기는 결과 enum으로, 다섯 갈래 복구 판정은 **분류 enum**으로 올렸습니다.

다섯 개 파일에 흩어져 있던 국가별 분기 리터럴과 정책은 **국가 enum 하나로** 모으되, enum의 적용 범위를 정책 판정 지점까지로 제한하고 **저장 계층은 문자열을 유지해 마이그레이션 없이는 되돌릴 수 없는 변경을 만들지 않았습니다**.
