# 2. 앞선 프로젝트의 사후 조정 비용을 반복하지 않으려면 구조 확정 전에 기준 인덱스로 실측이 필요함

> 검색 서버 부하테스트 설계와 샤드 구조 최적화 - 문제 상황 2/2. [사례로 돌아가기](../../) | [이전 1](../01_되돌리기_어려운_샤드_결정/post.md)

앞선 프로젝트에서 세그먼트와 샤드를 사후에 조정하며 치른 비용이 있어, 이번에는 **구조를 확정하기 전에 실측으로 근거를 만들기로** 했습니다.\
통합 인덱스를 만들기 전이었으므로, 먼저 기존 국가 인덱스 중 **규모가 다른 둘(태국, 인도네시아)로 기준을** 세우기로 했습니다.
