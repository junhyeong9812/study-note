# 2. 유일한 발송 구현이 로그만 남기고 정상 종료되고, 결과가 전체 성공 또는 전체 실패로만 표현됨

> 레거시 동기화와 경보 메일 발송 파이프라인 - 문제 상황 2/2. [사례로 돌아가기](../../) | [이전 1](../01_push_연동이_없는_레거시/post.md)

발송 쪽도 온전하지 않았습니다.\
코드 리뷰 중 전체 코드를 점검하다가, 당시 유일한 발송 구현이 **실제로 메일을 보내지 않고 로그만 남기며 정상 종료**된다는 점(발송 성공으로 오인될 수 있는 상태)과, 발송 결과가 **전체 성공 또는 전체 실패로만 표현**돼 여러 수신자 중 **일부만 실패한 경우의 이력과 재시도 근거를 남길 수 없다**는 점을 확인했습니다.
