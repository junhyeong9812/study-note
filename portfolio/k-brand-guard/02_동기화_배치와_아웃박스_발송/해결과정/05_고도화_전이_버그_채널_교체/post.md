# 5. 전이 조건 반전 버그와 재시도 성공 경로 누락을 고쳐 테스트로 고정하고, 발송 채널 교체는 어댑터만 갈아끼우며 무음 성공 차단과 런타임 예외의 실패 계약 변환 2건을 흡수

### 고도화 - 상태 전이 버그 수정, 발송 어댑터 교체 (아웃박스, 상태머신은 불변)

```text
     +-------------------------------------------------------------------+          +-------------------------------------------------------------------+
     | 발견한 버그 (브랜치 병합 검증 중)                                 |          | 수정                                                              |
     | 허용된 전이에서 예외 발생 (조건 반전) -> 정상 전이 전부 실패      |          | 조건 정정                                                         |
     | 실패 -> 성공 전이가 허용 목록에 없음 -> 재시도 성공 반영 불가     |----------> 실패 -> 성공(재시도 성공) 경로 추가                               |
     |                                                                   |          | 전이 케이스를 테스트로 고정                                       |
     |                                                                   |          |                                                                   |
     |                                                                   |          |                                                                   |
     +-------------------------------------------------------------------+          +-------------------------------------------------------------------+

     +-------------------------------------------------------------------+          +-------------------------------------------------------------------+
     | 채널 교체                                                         |          | 리뷰에서 계약으로 흡수한 2건                                      |
     | 불변식 선고정: 아웃박스, 상태머신 무변경                          |          | 2xx인데 접수 식별자 없음 -> 실패 판정 (무음 성공 차단)            |
     | 발송 어댑터만 교체: SMTP -> 클라우드 메일 API                     |----------> 서명, 본문 구성 런타임 예외 -> 발송 실패 계약으로 변환            |
     |                                                                   |          | (배치 전체가 중단되지 않음)                                       |
     |                                                                   |          |                                                                   |
     |                                                                   |          |                                                                   |
     +-------------------------------------------------------------------+          +-------------------------------------------------------------------+
```

도식 14. 고도화 - 전이 조건 반전 버그 수정과 재시도 성공 경로 추가, 어댑터만 교체하며 계약 2건 흡수

브랜치 병합 검증 중에 **상태 전이 검증의 조건이 반대로 쓰여 있는 것을 발견**했습니다.\
허용된 전이일 때 예외를 던지고 있어서 정상 전이가 전부 실패하는 상태였고, 실패에서 성공으로 가는 전이가 허용 목록에 아예 없어 재시도가 성공해도 반영할 수 없었습니다.\
조건을 바로잡고 **재시도 성공 경로를 허용 목록에 추가**한 뒤 **전이 케이스를 테스트로 고정**했습니다.

발송 채널을 SMTP에서 클라우드 메일 API로 교체할 때는, **아웃박스와 상태머신을 변경하지 않는다를 불변식으로 먼저 고정**하고 **발송 어댑터만 갈아끼웠습니다**. 이때 코드 리뷰 과정에서 찾은 두 가지를 계약으로 흡수하도록 설계했습니다.\
**응답이 2xx인데 접수 식별자가 비어 있으면 성공으로 확정하지 않고 실패로 판정하는 불변식(무음 성공 차단)**, 그리고 서명이나 본문 구성에서 나는 **런타임 예외까지 발송 실패 계약으로 변환**해 **배치 전체가 중단되지 않게** 하는 처리입니다.
