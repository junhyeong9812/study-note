### 동기화 배치 - pull, 순서, 멱등, 실패 시각 앵커 재시도

```text
                                                                                                                                     +-------------------+
     +------------------------------------+     +------------------------------------+     +------------------------------------+    |                   |
     | 매일 새벽 정해진 시각              |     | 순서 보장 적재                     |     | 전량 대조 멱등                     | +-->       성공?       |
     | 타임존 명시 - 한국시간 고정        |-----> 1 출원인 마스터 -> 2 피해사례      |-----> 레거시 식별자 기준                 |-+  |                   |
     |                                    |     | (본인확인 기준 선행)               |     | 재호출 = 재처리                    |    +-------------------+
     +------------------------------------+     +------------------------------------+     +------------------------------------+--------------|
                                                                                                   |실패                                 |성공
                                                                                                   |                                     |
                                                                                                   v                                     v
                                                                                 +-------------------------------------+ +------------------------------+
                                                                                 | 실패 - 재처리 큐 (인메모리)         | | 성공                         |
                                                                                 | 항목에 다음 재시도 시각을 직접 담음 | | 적재 완료 -> 아웃박스 단계   |
                                                                                 | (실패 시각 기준 앵커)               | |                              |
                                                                                 | 최대 2회, 초과 시 로그 + 제거       | +------------------------------+
                                                                                 +-------------------------------------+
     * 폴러는 짧은 주기로 돌되 시각 미도래 항목은 큐에 되돌림. 고정 간격 폴러의 재시도 몰림(리뷰 지적)을 관측 테스트로 재현해 확인하고 교체. 유실 방어 = 멱등성(다음날 정기 실행)
```

도식 12. 동기화 배치 - 순서 보장과 멱등 전량 대조, 실패는 시각 앵커 재시도 후 다음날 멱등 커버

레거시를 **매일 새벽 정해진 시각에 우리가 조회해 적재하는 pull 방식**으로 정했습니다.\
배치 시각은 **타임존을 명시**해 배포 환경의 기본 타임존이 바뀌어도 한국시간 기준이 유지되게 했습니다.\
동기화는 레거시 식별자를 기준으로 **전량 대조하는 멱등 연산**이라 몇 번 호출해도 중복이 생기지 않고, 그래서 실패한 행 데이터를 따로 보관할 필요 없이 **재호출이 곧 재처리**가 됩니다.

동기화 단위에는 순서를 뒀습니다.\
**출원인 마스터를 피해사례보다 먼저 적재**합니다.\
출원인 이메일이 상세 결과 열람의 본인확인 기준이라, 피해사례만 먼저 들어오고 출원인이 따라오지 않으면 그 건은 아무도 열 수 없기 때문입니다.

실패는 인메모리 재처리 큐로 다룹니다.\
처음 설계에서는 재처리 폴러를 고정 간격으로 돌렸는데, Claude와 Codex로 놓친 부분을 점검하는 과정에서 "실패 직후에 폴러 tick이 오면 재시도가 몰려 의도한 간격 분산이 깨진다"는 지적을 받았고, 이를 관측 테스트로 만들어 돌려 실제로 재현되는 것을 확인했습니다.\
그래서 큐 항목에 **다음 재시도 시각을 직접 담아 실패 시각 기준으로 앵커**하고, 폴러는 짧은 주기로 돌되 시각이 도래하지 않은 항목은 큐에 되돌려 놓는 방식으로 고쳤습니다.\
**최대 2회까지만 재시도**하고 그 이후는 에러 로그를 남기고 큐에서 제거합니다.\
데이터 유실이 없는 근거는 멱등성입니다.\
**다음날 정기 실행이 미적재분을 다시 채웁니다**.
