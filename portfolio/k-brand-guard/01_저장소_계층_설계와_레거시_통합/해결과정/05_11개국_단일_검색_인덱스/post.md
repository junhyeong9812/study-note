# 5. 국가별 격리 인덱스를 단일 검색 인덱스 + 상세 인덱스로 전환하고 국가별로 달랐던 정규화와 검색 알고리즘을 통일

> 약 50억 행 저장소 계층 설계와 레거시 통합 - 해결 과정 5/5. [사례로 돌아가기](../../post.md) | [이전 4단계](../04_접근_패턴별_계층_분리/post.md)

### 국가별 격리 인덱스 -> 단일 검색 인덱스 + 상세 인덱스

```text
    +-- 전환 전 - 국가별 격리 (4개국) ---------------------------------+           +-- 전환 후 - 11개국 --------------------------+
    |                                                                  |           |                                              |
    |  +----------------------------+  +----------------------------+  |           |   +---------------------------------------+  |
    |  | 미국                       |  | 태국                       |  |           |   | 단일 검색 인덱스                      |  |
    |  | 정규화, 알고리즘 제각각    |  | 정규화, 알고리즘 제각각    |  |   전환    |   | 정규화, 검색 알고리즘 통일            |  |
    |  +----------------------------+  +----------------------------+  |----------->   +---------------------------------------+  |
    |  | 베트남                     |  | 인도네시아                 |  |           |   +-------------------v-------------------+  |
    |  | 정규화, 알고리즘 제각각    |  | 정규화, 알고리즘 제각각    |  |           |   | 상세 인덱스                           |  |
    |  +----------------------------+  +----------------------------+  |           |   | (샤드 수는 통제 실험으로 확정)        |  |
    |                                                                  |           |   +---------------------------------------+  |
    +------------------------------------------------------------------+           +----------------------------------------------+
```

도식 8. 국가별 격리 인덱스를 단일 검색 인덱스 + 상세 인덱스로 전환, 정규화와 알고리즘 통일

검색 인덱스는 원래 국가별로 격리돼 있었습니다.\
11개국 동시 검색 요구에 맞춰 이를 단일 검색 인덱스와 상세 인덱스 구조로 전환했고, 하나의 인덱스에서 제대로 검색되도록 국가별로 달랐던 데이터 정규화와 검색 알고리즘을 어느 정도 통일해 나갔습니다(샤드 수는 사례 6의 통제 실험으로 확정).
