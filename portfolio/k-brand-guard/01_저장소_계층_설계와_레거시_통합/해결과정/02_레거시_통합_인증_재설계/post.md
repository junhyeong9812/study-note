# 2. 기존 팀의 스키마와 코드를 분석해 공유 영역은 JDBC로 맞물리고 신규 영역은 JPA로 두며, 로그인과 백오피스를 양쪽이 공유하는 JWT + DB 기반 RBAC로 인증을 재설계

> 약 50억 행 저장소 계층 설계와 레거시 통합 - 해결 과정 2/5. [사례로 돌아가기](../../post.md) | [이전 1단계](../01_서버_2대_분리_배치/post.md) | [다음 3단계](../03_로그인_세션_모델/post.md)

### 레거시 통합 - 공유 영역은 JDBC 조회, 신규 영역은 자체 DB(JPA), 권한은 변환 정책으로 래핑

```text
                                                                                          +-- 우리 WAS -------------------------------------------------+
      +-- 레거시 데이터베이스 서버 ------------------------------+                        |                                                             |
      |   +--------------------------------------------------+   |                        |   +------------------------------------------------------+  |
      |   | 회원, 로그인 데이터                              |   |         JDBC           |   | 공유 영역                                            |  |
      |   |                                                  <---|------------------------|---| 레거시 DB를 JDBC로 직접 조회 (로그인, 백오피스 공유) |  |
      |   |                                                  |   |                        |   |                                                      |  |
      |   +--------------------------------------------------+   |                        |   |                                                      |  |
      |   +--------------------------------------------------+   |                        |   +-----------------------------------------------------++  |
      |   | 권한 원본                                        |   |   권한 조회 -> 변환    |   | 권한 변환 정책                                      |   |
      |   | (레거시 권한 체계)                               <---|-----------+            |   | 레거시 권한 -> 우리 정책으로 래핑                   |   |
      |   |                                                  |   |           +------------|---| 자체 인증/인가 테이블 (RBAC)                        |   |
      |   +------------------------^-------------------------+   |                        |   | Spring Security 6 + JWT                             |   |
      +----------------------------------------------------------+                        |   |                                                     |   |
      +-- 레거시 웹서버 -------기존 운영-------------------------+                        |   +-----------------------------------------------------+   |
      |                            |                             |                        |   +-----------------------------------------------------+   |
      |   +--------------------------------------------------+   |                        |   | 신규 영역                                           |   |
      |   | Java 8, Spring 2.x (WAR) - 기존 서비스           |   |                        |   | 도메인은 자체 DB만 사용 (JPA)                       |   |
      |   | (연계 기업 운영)                                 |   |                        |   |                          |                          |   |
      |   |                                                  |   |                        +---+-----------------------------------------------------+---+
      |   +--------------------------------------------------+   |                                                      JPA
      +----------------------------------------------------------+                        +-- 자체 DB --------------------------------------------------+
                                                                                          |   +--------------------------v--------------------------+   |
                                                                                          |   | 신규 도메인, 인증/인가 테이블                       |   |
                                                                                          |   +-----------------------------------------------------+   |
                                                                                          +-------------------------------------------------------------+
```

도식 5. 레거시 통합 - 공유 영역은 JDBC 조회, 신규 영역은 자체 DB(JPA), 레거시 권한을 변환 정책으로 래핑해 접근 권한 분리

기존 팀이 구축한 DB 스키마와 서버 코드, 데이터 처리 절차를 직접 분석해, **공유 영역은 기존 시스템과 충돌 없이** 맞물리게 하고 **신규 영역은 우리 구조로** 구현하는 방식으로 통합을 설계했습니다.\
신규 영역은 전자정부 프레임워크의 레거시, MSA 예제 코드를 직접 분석해, 보안성 평가를 통과해야 하는 인증, 인가와 통신 구조는 **MSA 예제를 커스터마이징**하고, 게시판 등 도메인 모듈은 레거시 예제 기반에 **데이터 접근 계층만 JPA로 전환**하는 식으로 영역별로 적합한 구조를 선택했습니다.\
이 결정들은 **구현 가이드**로 정리해 팀이 동일한 기준으로 개발하게 했습니다.\
이미 설계해 둔 인증/인가는 이 분석 결과에 맞춰 다시 설계해, **Spring Security 6 기반 JWT 인증과 DB 기반 동적 권한(RBAC)**으로 로그인과 백오피스를 양쪽이 공유하게 했습니다.
