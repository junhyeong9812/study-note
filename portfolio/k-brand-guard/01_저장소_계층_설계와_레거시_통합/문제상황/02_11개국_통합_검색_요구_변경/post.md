# 2. 4개국 국가별 검색이 같은 시점에 11개국 통합 검색 + 국가별 검색으로 바뀜

> 약 50억 행 저장소 계층 설계와 레거시 통합 - 문제 상황 2/3. [사례로 돌아가기](../../) | [이전 1](../01_인증_공유_요구_변경/post.md) | [다음 3](../03_랜덤_액세스_워크로드와_저장_매체/post.md)

여기에 **4개국 검색**을 기준으로 시작했던 검색 범위가, 역시 **1개월이 지난 시점**에 "**11개국 데이터**가 있으니 전부 한 번에 검색되게 해 달라"는 요구로 아래와 같이 바뀌었습니다.

### 검색 요구 변경 - 국가별 검색뿐이던 4개국이, 11개국 통합 검색 + 국가별 검색으로

```text
     +-- 처음 요구사항 - 4개국, 국가별 검색만 --------------------+                         +-- 변경된 요구사항 - 11개국, 통합 + 국가별 ----------------+
     |                                                            |                         |                                                           |
     |    +-----------------------+   +-----------------------+   |                         |   +---------------------------------------------------+   |
     |    | 미국                  |   | 태국                  |   |                         |   | 11개국 통합 검색                                  |   |
     |    | 국가별 유사 검색      |   | 국가별 유사 검색      |   |                         |   | 전체 국가를 한 번에 유사 검색                     |   |
     |    | (개별 인덱스)         |   | (개별 인덱스)         |   |                         |   |                                                   |   |
     |    |                       |   |                       |   |  1개월 후 - 요구 변경   |   +---------------------------------------------------+   |
     |    +-----------------------+   +-----------------------+   |------------------------->                             |                             |
     |    | 베트남                |   | 인도네시아            |   |                         |   +-------------------------v-------------------------+   |
     |    | 국가별 유사 검색      |   | 국가별 유사 검색      |   |                         |   | 국가별 검색                                       |   |
     |    | (개별 인덱스)         |   | (개별 인덱스)         |   |                         |   | 기존처럼 국가를 지정한 검색도 유지                |   |
     |    |                       |   |                       |   |                         |   |                                                   |   |
     |    +-----------------------+   +-----------------------+   |                         |   +---------------------------------------------------+   |
     |    * 통합 검색 없음 - 국가를 골라 따로 검색                |                         |                                                           |
     |                                                            |                         |                                                           |
     +------------------------------------------------------------+                         +-----------------------------------------------------------+

     * 단순한 데이터 확장이 아니라, 국가별로 격리돼 있던 검색 구조를 통합 검색이 가능한 구조로 바꿔야 하는 요구
```

도식 2. 검색 요구 변경 - 4개국 국가별 검색만 -> 11개국 통합 검색 + 국가별 검색 (데이터 확장 + 검색 방식 변경)
