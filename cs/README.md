# cs — 일반 CS·설계 지식

특정 프로젝트에 속하지 않는 지식(설계 원칙, 클린코드, 디자인 패턴, 아키텍처 등)의 복습 노트.
어느 프로젝트에서 공부했든, 프로젝트 무관 지식은 여기로 모은다.
복습 접근 순서·간격 규칙은 루트 [README](../README.md), 파일 포맷은 [templates/](../templates/)를 따른다.

## 이 폴더의 문서가 만들어지는 흐름

CS 주제는 두 종류의 산출물을 거친다. 역할이 다르므로 섞지 않는다.

1. **따라 친 원본 노트** — 강의·책·교재를 따라 치면서 각인하는 과정의 글.
   문장이 끊기고 질문이 섞여 있어도 된다. 그게 목적이다.
2. **순수 서머리(2-summary)** — 원본 노트를 남이 읽어도 되는 형태로 다시 정리한 것.
   여기(cs/<주제>/2-summary.md)에 둔다.
3. **질문·정답(1-question / 3-answer)** — 서머리가 **완성된 뒤에만** 작성한다.

> **규칙: 순수 서머리 문서 작성이 끝난 것을 기준으로 질문·정답을 정리한다.**
> 서머리가 미완인 채로 질문을 만들면 "무엇이 핵심인가"의 판별이 미완의 이해 위에서 이뤄진다.
> 서머리 완성 = 그 주제의 이해가 한 바퀴 닫혔다는 신호이고, 그때 질문을 뽑는다.

## 융합 규칙 — 따라 친 내용과 정리된 내용을 합치는 법

원본 노트를 서머리로 다시 정리할 때 따르는 순서다.
전문은 [reference/organize-guide.md](../reference/organize-guide.md),
문단 길이·표 사용 조건 같은 형식 상한은 [reference/writing/](../reference/writing/README.md) (README가 색인, 근거는 evidence 파일 10개).
아래는 그 핵심만 추린 것이다.

1. **입력을 먼저 모은다** — 내 원본 노트 + 기준 문서(교재).
   **기준 문서의 위치는 주제마다 다르므로 정리 시작 시 사용자에게 받는다** — 경로를 추측하지 않는다.
   기준 문서는 읽기만 하고 고치지 않는다.
2. **누락부터 찾는다** — 끊긴 문장, 기준 문서와의 절 대조(`grep -E '^#{1,4} '`), 헤딩 계층 뒤섞임.
   다듬는 건 그다음이다.
3. **골격을 하나로 통일한다** — 같은 종류의 항목은 같은 순서로 서술한다
   (원칙류: 먼저 알아야 할 것 → 정의 → 왜 중요한가 → 나쁜 예 → 좋은 예 → 위반 신호 → 현장 상황).
   골격 자체는 주제마다 달라도 되지만 문서 안에서는 일정해야 한다.
4. **사전 지식은 필요해지는 자리에 푼다** — 항목마다 앞에 「먼저 알아야 할 것」 3~5줄.
   "없으면 다음 문단이 안 읽히는 것"만 넣는다.
5. **예제는 2단으로** — 도메인 지식이 필요 없는 쉬운 예 먼저, 같은 구조를 실무 도메인으로 다시.
   두 예제 사이는 "똑같은 구조다"로 명시적으로 잇는다.
6. **표는 시각화·산문으로** — 표가 이기는 건 고정 차원의 값 비교뿐. 규칙 나열 표는 묶어서 계층으로,
   비교 표는 정렬 블록으로, 다이어그램은 인과 순서대로.
7. **프로젝트 맥락은 일반화한다** — 특정 프로젝트 이름·클래스·경로에 기대지 않는다.
   지우는 게 아니라 누구나 겪는 형태로 다시 쓴다 (「현장에서 만나는 상황」).
8. **문체는 내 것을 유지한다** — 정리는 다시 쓰기가 아니라 고쳐 쓰기.
   오탈자·비문·사실 오류·끊긴 문장은 고치고, 서술체·리듬·설명 순서는 그대로 둔다.
   그게 내가 이해한 순서다.

검증: 소제목만 위에서 아래로 읽었을 때 문서의 구조와 결론이 재구성되면 합격.

## 하지 말 것

- 기준 문서(교재)를 서머리와 같이 고치지 않는다 — 둘이 동시에 움직이면 뭐가 맞는지 알 수 없다.
- 원본에 없던 기술적 주장을 새로 만들지 않는다 — 보강은 맥락과 사전 지식까지다.
- 서머리 완성 전에 질문·정답을 만들지 않는다.
- 서머리 안에 질문·정답을 함께 두지 않는다 — 복습 시 정답이 눈에 들어오는 경로가 생긴다.
  (jun-bank SOLID.md의 「스스로 고민해볼 포인트」가 그 사례 — 이관하면서 분리했다.)
