# database/35-bulk-file-import-export — 질문

## 질문

1. (왜) `line.split(",")`로 CSV를 읽으면 `1,홍길동,"서울, 강남구","여러 줄⏎둘째 줄"` 같은 입력에서 무엇이 깨지나? RFC 4180의 규칙 셋(인용, 따옴표 이스케이프, 줄바꿈)과 그 문서의 규범 수준(어떤 종류의 RFC인가)은?
2. (그림) CSV 파서의 상태 기계를 그려라. 상태는 몇 개이고, 쉼표·줄바꿈·따옴표가 각 상태에서 무엇을 뜻하나? 파일이 따옴표 안에서 끝나면?
3. (예측) CP949로 저장된 파일을 서버가 UTF-8로 읽는다. Java `Files.readAllLines(p, UTF_8)`, Java `new String(bytes, UTF_8)`, PostgreSQL `COPY`는 각각 어떻게 반응하나? 이 중 가장 위험한 것은?
4. (경계) "똠방각하"가 든 파일을 EUC-KR로 읽으면? CP949와 EUC-KR은 어떤 관계인가? 브라우저(WHATWG)의 `euc-kr` 레이블은 실제로 무엇을 뜻하나? PostgreSQL에서는 어떤 인코딩 이름을 써야 하나?
5. (장애 진단) 내려받은 UTF-8 CSV를 엑셀에서 열면 한글이 깨지고, 반대로 사용자가 올린 UTF-8 파일은 첫 열 헤더 검증이나 첫 행 정수 변환에서만 실패한다. 두 현상의 공통 원인과 각각의 대처는?
6. (예측) id가 정수인 4열 테이블에 `1,a,b,c / X,b,c,d / 3,c,d,e / 4,d,e`를 넣는다. PostgreSQL 17 기본 COPY, `ON_ERROR ignore`, MySQL 8.4 strict `LOAD DATA`, `LOAD DATA … IGNORE`의 결과는 각각?
7. (설계) 3만 행 업로드에서 10행이 틀렸다. 사용자에게 무엇을 보여 줘야 하나? 가져오기의 단계(인코딩 → 파싱 → 검증 → 정책 → 적재)마다 무엇을 하나?
8. (장애 진단) 대용량 업로드 때 서버가 `OutOfMemoryError`로 죽는다. 어떤 코드 패턴을 의심하나? 스트리밍 파서로 바꿔도 메모리가 폭주할 수 있는 입력은 무엇이고, 어떻게 막나?
9. (보안) 사용자 입력을 CSV로 내보냈는데 관리자 PC에서 `=HYPERLINK(…)`가 수식으로 동작했다. CSV 인용(`"…"`)으로 왜 못 막나? OWASP가 드는 위험 시작 문자와 완화법, 그리고 그 완화의 한계는?
