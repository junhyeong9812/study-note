# database/36-data-models-document-graph — 질문

## 질문

1. (왜) 이력서 데이터를 관계 모델과 문서 모델로 각각 표현하고, 문서 모델이 유리한 이유(지역성)와 그 이득이 사라지는 조건을 설명하라.
2. (경계) 사용자 문서에 소속 회사를 넣을 때, 회사 이름을 복사하는 방식과 회사 id로 참조하는 방식은 각각 어떤 비용을 누가 치르나? DDIA가 IMS 이야기를 꺼내는 이유는?
3. (경계) "스키마리스"가 오해인 이유를 스키마 온 리드/온 라이트로 설명하라. 스키마 온 리드가 더 나은 두 경우는?
4. (예측) PostgreSQL `jsonb` 열에 `{"name":"lee","age":"unknown"}`을 넣으면? MySQL `JSON` 열에 `'{bad json'`을 넣으면? 두 DB의 JSON 타입이 쓰기 때 검사하는 것과 하지 않는 것은?
5. (예측) 나이가 31, "unknown", 40인 세 문서에서 평균 나이를 PostgreSQL `avg((doc->>'age')::int)`과 MySQL `avg(doc->'$.age')`로 구하면 각각 어떻게 되나?
6. (그림) 속성 그래프를 관계 DB에 담는 두 테이블과 인덱스를 적어라. "미국에서 태어나 유럽에 사는 사람" 질의가 어려운 이유와, Cypher와 SQL이 각각 이를 어떻게 표현하나?
7. (설계) 상품마다 속성이 제각각이라 `jsonb`를 쓰려 한다. 어떤 것은 열로, 어떤 것은 jsonb로 두고, 어떤 제약·인덱스를 걸겠나? 이미 위반 데이터가 있을 때 제약은 어떻게 추가하나?
8. (장애 진단) 문서 DB에 복사해 둔 회사 이름이 사용자마다 다르게 보인다. 원인, 확인 방법, 근본 대처는?
9. (장애 진단) 수백 KB 사용자 설정 문서를 필드 하나씩 자주 갱신하는 서비스에서 대기와 쓰기량이 늘었다. PostgreSQL 문서와 DDIA가 설명하는 원인과 대처는?
