5. (예측) PostgreSQL 17 READ COMMITTED에서 두 세션이 같은 행을 `UPDATE ... SET version = 8 WHERE id = 1 AND version = 7`로 거의 동시에 고친다. 두 번째 세션은 어떤 과정을 거쳐 몇 행을 고치나?
