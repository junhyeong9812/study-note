1. (왜) 복제로 풀리지 않는 두 가지를 분할은 어떻게 푸나? 샤딩 전에 "한 인스턴스 안 선언적 분할"을 먼저 검토하는 이유는?
2. (경계) 키 범위 분할과 해시 분할을 범위 조회·쓰기 분포·핫 키 대응으로 비교하라. 해시 분할이면 핫 키 문제도 사라지나?
3. (예측) PostgreSQL 17에서 `created`로 월 단위 범위 분할한 테이블에 (a) `WHERE created >= '2026-09-10'` (b) `WHERE user_id = 7`(인덱스 있음)을 실행한다. 각각의 `EXPLAIN` 모양을 예측하라.
4. (예측) 이 테이블에 `ALTER TABLE ev ADD PRIMARY KEY (id)`를 실행하면? 왜 그런가? MySQL 8.4에서 대응되는 규칙과 에러 번호는?
5. (경계) 로컬(문서 기준) 보조 인덱스와 글로벌(용어 기준) 보조 인덱스의 읽기·쓰기 비용을 비교하라. 샤딩된 서비스에서 "이메일 중복 금지"는 어떻게 구현하나?
6. (계산) 키 10만 개를 `hash % 4`에서 `hash % 5`로 바꾸면 대략 몇 %가 움직이나? 일관 해싱에서 노드당 가상 노드가 1개일 때와 100개일 때 이동량·부하가 어떻게 다른가(로컬 시뮬레이션 수치 기준)?
7. (설계) 재조정 전략 네 가지(`hash % N`, 고정 파티션 수, 동적 분할, 일관 해싱)를 "키 → 파티션 대응이 바뀌나"와 "이동 단위"로 비교하라. 원본이 "사전 분할"을 권하는 이유는?
8. (장애 진단) 샤드를 8 → 16개로 늘렸는데 특정 화면의 p99 지연이 오히려 늘었다. 무엇을 확인하고 어떻게 고치나?
9. (장애 진단) 앱 이중 쓰기 + 백필로 샤드를 옮겼다. 행 수는 같은데 일부 행이 옛 값이다. 경쟁이 일어나는 시간축을 그리고, 재발 방지책 세 가지를 말하라.
