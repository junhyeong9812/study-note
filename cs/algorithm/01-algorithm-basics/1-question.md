# algorithm/01-algorithm-basics — 질문

## 질문

1. (왜) 알고리즘 성능을 "몇 초 걸렸나"가 아니라 "n이 두 배가 될 때 일이 몇 배가 되나"로 보는 이유는? 테스트 데이터 100건과 운영 100만 건의 예로 설명하라.
2. (계산) 정렬된 `[1..10]`에서 원본 이진 탐색으로 1을 찾으면 mid를 몇 번 확인하나? 최악은 몇 번이고, n = 1,000,000이면 최악 몇 번인가?
3. (예측) 원본 거품 정렬과 퀵 정렬을 무작위 정수 n = 1,000 → 2,000 → 4,000으로 돌리면 두 배마다 시간은 각각 몇 배쯤 되겠나? 거품 정렬 n = 100,000은 대략 얼마가 걸리겠나(추정 근거 포함)?
4. (장애 진단) 원본 `binary_search`를 조회 API에서 질의마다 불렀더니, 이진 탐색인데 선형 탐색과 비슷하게 느렸다. 무엇 때문인가? 이 함수의 부작용 두 가지도 대라.
5. (경계) 원본 §1의 예 "O(1) — map", "O(log n) — 이진 탐색 트리", "O(n log n) — 퀵 정렬"에 각각 붙어야 할 조건은?
6. (예측) Java에서 `int lo = 1_500_000_000, hi = 2_000_000_000;`일 때 `(lo + hi) / 2`, `lo + (hi - lo) / 2`, `(lo + hi) >>> 1`의 값은? 파이썬 원본 `(start + end) // 2`는 왜 문제가 없나?
7. (적용) n = 100만인 ID 목록에 질의가 1만 번 온다. 선형 탐색과 "정렬 1번 + 이진 탐색"의 비교 횟수를 어림하고, Java 21 표준 라이브러리로 쓰는 코드를 적어라. `Arrays.binarySearch`가 음수를 돌려주면 무엇을 뜻하나?
8. (장애 진단) 배치가 스테이징에서 30 ms였는데 운영에서 타임아웃 났다. 원인이 알고리즘 차수인지 확인하는 방법과, 확인됐을 때 대처를 적어라.
9. (경계) 원본 거품 정렬에 이미 정렬된 n개를 넣으면 비교를 몇 번 하나? 최선을 O(n)으로 만들려면 무엇을 더해야 하나?
