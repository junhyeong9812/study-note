# algorithm/12-hash-functions — 질문

## 질문

1. (왜) 해시 함수가 "충돌이 없게" 만들어질 수 없는 이유는? 그렇다면 해시 테이블용 해시가 좋다는 것은 무엇을 뜻하나? 외부 입력을 받는 서버라면 조건이 하나 더 붙는데, 그것은?
2. (그림) Java에서 `map.put("Aa", 1)`이 칸 번호를 정하기까지의 세 단계(`String.hashCode` → `HashMap.hash` → 인덱스)를 식과 함께 그려라. `"Aa"`와 `"BB"`가 같은 칸에 가는 이유와, 이 둘로 충돌 문자열을 2^k개 만드는 원리는?
3. (예측) 같은 hashCode를 갖는 키 n개를 `HashMap`에 넣고 전부 조회한다. 키가 `String`일 때와, `hashCode`·`equals`만 위임하고 `Comparable`이 아닌 래퍼일 때, n을 8192 → 16384로 두 배 늘리면 시간이 각각 대략 몇 배가 되나? 이유는 `HashMap` 소스의 어느 규칙인가?
4. (경계) 유니버설 해시 족의 정의는? `((a·x + b) mod p) mod m`에서 무작위로 고르는 것은 무엇이고, 그 보장(기대 비교 수)은 어떤 가정이 깨지면 사라지나?
5. (연결) SipHash가 유니버설 해싱이나 SHA-256 대신 해시 테이블 방어용으로 제안된 이유를 Aumasson–Bernstein 논문의 논리로 설명하라. SipHash-2-4의 2와 4는 무엇인가?
6. (예측) CPython 3.12에서 `python3 -c "print(hash('abc'))"`를 세 번 돌리면? `PYTHONHASHSEED=0`을 주면? `hash(12345)`는?
7. (장애 진단) 다운로드 파일 위조를 막으려고 CRC32를 함께 배포했다. 무엇이 문제인가? CRC의 어떤 성질 때문이며, 무엇으로 바꿔야 하나?
8. (장애 진단) 웹 서버 CPU가 100%인데 요청률은 평소와 같다. 스레드 덤프에 `HashMap$TreeNode.find`가 여러 스레드에서 반복된다. 가능한 원인 두 가지와 확인·대처 순서는?
9. (경계) 샤드 번호를 `Math.abs(key.hashCode()) % n`으로 계산하면 어떤 키에서 무엇이 터지나? 고친 식은?
