# algorithm/02-asymptotic-analysis — 질문

## 질문

1. (정의) O, Ω, Θ를 상수 c·n₀를 써서 정의하라. "삽입 정렬은 O(n³)이다"는 참인가? 실무에서 "O(n²)"를 말할 때 흔히 뜻하는 것은?
2. (예측) 삽입 정렬에 n = 4,000인 정렬된 배열, 무작위 배열, 역순 배열을 넣으면 비교 횟수는 각각 대략 얼마인가?
3. (경계) "평균 경우"와 "기대 실행 시간"은 어떻게 다른가? 각각 무엇에 대한 평균인가? 실무 SLA에 최악을 기본으로 쓰는 이유는?
4. (계산) OpenJDK 21 `ArrayList`(처음 용량 10, 1.5배 확장)에 원소 100만 개를 add하면 확장 복사로 옮겨지는 원소 수 합은 대략 얼마인가? 꽉 찰 때마다 10칸씩만 늘린다면?
5. (경계) 분할상환 O(1)과 평균 경우 O(1)은 무엇이 다른가? 분할상환 O(1)인 연산 한 번이 수백 ms 걸릴 수 있나? 실험 근거로 답하라.
6. (예측) 크기를 두 배로 할 때 O(n) 합계, `Arrays.sort(int[])`, 모든 쌍 비교의 시간 비율은 각각 얼마쯤 나오겠나? 두 배 실험으로 O(n)과 O(n log n)을 가를 수 있나?
7. (장애 진단) 테스트 데이터 100건에서 1 ms이던 이중 루프 대조가 운영 100만 건에서 타임아웃 났다. 비교 횟수를 계산하고, 실측 한 점(n = 40,000에서 약 0.73초)에서 운영 시간을 외삽하라. 대처는?
8. (연결) OpenJDK 21 `DualPivotQuicksort`가 길이 44 미만인 (가장 왼쪽) 구간을 삽입 정렬로 처리하는 것은 점근 분석과 모순인가? 무엇을 보여 주나?
9. (장애 진단) 처리량은 정상인데 가끔 한 요청이 수백 ms 멈추고, GC 로그에 `G1 Humongous Allocation`이 찍힌다. 분할상환과 어떤 관계가 있고, 어떻게 줄이나?
