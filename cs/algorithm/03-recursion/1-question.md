# algorithm/03-recursion — 질문

## 질문

1. (왜) 재귀 함수가 맞다는 것을 보이려면 무엇 세 가지를 확인하나? 그것이 수학적 귀납의 어느 부분과 짝지어지나?
2. (그림) `fact(3)`을 호출했을 때 호출 스택이 어떻게 쌓였다가 걷히는지 그려라. 각 프레임에는 무엇이 들어 있나?
3. (예측) OpenJDK 21에서 `-Xint`로 지역 변수 없는 무한 재귀를 돌렸더니 `-Xss1m`에서 깊이 10,718에서 넘쳤다. `-Xss2m`이면 대략 얼마일까? 지역 변수가 많은 프레임이면 같은 `-Xss1m`에서 어떻게 달라지나? JIT를 켜면 왜 값이 실행마다 흔들리나?
4. (경계) 꼬리 재귀란 무엇이고, 이론상 왜 스택이 필요 없나? OpenJDK 21에서 `sumTail(1_000_000, 0)`을 기본 스택으로 돌리면 어떻게 되나? Kotlin과 Node.js 22는 각각 어떤가?
5. (예측) 메모 없는 `fib(n)`의 호출 수는 n이 2 늘 때마다 몇 배가 되나? 그 수는 어디서 나오나? 메모이제이션을 하면 호출 수는 n에 대해 어떻게 되나?
6. (경계) 메모이제이션이 효과가 있는 재귀와 없는 재귀를 하나씩 들고, 차이를 "중복 부분문제"로 설명하라.
7. (적용) 정렬된 키를 차례로 넣은 BST의 노드 수를 재귀로 세면 무엇이 문제인가? 명시적 스택으로 바꾸면 깊이 한계가 어디로 옮겨 가나?
8. (장애 진단) 운영 로그에 `java.lang.StackOverflowError`와 같은 줄이 천여 줄 반복된 트레이스가 찍혔는데 `main`이나 컨트롤러 프레임이 안 보인다. 왜 그런가? 원인 후보 셋과 확인 방법을 대라.
9. (장애 진단) 외부에서 받은 JSON 한 건으로 요청 스레드가 죽었다. 재귀와 어떤 관계이고, 어떻게 막나?
10. (연결) 퀵 정렬의 재귀 깊이를 O(log n)으로 묶는 방법은? 이것이 이 노트의 "재귀 → 반복 변환"과 어떻게 이어지나?
