public static List<Integer> findAll(CountedText text, String pattern, long[] patternComparisons) {

    //   시작 위치가 어디인가. i 에서 무엇을 빼야 하나.
    //   그 다음에 matched 를 0 으로 두면 무엇을 놓치나.
    //   "aaa" 안에서 "aa" 를 찾으면 몇 개가 나와야 하나.

- KMP 에서 `text.backtrack()` 을 부를 일이 정말 없는가, 그것이 왜 "KMP 의 전부"인가?
- 어긋났을 때 보는 값이 `failure[matched]` 가 아니라 `failure[matched-1]` 인 이유는?
- 되돌린 뒤 또 어긋날 수 있으니 `if` 가 아니라 `while` 이어야 하는 이유는?
- 다 맞췄을 때 발견 시작 위치는 `i` 에서 무엇을 빼는가?
- 발견 직후 `matched` 를 0 으로 두면 무엇을 놓치는가 — `"aaa"` 속 `"aa"` 는 몇 개인가? (원본 함정)
- 그래서 발견 직후에도 `failure[m-1]` 을 쓰는데, 그것이 뜻하는 상태는 무엇인가?
- 빈 패턴을 나이브와 KMP 가 똑같이 다뤄야 하는 이유는?
- 최악 입력에서 되돌림이 나이브 9,900번 대 KMP 0번이라는 수는 무엇을 세는 것인가? (원본 측정 하나·둘)
