#### 1. 버블 정렬 (BubbleSort, TODO 1~4)

```java
/**
 * 버블 정렬. 인접한 둘을 비교해 어긋나 있으면 교환한다.
 * <p>한 바퀴 돌면 가장 큰 원소가 끝에 확정된다.
 */
// TODO 1: 바깥 루프.
//   한 바퀴에 원소 하나가 뒤쪽에 확정된다. 그러면 다음 바퀴는 어디까지만 보면 되나.
// TODO 2: 안쪽 루프.
//   a.compare(i, i + 1) 이 어떤 부호일 때 a.swap(i, i + 1) 을 해야 하나.
//   등호를 포함시키면 어떻게 되나. 값이 같은 둘을 굳이 바꾸면 무엇을 잃나.
// TODO 3: 조기 종료.
//   한 바퀴 동안 교환이 한 번도 없었다면 그 배열은 어떤 상태인가.
// TODO 4: stable() — 이 정렬이 안정인지 판단해서 선언하라.
```

- 한 바퀴가 끝나면 무엇이 확정되고, 그래서 다음 바퀴는 어디까지만 보면 되는가?
- `compare(i, i+1)` 가 어떤 부호일 때 교환해야 하는가?
- 비교에 등호를 포함하면(`>=`) 결과는 여전히 정렬되는데 무엇을 잃는가?
- 한 바퀴 동안 교환이 0번이면 배열은 어떤 상태이고, 그때 무엇을 해야 하는가?
- 조기 종료 한 줄이 있고 없고에 따라 이미 정렬된 입력의 비용이 어떻게 달라지는가?
- 버블 정렬은 안정인가, 그 근거는 무엇인가?

#### 3. 삽입 정렬 (InsertionSort, TODO 8~11)

```java
/**
 * 삽입 정렬. 앞쪽을 정렬된 구간으로 두고, 원소 하나를 빼서 그 안의 제자리에 꽂는다.
 */
// TODO 8: i 번째 원소를 배열 밖으로 빼둔다(key).
//   빼두지 않고 교환으로만 처리하면 쓰기 횟수가 어떻게 달라지나.
// TODO 9: 뺀 값보다 큰 원소들을 한 칸씩 뒤로 민다.
//   비교는 a.compareTo(j, key) 를 쓴다. 부등호에 등호를 넣으면 무엇이 깨지나.
//   j 가 0 보다 작아지는 경우를 먼저 막지 않으면 무슨 일이 생기나.
// TODO 10: 뺀 값을 빈 자리에 꽂는다. 꽂을 자리는 j 인가 j+1 인가.
// TODO 11: stable() — TODO 9 의 부등호를 어느 쪽으로 골랐는지에 달려 있다.
```

- key 를 배열 밖으로 빼두지 않고 교환으로만 처리하면 쓰기 횟수가 어떻게 달라지는가?
- 비교를 `compare(i, j)` 가 아니라 `compareTo(j, key)` 로 해야 하는 이유는 무엇인가?
- 부등호에 등호를 넣으면 결과는 여전히 정렬돼 있는데 무엇이 깨지는가?
- `j >= 0` 검사와 비교 중 어느 쪽을 먼저 해야 하고, 순서를 바꾸면 무슨 일이 생기는가?
- 밀기 루프가 끝났을 때 key 를 꽂을 자리는 j 인가 j+1 인가, 왜인가?
- 삽입 정렬이 "거의 정렬된 입력"에서 강한 이유는 무엇인가?

/**
 * 셸 정렬. 삽입 정렬을 간격 gap 으로 띄워서 하고, gap 을 줄여가며 반복한다.
 * <p>삽입 정렬의 약점은 원소가 한 칸씩만 움직인다는 것이다.
 */
// TODO 12: 간격 수열의 시작값을 정한다.
//   크누스 수열은 1, 4, 13, 40, ... (다음 항 = 이전 항 x 3 + 1)
//   n 보다 큰 간격에서 시작하면 그 바퀴는 아무 일도 하지 않는다. 어디서 멈춰야 하나.
// TODO 13: 간격을 줄여가며 각 간격으로 삽입 정렬을 한다.
//   TODO 8~10 과 같은 코드인데 이웃이 j-1 이 아니라 j-gap 이다.
//   마지막 바퀴(gap == 1)는 그냥 삽입 정렬이다. 그런데도 왜 전체가 빨라지나.
//   간격을 1 로 끝내지 않으면 무엇이 보장되지 않나.
// TODO 14: stable() — gap 이 3 이면 원소가 3 칸을 건너뛴다. 그 사이의 같은 값은?

- 셸 정렬은 삽입 정렬의 어떤 약점을 어떻게 고친 것인가?
- 간격 시작값은 어디서 멈춰야 하고, n 이상의 간격에서 시작하면 무슨 일이 생기는가?
- 시작값을 n/3 대신 n/2 로 잘못 잡으면 틀리는가, 아니면 다른 종류의 문제인가?
- 마지막 바퀴(gap=1)는 그냥 삽입 정렬인데 왜 전체가 O(n^2) 를 벗어나는가?
- 간격을 1 로 끝내지 않으면 무엇이 보장되지 않는가?
- 각 바퀴 안에서는 안정적으로 미는데도 셸 정렬이 안정이 아닌 이유는 무엇인가?
