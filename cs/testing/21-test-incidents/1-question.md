# testing/21-test-incidents — 질문

## 질문

1. (사실) goto fail의 결함은 어느 파일·어느 함수의 무엇이었나? 수정 전후 소스 태그를 비교하면 diff는 몇 줄이고 어떤 모양인가? iOS와 OS X의 수정판은 각각 언제 나왔나?
2. (왜) 중복된 `goto fail;` 뒤에 함수가 "성공"을 돌려준 이유를 `err` 변수와 호출자 코드로 설명하라. TLS 1.2 연결은 왜 이 함수의 영향을 받지 않았나(원문 근거)?
3. (예측) 실험 A-2의 결함판에 (가) 양성 테스트만, (나) 음성 테스트 3개를 더해 돌리면 각각 결과는? 음성 테스트의 실패 메시지는 무엇을 말해 주나?
4. (구분) 같은 "중복된 탈출 한 줄"을 Java로 쓰면 javac는 어떻게 반응하나(실험 A-1)? C에서 Langley가 관찰한 GCC·Clang `-Wall`의 반응과 비교하고, 언어 차이가 시험 전략에 주는 의미를 말하라.
5. (사실) CrowdStrike 채널 파일 291에서 개수 불일치는 정확히 무엇과 무엇 사이였나? RCA가 꼽은 세 요소의 "합류"를 원문대로 말하라.
6. (장애 진단) IPC Template Type은 시험 사례 12개·스트레스 시험을 통과했고, 운영에 나간 인스턴스 네 개도 정상 동작했다. 그런데도 결함이 남은 이유를 시험 입력의 관점(동치 분할)에서 설명하라. 실험 B의 어느 시험이 이것을 잡았나?
7. (연결) Content Validator가 문제 콘텐츠를 통과시킨 구조를 테스트 대역(03)·계약 테스트(13)의 말로 바꿔 설명하라. RCA의 조치 중 이 구조를 직접 겨냥한 것 두 가지는?
8. (경계) 이 노트의 "사실"과 "해석"을 하나씩 짝지어 보라. 예: "OS X 사용자는 원인 공개 뒤 며칠 동안 수정판 없이 있었다"는 무엇에서 나온 해석인가? CrowdStrike 사건의 운영 관점(영향 규모·복구)은 왜 이 노트가 아니라 reliability/53에서 다루나?
