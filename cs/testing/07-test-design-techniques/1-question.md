# testing/07-test-design-techniques — 질문

## 질문

1. (왜) 입력을 아무 값이나 몇 개 넣는 테스트는 왜 경계 결함을 거의 못 잡나? 동치 분할과 경계값 분석은 각각 무엇을 정해 주나?
2. (분할) 배송비 명세 "1..2000g → 3000원, 2001..5000g → 4000원, 5001..30000g → 6000원, 그 밖 → 거부"의 동치 분할을 전부 적어라. EP 100%에는 테스트가 몇 개 필요한가? 무효 분할도 세나?
3. (예측) 위 명세에서 경계 하나를 어긋나게 짠 구현 4개(`<=2000 → <2000`, `<=5000 → <=5001`, `<1 → <0`, `>30000 → >=30000`)가 있다. 분할 대표값 5개, 2값 경계값 8개, [-1000, 40000]에서 균등하게 뽑은 무작위 8개는 각각 몇 개를 잡을까? 무작위 쪽 검출률의 크기를 어림해 보라.
4. (경계) 2값 BVA와 3값 BVA의 차이는? `if (x <= 10)`이 `if (x == 10)`으로 잘못 구현됐을 때 어느 쪽이 잡나? BVA를 쓸 수 없는 분할은?
5. (결정 테이블) "VIP이고 10만 원 이상이면 10%, 아니면 5만 원 이상이면 5%, 그 밖은 할인 없음"의 결정 테이블을 그려라. 조건 3개인데 왜 열이 8개가 아닌가? 사람이 가장 빠뜨리기 쉬운 열은?
6. (상태 전이) 주문 상태 5개(CREATED·PAID·SHIPPED·DELIVERED·CANCELLED)와 이벤트 4개(pay·ship·deliver·cancel)에서, 모든 상태·유효 전이·모든 전이 커버리지는 각각 무엇을 요구하나? "SHIPPED에서 cancel을 허용"하는 버그는 어느 기준부터 잡히나?
7. (예측) 인자 5개(3·3·3·4·2값)의 전수 조합은 몇 개인가? pairwise 집합은 최소 몇 행 이상이어야 하나? 탐욕법으로 만든 집합은 몇 행이었고, 세 인자 조합은 얼마나 덮었나?
8. (연결) pairwise가 효과적이라는 근거로 CTAL-TA가 드는 관찰은 무엇이고, pairwise가 보장하지 않는 것은?
9. (장애 진단) 정확히 5만 원짜리 주문만 쿠폰이 안 먹는다는 문의가 왔다. 예외 로그는 없다. 의심할 코드 모양과, 다시 생기지 않게 할 테스트를 대라.
10. (장애 진단) 이미 출고된 주문이 취소·환불됐다. 테스트는 전부 초록이었다. 테스트 스위트에서 무엇이 빠졌을 가능성이 크고, 어떻게 메우나?
