# testing/09-flaky-tests — 질문

## 질문

1. (왜) 불안정 테스트 몇 개가 "가끔 빨강"을 내는 것이, 테스트가 아예 없는 것보다 나쁠 수 있는 이유는? SWE@G 11장과 Google Testing Blog(2016)의 수치 하나씩을 들어 설명하라.
2. (분류) Luo 외 FSE 2014가 분류한 상위 세 원인과 그 비율은? 나머지 일곱 범주 중 셋을 대고, 각 범주에서 "테스트가 통제하지 않는 숨은 입력"이 무엇인지 말하라.
3. (예측) 공유 정적 리스트를 쓰는 테스트 세 개(`addOne`·`addTwo`는 원소를 넣고 자기 원소가 있는지만 확인, `startsEmpty`는 크기가 0인지 확인)를 무작위 순서로 20번 돌리면 대략 몇 번 실패할까? 이유와 함께 예측하고, `@BeforeEach`로 초기화하면 어떻게 되나?
4. (예측) 약 30ms 걸리는 비동기 작업을 `Thread.sleep(50)` 뒤에 검사하는 테스트가 있다. 같은 JVM에서 CPU를 쓰는 부하 스레드를 0·2·4개 띄우고(`--cpus=2`) 50번씩 돌리면 실패 횟수가 어떻게 변할까? `Future.get(5, SECONDS)`로 기다리는 판은?
5. (경계) Surefire `rerunFailingTestsCount=3`이 켜진 빌드에서 어떤 테스트가 Run 1·Run 2 실패, Run 3 통과했다. 빌드 결과와 요약 줄은 어떻게 나오나? 이 설정이 "진짜 결함"을 가리는 조건은?
6. (경계) JUnit 5의 기본 테스트 메서드 순서는 무작위인가? 기본 순서에서 순서 의존 테스트가 몇 달간 초록이다가 갑자기 깨지는 경로를 설명하라.
7. (연결) Luo 논문의 F.12(수정의 24%가 제품 코드를 고쳤고 그중 94%가 버그 수정)가 "불안정 테스트는 일단 격리한다"는 운영 방식에 주는 경고는? 격리를 쓸 때 붙여야 할 조건 세 가지는?
8. (장애 진단) `OrderServiceTest`가 단독 실행에서는 통과하고 전체 실행에서만 실패한다. 원인 범주를 짐작하고, 테스트 200개 중 오염자 하나를 효율적으로 찾는 절차를 대라.
9. (계산) 어떤 테스트를 50번 돌려 한 번도 실패하지 않았다. 실패율이 0이라고 말해도 되나? 실패율 0.5인 테스트에 독립 재시도 3회를 붙이면 끝내 빨강으로 남는 비율은?
