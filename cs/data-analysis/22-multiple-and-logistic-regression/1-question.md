# data-analysis/22-multiple-and-logistic-regression — 질문

## 질문

1. (왜) 단순 회귀 `이탈 ~ 문의`의 계수와 다중 회귀 `이탈 ~ 문의 + 미접속일`의 문의 계수가 다른 이유는? 다중 회귀의 계수는 무엇을 "고정한" 기울기인가?
2. (예측) 참 모형이 `y = x₁ + x₂ + 잡음`이고 x₂가 x₁과 상관 0.999로 거의 같다. n = 50 표본 10개에서 각각 회귀하면 b₁·b₂와 b₁ + b₂는 어떻게 나오나? 상관이 0.69로 낮아지면? 실험 출력으로 확인하라.
3. (경계) 위 실험에서 같은 seed라면 상관 0.999일 때와 0.69일 때 b₁ + b₂가 소수 둘째 자리까지 똑같았다. 우연인가? 이유를 설명하라.
4. (예측) 참 모형 `y = 2x + 잡음`, n = 40에 순수 잡음 변수를 15개까지 더하면 R²·수정 R²·새 데이터 R²는 각각 어떻게 움직이나? 수정 R²는 과적합을 막아 주었나?
5. (그림) 확률 p와 logit(p)의 대응을 몇 점 그려라. 로지스틱 회귀에서 b₁ = 1.5는 무엇의 변화이고, "확률이 1.5 오른다"는 말은 왜 틀렸나?
6. (계산) 로지스틱 회귀를 경사 하강으로 풀 때 한 번의 갱신에서 쓰는 기울기는 무엇인가? 시그모이드를 계산할 때 `1/(1+exp(−z))`를 그대로 쓰면 어떤 z에서 문제가 생기고, 어떻게 피하나?
7. (장애 진단) 이탈 예측 모델이 오프라인 시험 정확도 97.7%, AUC 0.99였는데 운영에서 이탈자를 거의 못 잡는다. 실험에서 누설 변수를 `leak = 0`으로 넣었을 때 정확도·AUC·이탈 예측 비율은 어떻게 됐나? 왜 AUC는 덜 떨어졌나?
8. (장애 진단) 누설을 찾는 점검 순서 세 가지를 대고, 특징을 기준 시각 이전 값으로만 만드는 SQL의 모양을 적어라.
9. (연결) 다중 회귀 계수가 상식과 반대 부호일 때 원인 후보로 다중공선성 말고 무엇이 있나? ([25](../25-causal-inference-basics/2-summary.md)과 연결)
