# data-analysis/25-causal-inference-basics — 질문

## 질문

1. (왜) "변수를 많이 통제할수록 인과 추정이 좋아진다"는 생각은 왜 틀렸나? 통제해야 할 변수와 통제하면 안 되는 변수를 DAG 모양으로 구분하라.
2. (그림) 사슬·분기·충돌 세 모양을 그리고, 가운데 변수를 통제했을 때와 안 했을 때 경로가 열리는지 막히는지 표로 적어라.
3. (예측) 참 효과 1.0인 선형 데이터에서 (1) 교란 Z, (2) 매개 M, (3) 충돌 C를 각각 회귀에 넣으면 X의 계수는 몇 근처가 되나? 실험 출력으로 확인하라.
4. (예측) 서로 독립인 재능 X와 운 Y가 있고 `X + Y > 1.5`인 사람만 합격한다. 합격자만 보면 X와 Y의 상관은? 이런 착시가 생기는 실무 예를 하나 들어라.
5. (계산) DAG `Z→X, Z→Y, X→M→Y, X→C←Y, C→D`에서 X → Y 전체 효과를 위한 조정 집합은? `{Z, M}`, `{Z, C}`, `{Z, D}`는 각각 무엇이 잘못됐나? 뒷문 기준의 두 조건으로 답하라.
6. (계산) 서울(처리) 100 → 108, 지방(비처리) 70 → 75일 때 DiD 추정치는? 이 계산이 기대는 가정은 무엇이고, 서울이 원래 +4 더 오르는 추세였다면 추정은 어떻게 되나?
7. (경계) 도구 변수의 세 조건을 대고, 데이터로 확인할 수 있는 것과 없는 것을 구분하라. 1단계(도구 → 처리) 효과가 0.02뿐이면 무슨 일이 생기나?
8. (장애 진단) "푸시 알림은 구매에 효과 없다"는 분석이 회귀에 "앱 방문 수"를 통제 변수로 넣었다. 무엇이 문제이고 어떻게 다시 분석하나?
9. (연결) A/B 테스트에서 "처리를 실제로 사용한 사람만" 분석하면 왜 편향되나? 배정을 도구로 쓰는 추정과 ITT는 각각 무엇을 답하나? ([15](../15-ab-pitfalls-srm-peeking/2-summary.md)의 처리 후 필터와 연결)
