# data-analysis/25-causal-inference-basics — 정답

## 정답

### 1. "많이 통제할수록 좋다"가 틀린 이유

- 교란(분기 `X ← Z → Y`)은 통제해야 한다. 통제하지 않으면 Z를 통한 가짜 연관이 효과에 섞인다.
- 매개(사슬 `X → M → Y`)를 통제하면 X의 효과가 지나가는 길을 막아 효과를 지운다.
- 충돌(`X → C ← Y`)을 통제·선택하면 막혀 있던 길을 열어 없던 연관을 만든다. 충돌의 자손을 통제해도 그렇다(Primer 2.3).
- 그래서 통제 여부는 변수 수가 아니라 원인 구조(DAG)로 정한다.

### 2. 세 모양과 통제

```text
  사슬  X → M → Y     분기  X ← Z → Y     충돌  X → C ← Y
```

| | 통제 안 함 | 가운데 변수 통제 |
|---|---|---|
| 사슬 | 열림 | 막힘 |
| 분기 | 열림 | 막힘 |
| 충돌 | 막힘 | **열림** |

### 3. 회귀에 넣은 변수별 X 계수

- (1) 교란: Z 없이 2.202(이론 2.2), Z를 넣으면 1.004. 통제해야 맞다.
- (2) 매개: X만 1.020(전체 효과), M을 넣으면 0.025. 효과가 전부 M을 거치므로 M을 고정하면 남는 것이 없다.
- (3) 충돌: X만 1.005, C를 넣으면 −0.006. C > 1인 행만 남겨도 0.535로 줄었다.

### 4. 합격자 선택의 착시

- 전체 상관 0.014(거의 0), 합격자 2,862명만 보면 −0.676.
- 합격 = 두 변수의 합이 크다는 조건이다. 합격자 중 재능이 낮은 사람은 운이 좋았어야 하므로 음의 상관이 생긴다.
- 실무 예: "유명해진 앱 중에서는 기능이 많을수록 디자인 점수가 낮다", "문의한 고객 중에서는 알림 수신자가 구매가 적다" — 선택 기준이 두 변수의 영향을 받는 경우다.

### 5. 조정 집합 판정

- 정답: `{Z}`. Z는 X의 자손이 아니고, X로 들어오는 경로 `X ← Z → Y`를 막는다. 인과 경로 `X → M → Y`는 열어 두고, 충돌 경로 `X → C ← Y`는 막힌 채로 둔다.
- `{Z, M}`: M은 X의 자손이다(뒷문 기준 첫 조건 위반). 인과 경로를 막는다.
- `{Z, C}`: C는 X의 자손이고 충돌 변수다. 통제하면 충돌 경로가 열린다.
- `{Z, D}`: D도 X의 자손(C의 자손)이다. 충돌의 자손을 통제해 충돌 경로가 열린다.
- 경로 판정 코드의 출력이 이와 같다.

### 6. DiD 계산

- `(108 − 100) − (75 − 70) = 8 − 5 = +3`.
- 가정: 정책이 없었다면 서울도 지방과 같은 만큼 변했을 것(평행 추세, What If 기술 노트 7.3의 가법적 동일 교란).
- 서울이 원래 +4 더 오르는 추세였다면 그 4가 효과로 섞여 약 +7이 된다. 실험에서 참 효과 3, 추세 차이 4일 때 DiD 7.14였다.
- 점검: 정책 전 기간만으로 가짜 시작일을 두고 DiD를 구해 0 근처인지 본다(합성 SQL 실행에서 −0.223).

### 7. 도구 변수 조건

- ① Z가 X와 연관된다 — 데이터로 확인할 수 있다(1단계 차이).
- ② Z는 X를 거쳐서만 Y에 영향을 준다 — 데이터만으로 증명할 수 없다.
- ③ Z와 Y의 공통 원인이 없다 — 데이터만으로 증명할 수 없다. 무작위 배정이면 기대된다(What If 16.1). 같은 절은 세 조건 중 경험적으로 확인할 수 있는 것이 (i)뿐이라고 적는다.
- 1단계가 0.02뿐이면 Wald 추정이 작은 수로 나눠져 크게 흔들린다. 실험에서 재표집마다 1.66 ~ 6.81(참값 0.5)이었다.

### 8. 방문 수를 통제한 알림 분석

- 문제: 알림 → 방문 → 구매에서 방문은 매개 변수다. 통제하면 알림 효과가 지나가는 길을 막아 효과를 지운다(실험 0.025).
- 다시 분석: 처리 이후에 정해지는 변수(방문 수)를 통제에서 뺀다. 처리 이전의 교란(평소 활동성, 가입 기간)을 통제한다. 가능하면 알림 발송을 무작위로 나눠 실험한다.

### 9. "실제 사용자만" 분석

- 실제 사용 여부는 배정과 사용자 성향(열성도)이 함께 정한다. 사용자로 거르면 열성 사용자가 처리군 쪽에 몰려 선택 편향이 생긴다. 처리 후 행동으로 거르는 [15](../15-ab-pitfalls-srm-peeking/2-summary.md)의 봇 필터와 같은 구조다.
- ITT: 배정받은 대로 비교한다. "기능을 제공하면(권유하면) 효과가 얼마인가"에 답한다. 무작위성이 그대로 남아 편향이 없다.
- 배정을 도구로 쓴 IV(Wald): `ITT 효과 / (사용률 차이)`. 세 조건에 넷째 조건이 더해져야 해석이 정해진다. What If 16.3·16.4: 효과가 모두 같다는 동질성 조건이면 평균 인과 효과로, 단조성 조건이면 "배정에 따라 사용 여부가 바뀐 사람들(compliers)"의 효과로 읽는다. 어느 경우든 도구 조건 ②(배정이 사용을 거쳐서만 결과에 영향)를 가정한다.
