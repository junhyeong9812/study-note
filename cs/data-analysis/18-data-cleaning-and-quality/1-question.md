2. (계산) 관측이 12,000 / 없음 / 31,000 / 없음 / 18,000이다. 결측 제외 평균과 0으로 채운 평균을 구하라. 값이 모두 양수일 때 0 채움 평균이 항상 더 작은 이유는?

4. (예측) CSV 열 이름이 `amount`에서 `amount_krw`로 바뀐 파일을 `float(r.get("amount") or 0)`으로 읽으면 어떻게 되나? 에러가 나나? 어떻게 바꿔야 하나?

6. (장애 진단) 지역별 매출 표의 합이 전체 매출보다 8% 적다. 가장 먼저 의심할 원인과 확인 SQL, 리포트에서 바꿀 점은?
7. (예측) app 수집기는 KST, web 수집기는 UTC로 시간대 없는 문자열을 쓴다. 문자열 앞 10자로 일별 건수를 내면 어떤 날짜가 새로 생기고, 어느 날이 줄어드나?
8. (장애 진단) 분기 보고서의 합계가 회계 시스템보다 적고, 내보낸 파일이 정확히 10,000행이다. 무엇을 의심하고 어떤 검사로 재발을 막나? 같은 모양의 실사건은?
