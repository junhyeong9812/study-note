## 질문

1. (왜) 같은 분석을 다시 돌렸는데 결과가 달라지는 출처 다섯 가지를 대라. 각각 "같은 프로세스 안에서도 달라지나 / 프로세스마다 다른가 / 환경마다 다른가 / 처음부터 돌릴 때만 다른가" 중 어디에 해당하나?
2. (예측) 셀 c1(로드)·c2(결측 제거)·c3(200 상한)·c4(평균)에서, 작성자가 c3를 만들기 전에 c4를 실행해 출력을 저장했다. 저장된 값과 "위에서 아래로" 재실행한 값은? 실험 C의 숫자로 답하라.
3. (경계) c3를 상한 150으로 고쳐 한 번 실행했다가 200으로 되돌려 다시 실행했다. 결과는 왜 상한 200만 적용한 값과 다른가?
4. (원리) Python 3.12 `random` 문서가 버전 간에 보장하는 것과 보장하지 않는 것은? "시드만 고정하면 어느 버전에서나 같은 `choices` 결과"는 맞나?
5. (예측) 문자열 `set`에서 `max(set, key=count)`로 동률(40·40·40) 중 하나를 고르는 코드를 새 프로세스로 세 번 돌리면? `PYTHONHASHSEED`를 고정하는 것이 분석 코드의 올바른 해법이 아닌 이유는?
6. (계산) 값 12개(9, 10, 11, 12, 12, 13, 14, 14, 15, 16, 30, 80)의 p90을 `statistics.quantiles(n=10)` 기본값과 `method='inclusive'`로 구하라. PostgreSQL 17 `percentile_cont(0.9)`는 어느 쪽과 같은가?
7. (적용) Wilson 외 2017의 데이터 관리·소프트웨어 실천 중 이 노트가 고른 다섯 가지는? 원본이 너무 커서 복사해 둘 수 없을 때는 어떻게 하라고 하나?
8. (그림) raw → clean → features → report, dims → report의 DAG에서 dims만 바뀌면 무엇이 다시 실행되나? raw가 바뀌면? 입력 해시 키가 이것을 어떻게 가능하게 하나?
9. (장애 진단) 리뷰어가 같은 데이터로 부트스트랩 구간을 다시 냈더니 위쪽 끝이 32.42가 아니라 31.92다. 무엇을 확인하고 어떻게 고치나? 끝자리가 크게 흔들리는 것은 무엇의 신호인가?
