# data-analysis/09-hypothesis-testing — 질문

## 질문

1. (왜) 가설검정을 법정에 빗대어 설명하라. 귀무가설·p값·"기각하지 못함"은 각각 법정의 무엇에 해당하나?
2. (경계) OpenIntro의 p값 정의를 한 문장으로 쓰라. "p = 0.03이면 귀무가설이 참일 확률이 3%"는 왜 틀렸나? ASA 2016 원칙 몇 번이 이를 다루나?
3. (그림) 1종 오류·2종 오류·검정력을 2×2 표로 그려라. α를 0.05에서 0.01로 낮추면 같은 표본에서 무엇이 늘어나나? 둘 다 줄이려면?
4. (예측) 두 군 모두 전환율 10%(군당 5,000명)인 A/A 검정을 4000번 하면 p값 히스토그램은 어떤 모양이고 p < 0.05 비율은 얼마쯤인가? 이 실험에서 정확히 균등하지 않은 이유는?
5. (예측) 진짜 차이가 10% → 11%이고 군당 5,000명이면 p값 분포는 어떻게 바뀌나? p < 0.05 비율은 무엇을 뜻하나?
6. (계산) 군당 100만 명에서 100,000 vs 101,000 전환, 군당 1천 명에서 100 vs 135 전환. 두 결과의 p값과 효과 크기를 비교하고, 무엇을 함께 보고해야 하는지 말하라.
7. (장애 진단) 군당 100명 실험에서 p = 0.82가 나와 기능을 폐기했다. 차이의 95% 구간은 [−7.5, +9.5]%p였다. 무엇이 잘못된 결론인가?
8. (장애 진단) 양측 p = 0.08이 나오자 단측으로 바꿔 p = 0.04를 보고했다. 왜 문제인가? 실제로는 어떤 α로 판단한 셈인가?
9. (연결) 정규 근사가 의심스러운 작은 표본에서 분포 가정 없이 p값을 구하는 방법은? 그 방법이 의지하는 전제는?
