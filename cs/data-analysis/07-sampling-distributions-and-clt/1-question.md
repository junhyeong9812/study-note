# data-analysis/07-sampling-distributions-and-clt — 질문

## 질문

1. (왜) 아무것도 바꾸지 않았는데 일별 전환율이 10.4% → 9.8%로 움직였다. 표본 분포와 표준오차는 이 상황에서 어떤 질문에 답하나? 전환율 10%, 하루 방문 5,000명이면 하루 전환율의 표준오차는 대략 얼마인가?
2. (경계) 표준편차와 표준오차는 각각 무엇의 퍼짐인가? 표본을 1만 건으로 늘리면 둘은 각각 어떻게 되나?
3. (예측) 지수분포(평균 1, 표준편차 1)에서 n=5와 n=30의 표본 평균을 2만 번 뽑았다. 표본 평균들의 표준편차와 왜도는 각각 대략 얼마가 되나?
4. (경계) 중심극한정리를 쓰기 위한 전제 세 가지는? OpenIntro가 비율과 평균에 각각 쓰는 "충분히 큰 n" 경험칙은?
5. (예측) 로그정규(σ=1.5)에서 n=30 표본으로 "x̄ ± 1.96·s/√n"을 만들면 참 평균을 덮는 비율은 95%보다 큰가 작은가? 놓칠 때 참값은 주로 구간의 위·아래 중 어디에 있나? 이유는?
6. (경계) 분산이 무한한 파레토(α=1.5)에서 표본을 1만 개로 늘려도 표본 평균의 분포가 정규처럼 좌우 대칭이 되지 않는 이유는? 실무에서 이런 값의 예는?
7. (장애 진단) 세션 단위 전환율 차이가 "매우 유의"했는데 재실험에서 재현되지 않았다. 한 사용자가 여러 세션을 만든다. 무엇이 SE를 어떻게 틀리게 했나?
8. (연결) 부트스트랩은 어떻게 표본 분포를 흉내 내나? 중앙값 지연의 SE를 부트스트랩으로 구할 때 결과를 그대로 믿으면 안 되는 이유를 실험 수치로 설명하라.
