# data-analysis/26-bayesian-thinking — 정답

## 정답

### 1. 소표본 극단값과 사전 지식

- 리뷰 1개의 평균은 우연에 크게 흔들린다. 5.0은 "좋은 가게"보다 "아직 모르는 가게"에 가깝다.
- 신인 타자가 첫 타석에 안타를 치면 관측 타율은 1.000이지만, 실력(안타 확률)이 1이라고 판단하지 않는다. "보통 타자는 2할 5푼쯤"이라는 사전 지식이 있어, 한 타석으로는 믿음이 조금만 움직인다.
- 베이즈는 이 직관을 계산으로 만든다. 사후 ∝ 가능도 × 사전. 데이터가 적으면 사전 쪽, 많으면 데이터 쪽에 무게가 실린다.

### 2. 베타-이항 갱신

- 1개 중 1개: 사후 Beta(9, 2), 평균 9/11 = 0.818. 95% 신용구간 [0.552, 0.975] — 사후 표본 근사이고, 정확한 분위수는 0.555·0.975다.
- 500개 중 450개: 사후 Beta(458, 52), 평균 458/510 = 0.898. 구간 [0.870, 0.923].
- 원 비율 순위는 1.000 > 0.900. 사후 평균 순위는 0.898 > 0.818로 뒤집힌다.

### 3. 가중 평균 식

```text
  사후 평균 = (a + k) / (a + b + n) = w · (k/n) + (1 − w) · a/(a+b),   w = n / (n + a + b)

  w  1.0 ┤                          ●──────●   n이 클수록 데이터 평균 쪽
     0.5 ┤           ●  (n = a+b일 때 절반)
     0.0 ┼──●──────────────────────────────> n
           n = 0이면 사전 평균 그대로
```

- 사전 Beta(8, 2)에서 a + b = 10. 리뷰 1개면 w = 1/11, 리뷰 500개면 w = 500/510.

### 4. 평탄 사전

- Beta(1, 1)이면 1개 중 1개의 사후는 Beta(2, 1), 평균 2/3 = 0.667(실험 출력).
- 평탄 사전도 사전이다. "모든 θ가 똑같이 그럴듯하다"는 가정이고, 평균을 0.5 쪽으로 당긴다. 사전이 없는 베이즈 계산은 없다.

### 5. 순차 갱신과 일괄 갱신

- 같다. 실험에서 50개씩 10번 갱신한 결과가 Beta(458, 52)로 한 번에 갱신한 것과 같았다. 켤레 갱신은 개수를 더하는 것이라 순서·묶음에 무관하다.
- 가정: 리뷰들이 θ가 주어졌을 때 서로 독립(이항 가능도).
- 깨지는 데이터: 같은 사용자의 반복 리뷰, 같은 날 몰린 몰아주기 리뷰. 실제 정보보다 n을 부풀려 사후가 지나치게 좁고 치우친다.

### 6. 디리클레 별점

- 실험 출력: 5점 1개 → 4.227, 5점 3개 → 4.346, 200개 평균 4.6 → 4.579. 사전 평균은 4.150.
- 같은 이유: 사후 평균 별점 = `Σk·(α_k + c_k) / (W + n)`. `Σk·α_k = W·m`(사전 평균 m에 가짜 개수 W를 곱한 것), `Σk·c_k` = 실제 별점 합이다. 그래서 `(W·m + 별점 합)/(W + n)`이 된다.

### 7. 세 가게만으로 시험한 SQL

- 사전 평균을 같은 세 가게의 리뷰로 구했다. 리뷰 200개인 Q가 대부분이라 사전 평균이 4.608(= 940/204)로 Q 값에 붙었다.
- P·R은 Q의 값 쪽으로 당겨졌을 뿐이라 순서가 R 4.698 > P 4.643 > Q 4.600으로 그대로였다.
- 사전은 넓은 모집단(사이트 전체·같은 범주 전체)으로 구해야 한다. 다른 가게 100곳(리뷰 2,000건, 사이트 평균 4.192)을 더하자 Q 4.581 > R 4.379 > P 4.266이 됐다.

### 8. P(B > A)와 p값

- P(B > A | 데이터) = 0.92: 사전(평탄)과 이항 모형을 받아들이면, B의 전환율이 A보다 높을 확률이 0.92다.
- 단측 p = 0.083: 차이가 없다고 가정했을 때 관측한 차이 이상이 나올 확률이다.
- "B가 나쁠 확률 8.3%"는 p값을 가설의 확률로 읽은 것이다. ASA 2016 성명 원칙 2: p값은 연구 가설이 참일 확률을 재지 않는다.
- 이 실험에서 두 수(0.9172, 1 − p = 0.9173)가 비슷했던 것은 평탄 사전·이 표본 크기에서 본 것이지 일반 법칙이 아니다.

### 9. 신용구간 vs 신뢰구간, 베이즈와 데이터 편향

- 신용구간의 95%: 사후 분포에서 θ가 그 안에 있을 확률. 사전과 모형을 받아들인다는 조건 아래에서의 확률이다.
- 신뢰구간의 95%: 표본을 여러 번 뽑아 같은 방식으로 구간을 만들면 그중 약 95%가 모수를 포함한다(OpenIntro 5.2.2). 한 번 만든 구간을 "95% 확률로 참값을 포함"이라 읽는 것은 흔한 오류다(5.2.5).
- 사라지지 않는다. SRM·간섭([15](../15-ab-pitfalls-srm-peeking/2-summary.md))이나 중복 리뷰는 데이터 자체의 편향이다. 편향된 데이터로 갱신하면 사후도 편향된다.
