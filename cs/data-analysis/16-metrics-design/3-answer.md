# data-analysis/16-metrics-design — 정답

## 정답

### 1. 지표를 미리 안 정하면

- 결과를 본 뒤 유리한 지표를 고른다. 여러 지표 중 우연히 유의한 것을 발견으로 보고하는 다중 비교(11번)와 같은 모양이다.
- 쉬운 지표(클릭)만 올리고 진짜 목표가 내려가는 것을 놓친다. 굿하트의 법칙과 같은 모양이다.
- 가드레일을 안 정하면 지연·오류 악화가 "성공" 속에 묻혀 출시된다.

### 2. 세 지표

- OEC: 실험의 목적을 나타내는 정량 지표. 실험 기간에 잴 수 있으면서 장기 전략 목표를 인과적으로 끈다고 믿어지는 것(Kohavi 외 2020 1장).
- 대리 지표: 목표를 직접 재기 어려울 때 대신 보는, 더 빠르고 민감한 지표(예: 클릭률).
- 가드레일 지표: 조직이 나빠지게 두지 않겠다고 정한 것(크래시·지연·오류). 넘으면 OEC가 좋아도 출시하지 않는다.
- 이익: 가격 인상 같은 단기 조치로 당장 이익을 올리면서 장기적으로는 해칠 수 있다. 1장은 고객 생애 가치를 전략적으로 강력한 OEC의 예로 든다.

### 3. 두 평균

- 비율 지표 = (6+1+2)/(60+4+5) = 9/69 ≈ 0.130.
- 사용자 평균 = (0.10 + 0.25 + 0.40)/3 = 0.25.
- 어느 쪽도 틀리지 않았다. 비율 지표는 "노출 한 건당", 사용자 평균은 "사용자 한 명당" 클릭률이다. 노출이 많은 u1(CTR 0.10)이 비율 지표를 끌어내린다. 정의를 명세에 적어야 한다.

### 4. 노출 단위 분산의 A/A

- 크다. 같은 사용자의 노출들은 상관이 있어(사용자마다 CTR이 다름) 독립 노출 가정은 분산을 과소 추정한다. 표준오차가 작으니 |z|가 커져 유의가 잦아진다.
- 실험 A: 노출 단위 표준오차 평균 0.00293, 거짓 양성 272/1000 = 27.2%. 사용자 단위 델타 방법은 0.00537, 43/1000 = 4.3%.

### 5. 델타 방법의 재료와 전제

- 재료: 사용자 단위 분자 평균 μx, 분모 평균 μy, 분산 σx²·σy², 공분산 σxy(그리고 사용자 수 n).
- 식: Var(R) ≈ (1/n)[σx²/μy² − 2μxσxy/μy³ + μx²σy²/μy⁴].
- 전제: 사용자(분석 단위)들이 독립·같은 분포, 사용자별 분자·분모의 분산·공분산이 유한, n이 커서 1차 테일러 근사가 맞음, μy > 0.
- 근사다. 표본이 작거나 분모가 0에 가까우면 어긋날 수 있다. 사용자 단위 부트스트랩이 대안이다.

### 6. 실험 B의 판단

- CTR만: B(+0.0367, 구간 [+0.0333, +0.0400]).
- 7일 재방문: B는 −0.0227, 구간 [−0.0323, −0.0131] 전체가 음수라 탈락. C는 +0.0082이지만 구간 [−0.0014, +0.0178]이 0을 포함해 이 표본으로는 판단 보류.
- 가드레일: C는 p95 368.9ms(대조 274.1ms 대비 +34.6%)와 오류율 0.0042(대조 0.0021의 2배)로 두 조건 모두 위반 → 출시 금지. 결국 이 실험에서는 어느 변형도 출시하지 않는다.
- 이 효과 크기는 시뮬레이션에 넣은 가정이다. 결론의 모양(대리만 보면 해로운 변형을 고른다)을 보이는 예다.

### 7. CTR은 오르고 유지율은 내려감

- 가설: 대리 지표(CTR)를 직접 올리는 수단(자극적 썸네일·문구, 클릭 유도)이 쌓여 CTR과 유지율의 연결이 끊겼다(굿하트).
- 규칙 1: 출시 판단을 OEC(유지율에 가까운 지표, 예: 사용자당 활동 일수)로 한다. CTR은 진단용으로 둔다.
- 규칙 2: 가드레일과 OEC를 실험 템플릿에 고정하고, 실험 시작 전에 지표 명세(분자·분모·단위·창·방향)를 쓴다. 과거 실험들로 대리와 목표가 같은 방향인지 주기적으로 다시 확인한다.

### 8. OEC 구간이 0을 포함

- 할 수 있는 일: 더 민감한 지표를 OEC 후보로 검토한다(분산이 작은 지표 — 구매 여부, 금액 상한 처리). 실험 전에 최소 탐지 효과로 표본 크기를 계산한다(10번).
- 하면 안 되는 일: 결과를 계속 보면서 유의해질 때까지 연장하거나 멈추는 것. 엿보기는 1종 오류를 키운다(15번). 결과를 본 뒤 OEC를 다른 지표로 바꾸는 것도 같은 문제다.
