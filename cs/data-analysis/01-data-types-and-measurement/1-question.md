# data-analysis/01-data-types-and-measurement — 질문

## 질문

1. (왜) 값이 숫자로 저장돼 있으면 수치형 변수인가? OpenIntro가 수치형을 가르는 기준과 그 기준에 걸리는 예(지역번호·우편번호)를 들어라.
2. (그림) 변수 유형 나무(수치형·범주형 → 연속·이산·명목·순서)와 Stevens의 척도 사다리(명목·순서·구간·비율)를 그리고, 단계마다 의미 있는 관계와 중심값을 적어라.
3. (예측) 상품 A는 보통 60·만족 40, 상품 B는 매우 불만 20·보통 25·매우 만족 55다. 코딩을 1~5에서 "매우 만족 = 4.2"로만 바꾸면 평균이 고르는 승자와 중앙값이 가리키는 수준은 각각 어떻게 되나?
4. (경계) 20°C는 10°C의 두 배로 더운가? 지연 200ms는 100ms의 두 배로 느린가? 둘의 차이를 척도로 설명하라.
5. (연결) PostgreSQL 17에서 만족도를 `ENUM`으로 저장하면 `avg`, `percentile_disc(0.5)`, `mode()`는 각각 어떻게 동작하나? 이것이 왜 좋은 설계인가?
6. (장애 진단) 지역별 매출 리포트에 `1234` 같은 4자리 "지역"이 나타나고 일부 지역 매출이 사라졌다. 원인과 확인 쿼리, 복구 조건, 재발 방지를 대라.
7. (장애 진단) 리뉴얼 뒤 "평균 만족도 3.4 → 3.7"로 개선을 발표했는데 불만 문의가 늘었다. 무엇을 놓쳤고, 어떤 지표 묶음으로 다시 보고해야 하나?
8. (경계) Stevens 척도를 "순서형에는 절대 평균을 쓰면 안 된다"는 규칙으로 쓰면 무엇이 문제인가? 이 노트는 척도를 어떤 질문으로 바꿔 쓰나?
