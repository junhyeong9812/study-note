# data-analysis/10-power-and-sample-size — 정답

## 정답

### 1. 왜 미리 정하나

- 검정력은 "어떤 크기의 효과를 잡을 확률"이라, 효과 크기(MDE)를 정하지 않으면 계산할 수 없다. 표본 크기도 정할 수 없다.
- 실패 1(검정력 부족): 표본이 작아 진짜 효과가 있어도 "유의하지 않음"이 자주 나오고, 그것을 "효과 없음"으로 읽는다.
- 실패 2(너무 작은 MDE): 아주 작은 효과까지 잡으려다 필요한 표본이 비현실적으로 커져 실험이 끝나지 않는다.
- 둘 다 커리큘럼 ⚠ 칸이다.

### 2. 두 분포 그림

```text
     대립 분포(차이 δ)                    귀무 분포(차이 0)
         ▁▂▄▆█▆▄▂▁                          ▁▂▄▆█▆▄▂▁
  ░░░░░░░░░░░░░|▒▒▒▒                    ....|▓
  ← 검정력 ──→ | β                            | α/2
            기각 경계
  ├──── δ = (1.96 + 0.84)·SE = 2.8·SE ───────┤
```

- 기각 경계는 귀무 분포 중심에서 1.96·SE 떨어진 곳이다(α/2 = 2.5%).
- 대립 분포에서 그 경계 너머가 80%가 되려면 경계가 대립 분포 중심에서 0.84·SE(80% 분위) 떨어져야 한다. 반대쪽 기각역(엄밀히는 검정력에 더해진다)은 무시할 만큼 작아 뺀 근사다(OpenIntro 7.4.2).
- 합치면 2.8·SE(OpenIntro 7.4.3). 정밀한 z로는 1.960 + 0.842 = 2.802다.

### 3. 혈압 예제

- 군당 100명: SE = `√(12²/100 + 12²/100)` = 1.70, 기각 경계 ±3.33. 진짜 차이 −3이면 경계 −3.33 너머일 확률 ≈ 0.42(OpenIntro 7.4.2). 실험 A 계산 0.424.
- 80%를 위한 n: `3 = 2.8·√(2·144/n)` → n = 250.88 → 251(OpenIntro 7.4.3). 실험 A의 정밀 계산은 251.2.
- 참고로 군당 500명이면 97.7%(OpenIntro), 실험 A 0.977.

### 4. 10% → 11%

- 공식: `n = (z_{α/2} + z_β)² · (0.1·0.9 + 0.11·0.89) / 0.01²`. 정밀한 z(1.960 + 0.8416)로 군당 14,749(실험 B). 반올림한 1.96 + 0.84로 계산하면 약 14,731이다(계산). 검정이 합동 비율 SE를 쓰는 것에 맞춰 귀무·대립 분산을 나눈 식으로는 14,751이다(계산).
- 시뮬레이션(반복 4000, seed 31): n이면 78.8%, n/2(7,374)이면 50.5%, n/4(3,687)이면 28.8%, 2n이면 97.5%.
- 표본을 절반으로 줄여도 검정력이 절반(40%)이 되는 것이 아니라, 경계와의 거리가 `√2`배 줄어든 만큼 떨어진다.

### 5. MDE를 10분의 1로

- n은 MDE²에 반비례하므로 약 100배다. 실험 C: 상대 +10% → 군당 14,749, 상대 +1% → 군당 1,419,070(약 96배 — 분산 항도 조금 바뀐다).
- 하루 군당 5,000명(예시)이면 2.9일 → 283.8일.

### 6. 검정력 손잡이

| 손잡이 | 대가 |
|---|---|
| 표본 n을 늘린다 | 시간·트래픽·비용. 노출되는 사용자도 늘어난다(OpenIntro 7.4.3은 임상시험의 윤리 문제를 든다) |
| 개별 값의 분산 σ²를 줄인다(더 민감한 지표, 이상값 처리 등) | 지표의 의미가 바뀔 수 있다. 방법을 미리 정해야 한다 |
| α를 키운다 | 1종 오류(거짓 양성)가 늘어난다 |
| 단측 검정 | 반대 방향 효과(악화)를 검정하지 못한다. 방향은 데이터를 보기 전에 정해야 한다 |

- 효과 δ 자체는 설계로 바꿀 수 없다. 목표(MDE)로 정할 뿐이다.

### 7. 유의한 실험만 모으면

- 크다. 실험 D(반복 20000, seed 32): 검정력 17.2%, 전체 실험의 추정 효과 평균은 +1.00%p(편향 없음), 유의했던 양의 방향 실험 3,406건의 평균은 +2.43%p였다. 반대 부호로 유의한 실험도 26건이었다.
- 이유: SE가 커서 우연히 크게 나온 추정값만 기각 경계를 넘는다. "유의함"으로 거르는 순간 큰 추정값만 남는다(해석).

### 8. 분석 단위와 표본 크기

- 틀린 점: 표본 크기 공식은 독립 관측을 가정한다. 같은 사용자의 세션들은 서로 닮아 세션 수만큼의 정보가 없다([07](../07-sampling-distributions-and-clt/2-summary.md) 실험 E).
- n은 SE²에 비례하므로 SE가 1.45배면 같은 검정력에 n이 약 1.45² ≈ 2.1배 필요하다(계산).
- 대처: 배정 단위(사용자) 기준으로 분산과 n을 계산하고, 같은 단위로 분석한다.

### 9. 정규 근사 보완과 시뮬레이션

- 평균 차이 공식에서 계산된 n이 작으면(대략 30 이하) t 분포로 다시 계산한다. 보통 조금 더 커진다(OpenIntro 7.4.3). 비율 공식은 t가 아니라 기대 성공·실패 건수(OpenIntro 6.2.1)를 확인하고, 모자라면 이항 시뮬레이션으로 간다.
- 비율 지표는 델타 방법으로 분산을 근사해 공식에 넣을 수 있다(Deng 외 KDD 2018). 공식이 없거나 근사가 미덥지 않은 지표(중앙값, 순열 검정, 순차 검정 등)는 **시뮬레이션**한다: 가정한 효과로 데이터를 생성하고, 실제로 쓸 검정을 적용해 기각 비율을 센다(실험 B 방식, Think Stats 2판 9.10).
- 공식이 있어도 실제 분석 절차(분석 단위·이상값 처리)로 한 번 시뮬레이션해 목표 검정력이 나오는지 확인한다(해석).
