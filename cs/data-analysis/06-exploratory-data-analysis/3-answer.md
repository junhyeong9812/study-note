# data-analysis/06-exploratory-data-analysis — 정답

## 정답

### 1. Anscombe 콰르텟

- 같은 것(Python 3.12 실험): 평균 x 9.00, 분산 x 11.00, 평균 y 7.50, 분산 y 4.123~4.128, 상관 0.816~0.817, 회귀선 y = 3.00 + 0.500x.
- 다른 것: I 흩어진 직선, II 곡선, III 직선 + 이상점 하나, IV x가 거의 다 8이고 점 하나(x=19)가 상관을 만든다.
- 요약은 모양을 버린다. 곡선에 직선 모델, 영향점 하나에 기댄 상관은 그림을 봐야만 드러난다.

### 2. EDA 순서

```text
  ① 한 변수 히스토그램: 봉우리 수, 꼬리 방향, 0·음수·상한 붙음
  ② 그룹별 나란히 박스플롯/겹친 히스토그램: 위치 차이? 모양 차이?
  ③ 산점도: 직선/곡선, 뭉침, 영향 큰 점
  ④ 요약·모델: 평균·표준편차·상관·회귀
```

- OpenIntro 2.1(산점도·히스토그램·박스플롯·변환)과 2.2.6(그룹 간 비교)이 도구 근거다.

### 3. 쌍봉 지연

- 평균 19.7ms, 평균 ±10ms 안의 비율 **0.000** — 평균은 아무도 겪지 않은 값이다.
- 5수치 min 1.5, Q1 4.5, 중앙값 5.3, Q3 6.5, max 114.5. 위 울타리 9.5ms 밖 **1,953건** — 캐시 미스 무리 전체다(시뮬레이션, 시드 42).

### 4. 구간 폭

- 너무 좁으면 뾰족하고 어수선해 주된 경향이 묻힌다. 너무 넓으면 작은 특징(작은 봉우리·골)이 사라진다(Wilke 7.1). 실험의 60ms 폭에서는 두 번째 봉우리가 70~90ms에 몰려 있다는 모양이 "60~119ms 1,914건" 한 칸으로 뭉개졌다.
- 습관: 여러 폭을 시도한다. 도구 기본값이 그 데이터에 맞는다는 보장은 없다.

### 5. 박스플롯 vs 히스토그램

- 박스플롯: 여러 그룹의 위치·퍼짐을 한눈에 비교하기 좋다.
- 히스토그램·바이올린: 한 분포의 모양(봉우리 수)을 본다. Wilke 9.1: 바이올린은 (그룹마다 점이 충분하면) 쌍봉을 정확히 보여 주지만 박스플롯은 그렇지 못하다.
- 박스플롯이 못 보여 주는 것: 봉우리 수(쌍봉·다봉), 상자 안의 뭉침.

### 6. 상관계수의 한계

- Pearson r은 선형 관계의 방향과 강도를 잰다(Python 3.12 문서).
- II: 곡선인데 r = 0.816으로 "강한 선형"처럼 보인다. IV: 점 하나를 빼면 x가 모두 8이라 관계를 말할 수 없는데 r = 0.817이다.
- 단조지만 직선이 아닌 관계나 순서형 데이터에는 순위 상관(`method='ranked'`, Spearman)이 대안이다(같은 문서). 영향점 문제는 순위 상관도 완전히 해결하지 못하므로 산점도가 먼저다(해석).

### 7. `width_bucket`

- 하한 미만 → 0, 상한 이상 → 칸 수 + 1(여기서 13). 구간은 하한 포함·상한 제외(PostgreSQL 17 문서).
- 실행 확인(PostgreSQL 17.11): −1 → 0, 0 → 1, 119.9 → 12, 120 → 13, 500 → 13.

### 8. 쌍봉에 평균 + 3σ

- 봤어야 할 것: 히스토그램. 두 무리(적중 ~5ms, 미스 ~80ms)가 섞여 있었다. 평균·표준편차 하나로는 미스 무리의 꼬리 위치를 알 수 없다.
- 적중률이 떨어지면 미스 무리의 비중이 커져 그 꼬리가 타임아웃에 더 많이 걸린다.
- 대처: 원인별로 나눠 각 무리의 백분위를 보고, 타임아웃은 백분위 기반으로 정한다(reliability/08-time-budget-allocation). 정규 가정의 위험은 math/09.

### 9. 울타리 밖 20% 삭제

- 문제: 1.5 × IQR 울타리는 이상치 후보 표시 관례다. 울타리 밖이 20%나 되면 이상치라기보다 다른 무리(캐시 미스·리전·버전)이거나 심하게 치우친 꼬리다. 치우친 분포에서는 정상 값도 울타리를 많이 넘는다(Hubert·Vandervieren 2008: 로그정규 σ=1에서 약 7.76%). 박스플롯은 쌍봉을 보여 주지 못한다.
- 먼저: 히스토그램을 여러 폭으로 그리고, 원인 후보 변수로 나눠 각 그룹이 단봉인지 본다.
