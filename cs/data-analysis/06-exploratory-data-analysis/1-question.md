# data-analysis/06-exploratory-data-analysis — 질문

## 질문

1. (왜) Anscombe의 네 데이터셋은 어떤 요약 통계가 같고, 그림으로는 어떻게 다른가? 이 예가 "모델링 전에 그림"을 요구하는 이유는?
2. (그림) EDA의 순서(한 변수 → 그룹 → 두 변수 → 요약·모델)를 그리고, 각 단계에서 찾는 것(봉우리·꼬리·이상한 값·곡선·영향점)을 적어라.
3. (예측) 80%는 약 5ms, 20%는 약 80ms인 쌍봉 지연 10,000건에서 평균 근처(±10ms)에 있는 요청 비율은 대략 얼마일까? 박스플롯 울타리 밖으로 찍히는 점은 몇 개쯤일까? (실험 출력으로 확인)
4. (경계) 히스토그램 구간 폭이 너무 좁을 때와 너무 넓을 때 각각 무엇을 놓치나? Wilke가 권하는 습관은?
5. (경계) 박스플롯과 히스토그램(또는 바이올린 그림)은 각각 무엇에 좋은가? 박스플롯이 못 보여 주는 모양은?
6. (연결) Pearson 상관계수는 무엇을 재나? Anscombe II(곡선)와 IV(점 하나)에서 r이 오해를 부르는 방식은? 순위 상관은 언제 대안이 되나?
7. (연결) PostgreSQL 17 `width_bucket(ms, 0, 120, 12)`로 히스토그램을 만들 때 범위 밖 값은 어느 칸에 들어가나? 구간 경계는 어느 쪽이 포함되나?
8. (장애 진단) "평균 20ms, 표준편차 30ms → 평균 + 3σ = 110ms"로 타임아웃을 정했는데 캐시 적중률이 떨어지자 타임아웃이 급증했다. 무엇을 봤어야 했나?
9. (장애 진단) 박스플롯 울타리 밖 값이 20%라 노이즈로 지웠다. 이 판단의 문제와 먼저 했어야 할 일은?
10. (경계) OpenIntro 2.3은 무엇을 다루나? 커리큘럼이 EDA 근거로 2.3을 가리킨 것을 이 노트는 어떻게 처리했나?
