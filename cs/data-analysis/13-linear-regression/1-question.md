# data-analysis/13-linear-regression — 질문

## 질문

1. (왜) 최소제곱은 무엇을 최소로 하는 직선인가? 기울기와 절편의 식을 쓰고, 해가 만족하는 두 성질(정규방정식)을 말하라. 왜 "제곱"이 이상값에 민감하게 만드나?
2. (계산) OpenIntro Elmhurst 요약 통계 x̄ = 101,780, sx = 63,200, ȳ = 19,940, sy = 5,460, R = −0.499로 기울기·절편·R²를 구하라. 소득 100만 달러를 넣으면 무엇이 나오며, 이것을 무엇이라 부르나?
3. (예측) 이용률 ρ = 0.1~0.6에서 W = 1/(1 − ρ)를 11점 재고 직선을 그었다(R² 0.95). ρ = 0.9에서 직선 예측과 실제 값은 대략 얼마인가? 왜 이렇게 차이 나나?
4. (예측) 200점이 깔끔한 직선(기울기 약 0.81)을 이루는데, 추세에서 240만큼 아래인 점을 x = 400(다른 점은 x ≤ 100)에 하나 더한다. 기울기는 어떻게 되나? 같은 크기로 벗어난 점을 x 중앙(55)에 두면? 두 경우 그 점의 잔차는 각각 어떻게 보이나?
5. (경계) R² = 0.937이면 직선 모형이 맞다고 할 수 있나? 어떤 잔차 모양이 나오면 아니라고 판단하나? OpenIntro가 드는 네 조건은?
6. (계산) 기울기 −0.0431, 표준오차 0.0108, n = 50일 때 기울기의 t 통계량·자유도·양측 p값의 크기·95% 신뢰구간을 구하라. 자유도가 n − 2인 이유는?
7. (연결) PostgreSQL에서 `regr_slope(x, y)`로 쓰면 무엇이 나오나? 그 값은 y를 x로 적합한 기울기 b1의 역수인가? 실험 (B)의 숫자로 답하라.
8. (연결) 기울기·절편·r을 SQL 집계 한 번(행을 한 번만 읽기)으로 구할 수 있는 이유는? 그 공식을 그대로 쓰면 어떤 수치 문제가 생길 수 있나?
9. (장애 진단) 요청당 비용 회귀의 기울기가 한 달 만에 0.81에서 0.47로 떨어졌다. 데이터에 x가 혼자 아주 큰 점이 있고 그 점의 잔차는 크지 않다. 무엇을 의심하고 어떻게 확인하나?
