# data-analysis/03-observational-vs-experimental — 질문

## 질문

1. (왜) 관찰 연구와 실험을 가르는 기준은 무엇인가? "기능 X 사용자의 잔존이 높다"는 데이터는 어느 쪽이고, 그것만으로 무엇을 말할 수 없나?
2. (그림) 교란 변수 Z, 처치 X, 결과 Y의 화살표 그림을 그리고, 관찰된 X–Y 연관이 어떤 두 경로의 합인지 설명하라. OpenIntro의 선크림 예에서 Z는 무엇인가?
3. (예측) 진짜 효과가 −2%p인데 heavy 사용자(잔존 80%)의 70%, light 사용자(잔존 30%)의 10%가 스스로 기능을 켠다. 관찰 비교의 차이는 어느 부호로 나오나? 해시 무작위 배정이면? (실험 출력으로 확인)
4. (경계) 같은 관찰 데이터를 교란 변수로 층을 나눠 비교하면 진짜 효과에 가까워졌다. 그렇다면 관찰 연구도 층화만 잘하면 실험을 대신할 수 있나?
5. (연결) 실험 설계 네 원칙(통제·무작위·반복·블록)을 서비스 A/B 실험의 장치에 하나씩 대응시켜라.
6. (경계) "무작위 배정이면 두 그룹이 똑같다"는 말은 어디까지 맞나? 블록은 왜 필요한가?
7. (장애 진단) "같은 세션 수를 가진 사용자끼리 비교하면 기능 효과가 0"이라며 기능을 폐기했다. 무엇이 잘못됐나?
8. (장애 진단) 출시 전 주와 후 주의 전환율을 비교해 "기능 효과 +5%"를 보고했다. 이 비교의 교란 변수는 무엇이고, 어떤 설계가 필요한가?
9. (연결) 해시 배정 `hash(salt + user_id)`에서 salt를 실험마다 달리하는 이유는? 같은 사용자를 같은 버킷에 두는 것이 왜 중요한가?
