# data-analysis/03-observational-vs-experimental — 정답

## 정답

### 1. 누가 처치를 정했나

- 연구자가 처치를 배정하면 실험, 일어난 대로 기록하면 관찰 연구다(OpenIntro 1.2.5·1.4).
- 사용자가 스스로 기능을 켰다면 관찰 데이터다. OpenIntro 1.2.5: 관찰 연구는 자연스러운 연관의 증거는 줄 수 있지만 그것만으로 인과 관계를 보이지 못한다.

### 2. 두 경로

```text
        Z
       ↙ ↘
      X ─?→ Y        관찰된 X–Y 연관 ← 진짜 효과와 뒷문 경로가 섞인 것(개념 그림)
```

- 선크림 예(OpenIntro 1.3.4): Z = 햇빛 노출. 햇빛을 많이 쬐는 사람이 선크림도 많이 쓰고 피부암 위험도 높다.

### 3. 부호가 뒤집힌다

- 관찰: 처치 잔존 0.649, 대조 0.365, 차이 **+0.284**. 처치 그룹 heavy 비율 0.75, 대조 0.12.
- 해시 배정 실험: 처치 0.430, 대조 0.450, 차이 **−0.019**. heavy 비율 양쪽 0.30.
- 실험 설정의 진짜 효과는 −0.02다. 관찰 비교는 부호까지 틀렸다(시뮬레이션, 사용자 10만, 시드 42).

### 4. 층화는 잰 교란만 고친다

- 같은 관찰 데이터를 Z로 나눈 층별 차이는 heavy −0.027, light −0.030으로 진짜 효과 근처다. 하지만 이것은 Z(heavy)를 **재고 있었고**, Z가 **유일한** 교란이라는 설정이라서 가능했다.
- OpenIntro 1.3.4: 모든 교란 변수를 검토하거나 잴 수 있다는 보장이 없다. 무작위 배정은 못 잰 교란까지 평균적으로 고르게 나눈다. 그래서 대신할 수 없다.

### 5. 네 원칙 ↔ A/B 장치

| 원칙 | A/B에서 |
|---|---|
| 통제 | 같은 기간·같은 화면 경로·같은 지표 정의로 두 그룹을 돌린다 |
| 무작위 | 해시 배정(사용자 단위) |
| 반복 | 충분한 사용자 수(검정력, data-analysis 10), 재실험 |
| 블록 | 신규/기존 사용자·플랫폼별로 나눠 각각 같은 비율로 배정 |

### 6. 무작위 배정의 한계와 블록

- 무작위 배정은 교란 변수를 **평균적으로** 고르게 나눈다. 작은 표본에서는 우연히 기울 수 있다(실험에서는 10만 명이라 0.30/0.30).
- 결과에 큰 영향을 준다고 아는 변수는 먼저 블록으로 묶고 블록 안에서 무작위로 나눈다. 그 변수의 불균형을 우연에 맡기지 않는다(OpenIntro 1.4.1의 저위험/고위험 예).

### 7. 처치 후 변수 통제

- 세션 수는 기능의 **결과**일 수 있다(매개 변수). 같은 세션 수끼리 비교하면 기능이 세션을 늘려 만든 효과를 지운다.
- 통제·층화 변수는 처치 전에 정해진 것만 쓴다. 정식 판단은 data-analysis 25의 인과 DAG.

### 8. 전/후 비교

- 교란: 시점 자체(계절성·요일·마케팅 캠페인·장애·다른 배포). 처치와 시점이 완전히 겹친다.
- 설계: 같은 기간에 무작위로 나눈 대조군(A/B). 불가능하면 영향을 받지 않은 비교 그룹을 두고 차분의 차분을 검토한다(data-analysis 25).

### 9. salt와 고정 버킷

- salt가 같으면 실험 A의 처치 그룹이 실험 B의 처치 그룹과 같은 사람들이 된다. 두 실험 효과가 섞인다. salt를 달리하면 배정이 서로 독립에 가까워진다.
- 같은 사용자가 방문마다 그룹을 오가면 두 처치를 모두 경험해 결과가 섞이고, 사용자 단위 지표가 깨진다. 실험 출력의 "같은 사용자 같은 버킷: True"가 이 성질의 확인이다. 구현 세부는 domain-modeling/advanced/27-ab-assign.
