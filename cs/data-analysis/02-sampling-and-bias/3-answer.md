# data-analysis/02-sampling-and-bias — 정답

## 정답

### 1. 세 정의와 비유

- 모집단 = 알고 싶은 대상 전체. 표본 = 실제로 관찰한 일부. 편향 = 뽑는 방식 때문에 표본 값이 모집단 값에서 한쪽으로 체계적으로 어긋나는 것.
- 숟가락을 더 뜨기 = 표본 크기 늘리기(우연 오차만 준다). 잘 젓기 = 무작위 추출(추출 단계의 편향을 줄인다 — 무응답·표본 틀 누락 편향은 따로 남는다, OpenIntro 1.3.3).

### 2. 깔때기

```text
  모집단 ─① 표본 틀(연락 가능한 사람만?)  → 포함 편향
        ─② 응답(누가 답하나)              → 무응답(응답) 편향
        ─③ 생존·기록(누가 남아 있나)       → 생존자 편향
        → 분석 행
```

- 편한 대상만 모으면 편의 표본(OpenIntro 1.3.3) — 어떤 부분 모집단을 대표하는지 알기 어렵다.

### 3. 표본을 키워도 오차는 그대로

- 실험(시드 42·7): 초대 1,000 → 응답 173명 평균 21.72h(오차 +12.73), 10,000 → 1,604명 22.17h(+13.18), 100,000 → 16,972명 21.10h(+12.11).
- 응답 인원이 98배가 돼도 오차는 +12~13h다. 편향은 체계적 오차라서 표본 크기와 무관하다.

### 4. 네 추출과 층화의 효과

- 단순 무작위: 모두 같은 확률. 층화: 층마다 단순 무작위. 군집: 몇 군집을 통째로. 다단계: 군집을 고른 뒤 그 안에서 다시 무작위(OpenIntro 1.3.5).
- 층화가 이득인 조건: 층 안이 관심 값에 대해 비슷하고 층끼리 다를 때(OpenIntro).
- 실험(n=500, 2,000회, 비례 배분): 추정 표준편차 단순 0.546 → 층화 0.374, 분산 비 0.47(시드 9조합으로 다시 돌리면 0.42~0.47). 유료/무료 층이 사용 시간과 강하게 관련돼 있어서다(해석).

### 5. 층 가중

- 층별 표본 평균에 **모집단의 층 비율**을 곱해 더한다: `Σ w_s · mean_s`.
- 표본의 층 비율이 모집단과 다를 때(예: 작은 층을 일부러 많이 뽑음) 그냥 모아 평균 내면 많이 뽑은 층의 비중이 실제보다 커져 그쪽으로 기운다. 비례 배분이면 그냥 모은 평균도 가중 평균과 같다.

### 6. 요청 단위 동전 vs 사용자 해시

- 요청마다 동전: 한 사용자의 요청이 일부만 남는다. 사용자 단위 지표(세션 수·전환)가 깨진다. 같은 사용자가 시점마다 들어왔다 나간다.
- 해시: 같은 사용자 + 같은 salt → 늘 같은 답. 사용자 단위로 전부 남거나 전부 빠진다. 실행 확인(OpenJDK 21.0.12): 10만 명 중 9,962명(9.96%), 같은 사용자 반복 호출 같은 답.

### 7. 생존자만 본 분석

- 틀린 곳: 떠난 고객이 분석 테이블에 없었다(생존자 편향). 실험 설정에서 생존자 평균은 16.86h, 전체는 8.99h.
- 게다가 "첫 주 사용 → 잔존"은 관찰 데이터의 연관이다. 많이 쓰는 성향(교란 변수)이 둘 다를 일으켰을 수 있다(03번 노트).
- 다시: 시작 시점 코호트 전체(이탈자 포함)를 고정해 비교하고, 인과는 무작위 실험으로 확인한다.

### 8. 샘플링 규칙이 다른 로그

- 오류는 확률 1, 정상은 확률 0.01로 보관됐다. 보관된 행을 그대로 세면 오류가 100배 과대 대표된다.
- 행마다 보관 확률을 기록하고 1/확률로 가중해 센다: 오류 행 1개 = 1, 정상 행 1개 = 100.

### 9. 역확률 가중이 믿을 만하려면

- 응답 확률 p를 모르므로 모델로 추정해야 한다. 그 모델이 맞아야 한다.
- 핵심 가정: 관찰된 변수(사용 시간·가입 기간 등)로 응답 여부가 설명된다. 관심 변수 자체(예: 만족도)가 관찰 변수와 별개로 응답에 영향을 주면 가중으로 되돌릴 수 없다(해석).
- 실험의 8.94h는 p를 정확히 아는 시뮬레이션이라 가능했다.
