# data-analysis/02-sampling-and-bias — 질문

## 질문

1. (왜) 모집단·표본·편향을 각각 한 문장으로 정의하라. 국 간 보기 비유에서 "숟가락을 더 뜨는 것"과 "잘 젓는 것"은 각각 무엇에 해당하나?
2. (그림) 모집단 → 표본 틀 → 추출 대상 → 응답자 → 분석 행의 깔때기를 그리고, 각 단계에 들어오는 편향의 이름을 붙여라.
3. (예측) 응답 확률이 사용 시간에 비례하는 설문에서 초대 인원을 1,000 → 100,000명으로 늘리면 응답자 평균의 오차는 어떻게 되나? (참 평균 8.99h, 실험 출력으로 확인)
4. (경계) 단순 무작위·층화·군집·다단계 추출을 구분하라. 층화가 단순 무작위보다 분산을 줄이는 조건은 무엇이고, 실험에서 분산은 얼마나 줄었나?
5. (경계) 층마다 뽑는 수를 일부러 다르게 했을 때 전체 평균을 어떻게 합쳐야 하나? 그냥 다 모아 평균 내면 무엇이 틀리나?
6. (연결) 로그·트레이스를 "사용자의 10%"로 샘플링할 때 요청마다 동전을 던지는 것과 `hash(user_id + salt)`로 고르는 것은 무엇이 다른가?
7. (장애 진단) "1년 이상 남은 고객은 첫 주에 많이 썼다 → 첫 주 사용을 늘리자" 캠페인이 효과가 없었다. 분석의 어디가 틀렸고, 어떻게 다시 분석해야 하나?
8. (장애 진단) 오류 요청은 100%, 정상 요청은 1%만 보관하는 로그로 오류율을 셌더니 30%가 나왔다. 왜이며, 올바르게 세는 법은?
9. (경계) 응답 확률을 알면 역확률 가중으로 편향을 되돌릴 수 있다(실험 8.94h). 실무에서 이 보정이 믿을 만하려면 무엇이 성립해야 하나?
