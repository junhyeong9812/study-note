# data-analysis/21-numerical-inference-t-anova — 정답

## 정답

### 1. t 분포를 쓰는 이유

- 표준오차에 σ 대신 표본 표준편차 s를 넣으면 s 자체도 표본마다 흔들린다. 그 추가 불확실성 때문에 통계량의 꼬리가 정규보다 두껍다. t 분포의 두꺼운 꼬리가 이를 보정한다(OpenIntro 7.1.3).
- t*(0.975): df 2 → **4.303**, df 30 → **2.042**, df ∞ → **1.960**(`dist.py` 계산).
- 정확하려면 관측이 독립이고 **정규분포**에서 나왔다고 가정한다. 실무에서는 n < 30이면 뚜렷한 이상값이 없을 것, n ≥ 30이면 극단적 이상값이 없을 것이라는 경험 규칙으로 확인한다(OpenIntro 7.1.2).

### 2. 대응 vs 독립 예측

- 독립(Welch): p가 크게 나온다. 실험 A에서 t = 0.17, **p = 0.863**.
- 대응: p가 아주 작다. 실험 A에서 t = 4.07, df 29, **p = 0.00033**.
- 4000번 반복(실험 B): 대응 **4000/4000**, 독립 **0/4000**.
- 이유: 엔드포인트 사이의 차이(sd 약 51ms)가 배포 효과(3ms)를 덮는다. 차이를 먼저 구하면 그 변동이 지워져 차이의 sd가 3.10ms가 된다.

### 3. Var(후 − 전)

- `Var(후 − 전) = Var(후) + Var(전) − 2·Cov(후, 전)`.
- 이 예처럼 대상 사이 차이가 큰 것을 두 번 재면 후와 전이 강하게 양의 상관이라 Cov가 크다(상관이 약하면 대응의 이득도 작다). 그래서 차이의 분산이 두 분산의 합보다 훨씬 작다.
- 독립 t는 `Var(x̄후 − x̄전) = Var(후)/n + Var(전)/n`으로 계산한다. **−2·Cov 항을 버린다**. 그래서 표준오차를 과대평가해 검정력을 잃는다.

### 4. 짝이 어긋나면

- 실험 D: 순서만 섞자 t = 0.16, **p = 0.872**. 대응의 이점이 사라진다(공분산이 0 근처가 됨).
- 흔한 경로
  1. 전·후 결과를 각각 정렬하거나 수집 순서대로 행 번호로 맞춘다.
  2. 배포 뒤 엔드포인트 이름·ID가 바뀌거나 일부가 사라져 다른 대상과 짝지어지거나 조인에서 빠진다.
- 대처: 대상 키로 조인하고, 짝 개수와 매칭 안 된 대상을 함께 출력한다.

### 5. 교재 가격 대응 예

- SE = 13.42 / √68 ≈ **1.63**.
- T = 3.58 / 1.63 ≈ **2.20**, df = **67**.
- 양측 p ≈ **0.031**(직접 계산 0.0313, 책 0.0312).
- t*(67) ≈ 2.00. CI = 3.58 ± 2.00 × 1.63 ≈ **(0.32, 6.84)**(직접 계산은 t* 1.996으로 (0.33, 6.83)).

### 6. 두 독립 평균의 자유도

- min(n1 − 1, n2 − 1): 소프트웨어가 없을 때의 보수적 선택(OpenIntro 7.3.1).
- Welch–Satterthwaite: 두 분산이 다를 수 있을 때의 기본(소프트웨어가 보통 쓰는 계산).
- 합동(n1 + n2 − 2): 두 모집단 sd가 같다는 배경 근거가 있을 때만(OpenIntro 7.3.4).
- 10 vs 40, 작은 그룹 sd 4배, 귀무 참: 합동 t의 거짓 양성률 **약 0.28**(실험 C: 0.283). Welch는 0.051.

### 7. 중간고사 ANOVA

- 전체 평균 x̄ = (58×75.1 + 55×72.0 + 51×78.9)/164 ≈ 75.24.
- SSG = Σ ni(x̄i − x̄)² ≈ **1261.7**, MSG = SSG/2 ≈ **630.8**.
- SSE = Σ (ni − 1)si² ≈ **29877**, MSE = SSE/161 ≈ **185.6**.
- F ≈ 630.8 / 185.6 ≈ **3.40**, df = (2, 161), p ≈ 0.036.
- 책의 F 3.48(SSG 1290.11, SSE 29810.13)과 다른 이유: 책 표의 평균·sd가 소수 첫째 자리로 반올림되어 있다. 그룹 평균의 작은 차이가 SSG에 제곱으로 들어가고, sd 반올림은 SSE를 바꾼다. 책의 F 3.48을 F(2, 161) 꼬리에 넣으면 p = 0.0331로 책(0.0330)과 같다.

### 8. ANOVA 뒤 쌍별 비교

- 쌍마다 두 표본 t를 하되, ANOVA 표의 합동 sd(13.61, df 161)를 쓰고 문턱을 보정한다(OpenIntro 7.5.6).
- Bonferroni: 쌍 K = 3 → α* = 0.05/3 ≈ **0.0167**.
- 결과: A–B p 0.228, A–C p 0.148(책 0.1462), **B–C p 0.0100(책 0.0102)만 유의**.
- 모순이 아니다. ANOVA는 "어딘가 차이가 있다"는 전체 증거를 모으고, 특정 쌍을 짚기에는 증거가 부족할 수 있다. OpenIntro 7.5.6은 이것이 ANOVA 결론을 무효로 만들지 않는다고 적는다.

### 9. 성능 회귀 게이트

- 원인: 같은 엔드포인트를 두 번 잰 **대응 데이터**를 독립 두 그룹으로 검정했다. 엔드포인트 사이의 큰 차이가 오차로 들어가 회귀가 묻혔다(실험 A: 독립 p 0.863 vs 대응 p 0.00033).
- 고치는 법
  1. 엔드포인트 키로 전후를 조인해 차이를 만들고 대응 t(또는 차이의 신뢰구간)로 판정한다(SQL 예: n 30, 평균 차 2.30, t 4.07).
  2. 짝 개수가 엔드포인트 수와 같은지 검사한다.
  3. 극단값이 많은 지연이면 차이의 분포를 그려 보고, 중앙값 기반 비교를 함께 둔다.
