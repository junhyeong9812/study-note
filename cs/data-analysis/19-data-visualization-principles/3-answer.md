# data-analysis/19-data-visualization-principles — 정답

## 정답

### 1. 비례 잉크

- 칠해진 면적의 크기는 그것이 나타내는 값에 비례해야 한다(Bergstrom·West 2016, Wilke 17장).
- 막대는 끝점과 길이 두 가지로 값을 말한다. 50에서 시작하면 끝점은 52를 말하고 길이는 2를 말한다. 같은 요소가 두 값을 말하니 모순이다. 눈은 길이를 읽는다.
- 점은 끝점(위치)만 값을 말한다. 축을 좁혀도 모순이 생기지 않는다(Wilke 6.3).

### 2. 막대 길이 비

- 0부터: 55/52 ≈ 1.06(이론값. 실험의 텍스트 막대는 `#`를 반올림해 38개·40개라 40/38 ≈ 1.05).
- 50부터: (55−50)/(52−50) = 2.5.
- 값의 비는 어느 쪽이든 1.058이다(실험 [1]).

### 3. 이중 축 범위

- 210~216: 두 선이 화면 높이 0에서 1까지 거의 같이 오른다. "가입이 늘면 지연도 같은 만큼 는다"는 인상.
- 0~400: 지연 선은 0.53~0.54로 거의 평평하다. 가입 선만 0.67 → 0.81로 오른다.
- 실제 변화율: 가입 +22.0%, 지연 +2.9%(실험 [2]).

### 4. 이중 축 대안

- 두 시계열을 위아래 두 패널로 따로 그린다(Wilke 13.3).
- 두 변수를 x·y 축으로 하고 시간 순으로 점을 이은 연결 산점도를 그린다(Wilke 13.3).
- 두 계열을 같은 기준(시작점 = 100)으로 지수화해 한 축에 그린다. 상대 변화를 같은 단위로 비교할 수 있다.

### 5. 3D 파이의 앞뒤

- 실험 모형에서 25% 조각이 앞쪽 가운데면 보이는 넓이의 34.3%, 뒤쪽 가운데면 19.9%. 두께를 0으로 하면 25.0%.
- 이 모형의 윗면은 정사영이라 넓이 비율이 보존된다. 왜곡은 앞쪽 조각에만 보이는 옆면(두께) 띠에서 온다. 실제 렌더링은 원근 투영이 더해져 왜곡의 크기가 이 모형과 다를 수 있다(이 모형은 원근을 넣지 않았다). Wilke 26.1도 앞쪽 조각이 실제보다 커 보이고 뒤쪽이 작아 보인다고 적는다.

### 6. 색 척도 세 종류

- 범주형: 순서 없는 범주를 구분할 때(채널, 서비스).
- 순차: 작다 → 크다처럼 한 방향의 크기를 나타낼 때. 밝기가 한 방향으로 변해야 한다.
- 발산: 가운데 기준(0, 목표치)이 있고 양쪽 방향이 의미를 가질 때(전주 대비 증감).
- Wilke 19.1: 범주 색은 3~5개일 때 가장 잘 작동하고, 8~10개 이상이면 색과 범주를 짝짓는 일이 부담이 된다.

### 7. 무지개 척도와 노란 띠

- 색상환(무지개) 척도는 밝기가 단조롭지 않다. 노랑 근처가 가장 밝아 그 구간의 값이 실제보다 두드러져 보이고, 데이터에 없는 경계가 생긴다(Wilke 19.2).
- 실험 [4]: 파랑 → 빨강 무지개의 상대 휘도가 0.072 → 0.787 → 0.715 → 0.928(노랑, 값 0.75) → 0.213으로 오르내린다. 회색 순차 척도는 0.787 → 0.010으로 한 방향이다.
- 대처: 밝기가 단조인 순차 척도로 바꾼다.

### 8. 거리 vs 면적

- 값이 길이 하나로 표현되는 막대가, 두 거리가 함께 만드는 면적·각도로 표현되는 파이 조각보다 정확히 읽힌다. 비슷한 비율 여러 개를 비교해야 하면 막대가 낫다.
- 파이 차트는 조각 면적이 각도에, 각도가 값에 비례하므로 비례 잉크 원칙은 지킨다(Wilke 17.3). 문제는 원칙 위반이 아니라 면적 지각의 부정확함이다.
- 그렇다고 파이가 늘 나쁜 것은 아니다. Wilke 10.1은 파이가 1/2·1/3·1/4 같은 단순한 비율을 강조할 때와 데이터가 아주 작을 때 잘 작동한다고 적는다. 10.2의 그림 10.4(점유율이 비슷한 회사 다섯 곳 × 3년)처럼 비슷한 비율 여러 개를 해마다 비교하는 경우에는 연도 안 비교도, 연도 간 변화도 보기 어렵다. 각 조각끼리 직접 비교하려면 나란히 놓은 막대가 낫다.
