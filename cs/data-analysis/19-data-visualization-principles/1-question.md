# data-analysis/19-data-visualization-principles — 질문

## 질문

1. (원리) 비례 잉크 원칙을 한 문장으로 말하라. 막대 그래프의 y축을 0이 아닌 값에서 시작하면 왜 "그림 안의 모순"이 생기나? 점 그림은 왜 괜찮나?
2. (계산) 값 52와 55를 y축 0부터, 50부터 그린 막대에서 길이 비는 각각 얼마인가? 값의 비는?
3. (예측) 가입 수(100 → 122)와 지연(210 → 216ms)을 이중 축에 그린다. 오른쪽 축을 210~216으로 잡을 때와 0~400으로 잡을 때 인상이 어떻게 다른가? 실제 변화율은?
4. (대안) 단위가 다른 두 시계열의 관계를 보여 주고 싶다. 이중 축 대신 쓸 수 있는 방법 세 가지는? (Wilke 13.3과 지수화)
5. (예측) 기울인 3D 파이에서 같은 25% 조각이 앞쪽에 있을 때와 뒤쪽에 있을 때 보이는 넓이는 어떻게 다른가? 실험 모형의 숫자와, 그 모형의 왜곡이 어디서 오는지 설명하라.
6. (구분) 범주형·순차·발산 색 척도를 언제 쓰나? Wilke 19.1이 범주 색 개수에 대해 적은 경험칙은?
7. (장애 진단) 지역별 지연 지도를 무지개 척도로 그렸더니 노란 띠 지역이 문제 지역으로 지목됐다. 원인을 밝기 관점에서 설명하고 실험 [4]의 숫자로 뒷받침하라.
8. (연결) 사람의 지각이 면적보다 거리를 더 정확히 판단한다는 사실(Wilke 17.3)은 파이 차트와 막대 차트 선택에 어떤 함의가 있나? 파이 차트는 비례 잉크 원칙을 어기나?
