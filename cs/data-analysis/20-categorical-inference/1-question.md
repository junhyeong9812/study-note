# data-analysis/20-categorical-inference — 질문

## 질문

1. (왜) 50:50 설계 실험에서 50,800 : 49,200은 "거의 반반"처럼 보이는데 왜 강한 경고 신호인가? 같은 비율이 n = 1,000이면 결론이 어떻게 달라지나? 두 경우의 X²를 계산하라.
2. (계산) OpenIntro 배심원 예(관측 205·26·25·19, 모집단 비율 0.72·0.07·0.12·0.09, n = 275)의 기대 빈도, X², 자유도를 구하라. p값 0.1171은 어떤 넓이인가?
3. (계산) iPod 분할표(공개: 2·23·36, 숨김: 71·50·37)에서 "공개 × 일반 질문" 칸의 기대 빈도를 구하는 식을 쓰고 계산하라. 자유도는? X²의 대부분은 어느 칸들에서 나오나?
4. (경계) 두 비율 검정에서 귀무가 p1 = p2일 때 SE에 합동 비율을 쓰는 이유는? 신뢰구간을 만들 때는 왜 합치지 않나?
5. (연결) 2×2 분할표의 독립성 검정과 두 비율 z 검정은 어떤 관계인가? 유방촬영 예(500/44,925 vs 505/44,910)의 Z와 X²로 확인하라. Z가 책(−0.17)과 조금 다른 이유는?
6. (예측) 귀무가 참이고 한 칸의 기대 빈도가 0.6인 3칸 적합도 검정을 40000번 한다. 카이제곱 근사로 α = 0.05, 0.01, 0.001에서 기각하는 비율은 명목과 비교해 어떻게 될까? 기대 빈도가 고르게 4인 5칸이면?
7. (예측) 사용자 1,000명을 무작위 배정했고 효과는 없다. 사용자마다 페이지뷰 10개가 같은 전환 성향을 공유한다. 페이지뷰 단위 2×2 카이제곱의 p < 0.05 비율은 5%보다 클까? 왜 그런가? 어떻게 세야 하나?
8. (장애 진단) SQL로 만든 분할표의 X²가 노트북 계산과 다르다. `GROUP BY` 결과 행이 5개인데 범주는 3 × 2다. 원인과 고치는 쿼리 모양은?
9. (장애 진단) 배포 전후 오류 유형 분포 비교에서 p = 0.007 경보가 떴는데, 차이는 희귀 유형 3건(기대 0.6건)뿐이다. 이 p값을 믿어도 되나? 어떻게 다시 계산하나?
