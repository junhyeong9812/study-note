# data-analysis/12-correlation-vs-causation — 정답

## 정답

### 1. 상관만으로 인과를 말할 수 없는 이유

- r은 대칭이다(corr(X, Y) = corr(Y, X)). 방향 정보가 없다.
- 같은 상관을 만드는 다섯 갈래
  1. 인과: X → Y.
  2. 역인과: Y → X(느린 노드에 운영자가 캐시를 더 붙임).
  3. 교란: X ← Z → Y(트래픽이 미스와 지연을 둘 다 늘림).
  4. 선택(충돌): X → C ← Y인 C로 걸러 본 데이터 안에서만 상관이 생김.
  5. 우연: 지표를 많이 보면 하나쯤 상관이 큼(11 다중 비교).
- 데이터에는 화살표가 없으므로 셋 이상이 같은 숫자를 낼 수 있다.

### 2. y = x²

- 피어슨 r = **0**, 스피어만 = **0**(실험 E: 0.000, 0.000). 대칭이라 왼쪽의 감소와 오른쪽의 증가가 상쇄된다. 순위로 바꿔도 대칭이 그대로다.
- "관계 없음"이 아니다. y는 x로 완전히 정해진다. r = 0은 **직선(피어슨)·단조(스피어만) 관계가 없다**는 뜻이다(OpenIntro 8.1.4).

### 3. 이상값 하나

- 피어슨 r: 0.046 → **0.944**. 스피어만: 0.030 → **0.121**(실험 E, seed 9).
- 피어슨은 평균에서의 거리 곱을 쓰므로 멀리 떨어진 한 점의 곱이 합을 지배한다. 스피어만은 그 점을 "가장 큰 순위"로만 바꾸므로 거리의 크기가 사라진다.

### 4. Primer 표 1.1

| | 복용 | 미복용 |
|---|---|---|
| 남 | 81/87 = 93.1% | 234/270 = 86.7% |
| 여 | 192/263 = 73.0% | 55/80 = 68.8% |
| 합계 | 273/350 = 78.0% | 289/350 = 82.6% |

- 두 부분군 모두 복용이 높은데 합계는 미복용이 높다.
- 합계 = 부분군 비율의 가중 평균. 복용 열은 여성(회복률 낮음)이 263/350 = 75%, 미복용 열은 80/350 = 23%다. 복용 열이 "회복이 어려운 사람"으로 더 많이 채워졌다.
- 직접 표준화(전체 성비 357:343을 두 열에 똑같이 씌움): 복용 **83.3%**, 미복용 **77.9%**(실험 A). 성별을 맞추면 약이 낫다.

### 5. 표 1.2 — 같은 숫자, 다른 답

- 혈압은 약을 먹은 **뒤**에 정해지고, 약이 회복을 돕는 길(매개 변수)이다. 혈압으로 나누면 약이 일하는 길을 막고 독성 효과만 남겨 본다. 그래서 전체 효과를 묻는다면 합계를 따른다(Primer 1.2절). 표 1.2는 복용·미복용 열 제목도 바뀌어 있어, 합계는 복용 289/350(83%) > 미복용 273/350(78%)이다. 약을 권한다.
- 숫자만으로는 **구별할 수 없다**. 두 표는 숫자 배열이 똑같다. 변수가 처치 전에 정해졌는지(교란 후보) 처치의 결과인지(매개)는 데이터 밖의 인과 정보다.

### 6. 교란만으로 생긴 상관

- Z, e1, e2가 서로 독립이면 Cov(X, Y) = Cov(Z, 2Z) = 2. Var X = 1 + 1 = 2. Var Y = 4 + 1 = 5. r = 2/√(2·5) = 2/√10 ≈ **0.632**. 실험 D: 0.635.
- Z로 조정한 편상관은 **0 근처**다. 실험 D: 0.021. Z가 거의 같은 층(|Z| < 0.1)만 봐도 0.056.

### 7. SQL 세 쿼리와 전제

1. `GROUP BY GROUPING SETS ((device), ())`로 전체와 기기별 전환율을 나란히 낸다.
2. 처리군·대조군별 기기 구성비(`avg((device = 'mobile')::int)`)를 본다. 반전의 이유가 여기서 보인다(80.0% vs 20.1%).
3. 기기별 차이를 전체 기기 비율로 가중해 표준화 차이를 낸다(+0.48%p).
- 전제: 기기 안에서는 새 화면·옛 화면 사용자가 서로 바꿔 놓아도 같은 결과를 낼 집단이어야 한다(기기별 교환가능성). 이 합성 설정은 노출이 기기로만 정해져 성립한다. 재지 않은 교란 변수가 있으면 표준화도 틀린다. 각 기기에 두 화면 사용자가 모두 있어야 한다(양성 조건 — 80%/20%라 성립, Hernán·Robins 2006). 그리고 기기가 처치의 결과가 아니어야 한다(처치 전 변수).

### 8. 롤백 진단

- 먼저: 새 화면 그룹과 옛 화면 그룹의 **기기 구성비**. 실험 B·SQL 출력처럼 새 화면의 80%가 모바일이면, 낮은 전체 비율은 모바일의 낮은 기본 전환율 때문이다.
- 판단: 기기별 차이(모두 +0.5%p 근처)나 표준화 차이로 본다. 기기는 화면보다 먼저 정해지므로 교란 변수다.
- 다음 설계: 배포 순서가 노출을 정하지 않게 한다. 사용자 단위 무작위 배정, 필요하면 기기 안에서 같은 비율로 나누는 블록 무작위화(실험 C: 무작위면 전체 차이 +0.63%p).

### 9. 캐시 미스와 지연

- 가능한 설명: 트래픽(Z)이 미스와 지연을 둘 다 늘리는 교란. 또는 역인과(느린 노드에 운영자가 다른 설정을 붙였다).
- 확인
  - 트래픽 구간별로 나눠 미스–지연 상관을 본다. 또는 트래픽으로 조정한 편상관을 본다(실험 D: 0.635 → 0.021).
  - 무작위로 고른 일부 노드만 캐시를 늘리고 나머지와 비교하는 실험을 한다.
