# data-analysis/14-ab-testing-design — 정답

## 정답

### 1. 전후 비교의 한계와 무작위 배정

- 전후 비교에서는 화면 말고도 급여일·광고·계절·경쟁사 같은 것이 같이 바뀐다. 그 효과가 화면 효과와 섞여 가를 수 없다(교란).
- 무작위 배정은 같은 기간에 두 그룹을 만든다. 측정 못 한 성질도 **평균적으로** 두 그룹에 고르게 나뉜다. 그래서 차이는 "처리 또는 우연"으로 좁혀진다.
- 남는 것: 우연(한 번의 배정이 우연히 치우칠 수 있다 → 표준오차·검정으로 다룬다), 그리고 배정·로깅 버그·간섭 같은 실행 문제([15](../15-ab-pitfalls-srm-peeking/2-summary.md)).

### 2. 해시 배정 그림

```text
  "exp-checkout" + "|" + "user_000123" ──해시──> 64비트 수 ──floorMod 10,000──> 칸 c
  c < 5,000 (B 50%) → B,   c ≥ 5,000 → A
```

- 해시는 같은 입력에 늘 같은 값을 낸다. 그래서 배정을 저장하지 않고 매번 계산해도 같은 칸, 같은 화면이 나온다(실험에서 10만 명 재계산 일치 100,000/100,000).
- `floorMod`는 해시가 음수여도 0~9,999를 낸다.

### 3. salt가 같을 때와 다를 때

- 같은 salt: 두 실험의 배정이 똑같다. 실험 출력에서 100,000/100,000명이 같은 그룹이었다. 두 실험의 효과를 가를 수 없다.
- 다른 salt: 독립이면 약 50%(50,000 ± 158, 표준편차)가 같은 그룹이다. 실험 출력은 49,503(FNV-1a 단독)·49,597(fmix64 추가)이었다.
  - 각각 약 −3.1·−2.5 표준편차다. 독립 이항 근사로는 양측 p ≈ 0.0017·0.011이라 5% 기준에서 우연으로 보기 어렵다. 다만 쌍 하나라 원인(해시 구조 vs 이 ID 집합의 우연)은 가르지 않는다. 끝 글자만 다른 salt 8쌍(`exp-0a`/`exp-0b` …)에서는 이 실험에서 FNV-1a 단독이 최대 1,263(약 8 표준편차) 벗어났고, fmix64 판은 모두 ±230 안이었다. salt는 해시 입력의 앞부분이라 뒤의 사용자 ID가 더 섞여, 세션 키(64.2%)보다 어긋남이 훨씬 작다.

### 4. 단위 불일치 A/A의 거짓 양성률

- 세션 단위 z 검정: 약 13%(seed 1에서 0.128, seed 2에서 0.127).
- 사용자 단위 델타 방법: 약 5%(0.051, 0.053). 2,000회 시뮬레이션의 표본 오차(약 ±1%p) 안이다.
- 이유: 같은 사용자의 세션은 같은 성향을 공유해 독립이 아니다(양의 상관 — 이 설정처럼 사용자마다 성향이 다를 때). 세션 수를 표본 크기로 쓰면 정보량을 부풀려 표준오차가 작아진다. 13%라는 크기는 이 합성 설정의 값이다.

### 5. 표본 크기

- 식: `n = (z_{0.975} + z_{0.8})² · [p₁(1−p₁) + p₂(1−p₂)] / (p₂ − p₁)²`.
- 5% → 5.5%: 그룹당 31,231명(실험 출력). 같은 n에서 시뮬레이션 검정력은 0.823(seed 7, 400회)이었다.
- 상대 5%(5% → 5.25%): 122,121명. 약 4배다. 효과 크기가 분모에서 제곱으로 들어가기 때문이다.
- 이 식은 정규 근사다. 전환율이 아주 작거나 n이 작으면 맞지 않을 수 있다.

### 6. 끝 글자만 다른 키

- 독립이면 두 세션이 같은 그룹일 비율은 50%(30,000명 중 약 15,000), 세 세션이 모두 같을 비율은 25%(약 7,500)다.
- 실험(FNV-1a 단독): 19,258(64.2%)과 4,259(14.2%). fmix64를 더하면 15,002와 7,496.
- 원인: FNV-1a는 마지막 바이트를 XOR 한 번·곱 한 번으로만 섞는다. `'0'`과 `'1'`은 XOR 뒤 값이 1 차이라 두 해시는 정확히 ±P(FNV 소수) 차이가 나고, 칸은 늘 ±1,789(P mod 10,000 = 8,211)만큼 떨어진다. 거리는 결정적이고, 출발 칸이 고르게 퍼졌다고 가정하면 같은 쪽 기대 비율은 1 − 2 × 0.1789 = 64.22%다(이 키 형식·10,000칸·50% 경계에서의 계산, 관측 19,258/30,000 = 64.19%와 일치).
- 고치기: 마무리 섞기(fmix64 등)를 더하거나 섞임이 검증된 해시를 쓴다. 실제 키 형식으로 일치율·χ² 독립성 시험을 배포 전에 돌린다.

### 7. 3일 실험의 +6%

- 의심: 신규성 효과. 바뀐 것이 새로워 처음에만 반응이 크다.
- 확인: 일별(또는 노출 후 경과 일수별) 효과 그래프가 내려가며 수렴하는지 본다. 신규 사용자 부분군의 효과를 본다(그들에게는 "새로움"이 없다).
- 기간: 표본 크기(MDE·α·검정력)로 정한 그룹당 n을 그룹당 하루 유입으로 나누고(50:50이면 2n ÷ 전체 하루 유입), 온전한 주 단위로 올린다. 중요한 변경은 일부 사용자를 오래 남겨(홀드아웃) 장기 효과를 잰다.

### 8. 로그인 순간 키가 바뀐다

- 익명일 때 `기기 ID`, 로그인 후 `회원 ID`로 해시하면 열쇠가 바뀌어 칸이 바뀔 수 있다. 같은 사람이 A를 보다가 B를 본다.
- 결과: 두 화면을 다 본 사용자가 양쪽 지표에 섞인다. 효과가 희석되거나, 로그인 여부와 처리가 엉켜 편향이 생긴다.
- 대처: 실험 모집단을 로그인 사용자로 한정하거나, 기기 ID로 일관되게 배정한다. 두 화면을 다 본 사용자 수를 리포트에 표시한다.

### 9. 실험 전에 정할 것

| 정할 것 | 뒤에 정하면 |
|---|---|
| 가설(방향·크기) | 결과를 보고 이야기를 맞춘다 |
| 배정 단위 | 같은 사람이 두 화면을 본다 |
| 분석 단위·판단 지표 | 유의한 지표를 골라 보고(다중 비교, [11](../11-multiple-comparisons/2-summary.md)), 분산 과소 |
| 가드레일 | 판단 지표만 좋고 지연·오류가 나빠진 채 출시 |
| 표본 크기·기간 | 유의가 나올 때 멈춤(엿보기, [15](../15-ab-pitfalls-srm-peeking/2-summary.md)), 검정력 부족 |
