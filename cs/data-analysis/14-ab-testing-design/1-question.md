# data-analysis/14-ab-testing-design — 질문

## 질문

1. (왜) 배포 전주와 배포 후주의 전환율을 비교하는 것으로는 왜 화면 효과를 알 수 없나? 무작위 배정은 이 문제를 어떻게 줄이고, 무엇은 여전히 남기나?
2. (그림) "exp-checkout" 실험에서 `user_000123`이 B인지 A인지 정해지는 과정을 해시 → 칸 → 경계 순서로 그려라. 저장 없이도 같은 사람이 같은 화면을 보는 이유는?
3. (예측) 10만 명을 50:50으로 나누는 실험 두 개가 같은 salt를 쓰면, 두 실험에서 같은 그룹인 사용자는 몇 명쯤인가? 서로 다른 salt(앞부분부터 다른 문자열)면? 실험 출력으로 확인하라.
4. (예측) 사용자 단위로 배정하고 세션 단위로 전환율을 비교한 A/A 실험을 2,000번 하면, 유의수준 5%에서 "유의"가 몇 %쯤 나오나? 사용자 단위 분산(델타 방법)으로 바꾸면?
5. (계산) 기준 전환율 5%에서 상대 10% 상승(5% → 5.5%)을 α = 0.05(양측), 검정력 80%로 잡으려면 그룹당 몇 명이 필요한가(정규 근사)? 탐지할 효과를 상대 5%로 줄이면 몇 배가 되나?
6. (경계) 세션 ID처럼 `user_7#s0`, `user_7#s1` 끝 글자만 다른 키를 FNV-1a 단독으로 해시해 배정했다. 같은 사용자의 두 세션이 같은 그룹일 비율은 독립이면 얼마여야 하고, 실험에서는 얼마였나? 어떻게 고치나?
7. (장애 진단) 3일 실험에서 +6%로 출시했는데 한 달 뒤 효과가 거의 없다. 어떤 현상을 의심하고, 어떤 그래프·부분군으로 확인하나? 다음 실험의 기간은 어떻게 정하나?
8. (연결) 익명 방문자는 기기 ID로, 로그인 사용자는 회원 ID로 배정한다. 로그인하는 순간 어떤 일이 생길 수 있고, 실험 결과에 어떻게 섞이나? ([domain-modeling/advanced/27-ab-assign](../../domain-modeling/advanced/27-ab-assign/2-summary.md)과 연결)
9. (경계) 실험 전에 정해야 할 것 다섯 가지를 들고, 각각을 실험 뒤에 정하면 생기는 문제를 하나씩 대라.
