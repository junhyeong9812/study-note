## 1. 전압과 트랜지스터

출처: `computer_science/chapter/chapter8/chapter8.py`

컴퓨터를 통과하는 전기의 특성인 전압, 전류, 저항이 존재한다.
이때 저항을 전기가 통과하게 되면 전압이 낮아지는데 이 순간을 전압 강하라 한다.
그리고 이렇게 전압이 저항을 지나면 강하로 인해 0V가 된다.
저항을 만나지 않으면 5V로, 이를 바탕으로 0과 1을 인식한다.
+5V 라인을 1 그리고 0V 라인을 0으로 인식한다.
이때 전자회로 자체에 스위치를 통해 전압을 알맞은 위치에서 측정하면 스위치를 켜거나 끄면서 1과 0을 바꿀 수 있게 된다.
이러한 스위치의 역할을 하는 것이 트랜지스터이다.
이때 트랜지스터의 베이스에 전압을 공급하면 콜렉터에서 이미터로 + -> -로 전류가 흐른다.
스위치가 켜진 것이다.
베이스에 0V를 공급하면 전류는 흐르지 않는다.
스위치가 꺼진 것이다.
이렇게 트랜지스터에 의해 0과 5V를 통해 0과 1을 인식하는 것이다.

## 2. 논리 게이트

출처: `computer_science/chapter/chapter8/chapter8.py`

논리 게이트란 컴퓨터에 들어가는 수많은 디지털 회로를 구성하는 가장 기본적인 요소를 말한다.
bool 함수를 구현하기 위한 회로를 논리 게이트라 하며 AND, OR, XOR, NOT이 있다.
AND 게이트는 다양한 트랜지스터를 거쳐 1이 되는 순간 Y에서 5V일 경우 True이며, 이게 저항 이후에 있게 되면 0V가 되기 때문에 저항 이전에 구현해야 된다.

## 3. CPU 내부 구조

출처: `computer_science/chapter/chapter8/chapter8.py`

CU(Control Unit)는 제어 장치.
우리가 작성한 코드는 컴퓨터가 이해할 수 있는 언어인 기계어(0과 1로 이루어짐)로 번역되어 메모리에 저장된다.
이후 프로그램이 실행되면 CPU는 이 명령을 한 줄씩 읽어들여 실행한다.
이때 어떤 명령인지 해석하고 이를 실행하려고 할 때 CPU의 각 파트에 지시를 내리는 역할을 하는 것이 제어 장치.
ALU는 산술 논리 연산 장치로 덧셈 같은 산술 연산과 AND, OR 같은 논리 연산을 하는 곳.
AX, BX, IR, PC는 모두 레지스터이다.
레지스터는 CPU 안에 내장된 메모리라 생각하면 된다.
보통 가산기는 대표적인 조합 논리 회로이며 레지스터는 대표적인 순차 논리 회로이다.

조합 논리 회로는 현재 입력에 의해서만 출력이 결정되는 논리 회로이다.

가산기는 ALU 내부에 위치하고 레지스터 AX와 BX 값을 받는다.
우리는 현재 4비트 CPU를 다루기 때문에 AX와 BX 값도 4비트로 입력된다.
AX와 BX가 덧셈 연산 후 다시 AX로 출력된다.
AX에서 A는 Accumulator로 이름 그대로 값을 축적해 나가는 레지스터이다.

## 4. 가산기 — 반가산기와 전가산기

출처: `computer_science/chapter/chapter8/chapter8.py`

가산기는 단순히 비트 두 개만 더하는 반가산기와 캐리까지 연산에 포함하는 전가산기가 있다.
전가산기는 반가산기 두 개와 OR 게이트 하나로 이뤄져 있다.
반가산기는 XOR 게이트와 AND 게이트가 하나씩만 있다면 만들 수 있다.
이때 전가산기에는 CI(Carry In), CO(Carry Out)이 존재한다.
이때 출력 회로인 Y는 1개이기에 만약 1, 1을 더해 10이 된다면 Y는 0이 되고 CO에 1이 들어가며 받아올림수를 보관한다.
그리고 CO로 나가게 되는 1은 다음 회로의 CI로 데이터를 전달하여 올림을 할 수 있게 해주는 것.
그러면 만약 두 자리를 더한다면 0100 + 0110일 경우 1010이 되는데, 이때 3번째 자리의 회로 CO에는 1이 들어가 다음 자리 CI로 넘어가 1000이 되는 것.
이러한 덧셈이나 뺄셈 등을 포함한 ALU 연산은 현재 출력이 오로지 현재 입력에 의해서만 결정된다는 특징이 있다.
CI는 입력 / CO는 출력.

## 5. 순차 논리 회로와 플립플롭

출처: `computer_science/chapter/chapter8/chapter8.py`

순차 논리 회로는 현재의 출력이 현재의 입력과 과거의 출력에 따라 정해지는 논리 회로.
AND 게이트 앞에 추가된 동그라미 논리 게이트인 NAND가 있는데 이는 모든 AND 출력 값을 반전시키면 된다.
이때 순차 논리 회로는 출력이 분기되어 다시 입력 레지스터로 돌아오는 것인데,
순차 논리 회로는 S, R과 함께 지난번 출력으로 결정된다. 순차 논리 회로의 핵심은 Q값이 S와 R이 특정한 값일 때만 바뀐다는 점이다.
이를 보면 입력에 따라 무조건 출력이 되는 것이 아닌 이전의 데이터에 따라 출력이 바뀐다는 것이다.
즉 특정 상황이 되었을 때만 바뀐다는 점과 이를 통해 이전 출력값이 유지된다는 점이다.
즉 출력값이 저장된다고 볼 수 있다.
이러한 특성으로 플립플롭을 메모리 소자, 즉 메모리를 구성하는 기본 단위라 한다.
CPU 안에 있는 레지스터는 사실 많은 플립플롭의 묶음이다.

순차 논리 회로의 특징
-> 현재의 출력이 현재의 입력과 함께 과거의 출력에 따라 결정된다.

## 6. 클록과 D 플립플롭

출처: `computer_science/chapter/chapter8/chapter8.py`

클록에 대해 알아보기 전에 우리는 주파수와 주기에 대해 알아야 된다.
전자는 왔다갔다를 반복하는 주기 운동을 한다.
즉 전자가 1초 동안 왕복한 횟수를 주파수라 한다.
전자가 1초 동안 두 번 왕복했을 때 2Hz = 2cycle/sec로 표현하고
t = 1/f = 1/2 = 0.5sec/cycle이라 표현하며
주파수와 주기는 반비례 관계이다.

CPU의 속도에 GHz라는 단위가 존재하는데, 이때 클록 속도는 CPU 혹은 프로세서 속도의 지표로 1초에 클록이 몇 번 발생했는가를 의미한다.
컴퓨터 내부에는 클록 발생기가 있는데 이 발생기는 일정 시간에 맞춰 펄스 신호를 생성한다.
클록 펄스를 보면 일반적으로 상승 에지에 맞춰 인스트럭션을 실행한다.
인스트럭션이란 우리가 작성한 코드가 CPU에서 실행되기 위해 최종적으로 변환된 기계어 명령어이다.
모든 에지마다 인스트럭션을 하나씩 실행하는 것은 아니지만
클록 주파수가 높을수록 1초당 상승 에지 수가 높아지고 그만큼 실행되는 인스트럭션 수도 늘어나니
CPU의 주파수가 높을수록 연산 속도가 빠른 성능 좋은 컴퓨터이다.

그럼 이제 이 클록과 동기화가 어떻게 되는가에 대해서 —
ALU의 가산기나 레지스터는 어떻게 클록에 동기화할까?
이 질문에 답하려면 D 플립플롭이라는 논리 회로를 알아야 한다.
D는 Data/Delay를 의미한다.

D 플립플롭 진리표

```
CLK D Q      Q_
0   x Q이전  Q_이전
1   1 1      0
1   0 0      1
```

2와 3, 즉 클록이 1일 경우 출력 Q는 입력과 같은 값을 전달한다.
입력 D값이 1이면 출력 Q도 1을 출력하고 D값이 0이면 출력 Q도 0을 출력한다.
(클록이 0일 경우 입력이 무엇이든 출력은 변하지 않는다.)

즉! 레지스터는 플립플롭의 묶음이라고 하였습니다.
레지스터가 이러한 특성이 있으면 연산이나 데이터의 전송을 클록에 동기화할 수 있습니다.
예를 들어 ALU에서 입력과 동시에 출력이 나왔다고 해도 레지스터가 클록에 맞춰 결괏값을 저장한다면 이는 결국 클록에 동기화된 것이다.

## 7. 레지스터 — IR·PC·범용 레지스터

출처: `computer_science/chapter/chapter8/chapter8.py`

이제 레지스터의 의미와 시스템 버스란 —
우선 레지스터부터 알아보자.

IR(Instruction Register): C = A + B 코드는 1줄이지만 기계어로 번역하면 최소 네 개의 명령어로 변환된다.
변환된 명령어는 프로그램을 실행하면 메인 메모리에 올려지고 하나씩 실행되는데,
이때 메모리에 있는 명령어를 CPU에 가져와 저장해 두는 것이 IR이다.

PC(Program Counter): 현재 실행 중인 명령어 다음에 실행될 명령어의 메모리 주소를 담고 있다.

AX, BX는 범용 레지스터라 부르며 주로 메모리에서 읽어들인 데이터를 저장했다가
ALU가 연산할 때 피연산자로 전달하거나 연산 결과 값을 저장할 때 쓰인다.

## 8. 시스템 버스

출처: `computer_science/chapter/chapter8/chapter8.py`

시스템 버스는 CPU, I/O, 주변 장치가 모두 시스템 버스를 통해 데이터를 주고받는다.

1. 데이터 버스(Data Bus): 제어 버스의 신호(signal)에 따라 데이터를 CPU에서 메모리로 전송하거나 반대로 메모리에서 CPU로 전송한다. 그러므로 버스는 양방향이어야 한다.
2. 제어 버스(Control Bus): 데이터를 레지스터로 읽어올지(READ) 아니면 메모리에 쓸지(WRITE) CPU가 메모리에 전달한다.
3. 주소 버스(Address Bus): 메모리에서 레지스터로 혹은 레지스터에서 메모리로 데이터를 전송할 때 필요한 메모리 주소를 전달한다. CPU가 메모리에 알려주는 방식이므로 단방향이다.

결국 심플하게, IR에서 명령어를 처리하고 다음 실행할 명령어를 위해 PC에서 주소를 메모리에 보내면 메모리는 IR에 해당 연산 정보를 보낸다.

## 9. 인스트럭션 세트

출처: `computer_science/chapter/chapter8/chapter8.py`

인스트럭션 세트는 CPU가 인식하여 실행할 수 있는 기계어이다.
이때 기계어는 바이너리 형태라 사람이 읽기 힘들어서, 기계어를 사람이 읽을 수 있도록 1대1 대응한 문자 형태의 명령어가 어셈블리어이다.
인스트럭션 세트는 CPU마다 다르다.
그래서 새로운 CPU를 도입하였으면 그에 맞게 프로그래밍해야 한다.
이러한 불편함을 없애고자 C언어를 비롯한 하이레벨 언어가 탄생.
컴파일 언어는 작성한 코드는 그대로 두고 작동하는 컴퓨터에 따라 컴파일만 다시 하면 된다.

인스트럭션 세트는 맨 앞에 명령어/레지스터/레지스터로 대부분 되며
레지스터는 AX, BX, CX, DX로 대부분 4개가 범용이며
예시로 AX와 CX를 더해 그 값을 첫 번째 연산자인 AX에 저장하라는 의미로 ADD AX, CX로 바꾸면 0000010이 되고
이때 곱셈과 나눗셈은 AX값은 이미 지정되어 있고 피연산자만 코드에 추가하는 설계로 된다.
이때 나눗셈을 한다면 몫이 AX 그리고 DX에 나머지가 저장되는 걸 볼 수 있다.

메모리 접근 명령어인 LOAD와 STORE를 설계해 본다면,
우선 직접 주소 방식(Direct Addressing Mode) 명령어를 만들고 간접 주소 방식(Indirect Address Mode) 명령어가 필요한 이유 —
로드 명령어는 메모리에서 레지스터로 데이터를 읽어들이는 명령어이다.
가운데 2비트는 범용 레지스터 네 개 중 메모리에 저장하려는 위치, 나머지 3비트는 데이터가 있는 메모리 주소를 나타낸다.
이처럼 데이터의 메모리 주소를 직접 저장하는 방식을 직접 주소 방식이라 한다.
하지만 이러한 직접 주소 방식은 3비트는 주소 8개만 가리킬 수 있어서 8비트 컴퓨터는 256개의 주소를 가질 수 있고 이건 비효율적이다.

어셈블리어를 보면 `LOAD BX, [0x02]` 이러한 구조인데, [] 안에 들어 있는 주소는 읽어들일 데이터의 메모리 주소가 아닌 데이터의 메모리 주소값을 저장하는 곳의 주소이다.
다시 말해서 [] 기호 속 들어 있는 주소로 접근해 그곳에 저장된 값을 다시 주소로 사용하여 접근하면 데이터가 존재하게 되고,
STORE 명령어는 LOAD 명령어와 명령어 구조는 같지만 데이터 이동 방향만 다르다.

## 10. 어셈블리 예제 — C = A + B

출처: `computer_science/chapter/chapter8/chapter8.py`

C로 보는 변경 코드

```c
int A = 5;
int B = 3;
int C = 0;
C = A + B;
```

```asm
LOAD AX, A(0x01)
LOAD CX, B(0x02)
ADD AX, CX
STORE AX, C(0x3)
```

위 코드는 C = A + B 코드의 어셈블리어 코드이다.
