## 질문

### 1. 캐스트 네 개가 만드는 기계어 (예측) ★

```c
char *   c_ptr (int *p)   { return (char *)p; }
unsigned c_u   (int i)    { return (unsigned)i; }
long     c_long(int i)    { return (long)i; }
int      c_int (double d) { return (int)d; }
```

`gcc -std=c17 -O1 -S -masm=intel` 로 찍는다.

- 네 함수 각각에서 **캐스트 때문에 생긴 명령**은 몇 개인가?
- 넷 중 **명령이 하나도 안 생기는 것**은 어느 것들인가?
- `(int)d` 가 만드는 명령의 이름에서 무엇을 읽을 수 있는가?
- 이 실험이 「캐스트는 두 종류다」를 어떻게 보여 주는가?

### 2. 같은 `int` 를 `float` 로 (예측)

```c
int x = 1078530011;             /* 0x40490FDB */
float g;
memcpy(&g, &x, sizeof g);
printf("%.8f\n", g);
printf("%.8f\n", (float)x);
```

- 두 줄은 각각 무엇을 찍는가?
- 두 값이 **얼마나** 다른가 — 왜 다른가?
- 「비트를 그대로 옮긴다」와 「값을 옮긴다」 중 각각 어느 쪽인가?
- `*(float *)&x` 로 써도 같은 답이 나오는가 — 나온다면 그래도 쓰면 안 되는 이유는?

### 3. 포인터를 정수에 담았다 되돌리기 (예측)

```c
int x = 5;
void *p = &x;
intptr_t ok   = (intptr_t)p;
int      lost = (int)(intptr_t)p;
printf("%d\n", (void *)ok == p);
printf("%d\n", (void *)(intptr_t)lost == p);
printf("%zu %zu %zu\n", sizeof(void *), sizeof(int), sizeof(intptr_t));
```

- 두 비교는 각각 무엇을 찍는가?
- 왜 갈리는가?
- `(int)p` 에는 **캐스트를 씌웠는데도** 경고가 남는다 — 플래그를 하나도 안 줘도 남는가?
- `intptr_t` 는 어느 층인가 — **반드시 있는 타입인가?**

### 4. 정렬이 안 맞는 포인터 (예측) ★★

```c
char buf[16] = {0};
int *p = (int *)(buf + 1);      /* (a) 캐스트만 한다 */
/* (b) 여기서 *p = 0x41424344; 를 더하면? */
```

- `-fsanitize=undefined` 로 **(a)만** 돌리면 무엇이 나오는가?
- **(b)까지** 돌리면 무엇이 나오는가 — 몇 줄인가?
- 이 검사는 `-fsanitize=undefined` **기본 집합에 들어 있는가**, 따로 켜야 하는가?
- 표준이 금지하는 자리와 **도구가 잡는 자리가 같은가?**
- 이식 가능한 대안은 무엇인가?

### 5. 같은 객체를 두 타입으로 (예측) ★★★ 이 주제의 위험지대

```c
int alias_test(int *pi, float *pf) {
    *pi = 1;
    *pf = 2.0f;
    return *pi;
}
int x = 0;
int r = alias_test(&x, (float *)&x);
printf("%d %d\n", r, x);
```

**`-O0`·`-O1`·`-O2`·`-O3`·`-Os` 다섯 수준을, 각각 `-fstrict-aliasing`(기본)과 `-fno-strict-aliasing` 으로 돌린다.**

- 열 번의 실행에서 `r` 은 몇 종류의 값을 내는가 — 경계선은 어느 최적화 수준인가?
- `x` 도 같이 갈리는가?
- 어셈블리에서 두 빌드는 **몇 명령** 차이인가 — 무엇이 없어졌는가?
- `-Wall -Wextra` 는 몇 건을 말하는가? `-Wstrict-aliasing` 은 **수준별로** 어떤가?
- `-fsanitize=undefined` 와 `-fsanitize=address` 는 각각 무엇을 말하는가?
- `memcpy` 로 바꾸면 **기계어가 얼마나 느려지는가?**

### 6. `const` 를 캐스트로 떼고 쓰면 (예측) ★

```c
const int frozen = 7;
int *bad = (int *)&frozen;
*bad = 99;
printf("*bad = %d, frozen = %d\n", *bad, frozen);
```

**`-O0`·`-O1`·`-O2`·`-O3`·`-Os` 다섯 수준으로 돌린다.**

- 다섯 줄의 출력은 각각 무엇인가 — 경계선은 어느 수준인가?
- `-fsanitize=undefined` 는 무엇을 말하는가?
- `-Wall -Wextra` 는 몇 건인가? 어떤 플래그를 더 켜야 1건이 되는가?
- 캐스트를 **빼면** 어떤 진단이 나오는가?
- 같은 코드인데 **원래 객체가 `const` 가 아니면** 결론이 달라지는가?

### 7. 캐스트가 끄는 경고와 못 끄는 경고 (왜)

- 캐스트를 씌우면 `-Wconversion` 이 조용해지는 이유는 무엇인가?
- 캐스트를 씌워도 **남는** 경고가 있다 — 어떤 것들이고, 왜 그것만 남는가?
- `-Wsign-compare` 를 캐스트로 고치는 두 방법 중 **하나는 답까지 고치고 하나는 경고만 끈다** — 어느 쪽이 어느 쪽인가?
- 「경고가 사라졌다」를 「고쳤다」로 읽으면 안 되는 이유를 한 줄로 쓰면?

### 8. `(char)` 로 좁히면 (경계)

- `(char)200` 은 이 환경에서 무엇인가?
- `-funsigned-char` 를 붙이면 같은 식이 무엇이 되는가?
- 이것은 어느 층인가 — UB 인가?
- `-Wconversion` 이 이것을 말해 주는가?
- 그래서 바이트를 다룰 때 무엇을 쓰는가?

### 9. 함수 포인터 캐스트 (경계)

- 함수 포인터를 **다른 함수 포인터 타입으로 바꿨다 되돌리면** 원래 값인가?
- 그 타입으로 **호출**하면 어느 층인가?
- `-O0` 으로 세 판 돌리면 값이 같은가?
- `-O2` 에서 gcc 가 내는 경고 문구는 무엇인가 — 소스에 초기화 안 한 변수가 없는데 왜 그런 말이 나오는가?
- 이 경고는 `-Wall` 에 있는가 `-Wextra` 에 있는가?
- gcc 의 `-fsanitize=undefined` 로 이것을 잡을 수 있는가?

### 10. `void *` 는 무엇이 다른가 (연결)

- `void *` 와 `int *` 사이에 **캐스트가 필요한가?**
- 왕복이 보장되는가 — 어떤 왕복이?
- `malloc` 의 반환에 캐스트를 붙이지 않는 관례의 근거는 무엇인가?
- 붙이면 **무엇이 가려지는가?**
- `void *` 와 **함수 포인터** 사이는 같은 이야기인가?

### 11. 그래서 언제 캐스트를 쓰나 (연결)

- 「비트를 다른 타입으로 읽고 싶다」에 대한 이식 가능한 답은 무엇이고, 그 비용은 얼마인가?
- 「캐스트를 쓰고 싶다」는 생각이 들 때 **먼저 물어야 할 한 문장**은?
- 이 주제의 결론을 빌드 플래그 한 줄로 쓰면?
- UB 다섯 개(정렬·앨리어싱·`const`·시그니처·리터럴) 중 **도구가 못 잡는 것**은 몇 개인가?
