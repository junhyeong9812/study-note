# c/syntax/18 — 가변 길이 배열(VLA): 「**크기를 실행 시점에 정하고, 그 자리를 스택에서 꺼낸다**」 — 질문

> 복습은 항상 이 파일에서 시작한다. **맨기억으로 답을 시도**하고,
> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.
> 이 주제의 질문은 **예측형 위주**다 — 아는지가 아니라 **출력을 맞힐 수 있는지**를 묻는다.
> **환경** — gcc 13.3.0 · clang 18.1.3 · x86-64 Linux · 기본 `-std=c17 -Wall -Wextra -pedantic` · `ulimit -s` 는 **8192 KB**.
> ★★ **이 주제의 인출 축은 셋**이다.
> ① **`sizeof` 의 숫자**(16 인가 36 인가 8 인가 12 인가) ② **종료 코드**(`0` · `1` · `139`) ③ **누가 침묵하나.**
> ★★ **답할 때 「표준 문서가 그렇게 정했다」와 「이 구현에서 재 보니 그렇더라」를 반드시 갈라 말해라** —
> 이 주제에서 가장 자주 섞이는 자리가 거기다.
> ★ 코드는 **발췌**다. 전문은 정답 파일에 있다.

### 1. 같은 함수를 세 `n` 으로 부르면 (예측) ★★

```text
(발췌 — 전문은 정답 파일에)

static void show(int n) {
    int vla[n];
    int fixed[8];
    printf("sizeof vla = %zu · 원소 %zu 개\n", sizeof vla, sizeof vla / sizeof vla[0]);
}
int main(int argc, char **argv) {
    int n = 3 + argc;
    int vla[n];  int fixed[8];
    /* sizeof fixed, sizeof vla, _Generic(sizeof vla, size_t: …) 를 찍는다 */
    show(4); show(9); show(17);
}
```

- `main` 에서 찍는 **`sizeof fixed` 와 `sizeof vla`** 는 각각 얼마인가?
- `show(4)`·`show(9)`·`show(17)` 이 찍는 **`sizeof vla` 세 값**은?
- `sizeof` 의 **결과 타입**은 VLA 에서 달라지는가?
- ★ `sizeof vla / sizeof vla[0]` 관용구가 **여기서는** 맞는 답을 내는가?

### 2. `sizeof` 안에 함수 호출을 넣은 여섯 식 (예측) ★★★ 이 주제의 축

```text
(발췌 — 전문은 정답 파일에. f() 는 부를 때마다 호출 수를 1 늘리고 5 를 돌려준다)

int n = 4;
int fixed[8];
int vla[n];

sizeof fixed[f()]          sizeof vla[f()]
sizeof vla                 sizeof(int[3])
sizeof(int[f()])           sizeof(int[f() ? 3 : 3])
```

- **여섯 값**은 각각 얼마인가?
- **`f()` 는 모두 몇 번 불리는가** — 어느 식에서 불리는가?
- ★ `sizeof vla[f()]` 와 `sizeof(int[f()])` 가 갈리는 **기준 한 줄**은 무엇인가?
- ★ `sizeof(int[f() ? 3 : 3])` 은 결과가 늘 같은데도 왜 그런가?
- gcc 와 clang 이 다른가?

### 3. `__STDC_NO_VLA__` 를 여덟 벌로 찍으면 (예측) ★★★

```text
(발췌 — 전문은 정답 파일에)

#ifdef __STDC_VERSION__  … __STDC_VERSION__ 를 찍는다 … #else … "정의 안 됨" … #endif
#ifdef __STDC_NO_VLA__   … 값을 찍는다        … #else … "★ 정의 안 됨" … #endif
int n = 4;  int vla[n];  vla[0] = 42;
/* sizeof vla 와 vla[0] 를 찍는다 */
```

- gcc 를 `-std=c89`·`c99`·`c11`·`c17`·`c2x` 로, clang 을 `-std=c89`·`c17`·`c23` 으로 던지면 **`__STDC_NO_VLA__` 는 몇 벌에서 정의되는가?**
- **`-std=c89 -pedantic`** 에서 `int vla[n]` 은 컴파일되는가 — **`cc exit`** 과 **`run exit`** 은?
- ★ gcc 를 **`-std=c23`** 으로 던지면 무슨 일이 나는가?
- ★ gcc `-std=c2x` 와 clang `-std=c23` 의 **`__STDC_VERSION__` 값이 같은가?**
- ★★ 이 출력에서 **「표준이 정한 것」은 무엇이고 「이 구현이 그런 것」은 무엇인가?**

### 4. 8MB 스택에 두 크기를 던지면 (예측) ★★★

```text
(발췌 — 전문은 정답 파일에)

static void touch(long n) {
    char vla[n];
    vla[0] = 1;
    vla[n - 1] = 2;
    fprintf(stderr, "  n = %ld 바이트 : 잡았다 (%d %d)\n", n, vla[0], vla[n - 1]);
}
/* main 은 인자를 받아 touch(n) 을 부르고 "정상 종료" 를 찍는다 */
```

- `./x 8000000` 과 `./x 9000000` 의 **출력과 `run exit`** 은 각각 무엇인가?
- ★ 죽는 판에서 **컴파일 경고는 몇 건**이고 **실행 중 진단은 몇 줄**인가?
- `./x 100000000` 은 9,000,000 판과 **무엇이 다른가?**
- ★ **ASan 을 켜면** 무엇이 달라지는가 — **`run exit`** 은?
- ★ `-Wvla` 를 켜면 이 사고를 막을 수 있는가 — **왜 그런가?**

### 5. 크기가 0 이거나 음수면 (예측) ★★

- 같은 프로그램에 **`0`** 과 **`-1`** 을 던지고 **UBSan** 을 켜면 각각 **몇 줄**이 나오는가?

### 6. VLA 매개변수 두 꼴의 `sizeof` (예측) ★★

```text
(발췌 — 전문은 정답 파일에)

static int sum1(int n, int a[n]) { … printf("sizeof a = %zu\n", sizeof a); }
static int sum2(int rows, int cols, int a[rows][cols]) {
    … printf("sizeof a = %zu · sizeof a[0] = %zu\n", sizeof a, sizeof a[0]);
}
int sum3(int n, int a[*]);
int sum3(int n, int a[n]) { … }

int flat[6] = {1,2,3,4,5,6};
int grid[2][3] = {{1,2,3},{4,5,6}};
```

- `sum1` 안의 **`sizeof a`** 는 얼마인가?
- ★ `sum2` 안의 **`sizeof a` 와 `sizeof a[0]`** 은 각각 얼마인가 — **그 값은 언제 정해지는가?**
- 세 합(`sum1`·`sum2`·`sum3`)은 각각 얼마인가?
- ★ 경고는 몇 건이고 **gcc 와 clang 의 플래그 이름이 같은가?**
- ★ 이 판과 목록의 **17번 주제**의 차이는 무엇인가?
