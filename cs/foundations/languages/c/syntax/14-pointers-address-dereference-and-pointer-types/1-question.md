## 질문

### 1. 네 변수의 주소를 찍고 둘을 고치면 (예측) ★★

```c
int   x  = 42;
int   y  = 7;
int  *p  = &x;
int **pp = &p;
/* &x, &y, &p, &pp 와 p, pp, *p, *pp, **pp 를 찍는다 */
/* 그리고 uintptr_t 로 &y-&x, &p-&x, &pp-&p 를 찍는다 */

*p = 99;
/* 여기서 x 를 찍는다 */
p = &y;
/* 여기서 x 와 *p 를 찍는다 */
```

- `p` 와 `*p` 와 `&p` 는 각각 무엇인가?
- 세 바이트 차이는 각각 얼마인가 — **다시 돌리면 같은가?**
- `*p = 99` 뒤 `x` 는? 그 다음 `p = &y` 뒤 `x` 는?
- ★ 이 출력에서 **근거로 쓸 수 있는 것**과 **쓸 수 없는 것**을 가르면?

### 2. 함수 둘이 각각 호출자의 포인터를 건드리면 (예측) ★★★ 이 주제의 축

```c
static void alloc_bad(int *p, int n) {
    p = malloc((size_t)n * sizeof *p);
    if (p) p[0] = 7;
}
static void alloc_good(int **pp, int n) {
    *pp = malloc((size_t)n * sizeof **pp);
    if (*pp) (*pp)[0] = 7;
}
int main(void) {
    int *a = NULL;  alloc_bad(a, 4);   /* a 는? */
    int *b = NULL;  alloc_good(&b, 4); /* b 는? */
}
```

- 두 줄은 각각 무엇을 찍는가?
- 경고는 몇 건인가 — 어느 플래그에서?
- ★ ASan 을 붙이면 무엇이 추가로 나오는가 — **몇 바이트**인가?
- 왜 `alloc_bad` 는 실패하는가 — 한 문장으로?

### 3. 타입이 다른 포인터를 대입하면 (예측)

```c
int     i = 0x41424344;
char   *cp;   int *ip;   void *vp;   double *dp;

cp = &i;
ip = &i;
vp = &i;
ip = vp;
dp = ip;
```

- **다섯 줄 중 몇 줄**에서 진단이 나오는가 — 어느 줄인가?
- 그것은 **경고인가 에러인가** — 종료 코드는?
- `-pedantic-errors` 를 붙이면 어떻게 되는가?
- `void *` 가 오가는 두 줄이 조용한 이유는?

### 4. `%p` 에 캐스트를 빼면 (예측) ★★

```c
int    i = 42;
int   *ip = &i;
char   s[] = "hi";
void (*fp)(void) = 0;

printf("캐스트 함  : %p\n", (void *)ip);
printf("캐스트 안 함: %p\n", ip);
printf("char 배열  : %p\n", s);
printf("함수 포인터: %p\n", (void *)fp);
```

- `gcc -Wall -Wextra` 는 몇 건인가 — `-pedantic` 을 붙이면?
- **gcc 와 clang 이 잡는 줄이 같은가?**
- 네 줄의 실행 출력은 무엇인가 — 첫 줄과 둘째 줄이 다른가?
- ★ 그래서 이 함정이 안 보이는 이유는?

### 5. 포인터들의 `sizeof` (예측)

```c
printf("%zu %zu %zu %zu\n",
       sizeof(int), sizeof(int *), sizeof(int **), sizeof(char *));
```

- 네 수는 각각 얼마인가?
- 가리키는 타입이 바뀌면 포인터의 크기가 바뀌는가?
- 그러면 **가리키는 타입이 정하는 것**은 무엇인가?

### 6. 주소를 근거로 쓸 수 있나 (경계) ★★

- 같은 바이너리를 다섯 번 돌리면 `&x` 는 같은가 — 왜인가?
- 그러면 **무엇을 근거로 실어야** 하는가?
- 두 주소의 거리를 재는 **올바른 방법**은 — 왜 포인터 뺄셈이 아닌가?
- ★ 「차이가 다섯 번 다 같았다」는 **보장인가 관찰인가?**

### 7. 선언의 `*` 와 식의 `*` (왜) ★

- `int *p = &x;` 에서 `*` 는 몇 번 나오고 각각 무슨 일을 하는가?
- `&` 는 타입에 무엇을 하는가 — `&x` 와 `&p` 의 타입은?
- `**pp` 를 말로 풀면?

### 8. `void *` 의 자리 (경계)

- `void *` 가 **객체 포인터와 캐스트 없이 오가는** 이유는?
- 함수 포인터도 그런가 — 어느 플래그가 말해 주는가?
- `%p` 가 요구하는 타입이 `void *` 인 것과 무슨 관계인가?

### 9. 어느 도구가 무엇을 보나 (연결) ★★

- 네 프로그램 중 **어느 컴파일러 플래그로도 0건**인 것은 무엇인가?

- **`-pedantic` 에서만** 보이는 것은?

### 10. 다섯 층과 도구 (연결) ★★

- 이 주제에서 **표준 / 조건부 표준 / 구현 정의 / 미명시 / UB** 칸에 각각 무엇이 들어가는가?
