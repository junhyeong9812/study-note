# c/syntax/09 — 연산자 우선순위와 결합성: 무엇이 먼저 **묶이나** — 질문

> 복습은 항상 이 파일에서 시작한다. **맨기억으로 답을 시도**하고,
> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.
> 이 주제의 질문은 **예측형 위주**다 — 아는지가 아니라 **출력을 맞힐 수 있는지**를 묻는다.
> **환경** — gcc 13.3.0 · x86-64 Linux · 기본 `-std=c17 -Wall -Wextra -pedantic`.\
> `clang 18.1.3` 이 답을 바꾸는 문항은 **문항 안에 적었다.**
> ★ **이 주제에는 UB 가 없다.** 잘못 묶인 식도 **정의된 동작**이고 다만 뜻이 다를 뿐이다.\
> 그래서 sanitizer 가 할 일이 없고, **「어느 플래그가 몇 건을 말하나」를 세는 것**이 유일한 검사다.
> ★★ **이 주제는 「무엇이 먼저 묶이나」만 묻는다.** 「무엇이 먼저 도나」는 [10번 형제](../10-evaluation-order-and-sequence-points/)다.
> 선행 — [`01-declaration-syntax-and-reading/`](../01-declaration-syntax-and-reading/).

## 질문

### 1. 다섯 줄이 각각 무엇을 찍는가 (예측) ★★ 이 주제의 위험지대

```c
int a = 6, b = 2, c = 2;
printf("%d | %d\n", a & b == c, (a & b) == c);
printf("%d | %d\n", a << 1 + 2, (a << 1) + 2);
int x = 0, y = 2;
printf("%d | %d\n", !x & y, !(x & y));
int d = 6, e = 3, f = 1;
printf("%d | %d\n", d & e ^ f, d & (e ^ f));
int g = 1, h = 3, i = 1;
printf("%d | %d\n", g | h ^ i, (g | h) ^ i);
```

- 다섯 줄의 왼쪽 값은 각각 무엇인가?
- 다섯 줄 중 **왼쪽과 오른쪽이 같은 줄**이 하나라도 있는가?
- `&`·`^`·`|` 셋 사이의 힘 순서는 어떻게 되는가?
- 이 다섯 줄에 경고가 몇 건 나고, **어느 플래그**의 것인가?

### 2. `sizeof` 뒤에 연산을 이으면 (예측) ★

```c
int a = 10, b = 2;
printf("%zu | %zu\n", sizeof a + b, sizeof (a + b));
printf("%zu | %zu\n", sizeof a * 2, sizeof (a * 2));
```

- 네 값은 각각 무엇인가?
- 왼쪽 두 값이 그렇게 되는 규칙을 한 줄로 쓰면?
- `-Wall -Wextra -Wconversion -pedantic` 을 전부 켜면 몇 건인가?
- 이 자리가 1번과 **결정적으로 다른 점**은 무엇인가?

### 3. 포인터 증감 세 형태 (예측)

```c
int arr[4] = {10, 20, 30, 40};
int *p = arr, v;
v = *p++;    /* 여기서 v 와 p - arr 를 찍는다 */
p = arr;
v = (*p)++;  /* 여기서 v 와 arr[0] 과 p - arr 를 찍는다 */
arr[0] = 10; p = arr;
v = *++p;    /* 여기서 v 와 p - arr 를 찍는다 */
```

- 세 형태가 각각 무엇을 내고 `p - arr` 는 각각 몇인가?
- 셋을 괄호로 풀어 쓰면 각각 어떤 모양인가?
- `p->x++` 는 어느 것과 같은 집안인가?
- ★ **이 실험을 한 `printf` 안에서 재면 답이 어떻게 되는가?**

### 4. 결합성이 답을 바꾸는 자리 (예측)

```c
int a = 10, b = 2, c = 100;
int t = 0 ? 1 : 0 ? 2 : 3;
a = b = c;
int p = 10, q = 2, r = 3;
int z = (1, 2, 3);
int w = 5; w = 1, 2;
/* t · a · b · c · (p - q - r) · z · w 를 찍는다 */
```

- 일곱 값은 각각 무엇인가?
- **오른쪽 결합인 연산자**는 무엇무엇인가 — 전부 대면?
- `w` 가 그 값이 되는 이유는?
- `int z = 1, 2, 3;` 이라고 쓰면 무엇이 되는가?

### 5. 비교를 사슬로 쓰고 조건에서 대입하면 (예측)

```c
int a = 5, b = 3, c = 1, x = 0;
printf("%d | %d\n", a < b < c, (a < b) < c);
printf("%d | %d\n", a == b == 0, (a == b) == 0);
if (x = b) printf("여기가 실행되는가? x = %d\n", x);
printf("%d | %d\n", a + b << c, a + (b << c));
```

- 네 줄은 각각 무엇을 찍는가 — **`if` 는 실행되는가?**
- 첫 줄에 대해 gcc 가 하는 말은 무엇인가 — 문구를 그대로 쓰면?
- 경고는 몇 건이고 어느 플래그인가?
- 일부러 조건에서 대입하고 싶을 때 쓰는 관용구는?

### 6. 괄호가 캐스트인가 호출인가 (예측) ★

```c
typedef int T;
int f(int v) { return v * 10; }
int (*g)(int) = f;
double d = 3.9;
printf("%d\n", (T)(d));
printf("%d\n", (g)(4));
```

- 두 줄은 각각 무엇을 찍는가?
- `typedef int T;` 를 `int T = 7;` 로 바꾸면 무슨 일이 나는가 — 메시지는?
- 이것은 **우선순위로 풀리는 문제인가?**
- 그 메시지가 「파스가 바뀌었다」는 증거가 되는 이유는?

### 7. 비트 연산자의 자리 (왜)

- `&`·`^`·`|` 가 `==` 보다 **약한** 자리에 있는 탓에 실무에서 어떤 코드가 깨지는가?
- 그 형태를 올바로 쓰면 어떻게 되는가?
- 이 사고가 `&&`·`||` 에서는 왜 안 나는가?

### 8. `-Wparentheses` 의 소속과 한계 (경계)

- 이 플래그는 `-Wall` 인가 `-Wextra` 인가 — 어떻게 확인했는가?
- 이 문서의 여섯 함정 중 **몇 개를 잡고 몇 개를 못 잡는가?**
- 못 잡는 것은 무엇인가?
- 어떤 경고가 이 플래그의 것인지 **가르는 방법**은?

### 9. 경고를 세다가 0 을 받았을 때 (경계) ★★

- `gcc -Wall -Wprecedence ex.c | grep -c warning` 이 `0` 을 냈다. 무슨 뜻인가?
- 이것을 가르는 한 가지를 더 보면 되는데, 무엇인가?
- 이 사고가 「안 터졌다 ≠ 안전하다」와 **같은 집안인 이유**는?

### 10. 우선순위는 무엇을 정하지 않는가 (연결) ★★★ 이 묶음의 축

```c
static int f(void) { /* 호출 순서를 기록하고 1 을 반환 */ }
static int g(void) { /* 호출 순서를 기록하고 2 를 반환 */ }
static int h(void) { /* 호출 순서를 기록하고 3 을 반환 */ }
int v = f() + g() * h();
```

- `v` 는 무엇인가?
- 세 함수는 **어느 순서로 불렸는가** — 그리고 그것을 우선순위로 설명할 수 있는가?
- 「먼저 묶인다」와 「먼저 돈다」의 관계를 한 문장으로 쓰면?
- 이 질문의 정본은 어느 주제인가?
