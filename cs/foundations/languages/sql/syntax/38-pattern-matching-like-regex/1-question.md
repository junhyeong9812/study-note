# sql/38-패턴 매칭 (LIKE·ESCAPE·정규식) — 질문

> 복습은 항상 이 파일에서 시작한다. **맨기억으로 답을 시도**하고,\
> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.\
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.

대상은 **PostgreSQL 18.6** 과 **MySQL 8.4.10** 두 서버다. 「두 엔진에서」라고 물으면 **각각** 답한다.

★ **환경을 먼저 읽어라 — 이 주제의 답 절반이 여기서 나온다.**

```text
PG    데이터베이스 collate = en_US.utf8  (libc 제공자, 결정적)
MySQL 기본 collation      = utf8mb4_0900_ai_ci
```

인덱스 실험은 두 엔진에 같은 모양으로 만든 표 `t38` 을 쓴다.

```text
t38 (20,000행)
+-------+-----------+
| id    | code      |   code 는 varchar(20), 인덱스 있음
+-------+-----------+
|     1 | C000001   |
|   ... | ...       |
| 20000 | C020000   |
+-------+-----------+
```

## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 와일드카드 넷 (예측)

```sql
SELECT 'abc' LIKE 'a%' AS a, 'abc' LIKE '_b_' AS b,
       'abc' LIKE '%'  AS c, 'abc' LIKE 'A%'  AS d;
```

- 네 값이 두 엔진에서 각각 무엇인가?

### 2. ★ `%` 를 글자로 찾으려면 (예측)

```sql
SELECT '100%' LIKE '100%' AS a, '1000' LIKE '100%' AS b;
SELECT '100%' LIKE '100!%' ESCAPE '!' AS a, '1000' LIKE '100!%' ESCAPE '!' AS b;
```

- 네 값이 두 엔진에서 각각 무엇인가?

### 3. 정규식 연산자 (예측)

```sql
SELECT 'abc' ~ '^a' AS a;              -- (a)
SELECT 'abc' REGEXP '^a' AS a;         -- (b)
SELECT REGEXP_LIKE('abc','^A') AS a;   -- (c)
```

- 세 문이 두 엔진에서 각각 어떻게 되는가?

### 4. ★ 대소문자 무시 (예측)

```sql
SELECT 'abc' ILIKE 'A%' AS r;                                -- (a)
SELECT 'abc' LIKE 'A%' COLLATE utf8mb4_0900_as_cs AS r;      -- (b)
```

- 두 문이 두 엔진에서 각각 어떻게 되고, 각 엔진의 **기본값**은 어느 쪽인가?

### 5. ★ 어느 패턴이 인덱스를 타나 (예측)

```sql
EXPLAIN SELECT * FROM t38 WHERE code LIKE 'C00012%';   -- (a)
EXPLAIN SELECT * FROM t38 WHERE code LIKE '%00123';    -- (b)
```

- 두 질의의 계획이 두 엔진에서 각각 어떻게 나오는가?

### 6. `NULL` 이 걸리면 (경계)

- `NULL LIKE 'a%'` 는 참인가 거짓인가 — 그리고 `NOT LIKE` 로 뒤집으면 잡히는가?

### 7. 정규식으로 접두사를 찾으면 (경계)

- `code ~ '^C00012'`(PG) · `code REGEXP '^C00012'`(MySQL) 는 인덱스를 타는가?

### 8. PG 의 계획이 왜 예상과 달랐나 (왜)

- 앞이 고정된 `LIKE 'C00012%'` 인데 PG 가 기본 인덱스를 버린 이유는 무엇인가?

### 9. 역슬래시와 `ESCAPE` (경계)

- 역슬래시가 기본 이스케이프인데도 `ESCAPE` 를 명시하라고 하는 이유는 무엇인가?

### 10. 이식할 때 어디가 조용한가 (연결)

- 패턴 매칭에서 **에러 없이 답만 달라지는** 자리는 어디인가?

### 11. 검색 기능을 어떻게 만드나 (연결)

- 사용자 입력으로 부분 문자열 검색을 만들 때, `LIKE` 로 해결되는 부분과 안 되는 부분은 각각 무엇인가?
