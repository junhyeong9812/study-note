# ts/syntax/45 — 타입 수준 성능 — 질문

> 복습은 항상 이 파일에서 시작한다. **맨기억으로 답을 시도**하고,
> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 「틀림」으로 표시한다.
>
> 이 갈래는 **예측형**이다. ★★ **45 는 25 에서 온다** — [**25번 주제**](../25-infer-and-recursive-conditional-types/)가 7.0.2 의 `TS2589` 문턱을 쟀고 시간은 재지 않았다.
> 여기서는 **결정적 칸**(`Types`·`Instantiations`·문턱)과 **흔들리는 칸**(시간)을 갈라, 앞쪽에만 주장을 세운다.
> 실행 환경: `tsc` **7.0.2** · `node` **v18.19.1**. 판 비교에는 이 머신의 다른 프로젝트에 깔린 **`tsc` 5.9.3 · 4.9.5** 를 **읽기만** 해서 썼다(환경변수 `TSC_OLD`·`TSC_49`).
>
> ★ 탐침은 전부 생성기 `ts42b-gen45.sh` 가 찍는다 — 요약 파일 0절에 소스가 있다. 설정은 판 둘에 같은 `tsconfig.json`(`target`·`lib` es2022 · `types: []` · `strict` · `noEmit`).

## 질문

<!-- 형식: 질문 하나 = "?" 하나 = 한 줄.
     유형 태그: (예측) / (왜) / (경계) / (연결) -->

### 1. 크기 여덟 × 세 판 (예측)

- `count 999`·`count 1000`(꼬리 재귀로 길이를 셈) · `spread 48`·`spread 49`(겹마다 튜플 스프레드로 쌓음) · `union 316`·`union 317`(`${A}-${A}`) · `cube 46`·`cube 47`(`${A}${A}${A}`) 을 7.0.2 · 5.9.3 · 4.9.5 에 던지면 칸마다 무엇이 나는가? 판에 따라 문턱이 옮겨 가는가?

### 2. 같은 입력의 두 판 — 수 (예측)

- 빈 파일(`base 0`)을 7.0.2(기본) 와 5.9.3 에 `--extendedDiagnostics` 로 던지면 `Types`·`Instantiations` 는 같은가?
- 7.0.2 에 `--checkers 1` 을 붙이면? 입력을 키울 때(`count` 100 → 400 · `union` 100 → 300) 두 판의 `Instantiations` 증분은?

### 3. `--checkers` 값 넷 (예측)

- 빈 파일을 7.0.2 의 `--checkers 1` · `2` · `4` · `8` · `--singleThreaded` 로 던지면 `Types` 는 어떻게 움직이는가? `--generateTrace` 가 쓰는 파일은 몇 개이고 5.9.3 은?

### 4. 교차 대 인터페이스 — 수 (예측)

- `xsect 20,60`(기반 20개를 `&` 로 묶은 타입 60개를 서로 대입)과 `iface 20,60`(같은 것을 `interface … extends` 로)을 `--checkers 1` 로 던지면 `Types` 와 `Instantiations` 는 어느 쪽이 많은가?

### 5. 시간 격자 한 장 (예측)

- 입력 다섯(`base 0`·`union 150`·`union 300`·`xsect 20,60`·`iface 20,60`) × (7.0.2 · 7.0.2 `--singleThreaded` · 5.9.3) × 7판. 「5.9.3 의 최소가 7.0.2 두 설정의 최대보다 크다」는 입력 몇 개에서 참인가? 교차 대 인터페이스의 범위는 겹치는가?

### 6. 주장을 어느 칸에 세우나 (왜)

- 이 주제는 「7.0 이 몇 배 빠르다」를 말하지 않는다. 시간 블록에서 **결론으로 쓰는 줄**과 **쓰지 않는 줄**은 각각 무엇이고, 왜 그렇게 가르는가?

### 7. 알고리즘이 같다는 근거 (왜)

- 2번의 수로 「두 판의 타입 시스템이 같은 계산을 한다」고 말하려면 **무엇**을 봐야 하는가? `spread` 처럼 두 판의 값이 같지 않은 행이 있어도 그 말이 서는 까닭은?

### 8. 판 사이에 수를 댈 때 (경계)

- 7.0.2 와 5.9.3 의 `--extendedDiagnostics` 수를 나란히 놓을 때 7.0.2 쪽에서 맞춰 둬야 하는 것은 무엇인가? 안 맞추면 어떤 틀린 결론이 나오는가?

### 9. 폭의 벽이 세는 것 (경계)

- 1번의 `union` 두 칸과 `cube` 두 칸은 N 이 다르다. 두 꼴이 **같은 벽**에 닿는다고 말하려면 1번 격자의 어느 열을 봐야 하는가? `union` 이 커질 때 늘어나는 수는 `Types`·`Instantiations` 중 어느 쪽인가?

### 10. 25편과 잇기 (연결)

- 1번의 `count`·`spread` 문턱은 25편 몇 절의 어느 수와 같은가? 25편이 「느리다는 말이 한 줄도 없다」로 남긴 자리를 이 주제는 어떤 방식으로 채웠는가?
