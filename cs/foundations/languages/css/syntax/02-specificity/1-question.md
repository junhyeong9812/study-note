# css/syntax/02 — 명시도 계산: (ID, 클래스, 타입) 세 자리와 무엇이 어디에 기여하나 — 질문

> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.

## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 이 문단은 무슨 색인가 (예측)

```html
<p id="x" class="a b c">ID 하나 대 클래스 셋</p>
<style>
  .a.b.c { color: green; }
  #x     { color: red; }
</style>
```

- 이 문단은 무슨 색인가?
- `.a.b.c` 가 더 나중에 쓰였는데 왜 순서가 안 통하는가?
- 클래스를 열 개로 늘리면 결과가 바뀌는가?
- `#x` 를 `[id="x"]` 로 바꾸면 무슨 색이 되는가, 그 이유는?

### 2. 세 자리를 한 수로 더해도 되는가 (왜)

- `(0, 3, 0)` 과 `(1, 0, 0)` 중 어느 쪽이 센가?
- 흔히 쓰이는 "ID=100, 클래스=10, 타입=1" 모델은 어디서 깨지는가?
- 그 모델이 오래 살아남은 이유는 무엇인가?
- 두 선택자를 비교할 때 실제로 어느 자리부터 보는가?

### 3. 두 규칙 중 어느 쪽이 이기는가 (예측)

```html
<div id="box"><p class="t">이 줄</p></div>
<style>
  :is(#box) .t    { color: red; }
  :where(#box) .t { color: green; }
</style>
```

- 두 선택자의 `(A, B, C)` 를 각각 계산할 수 있는가?
- 이 문단은 무슨 색인가?
- `:is(#box)` 를 `:where(#box)` 로 바꾸면 무슨 색이 되는가?
- `:where()` 는 매칭도 안 하는가, 세기만 0 인가?

### 4. 문서에 없는 ID 가 승부를 가른다 (예측)

```html
<p class="t">이 줄</p>
<style>
  .t.t.t            { color: green; }
  p:not(.zz, #nope) { color: red; }
</style>
```

- `p:not(.zz, #nope)` 의 `(A, B, C)` 는 얼마인가?
- 문서에 `#nope` 라는 요소가 없는데도 A 자리가 올라가는 이유는 무엇인가?
- 이 문단은 무슨 색인가?
- `#nope` 를 `.nope` 로 바꾸면 무슨 색이 되는가?

### 5. 이 규칙의 명시도는 얼마인가 (경계)

```css
h1, #x { color: red; }
```

- `h1` 요소에 걸릴 때 이 규칙의 명시도는 얼마인가?
- `#x` 요소에 걸릴 때는 얼마인가?
- "규칙 하나의 명시도"라는 말이 왜 성립하지 않는가?
- 조합자(`>` `+` `~` 공백)는 어느 자리에 얼마를 보태는가?

### 6. 다섯 개를 손으로 세어 보라 (예측)

```css
p::before
p:nth-child(1 of .c1)
:is(p, #t1)
p:has(+ p#t2)
section:is(div section) p
```

- 다섯 선택자의 `(A, B, C)` 를 각각 계산할 수 있는가?
- 의사 요소(`::before`)와 의사 클래스(`:nth-child`)는 서로 다른 자리에 들어가는가?
- `of S` 형태가 명시도에 더하는 것은 무엇인가?
- `p.c1.c1.c1` 처럼 같은 클래스를 반복하면 B 자리는 1인가 3인가?

### 7. 명시도를 올려도 안 먹는다 (경계)

- 선택자를 길게 늘였는데 여전히 안 먹을 때, 명시도보다 **위**에 있는 단계 셋은 무엇인가?
- 명시도는 캐스케이드 정렬의 몇 번째 단계인가?
- `style=""` 는 명시도가 얼마인가?
- `!important` 는 `(A, B, C)` 중 어느 자리를 올리는가?

### 8. 다른 주제와 잇기 (연결)

- 라이브러리가 "덮기 쉬운 기본값"을 주고 싶다면 어떤 문법을 쓰는가?
- `@layer` 와 `:where()` 는 각각 캐스케이드의 어느 단계를 건드리는가?
- 중첩(nesting)에서 `& .x` 가 명시도를 조용히 올릴 수 있는 이유는 무엇인가?
- 명시도가 동점이면 승부는 무엇으로 갈리고, 그것에 의존하는 CSS 는 무엇에 취약해지는가?
