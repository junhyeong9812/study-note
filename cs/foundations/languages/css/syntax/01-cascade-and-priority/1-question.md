### 1. 이 문단은 무슨 색인가 (예측)

```html
<p class="note" id="lead">이 줄은 무슨 색으로 나올까?</p>
<style>
  p     { color: green; }
  #lead { color: blue; }
  .note { color: red !important; }
</style>
```

- 이 문단의 `color` 는 무엇이 되는가?
- `#lead` 가 명시도로는 가장 높은데 왜 지는가?
- `.note` 의 `!important` 를 떼면 무슨 색이 되는가?
- `p` 선언에도 `!important` 를 붙이면 무슨 색이 되는가?

### 2. `!important` 는 명시도를 얼마나 올리는가 (왜)

- `!important` 는 `(A, B, C)` 세 자리 중 어느 자리를 얼마나 올리는가?
- 그 답이 이 주제에서 가장 자주 틀리는 자리인 이유는 무엇인가?
- 출처·중요도 사다리에서 작성자의 `!important` 보다 **위에 있는 칸**은 무엇인가?
- 사다리의 `!important` 구간에서 작성자와 사용자의 순서가 뒤집혀 있는 이유는 무엇인가?

### 3. "우선순위"는 여섯 단계 중 어디인가 (경계)

- 캐스케이드 정렬의 여섯 단계를 순서대로 말할 수 있는가?
- 흔히 "CSS 우선순위"라 부르는 명시도는 그중 몇 번째인가?
- 1단계에서 승자가 하나로 갈리면 5단계에서는 무슨 일이 일어나는가?
- "선택자를 더 길게 썼는데 안 먹는다"를 진단할 때 어느 단계부터 확인해야 하는가?

### 4. 두 줄의 색을 각각 예측하라 (예측)

```html
<p class="a">첫째 줄</p>
<p class="b">둘째 줄</p>
<style>
  @layer base, theme;
  @layer base  { .a { color: red; } .b { color: red !important; } }
  @layer theme { .a { color: green; } .b { color: green !important; } }
</style>
```

- 첫째 줄과 둘째 줄은 각각 무슨 색인가?
- 두 규칙 집합은 대칭인데 결과가 갈리는 이유는 무엇인가?
- 맨 위 `@layer base, theme;` 를 `@layer theme, base;` 로 바꾸면 무엇이 달라지는가?
- 이 동작 때문에 `@layer` 안에서 `!important` 를 쓸 때 조심해야 할 것은 무엇인가?

### 5. 이 인라인 스타일을 시트로 덮을 수 있는가 (경계)

```html
<p id="p1" style="color: blue">덮을 수 있을까?</p>
<style>
  #p1#p1#p1 { color: red; }
</style>
```

- 이 문단은 무슨 색인가?
- 선택자를 `#p1#p1#p1#p1#p1` 로 더 늘리면 달라지는가, 그 이유는?
- 시트에서 이것을 덮을 수 있는 수단은 무엇 하나뿐인가?
- JS 가 인라인 스타일을 찍는 코드베이스에서 이 규칙이 만드는 장기 비용은 무엇인가?

### 6. 레이어 밖에 남은 규칙 (예측)

```html
<p class="x">어느 쪽이 이길까?</p>
<style>
  @layer theme { #app .x { color: green; } }
  .x { color: red; }
</style>
```

- 이 문단은 무슨 색인가? (`#app` 조상이 있다고 가정한다)
- 레이어 안의 `#app .x` 가 레이어 밖의 `.x` 에 지는 이유는 무엇인가?
- 양쪽 선언에 `!important` 를 붙이면 승자가 어떻게 바뀌는가?
- 기존 시트에 `@layer` 를 도입할 때 가장 먼저 확인해야 할 것은 무엇인가?

### 7. 이 배경은 어떻게 그려지는가 (예측)

```css
/* 같은 요소에 .theme .card 둘 다 걸려 있다 */
.theme { background-color: navy; }
.card  { background: url(a.png) no-repeat; }
```

- 이 요소의 `background-image` 와 `background-color` 는 각각 무엇이 되는가?
- 두 선언의 순서를 뒤집으면 둘 중 무엇이 달라지는가?
- 이 현상이 "캐스케이드는 규칙 단위가 아니라 속성 단위"와 어떻게 이어지는가?
- 순서에 기대지 않고 이미지와 색을 둘 다 지키려면 무엇을 고쳐야 하는가?

### 8. 다른 주제와 잇기 (연결)

- 부모에게 `color: red`, 자식에게 `color: inherit` 이 아닌 아무 약한 선언이 걸리면 자식은 무슨 색인가?
- 상속이 캐스케이드의 몇 단계에서 일어나는지, 아니면 캐스케이드 밖인지 말할 수 있는가?
- `:where()` 로 감싼 선택자가 이 문서의 어느 단계를 무력화하는가?
- 전환(`transition`)이 도는 동안의 값이 `!important` 에도 안 덮이는 이유를 사다리로 설명할 수 있는가?
