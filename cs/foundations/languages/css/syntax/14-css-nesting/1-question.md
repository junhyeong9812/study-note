## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 이 글자는 무슨 색인가 (예측)

```html
<b class="foo"><c>Blue text</c></b>
<style>
  #a, b { & c { color: blue; } }
  .foo c { color: red; }
</style>
```

- 글자는 무슨 색인가?
- 문서에 `#a` 라는 요소가 없는데도 결과에 영향을 주는가?
- 같은 중첩을 손으로 펼쳐 `#a c, b c { color: blue; }` 로 쓰면 무슨 색이 되는가?
- 두 판이 갈리는 이유를 한 문장으로 설명할 수 있는가?

### 2. `&` 는 무엇으로 치환되는가 (왜)

- `.a, #b` 아래의 `&` 는 무엇을 뜻하는가 — 문자열인가 선택자 목록인가?
- `&` 의 명시도를 정하는 규칙은 무엇과 같은 조항인가?
- 부모 규칙이 아예 없는 최상위에서 `&` 를 쓰면 명시도가 얼마인가?
- 전처리기(Sass)의 `&` 와 CSS 중첩의 `&` 는 같은 것인가?

### 3. 네 줄의 명시도를 세어 보라 (예측)

```css
.a, #b { & .c { } }
.a .c  { }
.a, #b { && { } }
.a, #b { & .c { & .d { } } }
```

- 네 줄의 `(A, B, C)` 를 각각 계산할 수 있는가?
- 첫째와 둘째가 겨루면 어느 쪽이 이기는가?
- `&&` 는 무엇과 같은가?
- 중첩을 한 겹 더 쌓았을 때 앞 단의 ID 는 계속 따라오는가?

### 4. `&` 를 빼면 무엇이 되는가 (예측)

```css
.card { .title  { } }
.card { > .body { } }
.card { div     { } }
.card { .x &    { } }
```

- 네 줄의 `selectorText` 는 각각 무엇으로 나오는가?
- `&` 를 생략한 것과 앞에 쓴 것의 명시도는 같은가?
- 네 번째 줄은 무엇을 가리키는가?
- 조합자로 시작하는 중첩 규칙의 명시도에 암묵의 `&` 가 포함되는가?

### 5. 공백 하나가 가르는 것 (경계)

```css
.card { &.active { } }
.card { & .active { } }
```

- 두 줄은 각각 무엇을 고르는가?
- 둘 다 유효한가?
- 실수했을 때 브라우저가 알려 주는가?
- 명시도는 같은가?

### 6. 이 셋 중 살아남는 것은 (예측)

```css
.a { &div     { } }
.a { &-suffix { } }
.a { &.b      { } }
```

- 안쪽 규칙이 `cssRules` 에 담기는 것은 몇 줄인가?
- 무효한 중첩 규칙이 있을 때 바깥 `.a` 규칙은 어떻게 되는가?
- `&div` 가 무효인 것은 처음부터 그랬는가?
- BEM 의 `&__title` 을 CSS 중첩으로 그대로 옮길 수 있는가?

### 7. 어느 선언이 이기는가 (예측)

```css
.a { color: rgb(1,1,1); & { color: rgb(2,2,2); } color: rgb(3,3,3); }
.b { color: rgb(1,1,1); & { color: rgb(2,2,2); } }
.c { @media (min-width: 1px) { color: rgb(2,2,2); } color: rgb(3,3,3); }
```

- 세 요소의 계산된 `color` 는 각각 무엇인가?
- 중첩 규칙 **뒤**에 쓴 선언은 `cssRules` 에서 어떤 규칙으로 나타나는가?
- `&` 규칙과 부모의 선언이 동점일 때 무엇으로 승부가 나는가?
- 명세는 이 순서에 대해 무슨 주의를 붙여 놓았는가?

### 8. `@media` 를 중첩하면 (경계)

- 중첩된 `@media` 안의 선언들은 `cssRules` 에서 어떻게 담기는가?
- `@media` 를 중첩해도 명시도가 바뀌는가?
- `@media` 블록의 위치는 선언 순서에 영향을 주는가?
- 레이어(`@layer`)와 중첩은 명시도에 대해 각각 무엇을 하는가?

### 9. 세기를 안 올리고 중첩하려면 (예측)

```css
.a, #b { & .c { } }
:where(.a, #b) { .c { } }
.a, #b { :where(&) .c { } }
```

- 세 줄의 `(A, B, C)` 는 각각 얼마인가?
- 뒤 두 줄이 같은 값을 내는 이유는 무엇인가?
- 부모 목록에 레거시 ID 가 하나 섞였을 때 무엇부터 하는가?
- `:where()` 는 매칭도 없애는가, 세기만 없애는가?

### 10. 최상위의 `&` (경계)

- 최상위(어느 규칙에도 중첩되지 않은 자리)에 `& p { }` 라고 쓰면 규칙이 담기는가?
- 그것은 무엇을 고르는가?
- `:scope p` 와 고르는 것이 같은가, 명시도가 같은가?
- 명세는 부모 목록이 없을 때의 `&` 를 뭐라고 정하는가?

### 11. 다른 주제와 잇기 (연결)

- `&` 의 명시도 규칙과 `:has()` 의 명시도 규칙은 어떤 관계인가?
- 중첩 안에서 `&::before` 를 쓸 때 의사 요소 규칙은 어떻게 적용되는가?
- 중첩 깊이를 얕게 유지하라는 조언의 근거를 명시도로 설명할 수 있는가?
- Baseline 날짜만 보고 「내가 쓰는 중첩 문법이 그 버전에서 돈다」고 판단해도 되는가?
