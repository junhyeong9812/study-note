## 질문

### 1. `100vw` 와 `100%` 가 갈린다 (예측)

```css
body { margin: 0; }
.vw   { width: 100vw; height: 40px; }
.pc   { width: 100%;  height: 40px; }
.tall { height: 2000px; }   /* 세로 스크롤이 생긴다 */
```

- 창 폭이 800px 일 때 두 상자의 실제 폭은 각각 몇 px 인가?
- 그 차이가 문서에 무엇을 만드는가?
- `.tall` 을 지우면 무엇이 달라지는가?

### 2. 창 크기를 세 번 바꿔 잰다 (예측)

```css
.a { width: 10vw; }  .b { height: 10vh; }
.c { width: 10vmin; } .d { width: 10vmax; }
```

- 창이 `1200 × 313` 일 때 네 값 중 **가장 큰 것과 가장 작은 것**은 각각 무엇인가?
- `vmin` 과 `vmax` 가 고르는 축은 무엇으로 정해지는가?
- `vi`/`vb` 는 `vw`/`vh` 와 언제 같고 언제 다른가?

### 3. `svh`·`lvh`·`dvh` 셋 (왜)

- 셋이 각각 무엇을 재는지 한 줄씩 말할 수 있는가?
- `100vh` 는 셋 중 어느 것과 같게 정의돼 있는가?
- 셋의 값이 **갈리는 환경**은 어디이고, headless 에서는 왜 안 갈리는가?
- 셋을 고를 때 각각 무엇을 대가로 받는가?

### 4. 컨테이너 단위를 등록 없이 쓴다 (예측)

```css
.card { width: 300px; height: 150px; }   /* container-type 선언 없음 */
.card .t { width: 50cqw; }
```

- `.t` 의 폭은 몇 px 인가? 창이 800×513 이라고 하자.
- 이때 에러나 경고가 나오는가?
- 이 증상은 「진단 3창」 중 어느 창으로 잡히는가?

### 5. `container-type: inline-size` 의 경계 (예측)

```css
.card { width: 300px; height: 150px; container-type: inline-size; }
.card .w { width: 50cqw; }
.card .b { height: 50cqb; }
```

- 두 값은 각각 몇 px 인가? 창이 800×513 이라고 하자.
- 둘 중 하나가 카드를 안 보는 이유는 무엇인가?
- 두 축을 다 쓰려면 무엇을 바꿔야 하고, 그 대가는 목록의 몇 번 주제가 정본인가?

### 6. `cqmin` 이 축을 섞는다 (경계)

- `container-type: inline-size` 인 300×150 카드 안에서 `50cqmin` 과 `50cqmax` 는 각각 무엇을 기준으로 삼는가?
- `container-type: size` 로 올리면 두 값이 어떻게 달라지는가?

### 7. 기준을 찾아 올라가는 경로 (왜)

- `%`·`cqi`·`vw` 는 기준을 찾을 때 각각 조상을 몇 칸 올라가는가?
- 같은 카드 컴포넌트를 본문과 사이드바에 넣었을 때, 글자 크기가 **안 줄어드는** 쪽은 어느 단위로 짠 것인가?

### 8. 모바일에서 화면이 잘린다 (연결)

- `height: 100vh` 짜리 전체 화면이 모바일에서 아래가 잘리는 이유는 무엇인가?
- 그것을 `dvh` 로 바꾸면 무엇을 얻고 무엇을 잃는가?
- `svh` 로 바꾸면?

### 9. 이 환경에서 못 잰 것 (경계)

- 이 문서가 **재지 못했다**고 밝힌 것은 무엇인가? 그 이유는?
- 스크롤바 폭 15px 은 보장인가 관찰인가?
- `--window-size=375,667` 로 잰 판을 그대로 「375px 판」이라 부를 수 없는 이유는?

### 10. 다른 주제로 잇기 (연결)

- `@container` 질의와 `container-type` 의 대가는 목록의 몇 번 주제인가?
- 창 크기로 **규칙을 갈라 쓰는** 문법은 몇 번 주제인가?
- 뷰포트 단위를 상하한으로 묶어 유동 타이포를 만드는 함수는 몇 번 주제인가?
- `vi`/`vb` 의 축이 뒤집히는 규칙의 정본은 몇 번 주제인가?
