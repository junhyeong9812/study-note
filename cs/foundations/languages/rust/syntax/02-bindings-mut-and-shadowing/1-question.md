## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 이 네 줄은 컴파일되는가 (예측)

```rust
let x = 5;
println!("x = {x}");
x = 6;
println!("x = {x}");
```

- 컴파일되는가? 안 된다면 **에러 번호**는 무엇인가?
- 에러 문구의 핵심 낱말은 「cannot assign …」 뒤에 무엇인가 — 그 낱말이 규칙의 정확한 모양을 말한다?
- 컴파일러가 `help:` 로 제안하는 수정은 무엇인가?
- `rustc --explain` 이 드는 해법은 **두 가지**다. `mut` 말고 다른 하나는 무엇인가?

### 2. `mut` 가 없는데 대입이 있다 (예측)

```rust
let x: i32;
x = 5;
println!("x = {x}");

let label: &str;
if x > 3 { label = "큼"; } else { label = "작음"; }
println!("label = {label}");
```

- 이 프로그램은 컴파일되는가?
- 된다면 「불변」이라는 말을 어떻게 다시 읽어야 하는가?
- 여기에 `x = 6;` 한 줄을 더하면 무슨 에러가 나는가 — 그리고 **경고**가 하나 더 붙는데 무엇인가?
- `x = 5;` 를 지우고 `println!` 만 남기면 무슨 에러가 나는가?

### 3. 이 다섯 줄의 출력을 예측하라 (예측)

```rust
let x = 5;
println!("1) x = {x:?} / 크기 {}", std::mem::size_of_val(&x));
let x = "다섯";
println!("2) x = {x:?} / 크기 {}", std::mem::size_of_val(&x));
let x = x.len();
println!("3) x = {x:?} / 크기 {}", std::mem::size_of_val(&x));
```

- 세 줄의 값과 **크기**는 각각 무엇인가?
- 크기가 바뀌었다는 사실이 무엇을 증명하는가?
- 3번 줄의 값이 5가 아니라면 왜 그런가?
- 같은 일을 `let mut x = 5;` 로 하려면 무엇이 막히는가?

### 4. 블록 안에서 가린 것 (예측)

```rust
let x = 5;
{
    let x = 99;
    println!("안: {x}");
}
println!("밖: {x}");
```

- 두 줄의 출력은 각각 무엇인가?
- 「블록 안에서 바꿨는데 왜 밖에서 안 바뀌지?」라는 물음에 한 문장으로 답할 수 있는가?
- 진짜로 바깥 값을 바꾸려면 무엇을 어떻게 고치는가?
- 섀도잉이 「값 변경」과 다른 점을 **스코프**라는 낱말을 써서 말할 수 있는가?

### 5. `mut` 로 타입을 바꾸면 (예측)

```rust
let mut x = 5;
x = "다섯";
```

- 컴파일되는가? 안 된다면 **에러 번호**와 「expected … found …」 부분은 무엇인가?
- 에러가 가리키는 「expected due to this value」는 소스의 어디인가?
- 나는 타입을 한 글자도 안 적었는데 왜 타입이 정해져 있는가?
- `mut` 가 푸는 것과 못 푸는 것을 한 줄씩으로 가를 수 있는가?

### 6. 이 두 줄은 컴파일되는가 (예측)

```rust
let v = Vec::new();
println!("{:?}", v);
```

- 컴파일되는가? 안 된다면 **에러 번호**는?
- `println!("{:?}", v)` 는 왜 타입 힌트가 못 되는가?
- 고치는 방법을 **세 가지** 들 수 있는가?
- 다음 줄에 `v.push(7u8);` 를 넣으면(그리고 `v` 를 `mut` 로 바꾸면) 어떻게 되는가 — 그 이유는?

### 7. 이 프로그램이 내는 경고를 전부 대라 (경계)

```rust
let unused = 1;
let _unused = 2;
let mut never_changed = 3;
println!("never_changed = {never_changed}");
let myValue = 4;
println!("myValue = {myValue}");
```

- 경고는 **몇 개**이고 각각의 **린트 이름**은 무엇인가?
- `_unused` 에는 왜 경고가 안 붙는가?
- 이 프로그램은 실행되는가?
- 첫 줄에 `#![deny(unused_variables)]` 를 붙이면 무엇이 달라지며, 그때 메시지에 `E0xxx` 번호가 붙는가?

### 8. 타입을 안 적으면 무엇이 되는가 (왜)

- `let n = 3;` 의 `n` 은 무슨 타입인가 — 그리고 그것이 **언어 규칙**임을 어떻게 증명하겠는가?
- `let f = 3.0;` 은?
- `let big = 3u64; let m = 3; big + m;` 에서 `m` 은 무슨 타입이 되는가, 왜인가?
- 추론은 「그 줄」만 보는가, 아니면 더 넓게 보는가?

### 9. `const` 와 `let` 의 경계 (경계)

- `const LIMIT = 100;` 은 컴파일되는가? 안 된다면 무엇이 빠진 것인가?
- 함수 **밖**에 `let x = 1;` 을 쓰면 컴파일러가 무엇을 쓰라고 하는가?
- `const` 와 `let` 을 가르는 축을 두 가지만 댈 수 있는가?
- 이 주제에서 `const` 를 깊이 안 다루는 이유는 무엇이며, 정본은 몇 번 주제인가?

### 10. 다른 주제와 잇기 (연결)

- 섀도잉으로 가려진 **옛 값**은 언제 해제되는가 — 이 질문의 정본은 몇 번 주제인가?
- `let _ = f();` 와 `let _x = f();` 는 무엇이 다른가?
- 이 문서의 예제를 돌릴 때 `rustc` 에 반드시 붙여야 하는 플래그는 무엇이며 그 근거는 몇 번 주제인가?
- `let x = { ... };` 의 오른쪽이 **값**인 이유를 다루는 주제는 몇 번인가?
