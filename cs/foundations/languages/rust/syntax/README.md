## 이 언어에서 무엇을 자르는 축

Rust의 문법 주제는 **컴파일러가 거부하는 자리를 중심으로** 잘린다.
다른 언어에서 "쓸 줄 안다"는 문법을 아는 것이지만, Rust에서는 **거부당했을 때 무엇을 고쳐야 하는지 아는 것**이다.
그래서 이 목록은 네 층으로 자른다.

1. **소유권 층** — 이동·복사·빌림·수명. 여기가 막히면 아래 어떤 층도 안 쓰인다(8~15).
2. **타입으로 말하는 층** — 열거형·`match`·`Option`/`Result`. Rust에서 "없음"과 "실패"는 제어 흐름이 아니라 **값**이다(16~24).
3. **추상화 층** — 트레이트·제네릭·클로저·이터레이터. 정적 디스패치와 동적 디스패치를 고르는 감각(25~37).
4. **공유와 동시성 층** — 스마트 포인터·내부 가변성·스레드·`async`. 1층의 규칙을 **런타임 비용을 내고 완화하는** 방법들이다(38~55).

옆 축인 [`../언어-특성/README.md`](../언어-특성/README.md)는 *Rust를 고를 것인가*를 다룬다.
소유권 **모델 자체의 논증**(왜 별칭과 변경을 동시에 안 주나, `Send`/`Sync`가 왜 데이터 레이스를 타입 오류로 만드나, 청구서가 왜 사람의 시간인가)은 **거기**고,
여기는 **그래서 `&`·`&mut`·`'a`를 코드에 어떻게 쓰는가**다.

## 버전 기준

- **기준 에디션은 2021.** 본문은 2021로 쓰고, **2024 에디션에서 달라지는 것은 그 주제 안에 별도 표기**한다.
- 이 머신의 툴체인은 `rustc 1.92.0`(2025-12-08 빌드)이다. 실행 결과는 이 버전 기준으로 기록한다.
- 이 목록이 이미 고정한 버전·에디션 사실:

| 사실 | 버전·에디션 | 주제 |
|---|---|---|
| `let ... else` | 1.65부터 (에디션 무관) | 20 |
| **2024 에디션 안정화** | 1.85.0 (2025-02-20) | 47 |
| **`let` 체인 (`if let` / `while let` 의 `&&` 연쇄)** | 1.88부터, **2024 에디션에서만** | 20 |
| 반환 위치 `impl Trait`의 수명 포착 규칙 변경 | 2024 에디션 | 32 |
| `if let` 임시값 스코프 변경 (드롭 시점) | 2024 에디션 | 20·44 |

- 2024 에디션의 나머지 변경(`unsafe` 관련 규칙, 예약 키워드, prelude 추가 등)은 **47번 주제를 쓸 때 [Edition Guide](https://doc.rust-lang.org/edition-guide/rust-2024/)를 직접 열어 전수 확인**한 뒤 적는다. 이 목록에는 확인한 것만 올렸다.
- 버전 의존 API(`OnceLock`·`LazyLock`·스코프 스레드 등)는 3파일 작성 시 std 문서의 "Stable since" 표기를 확인해 적는다.
