### 1. ★ 두 참조 중 하나를 돌려주는 함수 (예측)

```rust
fn longest(x: &str, y: &str) -> &str {
    if x.len() >= y.len() { x } else { y }
}

fn main() {
    println!("{}", longest("가나다", "라"));
}
```

- 컴파일되는가? 안 되면 에러 번호와 제목 줄은 무엇인가?
- `^` 표시는 **어느 자리**에 붙는가?
- `help:` 가 대는 이유 한 구절은 무엇인가 — 컴파일러가 못 알아낸 것이 정확히 무엇인가?
- 컴파일러는 이 함수의 **몸통**을 읽고 판정하는가?

### 2. ★★ 생략형이 무엇으로 풀렸는지 컴파일러에게 묻기 (예측)

```rust
fn first_word(s: &str) -> &str {
    s.split(' ').next().unwrap()
}

fn main() {
    let f: fn(&str) -> &'static str = first_word;
    println!("{}", f("hello rust"));
}
```

- 이 코드를 컴파일하면 무엇이 나오는가?
- 진단의 `= note:` 두 줄은 각각 무엇을 말하는가?
- 그 줄에서 `first_word` 의 **실제 타입**을 읽어 적을 수 있는가?
- `&'static str` 대신 무엇으로 적으면 통과하는가?

### 3. ★ `&self` 가 있는 메서드에서 두 번째 인자를 돌려주면 (예측)

```rust
struct Parser { text: String }

impl Parser {
    fn head(&self, sep: &str) -> &str {
        let _ = &self.text;
        sep
    }
}

fn main() {
    let p = Parser { text: String::from("a,b,c") };
    println!("{}", p.head(","));
}
```

- 컴파일되는가? 된다면 왜, 안 되면 에러는 무엇인가?
- 이 진단의 **에러 번호**는 무엇인가?
- `'1`·`'2` 라는 이름은 어디서 온 것인가 — 내가 쓴 적이 없는데?
- 첫 인자를 `this: &Parser` 로 바꾸면 무엇이 달라지는가?

### 4. ★★ 같은 `String` 을 두 자리에 던지면 (예측)

```rust
fn needs_static_ref(s: &'static str) { println!("참조: {}", s); }
fn needs_static_bound<T: 'static>(_t: T) { println!("경계: 통과"); }

fn main() {
    let owned = String::from("소유한 문자열");

    needs_static_ref(&owned);
    needs_static_bound(owned);
}
```

- 두 호출 중 거부되는 것은 어느 쪽인가 — 둘 다인가, 하나인가?
- 나오는 에러 번호를 전부 대라. 그중 **덤으로 따라온 것**은 어느 것이고 왜 생겼는가?
- `needs_static_ref(&owned)` 줄만 지우면 남은 코드는 통과하는가?
- `'static` 이라는 같은 글자가 두 자리에서 **각각 무슨 뜻**인가?

### 5. ★ `'a` 를 붙였는데 스코프가 다르면 (예측)

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() >= y.len() { x } else { y }
}

fn main() {
    let long = String::from("가나다라마");
    let winner;
    {
        let short = String::from("가나");
        winner = longest(&long, &short);
    }
    println!("{}", winner);
}
```

- 이 프로그램을 실행하면 무엇이 나올 **예정**이었는가? 그리고 실제로 컴파일되는가?
- 에러가 짚는 변수는 `long` 인가 `short` 인가?
- 두 입력에 **같은 이름 `'a`** 를 준 것이 무슨 뜻이었는지 한 문장으로 적을 수 있는가?
- `<'a, 'b>` 로 갈라 적으면 이 코드가 통과하는가?

### 6. ★★ 한 갈래에서만 빌림이 나가는 함수 (예측)

```rust
use std::collections::HashMap;

fn get_or_insert(map: &mut HashMap<u32, String>) -> &String {
    match map.get(&0) {
        Some(v) => v,
        None => {
            map.insert(0, String::from("기본값"));
            map.get(&0).unwrap()
        }
    }
}
```

- `None` 갈래에서는 `map.get(&0)` 의 결과를 쓰지 않는데도 막히는가?
- 에러 번호와, 진단에 나오는 `'1` 이 무엇인지 말할 수 있는가?
- 「사람 눈에 안전한데 거부됐다」와 「언어가 금지했다」는 어떻게 다른가?
- 코드를 어떻게 바꾸면 통과하며, 그 대가는 무엇인가?
