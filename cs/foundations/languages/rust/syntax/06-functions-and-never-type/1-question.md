## 질문

### 1. 함수 넷의 반환값과 크기 (예측)

```rust
fn add(a: i32, b: i32) -> i32 { a + b }
fn greet(name: &str) { println!("안녕 {name}"); }
fn unit_explicit() -> () {}
fn early(a: i32) -> i32 {
    if a < 0 { return 0; }
    a * 2
}
```

- `add(2, 3)` 과 `early(-1)`·`early(5)` 는 각각 무엇을 돌려주는가?
- `greet` 와 `unit_explicit` 의 반환 타입은 각각 무엇인가 — 둘은 같은 것인가?
- `let u = unit_explicit();` 했을 때 `u` 의 값과 **크기**는?
- 인자의 타입은 생략할 수 있는가, 반환 타입은?

### 2. ★ 마지막 줄을 건드린 함수 둘 (예측)

```rust
fn twice(a: i32) -> i32 {
    a * 2;
}

fn half(a: i32) -> i32 {
    if a < 0 { return 0; }
}
```

- 둘 다 컴파일되는가? 안 된다면 **각각의 에러 번호**는 무엇인가?
- 두 번호가 같은가 다른가 — 다르다면 무엇이 그 둘을 갈랐는가?
- 각 에러의 `help:` 가 가리키는 **고칠 곳**은 어디인가?
- `implicitly returns …` 로 시작하는 줄은 무엇을 말하는가?

### 3. ★ 기대 타입이 `i32` 인 자리에 `panic!` (예측)

```rust
fn main() {
    println!("시작");
    let x: i32 = panic!("여기서 끝");
    println!("{x}");
}
```

- 이 프로그램은 컴파일되는가 — 에러인가, 경고인가, 아무것도 없나?
- 무엇이 출력되고 **종료 코드**는 얼마인가?
- 경고가 난다면 **린트 이름**은 무엇이고 몇 개가 붙는가?
- `x` 에는 무엇이 들어가는가?

### 4. ★ 네 자리에 넣은 세 가지 (예측)

```rust
let flag = std::env::args().count() > 99;   // 항상 거짓

let a: i32    = if flag { panic!() } else { 1 };
let b: String = if flag { panic!() } else { String::from("문자열") };
let c: Vec<u8>= if flag { std::process::exit(3) } else { vec![7] };
let d: bool   = if flag { loop {} } else { true };
```

- 네 줄 중 컴파일되는 것은 몇 개인가?
- `if` 두 갈래의 타입이 같아야 한다는 규칙([**04번 주제**](../04-expressions-and-semicolons/))을 이건 어떻게 통과하는가?
- `panic!()`·`process::exit(3)`·`loop {}` 세 식의 **공통 타입**은 무엇인가?
- 그 타입이 들어갈 수 **없는** 타입 자리가 있는가?

### 5. `match` 한 갈래만 다른 것 (예측)

```rust
let n = 1;
let _: () = match n {
    1 => "하나",
    _ => panic!("없음"),
};

let both_never: i32 = match n {
    1 => panic!("a"),
    _ => std::process::exit(1),
};
println!("{both_never}");
```

- 위쪽 `match` 전체의 타입은 무엇인가 — 컴파일러는 어떤 에러로 그걸 알려 주는가?
- 아래쪽은 컴파일되는가? 된다면 `both_never` 의 타입 자리에 `String` 을 적어도 되는가?
- 아래쪽에 붙는 경고의 `note` 한 줄(`as all arms …`)은 무엇을 말하는가?
- `match` 팔들에 요구되는 규칙과 이 결과는 어떻게 어울리는가?

### 6. 함수 이름을 변수에 담으면 (예측)

```rust
fn double(x: i32) -> i32 { x * 2 }
fn triple(x: i32) -> i32 { x * 3 }

let p: fn(i32) -> i32 = double;
let mut f = double;
f = triple;

println!("{}", std::mem::size_of::<fn(i32) -> i32>());
println!("{}", std::mem::size_of_val(&double));
```

- `p` 는 만들어지는가? `f = triple;` 은 어떻게 되는가 — 에러라면 번호와 `note` 는?
- `double` 이라는 이름의 **진짜 타입 이름**은 무엇인가(`let _: () = double;` 로 물어보라)?
- 두 `println!` 이 찍는 두 수는 각각 얼마인가 — 왜 다른가?
- 에러가 난다면 컴파일러가 제안하는 고치는 법 두 가지는?

### 7. ★ `!` 를 타입으로 적을 수 있는 자리 (경계)

```rust
fn spin() -> ! { loop {} }          // (가)
let p: fn() -> ! = spin;            // (나)
let x: ! = panic!();                // (다)
let v: Vec<!> = Vec::new();         // (라)
fn take(x: !) -> i32 { x }          // (마)
type Never = !;                     // (바)
```

- 여섯 중 **stable 1.92.0 에서 통과하는 것**은 어느 것인가?
- 통과하지 않는 것들의 **에러 번호와 첫 줄**은 무엇인가?
- 그 에러가 말하는 「experimental」은 무엇에 달린 문제인가 — 버전인가, 에디션인가, 다른 무엇인가?
- 규칙을 한 문장으로 말하면?

### 8. `-> !` 가 약속하는 것 (경계)

```rust
fn die(msg: &str) -> ! {
    eprintln!("치명적: {msg}");
    std::process::exit(2);
}

fn bad() -> ! {
    println!("여기서 끝나 버린다");
}
```

- `die` 는 컴파일되는가? `main` 에서 `die("…")` 로 끝내면 **종료 코드**는 얼마인가?
- `bad` 는 컴파일되는가 — 안 된다면 에러 번호와 「expected … found …」는?
- `bad` 의 에러 메시지에 붙는 설명 한 줄은 2번의 어느 함수와 같은 문장인가?
- `-> !` 함수의 몸통 마지막에 올 수 있는 것은 무엇인가?

### 9. 클로저와 `fn` 포인터의 경계 (경계)

```rust
let c1: fn(i32) -> i32 = |x| x + 1;

let k = 10;
let c2: fn(i32) -> i32 = |x| x + k;

fn main() {
    let k = 10;
    fn inner() -> i32 { k + 1 }
}
```

- `c1` 과 `c2` 중 컴파일되는 것은? 안 되는 쪽의 에러 번호와 `note` 한 줄은?
- `inner` 는 컴파일되는가 — 안 된다면 번호와 `help:` 는?
- `fn` 아이템과 클로저를 가르는 기준을 한 문장으로 말하면?
- `--explain` 이 알려 주는 해결책 **둘**은 각각 무엇인가?

### 10. 인자 타입과 같은 이름 (경계)

```rust
fn add(a, b) -> i32 { a + b }

fn add2(a: i32, b: i32) -> i32 { a + b }
fn add2(a: f64, b: f64) -> f64 { a + b }
```

- 위쪽은 어떤 에러를 내는가 — **에러 번호가 붙는가?**
- 그 차이(번호가 붙고 안 붙고)가 뜻하는 것은 무엇인가?
- 아래쪽 둘은 오버로딩으로 동작하는가? 에러라면 번호와 `note` 는?
- 이 언어에서 「같은 일을 여러 타입에 대해」 하려면 어디로 가야 하는가?

### 11. `!` 와 `()` 는 무엇이 다른가 (왜)

- `()` 와 `!` 를 각각 한 문장으로 정의하면?
- 둘 다 **크기가 0**인가 — 그 답을 어떻게 확인했나?
- `let a = nothing();` 은 되는데 `let x: ! = panic!();` 은 왜 안 되는가?
- 반환 타입을 안 적은 함수와 `-> !` 함수는 **호출자 쪽에서** 무엇이 다른가?
