## 질문

### 1. 대입이 복사하는 것 (예측)

```python
a = [1, 2]
b = a
b.append(3)
print(a)
print(a is b)
```

- 두 줄의 출력은 각각 무엇이고, `b = a` 가 한 일을 한 문장으로 말하면 무엇인가?

### 2. 한 객체인가 두 객체인가 (예측)

```python
a = b = []
print(a is b)
a.append(1)
print(a, b)

c, d = [], []
print(c is d)
c.append(1)
print(c, d)
```

- 네 줄의 출력은 각각 무엇이고, 두 형태가 갈리는 것을 `dis` 의 어느 명령으로 보일 수 있는가?

### 3. 왼쪽 대상의 처리 순서 (예측)

```python
L = [0, 0]
i = 0
i, L[i] = 1, 5
print(i, L)
```

- 출력은 무엇이고, `L[0]` 이 아니라 `L[1]` 이 바뀌는(또는 안 바뀌는) 이유는 무엇인가?

### 4. 함수에 넘긴 것은 무엇인가 (예측)

```python
def rebind(lst):
    lst = [9, 9]

def mutate(lst):
    lst.append(9)

L = [1, 2]
rebind(L); print(L)
L = [1, 2]
mutate(L); print(L)
```

- 두 줄의 출력은 각각 무엇이고, 파이썬의 인자 전달을 「값 전달」·「참조 전달」 중 무엇이라 불러야 하는가?

### 5. 같은 줄인데 명령이 다르다 (예측)

```python
x = "전역"

def read():
    print(x)

def write():
    print(x)
    x = "지역"

read()
try:
    write()
except UnboundLocalError as e:
    print(type(e).__name__, ":", e)
```

- 두 줄의 출력은 각각 무엇이고, 소스의 `print(x)` 가 글자까지 같은데 갈리는 이유는 무엇인가?

### 6. `del` 과 스코프가 만나는 자리 (예측)

```python
a = [1, 2, 3]
b = a
del a
print(b)
print("a" in globals())

def g():
    v = 1
    del v
    try:
        print(v)
    except UnboundLocalError as e:
        print(type(e).__name__, ":", e)
g()
```

- 세 줄의 출력은 각각 무엇이고, `del` 이 지운 것은 정확히 무엇인가?

### 7. LEGB 와 `global`·`nonlocal` (왜)

- `global x` 와 `nonlocal x` 는 각각 **어느 층**의 이름을 가리키며, 둘 다 안 쓰고 함수 안에서 `x = ...` 라고 쓰면 무슨 일이 일어나는가?

### 8. 참조를 세는 도구의 함정 (예측)

```python
import sys
obj = object()
print(sys.getrefcount(obj))
print(sys.getrefcount(object()))
```

- 두 줄의 출력은 각각 무엇이고, 이름이 하나뿐인데 그 값이 나오는 이유는 무엇인가?

### 9. 컴파일 단위가 답을 바꾼다 (경계)

- 같은 `a = "hello world"; b = "hello world"` 가 **파일 실행과 대화형에서 `a is b` 의 답이 갈리는** 이유는 무엇이고, 그 사실이 「같은 값이면 같은 객체」라는 문장에 무엇을 뜻하는가?

### 10. 세 층 가르기 (경계)

- 이 주제에서 **언어 보장** · **CPython 구현 세부사항** · **이 판(3.12.3)의 관찰**에 각각 해당하는 것을 나열할 수 있는가?

### 11. 뿌리에서 갈라져 나온 것들 (연결)

- 「변수는 이름표」라는 한 모델이 **가변 기본 인자**·**얕은 복사**·**`is` 가 우연히 참이 되는 것** 셋을 각각 어떻게 설명하는가?
