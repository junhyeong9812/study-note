언어 선택의 축(“RAII 가 지우는 실패와 못 지우는 실패”)은 [`../../c-cpp-csharp.md`](../../c-cpp-csharp.md)에 있다.
이 목록은 그 논증이 아니라 “**그래서 어떻게 쓰나**”다 — 저기서 *RAII 가 왜 UAF 를 못 지우는가*를 읽었다면, 여기서는 *소멸자·이동·`weak_ptr`·이터레이터 무효화를 코드에서 어떻게 다루는가*를 인출한다.

**C 문법은 이 목록에 다시 넣지 않았다.** 포인터·배열 감쇠·구조체 레이아웃·전처리기·저장 기간은 [`../../c/syntax/`](../../c/syntax/README.md) 에 있고, 여기서는 **선행 칸에 `C-NN` 으로 건다**(예: `C-14` = C 목록 14번 포인터).

## 이 언어에서 무엇을 자르는 축

C++ 의 면적은 C 의 몇 배지만, 인출해야 하는 것은 기능 개수가 아니라 **네 가지 질문에 대한 답**이다.

```text
① 이 값은 복사되나 옮겨지나 빌려지나   값 범주 · 참조 · move · 매개변수 전달
② 이 자원은 언제 사라지나              RAII · 소멸자 · 스마트 포인터 · 수명
③ 이 코드는 언제 만들어지나            템플릿 인스턴스화 · constexpr · 컨셉
④ 이 실패는 어디로 나가나              예외 · 안전 보장 · noexcept · 값 기반 오류
```

C 목록의 축이 “메모리를 직접 다루는 규칙”이었다면, C++ 의 축은 “**그 규칙을 타입으로 감싸는 방법**”이다.
그래서 같은 이름의 주제라도 내용이 다르다 — C 의 `const` 는 *포인터 선언을 읽는 규칙*이고, C++ 의 `const` 는 *인터페이스 설계 도구*다.

## 뺀 것과 이유

- **C 문법 전부** — [`../../c/syntax/`](../../c/syntax/README.md) 에 있다. 이 목록에서는 선행(`C-NN`)으로만 건다. 구체적으로 뺀 것:
  기본 타입·정수 승격·산술 변환(`C-02`\~`C-04`) · 포인터 산술·배열 감쇠·다차원 배열(`C-15`\~`C-17`) · 구조체 레이아웃·패딩·`union`·비트필드(`C-21`\~`C-24`) ·
  저장 기간·링크·`static`/`extern`(`C-28`\~`C-30`) · `volatile`·`restrict`(`C-32`·`C-33`) · 함수 포인터(`C-35`, 여기서는 40 호출 가능 타입으로 대체) ·
  가변 인자 `<stdarg.h>`(`C-36`, 여기서는 34 가변 인자 템플릿) · 전처리기·매크로(`C-41`\~`C-43`) · 헤더·링크 오류(`C-44`·`C-45`) ·
  `<stdio.h>`·`<string.h>`·`<stdlib.h>`(`C-47`\~`C-51`) · `goto cleanup`(`C-13`, 여기서는 15 RAII 가 대체) · 미정의 동작 4종(`C-54`\~`C-57`).
  **C++ 에서만 새로 생기는 수명 함정**(30 댕글링 참조·43 이터레이터 무효화)만 여기 남겼다.
- **동시성(`<thread>`·`<mutex>`·`<atomic>`·코루틴)** — 면적이 독립 주제군이고 개념 축은 [`foundations/process-thread/`](../../../process-thread/) 에 있다. 2단계에서 수요가 확인되면 별도 묶음으로 붙인다.
- **다중 상속·가상 상속·CRTP·표현식 템플릿** — 읽을 일은 있어도 쓸 일이 드물다. 21·33 의 자매 주제로 미룬다.
- **`<regex>`·로케일·와이드 문자** — 표준 구현의 품질 편차가 커서 “표준대로”가 실무 조언이 되지 않는다.
- **빌드 시스템(CMake) 자체** — 언어가 아니라 도구다. 55에서 번역 단위 개념만 다룬다.

## 버전 기준

**C++20 기준**(ISO/IEC 14882:2020, 대응 공개 초안 N4849)으로 쓰고, **C++23(대응 초안 N4950)에서 달라지는 것은 주제 안에서 「C++23부터」로 표기**한다.
C++11/14/17 에서 들어온 것도 “언제부터”가 인출 대상이라 함께 적는다.

| 표기 | 해당 주제 |
|---|---|
| **C++11부터** | 05 `auto`/`decltype` · 09 rvalue 참조·`move`/`forward` · 17 이동 연산 · 18 `=default`/`=delete` · 19 `override`/`final` · 26\~28 스마트 포인터 · 34 가변 인자 템플릿 · 38 `constexpr` · 39 람다 · 53 `noexcept` |
| **C++14부터** | 26 `make_unique` · 39 초기화 캡처·제네릭 람다 · 38 `constexpr` 완화 |
| **C++17부터** | 25 `inline` 변수 · 32 CTAD · 34 폴드 식 · 47 `optional`/`variant`/`any` · 48 구조적 바인딩 · 50 `<filesystem>` |
| **C++20부터** | 23 `<=>` · 36 컨셉 · 38 `consteval`/`constinit` · 45 범위와 뷰 · 49 `std::format` · 55 모듈 |
| **C++23부터** | 54 `std::expected` · 45 범위 확장(`ranges::to` 등) |

C++20·23 항목은 **컴파일러마다 지원 상태가 다르다** — 특히 **모듈(55)과 `std::format`(49)은 `g++ 13` 에서 사용 방법·지원 범위가 제한된다.**
3파일을 쓸 때 각 예제를 `g++ -std=c++20` 과 `clang++ -std=c++20` 양쪽으로 돌려 보고, 안 되는 것은 「이 머신에서 미지원」으로 사실대로 적는다.
