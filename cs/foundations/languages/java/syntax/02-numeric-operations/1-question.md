## 질문

### 1. 이 네 줄 중 어느 것이 컴파일되는가 (예측)

```java
byte b1 = 10, b2 = 20;
byte b3 = b1 + b2;        // (A)
byte b4 = 10 + 20;        // (B)
char c = 'A';
char c2 = c + 1;          // (C)
final char fc = 'A';
char c3 = fc + 1;         // (D)
```

- 네 줄 중 컴파일되는 것과 안 되는 것은 각각 무엇인가?
- 안 되는 줄의 에러 메시지는 무엇인가?
- 되는 줄과 안 되는 줄을 가르는 **한 가지 조건**은 무엇인가?
- `b1 + b2` 의 타입은 무엇인가, 그리고 그것을 바이트코드에서 어떻게 확인하는가?

### 2. 하루를 마이크로초로 세면 무엇이 나오는가 (예측)

```java
long a = 24 * 60 * 60 * 1000;
long b = 24 * 60 * 60 * 1000 * 1000;
long c = 24L * 60 * 60 * 1000 * 1000;
long d = (long) (24 * 60 * 60 * 1000 * 1000);
```

- 네 값은 각각 무엇인가?
- `b` 와 `d` 가 같은 값인 이유는 무엇인가?
- 변수를 `long` 으로 선언했는데도 안 통하는 이유는 무엇인가?
- 이 계산을 `Math.multiplyExact` 로 바꾸면 무엇이 출력되는가?

### 3. 절댓값이 음수가 되는 자리 (경계)

- `Math.abs(Integer.MIN_VALUE)` 는 무엇을 반환하는가?
- 그 값이 나오는 이유를 `int` 의 범위로 설명할 수 있는가?
- `Math.abs(hash) % buckets` 로 버킷을 고르는 코드는 언제 깨지는가?
- 그것을 한 줄로 고치는 표준 라이브러리 메서드는 무엇인가?
- `Math.absExact(Integer.MIN_VALUE)` 의 예외 메시지는 다른 `*Exact` 들과 어떻게 다른가?

### 4. 음수가 섞인 나눗셈과 나머지 (예측)

```java
System.out.println(-7 / 2);
System.out.println(-7 % 2);
System.out.println(Math.floorDiv(-7, 2));
System.out.println(Math.floorMod(-7, 2));
System.out.println(-1 % 3);
System.out.println(Math.floorMod(-1, 3));
```

- 여섯 줄의 출력은 각각 무엇인가?
- `/` 는 어느 방향으로 자르는가, 그 방향의 이름은 무엇인가?
- `%` 결과의 부호는 어느 피연산자를 따라가는가?
- 링 버퍼 인덱스를 `(cur - 1) % n` 으로 계산하면 무엇이 터지는가?

### 5. 시프트 세 줄 (예측)

```java
int n = -8;
System.out.println(n >> 1);
System.out.println(n >>> 1);
System.out.println(1 << 32);
byte sb = -8;
System.out.println(sb >>> 1);
```

- 네 줄의 출력은 각각 무엇인가?
- `1 << 32` 가 `0` 이 아닌 이유는 무엇인가, 그 규칙은 무엇이 정하는가?
- `byte` 에 `>>>` 를 썼는데 큰 양수가 나온 이유는 무엇인가?
- `x / 2` 를 `x >> 1` 로 바꾸면 언제 답이 달라지는가?

### 6. 축약형이 더 안전해 보이는 함정 (예측)

```java
byte b = 100;
b = b + 300;    // (A)
b += 300;       // (B)
```

- (A)와 (B) 중 어느 쪽이 컴파일되는가?
- 컴파일되는 쪽의 출력은 무엇인가?
- 두 줄이 갈리는 이유는 언어 명세의 어느 규칙 때문인가?
- `javap -c` 에서 그 규칙의 흔적은 어떤 명령으로 보이는가?

### 7. 넘치는 순간 던지게 만들기 (경계)

```java
Math.addExact(Integer.MAX_VALUE, 1);
Math.multiplyExact(86_400_000, 1000);
Math.toIntExact(Long.MAX_VALUE);
Math.addExact(Long.MAX_VALUE, 1L);
```

- 네 줄이 던지는 예외의 **클래스와 메시지**는 각각 무엇인가?
- `int` 판과 `long` 판의 메시지는 어떻게 다른가?
- `Math.*Exact` 를 **쓰면 안 되는** 코드는 어떤 종류인가?

### 8. 0으로 나누면 (경계)

- `5 / 0` 과 `5.0 / 0` 은 각각 무엇을 하는가?
- `5 % 0` 의 예외 메시지는 무엇인가, 왜 헷갈리는가?
- `0.0 / 0.0` 은 무엇인가, 그 값으로 계속 계산하면 무슨 일이 생기는가?

### 9. 누가 보장하고 누가 안 보장하는가 (왜)

- 정수 오버플로의 결과값은 JVM 구현이 정하는가, 언어 명세가 정하는가?
- 명세가 그것을 어떤 문장으로 말하는가?
- `Math.sin` 의 마지막 자리는 JVM마다 달라도 되는가, 그 근거는 어디에 적혀 있는가?
- 비트까지 같은 결과가 필요하면 무엇을 쓰는가?
- 이 문서의 어떤 출력은 JDK 17에서 **컴파일조차 안 되는가**?

### 10. 이진 탐색의 중간값 (연결)

- `int mid = (low + high) / 2;` 는 언제 깨지는가?
- 깨졌을 때 스택트레이스는 어느 줄을 가리키는가, 진짜 원인은 어느 줄인가?
- `(low + high) >>> 1` 이 고쳐 주는 이유를 비트로 설명할 수 있는가?
- `low + (high - low) / 2` 와 `>>> 1` 중 어느 쪽을 고르겠는가, 왜인가?

### 11. 다른 주제와 잇기 (연결)

- `Integer a = 127, b = 127; a == b` 가 `true` 인 것과 이 주제의 이항 승격은 어떻게 이어지는가?
- 금액 계산을 `long` 원 단위로 바꾸면 이 주제의 어떤 위험이 남고 어떤 위험이 사라지는가?
- `'A' + 'B'` 가 `131` 인데 `"" + 'A' + 'B'` 가 `"AB"` 인 이유는 무엇인가?
