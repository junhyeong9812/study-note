## 질문

### 1. 이 네 줄의 출력을 예측하라 (예측)

```java
Integer a = 127, b = 127;
Integer c = 128, d = 128;
System.out.println(a == b);
System.out.println(c == d);
System.out.println(c.equals(d));
Integer e = 128; int f = 128;
System.out.println(e == f);
```

- 네 줄의 출력은 각각 무엇인가?
- 두 번째 줄과 네 번째 줄의 결과가 갈리는 이유는 무엇인가?

### 2. 컴파일러가 무엇을 끼워 넣는가 (왜)

```java
static boolean sameRef(int n) {
    Integer a = n;
    Integer b = n;
    return a == b;
}
```

- 이 메서드의 클래스 파일에는 소스에 없는 어떤 메서드 호출이 들어 있는가?
- `a == b` 는 어떤 바이트코드 명령으로 컴파일되는가?
- `Integer a = n; Integer b = n;` 에서 `n` 이 `500` 이면 `sameRef` 는 무엇을 반환하는가?

### 3. `==` 의 의미는 누가 언제 정하는가 (경계)

- `==` 가 값 비교가 될지 참조 비교가 될지는 무엇을 보고 결정되는가?
- 그 결정은 컴파일 타임에 나는가, 런타임에 나는가?
- `Integer x` 와 `int y` 를 `==` 로 비교하면 어느 쪽이 어떻게 변환되는가?

### 4. 캐시의 보장 범위 (경계)

- JLS 가 `==` 를 `true` 로 **강제**하는 값의 범위는 어디까지인가?
- 그 보장에는 값 말고 어떤 조건이 하나 더 붙는가?
- 그 범위 밖의 값에 대해 명세는 무엇을 말하는가?
- `Integer a = 1000, b = 1000; a == b` 를 `true` 로 만드는 방법이 있는가?
- `Integer a = -129, b = -129; a == b` 를 `true` 로 만드는 방법이 있는가, 없다면 왜인가?

### 5. 이 메서드가 끝난 뒤 세 값은 무엇인가 (예측)

```java
static void tryChange(int n, Integer boxed, int[] arr) {
    n = 99;
    boxed = 99;
    arr[0] = 99;
}
// 호출 전: n = 1, boxed = 1, arr = {1}
```

- 호출이 끝난 뒤 `n`, `boxed`, `arr[0]` 은 각각 무엇인가?
- `boxed` 는 참조 타입인데 왜 `arr` 처럼 바뀌지 않는가?
- `Integer` 가 불변이 아니었다면 무엇이 달라졌겠는가?

### 6. 이 메서드는 언제 터지는가 (예측)

```java
static Integer pick(boolean flag, Integer box) {
    return flag ? 0 : box;
}
```

- `pick(true, null)` 은 무엇을 반환하거나 무엇을 던지는가?
- `pick(false, null)` 은 무엇을 반환하거나 무엇을 던지는가?
- 예외가 난다면 스택트레이스에 나오는 메서드 이름은 무엇인가?
- 이 코드를 한 글자 수준으로 고쳐 예외를 없애려면 무엇을 바꾸는가, 그러면 무엇이 달라지는가?

### 7. 이 두 줄이 NPE 를 내는지 예측하라 (예측)

```java
Map<String, Integer> m = new HashMap<>();
int v = m.get("missing");         // (A)
Integer w = m.get("missing");     // (B)
```

- (A)와 (B) 중 어느 쪽이 터지는가?
- 터지는 쪽의 예외 메시지에는 어떤 메서드 이름이 등장하는가, 그 메서드는 소스 어디에 있는가?
- `m.getOrDefault("missing", 0)` 은 (A)를 고치는가?

### 8. 어느 래퍼에 캐시가 있는가 (연결)

- `Long l1 = 127L, l2 = 127L; l1 == l2` 는 무엇인가?
- `Double d1 = 1.0, d2 = 1.0; d1 == d2` 는 무엇인가?
- `Double` 에 캐시가 없는 이유를 `Integer` 와 대비해 설명할 수 있는가?
- `Boolean b1 = true, b2 = true; b1 == b2` 는 무엇이고, 왜 그런가?

### 9. 다른 주제와 잇기 (연결)

- `IntStream.boxed()` 는 내부에서 무엇을 부르며, 그것이 이 주제와 어떻게 이어지는가?
- 기본형 대신 래퍼를 골라야만 하는 상황을 두 가지 들 수 있는가?
- 래퍼를 골랐을 때 코드 리뷰에서 반드시 확인해야 할 한 가지는 무엇인가?
