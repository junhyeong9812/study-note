### 1. 닫는 `"""` 를 옮기면 문자열이 어떻게 달라지나 (예측)

```java
String a = """
............hello
..............world
............""";        // 12열

String b = """
............hello
..............world
""";                     // 0열

String c = """
............hello
..............world
........""";             // 8열
```

- 세 문자열의 **각 줄과 길이**는 각각 무엇인가?
- 세 값이 갈리는 이유를 한 문장으로 말할 수 있는가?
- 닫는 `"""` 를 내용보다 **더 오른쪽**(16열)으로 옮기면 무엇이 달라지는가?

### 2. 최소 들여쓰기를 재는 줄은 어느 줄들인가 (경계)

- 빈 줄은 계산에 참여하는가?
- 닫는 `"""` 가 있는 줄은 빈 줄이어도 참여하는가?
- 이 규칙이 적힌 곳을 댈 수 있는가 — 어느 문서의 어느 메서드 javadoc 인가?
- 탭 한 개는 몇 칸으로 세어지는가?

### 3. 후행 공백과 `\s` (예측)

```java
String e = """
....hello...             // hello 뒤에 공백 셋
....world\s\s\s
....""";
```

- 두 줄 각각의 끝에 공백이 남는가, 몇 개인가?
- 왜 한쪽만 살아남는가 — 처리 순서의 어느 단계 때문인가?
- `\s` 는 일반 문자열 리터럴에서도 쓸 수 있는가?

### 4. 줄 끝 백슬래시 (예측)

```java
String f = """
....hello \
....world
....""";

String g = """
....hello
....world\
....""";
```

- 두 문자열의 **줄 수와 내용**은 각각 무엇인가?
- `f` 에서 `hello` 와 `world` 사이에 공백이 있는가, 왜인가?
- 줄 끝 `\` 는 일반 문자열 리터럴에서도 쓸 수 있는가?

### 5. 이 셋 중 무엇이 컴파일 에러인가 (예측)

```java
String p = """hello
....world
....""";

String q = """
....hello""" + """ world""";

String r = """
....안 닫음
```

- 셋 다 에러인가? 각각의 **에러 메시지 첫 줄**은 무엇인가?
- 에러가 하나만 나는 것과 둘 나는 것이 있다 — 왜 갈리는가?
- 세 메시지 중 둘은 같고 하나만 다르다. 다른 하나는 무엇인가?

### 6. 텍스트 블록과 일반 리터럴의 `==` (예측)

```java
static String block() {
    return """
....    hello
....      world
....    """;
}
static String plain() {
    return "hello\n  world\n";
}
// block() == plain() 은?
```

- 출력은 무엇인가?
- `javap -c` 로 두 메서드를 보면 몇 개의 명령이 나오는가, 무슨 명령인가?
- 이 결과가 뜻하는 것은 텍스트 블록이 **어느 시점의 기능**이라는 것인가?

### 7. 탭과 공백을 섞으면 (경계)

- 첫 줄을 `탭 + 공백 8`, 둘째 줄을 `공백 12`, 닫는 줄을 `공백 12` 로 두면 min 은 얼마인가?
- 두 줄에 각각 몇 칸이 남는가?
- 화면에서 두 줄이 같은 열로 보이는데 문자열이 다를 수 있는 이유는 무엇인가?
- 이 동작을 적어 놓은 javadoc 태그의 이름은 무엇인가?

### 8. 빈 블록과 개행 하나짜리 (경계)

- 여는 `"""` 바로 다음 줄에 닫는 `"""` 를 두면 길이가 얼마인가?
- 한 줄을 띄우면 길이가 얼마인가?
- 마지막 줄에 내용을 두고 `"""` 를 바로 붙이면 끝에 개행이 붙는가?

### 9. 짝으로 들어온 `String` 메서드 (연결)

- `formatted`·`stripIndent`·`translateEscapes` 는 각각 몇 부터인가?
- `stripIndent` 는 **무엇을 위해** 있는가 — 텍스트 블록에 쓰라고 만든 것인가?
- `translateEscapes` 의 입력과 출력을 한 줄 예로 들 수 있는가?
- `indent(4)` 와 `stripIndent()` 중 결과 끝의 개행을 **보장**하는 쪽은 어느 것인가?

### 10. 왜 이렇게 설계했나 (왜)

- 닫는 `"""` 를 계산에 참여시킨 덕에 무엇이 가능해지는가?
- 후행 공백을 무조건 지우는 결정의 이득과 대가는 각각 무엇인가?
- 텍스트 블록이 **raw 문자열이 아닌** 것은 정규식을 적을 때 어떤 결과로 나타나는가?

### 11. 다른 주제와 잇기 (연결)

- 텍스트 블록이 상수 풀에 들어간다는 사실은 어느 주제의 어떤 규칙과 같은 것인가?
- 텍스트 블록에 `+` 를 붙이는 순간 어느 주제의 이야기가 되는가?
- 테스트의 기대값을 텍스트 블록으로 쓸 때 조심할 것은 무엇인가?

### 12. ★ 블록 안에 `\n` 을 쓰면 (예측)

```java
String a = """
............hello\nworld
............""";

String b = """
............A\n....B
............""";

String c = """
............A...\nB...
............""";        // A 뒤에도 B 뒤에도 공백 셋
```

- 세 문자열의 **각 줄**은 무엇인가?
- `b` 에서 `\n` 뒤의 공백 넷은 **부수 공백으로 지워지는가, 본문으로 남는가?**
- `c` 에서 `A` 뒤의 공백 셋은 남는가 — 후행 공백은 지워진다고 했는데 왜인가?
- 이 결과가 「단계 2 와 단계 3 중 무엇이 먼저인가」에 대해 말해 주는 것은 무엇인가?
