# cs/foundations — CS 기초 (책 원고 이관)

「컴퓨터사이언스 부트캠프 with 파이썬」을 따라 치며 만든 노트(`computer_science` repo)를 주제별 폴더로 **구조만 잡아 이관**한 것. 원문 유지(오탈자만 교정), 내용 보강 없음 — 각 절에 원본 파일 출처를 명기한다.

- 현재는 폴더당 README 하나(구조 잡기 단계). 이후 복습 대상으로 승격할 주제는 templates/ 3파일(질문·서머리·정답) 형태로 전환한다.
- 자료구조·알고리즘(ch11~14)은 [data-structure/](../../data-structure/)·[algorithm/](../../algorithm/)에 이미 심화판이 있다 — 여기 이관본은 책 원고 보존용.
