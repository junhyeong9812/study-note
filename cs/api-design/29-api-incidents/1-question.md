# api-design/29-api-incidents — 질문

## 질문

1. (사실) Twitter가 Snowflake를 만든 동기와 요구사항(조정 없음·대략 시간순·64비트 미만)을 README 원문으로 말하라. ID는 어떤 필드로 이뤄지고 `IdWorker.scala`에서 각각 몇 비트인가?
2. (사실) 2010-10-19 공지가 밝힌 보류 이유와 세 날짜(10-22·11-04·11-26)는 무엇이었나? 어떤 자원의 ID에 `id_str`가 붙었고, JS 개발자에게 무엇을 요청했나?
3. (예측) Snowflake 공식(`(ts - twepoch) << 22 | …`)에서 ID가 2^53 이상이 되는 조건은? `twepoch = 1288834974657`이면 그 시각은 언제인가? 공지의 날짜와 비교하고, 차이에 대해 무엇을 단정할 수 없나?
4. (예측) 2026-10-04 시각에 같은 밀리초에 만든 연속 ID 1000개를 JSON 숫자로 보내 Node 22에서 `JSON.parse`하면 서로 다른 값은 몇 개가 되나? 왜 그런지 binary64 간격으로 설명하고, 클라이언트에서 어떤 2차 피해가 생기나?
5. (왜) Twitter는 왜 `id`를 문자열로 바꾸지 않고 `id_str`를 추가했나? 07번의 호환 규칙으로 설명하고, 반대로 교체했다면 어떤 클라이언트가 깨졌을지 말하라.
6. (사실) Optus 사건의 날짜표를 1차·2차 출처로 나눠 만들어라. 2018-09·2020-06·2021-08·2022-09-17~20·2022-09-22·2025-08-08에 각각 무슨 일이 있었나(또는 무엇이 주장됐나)?
7. (경계) Optus 사건에서 "약 950만 명", "약 980만 명", "2,470,036명"은 각각 어디서 나온 수치인가? 이 노트가 "순번 식별자 +1 열거"를 `[?]`로 둔 이유는?
8. (예측) 실험 B의 세 서버(순번 + 인가 없음, 무작위 + 인가 없음, 순번 + 소유자 검사)에 요청 5000건을 보내면 각각 몇 명이 노출되나? 샌 ID 50개로 조회하면? 이 결과가 말하는 "막는 층"과 "줄이는 층"은?
9. (연결) Optus 쪽 설명대로 공격자가 수만 개 IP를 돌렸다면, IP 기준 속도 제한(14-1)은 왜 이 공격에 약한가? 어떤 지표가 이 패턴을 더 잘 보나?
10. (경계) 두 사건의 "깨진 계약·원인 계층·보이는 계층"을 표로 비교하라. Optus 사건에서 "규제기관 주장"과 "법원 판단"을 왜 구분해야 하나? 2025-09-24의 Optus 1억 호주달러 제재는 이 사건과 어떤 관계인가?
