# software-design/46-quality-attributes-and-tradeoffs — 질문

## 질문

1. (왜) 기능 요구와 품질 요구는 무엇이 다른가? 품질 속성 사이 충돌을 적어 두지 않으면 어떤 일이 생기나?
2. (경계) ISO/IEC 25010:2023의 제품 품질 특성 9개를 대라. 확장성과 가용성은 각각 어느 특성의 하위 특성인가? 원본 7축 중 ISO 특성이 아닌 둘은?
3. (그림) 품질 속성 시나리오 6요소를 그림으로 그리고, "결제 수단 하나 추가"를 유지보수성 시나리오로 적어 보라.
4. (그림) ATAM 효용 트리의 뿌리·중간·잎은 무엇이고, 잎에 붙는 (H,M) 두 글자는 각각 무엇인가?
5. (경계) ATAM의 민감점과 맞교환점은 어떻게 다른가? 캐시 TTL은 어느 쪽인가?
6. (예측) 20ms마다 값이 바뀌는 원본 앞에 캐시를 두고 TTL을 0 → 1000ms로 늘리면 평균 응답과 낡은 값 비율은 어떻게 움직이나? 실험 수치는?
7. (예측) TTL 10ms에서 평균 응답은 크게 줄었다. p99는 어땠고 왜 그런가?
8. (장애 진단) 성능 개선 PR 뒤 "예전 가격으로 결제됐다"는 문의가 온다. 어디를 보고, 재발을 어떻게 막나?
9. (연결) 가용성을 위해 재시도를 늘렸더니 하류 장애 때 회복이 늦어졌다. 이것을 맞교환점의 언어로 설명하고 대처를 말하라.
