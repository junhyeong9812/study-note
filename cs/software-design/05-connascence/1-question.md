# software-design/05-connascence — 질문

## 질문

1. (왜) 결합도 단계(내용 → 자료)가 있는데 커너선스 어휘가 따로 필요한 이유는? 커너선스의 정의는?
2. (그림) 정적 커너선스 다섯과 동적 커너선스 넷을 나열하고, 정적과 동적 중 어느 쪽이 약한지 근거와 함께 말하라.
3. (경계) 강도·지역성·정도 세 축을 각각 한 문장으로 정의하라. "강한 커너선스는 무조건 나쁘다"는 맞나?
4. (예측) `transfer(String from, String to, long amount)`를 `transfer("bob", "alice", 300)`으로 잘못 불렀다. 컴파일되나? 잔액(alice·bob 각 1000에서 시작)은?
5. (예측) 주문 쪽은 포장 단계를 끼워 3=PACKED·4=SHIPPED로 바꿨고 알림 쪽은 아직 3=SHIPPED다. 포장 완료 주문과 배송 시작 주문에 각각 어떤 알림이 가나?
6. (예측) `From`·`To` record 타입으로 바꾼 뒤 `transfer(new To("bob"), new From("alice"), 300)`을 쓰면? 무엇이 어떤 종류의 커너선스로 바뀐 것인가?
7. (경계) 상태 `3`의 뜻을 찾는 `grep -rnw 3`과 메서드 이름 변경 뒤의 `javac`는 각각 몇 줄·몇 건을 냈고 실제 고칠 곳은 몇 곳이었나? 이것이 "강도"와 어떻게 이어지나?
8. (경계) 매직 값을 이름 있는 상수로 바꾸면 커너선스가 사라지나? record로 인자를 묶으면 위치 커너선스가 사라지나?
9. (장애 진단) 신규 호출자가 `NullPointerException: ... because "this.conn" is null`을 냈다. 어떤 커너선스이고, 같은 실수를 표현할 수 없게 하려면?
