# software-design/42-ui-architecture-patterns — 질문

## 질문

1. (왜) 화면 코드가 그리기·입력·규칙을 한 클래스에서 하면 무엇이 안 되나? Fowler가 MVC에서 가장 영향력 있는 생각으로 꼽은 것은?
2. (그림) Smalltalk MVC, MVP, MVVM, 서버 MVC, Flux에서 "누가 입력을 받고, 누가 그리고, 값이 어떻게 동기화되나"를 한 줄씩 그려라.
3. (경계) 옵서버 동기화와 흐름 동기화의 차이는? Fowler가 옵서버 동기화의 단점으로 든 것은?
4. (예측) 바인딩 두 개 — `total = subtotal - discount`, `discount = total ≥ 10000 ? subtotal의 10% : 0` — 에 소계 8,000 · 12,000 · 10,500을 차례로 넣으면 각각 어떻게 되나? "같은 값이면 멈춘다" 가드는 왜 소용없나?
5. (예측) Flux 4.0.4 `Dispatcher`에서 스토어 콜백 안에서 다시 `dispatch`하면 무엇이 나오나? 스토어 사이 순서가 필요할 때 쓰는 것은?
6. (경계) 실험의 단방향 버전은 양방향 버전과 규칙이 완전히 같은가? 단방향으로 바꾸면서 드러난 것은 무엇인가?
7. (경계) Front Controller, Page Controller, Template View를 PoEAA 정의로 구분하라. Spring MVC에서 Front Controller는 무엇인가?
8. (장애 진단) 웹과 모바일 API의 결제 금액이 다르다는 문의가 왔다. 웹 컨트롤러는 400줄이다. 원인과 대처는?
9. (장애 진단) 목록 화면과 상세 화면의 "VIP" 표시 조건이 다르다. 어디를 보고 어떻게 고치나?
