# software-design/20-oop-fundamentals — 질문

## 질문

1. (왜) 데이터와 그것을 바꾸는 규칙이 떨어져 있으면 무엇이 어려워지나? 객체로 묶으면 무엇이 "한 곳"으로 모이나?
2. (경계) 모든 필드가 `private`이고 getter/setter가 하나씩 붙어 있다. 이 클래스는 캡슐화돼 있나? 무엇으로 판정하나?
3. (예측) 실험 A에서 `OpenOrder`의 `getLines().add(500)` 뒤와 `setTotal(-200)` 뒤에 `invariant`는 각각 무엇인가? 캡슐화한 `Order`에서 `lines().add(500)`을 하면?
4. (예측) `Animal a = new Dog();`에서 `a.speak()`, `a.name`, `a.kind()`(static)은 각각 누구의 것이 나오나? `javap -c`에서 각각 어떤 명령으로 보이나?
5. (경계) 추상 클래스와 인터페이스는 무엇이 다른가? 추상 클래스를 `new`하면 자바와 파이썬 `abc`는 각각 언제 막나?
6. (경계) 정사각형은 직사각형의 한 종류다. 그런데 `Square extends Rectangle`이 문제가 되는 이유는? IS-A를 무엇으로 판정해야 하나?
7. (연결) 동적 디스패치는 HotSpot에서 어떤 자료구조로 구현되나? 같은 슬롯 번호가 무엇을 가능하게 하나?
8. (장애 진단) 정산 배치가 "주문 합계 ≠ 항목 합" 불일치를 매일 몇 건씩 보고한다. 에러 로그는 없다. 어디부터 보고 어떻게 고치나?
9. (장애 진단) 파이썬에서 `acct.__balance = -3000` 뒤 `acct.get_balance()`는 몇인가? 왜 그런가? 원본 §11의 서술과 무엇이 다른가?
