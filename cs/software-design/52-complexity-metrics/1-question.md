# software-design/52-complexity-metrics — 질문

## 질문

1. (계산) 독립된 `if` 두 개가 나란히 있는 메서드의 제어 흐름 그래프를 그리고 V = E − N + 2P로 순환 복잡도를 구하라. NPath는 얼마인가?
2. (경계) "순환 복잡도 = 최소 테스트 수"는 정확히 어떤 테스트 기준에서 맞는 말인가? McCabe 자신은 v를 어떻게 표현했나?
3. (예측) 실험 d에서 하한 1,000원을 빠뜨린 `fee(member, coupon)`에 분기 커버리지 최소 세트, 기저 경로 3개, 모든 경로 4개를 돌렸다. 각각 테스트 수와 버그 발견 여부는? 왜 그런가?
4. (규칙) 인지 복잡도의 세 기본 규칙은? `switch`, 같은 종류 논리 연산자 열, 조기 `return`, 레이블 `continue`는 각각 어떻게 세나?
5. (예측) 백서의 `sumOfPrimes`와 `getWords`를 PMD 7.28.0으로 쟀을 때 순환·인지 복잡도는? 실험 b의 중첩 `if`판과 가드 절판은?
6. (예측) 실험 c에서 순환 복잡도 14인 승인 메서드를 세 도우미로 기계적으로 쪼갰다. PMD 기본 임계로 돌리면 무엇이 보고되나? 클래스 합계와 인지 복잡도 합은 어떻게 변했나?
7. (경계) PMD 7.28.0의 CyclomaticComplexity·CognitiveComplexity·NPathComplexity·AvoidDeeplyNestedIfStmts 기본 임계는? Sonar Java S3776·S1541과 비교 연산이 어떻게 다른가?
8. (장애 진단) 순환 복잡도 40인 메서드에서 "특정 조합에서만 틀린 값" 버그가 반복되는데 커버리지는 높다. 원인과 대처는?
9. (연결) McCabe가 상한 10의 예외로 든 경우는? 이런 코드를 지표 게이트가 막을 때 어떻게 하나?
