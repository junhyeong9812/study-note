# software-design/04-decompose-by-change — 질문

## 질문

1. (왜) Parnas 1972의 두 분해는 각각 어떤 기준으로 잘랐나? 두 분해가 같은 실행 코드가 될 수 있는데도 다르다고 하는 이유는?
2. (그림) KWIC 분해 1과 분해 2를 그리고, 각 분해의 모듈 사이 인터페이스가 무엇인지 적어라.
3. (경계) Parnas가 든 다섯 변경 중 두 분해가 똑같이 한 모듈만 고치는 것은? 분해 1에서 "모든 모듈"을 고치는 것은?
4. (예측) 실험에서 저장 형식을 문자 배열에서 `String[][]`로 바꿨다. 분해 1과 분해 2의 `git diff --stat`은?
5. (예측) "출력에 원래 줄 번호 붙이기"에서는 어느 분해가 더 싼가? 왜 그런가?
6. (경계) 두 분해에서 바뀐 모듈에 의존하는 클래스의 도달 가능 집합은 각각 몇 개였나? 실제 변경 파일 수와 다른 이유는?
7. (연결) Parnas가 자기 분해 2에서 인정한 설계 오류는 무엇이고, 실험 5와 어떻게 이어지나?
8. (왜) 변동성 축을 찾는 네 질문은? 변동성 예측이 틀리면 어떤 스멜이 되나?
9. (장애 진단) 새 결제 수단을 넣었는데 알림만 안 간다. 로그에 `default` 분기 경고가 찍혔다. 분해의 어떤 문제이고 어떻게 고치나?
