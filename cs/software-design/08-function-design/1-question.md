# software-design/08-function-design — 질문

## 질문

1. (왜) 함수 시그니처가 "약속"이라는 말은 무슨 뜻인가? 질의 이름의 함수가 상태를 바꾸면 누가 어떤 방식으로 속나?
2. (예측) 실험 A에서 `getBalance()`를 연달아 두 번 부르면 값은? 디버그 로그를 켰을 때와 껐을 때 수수료는? CQS로 나눈 쪽은?
3. (경계) CQS의 예외로 Fowler가 드는 관용구는? 그런데도 `getBalance()`의 캐시 갱신은 왜 문제인가?
4. (예측) 실험 B에서 boolean 인자 순서를 바꿔 쓴 코드는 컴파일되나? 결과는? enum 두 개로 바꾼 쪽은?
5. (예측) 실험 C에서 섞인 함수와 나눈 함수의 순환 복잡도 최댓값과 합은 각각 얼마인가? 분해가 복잡도를 "없앤다"고 말할 수 있나?
6. (경계) PMD 7.28.0 기본 임계(인자 수·순환·인지·NPath)는? 실험 C의 섞인 함수는 기본 설정에서 보고되나?
7. (연결) "길이보다 깊이"를 Ousterhout와 Martin의 입장 차이로 설명하고, 나눈 함수가 적당한지 판정하는 질문 하나를 들어라.
8. (장애 진단) 할인 기준만 바꾼 배포 뒤 보고서 쿼리에서 지역 조건이 사라졌다. 함수 구조에서 무엇을 의심하고 어떻게 고치나?
9. (연결) 가드 절은 어떤 지표를 줄이고 왜 그런가? 출력 인자는 무엇이고 무엇으로 바꾸나?
