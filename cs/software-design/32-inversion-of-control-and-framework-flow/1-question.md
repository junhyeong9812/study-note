# software-design/32-inversion-of-control-and-framework-flow — 질문

## 질문

1. (왜) 제어 역전이 없으면 웹 서버·배치·테스트 러너를 만들 때 무엇을 매번 다시 쓰게 되나? "할리우드 원칙"은 무슨 뜻인가?
2. (그림) 라이브러리와 프레임워크를 "누가 부르나"로 그려 구분하라. Fowler와 Johnson·Foote는 프레임워크를 어떻게 설명했나?
3. (그림) 템플릿 메서드와 콜백을 그려 비교하라. Johnson·Foote의 화이트박스/블랙박스 구분과 어떻게 대응하나?
4. (예측) `@PostConstruct init()` 안에서 호출 스택을 찍으면 `init()` 바로 아래에 누가 보이나? `JdbcTemplate.query`에 넘긴 `RowMapper` 람다는?
5. (예측) `@Autowired` 필드 주입과 `@PostConstruct`가 있는 `Notifier`를 컨테이너에서 꺼낸 것과 `new Notifier()`로 만든 것의 `initialized`·`clock` 값은? `send()`를 부르면?
6. (예측) 하위 클래스 3개(CSV·TSV·Markdown)를 가진 템플릿 메서드 골격에 "CSV만 끝에 total 줄" 요구를 골격 한 줄로 반영하면 골든 테스트 몇 개가 깨지나? 훅으로 반영하면?
7. (경계) 실험 E에서 골격 한 줄 변경이 오히려 이득인 요구는 어떤 것인가? 템플릿 메서드 대신 콜백·전략을 고를 신호는?
8. (장애 진단) "이 메서드는 호출처 검색 결과가 0건인데 새벽마다 실행된다"는 문의가 왔다. 어떻게 추적하고, 무엇을 남겨 재발을 줄이나?
