# software-design/31-antipatterns — 질문

## 질문

1. (왜) 안티패턴은 패턴과 무엇이 다른가? 처음 이 말을 쓴 사람과, Koenig의 정의로 인용되는 문장은?
2. (연결) Foote·Yoder는 Big Ball of Mud가 생기는 이유를 어떤 힘(forces)들로 설명하나? 이 관점이 고치는 방법에 주는 시사점은?
3. (그림) God Object를 의존 그래프로 그려라. 어떤 지표(간선·변경 빈도)로 후보를 찾나?
4. (예측) 쿠폰 기능과 정산 기능을 두 브랜치에서 동시에 추가한다. God 판(`OrderManager`에 필드·메서드 추가)과 분리 판(새 클래스 추가)을 차례로 병합하면 각각 어떻게 되나? 줄 수는 어느 쪽이 적었나?
5. (예측) 전역 `Pricing.INSTANCE`의 할인율을 바꾸고 되돌리지 않는 `promotionDay` 테스트와, 할인 없음을 가정하는 `normalDay` 테스트가 있다. 이름순과 이름 역순으로 실행하면 결과는?
6. (예측) 4개 스레드가 동기화 없는 싱글턴의 `long` 카운터와 `HashMap`을 각 10만 번 갱신했다. 카운트와 `size()`는 어떻게 나오나? 예외는 나나? 드물게 어떤 일이 생겼나?
7. (경계) 싱글턴의 진짜 문제는 "인스턴스가 하나"인 것인가? Spring 빈의 기본 싱글턴 스코프는 왜 같은 문제를 덜 일으키나? God Object 분리가 오히려 손해인 경우는?
8. (장애 진단) 서버 한 대가 가끔 CPU 100%로 응답을 멈추고, 집계 수치가 요청 수보다 적게 나온다. 무엇을 떠서 어떻게 원인을 좁히고, 어떻게 고치나?
