# software-design/22-solid — 질문

## 질문

1. (경계) SRP·OCP·LSP의 원 출처는 각각 누구의 어떤 글인가? Martin의 2014 블로그는 "변경 이유"를 무엇이라고 말하나?
2. (예측) 실험 B에서 결제수단 EASY_PAY를 추가할 때 switch 설계와 다형 설계는 각각 몇 파일을 바꾸나? switch 쪽에서 라벨을 빠뜨리면 어떻게 되나?
3. (예측) 같은 저장소에서 "환불 수수료" 연산을 추가하면 두 설계의 diff는 어떻게 되나? 이 결과가 OCP에 대해 말해 주는 것은?
4. (예측) enum에 `POINT`를 더하고 컴파일하면 어느 파일에서 무슨 오류가 나고, 어느 파일은 조용히 통과하나? 왜 다른가?
5. (예측) `resize(Rectangle r)`에 `Square`를 넣으면 넓이는? `List.of("x")`, `Arrays.asList("x")`에 `add`하면? `Arrays.asList`에 `set(0, "z")`는?
6. (경계) JDK의 `List.of(...).add`가 예외를 던지는 것은 LSP 위반인가? `Collection` javadoc은 이를 어떻게 다루나?
7. (예측) 메일 서버 없는 환경에서 `SignupServiceV1`(SMTP 직접 생성)과 `SignupServiceV2`(포트 주입)의 테스트는 각각 어떻게 되나? DIP의 비용은?
8. (장애 진단) 새 결제수단 출시 뒤 영수증 라벨이 "기타"로 나간다는 CS 문의가 들어왔다. 에러 로그는 없다. 원인과 재발 방지는?
9. (연결) 원본 노트의 "좋은 instanceof — 빠트리면 컴파일 시점에 드러난다"는 언제 맞고 언제 틀리나?
