# language/21-language-choice-tradeoffs — 질문

## 질문

1. (왜) 언어를 벤치마크 순위로 고르면 무엇을 놓치나? 원고가 말하는 세 축은? 정합성 시스템에서 "조용한 실패"가 크래시보다 비싼 이유는?
2. (그림) 실패를 네 등급(컴파일 거부·즉시 예외·조용한 틀린 값·미정의 동작)으로 그리고, "32비트 최댓값 + 1"이 Java·Go·Python·JS·C에서 각각 어느 등급인지 표시하라.
3. (예측) 길이 3 배열의 5번째를 읽는 코드와 `"12a"`를 숫자로 바꾸는 코드를 Java 21·Go 1.23·Python 3.12·node 22·C에서 돌리면 각각 무엇이 나오나? 같은 언어 안에서도 등급이 갈리는 예를 둘 대라.
4. (경계) Go에서 `n, _ := strconv.Atoi(s)`와 `n, err := strconv.Atoi(s)`(err 미사용)는 컴파일러가 각각 어떻게 다루나? node 22에서 처리 안 한 `Promise.reject`는?
5. (연결) 안전의 두 축(메모리 안전·데이터 레이스 없음)에서 C/C++·JVM·Go·Rust는 각각 무엇을 누가 보장하나? 각 진영이 안전의 값을 어느 통화로 내나?
6. (경계) 원고 비교표의 "Rust: 경계 위반 = 컴파일 거부"와 "Go·JVM: 데이터 레이스는 정의되나 값만 어긋남"은 각각 무엇이 부정확한가? 근거 문서는?
7. (예측) hello world의 기동 시간을 C·Go·Python·node·Java 21에서 재면 대략 어떤 차이가 나나? `-Xshare:off`는? 이 수치가 언어 선택에 결정적인 층과 무의미한 층을 하나씩 대라.
8. (장애 진단) 프런트엔드에서 주문 ID로 조회하면 가끔 다른 주문이 나온다. 서버 로그와 끝자리만 다르다. 원인과 대처는?
9. (적용) 정합성이 1순위인 원장 서비스의 언어를 고를 때의 절차를 순서대로 적고, 고른 언어가 Java라면 막아야 할 조용한 경로 두 가지와 막는 코드를 대라.
