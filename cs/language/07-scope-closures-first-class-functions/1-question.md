# language/07-scope-closures-first-class-functions — 질문

## 질문

1. (왜) `counter()`가 반환한 `inc` 클로저는 `counter()`의 스택 프레임이 사라진 뒤에도 `n`을 어떻게 읽고 고치나? 환경 레코드 체인 그림으로 설명하고, `c1`과 `c2`가 서로 다른 `n`을 갖는 이유를 답하라.
2. (예측) JS에서 `for (var i …)`와 `for (let j …)`로 각각 클로저 3개를 만들어 부르면 출력은? 같은 일을 Python `[lambda: i for i in range(3)]`로 하면? 각각 고치는 방법은?
3. (경계) JS·Python·Java·Rust는 클로저가 "무엇을" 캡처하나? Java가 effectively final만 허용하는 이유를 JLS가 어떻게 설명하나?
4. (그림) `x -> x + base`(지역 변수 캡처)와 `() -> payload.length`(인스턴스 필드 사용)가 javac에서 각각 어떤 메서드와 어떤 `invokedynamic` 서명으로 바뀌나? 실행 중 람다 객체는 무엇을 필드로 갖나?
5. (예측) JDK 21 javac로 컴파일한, 바깥 인스턴스를 쓰지 않는 익명 클래스에는 `this$0` 필드가 있나? 바깥 필드를 쓰면? 이 차이는 어느 JDK에서 생겼나?
6. (예측) node 22에서 `big` 배열을 만든 함수가 `() => 42`만 반환한다. 같은 함수 안에 `big`을 쓰는 다른 클로저가 있으면 `big`은 회수되나? 그 클로저가 실행되지 않는 `if` 분기 안에 있으면?
7. (장애 진단) Java 서비스 힙 덤프에서 `…$$Lambda` 인스턴스가 요청 수만큼 있고 `arg$1`이 요청 처리 객체를 가리킨다. 원인과 코드 수정 방향은?
8. (예측) Java에서 `int[] box = {0}`을 람다로 캡처해 두 스레드가 각각 100만 번 `box[0]++`하면 결과는? 왜 컴파일은 통과하나? 무엇으로 고치나?
