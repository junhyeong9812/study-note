# language/19-modules-and-dependency-resolution — 질문

## 질문

1. (왜) 모듈·패키지·semver·락파일은 각각 어떤 질문에 답하나? 다이아몬드 의존이 문제가 되는 조건은 무엇인가?
2. (경계) semver에서 MAJOR·MINOR·PATCH를 올리는 조건은? `^1.2.3`·`^0.2.5`·`~1.2.3`이 허용하는 범위는? semver를 지켰다는 것을 도구가 검사해 주나?
3. (예측) `liba`는 money 1.0에, `libb`는 money 2.0(1.0 메서드 + 새 오버로드)에 맞춰 컴파일했다. 실행 클래스패스 끝을 (a) `libc-1.0.jar` (b) `libc-1.0.jar:libc-2.0.jar` (c) `libc-2.0.jar:libc-1.0.jar` (d) 비움으로 하면 각각 무엇이 출력·발생하나? 왜 기동 직후가 아니라 B를 부를 때 실패하나?
4. (계산) Maven 트리가 `A→B→C→D 2.0`, `A→E→D 1.0`이다. Maven·Gradle·Go(MVS, 두 요구를 최솟값으로 보면)는 D를 각각 몇으로 고르나? 어느 쪽이 3번 같은 오류를 낼 위험이 있나?
5. (연결) Cox가 버전 선택을 NP-완전이라고 보인 네 가정은? npm과 Go는 각각 어느 가정을 깨서 이 문제를 피하나? 각자의 대가는?
6. (예측) 2일째에 c 1.5.0이 공개됐다. 코드 변경 없이 (a) 락파일 없이 캐럿 범위로 해석, (b) 1일째 락파일로 설치, (c) MVS로 해석하면 c는 각각 몇인가?
7. (장애 진단) 운영에서 `java.lang.NoClassDefFoundError: com/x/Money`, `Caused by: ClassNotFoundException`이 났다. `NoSuchMethodError`와 무엇이 다른가? 무엇을 확인하나?
8. (장애 진단) left-pad 사건(2016-03)에서 왜 대체 패키지 1.0.0이 10분 만에 올라왔는데도 실패가 이어졌나? 락파일이 있었다면 막혔나? 무엇이 필요하나?
9. (경계) 스크립트 옆에 `json.py`를 두면 `import json`이 무엇을 가져오나? 클래스패스의 "앞이 이긴다"와 어떻게 같은 구조인가? Python 3.12에서 막는 옵션은?
