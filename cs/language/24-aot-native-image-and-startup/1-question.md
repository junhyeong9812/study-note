## 질문

1. (왜) JVM 시작 시간을 줄이는 두 방향은 무엇인가? 각각 무엇을 미리 해 두고, 무엇을 포기하나?
2. (그림) 진입점 `Main.main`에서 호출 그래프를 따라가는 도달성 분석을 그려라. `Class.forName("JsonCodec")`와 `Class.forName(config.get("gateway"))`는 분석에서 어떻게 다르게 다뤄지나? 아무도 부르지 않는 `LegacyReport`는?
3. (경계) GraalVM 문서가 말하는 closed-world assumption은 무엇인가? Spring Boot 문서가 JVM 배포와의 차이로 드는 것 세 가지를 대라.
4. (예측) JDK 21에서 `HelloStream`을 `-Xshare:off` / 기본 / AppCDS로 각각 돌리면 시작 시간과 "아카이브에서 온 클래스 수"는 어떤 순서가 되나? AppCDS 아카이브를 만들 때 클래스패스를 디렉터리로 주면 어떻게 되나?
5. (연결) 네이티브 이미지에서 빌드 때 초기화된 클래스의 static 값은 어디에 저장되나? 이것이 "수 ms 시작"과 "값이 굳는 함정"을 동시에 만드는 이유는? 스냅숏 복원(SnapStart)과 무엇이 닮았나?
6. (경계) JEP 483 AOT 캐시를 쓰려면 훈련 실행과 운영 실행이 무엇을 맞춰야 하나? 맞지 않으면 어떻게 되고, 그것을 배포 전에 잡으려면?
7. (연결) CDS → AppCDS → AOT 캐시(JEP 483) → 프로파일(JEP 515) → 컴파일된 코드(JEP 544)로 가면서 "미리 해 두는 것"이 어떻게 늘어나나? 네이티브 이미지와 결정적으로 다른 점은?
8. (장애 진단) 결제 게이트웨이를 설정으로 고르는 서비스가 JVM 테스트는 통과했는데 네이티브 바이너리에서만 실패한다. 보이는 오류, 원인, 대처를 대라.
9. (장애 진단) 네이티브 빌드를 추가한 뒤 CI 러너가 exit 137로 죽는다. 무엇을 보고 어떻게 바꾸나?
10. (장애 진단) Spring Boot 네이티브 이미지에 `--spring.profiles.active=prod`를 줬는데 빈 구성이 바뀌지 않는다. 왜인가?
