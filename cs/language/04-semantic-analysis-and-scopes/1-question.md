# language/04-semantic-analysis-and-scopes — 질문

## 질문

1. (왜) 파서를 통과한 프로그램에서 의미 분석이 따로 잡아야 하는 오류 세 가지를 예로 들어라. 심벌 테이블에는 무엇이 들어가나?
2. (그림) 전역 `{total, rate}`, 함수 `{price, total}`, 블록 `{i}`가 있을 때 스코프 체인을 해시 테이블의 스택으로 그려라. `i`·`total`·`rate`·`ratee`를 찾으면 각각 어디서 찾나(몇 칸 위)? 블록을 나간 뒤 `i`는?
3. (경계) 렉시컬 스코프와 동적 스코프는 무엇이 다른가? 같은 함수를 다른 곳에서 불렀을 때 결과가 어떻게 갈리는지 예를 들어라.
4. (예측) 다음 각각의 출력·결과는? (a) JS `for (var i=0;i<3;i++) fv.push(() => i)` 후 `fv.map(f=>f())` (b) 같은 코드의 `let` 판 (c) Python `[lambda: i for i in range(3)]`의 호출 결과 (d) Java `for (int i=0;i<3;i++) fs.add(() -> i)`
5. (예측) Python에서 전역 `count = 0`과 `def inc(): count += 1`을 두고 `inc()`를 부르면? 왜 그 줄보다 위의 읽기까지 영향을 받는지 실행 모델 규칙으로 설명하라.
6. (경계) Java 21에서 `int x = 1; { int x = 2; }`와 `int count; void add(int count) { count = count + 1; }`은 각각 어떻게 되나? 왜 하나는 오류고 하나는 허용인가?
7. (연결) Java는 람다가 캡처하는 지역 변수에 effectively final을 요구하는데 JS·Python은 그러지 않는다. 캡처 방식의 차이로 설명하라. JLS가 드는 이유는?
8. (그림) Python 3.12에서 `inner`가 전역 `x`와 바깥 함수의 `y`를 읽는다. `symtable`과 `dis`에서 두 이름이 어떻게 다르게 보이나? `outer`가 끝난 뒤에도 `y`가 살아 있는 이유는?
9. (장애 진단) 비동기 콜백 세 개가 전부 마지막 인덱스로 실행됐다(JS·Python 각각). 원인과 언어별 고침을 대라.
10. (장애 진단) Java에서 람다 캡처 오류를 피하려고 `int[] sum = {0}`을 캡처해 병렬 스트림에서 더했더니 합계가 실행마다 다르다. 무엇이 잘못됐고 어떻게 고치나?
