## 질문

1. (왜) 파서가 글자 대신 토큰을 받는 이유는? 토큰에는 무엇이 들어 있나? 렉서가 하지 않는 일은?
2. (예측) Java 21에서 `int c = a--b;`는 컴파일되나? 최장 일치 규칙으로 설명하고, `List<List<String>>`의 `>>`가 시프트로 잘리지 않는 이유도 JLS로 설명하라.
3. (그림) `a(b|c)*d`의 Thompson NFA를 조각 단위로 그려라. 후위 표기로 바꾸면 어떤 순서가 되나?
4. (계산) `(a+)+$`에 `aaaa!`를 넣으면 백트래킹 엔진은 바깥 `+`의 나눔을 몇 가지 시도하나? n글자일 때 일반식은? 상태 집합 시뮬레이션의 시간은?
5. (예측) 같은 `(a+)+$`·`a^n!`을 CPython 3.12, node 22, Go 1.23, Java 21에서 n=14→24로 늘리면 각각 시간이 어떻게 변할까? Java만 다른 이유는?
6. (경계) Java 21의 백트래킹 방어는 언제 꺼지나? `(a+)+$|(b)\2`와 Cox의 `a?ⁿaⁿ`가 각각 왜 지수 시간인지 설명하라.
7. (계산) `(a|b)*a(a|b)^k`의 NFA 상태 수와 DFA 상태 수는 k에 따라 어떻게 느나? 선형 엔진이 DFA를 미리 다 만들지 않는 이유는?
8. (장애 진단) 특정 요청부터 인스턴스 CPU가 100%가 되고 스레드 덤프 맨 위가 `java.util.regex.Pattern$...match`다. 즉시 조치와 근본 대처를 순서대로 대라. Cloudflare 2019-07-02 사고의 엔진·규칙 모양과 연결하라.
9. (장애 진단) 몇 KB 입력에서 `(a|b)*` 검증이 `StackOverflowError`로 죽는다. 왜 그런가? 같은 뜻으로 고친 패턴은?
10. (연결) "숫자만 허용" 검증을 `Pattern.compile("[0-9]+").matcher(s).find()`로 짰다. 무엇이 통과하나? 또 반복문 안의 `s.matches("user_[0-9]{3}")`는 무엇이 문제인가?
