# math/11-modular-arithmetic — 질문

## 질문

1. (왜) 수학의 나눗셈 정리는 나머지를 0 ≤ r < |d|로 정한다. Java `%`와 Python `%`는 각각 어떤 규칙이고, 차이는 몫을 어떻게 반올림하느냐와 어떻게 이어지나?
2. (예측) Java에서 `-7 % 3`, `-7 / 3`, `Math.floorMod(-7, 3)`, `Math.floorMod(7, -3)`의 값은? Python의 `-7 % 3`, `-7 // 3`, `7 % -3`은?
3. (경계) `Math.abs(Integer.MIN_VALUE)`, `Integer.MIN_VALUE / -1`, `Integer.MIN_VALUE % -1`의 값은? 왜 예외가 나지 않나? 넘침을 예외로 드러내는 메서드는?
4. (계산) ID가 0, 8, 16, 24, …인 키 1만 개를 `id mod n`으로 칸에 넣는다. n = 64, 61, 60일 때 각각 몇 칸을 쓰나? 일반식은? Java `HashMap`(256칸)에 8의 배수 `Integer` 키를 넣으면?
5. (계산) mod 7에서 3의 역원은? mod 9에서 6의 역원은 있나? 역원이 있을 조건과 구하는 방법, Java·Python에서 없을 때 보이는 형태는?
6. (경계) `(a * a) % m`을 `long`으로 계산하는 빠른 거듭제곱은 m이 얼마까지 안전한가? m이 그 경계를 1 넘었을 때 무작위 테스트 10만 건으로 버그를 잡을 수 있을까?
7. (장애 진단) Java 주문 서비스와 Python 정산 배치가 같은 해시값으로 샤드를 고르는데, 일부 주문만 배치에서 "없음"으로 나온다. 원인과 대처는?
8. (장애 진단) 0~255 무작위 바이트를 `% 10`해서 숫자 인증 코드 자리를 만든다. 무엇이 문제이고 어떻게 고치나?
9. (연결) PostgreSQL이 32비트 XID를 비교하는 방식과 링 버퍼 인덱스는 이 노트의 어떤 개념인가? 링 버퍼 용량을 2의 거듭제곱으로 잡는 이유는?
