# math/13-linear-algebra-essentials — 질문

## 질문

1. (왜) 내적 `x·y`와 코사인 유사도는 어떤 관계인가? 내적만으로 "비슷함"을 비교하면 무엇이 섞여 들어가나?
2. (계산) 질의 `q = [1, 1, 0]`, 문서 A = `[1, 1, 0]`, B = `[6, 2, 5]`, C = `[2, 0, 12]`의 내적 순위와 코사인 순위를 각각 구하라.
3. (경계) 질의 벡터만 정규화하고 문서 벡터는 그대로 두면 내적 순위가 고쳐지나? 반대로 문서만 정규화하면?
4. (증명 한 줄) 모든 벡터의 길이가 1이면 내적·코사인·유클리드 거리가 같은 순위를 내는 이유를 식으로 보여라.
5. (예측) 노름이 로그정규 배율로 제각각인 무작위 벡터 20,000개(64차원)에서 내적 top-10과 코사인 top-10은 몇 개 겹칠까? 내적 top-10의 평균 노름은 전체 평균과 비교해 어떨까?
6. (예측) 4096×4096 `double` 행렬(134 MB)을 행 우선과 열 우선으로 합산하면 시간 비율은 대략 얼마일까? 512×512(2 MB)에서는?
7. (연결) 행렬곱의 ijk 순서와 ikj 순서는 곱셈 횟수가 같은데 왜 속도가 다른가? 두 순서의 결과는 비트 단위로 같은가?
8. (장애 진단) 임베딩 모델을 교체한 뒤 오류는 없는데 일부 검색 결과가 엉뚱해졌다. 가능한 원인과 확인 방법은?
9. (경계) 무차별 최근접 탐색의 비용은 무엇에 비례하나? ANN 인덱스를 붙였을 때 생기는 대가와 그것을 재는 방법은?
