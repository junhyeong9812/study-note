# math/04-graph-theory-basics — 질문

## 질문

1. (왜) 의존 관계를 글이 아니라 그래프로 그리면 무엇을 얻나? "순서를 정할 수 있다"와 "DAG다"는 어떤 관계인가?
2. (계산) 무방향 그래프에 정점 1,000개, 간선 5,000개가 있다. 차수의 합은 얼마인가? 차수가 홀수인 정점이 501개일 수 있나? 인접 리스트로 두면 이웃 항목은 몇 개인가?
3. (경계) 정점 n개의 유한 무방향 그래프가 트리일 조건을 간선 수로 말하라. "간선이 n − 1개"만으로 충분한가? 반례를 들어라.
4. (예측) 마이그레이션 DAG `V1 → V2, V1 → V3, V2 → V4, V3 → V4, V4 → V5`에 `V5 → V2`를 더했다. Kahn 알고리즘은 몇 개를 꺼내고 멈추나? 3색 DFS는 무엇을 보고하나? 방문 표시 없는 재귀 해석은 어떻게 끝나나?
5. (경계) 방향 그래프 a → b, a → c, b → d, c → d에 사이클이 있나? "이미 방문한 정점을 다시 만나면 사이클" 판정이나 union-find 판정을 쓰면 어떻게 되나?
6. (연결) 사이클이 있는 의존 그래프에서 순서를 정해야 한다면 수학적으로 무엇을 할 수 있나? (강연결 요소)
7. (장애 진단) Spring Boot를 2.5에서 2.6으로 올린 뒤 기동이 `BeanCurrentlyInCreationException`으로 실패한다. 그래프로 무엇이 일어났나? 임시 조치와 근본 조치는?
8. (연결) 빌드 서버에 코어를 64개로 늘렸는데 빌드 시간이 거의 줄지 않았다. DAG의 어떤 성질로 설명하나?
9. (장애 진단) `jstack`에 `Found one Java-level deadlock`이 찍혔다. 이것을 그래프로 해석하고, 재발을 막는 설계 원칙을 그래프 성질로 설명하라.
