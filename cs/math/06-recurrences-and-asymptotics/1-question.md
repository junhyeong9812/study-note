# math/06-recurrences-and-asymptotics — 질문

## 질문

1. (왜) 하노이 탑 T(n) = 2T(n−1) + 1과 병합 정렬 T(n) = 2T(n/2) + n − 1은 모양이 비슷한데 왜 해가 전혀 다른가? 무엇이 성능을 정하나?
2. (그림) T(n) = 2T(n/2) + n의 재귀 트리를 세 층 그리고 층별 일과 층 수로 해를 구하라. 같은 방법으로 4T(n/2) + n과 2T(n/2) + n²은 어느 층이 지배하나?
3. (계산) 마스터 정리로 풀어라: (a) T(n) = 3T(n/2) + n (b) T(n) = T(n/2) + 1 (c) T(n) = 8T(n/2) + n³ (d) T(n) = 2T(n/2) + n log n. 각각 몇 번째 경우인가?
4. (경계) T(n) = 2T(n/2) + n / log n과 T(n) = T(n−1) + n에 마스터 정리를 쓸 수 있나? 쓸 수 없으면 무엇으로 푸나?
5. (예측) 실험의 `remove(0)` 반복은 n = 10만에서 약 1.3~1.4초였다. n = 20만, 30만이면 대략 얼마인가? 어떤 점화식으로 그렇게 예측했나?
6. (예측) 메모 없는 피보나치의 호출 수는 n이 4 늘 때마다 몇 배가 되나? n = 32의 호출 수 7,049,155를 닫힌 꼴로 설명하라.
7. (장애 진단) 연결 리스트를 재귀로 뒤집는 코드가 노드 1만 개에서는 되고 10만 개에서 `StackOverflowError`를 낸다. 점화식으로 원인을 설명하고 고쳐라.
8. (장애 진단) 재귀로 리스트 합을 구하는 코드가 `new ArrayList<>(xs.subList(1, xs.size()))`를 넘긴다. 입력이 2배가 되면 시간은? 깊이는? 어떻게 고치나?
9. (연결) 동적 배열을 2배씩 키울 때 총 복사량이 O(n)인 이유와, 쿠폰 수집 기댓값이 n ln n 근처인 이유를 각각 어떤 급수로 설명하나?
