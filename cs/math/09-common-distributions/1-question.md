# math/09-common-distributions — 질문

## 질문

1. (왜) 다음 상황은 각각 어떤 분포로 세나? ① 요청 1000건 중 실패 수 ② 첫 성공까지 재시도 횟수 ③ 초당 도착 수 ④ 다음 요청까지의 시간 ⑤ 키별 요청 빈도의 순위 분포. 각 분포의 평균은?
2. (예측) 칸 2^20개에 무작위 키 2^19개를 넣으면 빈 칸·길이 1·길이 2인 칸의 비율은 대략 얼마인가? 최대 칸 길이는 어느 정도일까? Java `HashMap` 주석의 표와 어떻게 연결되나?
3. (경계) 이항분포를 포아송으로 근사해도 되는 조건은? 포아송 과정의 정의(독립 증분)가 운영 트래픽에서 깨지는 원인 세 가지를 들어라.
4. (예측) 평균 100/s인 포아송 트래픽과, 10%의 초는 550/s·나머지는 50/s인 버스트 트래픽의 분산과 p99는? 포아송 p99(124/s)에 맞춘 용량은 각 트래픽에서 몇 %의 초에 넘치나?
5. (계산) 시도마다 성공 확률 0.3인 작업의 평균 시도 수는? 이미 3번 실패했을 때 앞으로 5번 더 실패할 확률은? 이 계산이 장애 상황에서 틀리는 이유는?
6. (경계) 로그정규 지연(평균 33.0ms, 표준편차 43.2ms)에서 "p99 ≈ 평균 + 2.326σ"로 어림하면 얼마이고, 실제 p99는 얼마인가? 왜 다른가?
7. (예측) 키 10만 개, Zipf(s=1) 접근에서 1위 키의 요청 비율은? 키의 1%를 LRU로 캐시하면 적중률은 대략? s=0.8이면?
8. (연결) Zipf 접근은 캐시와 샤드에 각각 어떤 영향을 주나? 샤드 16개에서 최대 샤드 부하가 평균의 약 2배가 되는 이유를 1위 키 비율로 설명하라.
9. (장애 진단) 분당 지표는 평온한데 특정 초마다 `RejectedExecutionException`과 503이 몰린다. 무엇을 측정해 원인을 가르고, 어떻게 대처하나?
