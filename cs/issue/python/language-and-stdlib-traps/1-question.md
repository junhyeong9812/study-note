## 질문
1. (예측) JSON 메시지 `{"cols": true, "rows": true}`가 "1~500 사이 정수" 검증 `isinstance(cols, int)`를 통과할까? 통과한다면 왜이고, 정수만 받으려면 무엇으로 검사해야 하는가? 같은 계열로 `next_v in "ei"`에서 `next_v == ""`이면 결과는?
2. (왜) `self.index = read_index(new_path)` 한 줄로 수백 GB짜리 객체를 교체하다 메모리가 순간 2배가 됐다. 대입문의 평가 순서로 설명하라. 또 정리 코드를 `except` 블록 안에 두자 `del obj`가 효과가 없었다 — 무엇이 그 객체를 붙들고 있었는가?
3. (경계) 동적 언어에서 "없는 속성·잘못된 시그니처·튜플을 dict처럼 쓰기" 같은 결함이 import·기동·단일 키워드 테스트를 다 통과하고 특정 입력에서만 500을 낸다. 왜 그런가? 인스턴스 메서드를 `Class.method(a, b)`로 부르면 인자가 어떻게 밀리는가?
4. (예측) `logger.debug(json.dumps(query, indent=2))`는 로그 레벨이 INFO일 때 비용이 0인가? `hit.get("_score", 0)`은 `_score`가 JSON `null`이면 무엇을 돌려주는가? 관찰용 코드가 어떻게 정상 요청을 500으로 만들 수 있는가?
5. (경계) 표준 라이브러리·ORM의 "기본값"이 데이터를 조용히 제한하거나 빠뜨린 사례를 들어라 — csv 필드 크기, 정규식 방언, JSON 인코더, ORM 쪽 기본값과 raw SQL. 각각 어느 경계에서 터지는가?
6. (왜) `ProcessPoolExecutor(max_workers=5)`를 썼는데 워커 하나만 일했다. `asyncio`로 짠 크롤러도 순차로 돌았다. 두 사건의 공통 원인은 무엇인가? 또 `Pool`의 initializer가 예외로 죽으면 호출자는 무엇을 보게 되는가?
7. (연결) 이 카드의 함정들은 모두 "드문 경로에서만 터진다". 이 부류의 결함을 개발 중에 찾아내는 수단(전 경로 실행 테스트·정적 검사·경계값 테스트·실제 메모리 계측)을 사례와 연결해 설명하라.
