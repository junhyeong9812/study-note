## 질문

1. (왜) async 함수 안에서 `showLoader()`(state를 true로 바꿈)를 부른 뒤 같은 함수에서 `if (!isLoading) throw new Error("stop")`을 검사했더니 **항상** 실패했다. 함수 컴포넌트의 클로저와 렌더 스냅샷으로 설명하라. 왜 ref는 최신 값을 읽을 수 있는가?

2. (예측) 입력 잠금 여부를 state로 두고, 마운트 때 한 번 등록한 외부 라이브러리 콜백(`term.onData`)에서 그 state를 검사했다. 잠금을 켠 뒤 입력하면 막히는가? 수명이 긴 콜백이 최신 값을 읽게 하려면?

3. (경계) 드래그 중 `dragover`에서 `setZone(...)`하고 `drop`에서 `zone`을 읽었더니, 미리보기와 실제 드롭 위치가 달랐다. React가 두 이벤트의 업데이트를 어떻게 다른 우선순위로 처리하길래 drop 시점 state가 오래됐는가? "drop 자신의 좌표로 다시 계산"이 왜 근본 해법인가?

4. (예측) [보내기] 버튼 핸들러가 `if (sending) return; setSending(true); await send();`이다. 같은 틱에 두 번 클릭되면 몇 번 보내지는가? "존재 확인 후 생성"(check-then-act)이 같은 문제를 갖는 이유는?

5. (경계) 스테퍼 버튼이 `setFont(font + 1)`을 쓴다. 빠르게 연타하면 값은 클릭 수만큼 오르는가? 입력칸을 비웠을 때 `Number("")`는 무엇이며, 왜 "빈 값"이 유효 숫자로 통과하는가?

6. (연결) effect를 강제로 재실행(세대 state 증가)시켰는데 effect가 아직 전파되지 않은 **옛 props**로 옛 세션에 다시 붙었다. 외부 라이브러리의 파라미터 갱신이 다음 렌더 props에 즉시 반영된다는 보장이 없을 때, 새 값을 effect에 어떻게 전달하는가?
