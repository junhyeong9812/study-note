# cs/issue/typescript/react/dependent-state-reset — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

```
상위 데이터 / 컨텍스트            종속 상태 (거기서 파생되었거나 그 안을 가리킴)
─────────────────────            ──────────────────────────────────────────────
목록 (스캔 결과)          ──▶     selectedId            ── 사라진 항목 → 없는 경로에 쓰기
데이터 길이               ──▶     scrollTop → start      ── start > length → 빈 화면
보이는 항목 목록          ──▶     선택 앵커 → findIndex  ── -1 → 처음/끝으로 점프
데이터의 키 집합          ──▶     기본 선택 = max(key)   ── 키 추가 → 초기 화면 탈취
입력 prop (src)           ──▶     failed 플래그          ── 새 src 인데 옛 실패 표시

   상위가 바뀜 ──(재검증 없음)──▶ 종속 상태가 유령 참조가 됨

[교정]
   상위 변경 지점에서:  재검증(아직 있으면 유지, 없으면 null)  또는  리셋
   파생 인덱스:         경계로 clamp
   앵커:                사라질 때 "남는 조상"으로 승격 · 닫기 경로는 앵커 유지
   기본값 파생:         파생 원천에 키를 추가하는 코드를 제한
   출처 변수 하나:      const target = selected ?? active  → 모든 호출이 이 변수만 사용
```

## 핵심 문장

- 종속 상태는 **자기가 가리키는 목록·컨텍스트의 수명**을 따른다 — 상위가 바뀌면 재검증하거나 리셋한다.
- 파생 인덱스(scrollTop → start)는 데이터 길이가 바뀌면 범위를 벗어난다 — 리셋 + clamp.
- 앵커(선택)가 파생 목록에서 사라지면 탐색이 -1로 떨어진다 — 사라지기 직전 보이는 조상으로 **승격**한다.
- "데이터에서 기본값 파생"은 데이터에 키를 더하는 모든 코드와 암묵 결합된다.
- prop에서 파생한 로컬 state(실패 표시 등)는 prop이 바뀔 때 리셋한다.
- 일부가 오래된 값이 설계라면 **어느 값이 라이브이고 어느 값이 스냅샷인지** 명시적으로 나눈다.
