# cs/issue/typescript/next/absolute-imports-and-per-tool-resolver — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

**한 문장:** 상대 임포트는 "파일의 현재 위치"를 기준점으로 삼아 파일이 이사하면 깨지므로 **절대경로(`@/...`)로 고정**하고, 그 alias는 프로젝트 한 곳이 아니라 **모듈을 찾는 도구마다(빌드·타입체크·테스트 러너) 따로** 알려줘야 한다 — 각 도구가 자기 리졸버를 갖기 때문이다.

### 원리 ① — 상대 임포트는 파일 위치가 기준점이라 이사에 깨진다

```
[상대 임포트]  from "./logger"   기준점 = "이 파일이 지금 있는 폴더"
   backend.ts 가 lib/ → shared/api/ 로 이사
   → "./logger" 는 이제 shared/api/logger 를 가리킴 → 실제 파일 없음 → 깨짐

[절대 임포트]  from "@/shared/lib/logger"   기준점 = 프로젝트 src 루트(고정)
   backend.ts 가 어디로 이사하든 가리키는 대상 불변 → 안 깨짐
```

`git mv`로 파일을 옮긴 뒤 일괄 치환은 `@/lib/...`(문자열이 고정적)만 바꿨고, `./logger`·`./backend` 같은 상대 임포트는 치환 대상 문자열이 아니어서 그대로 남아 깨졌다. 빌드가 **한 번에 하나씩만** 알려줘 고치고-빌드를 3회 반복. 근본 원인은 개별 실수가 아니라 **상대·절대가 정책 없이 섞여 있던 것** → 정책 확정: `@/...` 절대경로만, 같은 폴더 안이라도.

### 원리 ② — alias는 도구마다의 설정 (리졸버는 도구마다 별도)

```
같은 임포트 "@/features/wiki/lib/tree" 를 세 도구가 각자 해석한다:

  Next(빌드)      ─┐
  tsc(타입체크)   ─┼─▶ tsconfig.json 의 paths: {"@/*": ["./src/*"]} 를 읽음  ✅
  vitest(테스트)  ─┘        ↑ 이 둘만 읽는다
       └─▶ 자기 리졸버(vite) 사용 → tsconfig.paths 를 안 봄 → "모듈 못 찾음"  ❌
```

`@` alias 정의가 `tsconfig` 한 곳에만 있으면 Next·타입체커는 OK, vitest만 깨진다. vitest는 vite의 리졸버를 쓰므로 **같은 alias를 `vitest.config.ts`에도 또** 알려줘야 한다.

```
[기존]  alias 정의 = tsconfig(paths) 한 곳     → vitest "모듈 못 찾음"
[변경]  alias 정의 = tsconfig + vitest.config  → 세 도구 모두 해석
```

포인트: `tsconfig`의 `paths`는 **타입체커·에디터·번들러가 참고하는 힌트**지, 런타임 모듈 해석 규칙이 아니다(`moduleResolution: "bundler"`, `noEmit`). 그래서 실제로 모듈을 로드하는 각 도구(vite 등)에 alias를 별도로 심어야 한다. **①을 채택하면 ②가 필연으로 따라온다** — 절대경로를 쓰는 순간, 그 절대경로를 이해해야 하는 모든 도구에 alias를 등록해야 하기 때문.

## 핵심 문장

- 상대 임포트의 기준점은 "파일의 현재 위치" → 파일 이사에 깨진다. 절대경로(`@/`)의 기준점은 고정된 src 루트 → 안 깨진다.
- 일괄 치환은 상대 임포트를 못 고친다. 근본 원인은 개별 실수가 아니라 상대/절대 혼용이라는 **정책 부재**.
- 정책: `@/...` 절대경로만, 같은 폴더 안이라도. 파일 이동이 임포트를 못 깨뜨리게.
- alias는 "프로젝트 설정"이 아니라 **도구마다의 설정** — 빌드·타입체크·테스트 러너가 각자 리졸버를 가진다.
- `tsconfig.paths`는 타입체커·번들러용 힌트일 뿐, 런타임 리졸버는 도구별로 따로(vitest는 `vitest.config.ts`).
- 절대경로 정책(①)을 채택하면 도구별 alias 등록(②)이 필연으로 따라온다.
