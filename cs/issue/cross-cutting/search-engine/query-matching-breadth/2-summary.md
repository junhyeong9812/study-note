# cs/issue/search-engine/query-matching-breadth — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

```
의도: "이 이름 / 이 발음 / 이 인접 구문"과 맞는 문서
                      │
     매칭 단위가 의도보다 작거나 거칠면 → 넓어진다
                      │
 ┌────────────────────┼──────────────────────────────────────────────────────┐
 │ match (full-text)  │ 검색어 → 토큰들 → 기본 OR                               │
 │                    │ 흔한 토큰 1개 일치 = 매칭  ──▶ 수백만 건                  │
 │                    │ should+msm:1 로 0건 절과 묶이면 넓은 쪽이 그대로 결과       │
 │   교정             │ match_phrase(순서·인접) / operator:"and"                 │
 ├────────────────────┼──────────────────────────────────────────────────────┤
 │ match + fuzziness  │ 토큰마다 퍼지 + OR ──▶ 쪼개진 조각에 오타 매칭 · 첫 음절 치환 │
 │   교정             │ fuzzy/term (term-level, 전체 값 단위) on keyword 서브필드  │
 │ fuzzy (term-level) │ 다토큰 질의 = 한 term ──▶ 매치 불가 / 1음절 term ──▶ 광역  │
 │   교정             │ match(분석 후 토큰별) · 색인측 변형 보강                   │
 ├────────────────────┼──────────────────────────────────────────────────────┤
 │ ngram(letter)      │ 한글 음절도 2~10gram ──▶ "ab"가 "xxabyy" 내부에 걸림       │
 │   교정             │ 자모 시퀀스 1토큰 정확 match · ngram은 정규화 필드에만        │
 ├────────────────────┼──────────────────────────────────────────────────────┤
 │ 자질 합집합 배열     │ 위치 정보 없음 ──▶ 부분집합 조건 거의 항상 참 ──▶ prefix처럼 │
 │   교정             │ 단일 발음만 색인 or 위치를 별도 차원으로                     │
 ├────────────────────┼──────────────────────────────────────────────────────┤
 │ ngram + phrase/slop│ position이 단어 단위 아님 ──▶ 인접 의미 불성립 ──▶ 0건       │
 │   교정(방향)        │ 단어 단위 분석 필드에 span_near                           │
 ├────────────────────┼──────────────────────────────────────────────────────┤
 │ 음성 인코더         │ 짧은 입력 → 소수 코드로 붕괴 ──▶ 변별력 상실 · TF 노이즈      │
 └────────────────────┴──────────────────────────────────────────────────────┘
```

## 핵심 문장

- `match`는 토큰 **OR**이다 — 흔한 토큰 하나가 결과를 폭발시킨다.
- 넓은 절을 `should` + msm:1로 다른 절과 묶으면 **과다매칭이 숨는다**.
- full-text 퍼지는 **토큰마다**, term-level 퍼지는 **값 전체**에 걸린다 — 의도한 비교 단위를 고른다.
- n-gram·자질 합집합은 **위치·경계 정보**를 잃는다 — 부분문자열·부분집합 매칭이 과도하게 참이 된다.
- phrase/slop은 **단어 단위 position**을 전제한다.
- 쿼리 종류와 토큰화 단위를 **의도에 맞춘다**.
