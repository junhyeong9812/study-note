## 질문
1. IEEE-754에서 `NaN == NaN`은 무엇을 반환하는가. 이것이 동치 관계의 세 조건(반사성·대칭성·추이성) 중 어느 것을 깨뜨리는가.
2. 부동소수점 값을 (직접이든 동적 JSON 값 타입 안에든) 담은 구조체에 "완전한 동치(Eq)"를 선언할 수 없는 이유는 무엇인가. "부분 동치(PartialEq)"만 남기면 무엇을 잃는가(해시 맵 키 등).
3. 예측: 특수값 탐지를 `if (v == Float.NaN)`으로 쓰면 어떤 입력에서 이 분기가 실행되는가. 올바른 탐지는 무엇인가.
4. 코드 생성기가 값을 `toString()` 결과 그대로 소스 코드 리터럴로 박으면, NaN·±Infinity에서 생성 코드가 왜 컴파일되지 않는가. 어떻게 출력해야 하는가.
5. 경계: 코드 생성에서 특수값 분기를 "유한값 출력" 폴백보다 **앞**에 둬야 하는 이유는 무엇인가.
6. 연결: "값을 문자열로 바꿨다가 다시 해석한다(왕복)"는 관점에서 NaN 리터럴 문제는 직렬화·파싱 계약 문제와 어떻게 닮았는가.
