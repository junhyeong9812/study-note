# cs/issue/data/input-format-detection — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

```
입력 ──(형식 가정)──▶ 파서/렌더러 ──▶ 결과
         │
         ├─ 이름·경로로 형식 추정   /rss/... 인데 실제 Atom     → <item> 0건 (HTTP 200)
         ├─ 소스 간 구분자 동일 가정  , vs ;                    → 필드가 꼬인 채 적재
         ├─ 스칼라 가정             셀 = (번호,날짜) 반복         → 첫 쌍만, 나머지 소실
         ├─ 렌더 형식 가정          코드 파일 → 마크다운 렌더     → 태그 해석, 조용히 뭉개짐
         │                          마크다운 분석문 → 평문 출력   → ** ## 기호 노출
         ├─ 대상 종류 미판정        **/* glob                     → 비대상 수천 건 흡수
         └─ 주석 문법 가정          // 전제 파서                  → /* */ 블록 주석 놓침
                     │
                     └─ 공통: 예외 없음 → 결과가 "그럴듯함" → 늦게 발견 (silent)

[교정]
   형식을 내용으로 판정     네임스페이스 붙은 <entry> + href 속성, id 없으면 link 폴백
   소스별 형식 명세         전처리 사양 재정의 후 재적재
   다중값을 1급으로         자식 테이블 + 무손실 페어링 파서, 필드 크기 한도 상향
   판정 → 경로 선택         domain=='code' || 코드 확장자 → <pre> / 분석문 → 마크다운 렌더
   allowlist               언어별 확장자 목록으로 재수집
   검증                    같은 변환으로 기대 카디널리티 계산 → DB COUNT 대조
```

## 핵심 문장

- 형식 가정이 틀리면 파서는 **예외 없이** 0건·첫 값·꼬인 필드를 낸다 — 에러보다 늦게, 더 넓게 퍼진다.
- URL·파일명·경로는 **형식을 보장하지 않는다** — 내용(루트 요소·네임스페이스·확장자+도메인)으로 판정한다.
- 데이터 종류 판정은 **처리 경로 선택보다 먼저** 온다.
- 스칼라 파서는 다중값 입력을 **조용히 절단**한다 → 기대 카디널리티를 독립 계산해 대조한다.
- 수집 대상은 blocklist가 아니라 **allowlist**로; 제약(UNIQUE)은 중복만 막지 잘못된 대상은 못 막는다.
