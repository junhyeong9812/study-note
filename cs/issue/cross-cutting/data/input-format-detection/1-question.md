## 질문
1. 형식 가정이 틀렸을 때 왜 예외가 아니라 "그럴듯한 잘못된 결과"가 나오는가. 파서가 "0건"이나 "첫 값만"을 돌려주는 것이 왜 에러보다 위험한가.
2. 예측: 경로가 `/rss/news`인 피드를 RSS 파서(`findall("item")`)로 읽었더니 HTTP 200인데 0건이었다. 실제 형식은 무엇이었고, 네임스페이스와 링크 표현은 어떻게 달랐는가.
3. 한 셀에 (번호, 날짜) 쌍이 반복되는데 파서가 스칼라를 가정해 첫 쌍만 취했다. 이 절단을 어떻게 발견하고, 무손실 적재가 맞는지 어떻게 검증하는가. 멀티라인 CSV를 `head`로 샘플링하면 안 되는 이유는?
4. 여러 소스의 같은 필드가 서로 다른 구분자(`,` vs `;`)를 쓰는데 한 규칙으로 `split`했다. 이 오류를 파이프라인 안에서 잡으려면 무엇을 검사했어야 하는가.
5. 경계: 범용 마크다운 렌더러에 `.html/.css/.js` 코드 파일을 넣으면 무슨 일이 생기는가. "데이터 종류 판정이 렌더 경로 선택보다 먼저"라는 원칙은 어떤 이중 신호로 구현됐고, 남은 사각지대는 무엇인가.
6. 재귀 glob `**/*`로 자료를 수집했더니 비대상 파일까지 수천 건 적재됐다. UNIQUE 제약이 이것을 막지 못한 이유는 무엇이며, blocklist와 allowlist 중 무엇을 골랐는가.
