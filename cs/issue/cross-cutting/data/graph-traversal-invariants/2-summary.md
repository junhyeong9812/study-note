# cs/issue/data/graph-traversal-invariants — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

```
외부 데이터 ──파싱──▶ 링크(부모/자식/prev/심링크) ──순회·배치──▶ 화면/결과
                         │
                         ├─ 자기참조·사이클 ─▶ visited 없음 → 무한 재귀 → 스택 오버플로
                         │                      └─ 렌더 중 예외 → 경계 없으면 앱 트리 전체 언마운트(빈 화면)
                         ├─ 부재 노드       ─▶ "다음"을 본문에서 읽음 → 본문 없음 = 종단 오인 → 체인 상실
                         ├─ 순수 사이클     ─▶ head(진입차 0) = 공집합 → 통째로 무음 누락
                         ├─ 수렴(DAG 합류)  ─▶ 같은 부모를 두 레인에 → 한 노드가 두 줄
                         └─ 심링크 루프     ─▶ 재귀 파일 탐색이 같은 경로를 두 번 만남

[교정]
   visited Set (재귀 진입 직전 검사)            → 사이클도 유한 종료 + 중복 key 방지
   다음 포인터는 별도 메타(사이드카)에서         → 본문 부재 ≠ 종단
   head 순회 후 미방문 노드를 fallback head로     → 순수 사이클도 노출
   부모가 이미 대기 중이면 현재 레인 종료(합류)
   트리 이동: 자기 자신 + 마지막 원소면 no-op, "leaf ≥ 1" 불변식

[다른 방안 — 파일시스템 워크]
   심링크 미추적 + 경계(.git 발견 시 하강 중단) + 깊이/개수/방문 예산
   (또는 입력 쪽에서 순환 구조 자체를 제거: 링크 구조 마운트를 탐색 경로에서 분리)
```

## 핵심 문장

- 외부 데이터로 만든 링크 구조는 **트리라는 보장이 없다** — 자기참조·사이클·부재 노드·합류를 기본값으로 가정한다.
- 사이클 가드는 **visited 집합**. 깊이 제한은 정상적인 깊은 구조를 잘라 버린다.
- "다음"을 없을 수 있는 곳(노드 본문)에서 읽으면 **부재가 종단으로 오인**된다.
- "진입차 0 = head" 정의는 사이클에서 **공집합** → 미방문 노드를 따로 거둬야 무음 누락이 없다.
- 탐색의 종료성은 **순환 차단 + 폭·깊이 예산**이 모두 있어야 보장된다.
