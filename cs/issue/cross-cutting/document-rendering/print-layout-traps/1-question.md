## 질문
1. (왜) 고정 높이 `.page` div로 쪽을 표현하는 HTML에서 닫는 `</div>`가 하나 중복됐다. 브라우저는 에러를 내는가? 그 뒤의 요소(푸터·다음 쪽)는 어디로 가는가.
2. (예측) `.page { padding-bottom: 14mm }`와 `.footer { position: absolute; bottom: 10mm }`가 서로 참조 없이 따로 정해져 있다. 본문이 길어지면 무엇이 겹치는가. 이 두 값의 "관계"를 어떻게 명시하는가.
3. (경계) 인쇄(paged media)에서 `position: fixed` 푸터는 왜 모든 쪽에서 잘리거나 텍스트 추출 0건이 되는가. 쪽 번호를 안정적으로 넣는 CSS 수단은 무엇인가.
4. (예측) `column-count: 1`은 "단 없음"과 같은가? 큰 블록에 `break-inside: avoid`를 걸면 쪽 경계에서 무엇이 생기는가.
5. (왜) 문서 생성 라이브러리에서 이미지에 `width`만 주면 셀 밖으로 넘치는 이유는. 셀 폭과 이미지 가용 폭은 왜 다른가(셀 기본 여백).
6. (경계) 스프레드시트 라이브러리에서 이미지를 문자열 셀 주소(`"B2"`)로 붙이면 위치 오프셋은 무엇인가. 표의 열 폭 격자(grid)를 명시하지 않으면 워드 프로세서는 열 폭을 어떻게 정하는가.
7. (연결) 1~6번의 공통점 — "기본값·자동 복구가 조용히 결정한다". 이런 레이아웃 결함을 잡는 검증은 무엇이어야 하는가.
