# document-rendering — 텍스트·인쇄 레이아웃

문서를 화면·인쇄·오피스 파일로 렌더할 때의 패턴이다.\
공통 원리: **서구 텍스트 기준으로 정한 규칙·기본값은 CJK와 인쇄 매체에서 에러 없이 무너진다** — 값들 사이의 관계를 명시하고 실제 출력으로 확인한다.

## 공통 원리

```
  원문 ──▶ 파서(자동 복구) ──▶ 레이아웃(폰트·폭·페이지) ──▶ 출력
             │                     │
             │                     ├─ 고정폭 = 1칸 가정 → 한글 폭 어긋남
             │                     └─ 인쇄 CSS·기본 크기 → 잘림·넘침
             └─ 구분자 규칙이 문자체계에 따라 다름
                                   ▼
                     에러 없이 깨진 출력
```

## 패턴 카드

- [cjk-vs-western-text-rules](cjk-vs-western-text-rules/) — 서구 기준 텍스트 규칙(폰트 메트릭·monospace 폴백·고정폭=1칸·CommonMark 구분자 규칙)은 CJK에서 깨진다 — 한글의 폭·폰트·문장부호 경계를 명시적으로 다룬다.
- [print-layout-traps](print-layout-traps/) — 문서 레이아웃(인쇄 CSS·HTML 파서 자동 복구·docx/xlsx 기본 크기)은 에러 없이 조용히 무너진다 — 독립적으로 정한 값들의 관계를 명시하고 실물로 확인한다.
