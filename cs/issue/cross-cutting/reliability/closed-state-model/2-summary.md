# cs/issue/reliability/closed-state-model — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

```
 타입이 허용하는 값 공간  ⊋  도메인 불변식이 허용하는 공간
        └── 차이 = 불법 상태 → 컴파일 통과 → 런타임 오보고·보안 결함·교착

[값 공간 열림]                          [닫는 법]
 optional 쌍 (둘 다 없음/둘 다 있음)    → 판별 유니온
 kind: string                          → 리터럴 유니온 (리네임 시 컴파일 에러)
 f(&str, &str) 인자 뒤집기 컴파일됨     → 서로 다른 타입 (root: &Path, path)
 Option<root> → 무루트 legacy 경로      → 필수 인자
 Option<key> + default → 구버전 수용    → 필수 필드 (파싱 단계 거부)
 bool alive → pending ≡ dead           → 3상태 (pending/running/dead)
 결과 enum이 곱집합 일부만              → 모든 조합에 이름 (Lost 등)

[전이 열림]
 종단 → 종단 재전이 허용    → CAS 2회 성공 → 카운터 이중 감산 → 용량 영구 초과
 검사 없는 set             → 취소·승인 섞임, 취소가 작업을 못 멈춤
     → check-and-set(소유자 identity + 선행 상태) · 위반 시 협조 중단
 guard에 비단조 외부 입력    → 영원히 false → 고착 (liveness 위반)
     → 전이는 시간만으로 단조, 외부 입력은 "행동" 레이어에서만 보류
```

## 핵심 문장

- 타입이 허용하는 공간을 **도메인 불변식까지 좁혀라** — 불법 상태는 표현 자체가 안 되게.
- 버전 경계를 긋는 필드는 **필수**로 — 파서가 옛 형식을 조용히 받아들이지 않게.
- 불리언 하나로 **세 상태**를 판정하지 마라.
- 결과 열거형은 **독립 조건의 곱집합**을 전부 덮는다. 프로세스 신원은 `(pid, start_time)`.
- 종단 상태는 **재전이 금지**, 전이는 **현재 상태·소유자 확인 후** set.
- 전이 guard에는 **단조 입력(시간)**만 — 외부 상태는 행동을 보류할 뿐 전이를 막지 않는다.
