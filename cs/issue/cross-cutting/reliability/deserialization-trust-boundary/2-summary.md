# cs/issue/reliability/deserialization-trust-boundary — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

```
 디스크·외부 바이트 ──parse──▶ [경계] ──▶ 타입 있는 도메인 값
   (구버전 코드가 쓴 값,          ↑ 여기서 컴파일 타임 보장이 끊긴다
    버그 입력, 수동 편집,          캐스트(as T)는 검증이 아니다
    미래 버전, 악의적 입력)

 경계에서 할 일                       안 하면
 ─────────────────────────────────  ────────────────────────────────────────
 필드별 타입·범위 검증·정규화         .filter 크래시 · fontSize -5 · union 불변식 파괴
 새 필드 default (하위호환)           구버전 파일 "missing field" 로드 실패
 버전 게이트 + 의미 검증              미래/손상 데이터를 "모양이 맞으니" 정상 수용
 요소별 파싱 (부분 손상 격리)          블록 하나 손상 → 형제 블록 전부 유실
 드롭 카운트·로그 (관측)              포맷 드리프트가 에러 없이 기능 소실로
 깊이·노드 예산 + 파서 전체 try        12k 깊이 유효 JSON → 스택 오버플로 → 시작 크래시
 모르는 열거값 분기 + 표준 이름        미지 채널 데이터 무음 드롭 · Debug 문자열 와이어 누출
 요청 모델 = 실제 송신 형태           미선언 키 버려짐 → None → 필터 무시 / 먼 곳에서 속성 오류
```

## 핵심 문장

- 역직렬화 경계에서 **타입은 주장일 뿐**이다 — 로드 시 검증·정규화해야 보장이 된다.
- 부분 손상은 **격리**하되, 드롭은 반드시 **관측**한다(관용 파싱의 대가는 관측성).
- 스키마 진화: **과거는 default로 수용**, **미래·손상은 버전 게이트로 거부**.
- 재귀 검증에는 **깊이·노드 예산**, 예외 경계는 **파서 전체**를 덮는다.
- 확장 열거값은 **"모름" 분기를 명시**, 외부로 나가는 이름은 **표준 이름으로 정규화**.
- 선언적 모델은 "**선언된 것만 채운다**" — 송신 형태와 선언을 맞춘다.
