## 질문
1. `localStorage`·설정 JSON에서 읽은 값을 `as Mode`로 캐스트하거나 얕은 머지로 상태에 넣으면 왜 타입 시스템의 보장이 성립하지 않는가. 영속 저장소가 돌려줄 수 있는 "타입과 다른 값"의 출처 세 가지는?
2. `Vec<Block>`을 통째로 역직렬화할 때 블록 하나만 깨져 있으면 무엇이 사라지는가. 요소별로 파싱해 실패를 건너뛰면 무엇을 얻고, 그 대가로 무엇(관측성)을 잃는가 — 그것을 어떻게 되찾는가.
3. 예측: 스냅샷 구조체에 새 필드를 추가하고 배포했다. 사용자 디스크에는 구버전 파일이 있다. 엄격한 역직렬화는 어떻게 되는가. 반대로 **미래 버전**이 쓴 파일을 "모양만 맞으면 수용"하면 어떤 위험이 있는가.
4. 재귀 구조(트리)를 외부 데이터에서 검증할 때 예산(깊이·노드 수)이 없으면 12k 깊이의 **유효한** JSON은 무슨 일을 일으키는가. 예외 경계가 `JSON.parse`만 감싸고 있으면 왜 부족한가.
5. 확장 가능한 프로토콜 열거값(예: 확장 데이터 채널 번호·시그널 이름)을 받을 때 "모르는 값" 분기가 없으면 무엇이 사라지는가. 또 내부 Debug 표현(`format!("{:?}")`)을 와이어에 그대로 쓰면 무엇이 문제인가.
6. 경계: 선언적 요청 모델(Pydantic 등)에 프론트가 보내는 키가 선언돼 있지 않거나, 타입이 `Optional[bool]`인데 실제로는 `["no_x"]` 리스트가 온다. 필터는 어떻게 동작하는가 — 왜 에러가 아니라 "기능이 조용히 꺼짐"으로 나타나는가. 파생(computed) 필드를 원본 dict에서 읽으면?
7. 연결: "견고하게 받아들이기(관용 파싱)"와 "잘못된 입력을 거부하기(엄격 파싱)"는 어떻게 공존하는가. 부분 손상 격리·드롭 관측·모르는 값 분기·버전 게이트가 각각 어느 쪽을 담당하는가.
