# cs/issue/cross-cutting/reliability/edge-detection-on-raw-signals — 정리 (힌트)

> 복습 시 이 파일은 **질문에 막혔을 때만** 연다. 먼저 읽고 답하면 인출이 아니라 받아쓰기다.

## 전체 흐름

```
기저 신호들 ──▶ [가공] ──▶ 관찰값 ──▶ edge 판정 ──▶ 알림/확정
                  │
                  ├─ ① 스칼라로 접기   max(blocked=3, unseen=2)
                  │     2 → 3 → 2   : "2로 돌아옴"이 새 완료처럼 보임 → 재알림
                  │     (왜 그 값이 됐나가 사라짐)
                  │
                  ├─ ② 매 tick 덮어쓰기  hold 중 seen=true → 다음 tick seenNow=false
                  │     확정 시점엔 "본 적 있음"이 사라짐 → 본 완료가 unseen 표시
                  │
                  └─ ③ 주기 샘플링     poll 2.5s, 다운 펄스 1s
                        up ─┐_┌─ up   : 샘플 사이에 끼어 "down"을 못 봄 → 완료 확인 실패

[교정]
   ① 기저 신호별 rising edge + 조합 규칙표 (blocked 우선, done = !blocked && unseen↑)
   ② 구간 래치: seenInWindow ← seen 이 한 번이라도 true 면 유지, 확정 시 합침
   ③ 세대 ID: 재시작 전 sessionId 캡처 → "값이 바뀌었나"(영구 변화)로 판정

[반대 방향 — 너무 민감한 edge]
   순간값 1샘플 ≥ 임계 → 경보   : 정기 작업 스파이크에 오경보
   → N회 연속 초과 시 발화, 샘플 누락 시 카운터 리셋
   지속 이상에 고정 간격 재발송 → 알림 피로 → 사람이 무시 = 다시 무음
   → 점증 백오프 재알림 + 해소 시 복구 통지 1회 + 배포 중 억제 스위치
```

## 핵심 문장

- 사건은 **값이 아니라 전이**다. 전이를 판정하려면 "이전 값"과 "지금 값"을 **같은 해상도로** 가져야 한다.
- 여러 신호를 스칼라로 접으면 **원인 정보가 사라진다** — edge는 기저 신호마다 따로 판정하고 조합은 규칙표로 한다.
- 지연 확정 구간 동안의 일회성 사건은 현재값 덮어쓰기로는 남지 않는다 — **래치**로 "구간 안에 한 번이라도"를 기억한다.
- 주기 샘플링은 주기보다 짧은 펄스를 원리적으로 놓친다 — 순간을 잡으려 하지 말고 **영구적으로 남는 흔적(세대 ID)**을 비교한다.
- 반대로 1샘플 edge는 잡음을 사건으로 만든다 — **지속 조건**으로 발화하고, 재알림은 **간격을 늘려** 사람이 경보를 믿게 둔다.
