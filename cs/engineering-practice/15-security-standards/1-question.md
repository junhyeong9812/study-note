# engineering-practice/15-security-standards — 질문

## 질문

1. (왜) 보안 기준이 없으면 "알려진" 취약점이 반복되는 이유는? 고친 것이 무엇이고 고치지 못한 것이 무엇인가?
2. (경계) OWASP Top 10:2025, ASVS 5.0.0, NIST SSDF, 행정안전부 고시 별표 3은 각각 어떤 층의 문서인가? Top 10을 그대로 체크리스트로 쓰면 무엇이 부족한가?
3. (그림) SAST·SCA·사람 리뷰가 각각 맡는 영역을 코드/의존성/빌드 경로 축으로 그리고, 각 영역이 주로 잡는 Top 10 항목을 적어라. 도구가 0건을 보고했을 때 남는 위험은?
4. (예측) 실험 A의 `findByUser`(문자열 이어 붙이기)와 `findByUserSafe`(바인딩) 중 SQL 인젝션 경고를 받는 것은? 전체 9건 중 보안 경고는 몇 건이고, 나머지를 같은 게이트에 걸면 무슨 일이 생기나?
5. (예측) OSV 질의에서 log4j-core 2.25.2는 몇 건의 권고를 받았나? 이 버전이 출시 당시 깨끗했다고 해도 오늘 결과가 다른 이유와, 그것이 SCA 운영에 주는 결론은?
6. (계산) ASVS 5.0.0의 수준 열 분포가 L1 70·L2 183·L3 92일 때, L2를 목표로 하면 검증할 요구사항은 몇 개인가? "ASVS L2를 만족한다"는 문장이 왜 계약이 되나?
7. (경계) 행안부 고시 별표 3은 어떤 사업에 필수인가? 설계·구현 단계 항목 수와 감리 때 진단 도구에 대한 요구는?
8. (장애 진단) "우리는 그 라이브러리를 직접 쓰지 않는다"고 답했는데 운영 이미지에 취약한 jar가 들어 있었다. 원인과 대처는?
9. (장애 진단) 보안 체크리스트를 모두 통과한 결제 서비스가 인증 서버 타임아웃 중 요청을 승인했다. 도구와 체크리스트가 놓친 이유와 확인 방법은?
