# engineering-practice/17-legal-standards — 질문

## 질문

1. (경계) 개인정보 의무와 오픈소스 라이선스 의무는 각각 어떤 "행위"에 붙나? GPL-3.0의 "convey" 정의로 보면 서버에서만 실행하는 SaaS는 어떻게 되고, AGPL-3.0 §13은 무엇을 바꾸나? (해석임을 밝혀라)
2. (그림) 허용형·약한 copyleft·강한 copyleft·네트워크 copyleft를 예시 라이선스·핵심 의무·의무 시점으로 표로 그려라. Apache-2.0 §4가 요구하는 네 가지는?
3. (예측) 실험 A에서 `pom.xml`에 선언한 의존성은 6개다. 라이선스 목록에는 몇 개가 나오고, 늘어난 것은 무엇이며 어디서 왔나?
4. (예측) 실험 A의 정책 검사기는 몇 건을 DENY로 판정했나? 각각의 이유와, "모르는 라이선스 이름 = 실패"로 둔 이유는?
5. (장애 진단) 도구 보고서는 logback 1.5.12를 "EPL 1.0 / LGPL"이라 하는데 공식 페이지는 다르게 적는다. 무엇이 다르고, 라이선스 판정 절차에 주는 교훈은? org.json의 버전별 차이도 함께 말하라.
6. (예측) 원본 부록의 법 제34조·시행령 제40조를 law.go.kr 현행과 비교하면 무엇이 바뀌었나? 대조군 제21조를 함께 돌린 이유는?
7. (경계) 2026-09-11 시행 개정에서 새로 생긴 "유출 가능성 통지"는 어떤 경우에 적용되고 기한은 얼마인가? 일반 유출 통지와 어떻게 이어지나?
8. (적용) 탈퇴 처리를 데이터 모델로 설계하라. 즉시 파기 대상과 보존 대상을 어떻게 나누고(근거 조문과 기한 포함), 파기는 무엇으로 증명하나? soft delete가 파기가 아닌 이유는?
9. (장애 진단) 수정한 AGPL 컴포넌트를 외부 고객용 웹 서비스로 운영하고 있다는 사실이 감사에서 나왔다. 무엇이 문제이고, 정책표는 어떻게 바뀌어야 하나?
10. (연결) 접속기록 1년/2년, 권한 내역 3년, 거래기록 5년 같은 기한은 각각 어느 조문에 있나? 이 기한들이 운영 표준(16)·보안 표준(15)과 만나는 지점은?
