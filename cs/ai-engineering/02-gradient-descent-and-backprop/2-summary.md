# ai-engineering/02-gradient-descent-and-backprop — 연쇄 법칙·역전파·학습률과 발산 — 정리 (힌트)

## 해결하는 문제

경사 하강은 "손실이 줄어드는 방향으로 파라미터를 조금씩 옮긴다"([data-analysis/22](../../data-analysis/22-multiple-and-logistic-regression/2-summary.md) 4절 — 단일 출처). 그러려면 파라미터마다 기울기 `∂L/∂θ`가 필요하다.
파라미터가 수십억 개면 이 기울기를 어떻게 구하나?

```text
  수치 미분(파라미터 하나씩 살짝 바꿔 보기)
    θ₁ ± h → 순전파 2번,  θ₂ ± h → 순전파 2번,  …  파라미터 P개 → 순전파 2P번
  역전파(역방향 자동 미분)
    순전파 1번 + 역방향 1번 → 모든 파라미터의 기울기
```

- *기울기(gradient)*: 손실을 각 파라미터로 편미분한 값들의 벡터. "이 값을 조금 올리면 손실이 얼마나 변하나".
- 역전파는 계산 그래프를 출력에서 입력 쪽으로 한 번 훑으며 모든 기울기를 구한다(Goodfellow 외 6.5).

쉬운 예: 스프레드시트.
- 셀 C = A × B, 셀 D = C + A. "A를 1 올리면 D가 얼마나 바뀌나?"
- D에서 거꾸로 따라가면 두 길이 있다. D ← C ← A(B만큼), D ← A(1만큼). 답은 두 길을 더한 B + 1이다.

똑같은 구조다.\
신경망도 수식 셀이 아주 많은 스프레드시트다. 역전파는 마지막 셀(손실)에서 거꾸로 각 셀의 영향을 곱하고 더한다.

실무 예(백엔드가 보는 쪽):
- 파인튜닝 작업 로그에 `loss: nan`이 찍힌다. 원인 후보 하나가 너무 큰 학습률이다(실험 B). 다른 후보(데이터·수치 정밀도 문제 등)도 있으니 NaN 직전의 손실 추이부터 본다(해석).
- 손실이 처음부터 거의 안 줄거나, 갑자기 튄다. 기울기 소실·폭주의 모양이다(실험 C).
- 자체 손실 함수·연산을 붙였더니 학습은 "돌아가는데" 수렴이 이상하다. 기울기 누적 버그일 수 있다(실험 A).

## 동작·원리

### 1. 계산 그래프

`f = tanh(a·b + c) · a` 를 노드로 펼친다.

```text
   a ──┬──▶ [×] ──▶ u=a·b ──▶ [+] ──▶ s=u+c ──▶ [tanh] ──▶ t ──▶ [×] ──▶ f
       │     ▲                  ▲                                ▲
       │     b                  c                                │
       └─────────────────────────────────────────────────────────┘
                       a는 두 번 쓰인다 (경로 2개)
```

- *계산 그래프(computational graph)*: 연산을 노드, 값의 흐름을 간선으로 둔 방향 비순환 그래프(DAG). Goodfellow 외 6.5.1, SLP3 6.6.3.
- 노드마다 "입력에 대한 국소 미분"만 알면 된다. 곱셈 `u = a·b`의 국소 미분은 `∂u/∂a = b`, `∂u/∂b = a`. tanh의 국소 미분은 `1 − t²`.

### 2. 연쇄 법칙 — 경로를 따라 곱하고, 경로끼리 더한다

```text
  ∂f/∂a = (경로 1: a → u → s → t → f)  +  (경로 2: a → f)
        =  b · 1 · (1 − t²) · a          +  t
```

- *연쇄 법칙(chain rule)*: 합성 함수의 미분은 단계별 미분의 곱이다(Goodfellow 외 6.5.2).
- 한 변수가 여러 경로로 출력에 닿으면 경로별 값을 **더한다**. 구현에서는 `grad += 국소미분 × 위쪽 기울기`로 누적한다.
  - 흔한 오해: "역전파 = 신경망 학습 알고리즘 전체". Goodfellow 외 6.5는 역전파가 **기울기를 계산하는 방법만** 가리키고, 그 기울기로 학습하는 것은 SGD 같은 다른 알고리즘이라고 짚는다.

### 3. 역전파 = 위상 정렬의 역순으로 한 번 훑기

```text
  순전파(위상 순서)   a, b, c → u → s → t → f        값을 계산해 노드에 저장
  역방향(역순)        f → t → s → u → (a, b, c)      f.g = 1에서 시작해 국소 미분을 곱해 내려보냄
                      어떤 노드를 처리할 때 그 노드를 쓰는 노드(위쪽)는 이미 다 끝나 있다
```

- 역순으로 처리해야 노드의 기울기가 "모든 위쪽 경로의 합"으로 완성된 뒤에 아래로 내려간다.
- 위상 정렬은 DFS 종료 순서로 만든다([algorithm/12-dfs](../../algorithm/12-dfs/2-summary.md) — 위상 정렬).
- 순전파에서 계산한 중간값(t 등)을 역방향에서 다시 쓴다. 그래서 역방향이 끝날 때까지 중간값을 들고 있어야 하고, 학습이 추론보다 메모리를 더 쓰는 이유 중 하나가 된다(해석 — Goodfellow 외 6.5.9는 순방향 누적이 "그래프 전체의 값과 기울기를 저장할 필요"를 피한다고 대비한다).
- Goodfellow 외 6.5.9: 역전파는 *역방향 누적(reverse mode accumulation)*이라는 자동 미분의 한 경우다. 출력이 입력보다 많을 때는 순방향 누적이 나을 때도 있다. 손실처럼 출력이 스칼라 하나이고 입력(파라미터)이 많을 때 역방향이 유리하다(해석).

### 실험: 손으로 만든 역전파 vs 수치 미분 (실험 A)

```python
# scratchpad ai/01/e02/autodiff.py 핵심 — 값 노드 V(x, parents, local)
def backward(out, accumulate=True):
    order, seen = [], set()
    def dfs(v):                       # 위상 정렬: 입력을 먼저 방문하고 나를 뒤에 넣는다
        if id(v) in seen: return
        seen.add(id(v))
        for p in v.parents: dfs(p)
        order.append(v)
    dfs(out)
    out.g = 1.0
    for v in reversed(order):         # 출력 → 입력
        for p, d in zip(v.parents, v.local):
            if accumulate: p.g += d * v.g        # 연쇄 법칙 + 경로별 합
            else:          p.g = d * v.g         # 버그: 마지막 경로만 남는다
```

    df/da -1.17897307     -1.17897307
    df/db  0.38178424      0.38178424
    df/dc  0.54540606      0.54540606

- 관찰 1: 역전파 한 번으로 세 기울기가 모두 나왔다. 수치 미분과 소수 8자리까지 같다.
- 관찰 2: 누적을 대입으로 바꾸면 a의 기울기가 −1.179 → −0.709로 틀린다. 오류나 예외는 없다. 학습은 계속 "돌아가지만" 틀린 방향으로 움직인다.
- 수치 미분 대조(*gradient check*)는 새 연산을 붙일 때 쓰는 확인법이다. 파라미터마다 순전파 2번이라 운영 학습에는 쓰지 않는다.

### 4. 학습률 — 너무 크면 발산한다

한 변수 이차 손실 `L(w) = 평균 (w·x − y)²`에서 경사 하강 한 걸음은 오차 `w − w*`에 `(1 − lr·L″)`을 곱한다. `|1 − lr·L″| < 1`이어야 줄어든다.

```text
  lr·L″ < 1        오차가 같은 부호로 줄어든다          ───▶ w*
  1 < lr·L″ < 2    부호를 바꾸며 줄어든다(진동 수렴)     ◀──▶◀─▶ w*
  lr·L″ > 2        부호를 바꾸며 커진다(발산) → inf → NaN
```

- *학습률(learning rate)*: 기울기에 곱하는 걸음 크기 `lr`.
- Goodfellow 외 8.3.1: 학습률이 너무 크면 학습 곡선이 격하게 진동하고 비용이 크게 오르는 일이 잦다. 너무 작으면 학습이 느리고 높은 비용에 머물 수 있다.

- 부동소수의 inf·NaN 규칙은 [architecture/03-floating-point-ieee754](../../architecture/03-floating-point-ieee754/2-summary.md).

### 5. 기울기 소실·폭주 — 긴 곱셈 사슬

```text
  깊이 n 사슬의 dy/dx = (층마다 국소 미분)의 곱
     국소 미분 < 1 이 n번  → 0으로 (소실)     예: σ′ ≤ 0.25
     국소 미분 > 1 이 n번  → 매우 커짐 (폭주)  예: 선형 w = 1.5
```

- Goodfellow 외 8.2.5: 같은 행렬 W를 t번 곱하는 경로는 `Wᵗ`이고, 크기가 1에서 먼 고윳값은 1보다 크면 폭주, 작으면 소실한다. 기울기도 같은 배율(diag(λ)ᵗ)을 받는다 — 고유방향 성분마다 따로다.
- 같은 책 8.2.4: 큰 가중치 여러 개가 곱해지면 손실 곡면에 "절벽"이 생긴다. 절벽에서 한 걸음이 파라미터를 아주 멀리 보낸다. 이를 줄이는 것이 *기울기 클리핑(gradient clipping)* — 걸음이 너무 크면 줄인다(상세는 같은 책 10.11.1).

## 적용 — 풀어나가는 법

### 1. 파인튜닝 작업 로그를 읽을 때 — 증상 → 원리 → 확인

| 증상(로그 모양) | 의심할 원리 | 확인 |
|---|---|---|
| `loss: nan`·`inf` | 학습률 과대로 발산(4절) → inf → NaN | 처음 비정상이 된 걸음 앞의 손실이 커지고 있었나, 학습률을 낮춰 재실행 |
| 손실이 크게 진동하며 오름 | 학습률이 안정 한계 근처·위 | 학습률 절반으로 비교 |
| 손실이 처음부터 거의 안 줄어듦 | 학습률 과소, 또는 기울기 소실(5절) | 기울기 노름을 기록하는지, 층별로 작아지는지 |
| 손실이 갑자기 튐 | 기울기 폭주·절벽(8.2.4) | 튄 걸음의 기울기 노름, 클리핑 설정 |

- 백엔드가 파인튜닝 작업을 운영한다면 손실·기울기 노름을 지표로 내보내고 비정상에 작업을 멈춘다. 지표 설계는 [reliability/16](../../reliability/16-metrics-and-golden-signals/2-summary.md).

### 2. 손실 감시 — 비정상이면 일찍 멈춘다 (Java 21)

```java
// scratchpad ai/a01/e02/LossWatch.java 핵심 (ai/01/e02 판의 짝수 창 중앙값을 고친 판)
static Optional<Verdict> check(double[] losses, int window, double spikeRatio) {
    Deque<Double> recent = new ArrayDeque<>();
    for (int i = 0; i < losses.length; i++) {
        double l = losses[i];
        if (!Double.isFinite(l)) return Optional.of(new Verdict(i, "손실이 " + l));
        if (recent.size() == window) {
            double[] s = recent.stream().mapToDouble(Double::doubleValue).sorted().toArray();
            int n = s.length;
            double median = n % 2 == 1 ? s[n / 2] : (s[n / 2 - 1] + s[n / 2]) / 2; // 짝수 창은 가운데 두 값의 평균
            if (l > spikeRatio * median)
                return Optional.of(new Verdict(i, String.format("손실 %.3g > %.1f × 중앙값 %.3g", l, spikeRatio, median)));
            recent.removeFirst();
        }
        recent.addLast(l);
    }
    return Optional.empty();
}
```

(실험, JDK 21.0.12 eclipse-temurin:21-jdk 컨테이너, 2026-10-08 — 실험 B와 같은 손실, 600걸음, 창 5, 배율 3)

```text
lr=0.05 → 이상 없음
lr=1.00 → step 5 중단: 손실 8.43e+07 > 3.0 × 중앙값 1.01e+04
   (감시 없이 두면: 손실 첫 Infinity step 235, 첫 NaN step 471)
```

- 관찰: 튐 규칙은 5걸음째에 멈췄다. `isFinite` 검사만 두면 235걸음째(손실 Infinity)에야 멈춘다. 손실은 w의 제곱이라 w보다 먼저(235 < 470) 넘친다.
- 같은 코드를 창 20으로 돌리면 20걸음째에 멈췄다(같은 날 실행 — 짝수 창의 중앙값을 가운데 두 값의 평균으로 고친 판으로 다시 돌려도 `step 20 중단: 손실 3.33e+27 > 3.0 × 중앙값 1.51e+14`, 창 5 출력은 위와 같다). 창이 차기 전에는 튐 규칙이 작동하지 않으므로, 초반 감시는 `isFinite`나 첫 손실 대비 배율 같은 별도 규칙이 필요하다(해석).
- 배율 3·창 5는 이 실험의 예시 값이다. 정상 학습에서도 손실은 흔들리므로 실제 문턱은 정상 작업 로그로 정한다.

## 장애 시나리오와 대처

### 1. 학습률 과대 → 손실이 NaN·inf로 발산 (⚠ 커리큘럼)

- 현상: 파인튜닝 작업이 몇 시간 돈 뒤 체크포인트 손실이 `nan`이다. 그 체크포인트로 배포하면 출력이 깨진다.
- 보이는 형태: 손실이 진동하며 커지다가 `inf`, 이어 `nan`(실험 B: lr=1.0에서 470·471걸음).
- 원인: 걸음이 곡률에 비해 너무 크다(4절, `lr·L″ > 2`). 무한끼리 빼면 NaN이 되고 이후 전부 전파된다.
- 대처: 학습률을 낮춘다. 비정상 손실에 작업을 멈추는 감시를 넣는다(적용 2). NaN 체크포인트를 배포 후보에서 막는다.

### 2. 기울기 소실·폭주 → 손실이 멈추거나 튐 (⚠ 커리큘럼)

- 현상: 손실 곡선이 처음부터 평평하거나, 중간에 수직으로 튄다.
- 보이는 형태: 층별 기울기 노름이 깊은 층으로 갈수록 0에 가깝거나(실험 C: σ 사슬 깊이 10에서 3.9e-7), 특정 걸음에서 수십 배로 커진다.
- 원인: 긴 곱셈 사슬에서 1보다 작은(큰) 국소 미분이 반복 곱해진다(Goodfellow 외 8.2.5).
- 대처: 폭주에는 기울기 클리핑(8.2.4 → 10.11.1). 소실은 구조 문제라 파인튜닝 사용자 쪽에서는 학습률·설정 비교와 기울기 노름 기록이 우선이다.

### 3. 커스텀 연산의 기울기 누적 버그 → 조용히 틀린 학습

- 현상: 자체 손실 함수를 붙였더니 손실이 기대만큼 줄지 않는다. 오류는 없다.
- 보이는 형태: 수치 미분과 역전파 기울기가 다르다(실험 A: −1.179 vs −0.709).
- 원인: 같은 값이 여러 경로로 쓰이는데 기울기를 더하지 않고 덮어썼다.
- 대처: 새 연산마다 작은 입력으로 기울기 검사(중앙 차분 대조)를 단위 테스트로 둔다.

### 4. 감시 규칙이 늦게 발동 → 발산한 체크포인트가 저장됨

- 현상: 손실 감시가 있는데도 망가진 체크포인트가 여러 개 저장됐다.
- 보이는 형태: 감시 로그의 중단 걸음이 손실이 커지기 시작한 걸음보다 한참 뒤다(적용 2: 창 20이면 20걸음째, `isFinite`만이면 235걸음째).
- 원인: 이동 창이 다 차기 전에는 튐 규칙이 작동하지 않았다. 비유한 값 검사만으로는 이미 무한이 된 뒤에 잡는다.
- 대처: 초반 구간에는 첫 손실 대비 배율 같은 별도 규칙을 둔다. 체크포인트 저장 전에 손실이 유한한지 확인한다.

## 핵심 문장

- 역전파는 계산 그래프를 위상 정렬의 역순으로 한 번 훑어, 순전파 한 번 + 역방향 한 번으로 모든 파라미터의 기울기를 구한다.
- 연쇄 법칙은 경로를 따라 국소 미분을 곱하고, 한 값이 여러 경로로 쓰이면 경로별 값을 더한다 — 구현에서는 `+=` 누적이다.
- 역전파는 기울기 계산법이고, 그 기울기로 파라미터를 옮기는 것은 경사 하강(SGD 등)이다.
- 이차 손실에서 경사 하강은 `lr·L″ > 2`이면 발산하고, 발산의 끝은 inf → NaN이다.
- 깊은 곱셈 사슬은 1보다 작은 국소 미분이면 기울기를 소실시키고, 큰 국소 미분이면 폭주시킨다.
