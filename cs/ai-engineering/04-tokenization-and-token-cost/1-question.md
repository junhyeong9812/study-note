# ai-engineering/04-tokenization-and-token-cost — 질문

## 질문

1. (왜) 모델의 어휘표를 단어 단위로 만들 때와 바이트 단위로 만들 때 각각 무엇이 문제인가? 서브워드(BPE)는 그 사이에서 무엇을 얻나?
2. (그림) Sennrich 외 2016의 예제 어휘 `l o w </w> ×5`, `l o w e r </w> ×2`, `n e w e s t </w> ×6`, `w i d e s t </w> ×3`에서 첫 세 번의 병합을 그려라. 학습에 없던 `lowest`는 열 번 병합한 규칙표로 어떻게 토큰화되나?
3. (예측) 같은 한국어 시험 문장 300개를 (a) 영어 위주 9:1, (b) 한국어 위주 1:9 말뭉치로 학습한 바이트 수준 BPE(병합 300회)로 토큰화하면 토큰 수는 어느 쪽이 많을까? 대략 몇 배일까? 실험 출력으로 확인하라.
4. (계산) "안녕하세요 세계"는 Java `length()`로 몇이고 UTF-8로 몇 바이트인가? "토큰 하나 ≈ 4바이트"(tiktoken README의 평균)를 이 문자열의 `length()`에 4글자=1토큰으로 적용하면 무엇이 두 번 틀리나?
5. (경계) 같은 한국어 문장을 NFC와 NFD로 각각 보내면 왜 토큰 수가 크게 다를 수 있나? 실험에서는 몇 토큰 대 몇 토큰이었나? 앱에서 무엇을 하면 막을 수 있나?
6. (장애 진단) 요약 결과가 가끔 문장 중간에서 끊긴 채 저장된다. 요청 로그는 모두 HTTP 200이다. Anthropic Messages API, OpenAI Chat Completions, OpenAI Responses API에서 각각 어떤 필드·값을 확인해야 하나?
7. (장애 진단) 모델만 새 버전으로 바꿨는데 월 비용이 늘고, 전에는 들어가던 긴 문서가 한도에 걸린다. 무엇이 바뀌었을 수 있고, 어떻게 확인하나?
8. (연결) 토큰이 과금·문맥 한도·생성 시간의 세 단위라는 것은 각각 어떤 다른 주제(캐시·클라이언트 계약·지연 지표)와 이어지나?
9. (연결) BPE 학습에서 해시맵과 힙은 각각 어디에 쓰이나? 전문 검색 분석기([database/46](../../database/46-full-text-search-and-analyzers/2-summary.md))의 토큰화와는 무엇이 다르고, 무엇이 같은 조건인가?
