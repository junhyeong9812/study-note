## 질문

1. (경계) 프리필과 디코드는 각각 무엇을 처리하나? 왜 프리필은 병렬로 빠르게 돌고 디코드는 메모리 대역폭에 묶이나?
2. (왜) 생성 중 이전 토큰의 K·V를 저장해 재사용해도 결과가 바뀌지 않는 근거는 무엇인가([06편](../06-transformer-and-attention/2-summary.md)의 어떤 성질)?
3. (계산) LLaMA-7B 구조(층 32·헤드 32·헤드 차원 128, MHA, fp16)의 토큰당 KV 바이트와 32,768토큰 한 요청의 KV 크기를 식과 함께 구하라.
4. (예측) 같은 계산에서 헤드 수를 빠뜨리면 몇 배 틀리나? 이 계산기가 맞는지 독립 출처로 대조하려면 어떤 값을 쓰면 되나?

7. (예측) 장난감 디코더에서 프롬프트 64토큰, 생성 256토큰일 때 캐시 없는 K·V 투영 횟수와 캐시 있는 횟수는? 두 방식의 출력은 같은가?
8. (장애 진단) 짧은 요청 부하 시험은 통과했는데 긴 문서 요약 요청이 몰리자 OOM과 대기열 폭증이 났다. 원인과 대처를 써라.
9. (장애 진단) Mistral 7B를 올리면서 쿼리 헤드 수로 KV를 계산했다. 어떤 방향으로 틀리고, 운영에서 어떻게 보이나? 슬라이딩 윈도 롤링 버퍼는 이 차이를 어떻게 바꾸나?
