# ai-engineering/07-decoding-and-nondeterminism — 질문

## 질문

1. (왜) 모델은 한 단계에 무엇을 내고, 디코딩 규칙은 왜 따로 필요한가? greedy만 쓰면 무엇이 문제이고, 순수 샘플링만 쓰면 무엇이 문제인가?
2. (그림) 로짓에서 토큰 하나가 나오기까지(temperature → 절단 → 재정규화 → 뽑기)를 그려라. top-k와 top-p는 남기는 개수를 정하는 방식이 어떻게 다른가?
3. (계산) 확률 `.382 .224 .184 .101 .052 .037 .014 .007`에서 top-p = 0.9이면 몇 개가 남나? top-p = 0.5, 확률 `.498 .224 ...`이면?
4. (예측) 같은 로짓에서 T = 0.2와 T = 1.5로 각각 1만 번 뽑으면 1위 토큰 비율과 꼬리 2개 비율은 어떻게 될까? T = 1.5에 top-p 0.9를 걸면? 실험 출력으로 확인하라.
5. (경계) "temperature 0이면 결정적이다"는 왜 틀린가? Thinking Machines 글이 비판한 흔한 설명과, 그 글이 내세운 실제 원인은 무엇인가? 공개 실험의 숫자(1,000회)를 대라.
6. (예측) 입력·가중치가 비트까지 같은 float32 내적을 한 줄 누적과 8구간 분할 누적으로 계산하면 결과가 같을까? 거의 동점인 두 후보의 greedy 1위는? 실험 출력으로 확인하라.
7. (장애 진단) CI의 LLM 출력 스냅샷 테스트가 가끔 실패하고 재실행하면 통과한다. 원인과, 테스트를 어떻게 바꿔야 하나?
8. (장애 진단) 모델 ID만 새 Claude 모델로 바꿨더니 모든 요청이 400이다. 요청에는 `temperature: 0.2`가 있다. 무엇이 원인일 수 있고, 재시도로 해결되나?
9. (연결) 출력 문자열을 캐시 키로 쓰면 왜 안 되나? 대신 무엇을 키로 쓰고, 뜻이 같은 출력의 중복은 어떤 주제의 도구로 판정하나?
