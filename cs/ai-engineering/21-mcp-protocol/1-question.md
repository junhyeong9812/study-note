# ai-engineering/21-mcp-protocol — 질문

## 질문

1. (왜) MCP는 무엇과 무엇 사이의 규약인가? "모델 API"와 무엇이 다른가?
2. (경계) JSON-RPC 2.0의 요청·응답·알림을 구분하라. MCP는 요청 ID에 어떤 제약을 더하나? 알림이 실패하면 보낸 쪽은 알 수 있나?
3. (연결) 2026-07-28판에서 사라진 것 두 가지와 대신 생긴 것은? 서버가 "같은 연결의 이전 요청"에 기대면 안 되는 이유는?
4. (예측) 2026-07-28만 지원하는 서버에 `protocolVersion: "2025-11-25"`로 `tools/list`를 보내면 무엇이 돌아오나? 클라이언트는 그다음 무엇을 해야 하나?
5. (장애 진단) 판 업그레이드 뒤 한 클라이언트의 로그에 같은 오류 `-32022`가 백오프 간격으로 수백 번 찍힌다. 무엇이 잘못됐나?
6. (경계) 도구 인자 형식이 틀렸을 때와 없는 도구를 불렀을 때, 서버 응답은 각각 어떤 모양인가? JSON-RPC `error`만 실패로 보는 클라이언트는 무엇을 놓치나?
7. (예측) `tools/list` 결과에 `ttlMs: 300000`이 왔다. 받은 뒤 299,999ms와 300,000ms에 다시 필요하면 각각 캐시와 서버 중 어디서 가져오나? 그 사이 `notifications/tools/list_changed`가 오면?
8. (장애 진단) 네트워크 순단 뒤 긴 도구 호출의 결과가 오지 않아 클라이언트가 `Last-Event-ID`로 재연결을 시도한다. 2026-07-28판에서 맞는 처리와 함께 챙길 것은?
9. (장애 진단) `readOnlyHint: true`인 도구를 사용자 확인 없이 실행했더니 데이터가 바뀌었다. 명세는 annotations를 어떻게 다루라고 하나?
