# security/29-security-symptom-index — 질문

## 질문

1. (왜) 보안 증상을 "정상 요청이 막힌다"와 "막혀야 할 요청이 통과한다" 두 갈래로 나누는 이유는? 앞 갈래를 급하게 처방할 때 뒤 갈래가 생기는 예를 둘 들어라.
2. (구분) RFC 9110과 RFC 6750 §3.1로 `401`·`403`·`404`를 구분하라. 토큰이 없을 때와 토큰이 무효일 때 `WWW-Authenticate` 헤더는 어떻게 다른가?
3. (예측) `Triage.java` 실험에서 `401`을 낸 네 경우와 `403`을 낸 세 경우는 각각 무엇으로 갈렸나? 응답 코드만 세는 대시보드로는 무엇을 못 가르나?
4. (장애 진단) `invalid signature`가 웹훅 수신, JWT 검증, 키 교체 배포 직후에 각각 나왔다. 셋의 원인 후보와 첫 확인을 하나씩 말하라.
5. (장애 진단) `kid not found`로 401이 쏟아졌다. 회전 직후 캐시 미스, JWKS 엔드포인트 장애, 무작위 `kid` 폭격을 시각·페치 수로 어떻게 가르나? Spring Security에서 JWKS 장애가 401이 아닌 응답으로 보일 수 있는 이유는?
6. (경계) 콘솔에 CORS 에러가 났는데 서버 로그는 `200`이다. 요청은 처리됐나? preflight 405와는 무엇이 다른가? "Origin 반사"가 처방이 아닌 이유는?
7. (장애 진단) 로그인한 사용자의 POST만 `403`이다. 첫 후보는? 그 처방으로 CSRF를 꺼도 되는 조건은 무엇인가?
8. (연결) 앱 로그에 `169.254.169.254`로의 요청이 보였다. 원인 후보 셋과 확인 방법, 그리고 흔적을 본 직후 먼저 할 일을 말하라. 이 증상이 실제 사고로 이어진 사례는?
9. (장애 진단) 로그인 요청이 평소의 수십 배다. 크리덴셜 스터핑·계정 열거·KDF 과부하를 가르는 관찰을 하나씩 들고, IP당 한도만으로 부족한 이유를 말하라.
10. (경계) 인가 서비스 장애 회고가 "에러율 변화 없음, 사용자 영향 없음"이다. 무엇을 더 봐야 하나? 실험 (10)의 두 판 결과로 설명하라.
