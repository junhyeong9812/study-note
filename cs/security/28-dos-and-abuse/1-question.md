# security/28-dos-and-abuse — 질문

## 질문

1. (왜) DoS가 "비대칭"을 노린다는 것은 무슨 뜻인가? 볼륨·프로토콜·애플리케이션 세 계층은 각각 어떤 자원을 고갈시키고, 방어를 어느 층에 두나?
2. (그림) 증폭(reflection) 공격의 패킷 흐름을 그려라. 출발지를 왜 위조하나? 자사 서버가 "반사판"이 되지 않으려면?
3. (예측) slowloris 클라이언트가 헤더를 끝맺지 않고 천천히 보낸다. 수신 타임아웃이 없는 서버와 1초 타임아웃을 건 서버는 각각 어떻게 동작하나(실험 기준)?
4. (경계) 토큰 버킷(용량 20, 보충 5/s)에 정상 1건/s, 남용 50건/s, 비싼 리포트(cost 10) 5건/s를 넣으면 각각 허용/차단이 어떻게 갈리나? cost 가중이 하는 일은?
5. (연결) "거절도 공짜가 아니다"는 무슨 뜻인가? 429가 왜 재시도 폭풍을 부르고, 어떻게 받아야 하나?
6. (경계) 알고리즘 복잡도 공격(엔티티 폭탄·ReDoS·해시 충돌)의 공통 구조와 공통 방어는? 각각 어느 노트와 연결되나?
7. (장애 진단) 연결은 한도 근처인데 새 요청이 안 받아진다. CPU는 여유다. SYN flood와 slowloris를 어떻게 구분하고 각각 어떻게 대처하나?
8. (장애 진단) 리미터를 IP로만 걸었더니 회사 하나가 통째로 막혔고, 리미터 고장 시 거동이 불명확하다. 키 선택과 실패 모드를 어떻게 설계하나?
