# security/27-pii-classification-masking-retention — 정답

## 정답

### 1. 복제되는 곳에서 샌다

- 한 번 받은 PII는 운영 DB에만 있지 않고 여러 사본으로 퍼진다. 그래서 운영 DB만 잠가서는 못 막는다.
- 네 경로
  - 로그: 요청 바디 전체 로깅 → 로그 수집기·외부 SaaS.
  - 에러 트래커: 예외 메시지에 이메일 → Sentry 등.
  - 백업: 테이프에 영구 잔존(탈퇴해도 남음).
  - 스테이징/분석 DW: 운영 덤프 복제 → 통제 약한 곳의 유출이 실유출.

### 2. 되돌릴 수 있나

- 마스킹: 표시용(앞뒤 일부만) — 화면의 마스킹 문자열은 되돌릴 수 없지만, 원본 저장·파기는 별개 문제다. PCI DSS 표시 원칙 BIN+마지막 4(업무상 근거 있는 역할은 예외).
- 토큰화(볼트 방식): 볼트로만 가역. 토큰만 유통, 원본은 분리 볼트. (FPE처럼 키로 암호화해 형식을 보존하는 방식은 키로 복호된다.)
- 가명화(HMAC): HMAC 자체는 비가역. 같은 입력 → 같은 가명(조인 가능), 키 없이는 복원 어려움. 키와 추측 가능한 후보가 있으면 대조로 재식별된다. 가명정보도 개인정보.
- 익명화: 비가역, 재식별 불가하게 — 성공하면 개인정보가 아니게 됨.

### 3. redaction 거부 목록 vs 허용 목록 (실험)

- 거부 목록(아는 모양만 지움): 공백 있는 카드(`[CARD]`)·표준 이메일(`[EMAIL]`)은 지웠지만, **공백 없는 `cardAlt`·패턴이 없던 `rrn`·"kim at example dot com"으로 흘려 쓴 memo는 그대로 샜다**.
- 허용 목록(안전 필드만 남김): `orderId·amount·currency`만 남기고 나머지 전부 `[REDACTED]`.
- 로그에 허용 목록인 이유: 입력 형식은 끝없이 변형되므로 "아는 것만 지우기"는 새는 칸이 남기 쉽다(실험에서 세 칸이 샜다). "모르는 것은 가린다"가 안전하다.

### 4. 키 없는 해시 vs HMAC (실험)

- 전화번호를 SHA-256만으로 가명화하면, 값 공간이 작아(뒤 4자리) 후보 1만 개를 **약 0.3초**에 다 돌려 원본을 복원했다. "해시했으니 안전"이 거짓이다.
- HMAC(비밀 키): 같은 입력 → 같은 가명이라 조인은 되고, 키 없이는 열거가 막힌다.
- 한계: **키가 새면 전부 복원 가능**하다. 그래서 키 관리(KMS·회전, 09번)가 핵심이다.

### 5. crypto-shredding

- 사용자별 키로 암호화해 두면 백업·DW에 **암호문만** 남는다. 탈퇴 시 그 사용자 키를 (백업·에스크로 사본까지) 모두 파기하면, 흩어진 암호문이 한꺼번에 평문으로 못 돌아간다(실험: 키 파기 후 31바이트 복호 불가 — 암호문 하나로 확인).
- 백업 테이프를 일일이 찾아 지우지 않아도 된다는 것이 장점.
- 한계: 암호 자체가 뒤에 깨지면 과거 암호문이 복원될 수 있고, 법·규정이 "물리적 삭제"를 요구하면 이것만으로 부족할 수 있다.

### 6. 보존의 두 방향

- 너무 오래 둠: 유출 시 피해 확대, 삭제권 위반.
- 너무 일찍 지움: 법정 보존 의무(세금·거래 기록) 위반, 분쟁 증거 소멸.
- GDPR 17(3): 표현의 자유, **법적 의무**·공익 업무, 공공보건, 공익 기록보존·연구·통계, 법적 청구의 제기·행사·방어에 처리가 필요하면 그 범위에서 삭제권이 적용되지 않는다. 그 데이터는 예외로 분리 보관한다.

### 7. 삭제 전파 누락

- 빠진 것: 삭제가 운영 DB에만 적용되고 백업·로그·검색 인덱스·분석 DW의 사본은 손대지 않았다.
- 전파: 삭제 대상 목록을 운영·로그·인덱스·DW로 전파한다. 바로 못 지우는 백업은 crypto-shredding(키 파기)이나 접근 차단 후 주기 덮어쓰기. 단 법정 보존 의무가 겹치는 데이터는 예외로 분리.

### 8. 운영 덤프 스테이징

- 위험: 스테이징·테스트는 통제가 약한데 실제 고객 PII가 들어 있어, 그곳이 뚫리면 곧 실유출이다. 접근 권한도 운영보다 넓다.
- 테스트 데이터: 운영 복제 금지. 가명화·마스킹한 데이터나 합성 데이터로 구성한다. 토큰화돼 있으면 볼트 없이 토큰만 복제한다.
