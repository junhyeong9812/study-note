# security/02-threat-modeling — 질문

## 질문

1. (왜) 보안 체크리스트(인젝션·XSS·해시)를 다 통과해도 설계 결함은 남는다. OWASP A04(2021)는 설계 결함과 구현 결함을 어떻게 구분하나?
2. (그림) 브라우저 → API 게이트웨이 → 주문 서비스 → 주문 DB, 그리고 주문 서비스가 사용자 제공 URL에서 이미지를 가져오는 시스템의 DFD를 그리고 신뢰 경계를 표시하라. 경계를 건너는 흐름은 몇 개인가?
3. (경계) STRIDE 여섯 범주는 각각 어떤 보안 성질의 위반인가? STRIDE가 놓치기 쉬운 위협의 예를 하나 들어라.
4. (예측) 게이트웨이가 클라이언트의 `X-` 헤더를 모두 내부로 전달하고, 토큰에서 얻은 역할은 클라이언트가 같은 헤더를 안 보냈을 때만 붙인다. `Authorization: Bearer <user 토큰>`과 `X-User-Role: admin`을 같이 보내면 `/admin/users`는?
5. (예측) 4번의 게이트웨이를 "예약 헤더 삭제 후 재작성"으로 고쳤다. 공격자가 내부 서비스 포트에 직접 닿을 수 있다면 결과는? 이것은 STRIDE의 무엇이고 어떻게 막나?
6. (연결) 사용자가 준 URL을 서버가 가져오는 흐름은 신뢰 경계를 어느 방향으로 건너나? 위협 모델에서 어떤 질문을 해야 하고, AWS IMDSv2는 어떤 장치로 이 위험을 줄이나?
7. (경계) 위협 모델링의 네 질문은 무엇인가? 네 번째 질문을 빼먹으면 어떤 일이 생기나?
8. (장애 진단) 일반 사용자 계정이 `/admin/**`에서 200을 받은 기록이 감사에서 발견됐다. 게이트웨이 앞단 로그에서 무엇을 찾고, 어느 흐름의 어떤 STRIDE 위협으로 분류하며, 어떻게 고치나?
9. (장애 진단) 위협 모델 문서가 있는데 사고 경로가 문서에 없었다. 가능한 원인과 재발 방지책은?
