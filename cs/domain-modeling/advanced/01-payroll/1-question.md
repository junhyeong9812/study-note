#### 4. 야간 구간 (`PayRule.night` — 주어진 계약)

```java
public boolean night(LocalTime time) {
    if (nightStart.isBefore(nightEnd)) {
        return !time.isBefore(nightStart) && time.isBefore(nightEnd);
    }
    return !time.isBefore(nightStart) || time.isBefore(nightEnd);
}
```

- "22:00 이상 06:00 미만"이라는 흔한 식이 왜 빈 구간이 되는가?
- 자정을 넘는 구간에서 AND가 OR로 바뀌는 이유를 그림으로 설명할 수 있는가?
- 21:59 / 22:00 / 00:00 / 05:59 / 06:00 은 각각 야간인가?
