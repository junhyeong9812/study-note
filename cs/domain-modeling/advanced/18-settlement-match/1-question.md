    // reference 가 null 이거나 blank 면 예외

#### 5. search — 주어진 코드 (조합 탐색)

```java
private List<OurRecord> search(
        List<OurRecord> candidates, long target, AmountRule amountRule, int size, int from) {
    if (size == 0) {
        return target == 0 ? new ArrayList<>() : null;
    }
    for (int i = from; i <= candidates.size() - size; i++) {
        OurRecord record = candidates.get(i);
        long rest = target - expected(record, amountRule);
        List<OurRecord> tail = search(candidates, rest, amountRule, size - 1, i + 1);
        if (tail != null) {
            tail.add(0, record);
            return tail;
        }
    }
    return null;
}
```

- `size == 0` 에서 `target == 0` 이면 **빈 목록**, 아니면 `null` 을 주는데 이 둘을 왜 구별해야 하는가?
- 빈 목록과 `null` 을 안 구별하면 무슨 버그가 나는가?
- 반복문 조건이 `i <= candidates.size() - size` 인 이유는 무엇인가?
- 재귀 호출에 `i + 1` 을 넘기면 무엇이 보장되는가?
- `tail.add(0, record)` 로 앞에 꽂는 이유는 무엇인가?
- 후보가 n개, 묶음 최대 3이면 이 탐색이 보는 조합 수는 대략 얼마인가?
- 이 함수가 왜 `private` 이고, 왜 "주어진 코드"인가?
