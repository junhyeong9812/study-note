# domain-modeling/06-anemic-vs-rich-model — 질문

## 질문

1. (왜) Fowler(2003)는 빈약한 도메인 모델을 왜 안티패턴이라 부르나? 그 결과 설계는 어떤 패턴과 같아지나?
2. (판단) Vernon 『IDDD』 1장의 진단 질문 두 개는 무엇인가? 빈약 모델이 널리 퍼진 원인으로 Vernon은 무엇을 드나?
3. (예측) setter 4개와 수정 가능한 `getLines()`가 열린 빈약 `Order`, 같은 규칙을 의도 메서드로만 연 풍부 `Order`가 있다. 공개 메서드를 무작위로 1만 시퀀스(시퀀스당 최대 20호출) 부르면 각각 몇 시퀀스가 불변식을 깼나? 서비스 메서드만 부른 빈약 모델은?
4. (경계) 3번에서 "서비스만 부른 빈약 모델"도 위반 0이었다. 그렇다면 빈약 모델과 풍부 모델의 차이는 정확히 무엇인가? 풍부 모델이 무작위 호출 대부분을 예외로 거절했다는 것은 무엇을 뜻하나?
5. (예측) 추상 상태 `(status 4가지, paid, shipped, 줄 있음)` 32개 위에서 BFS를 돌리면 두 모델은 각각 몇 개 상태에 도달하나? 이 수가 테스트 설계에 주는 의미는?
6. (경계) 풍부 모델을 JPA 엔티티로 쓰려면 setter가 꼭 필요한가? Hibernate 6.6에서 setter 없이 저장·복원하려면 무엇을 해야 하나?
7. (장애 진단) 주문 `total`과 주문 줄 합계가 다른 행이 발견됐다. 어떤 코드 모양 두 가지를 의심하나? 찾는 SQL과 대처는?
8. (판단) 빈약한 구조가 맞는 경우는 언제인가? 반대로 풍부 모델이 과잉일 때 보이는 신호는?
9. (장애 진단) "행위를 객체에" 옮기다 보니 엔티티가 리포지토리·메일 발송기를 주입받게 됐다. 무엇을 섞었고 어떻게 나누나?
