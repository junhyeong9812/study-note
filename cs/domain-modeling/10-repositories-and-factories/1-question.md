# domain-modeling/10-repositories-and-factories — 질문

## 질문

1. (왜) 리포지토리 없이 서비스가 SQL을 직접 다루면 도메인 모델에 무슨 일이 생기나? Evans 『DDD Reference』가 "제약 없는 쿼리"의 위험으로 든 두 가지는?
2. (그림) 리포지토리 인터페이스와 구현이 각각 어느 계층에 있고, 어떤 메서드를 갖는지 그려라. 리포지토리는 어떤 타입에만 두나?
3. (구분) Vernon 『IDDD』의 컬렉션 지향 리포지토리와 영속 지향 리포지토리는 무엇이 다른가? JPA와 Spring Data JDBC는 각각 어느 쪽에 가까운가?
4. (예측) 엔티티의 연체 규칙에 유예 기간(NORMAL 3일, VIP 7일)을 넣었지만, 리포지토리 쿼리는 `due_date < ?` 그대로다. 실험 데이터 20건에서 메모리 판정과 쿼리 결과는 몇 건이 어긋났나? 명세 객체를 쓰면?
5. (경계) 명세 객체를 써도 남는 중복은 무엇이고, 그 중복을 어떻게 검증하나?
6. (계산) 선택 조건 3개(상태·VIP·연체)의 모든 조합을 Spring Data 파생 쿼리 메서드로 만들면 몇 개가 필요한가? 명세로 바꾸면?
7. (구분) 팩토리의 "생성"과 "재구성"은 식별자와 불변식 검사에서 어떻게 다른가? Evans 6장이 재구성 팩토리에 대해 말한 두 가지는?
8. (장애 진단) 생성 규칙("시작일 ≥ 오늘")을 강화해 배포한 뒤 오래된 구독 상세 화면이 500 에러를 낸다. 원인과 대처는? JPA는 재구성을 어떤 생성자로 하나?
9. (장애 진단) JPA에서 Spring Data JDBC로 옮긴 뒤 상태 변경 버튼이 동작하지 않는다(오류 없음). 원인은?
10. (연결) 주문 줄을 `OrderLineRepository`로 직접 고치면 05 애그리거트의 어떤 보장이 깨지나?
