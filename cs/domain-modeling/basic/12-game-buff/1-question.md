#### 2. TODO 1 딸림 — 상한과 버릴 대상 (요구사항에 없던 결정)

```java
case STACK -> {
    if (sameKind.size() >= maxStacks) {
        // 상한에 걸리면 남은 시간이 가장 짧은 것을 버린다.
        Buff weakest = sameKind.stream()
                .min(Comparator.comparing(b -> b.remainingAt(now)))
                .orElseThrow();
```
