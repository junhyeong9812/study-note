# cs/Hysteresis — 히스테리시스(Hysteresis) — 질문

## 질문

1. (정의) 히스테리시스를 한 문장으로 정의하고, 주로 어떤 상황을 막기 위해 쓰는지 말하라.
2. (예측) 동적 배열에서 확장 기준과 축소 기준을 둘 다 size = 8로 두면 무슨 일이 일어나는가? 기준을 16 / 4로 떨어뜨리면 왜 괜찮아지는가?
3. (왜) 이 개념에 "Hysteresis"라는 물리학 용어가 붙은 이유는? "현재 입력값"과 "이전 상태"라는 말로 설명하라.
4. (예측) CPU 팬을 "75°C 이상 ON, 미만 OFF" 하나의 기준으로 제어하면 어떤 문제가 생기는가? 80°C ON / 70°C OFF로 두었을 때 70~80°C 구간에서는 어떻게 동작하며, 이 구간을 무엇이라 부르는가?
5. (경계) Thrashing과 Hysteresis의 관계를 "현상"과 "원리"라는 말로 구분하라.
6. *(Claude 보충 — 노트 본문 요약)* (경계) hysteresis band를 좁게 잡을 때와 넓게 잡을 때 각각 무엇을 잃는가? 동적 배열의 C/4는 어느 쪽 비용을 감수한 선택인가?
