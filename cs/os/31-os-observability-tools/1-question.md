## 질문

1. (왜) 리눅스 load average는 정확히 무엇을 평균한 값인가? 8코어 서버에서 load 20일 때 CPU가 모자란 경우와 아닌 경우를 각각 그려 보라.
2. (예측) CPU `id`가 80%인데 load가 30이다. 무엇이 load를 올렸을 가능성이 크고, 어떤 명령으로 확인하나?
3. (경계) `vmstat`의 `b` 칸이 0인데 `ps`에는 D 상태 프로세스가 여럿 있다. 모순이 아닌 이유는?
4. (경계) `vmstat 1 1`로 찍은 한 줄을 근거로 "I/O 대기 없음"이라고 판단하면 왜 틀릴 수 있나? `iostat`는 어떤가?
5. (연결) USE 방법론의 세 글자를 정의하고, CPU·메모리·디스크 각각의 포화 지표를 하나씩 들어라. 사용률보다 포화가 더 직접적인 신호인 이유는?
6. (장애 진단) NVMe 디스크의 `iostat %util`이 100%다. 디스크 포화라고 결론 내려도 되나? 무엇을 더 봐야 하나?
7. (예측) 운영 중인 API 서버에 `strace -f -p`를 붙였다. 무슨 일이 생길 수 있고 왜 그런가? `perf`는 무엇이 다른가?
8. (연결) 컨테이너 안에서 `top`을 보면 CPU 여유가 있고 load도 낮다. 그런데 앱은 느리다. 왜 `top`을 믿으면 안 되고 무엇을 봐야 하나?
9. (적용) JVM 프로세스 하나가 CPU를 많이 쓴다. OS 도구에서 출발해 어느 Java 스레드인지 찾아가는 순서를 적어라.
