## 질문

1. (왜) 세마포어의 초깃값이 1, 0, N일 때 각각 어떤 용도가 되나? 용도마다 실무 예를 하나씩 들어라.
2. (예측) 리눅스에서 초깃값 2인 세마포어에 A, B, C가 차례로 `sem_wait`, 이어서 A가 `sem_post`, B가 `sem_post`한다. 각 단계의 값과 대기자를 적어라. C가 막혀 있을 때 `sem_getvalue`는 무엇을 돌려주나? OSTEP의 Dijkstra식 정의라면 그때 값은?
3. (연결) 부모가 자식을 기다리는 데 초깃값 0인 세마포어를 쓴다. 자식이 먼저 끝나 `sem_post`가 `sem_wait`보다 먼저 일어나면 어떻게 되나? 17번 조건 변수로 같은 일을 할 때 추가로 필요했던 것은 무엇이고, 왜 세마포어에는 필요 없나?
4. (그림) 유한 버퍼를 세마포어 `empty`·`full`·`mutex`로 만든다. 각 초깃값은? 소비자가 `sem_wait(&mutex)`를 `sem_wait(&full)`보다 **먼저** 부르면 교착이 나는 순서를 그려라. 고치는 방법은?
5. (경계) 초깃값 1인 세마포어와 뮤텍스는 무엇이 다른가? 소유자, 재진입, 상한 검사, JVM 교착 탐지 네 가지로 비교하라.
6. (장애 진단) 하위 API가 몇 번 에러를 낸 뒤부터 그 API를 부르는 기능 전체가 멈췄다. 하위 API는 이미 회복했다. 스레드 덤프와 지표에서 무엇이 보이나? 원인과 대처는?
7. (예측) `new Semaphore(2)`에서 버그로 `release()`가 두 번 더 불렸다. `availablePermits()`는 얼마이고, 시스템에는 어떤 문제가 생기나? POSIX `sem_post`는 어디까지 막지 않나?
8. (장애 진단) 여러 프로세스가 이름 있는 POSIX 세마포어로 동시 실행 수를 제한한다. 한 프로세스가 크래시한 뒤 서비스를 재시작했는데 첫 요청부터 막힌다. 왜인가? 무엇으로 확인하고 어떻게 대처하나?
9. (설계) 외부 결제 API 호출을 동시 10건으로 제한하는 Java 코드를 설계하라. 공정/비공정 선택, 무한 대기를 피하는 방법, 반납 위치, 대기열 길이 문제를 각각 어떻게 다루나?
