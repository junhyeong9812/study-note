## 질문

1. (왜) 가상 주소 공간이 이루려는 세 가지 목표는 무엇인가? 각각이 없으면 무엇이 깨지나?
2. (그림) 리눅스 x86-64 프로세스의 주소 공간을 낮은 주소부터 그려라. 코드·데이터·bss·힙·mmap 영역·스택·커널의 위치와, 힙과 스택이 자라는 방향을 표시하라.
3. (예측) C 프로그램에서 `malloc(64)`와 `malloc(1 << 20)`의 반환 주소는 `/proc/<pid>/maps`의 어느 줄에 속하나? 왜 다른가?
4. (계산) `size`가 `text 3773, data 704, bss 16`을 보였다. `readelf -lW`의 마지막 LOAD 세그먼트에서 `FileSiz`와 `MemSiz`는 어떤 관계일까? bss는 왜 파일 공간을 차지하지 않나?
5. (그림) 베이스/바운드 방식으로 가상 주소를 물리 주소로 바꾸는 과정을 그려라. 이 방식의 가장 큰 낭비는 무엇이고, 세그먼테이션은 그것을 어떻게 줄이나? 세그먼테이션에 남는 문제는?
6. (경계) 리눅스에서 SIGSEGV의 `si_code`가 `SEGV_MAPERR`인 경우와 `SEGV_ACCERR`인 경우를 각각 예로 들어라. 널 포인터 역참조는 왜 보통 매핑 없는 주소가 되나? "항상"인가?
7. (예측) `malloc(64)`로 받은 메모리를 `free`한 뒤 읽으면? `malloc(1 MB)`로 받은 메모리를 `free`한 뒤 읽으면? 결과가 다른 이유를 VMA로 설명하라.
8. (장애 진단) 사이드카 컨테이너가 `exit 139`로 재시작을 반복한다. 무엇을 뜻하고, 원인 지점을 어떻게 찾나? Java 서비스가 `hs_err_pid*.log`를 남기고 134로 죽는 경우와는 무엇이 다른가?
9. (연결) Java에서 `null` 객체의 필드를 읽으면 프로세스가 죽지 않고 `NullPointerException`이 난다. HotSpot 내부에서는 SIGSEGV와 어떤 관계가 있을 수 있나?
10. (경계) 원고는 "32비트면 2GB 커널 / 2GB 유저", "스택은 기본 1MB"라고 적었다. 리눅스에서 각각 맞나? 맞지 않다면 올바른 값과 출처는?
