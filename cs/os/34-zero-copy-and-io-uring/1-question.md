## 질문

1. (그림) `read(file)` + `write(socket)`로 파일을 보낼 때 데이터가 거치는 복사 네 번을 그리고, DMA 복사와 CPU 복사를 구분하라. 아까운 것은 어느 것인가?
2. (비교) mmap + write, sendfile(NIC gather 미지원), sendfile(gather 지원) 각각에서 CPU 복사는 몇 번 남나? mmap 방식에만 있는 위험은?
3. (경계) sendfile의 `in_fd`로 소켓을 줄 수 있나? `out_fd`가 소켓이 아니어도 되나? 한 번 호출로 3GB 파일을 다 보낼 수 있나?
4. (왜) TLS를 켜면 왜 sendfile을 못 쓰나? kTLS는 이 중 무엇을 되찾아 주고 무엇은 못 되찾나? 진짜 zero-copy가 되려면 무엇이 더 필요한가?
5. (그림) io_uring의 두 링을 그리고, 각 링에서 누가 생산자·소비자이며 누가 head·tail을 움직이는지 적어라. 왜 락이 필요 없나?
6. (예측) io_uring에 읽기 요청 A, B를 순서대로 제출했다. 완료 큐에 B가 먼저 나올 수 있나? 앱은 완료를 어떤 요청과 어떻게 짝짓나?
7. (왜) io_uring은 시스템 콜 수를 어떻게 줄이나? SQPOLL 모드는 무엇을 더 줄이고, 그 권한 요구는 커널 버전에 따라 어떻게 바뀌었나?
8. (장애 진단) 로컬에선 잘 도는 io_uring 기반 서버가 Docker 컨테이너에서 기동 실패한다. `strace`에 무엇이 보일 것이고, 가능한 원인 세 가지는?
9. (장애 진단) Node 서비스를 컨테이너로 옮긴 뒤 파일 I/O 벤치마크가 호스트보다 느려졌는데, 에러 로그는 없다. io_uring과 관련해 무엇을 의심하고 어떻게 확인하나?
10. (장애 진단) 2GB가 넘는 파일 다운로드만 항상 잘린다. 서버는 `sendfile`을 쓴다. 원인과 수정 방법은?
