# os/16-locks-and-spinlocks — 질문

## 질문

1. (그림) `flag` 변수의 load/store만으로 만든 락(`while (flag == 1) ; flag = 1;`)이 상호 배제에 실패하는 실행 순서를 두 스레드의 시간축으로 그려라. 무엇이 "한 동작"이어야 하나?
2. (왜) test-and-set 스핀락을 OSTEP의 세 기준(상호 배제·공정성·성능)으로 평가하라. 왜 CPU 하나에서는 나쁘고 여러 CPU에서는 괜찮을 수 있나?
3. (예측) 티켓 락이 `ticket = 5`, `turn = 3`인 상태다. 새 스레드 X가 `lock()`을 부르면 X의 `myturn`은 몇이고, `unlock()`이 몇 번 더 일어나야 X가 들어가나? 이 구조가 test-and-set보다 공정한 이유는?
4. (왜) futex로 만든 뮤텍스는 경합이 없을 때 시스템 콜을 몇 번 부르나? `FUTEX_WAIT`가 "예상 값(val)"을 인자로 받아 비교하는 이유를, 비교가 없을 때 생기는 실행 순서로 설명하라.
5. (예측) glibc 기본 뮤텍스의 futex word가 0/1/>1(2) 세 상태를 쓴다. A가 잡고 있는 동안 B가 `lock()`을 부르고, 이어서 A가 `unlock()`한다. 각 단계에서 word 값과 시스템 콜 호출 여부를 적어라.
6. (예측) 24 CPU 머신에서 락 하나로 보호하는 공유 카운터를 스레드 1개, 4개, 24개로 올린다. 초당 처리량은 어떻게 변하나? test-and-set 스핀락과 pthread_mutex 중 어느 쪽이 더 크게 무너지나, 왜?
7. (장애 진단) 서비스 CPU가 100%인데 처리량이 거의 없다. 락 문제로 의심된다. `ps -L`, `/proc/<pid>/status`, `strace -c`로 "스핀락 과점유"와 "뮤텍스 경합으로 잠들기"를 어떻게 구분하나?
8. (경계) 유저 공간 스핀락(`pthread_spin_lock`)을 써도 되는 조건은 무엇인가? `pthread_spin_init(3)`이 `SCHED_OTHER`에서의 사용을 "설계 실수"라고 보는 이유는?
9. (설계) Java에서 `new ReentrantLock(true)`를 쓰면 무엇을 얻고 무엇을 잃나? 공정 락인데도 `tryLock()`이 순서를 무시하는 경우는? `lock()` 직후 반드시 따라야 할 코드 형식은?
