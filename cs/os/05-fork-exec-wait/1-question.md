# os/05-fork-exec-wait — 질문

## 질문

1. (그림) 셸이 `ls > out.txt`를 실행하는 과정을 fork·exec·wait로 그려라. `>` 리다이렉트는 어느 시점에, 누가 하나? 이 예로 fork와 exec를 나눈 이유를 설명하라.
2. (예측) `fork()`의 반환값은 부모와 자식에서 각각 무엇인가? `execvp()` 다음 줄이 실행된다면 무슨 뜻인가? 그 자리에서 `exit` 대신 `_exit`를 쓰는 이유는?
3. (예측) `printf("hello ");`(줄바꿈 없음) 직후 `fork()`하고, 부모·자식이 각자 한 줄을 출력한 뒤 끝난다. 출력을 파이프로 보내면 "hello"는 몇 번 나오나? 왜?
4. (그림·계산) 256MB를 모두 쓴 프로세스가 `fork()`한다. fork 순간 무엇이 복사되나? 자식이 256MB 전부를 4KB 간격으로 읽기만 할 때와 쓸 때, 페이지 폴트는 대략 몇 번인가?
5. (경계) fork 후 자식이 물려받는 것과 받지 않는 것을 각각 세 가지 이상 들어라. 부모와 자식이 같은 fd로 `read`하면 파일 오프셋은 어떻게 되나?
6. (경계) `execve()` 뒤에도 남는 것과 사라지는 것은? 열린 fd는 기본으로 어떻게 되나?
7. (예측) 자식이 SIGTERM으로 죽었다. `waitpid`의 status로는 어떻게 알아내나? 셸 `$?`, Java `Process.waitFor()`, Node `'exit'` 이벤트는 각각 무엇을 보여 주나? `exit(256)`은?
8. (장애 진단) 컨테이너에서 `node server.js`를 PID 1로 띄웠다. 앱이 가끔 `sh -c`로 스크립트를 실행한다. 몇 주 뒤 `<defunct>`가 수천 개다. 왜 생기고, 어떻게 고치나?
9. (장애 진단) 서버를 재시작했더니 `bind: Address already in use`가 난다. `ss -ltnp`를 보니 그 포트를 서버가 띄운 헬퍼 프로세스가 잡고 있다. 원인과 코드 수준의 대처는? 파이프를 쓰는 경우 같은 원인이 어떤 증상을 내나?
10. (설계) 스레드가 많은 서비스에서 외부 명령을 자주 실행해야 한다. `fork()`+`exec()` 대신 무엇을 쓰는 게 좋고, 그 이유 두 가지는?
