## 질문

1. (그림) 소켓 `read()` 한 번이 거치는 두 단계를 시간축으로 그리고, 각 단계에서 무엇을 기다리는지 적어라.
2. (분류) 블로킹·논블로킹·I/O 다중화·시그널 구동·비동기 다섯 모델을 "① 준비 대기 동안 / ② 복사 동안 스레드가 무엇을 하나"로 표를 만들어라. POSIX 정의로 동기 I/O는 어느 것들인가?
3. (왜) "블로킹/논블로킹"과 "동기/비동기"는 각각 무엇의 성질인가? epoll + 논블로킹 소켓 조합을 "비동기 I/O"라고 부르면 POSIX 정의로 무엇이 틀렸나?
4. (예측) 논블로킹 소켓에서 읽을 데이터가 없을 때 `read()`는 무엇을 돌려주나? 이식성 있는 코드는 왜 errno 두 개를 검사하나? `read()`가 0을 돌려주면 무슨 뜻인가?
5. (경계) 정규 파일을 `O_NONBLOCK`으로 열고 `poll()`하면 어떻게 되나? epoll에 넣으면? 이 사실이 Node의 파일 I/O 구현에 어떤 결정을 강요했나?
6. (연결) 리눅스에서 비동기 파일 I/O를 하는 세 방법(POSIX AIO, native aio, io_uring)의 한계·특징을 각각 한 줄로 말하라.
7. (장애 진단) 트래픽이 없는데 프로세스 한 스레드가 CPU 100%, `%sy` 비중이 크다. `strace`에 무엇이 보일 것이라 예상하나? 원인과 고치는 방법은?
8. (장애 진단) 톰캣 워커 스레드가 서서히 줄어 요청을 못 받는다. CPU는 한가하다. 어떤 명령으로 스레드 상태를 보고, 무엇을 의심하며, 어떻게 막나?
9. (장애 진단) Node 서버가 평소엔 빠른데 가끔 **모든 요청이 동시에** 수백 ms 멈춘다. 코드에서 `fs.readFileSync`가 보였다. 왜 "모든" 요청이 멈추나?
