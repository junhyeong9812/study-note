# os/03-interrupts-traps-faults — 질문

## 질문

1. (표) 인터럽트·트랩·폴트·어보트를 "계기 / 동기·비동기 / 끝나면 어디로 돌아가나"로 표를 만들고 각각 예를 하나씩 들어라.
2. (왜) 폴트는 왜 "다음 명령"이 아니라 "같은 명령"으로 돌아가나? 페이지 폴트를 예로 설명하라.
3. (예측) x86-64 리눅스에서 다음을 유저 프로그램이 실행하면 어떤 예외 벡터가 나고 셸 exit code는 얼마인가? (a) 정수 `10/0` (b) `int3` (c) NULL 포인터 역참조 (d) 부동소수 `1.0/0.0`
4. (경계) 페이지 폴트가 났다는 것은 버그가 있다는 뜻인가? minor fault, major fault, SIGSEGV로 끝나는 폴트를 구분하라.
5. (계산·예측) 64MB 익명 메모리를 `mmap`한 뒤 4KB 간격으로 한 바이트씩 쓴다. 페이지 크기 4KB일 때 minor fault는 대략 몇 번인가? 같은 루프를 한 번 더 돌면? 캐시에 있는 64MB 파일을 `mmap`해 같은 방식으로 읽으면 왜 1024번 정도만 나올 수 있나?
6. (연결) 64비트 리눅스의 `syscall` 명령은 인터럽트 벡터 테이블(IDT)을 거치나? `int 0x80`은?
7. (그림) NIC에 패킷이 도착해 인터럽트가 걸린 뒤 원래 프로그램으로 돌아오기까지를 상반부·하반부로 나눠 그려라. 왜 둘로 나누나?
8. (장애 진단) 배포 직후 p99가 수백 ms로 뛰는데 CPU 사용률은 낮다. 페이지 폴트를 의심한다면 어떤 지표·명령으로 확인하고, 어떻게 대처하나?
9. (장애 진단) 네트워크 처리량이 오르지 않는데 전체 CPU는 여유다. `mpstat -P ALL`에서 한 코어만 `%soft`가 90%다. 무엇이 일어나고 있고 어디를 보나?
