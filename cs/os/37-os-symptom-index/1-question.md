# os/37-os-symptom-index — 질문

## 질문

1. (왜) 장애 현장에서 증상 이름 하나(예: `exit 137`, `EAGAIN`)만 보고 원인을 적으면 안 되는 이유는 무엇인가? 증상과 함께 확보해야 할 것 두 가지를 말하라.
2. (규칙) 셸이 보여 주는 종료 코드 128+N 규칙을 설명하라. 커널이 부모에게 주는 wait 상태에는 무엇이 들어 있나? 132·134·135·137·139·141·143은 각각 어떤 시그널인가?
3. (경계) JVM이 SIGTERM을 받고 끝났을 때와, 핸들러 없는 C 프로그램이 SIGTERM으로 죽었을 때 셸은 둘 다 143을 보여 준다. 두 경우는 wait 상태에서 어떻게 다른가? Node에서 SIGKILL로 죽은 자식은 어떤 모양으로 보이나?
4. (장애 진단) 파드가 `Exit Code: 137`로 재시작하는데 앱 로그에는 예외가 없고 중간에 끊겨 있다. SIGKILL을 보낸 쪽 후보 셋과, 각각을 가르는 확인 방법을 말하라.
5. (경계) `EAGAIN`이 `read`에서 났을 때, `fork`·`pthread_create`에서 났을 때, `sem_trywait`에서 났을 때 뜻은 각각 무엇인가? 논블로킹 `read`의 `EAGAIN`을 잘못 다루는 두 가지 방식과 그 증상은?
6. (장애 진단) 파일 생성이 `No space left on device`로 실패하는데 `df -h`는 여유 40%다. 가능한 원인 셋과 각각의 확인 명령을 말하라. 반대로 `df`는 가득인데 `du` 합계가 훨씬 작다면?
7. (예측) 8코어 서버의 load가 30인데 `vmstat`의 `id`는 75%다. 무엇을 의심하고 무엇으로 확인하나? 반대로 모든 작업 스레드가 교착으로 멈춘 서비스의 load는 어떻게 보이나, 왜?
8. (구분) `ps`의 R·S·D·T·Z 가운데 load average에 들어가는 것은? 좀비가 쌓인 서버에서 `kill -9 <좀비 PID>`가 소용없는 이유와 올바른 대처는?
9. (연결) Java `OutOfMemoryError: unable to create native thread`는 어느 시스템 콜의 어떤 errno에서 오나? 힙을 늘려도 해결되지 않는 이유와, 확인할 한도 넷을 말하라.
10. (연결) 에러도 지표도 없이 나타나는 OS 증상을 넷 들고, 각각이 가리키는 leaf와 첫 확인 수단을 말하라.
