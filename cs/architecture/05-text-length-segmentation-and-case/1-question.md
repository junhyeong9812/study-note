# architecture/05-text-length-segmentation-and-case — 질문

## 질문

1. (왜) "글자 수"에는 어떤 네 가지 뜻이 있나? 각각을 쓰는 곳(화면·Java/JS·DB·저장/전송 한도)을 짝지어라.
2. (예측) `👨‍👩‍👧`, `🇰🇷`, NFD `한글`, `e`+U+0301의 그래핌·코드 포인트·UTF-16 단위·UTF-8 바이트 수를 각각 예측하라(Java 21 `BreakIterator` 기준).
3. (예측) 국기 이모지 10개(`🇰🇷`×10)를 닉네임으로 넣었다. JS `length <= 10`, 코드 포인트 `<= 10`, 그래핌 `<= 10` 검사는 각각 통과하나? PostgreSQL `VARCHAR(10)`에는 들어갈 것으로 예측하나, 그 예측은 무엇에 기대나?
4. (그림) UAX #29가 국기(Regional Indicator)를 두 개씩 짝짓는 규칙을 상태 기계로 그려라. `🇰🇷🇯🇵`가 왜 `(🇰🇷)(🇯🇵)`이지 `🇰(🇷🇯)🇵`가 아닌가?
5. (경계) `"🇰🇷🇯🇵🇺🇸"`를 UTF-16 단위 3개, 코드 포인트 3개, 그래핌 3개로 자른 결과는? `"가나다😀라"`를 UTF-8 10바이트 이내로 자를 때 바이트 배열을 그냥 자르면 무엇이 남나?
6. (장애 진단) 터키어 로캘 서버에서만 `Level.valueOf(s.toUpperCase())`가 `IllegalArgumentException`을 낸다. 예외 메시지에 무엇이 보이고, 왜 그런가? 어떻게 고치고, 어떻게 테스트로 미리 찾나?
7. (경계) `"STRASSE".equalsIgnoreCase("straße")`와 `"TITLE".equalsIgnoreCase("tıtle")`의 결과는? `equalsIgnoreCase`가 비교하는 방식으로 두 결과를 설명하라.
8. (장애 진단) Spotify가 2013년에 공개한 사고에서 `ᴮᴵᴳᴮᴵᴿᴰ`로 `bigbird`(원문의 예시 이름) 계정을 빼앗는 흐름을 가입·재설정 요청·링크 사용 단계로 그려라. 근본 원인과 Spotify의 대처는?
9. (예측) Java 21에서 `NFKC(lower(x))`와 `lower(NFKC(x))` 중 어느 쪽이 멱등이 아닌가? `ᴮᴵᴳᴮᴵᴿᴰ`에 각각 한 번, 두 번 적용한 결과를 예측하라.
10. (연결) `paypal`과 `pаypаl`(키릴 а)은 NFKC·소문자화로 합쳐지나? 무엇으로 막아야 하나? 단순한 "스크립트가 둘 이상이면 거부" 규칙의 문제는?
