# architecture/04-character-encoding-unicode — 질문

## 질문

1. (왜) 글자를 저장하려면 왜 "문자 집합"과 "인코딩" 두 가지 약속이 필요한가? 둘 중 어느 쪽이 어긋날 때 모지바케가 생기나?
2. (그림) `가`(U+AC00)와 `😀`(U+1F600)를 UTF-8 바이트 틀과 UTF-16 서로게이트 계산으로 각각 손으로 인코딩하라. 결과 바이트를 적어라.
3. (예측) Java 21에서 `"a😀b".length()`, `codePointCount`, 그리고 `"a😀b".substring(0, 2).getBytes(UTF_8)`의 바이트는 무엇인가? 같은 잘린 문자열을 JS `TextEncoder`로 인코딩하면 바이트가 어떻게 다른가?
4. (예측) `"café"`를 UTF-8로 인코딩한 바이트를 ISO-8859-1로 디코딩하면 무엇이 나오고 길이는 몇인가? 이 값을 원래대로 되돌릴 수 있는 조건은 무엇이고, CP949 바이트를 UTF-8로 관대하게 읽은 경우는 왜 되돌릴 수 없나?
5. (경계) `C0 AF`, `ED A0 BD`, `F4 90 80 80`은 각각 왜 올바른 UTF-8이 아닌가? 관대한 디코더와 엄격한 디코더는 각각 어떻게 다루나? 과잉 길이 표현이 보안 문제가 되는 경로는?
6. (그림) `한é`의 NFC와 NFD를 코드 포인트로 그리고, `length()`와 UTF-8 바이트 수를 비교하라. NFKC는 NFC와 무엇이 다르고, 왜 표시용 원문에는 쓰지 않나?
7. (장애 진단) 같은 폴더에 `한글.txt`가 두 개 보이고, 이름으로 찾으면 하나만 찾힌다. 어떤 명령으로 원인을 확인하고, 어떻게 막나?
8. (장애 진단) MySQL에서 이모지가 든 닉네임 저장이 `ERROR 1366 … Incorrect string value`로 실패한다. 원인은 무엇이고, `utf8mb4`로 바꿀 때 인덱스에서 무엇을 확인해야 하나?
9. (연결) Java `String.compareTo`로 정렬한 결과와 UTF-8 바이트·코드 포인트 순 정렬(DB `C`·`utf8mb4_bin`) 결과가 어긋나는 문자는 어떤 것인가? 예를 들어 설명하라.
10. (연결) UTF-8의 "이어지는 바이트는 모두 `10xxxxxx`" 성질은 어떤 알고리즘을 가능하게 하나? 임의의 바이트 오프셋에서 글자 시작을 찾는 코드를 써라.
