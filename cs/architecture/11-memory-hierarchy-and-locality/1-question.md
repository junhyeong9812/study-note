# architecture/11-memory-hierarchy-and-locality — 질문

## 질문

1. (왜) CPU가 매 읽기마다 DRAM까지 간다면 무슨 일이 생기나? 메모리 계층이 이 문제를 푸는 데 필요한 프로그램 쪽 성질은 무엇인가?
2. (그림) 시간 지역성과 공간 지역성을 `for (int i = 0; i < n; i++) sum += a[i];` 한 줄 위에 각각 표시하라. 캐시 라인이 64바이트일 때 `int` 배열에서 미스 한 번이 몇 원소를 데려오나?
3. (예측) 무작위 포인터 사슬의 작업 집합을 16KB → 40KB → 64KB → 2MB → 256MB로 키우면, i7-13700HX P코어에서 접근 1회 지연(사이클)이 어디서 꺾이나? 같은 40KB를 E코어에서 돌리면 어떻게 다른가?
4. (예측) 같은 256MB를 무작위 순서 대신 주소 순서로 이은 사슬로 돌리면 접근 1회 지연이 어떻게 되나? 왜 그런가?
5. (경계) 행 우선 vs 열 우선 합에서 N=64(16KB)일 때는 차이가 거의 없는데, N=4000(61MB)에서는 10배 넘게 벌어진다. 차이가 생기는 조건을 한 문장으로 말하라.
6. (예측) Java에서 같은 400만 개 합을 `int[]`, 할당 순서 그대로의 `ArrayList<Integer>`, 참조 순서만 섞은 `ArrayList<Integer>`로 구하면 원소당 시간 순위와 대략의 배수는?
7. (연결) "배열 vs 연결 리스트"를 고를 때 빅오 표만으로는 무엇을 놓치나? 연결 리스트가 여전히 맞는 경우는?
8. (장애 진단) 정산 배치가 데이터 10배 증가에 시간 30배 증가를 보인다. CPU는 100%, GC는 평범하다. 어떤 순서로 원인을 좁히고 무엇을 바꾸나?
9. (경계) `getconf LEVEL1_DCACHE_SIZE`가 48KB로 나왔다. 이 값을 "이 서버의 L1 크기"로 써도 되나? 이 호스트에서 확인한 사실로 답하라.
10. (연결) CPU 캐시·OS 페이지 캐시·DB 버퍼 풀은 무엇이 같고 무엇이 다른가?
