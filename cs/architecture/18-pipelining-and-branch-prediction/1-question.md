## 질문

1. (왜) 파이프라인은 무엇을 늘리고 무엇은 줄이지 못하나? 5단계(F·D·E·M·W) 파이프라인에서 명령 3개를 처리하는 데 순차 처리와 비교해 몇 칸이 드나?
2. (그림) 데이터 해저드와 제어 해저드를 각각 명령 두 줄로 그려라. 각각의 대표적 처리법은?
3. (그림) 2비트 포화 카운터의 네 상태와 전이를 그려라. "4번 도는 루프(TTTN)"에서 1비트 예측기와 2비트 카운터의 적중률은 각각 몇 %인가? 왜 다른가?
4. (예측) 0~255 난수 32,768개 배열에서 "128 이상만 더하기"를 2,000번 반복한다. 같은 배열을 정렬한 뒤 돌리면 Java 21에서 시간이 대략 어떻게 달라질까? 브랜치리스 판(`s += v & mask`)은 정렬 전후에 어떻게 될까?
5. (경계) 같은 실험을 C로 `gcc -O2`로 컴파일했더니 정렬/무작위 시간이 거의 같았다(0.061s vs 0.067s). 분기 예측이 없어진 것인가? 무엇을 확인해야 하나?
6. (경계) 브랜치리스 코드가 분기 코드보다 느린 경우는 언제인가? 실험 수치로 근거를 대라.
7. (장애 진단) 어제 5분 걸린 집계 배치가 오늘 40분 걸렸다. 데이터 양·I/O·GC는 같고, 입력 파일이 어제는 정렬돼 있었다. 가설과 확인 실험, 대처는?
8. (연결) 이진 탐색에서 "같음을 먼저 검사하는 3갈래 비교"가 비교 횟수는 줄여도 실제로는 느릴 수 있는 이유를 분기 예측으로 설명하라.
9. (계산) 실험의 C 측정에서 무작위 1.04s, 정렬 0.085s, 반복 65,536,000번이었다. 실패율을 50%로 두면 예측 실패 1회당 비용은 몇 ns인가? 이 값을 사이클 수로 바꾸지 않은 이유는?
