# data-structure/43-ds-symptom-index — 질문

## 질문

1. (왜) 이 영역의 증상을 여섯 층(구조의 일관성·연산 비용·호출 스택·용량·분할 상환·지역성)에 놓아라. 증상 색인을 쓰기 전에 "그때의 n"을 먼저 확보해야 하는 이유를 예 두 개로 설명하라.
2. (장애 진단) 서버 한 대가 CPU 한 코어 100%이고 덤프에 `HashMap`이 보인다. 원인 후보 셋을 들고, 셋을 가르는 가장 싼 관찰을 순서대로 말하라. 각 원인의 처방과 leaf는?
3. (예측) `StackOverflowError`를 잡아 `getStackTrace().length`를 찍으면 OpenJDK 21 기본 설정에서 몇이 나오나? 실제 재귀 깊이와 같은가? 0-1 실험의 출력으로 답하고, 이것이 진단에 주는 함의 두 가지를 말하라.
4. (경계) 같은 `ArrayList`에서 for-each 중 `b`를 지우면 예외가 나고 끝에서 두 번째 `c`를 지우면 예외가 없다. 왜인가? 이 차이 때문에 무엇으로 정확성을 지켜야 하나?
5. (장애 진단) OOM이 매번 다른 줄(응답 직렬화, 로그 포맷팅…)에서 난다. 그 줄들을 고치면 되나? 무엇을 보고, 4절의 어느 갈래들을 의심하나? 상한을 두면 증상이 어떻게 바뀌나?
6. (구분) "평균 지연은 정상인데 p99만 튄다"와 "평균 적중률은 조금씩 떨어지는데 어느 날 DB가 넘친다"는 둘 다 비선형 증상이다. 각각의 원인 갈래와 첫 진단을 말하고, 평균 지표가 왜 둘을 가리는지 설명하라.
7. (예측) [44-ds-incidents](../44-ds-incidents/2-summary.md) 실험 A에서 같은 `hashCode`의 키 32,768개를 넣을 때 `String` 키와 비`Comparable` 키의 시간은 각각 얼마였나? 왜 이렇게 갈리나? 자체 키 클래스를 만들 때의 교훈은?
8. (연결) 8절 "하지 말 것" 표의 여섯 항목에서 공통 패턴을 한 문장으로 말하라. 운영에서 한도(`-Xss`·`-Xmx`)를 올려야만 했다면 함께 남겨야 할 기록은 무엇인가?
