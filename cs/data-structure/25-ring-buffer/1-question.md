# data-structure/25-ring-buffer — 질문

## 질문

1. (왜) 생산자와 소비자 사이에 크기 제한 없는 큐 대신 고정 크기 링 버퍼를 두는 이유는? 그 대가로 새로 정해야 하는 것은 무엇인가?
2. (그림) 용량 4의 링에서 빈 상태와 가득 찬 상태를 head·tail로 그려라. 왜 `head == tail` 하나로는 둘을 가를 수 없나? 해결법 세 가지와 각자의 실제 용량을 대라.
3. (예측) 가득 참 검사 없이 `head == tail`만 빈 것으로 보는 링(칸 4개)에 1..4를 넣은 뒤 `isEmpty()`는? 1..6을 넣은 뒤 전부 꺼내면 무엇이 나오나?
4. (경계) 마스크 `seq & (N-1)`이 `seq % N`과 같아지는 조건은? N=6에 마스크 5를 쓰면 0..59의 칸 분포는 어떻게 되나? `int` 시퀀스가 `Integer.MAX_VALUE`를 넘을 때 `&`와 `%`는 각각 어떻게 되나?
5. (예측) 용량 2의 `ArrayBlockingQueue`가 가득 찼을 때 `add`, `offer`, `offer(e, 200ms)`, `put`은 각각 어떻게 응답하나? `put`에서 멈춘 스레드를 스레드 덤프에서 어떻게 알아보나?
6. (연결) 단일 생산자-단일 소비자 링이 락 없이 동작하는 이유는? 생산자가 둘이 되면 무엇이 깨지고, 실험에서는 어떤 모습으로 드러났나?
7. (예측) SPSC 락 없는 링(`long`), 같은 링에 `Long`을 담은 것, `ArrayBlockingQueue<Long>`을 1000만 개로 비교하면 순서는? 이 측정을 일반화할 때 조심할 점 세 가지는?
8. (장애 진단) 디스크가 느려진 날 API 지연이 함께 올랐고 CPU는 낮았다. 스레드 덤프에 요청 스레드가 `WAITING`이다. 링 버퍼 관점에서 원인 후보와 Logback `AsyncAppender`의 관련 기본값, 대처를 대라.
9. (장애 진단) 패킷 일부가 사라지는 듯한데 앱 로그에는 오류가 없다. 어디서 무엇을 보나? 링 크기를 키우는 것만으로 해결되지 않는 경우는?
