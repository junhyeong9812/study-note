# data-engineering/04-slowly-changing-dimensions — 질문

## 질문

1. (왜) 팩트 테이블은 하나도 안 바뀌었는데 "지난달 지역별 매출이 달라졌다"는 일이 어떻게 생기나? as-was 리포트와 as-is 리포트의 차이로 설명하라.
2. (예측) 8월 매출이 busan 700 · daegu 1100 · seoul 300이다. 9/15에 서울 고객 user_001(100)·user_002(200)가 부산으로 이사했고 지역을 Type 1로 덮어썼다. 10/1에 다시 뽑은 8월 지역별 매출은? Type 2였다면 as-was와 as-is는 각각?
3. (그림) Type 2에서 user_001의 이사 전후 차원 행 두 개를 타임라인으로 그려라. 대리 키·내구 키·자연 키·유효 기간·현재 행 표시는 각각 어떤 값인가? Kimball Group이 권하는 최소 세 컬럼은?
4. (경계) SCD Type 0·1·2·3과 4·5·6·7을 한 줄씩 구분하라. Type 6과 Type 7은 같은 기능을 어떻게 다르게 구현하나?
5. (적용) Type 2 차원에서 같은 멤버의 유효 기간 겹침, 빈틈, 현재 행 중복을 찾는 SQL을 써라. 이웃 행 대조 한 번으로 겹침과 빈틈을 어떻게 구분하나?
6. (예측) user_003의 옛 행을 닫지 않은 채 9/10부터 새 행을 열었고, user_005는 옛 행을 9/01에 닫고 새 행을 9/05부터 열었다. 9/12 user_003 구매 900, 9/03 user_005 구매 800을 기간 조인으로 집계하면 각각 몇으로 세지나?
7. (적용) PostgreSQL 17에서 위 6번의 겹침과 현재 행 중복을 적재 시점에 거부하는 제약을 써라. 이 제약으로 막지 못하는 이상은?
8. (장애 진단) 8/30 판매가 9/20에 늦게 도착했고, 그 고객은 9/15에 지역이 바뀌었다. 팩트 적재가 대리 키를 `is_current`로 찾으면 무슨 일이 생기나? 올바른 조회 조건은?
9. (연결) Type 2 유효 기간과 database/50의 유효 시간(valid time)은 어떤 관계인가? 기간을 반열린 구간으로 두는 이유는?
