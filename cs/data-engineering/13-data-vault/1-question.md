# data-engineering/13-data-vault — 질문

## 질문

1. (왜) 원천 시스템이 여럿이고 자주 바뀌는 회사에서, 스타 스키마에 바로 적재하는 방식은 무엇이 어려운가? 데이터 볼트는 무엇과 무엇을 떼어 이 문제를 푸나?
2. (그림) 고객–주문 예로 Hub 2개, Link 1개, Satellite 3개(CRM 고객 속성, BILLING 고객 속성, 주문 금액)를 그려라. 각 표의 키와 공통 메타데이터 컬럼을 적어라.
3. (예측) 스테이징에 `'C001'`(CRM), `' c001 '`(BILLING), `'C002'`가 들어왔다. Hub 키를 `md5(customer_id)`로 만들면 Hub 행은 몇 개인가? `md5(upper(trim(customer_id)))`로 만들면? 고객별 매출(C001 주문 100·200, C002 주문 50)은 각각 어떻게 나오나?
4. (예측) CRM 속성이 5일 동안 (gold, SEOUL) → 같음 → (platinum, SEOUL) → 같음 → (gold, BUSAN)으로 왔고 BILLING 한도는 1000 → 1000 → 1000 → 3000 → 3000이었다. hashdiff로 바뀐 것만 넣으면 두 Satellite의 행 수는? 두 Satellite를 Hub 키만으로 조인해 `sum(credit_limit)`을 구하면 얼마가 나오나?
5. (경계) 해시 키와 시퀀스 대리 키는 적재 순서에서 무엇이 다른가? 해시 키를 "보안용"으로 봐도 되나? 128비트 해시의 무작위 충돌과 정규화 누락 중 어느 쪽이 현실적인 위험인가?
6. (연결) Satellite와 SCD Type 2는 무엇이 같고 무엇이 다른가? `load_ts`와 `EFFECTIVE_FROM`은 각각 어떤 질문에 답하나?
7. (장애 진단) 볼트 위의 고객 리포트가 새 원천이 붙을 때마다 느려진다. 무엇이 원인일 수 있고, PIT 테이블은 이 문제를 어떻게 줄이나? 측정은 어떻게 하나?
8. (장애 진단) Satellite 행 수가 원천은 거의 안 바뀌는데 매일 원천 행 수만큼 늘어난다. 원인 후보 셋과 확인 쿼리는?
9. (장애 진단) 데이터 볼트 구축 프로젝트가 끝났는데 분석가가 여전히 운영 DB 복제본을 직접 조회한다. 무엇이 빠졌나?
