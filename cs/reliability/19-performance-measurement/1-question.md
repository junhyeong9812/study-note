# reliability/19-performance-measurement — 질문

## 질문

1. (왜) 평균 지연 하나로 서비스 성능을 판단하면 무엇을 놓치나? 대신 어떤 숫자들을 함께 보나?
2. (경계) 서버 A의 p99가 10ms, 서버 B의 p99가 500ms다. 두 서버를 합친 p99를 255ms라고 보고하면 무엇이 틀렸나? 올바르게 구하려면 무엇이 필요한가?
3. (그림) coordinated omission을 closed 부하 + 1초 멈춤으로 그려라. 멈춤 동안 무엇이 기록되고 무엇이 빠지나?
4. (예측) 워커 1개·요청당 약 1ms 서버가 1초 멈춘다. 5ms 간격으로 8초 동안 closed 부하를 걸고 "보낸 시각부터" 재면 p50·p99·max는 대략 어떻게 나오나? "계획 시각부터" 재면 p99는? (실험으로 확인)
5. (경계) open 모델과 closed 모델의 차이를 "서버가 느려질 때 도착률"로 설명하라. 각각 어떤 상황을 재현하는 데 맞나?
6. (연결) coordinated omission을 교정하는 두 방법은? HdrHistogram 사후 보정이 동작하려면 무엇을 알아야 하나? 실험에서 보정 후 표본 수가 1600 → 1798이 된 이유는?
7. (연결) HdrHistogram·t-digest·Prometheus 고정 버킷 히스토그램은 각각 어떻게 분위수를 근사하나? 셋 중 "합칠 수 있다"는 성질이 중요한 이유는?
8. (장애 진단) 부하 테스트 p99는 2ms였는데 운영에서는 GC 때마다 p99가 수백 ms로 튄다. 테스트 리포트에서 무엇을 확인하고, 다시 잴 때 무엇을 바꾸나?
9. (적용) 배포 전후 지연을 비교하려 한다. 측정 전에 적어 둘 항목과, "빨라졌다"고 말하기 전에 할 일을 대라.
