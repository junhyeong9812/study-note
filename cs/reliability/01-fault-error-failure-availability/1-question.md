# reliability/01-fault-error-failure-availability — 질문

## 질문

1. (왜) 결함·오류·고장을 Avižienis 외(2004)의 정의로 구분하라. "DB 디스크 불량 → 캐시에 깨진 값 → 사용자에게 틀린 잔액"에서 각각은 무엇인가? DB 팀 입장과 주문 서비스 입장에서 답이 어떻게 달라지나?
2. (경계) 가용성과 신뢰성은 어떻게 다른가? 1시간에 한 번 1초씩 끊기는 서비스는 둘 중 무엇이 높고 무엇이 낮은가?
3. (연결) 시간 기반 가용성과 요청 기반 가용성의 식을 쓰라. 10대 중 1대가 죽어 요청의 10%가 실패하는 동안 둘은 각각 어떻게 나오나? SRE 책은 왜 요청 기반을 쓰나?
4. (예측) 99.9% 서비스 5개를 직렬로 거치는 요청의 가용성은? 월 허용 중단 시간은 대략 얼마에서 얼마로 바뀌나? 실험의 시뮬레이션 값은 공식과 얼마나 맞았나?
5. (예측) MTTF 999시간·MTTR 1시간 부품과 MTTF 499.5시간·MTTR 0.5시간 부품의 가용성은? 둘이 같다면 무엇이 다른가?
6. (그림) LB 2대(각 99.9%) → 앱 3대(각 99%) → DB 1대(99.95%)의 신뢰도 블록 다이어그램을 그리고 가용성을 계산하라. 어느 칸을 손봐야 가장 크게 오르나?
7. (경계) 병렬 식 1−(1−A)(1−B)이 성립하려면 무엇을 가정하나? 실험에서 공통 원인을 넣자 이중화 결과는 어떻게 됐나?
8. (장애 진단) 모든 서비스가 자기 목표 99.9%를 지켰는데 고객 SLA(99.9%) 위반 보상이 나갔다. 무엇을 보고 원인을 어떻게 설명하며, 무엇을 바꾸나?
9. (장애 진단) 에러율 0·경보 없음인데 몇 주 뒤 정산 대조에서 차이가 발견됐다. 고장 분류(3.3.1절)로 이것은 어떤 고장이며, 무엇으로 막나?
