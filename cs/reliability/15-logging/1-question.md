# reliability/15-logging — 질문

## 질문

1. (왜) 지표만 있고 로그가 없으면 무엇을 알 수 없나? 로그가 쓸모 있으려면 갖춰야 할 네 가지는?
2. (경계) 텍스트 로그 `INFO order placed for 1042 (req-7f3a)`와 구조화 로그 `{"mdc":{"requestId":"req-7f3a"},"kvpList":[{"orderId":"1042"}],"message":"order placed"}`는 검색·집계에서 무엇이 다른가? 메시지 문장에 값을 넣지 말아야 하는 이유는?
3. (예측) 요청 스레드에서 `MDC.put("requestId","req-7f3a")` 뒤 스레드풀에 작업을 넘겨 로그를 찍는다. 그 줄의 MDC는? 이어서 풀 스레드가 `req-AAAA`를 넣고 지우지 않은 뒤 다른 요청 B를 처리하면 B의 줄에는 무엇이 찍히나? 둘 중 어느 쪽이 더 위험한가?
4. (예측) 이벤트당 2ms 걸리는 목적지에 2000건(WARN 10%)을 연속 기록한다. Logback 1.5.18 기준으로 동기 appender, `AsyncAppender` 기본 설정, `neverBlock=true`에서 호출 지연과 전달 수가 각각 어떻게 될지 말하라.
5. (경계) `AsyncAppender` 기본 설정에서 WARN 기록 호출이 약 530ms 멈춘 이유를 큐 크기와 워커 동작으로 설명하라.
6. (예측) 요청 1000개 × 줄 5개를 10% 샘플링한다. 줄마다 무작위로 고를 때와 요청 ID 해시로 고를 때, "처음부터 끝까지 볼 수 있는 요청" 수는 각각 대략 몇 개인가?
7. (연결) 12-factor XI장은 로그를 어디에 쓰라고 하나? 그렇게 했을 때 회전 책임은 누구에게 가고, Docker `json-file` 기본값에서 무엇을 조심해야 하나?
8. (경계) 꺼진 DEBUG 로그가 비용이 거의 없다는 말은 어느 조건에서 깨지나?
9. (장애 진단) 로그 수집기가 느려진 시각에 API p99가 같이 올랐다. CPU는 한가하다. 무엇을 보고 원인을 확인하고, 무엇으로 고치나?
10. (적용) 보안 점검에서 로그 저장소에 액세스 토큰이 발견됐다. 무엇을 바꾸나?
