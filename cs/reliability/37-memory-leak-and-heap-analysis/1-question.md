## 질문

1. (왜) GC가 있는데도 누수가 생기는 이유를 "도달 가능성"으로 설명하라. GC 루트의 예를 셋 들어라.
2. (그림) 정상 힙과 누수 힙의 사용량 그래프를 그려라. 어느 선을 봐야 누수가 보이나?
3. (예측) `-Xmx128m`에서 세션(2 KiB 배열 포함)을 5,000개씩 static Map에 넣고 지우지 않는다. GC 직후 사용 힙은 단계마다 얼마씩 오르고, 몇 단계쯤 무엇으로 끝나나? OOM 직전 GC 로그는 어떤 모양인가?
4. (경계) 히스토그램 1위가 `byte[]`일 때 "byte[]를 줄이자"가 답이 아닌 이유는? shallow와 retained의 차이로 설명하라.
5. (그림) 루트→A→C, 루트→A→D, 루트→B→D 그래프의 지배자 트리를 그려라. D의 직접 지배자는? A의 retained set에 D가 들어가나?
6. (예측) 직접 지배자가 계산된 뒤 retained size를 한 번 훑기로 구하려면 어떤 순서로 돌아야 하나? 장난감 실험에서 공유 `Config`의 직접 지배자는 무엇이었나?
7. (예측) `-Xmx64m`에서 direct buffer를 16 MiB씩 쥐고 놓지 않는다. (A) `MaxDirectMemorySize=96m`일 때와 (B) `1g` + 컨테이너 한도 256m일 때 각각 어떻게 끝나나? 힙 사용량은?
8. (적용) "RSS는 오르는데 힙은 평평하다"를 받으면 어떤 순서로 좁히나? 명령도 적어라.
9. (장애 진단) 운영 중인 큰 힙에서 원인을 찾으려 힙 덤프를 떴다가 2차 장애가 났다. 무엇이 일어났고, 어떻게 떴어야 하나?
10. (적용) ThreadLocal이 스레드 풀에서 누수가 되는 조건과 처방은?
