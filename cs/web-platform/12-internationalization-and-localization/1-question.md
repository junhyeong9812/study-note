# web-platform/12-internationalization-and-localization — 질문

## 질문

1. (왜) 국제화(i18n)와 지역화(l10n)는 각각 무엇을 하나? "코드에는 자리만, 나라마다 다른 것은 데이터로"라는 원칙을 문자열·숫자 서식에 적용하면 각각 무엇이 데이터로 빠지나?
2. (계산) 서버가 `ko`, `en`, `de`, `zh-Hant`를 지원한다. `Accept-Language: zh-Hant-TW, de-CH;q=0.8`이 오면 RFC 4647 lookup으로 무엇을 고르나? 서버가 이 헤더로 응답 언어를 바꾼다면 응답에 무엇을 붙여야 하고, 빠지면 CDN에서 무슨 일이 생기나?
3. (예측) Chrome 151에서 `new Intl.PluralRules('ru').select(n)`의 결과를 n = 1, 2, 5, 11, 21, 22, 1.5에 대해 예측하라. `n === 1 ? 'item' : 'items'` 코드가 러시아어·프랑스어에서 틀리는 경우를 하나씩 들라.
4. (예측) `parseFloat("1.234,5")`, `Number("1.234,5")`, `parseFloat("1,234.5")`의 결과는? 이 동작이 금액 처리에서 위험한 이유는?
5. (예측) 같은 순간 `2026-03-01T15:30:00Z`를 `America/New_York`과 `Asia/Seoul`로 표시하면 날짜가 각각 며칠인가? "오늘 주문 수" 집계에 주는 교훈은?
6. (경계) `new Intl.NumberFormat('xx-YY')`와 `new Intl.NumberFormat('en_US')`는 각각 어떻게 되나(Chrome 151, 기본 로캘 en-US)? 어느 쪽이 더 늦게 발견되는 버그를 만드나?
7. (경계) 조합형 한글 "한글"(자모 6개)과 이모지 가족 "👨‍👩‍👧"의 `length`와 보이는 글자 수는? 입력 길이 제한을 무엇으로 걸어야 하나?
8. (예측) 400px 부모 안 100px 자식에 `margin-left: 40px`와 `margin-inline-start: 40px`를 각각 주고 부모를 `dir="rtl"`로 바꾸면, 두 자식의 오른쪽 간격은 각각 몇 px가 되나?
9. (장애 진단) 번역 파일에 `"총 "`, `"개 상품"` 같은 키가 있고, 독일어 화면의 문장이 어색하다는 신고가 들어온다. 원인과 고치는 방법(메시지 문법 예 포함)은?
10. (장애 진단) 특정 국가 사용자들이 가입 폼에서 계속 이탈한다. 폼은 "성(필수)·이름(필수), 영문만, 각 20자 이내"다. 어떤 가정이 깨졌고 어떻게 바꾸나?
