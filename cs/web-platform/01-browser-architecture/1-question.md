# web-platform/01-browser-architecture — 질문

## 질문

1. (왜) Chromium은 왜 웹 콘텐츠를 브라우저 UI와 다른 프로세스에서 돌리나? 안정성과 보안 두 측면으로 설명하라.
2. (그림) 브라우저 프로세스·렌더러 프로세스·Viz 프로세스·네트워크 서비스가 각각 무엇을 맡는지 상자 그림으로 그리고, 렌더러 안의 메인 스레드와 컴포지터 스레드의 일을 나눠 적어라.
3. (계산) `https://shop.example.co.kr:8443/cart`의 출처와 사이트는 각각 무엇인가? `http://127.0.0.1:5000`과 `http://127.0.0.1:6000`은 같은 출처인가, 같은 사이트인가?
4. (예측) 127.0.0.1:P1 페이지에 (a) 127.0.0.1:P2 iframe, (b) localhost:P1 iframe을 넣으면 headless Chrome 151에서 렌더러 수와 OOPIF 수는 iframe 없을 때보다 각각 얼마나 늘까?
5. (예측) 탭1이 4초 동기 루프에 빠졌다. 탭1이 `window.open`으로 연 같은 사이트 팝업, 같은 사이트의 별도 탭, 다른 사이트 탭 중 어느 것이 1.5초 안에 `evaluate(1+1)`에 응답할까? 이유는?
6. (경계) 사이트 격리가 막아 주는 것과 막아 주지 않는 것은? 같은 등록 도메인의 두 서브도메인 사이, 그리고 다른 사이트 iframe 사이로 나눠 답하라.
7. (연결) 사이트를 계산하려면 eTLD를 알아야 한다. Chromium은 Public Suffix List를 어떤 자료구조로 들고 있으며, 왜 호스트를 뒤집어 조회하나?
8. (장애 진단) 광고 iframe이 많은 뉴스 페이지가 저사양 기기에서 자주 재로드된다. 무엇을 확인하고 어떻게 줄이나?
9. (장애 진단) 결제 팝업을 연 뒤 원래 페이지까지 굳는다는 제보가 왔다. 아키텍처 관점의 원인 가설과 대처는?
