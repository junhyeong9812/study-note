# distributed/31-byzantine-and-blockchain — 질문

## 질문

1. (왜) Raft·Paxos의 과반 정족수는 왜 거짓말하는 노드 하나 앞에서 무너지나? 이중 발언(equivocation)을 예로 들어라.
2. (계산) n대 중 f대가 비잔틴일 때 PBFT 논문은 왜 n ≥ 3f+1이 필요하다고 하나? n − f, f, f를 써서 논증하라. 정족수 2f+1의 교집합은 몇 대 이상인가?
3. (예측) 이중 발언 열거 실험에서 (n, f, q) = (3,1,2), (4,1,3), (5,1,3), (5,1,4), (7,2,5)는 각각 서로 다른 값의 확정을 허용하나? 판정 공식은?
4. (그림) PBFT의 정상 동작을 클라이언트·주·백업 셋으로 그려라. PREPARE 단계와 COMMIT 단계는 각각 무엇을 지키나? 클라이언트는 왜 f+1개의 같은 응답을 기다리나?
5. (경계) PBFT의 안전성과 진행은 각각 어떤 가정에 기대나? 나쁜 주가 일을 안 하면 어떻게 되나?
6. (연결) 참가자를 모르는 열린 그룹에서 머릿수 투표가 안 되는 이유는? 비트코인은 무엇으로 투표하고, 무엇을 정답 사슬로 보나?
7. (예측) 계산량 비율 q=0.1인 공격자가 z블록 뒤에서 따라잡을 확률을 논문 식으로 z=1, 5, 10에 대해 대라. 블록 경주를 그대로 몬테카를로로 돌리면 논문 값보다 큰가 작은가? 왜 차이가 나나?
8. (예측) SHA-256 해시 사슬 10칸에서 4번 칸 거래만 고치면 검사 결과는? 해시까지 고치면? 끝까지 다시 계산하면? 이 결과가 사슬 운영에 주는 교훈은?
9. (장애 진단) 결제 확인 후 보낸 물건의 거래가 사슬에서 사라졌다. 무엇이 일어났고, 어떻게 막나?
10. (적용) 사내 감사 로그의 변조를 감지하고 싶다. BFT·블록체인이 필요한가? 신뢰 모델 질문 순서로 답하고, 최소 구성을 제시하라.
