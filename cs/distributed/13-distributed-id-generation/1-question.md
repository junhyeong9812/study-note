# distributed/13-distributed-id-generation — 질문

## 질문

1. (왜) DB 시퀀스 하나, UUIDv4, Snowflake, UUIDv7, 시퀀스 블록을 "조율·정렬·크기" 세 축으로 비교하라. 트위터가 Snowflake를 만든 직접 이유는?
2. (그림) 트위터 원본 Snowflake의 64비트 배치를 그려라. 41비트 시각이 약 69년인 이유와, 순번 12비트가 바닥나면 원본 코드가 하는 일은?
3. (예측) Snowflake 생성기가 실행 중에 시계가 500ms 뒤로 가면 어떻게 되나? 같은 상황에서 프로세스를 재시작했다면? 실험 결과로 답하라.
4. (예측) 두 인스턴스가 같은 worker ID로 ms당 3개씩 1초 동안 발급하면 중복이 몇 개쯤 나오나? 왜 그 정도인가?
5. (경계) Snowflake ID가 "시간 순"이라는 말은 어디까지 맞나? 한 노드 안, 노드 사이, 같은 ms 안을 나눠 답하라.
6. (그림·연결) UUIDv7의 비트 배치와 같은 ms 안 순서를 보태는 RFC 9562의 세 방법을 대라. PostgreSQL 18의 `uuidv7()`은 어느 방법이며, 순서 보장 범위는?
7. (예측) PostgreSQL 18에서 bigint 시퀀스·`uuidv4()`·`uuidv7()` 기본 키에 각각 20만 행을 넣으면 `avg_leaf_density`·`leaf_fragmentation`은 어떻게 다를까? v7 인덱스가 bigint보다 큰 이유는?
8. (경계) 시퀀스 블록(구간 할당)의 장점과 두 가지 부작용은? PostgreSQL `CACHE`와 JPA `allocationSize`는 이것과 어떤 관계인가?
9. (장애 진단) 프런트에서 넘어온 주문 ID로 조회하면 "없는 주문"이다. 서버 로그 ID와 끝자리만 다르다. 원인과 대처는? Snowflake ID는 언제부터 이 문제에 걸리나?
10. (장애 진단) worker ID를 etcd 리스로 배정하기로 했다. 같은 번호를 둘이 잡지 못하게 하는 방법, 그리고 리스만으로 부족한 경우와 그 대처는?
