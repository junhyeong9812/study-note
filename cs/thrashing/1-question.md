## 질문

1. (정의) 동적 배열에서 말하는 thrashing이란 무엇이며, 비용이 드는 실제 동작은 무엇인가?
2. (왜) 축소 조건을 "size가 capacity의 절반 이하면 capacity를 절반으로"로 잡으면 왜 thrashing이 생기는가? capacity = 32, size = 16에서 삭제 1회 → 추가 2회가 일어나는 시나리오로 설명하라.
3. (예측) 확장 조건 `size == capacity → ×2`, 축소 조건 `size <= capacity/4 → /2`일 때, capacity = 32에서 size가 16 → 12 → 8로 줄면 각 시점에 무슨 일이 일어나는가? 축소 직후 다시 확장되려면 size가 얼마까지 늘어야 하는가?
4. (핵심) "1/4라는 비율 자체가 핵심은 아니다"라고 했다. 그렇다면 진짜 핵심은 무엇인가?
5. (연결) 올라갈 때의 기준과 내려갈 때의 기준을 다르게 두는 이 설계를 일반적으로 무엇이라 부르는가?
