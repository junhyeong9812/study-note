#### 2. TODO 2 — Snowflake.nextId (이 상자의 본체)

```java
// TODO 2: 시각, 노드, 일련번호를 한 long 에 담는다. 이 상자의 본체다.

// 다섯을 지켜야 한다.
//
//   1. **시계가 뒤로 가면 던진다.** ClockWentBackwardsException 이 그 이유를 적어뒀다.

//   3. 밀리초가 바뀌면 **일련번호를 0 으로 되돌린다.** 안 되돌리면 쓸데없이 기다리게 되고,
//      id 를 보고 "이 밀리초의 몇 번째" 를 알 수 없게 된다.
//   4. 기준 시각보다 앞이면 던진다. 안 막으면 음수 시각이 되어 id 가 음수가 된다.
```
