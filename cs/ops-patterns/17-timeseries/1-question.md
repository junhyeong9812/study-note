#### 2. RollingSeries — record / rollUp (TODO 3\~4)

```java

public void record(long at, double value) {
    // TODO 3: 값을 그 시각이 속한 가는 버킷에 넣는다.
    //
    // **이미 접힌 구간의 값은 버려라.** 지금 넣으면 가는 버킷과 굵은 버킷이 어긋나서
    // 같은 값이 두 번 세어지거나 요약이 두 갈래로 갈린다.
    // 버린 수를 세라. 버리는 것도 손실인데, 세어두면 보존 기간이 짧다는 신호가 된다.
}

public int rollUp() {
    // TODO 4: 보존 기간이 지난 가는 버킷을 굵은 버킷으로 접는다.
    //
    // **컷오프에 딱 걸린 버킷은 아직 접지 마라.** 한 칸 일찍 접으면 보존 기간이
    // 약속보다 짧아지고, 그 버킷에 늦게 도착한 값이 버려지기 시작한다.
```

#### 4. 무엇을 얻고 무엇을 잃는가
