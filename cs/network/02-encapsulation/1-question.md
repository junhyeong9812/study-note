# network/02-encapsulation — 질문

## 질문

1. (왜) 각 층이 위층 데이터를 "해석하지 않는 payload"로 다루면 무엇이 좋은가? 라우터를 예로 설명하라.
2. (그림) HTTP 메시지 하나가 이더넷으로 나갈 때 붙는 헤더를 순서대로 그리고, 옵션 없는 최소 크기를 각각 적어라. 뒤에 붙는 것도 있나?
3. (정의) 수신 쪽의 각 층은 "다음에 누구에게 넘길지"를 어떤 헤더 필드로 아나? 링크·인터넷·전송 계층 각각 하나.
4. (계산) 이더넷 MTU 1500에서 옵션 없는 IPv4 + TCP 세그먼트의 최대 데이터(MSS)는 몇 바이트인가? 옵션 없는 IPv6면?
5. (예측) 패킷이 라우터 두 개를 지나 도착했다. 이더넷 목적지 MAC, IP 목적지 주소, TTL, TCP 포트 중 무엇이 바뀌었나? IPv4 헤더 체크섬은 왜 홉마다 다시 계산하나?
6. (경계) 헤더 파서를 "IP 헤더 20바이트, TCP 헤더 20바이트"로 고정해 짰다. 어떤 패킷에서 틀리고, 어떻게 고치나?
7. (계산) 물리 MTU 1500인 IPv4 망 위에 VXLAN 오버레이를 깔았다. 안쪽 IP 패킷의 최대 크기는 얼마이고, 그 50바이트는 무엇들로 이루어지나?
8. (장애 진단) VPN을 켠 뒤 로그인·헬스체크는 되는데 큰 파일 다운로드만 멈췄다가 끊긴다. 원인을 추정하고, 확인 명령과 대처 두 가지를 말하라.
