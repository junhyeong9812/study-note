# network/07-ip-addressing-cidr — 질문

## 질문

1. (왜) MAC 주소만으로 인터넷 전체를 라우팅할 수 없는 이유는 무엇인가? IP 주소의 "계층형"이란 무엇을 뜻하나?
2. (계산) `10.20.30.200/26`의 망 주소, 브로드캐스트 주소, 블록 크기를 구하라. 어떤 비트 연산으로 구하나?
3. (경계) `/24` 서브넷에서 호스트에 줄 수 있는 주소는 보통 몇 개인가? `/31`, `/32`, 그리고 AWS 서브넷에서는 어떻게 달라지나?
4. (예측) `172.16.0.0/12`와 `172.17.0.0/16`은 겹치나? 두 CIDR 블록이 "일부만 겹치는" 경우가 있을 수 있나? 이유는?
5. (왜) 클래스 A/B/C 방식을 CIDR로 바꾼 두 가지 이유는 무엇인가? 연속된 `/24` 네 개를 한 줄로 광고하려면 어떤 조건이 필요한가?
6. (암기·연결) RFC 1918 사설 대역 세 개, 루프백, 링크 로컬, CGN 공유 대역을 적어라. 사설 대역이 조직 간 연결에서 문제를 일으키는 이유는?
7. (IPv6) `2001:0db8:0000:0000:0000:0000:0000:0001`을 가장 짧게 적어라. `::`를 두 번 쓸 수 없는 이유와, IPv6에서 브로드캐스트 대신 쓰는 것은?
8. (장애 진단) 도커를 설치한 개발 서버에서 사내 `172.17.x.x` 서버에만 접속이 안 된다. 무엇을 확인하고 어떻게 고치나?
9. (장애 진단) "내부 주소면 거절" 검사를 넣었는데 내부 서비스가 호출됐다. 어떤 주소들이 빠졌을 수 있고, 검사 방식에서 무엇이 잘못됐을 수 있나?
