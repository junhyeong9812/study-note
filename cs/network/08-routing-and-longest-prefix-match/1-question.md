# network/08-routing-and-longest-prefix-match — 질문

## 질문

1. (예측) 테이블에 `0.0.0.0/0 → isp`, `10.0.0.0/8 → r1`, `10.144.0.0/16 → r2`, `10.144.2.0/24 → r3`가 있다. `10.144.2.5`, `10.144.9.1`, `10.9.9.9`, `8.8.8.8`은 각각 어디로 가나?
2. (왜) 라우터는 왜 "가장 구체적인(가장 긴) 프리픽스"를 골라야 하나? 짧은 쪽을 고르면 무엇이 깨지나?
3. (그림) 호스트 A → R1 → R2 → 호스트 B로 가는 동안, 홉마다 바뀌는 헤더 필드와 끝까지 그대로인 필드를 구분하라(NAT 없음).
4. (경계) 같은 서브넷에 있는 목적지로 보낼 때와 다른 망으로 보낼 때, 호스트가 이더넷 목적지 MAC으로 무엇을 쓰나?
5. (왜) TTL은 누가, 언제, 얼마나 줄이나? 0이 되면 무슨 일이 일어나고, 그 규칙이 없으면 라우팅 루프는 어떻게 되나?
6. (자료구조) 경로 백만 개에서 최장 접두사를 찾을 때, 트라이 조회 비용이 경로 수와 무관한 이유는? 리눅스 FIB는 어떤 트라이를 쓰나?
7. (경계) 리눅스 경로 종류 `unreachable`, `prohibit`, `blackhole`의 차이를 "원격 송신자가 받는 것"과 "로컬 프로그램이 받는 에러"로 설명하라.
8. (장애 진단) 특정 대역으로의 연결이 RST도 ICMP도 없이 전부 타임아웃난다. 무엇을 의심하고 어떤 순서로 좁혀 가나?
9. (장애 진단) 서버 `tcpdump`에는 SYN 수신과 SYN-ACK 송신이 보이는데, 클라이언트는 SYN-ACK를 받지 못한다. 방화벽이 이중화된 구간이다. 원인과 대처는?
10. (장애 진단) VPN을 켜자 사내 `10.8.x.x`에는 되는데 원래 되던 `10.20.x.x` 서버가 안 된다. 어떤 명령으로 무엇을 확인하나?
