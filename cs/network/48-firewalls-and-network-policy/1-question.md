# network/48-firewalls-and-network-policy — 질문

## 질문

1. (그림) 리눅스 netfilter에서 "나에게 온 패킷", "지나가는 패킷", "내가 만든 패킷"이 각각 어느 체인을 지나는지 그려라.
2. (경계) 상태 방화벽과 무상태 방화벽의 차이를, 서버가 외부 API를 호출하고 응답을 받는 상황으로 설명하라.
3. (예측) 클라이언트가 connect 타임아웃 없이 연결한다. 목적지 방화벽이 (a) DROP, (b) 기본 REJECT, (c) `reject-with icmp-host-prohibited`일 때 리눅스 클라이언트가 보게 되는 결과와 걸리는 시간은?
4. (왜) 규칙이 수만 개일 때 지연이 늘어나는 이유와, ipset·nftables 집합이 그것을 어떻게 바꾸는지 설명하라.
5. (적용) `ct state established,related accept`를 체인 맨 앞에 두는 이유는? `ct state invalid`에 reject 대신 drop을 쓰는 이유는?
6. (경계) AWS 보안 그룹과 네트워크 ACL의 차이 네 가지를 말하라. 침해 대응으로 "지금 당장" 연결을 끊어야 할 때는 어느 쪽을 쓰나?
7. (장애 진단) 요청은 서버에 도착하고 서버는 SYN/ACK를 보냈는데 클라이언트는 타임아웃이다. 최근 경로가 추가됐다. 원인 가설과 확인 방법은?
8. (장애 진단) 네임스페이스에 NetworkPolicy "기본 거부"를 건 뒤 모든 외부 호출이 `UnknownHostException`으로 실패한다. 왜이며 어떻게 고치나?
9. (적용) Java 서비스에서 DROP과 REJECT를 로그로 구분하려면 어떤 예외를 어떻게 나눠 잡고, 무엇을 반드시 설정해야 하나?
