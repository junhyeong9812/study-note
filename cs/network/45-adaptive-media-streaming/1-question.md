# network/45-adaptive-media-streaming — 질문

## 질문

1. (왜) 영상 파일 하나를 통째로 HTTP로 받는 방식과 비교해, 세그먼트 + 매니페스트 방식이 해결하는 문제 세 가지는?
2. (그림) HLS의 마스터 재생목록 → 미디어 재생목록 → 세그먼트 관계를 그리고, DASH MPD에서 각각에 대응하는 요소를 적어라.
3. (예측) 목표 길이(TARGETDURATION)가 6초인 라이브 스트림에서, 플레이어가 RFC 8216 규칙대로 시작하면 라이브 끝에서 최소 몇 초 뒤처지나? 그 외에 지연을 더하는 요소는?
4. (경계) 라이브 재생목록을 다시 받았는데 바뀌지 않았다. 플레이어는 언제 다시 요청하나? 바뀌었을 때는?
5. (왜) 화질을 중간에 바꾸려면 인코딩·패키징 단계에서 무엇이 맞아야 하나? 안 맞으면 어떤 증상이 나오나?
6. (연결) Shaka Player가 처리량을 "빠른 EWMA와 느린 EWMA의 최솟값"으로 추정하는 이유는? 버퍼 기반 ABR은 무엇을 입력으로 쓰나?
7. (적용) VOD 세그먼트, 라이브 세그먼트, 라이브 미디어 재생목록의 캐시 TTL을 각각 어떻게 정하나? 근거는?
8. (장애 진단) 생중계가 TV보다 수십 초 늦고, 재생목록을 여러 번 받아도 MEDIA-SEQUENCE가 한동안 그대로다. 무엇을 확인하고 어떻게 고치나?
9. (장애 진단) 인기 경기 시작 직후 리버퍼링이 급증했고 CDN 미스율이 높다. 원인 경로와 대처를 설명하라.
10. (장애 진단) 화질이 몇 초마다 올라갔다 내려갔다 한다. 되먹임 구조로 원인을 설명하고 대처 세 가지를 들어라.
