# network/13-routing-protocols-ospf-bgp — 질문

## 질문

1. (왜) 정적 라우팅만으로 큰 망을 운영하기 어려운 이유 두 가지를 말하라. 라우팅 프로토콜은 무엇을 자동화하나?
2. (비교) 링크 상태·거리 벡터·경로 벡터는 각각 이웃에게 **무엇을** 보내고, 각 라우터가 **무엇을** 가지고 계산하나? 대표 프로토콜과 계산 알고리즘을 짝지어라.
3. (그림) A–B–C 일렬 망에서 망 N은 C에 직접 붙어 있다. B–C 링크가 끊겼다. 거리 벡터에서 A와 B가 서로 거리를 올려 가는 과정을 그려라. split horizon은 이것을 어떻게 막나?
4. (예측) OSPF 망에서 링크 하나가 끊기면 어떤 순서로 모든 라우터의 테이블이 바뀌나? 거리 벡터보다 수렴이 빠른 이유는?
5. (경계) BGP는 목적지까지 AS 경로 전체를 전한다. 이 정보로 루프를 어떻게 막나? 그리고 BGP가 "최단 경로"보다 먼저 보는 것은 무엇인가?
6. (장애 진단) 2008년 Pakistan Telecom이 `208.65.153.0/24`를 광고하자 YouTube(`208.65.152.0/22`) 트래픽이 파키스탄으로 갔다. 왜 /24가 이겼나? YouTube는 어떻게 되찾았나?
7. (장애 진단) 2021년 Facebook은 서버가 살아 있는데 인터넷에서 사라졌다. BGP와 DNS가 어떤 순서로 얽혔나? 사용자 앱의 재시도는 무엇을 더했나?
8. (장애 진단) 라우터 로그에 "Hold Timer Expired"가 몇 분마다 찍히고 세션이 다시 맺어진다. 무엇이 일어나고 있고 무엇부터 확인하나?
9. (장애 진단) 새로 연결한 OSPF 라우터의 이웃 상태가 ExStart에서 멈춰 있다. 가장 흔한 원인은 무엇인가?
10. (연결) BGP 하이재킹을 막는 운영 수단 두 가지를 들고, 각각 무엇을 검사하는지 말하라.
