# network/25-kernel-network-stack — 질문

## 질문

1. (그림) 패킷이 NIC에 도착해서 앱의 `recv()`로 돌아오기까지의 단계를 순서대로 적어라. DMA·IRQ·NAPI·softirq가 각각 어디에 들어가나?
2. (왜) NIC가 패킷마다 인터럽트를 걸면 무엇이 문제인가? NAPI는 이를 어떻게 푸나?
3. (정의) RX 링 버퍼는 어떤 자료구조이고, 가득 차면 무슨 일이 일어나나? 이 손실이 앱에 "조용한" 이유는?
4. (경계) RSS와 RPS는 각각 무엇이고, 어디(하드웨어/소프트웨어)에서 CPU를 고르나? 둘 다 켜도 흐름 하나가 여러 코어로 나뉘지 않는 이유는?
5. (그림) `send()`에서 NIC까지의 송신 경로를 적어라. qdisc는 무엇이고 어디에 있나?
6. (예측) iptables가 DROP한 수신 패킷은 tcpdump에 보이나? qdisc에서 버려진 송신 패킷은? 각각 이유를 탭 위치로 설명하라.
7. (연결) `struct sk_buff`는 어떤 자료구조로 큐에 묶이나? 헤더를 붙이고 벗길 때 데이터를 복사하지 않는 방법은?
8. (장애 진단) 트래픽 폭증 순간 p99가 튀는데 앱 로그는 깨끗하다. 드롭 위치를 찾으려면 어떤 명령을 어떤 순서로 보나?
9. (장애 진단) CPU 전체 사용률은 30%인데 처리량이 더 오르지 않는다. `mpstat`에서 CPU0만 `%soft` 100%다. 원인 후보와 대처를 말하라.
10. (경계) `rx_dropped`와 `rx_missed_errors`는 커널 정의상 어떻게 다른가? `/proc/net/dev`의 drop 칸에는 무엇이 합쳐져 나오고, `ip -s link`는 이를 어떻게 보여 주나?
