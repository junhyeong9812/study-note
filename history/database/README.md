# 데이터베이스 변천사 — 쉽게 다시 쓴 판

> 원본: `~/project/database-history/README.md` — 이 문서는 그 내용을 초보자용으로 다시 쓴 것이다(2026-09-18).\
> 연도·인명·논문명·표준번호·코드는 원문 그대로다.\
> 「한눈에」 도식, 목차의 한 줄 요약, 「급하면 이렇게 골라 읽어도 된다」는 원문에 없는 보충 설명이다.

데이터베이스의 역사를 **시대순 + 개념사**로 정리한 문서 모음이다.\
어떤 시스템이 언제·왜 등장했고, 무엇에서 파생됐으며, 어떤 한계에 대한 반작용이었는지를 다룬다.\
모든 문서는 한국어다. (자매: `java-history`)

01~05가 "어떤 제품이 언제 나왔나"라면, 06은 "그 제품들이 공통으로 쓰는 부품이 언제 만들어졌나"다.

## 읽는 법

01→06 시간순으로 읽으면 하나의 줄거리가 보인다.\
**관계형 → NoSQL(분산 위해 일관성 포기) → NewSQL**(둘 다 되찾기)의 변증법이다.\
06은 그 흐름을 뒷받친 *개념*(왜 가능했나)을 모은다 — corpus의 `데이터-정합성`·`일관성-모델` 문서와 이어진다.

> 큰 줄기: **단일 노드 정확성(ACID) → 웹스케일 압박 → 분산 타협(CAP·BASE) → 분산+ACID 재통합(TrueTime·합의) → 워크로드별 특화(벡터·시계열·그래프).**

급하면 이렇게 골라 읽어도 된다.

- 지금 쓰는 RDBMS가 왜 이렇게 생겼는지 알고 싶다 → **01 → 06**
- 왜 어떤 DB는 "최신 값을 보장하지 않는다"고 하는지 알고 싶다 → **03 → 06의 CAP·복제 절**
- 분산 DB를 고르는 중이다 → **04 → 05**
- LLM/RAG 때문에 벡터 DB를 봐야 한다 → **05의 4절**
