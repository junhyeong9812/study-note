# 네트워크 변천사 — 쉽게 다시 쓴 판

> 원본: `~/project/network-history/README.md` — 이 문서는 그 내용을 초보자용으로 다시 쓴 것이다(2026-09-18).\
> 연도·인명·RFC 번호·표준명은 원문 그대로다.\
> 「한눈에」 ASCII 도식 1개와 목차의 「시기」·한 줄 요약, 「급하면 이렇게 골라 읽어도 된다」 길찾기는 원문 README에 없는 보충이다.\
> 그중 「시기」와 한 줄 요약은 **각 편 본문에서 발췌한 보충**이다.

네트워크의 역사를 **인터넷 탄생 + 프로토콜 스택 + 주소/라우팅 + 보안 + 응용 프로토콜 + 현대 네트워킹**으로 정리한 문서 모음이다.\
패킷교환에서 시작한 ARPANET이 어떻게 전 지구 인터넷이 됐고, 그 위에서 어떤 계층과 프로토콜이 쌓였는지를 다룬다.\
모든 문서는 한국어. (자매: `web-history`·`java-history`)

## 한눈에 — 6편이 하나로 이어지는 그림

```text
1969 ──── 1983 ──── 1993 ──── 1998 ──── 2011 ──── 2015 ──── 2021 ──── 현재
  │
  ▼
┌──────────────────┐
│ 01 인터넷의 탄생 │  ARPANET(1969) · 패킷교환 · TCP/IP(Cerf·Kahn) · 1983 Flag Day
└──────────────────┘
  │
  └─ 그 뒤로는 다섯 편이 각자의 범위를 다룬다
     (아래 다섯 줄은 각 편이 다루는 범위를 그 편의 절 순서대로 늘어놓은 것이다.
      줄과 줄 사이의 관계는 이 그림에서 표시하지 않는다.)

02 계층 스택   OSI 7계층(1984) vs TCP/IP 4계층 ── IP · TCP(Reno→BBR) · UDP · 포트와 소켓
03 주소·경로   클래스풀 ─ CIDR(1993) ─ IPv4 고갈→IPv6 ─ NAT ─ DNS ─ DHCP ─ BGP ─ 애니캐스트
04 보안        공개키(1976) ─ X.509(1988) ─ SSL/TLS ─ IPsec ─ 방화벽 ─ DDoS ─ 제로트러스트(2010)
05 응용 계층   Telnet/FTP/SMTP ─ SSH(1995) ─ SOAP/REST ─ gRPC(2015) ─ WebSocket(2011)·MQTT(1999/2014)
06 현대 운영   CDN(1998) ─ SDN(2008) ─ VXLAN(2014) ─ QUIC(2021) ─ Istio(2017) ─ eBPF·엣지
```

그림 읽는 법 — 맨 위 01편이 출발점이고, 아래 다섯 줄이 나머지 다섯 편이다.\
맨 위 연도 줄은 각 줄에 찍힌 연도를 읽는 눈금일 뿐이고, 다섯 줄이 같은 해에 나란히 놓였다는 뜻은 아니다.\
원문 README가 적은 순서 그대로 **01→02가 기반(인터넷·스택), 03이 주소·경로, 04가 보안, 05가 응용 계층, 06이 현대 운영**이다.

## 읽는 법

01→02가 *기반*(인터넷·스택), 03이 *주소·경로*, 04가 *보안*, 05가 *응용 계층*, 06이 *현대 운영*.\
02·06은 `web-history`의 HTTP/QUIC, corpus의 `확장성`·`인프라`와 직접 이어진다.\
관통 논지: **best-effort IP 위에 계층으로 신뢰·보안·효율을 쌓아 올린 역사.**

> 큰 줄기: **패킷교환(1969) → TCP/IP 단일화(1983) → 계층 스택 → 주소·라우팅으로 전 지구 연결 → 보안·응용 프로토콜 → 클라우드·엣지·메시로 분산.**

급하면 이렇게 골라 읽어도 된다.

- 인터넷이라는 게 어떻게 시작됐는지부터 알고 싶다 → **01**
- "TCP는 뭘 보장하고 UDP는 뭘 포기하나"가 궁금하다 → **02**
- IP 주소·DNS·공유기가 왜 이렇게 생겼는지 알고 싶다 → **03**
- HTTPS 자물쇠가 실제로 무엇을 보증하는지 알고 싶다 → **04**
- REST와 gRPC 중 무엇을 쓸지 지금 고르는 중이다 → **05의 3절 → 5절(직렬화)**
- 실시간 알림을 폴링 말고 어떻게 보낼지 찾고 있다 → **05의 4절**
- 쿠버네티스·서비스 메시·CDN이 네트워크를 어떻게 바꿨는지 알고 싶다 → **06**
- 네트워크 전체 지도를 한 번에 잡고 싶다 → **01 → 02 → 03 → 06**
