# Redis - 동작 구조 분석

이 폴더는 Redis(C)의 동작 구조를 소스 기준으로 정리하는 자리다. 단일 스레드 이벤트 루프 위에서 명령을 처리하고, fork로 스냅샷을 뜨고, 로그(AOF)를 다시 쓰는 구조가 작은 코드에 모여 있다. 이벤트 루프 모델의 기준점이 된다.

전체 도구 목록과 진행 순서는 [도구 동작 구조 분석 로드맵](../../docs/tool-analysis-roadmap.md)에 있다.

## 읽는 기준

공식 문서는 지도로 쓰고, 주장은 소스로 확인한다. 공식 문서의 설명을 그대로 옮기지 않고, 흐름을 고르는 출발점과 용어의 기준으로 삼는다.

- 소스: [redis/redis](https://github.com/redis/redis) - 기준 커밋은 [아키텍처 지도](architecture/README.md)에 적는다
- 공식 문서: [Redis Docs](https://redis.io/docs/latest/)

## 개념 교차표에서 맡는 칸

로드맵의 개념 교차표 가운데 이 도구가 채우는 축이다.

- 요청 처리 모델: 단일 스레드 이벤트 루프(ae) + I/O 스레드
- 로그와 내구성: RDB 스냅샷, AOF
- 복제: PSYNC 부분 재동기화
- 분산: Cluster 해시 슬롯
