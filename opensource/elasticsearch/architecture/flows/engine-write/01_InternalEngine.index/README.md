상위: [엔진 쓰기](../README.md)

## 결과가 쓰이는 곳

```text
 IndexResult
      --> seqNo, version, translog 위치, created 플래그
      --> freeze 이후로는 못 바꾼다 (L1384)

 releaseInFlightDocs
      --> finally 라 어느 길로 나가든 예약을 돌려준다
      --> 예약은 계획 단계에서 tryAcquireInFlightDocs 가 잡았다

 versionMap 갱신
      --> safe-access 모드일 때만 실제로 넣는다
      --> 아니면 tombstone 만 지우고 unsafe 표시를 한다

 체크포인트
      --> markSeqNoAsProcessed 는 "Lucene 에 반영됐다"
      --> markSeqNoAsPersisted 는 "디스크에 있다"
      --> translog 위치가 있으면 두 번째는 나중에 fsync 가 한다
```

## 다루지 않는 것

`innerNoOp` / `applyNoOpToLucene` 의 내부, `Translog.add` 안쪽과 tragic 처리, `LiveVersionMap` 의 safe-access 모드, `LocalCheckpointTracker` 의 구현, `IndexThrottle` 이 켜지고 꺼지는 조건, `failEngine` / `maybeFailEngine` 의 전체 판정, `generateSeqNoForOperationOnPrimary` 의 CCR 오버라이드는 같은 뼈대의 곁가지라 요약만 했다.
