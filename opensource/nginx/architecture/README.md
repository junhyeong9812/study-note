# Nginx 아키텍처 지도

소스를 **직접 읽어서** 그리는 탑다운 지도다. 아직 흐름 문서가 없는 골격 상태다.

기준 커밋: 정해지면 적는다 ([nginx/nginx](https://github.com/nginx/nginx)). 모든 줄 번호는 그 커밋 기준으로 쓴다.

이름에서 거꾸로 찾고 싶으면 [API 역인덱스](api-index.md)를 보면 된다. 상위: [Nginx](../README.md)

## 흐름 후보

아래는 공식 문서와 로드맵에서 뽑은 **후보**다. 소스를 읽고 진입점을 확인한 흐름만 `flows/` 아래 폴더로 만들고, 진입점 칸에 파일과 줄 번호를 적는다.

| 흐름 | 상태 | 진입점 |
|---|---|---|
| 마스터-워커 기동 | 후보 | - |
| 이벤트 루프 (epoll) | 후보 | - |
| HTTP 요청 phase 처리 | 후보 | - |
| upstream 프록시 | 후보 | - |
| 로드밸런싱 알고리즘 | 후보 | - |
| 설정 리로드 | 후보 | - |

## 구조

`structure/`(무엇이 있는가)와 `flows/`(무엇이 일어나는가)는 첫 문서를 쓸 때 만든다. 형식은 [Elasticsearch 아키텍처 지도](../../elasticsearch/architecture/README.md)를 따른다.
