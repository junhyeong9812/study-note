# css/syntax/35 — `calc()`·`clamp()`·`min()`/`max()` — 질문

> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.
> 이 주제의 질문은 **예측형 위주**다 — **「담겼나 / 버려졌나 / 무슨 값이 됐나」 세 가지를 따로 답하라.**
> ★ 「안 먹는다」는 답이 아니다. **선언이 사라졌는지, 남았는데 값이 이상한지**를 가려 적어라.

## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 공백 하나가 선언을 지운다 (예측)

```css
#cb { width: 400px; }         /* 부모 */
.a { width: calc(100% - 10px); }
.b { width: calc(100% -10px); }
.c { width: calc(100%-10px); }
.d { width: calc(100%/2); }
.e { width: calc(2*100px); }
```

- 다섯 중 **`cssRules` 에 담기는 것**은 어느 것인가?
- 버려지는 것들의 계산된 `width` 는 무엇이 되는가?
- `*`/`/` 만 공백 없이도 되는 이유를 **토큰**이라는 낱말로 설명할 수 있는가?

### 2. 곱셈·나눗셈의 타입 (예측)

```css
.a { width: calc(100% * 0.5); }
.b { width: calc(10px * 20px); }
.c { width: calc(400px / 10px); }
.d { opacity: calc(1 / 3); }
```

- 넷 중 살아남는 것은 어느 것인가?
- `.c` 의 계산 결과 자체는 수학적으로 무엇인가? 그런데 왜 `width` 에서 안 되는가?

### 3. `calc()` 안의 0 (경계)

```css
.a { width: 0; }
.b { width: calc(100% - 0); }
.c { width: calc(100% - 0px); }
.d { width: calc(100px * 0); }
```

- 넷 중 선언이 버려지는 것은 어느 것인가?
- `calc()` 밖과 안에서 `0` 의 대우가 다른 이유는 무엇인가?

### 4. ★ `clamp()` 의 상하한이 뒤집히면 (예측)

```css
#cb { width: 400px; }
.a { width: clamp(100px, 50%, 300px); }
.b { width: clamp(300px, 50%, 100px); }
.c { width: clamp(300px, 10px, 100px); }
.d { width: clamp(300px, 999px, 100px); }
```

- 네 값의 계산된 `width` 를 각각 px 로 적을 수 있는가?
- `.b`\~`.d` 에서 **가운데 인자가 무엇이든 결과가 같은** 이유는?
- `clamp(a, b, c)` 를 `min()`/`max()` 두 개로 다시 쓰면 어떤 모양인가?

### 5. `min()` 이 만드는 것 (왜)

- `min(100%, 300px)` 은 **상한**인가 **하한**인가?
- `max-width: 300px` 과 같은 일을 하는 함수는 `min()` 인가 `max()` 인가?
- 이 짝이 헷갈리는 이유를 한 문장으로 말할 수 있는가?

### 6. 적은 것과 담긴 것이 다르다 (예측)

```css
.a { width: calc(calc(100%/2) + calc(10px*2)); }
.b { width: calc(10em + 5% + 20px); }   /* 글꼴 20px, 부모 폭 400px */
.c { width: calc((100% - 40px) / 3); }
```

- 셋이 `cssRules` 에 **어떤 문자열로** 담기는가?
- `.b` 의 계산된 `width` 는 몇 px 인가?
- `.c` 의 계산값이 정확히 120px 이 아닌 이유는 무엇이고, 그것은 명세인가 구현인가?

### 7. 음수와 0으로 나누기 (경계)

```css
.a { width: calc(10px - 100px); }
.b { width: calc(100px / 0); }
```

- 둘 중 선언이 버려지는 것이 있는가?
- `.a` 의 계산된 `width` 는 무엇이 되고, 그 값을 누가 정했는가?
- `.b` 는 에러인가? 아니라면 무엇이 되는가?

### 8. 변수와 섞기 (예측)

```css
.a { --pad: 16px; width: calc(100% - var(--pad) * 2); }
.b { --expr: 100% - 20px; width: calc(var(--expr)); }
.c { --bad: 100% -20px;   width: calc(var(--bad)); }
```

- 셋의 계산된 `width` 를 적을 수 있는가? 부모 폭은 400px 이다.
- `.b` 가 되는 이유는 `var()` 가 무엇을 펼치기 때문인가?
- `.c` 의 실패는 질문 1의 실패와 **`cssRules` 창에서 어떻게 다른가**?

### 9. 어디서 쓸 수 있나 (경계)

- `@media (min-width: calc(100px + 100px))` 는 동작하는가?
- `@media (min-width: var(--bp, 100px))` 는 동작하는가? 규칙 자체는 담기는가?
- 둘의 답이 갈리는 이유는 커스텀 속성이 **어디에 붙어 있기** 때문인가?

### 10. 다른 주제로 잇기 (연결)

- 계산 결과가 **어느 단계에서 확정되는지**의 정본은 목록의 몇 번 주제인가?
- `display: none` 인 요소에서 `getComputedStyle().width` 를 읽으면 `calc(100% - 10px)` 이 그대로 나오는 이유는?
- 무효한 `var()` 가 **선언을 버리지 않고** `unset` 처럼 되는 규칙의 정본은 몇 번 주제인가?
- `calc()` 결과를 애니메이션하려면 무엇이 필요하고, 그것은 몇 번 주제인가?
