# css/syntax/19 — 인라인 서식 문맥 — 행 상자·`vertical-align`·`line-height` — 질문

> 복습은 항상 이 파일에서 시작한다. **맨기억으로 답을 시도**하고,
> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.
> 이 주제의 질문은 **예측형 위주**다 — 화면에서 **몇 px 이 될지** 맞힐 수 있는지를 묻는다.
> ★ **이 주제의 수치는 폰트에 달려 있다.** 답을 적을 때 **「무엇에 비례하는가」까지** 적어라 — 숫자만 외우면 폰트가 바뀔 때 전부 틀린다.
> 실측 환경: Chrome 151 headless · `system-ui` = Noto Sans CJK JP · 16px 글자의 내용 영역 높이 **24**.

## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 이 줄의 여유는 어디에 붙는가 (예측)

```css
p { font: 16px/40px system-ui; }   /* 내용 영역 높이는 24 */
```

- 행 상자의 높이는 몇인가?
- 글자 내용 영역의 **위쪽**에 붙는 여유는 몇 px 인가?
- **아래쪽**에는 몇 px 인가?
- 이 여유를 「위에만 20px」로 주는 방법이 `line-height` 에 있는가?

### 2. `line-height: 1` 은 딱 맞는가 (예측)

```css
p { font: 16px/1 system-ui; }
```

- 행 상자 높이는 몇인가?
- 인라인 상자의 내용 영역 높이는 몇인가?
- 반쯤 앞선 간격은 몇인가 — **부호까지** 답하라.
- 화면에서는 무엇이 보이는가?

### 3. 무단위와 `%` 는 무엇이 다른가 (예측)

```css
.a { font-size: 20px; line-height: 1.5; }
.b { font-size: 20px; line-height: 150%; }
/* 두 요소 안에 각각 font-size: 40px 인 자식을 넣는다 */
```

- `.a` 와 `.b` 의 `getComputedStyle().lineHeight` 는 각각 무엇인가?
- 두 **자식**의 `getComputedStyle().lineHeight` 는 각각 무엇인가?
- 부모만 찍어 보고 둘을 구분할 수 있는가?
- 리셋 CSS 가 무단위를 쓰는 이유는 무엇인가?

### 4. `<span>` 에 무엇이 먹고 무엇이 안 먹나 (경계)

```css
span { width: 200px; height: 80px; margin: 20px 6px; padding: 20px 6px; border: 10px solid; }
```

- 이 `<span>` 의 `rect.width`·`rect.height` 는 선언한 값이 되는가?
- `getComputedStyle(span).height` 는 무엇을 돌려주는가 — 그것으로 「먹었다」를 판정할 수 있는가?
- 세로 **마진**과 세로 **패딩**의 결과가 어떻게 다른가?
- 부모 문단의 줄 높이는 패딩 때문에 늘어나는가?

### 5. `vertical-align: middle` 은 가운데인가 (예측)

```css
p    { font: 40px/60px system-ui; }
.icon{ display: inline-block; width: 20px; height: 20px; vertical-align: middle; }
```

- 이 상자의 **중심**은 행 상자의 한가운데와 몇 px 어긋나는가 — 위인가 아래인가?
- `middle` 의 정의는 무엇을 기준으로 삼는가?
- 폰트를 바꾸면 그 위치가 움직이는가?
- 정말로 세로 가운데에 놓으려면 무엇을 쓰는가?

### 6. `top` 과 `text-top` 은 무엇이 다른가 (경계)

- 두 값의 기준선(재는 대상)은 각각 무엇인가?
- 같은 줄에서 둘의 결과가 갈리는가 — 갈린다면 몇 px 인가?
- `bottom` 과 `text-bottom` 은?
- `vertical-align` 은 상속되는가?

### 7. 이미지 아래 틈의 정체 (왜)

```html
<div><img style="height:50px"></div>   <!-- div 높이가 50 이 아니다 -->
```

- 이 `div` 의 높이는 몇인가?
- 그 차이는 마진인가 패딩인가 — 아니면 무엇인가?
- 부모의 `font-size` 를 두 배로 하면 틈은 어떻게 되는가?
- 부모의 `line-height` 를 `0.5` 로 하면?

### 8. 이미지 틈을 고치는 세 가지 (연결)

- `img { display: block }` 은 **무엇을 꺼서** 틈을 없애는가?
- `img { vertical-align: bottom }` 은 **무엇을 바꿔서** 없애는가?
- 부모에 `line-height: 0` 을 주면 **무엇이 딸려 오는가**(대가)?
- 셋 중 「줄 안에 글자와 함께 두어야 할 때」 고르는 것은 무엇인가?

### 9. 자식만 줄여도 줄이 안 줄어든다 (왜)

```html
<p style="line-height: 3">앞 <span style="line-height: 1">가운데</span> 뒤</p>
```

- 행 상자의 높이를 정하는 것은 무엇인가?
- 자식의 `line-height` 를 줄였는데 줄이 안 줄어드는 이유는 무엇인가?
- 이때 남아 있는 **보이지 않는 인라인 상자**의 이름은 무엇인가?
- 줄을 줄이려면 어디에 걸어야 하는가?

### 10. 다른 주제로 잇기 (연결)

- 인라인 상자가 **치수를 가질 수 있게** 하려면 `display` 를 무엇으로 바꾸며, 그 정본은 목록의 몇 번 주제인가?
- 블록 서식 문맥(BFC)과 인라인 서식 문맥(IFC)은 무엇이 짝인가 — BFC 의 정본은 몇 번인가?
- **행 상자를 옆으로 미는 것**은 무엇이며 몇 번 주제인가?
- `<img>` 에 `height` 가 먹는 이유를 한 낱말로 답하면?
