# css/syntax/08 — 기본 선택자·조합자·속성 선택자 — 질문

> 복습은 항상 이 파일에서 시작한다. **맨기억으로 답을 시도**하고,
> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.
> 이 주제의 질문은 **예측형 위주**다 — 아는지가 아니라 **몇 개가 잡히는지 세어 맞힐 수 있는지**를 묻는다.
> 답에 개수를 적을 때는 **어느 노드인지까지** 적어 본다. 개수만 맞고 노드가 틀리는 일이 흔하다.

## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

이 묶음의 질문은 아래 트리 위에서 답한다.

```html
<section class="wrap">
  <h2 class="hd">제목</h2>
  <p class="x" id="P1">P1</p>
  <p id="P2">P2</p>
  <div class="inner"><p class="x" id="P3">P3</p></div>
  <p class="x" id="P4">P4</p>
</section>
```

### 1. 조합자 넷은 각각 몇 개를 잡는가 (예측)

```css
.wrap p      { }
.wrap > p    { }
.hd + p      { }
.hd ~ p      { }
```

- 넷은 각각 몇 개를 잡고, 그것이 어느 노드인가?
- `P3` 이 잡히는 선택자와 안 잡히는 선택자는 각각 무엇이고, 왜 갈리는가?
- `.x + .x` 는 몇 개를 잡는가?
- `.hd ~ p` 가 `P3` 을 못 잡는 이유를 한 문장으로 말할 수 있는가?

### 2. 부모를 고르는 조합자는 무엇인가 (경계)

- 네 조합자 중 **위쪽·앞쪽**으로 가는 것은 몇 개인가?
- `document.querySelectorAll('p < section')` 을 실행하면 무엇이 돌아오는가?
- CSS 파일 안에 `p < section { color: red }` 를 쓰면 무슨 일이 일어나고, **그것을 어떻게 확인**하는가?
- 그 제약을 뚫는 문법의 이름은 무엇인가?

### 3. `~=` 와 `*=` 는 어디서 갈리는가 (예측)

```html
<b data-tags="alpha beta">1</b>
<b data-tags="alphabet">2</b>
<b data-tags="beta alpha">3</b>
<b data-tags="gamma">4</b>
```

- `[data-tags~="alpha"]` 는 몇 개를 잡는가?
- `[data-tags*="alpha"]` 는 몇 개를 잡는가?
- 둘의 차이를 만드는 요소는 넷 중 어느 것이고, 왜인가?
- `[data-tags^="alpha"]` 와 `[data-tags$="alpha"]` 는 각각 몇 개인가?

### 4. `|=` 는 접두사 매칭인가 (경계)

```html
<a hreflang="en-US">1</a>
<a hreflang="en">2</a>
<a hreflang="en-GB">3</a>
<a hreflang="english">4</a>
```

- `[hreflang|="en"]` 은 몇 개를 잡는가?
- `[hreflang^="en"]` 과 답이 다른가, 다르다면 어느 요소에서 갈리는가?
- `|=` 가 보는 경계 문자는 무엇인가?
- `[hreflang="en"]` 은 몇 개인가?

### 5. 대소문자는 어디서 구분되는가 (예측)

```html
<DIV id="Mix" class="CapCase" data-K="V">x</DIV>
<input type="CHECKBOX">
```

- `div`·`.capcase`·`#mix`·`[data-k="V"]`·`[data-k="v"]` 는 각각 몇 개를 잡는가?
- `input[type="CHECKBOX"]` 는 몇 개를 잡는가, 그 이유는 CSS 의 규칙인가 HTML 의 규칙인가?
- `i` 플래그는 무엇을 강제하고, `s` 플래그는 무엇을 강제하는가?
- Chrome 151 에서 `input[type="CHECKBOX" s]` 를 CSS 에 쓰면 어떻게 되는가?

### 6. 무효한 선택자 하나가 어디까지 죽이는가 (예측)

```css
.x, p < section { color: red; }
p ! section     { color: blue; }
.x              { color: green; }
```

- `document.styleSheets[0].cssRules` 에 남는 규칙은 몇 개이고 무엇인가?
- `.x` 는 멀쩡한 선택자인데 왜 첫 줄에서 살아남지 못하는가?
- 이 규칙을 "인자 하나만 죽게" 바꾸는 문법은 무엇인가?
- 화면만 보고 이 사고를 진단할 수 있는가?

### 7. "선택자를 고쳤는데 안 바뀐다"를 어떻게 가르는가 (연결)

- 원인 후보 셋을 순서대로 댈 수 있는가?
- 각 후보를 한 줄로 확인하는 방법은 각각 무엇인가?
- 「무엇이 잡혔나」와 「그래서 이겼나」는 왜 다른 질문인가?
- 명시도를 올리는 것이 효과가 없는 경우는 어떤 경우인가?

### 8. 같은 요소를 고르면서 세기만 낮추려면 (연결)

- `#nav` 와 `[id="nav"]` 는 고르는 요소가 같은가?
- 둘의 명시도는 각각 얼마이고, 그 정본은 어느 주제인가?
- 조합자(` `·`>`·`+`·`~`)는 명시도의 어느 자리에 얼마를 보태는가?
- 「그물 모양」과 「그물의 힘」이 서로 독립이라는 것이 이 두 선택자에서 어떻게 드러나는가?

### 9. `*` 는 무엇을 잡는가 (경계)

- 위 트리가 담긴 문서에서 `*` 는 몇 개를 잡는가?
- 그중 내가 쓴 태그가 아닌 것은 무엇인가?
- `section > * > p` 는 몇 개를 잡는가?
- `*` 의 명시도는 얼마인가?

### 10. ID 가 문서에 둘 있으면 (경계)

- `<p id="dup">` 가 둘 있을 때 `#dup` 은 몇 개를 잡는가?
- `#dup { color: … }` 는 둘 다에 먹는가?
- "ID 는 문서에서 유일해야 한다"는 것은 누구의 규칙인가?
- CSS 입장에서 ID 선택자가 클래스 선택자와 다른 점은 매칭인가 명시도인가?

### 11. 상태를 속성 선택자로 고르면 (연결)

```html
<input id="c1" type="checkbox" checked>
```

- 사용자가 `c1` 의 체크를 끄면 `[checked]` 는 여전히 맞는가?
- 같은 시점에 `:checked` 는 맞는가?
- 둘이 갈리는 이유를 한 문장으로 말할 수 있는가?
- 이 구분의 정본은 어느 주제인가?
