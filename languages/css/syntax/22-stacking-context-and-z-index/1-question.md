### 1. 9999 가 지는 판 (예측)

```html
<div class="A">              <!-- ① 아무것도 없음  ② z-index: 1 -->
  <b class="red" style="z-index: 9999"></b>
</div>
<div class="B" style="z-index: 2">
  <b class="blue"></b>
</div>
<!-- A·B 는 position: relative, red·blue 는 position: absolute -->
```

- ①에서 겹치는 지점의 색은 빨강인가 파랑인가?
- ②에서는?
- 두 경우의 `getBoundingClientRect()` 는 다른가?
- ②를 고쳐 빨강을 위로 올리는 방법을 **둘** 대 보라.

### 2. `opacity` 가 자식을 가둔다 (예측)

```css
.A { opacity: ???; }   /* 나머지 마크업은 1번과 같다 */
```

- `opacity: 0.99` 일 때 겹침 색은?
- `opacity: 1` 일 때는?
- `opacity: 0.999` 는 어느 쪽인가 — 경계는 무엇인가?
- 화면을 눈으로 봐서 이 차이를 알아챌 수 있는가?

### 3. 목록을 속성 이름으로 외우면 (경계)

- `mix-blend-mode: normal` 은 쌓임 맥락을 만드는가?
- `mix-blend-mode: multiply` 는?
- `position: sticky` 는 `z-index` 없이도 만드는가 — `relative` 는?
- 「속성 이름」이 아니라 무엇으로 외워야 하는가?

### 4. `position` 없이 `z-index` 가 먹는 경우 (경계)

```css
.parent { display: flex; }
.child  { z-index: 0; }     /* position 선언 없음 */
```

- 이 `z-index: 0` 은 먹는가?
- 같은 선언을 보통 블록(`position: static`)에 주면?
- flex 항목에 `z-index: auto` 면 쌓임 맥락이 생기는가?
- grid 항목도 같은가?

### 5. 페인트 순서 일곱 층 (예측)

- 아무도 `z-index` 를 안 줬을 때, **float 와 보통 블록의 배경** 중 무엇이 위에 그려지는가?
- **float 와 글자(인라인 내용)** 중에는?
- **`position: relative` 만 준 요소와 float** 중에는?
- 일곱 층을 아래부터 순서대로 대 보라.

### 6. `z-index: -1` 로 뒤로 보냈는데 (예측)

```html
<div class="wrap">                <!-- position: relative; z-index: 0; 배경 회색 -->
  <div class="card"></div>        <!-- 배경 노랑 -->
  <b class="deco" style="z-index: -1"></b>   <!-- 보라, card 와 일부 겹침 -->
</div>
```

- 보라가 노란 카드와 겹치는 지점의 색은?
- 보라가 회색 배경 위에만 있는 지점의 색은?
- `.wrap` 의 `z-index: 0` 을 지우면 보라는 어떻게 되는가?
- 「배경 뒤로 보내기」 관용구가 동작하는 조건은 무엇인가?

### 7. 세 구역을 가르기 (연결)

- `overflow: hidden` 은 BFC 를 만드는가 · 쌓임 맥락을 만드는가?
- `opacity: 0.99` 는 BFC 를 만드는가 · 포함 블록을 바꾸는가 · 쌓임 맥락을 만드는가?
- `transform` 은 셋 중 무엇을 하는가?
- 「`z-index` 가 안 먹는다」와 「`fixed` 가 안 붙는다」를 같은 원인으로 진단해도 되는가?

### 8. 실무에서 고치는 법 (왜)

- `z-index: 9999` → `99999` 로 올리는 것이 왜 소용없는가?
- 모달 라이브러리가 전부 `<body>` 바로 밑에 붙이는 이유는?
- `isolation: isolate` 는 무엇을 위해 있는 선언인가 — 투명도를 건드리는가?
- `will-change: transform` 을 성능 옵션으로만 보면 무엇을 놓치는가?

### 9. 이 주제를 어떻게 재는가 (왜)

- `getBoundingClientRect()` 로 「누가 위인지」 알 수 있는가?
- 그러면 무엇으로 재는가?
- 실험에 `#ef4444` 대신 `#ff0000` 같은 순색을 쓰는 것이 왜 편한가?
- 여러 무대를 한 문서에 넣고 잴 때 조심할 것은 무엇인가?

### 10. 다른 주제로 잇기 (연결)

- float 가 블록 배경 위에 그려지는 것은 일곱 층 중 몇 층 대 몇 층인가 — float 의 정본은 몇 번인가?
- 드롭다운이 **사라지는** 문제는 이 주제인가 다른 주제인가 — 몇 번인가?
- 쌓임 맥락을 만드는 선언과 포함 블록을 바꾸는 선언의 대조표는 몇 번 주제에 있는가?
- `mix-blend-mode` 의 **혼합 규칙 자체**는 몇 번 주제인가?
