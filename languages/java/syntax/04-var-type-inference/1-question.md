## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 이 다섯 줄은 각각 무슨 타입으로 추론되는가 (예측)

```java
var bytes = (byte) 1;
var ch    = 'a' + 1;
var div   = 1 / 2;
var cond  = args.length == 0 ? 1 : 2L;
var empty = java.util.Collections.emptyList();
```

- 다섯 변수의 타입은 각각 무엇인가?
- `ch` 가 `char` 가 **아닌** 이유는 무엇인가?
- `empty` 가 `List<String>` 이 될 수 없는 이유는 무엇인가?

### 2. 추론된 타입을 도구로 확인하는 방법은 무엇인가 (왜)

- 소스만 보고 확신이 안 설 때, **컴파일러에게 직접 물어보는** 가장 짧은 방법은 무엇인가?
- 그 방법이 반드시 답을 주는 이유는 무엇인가?
- 클래스 파일에서 읽으려면 어떤 컴파일 옵션과 어떤 도구·어떤 표를 봐야 하는가?
- 제네릭 인자까지 보려면 어느 표를 봐야 하는가?

### 3. 이 두 줄의 차이가 만드는 것 (예측)

```java
var raw   = new ArrayList<>();
var typed = new ArrayList<String>();

raw.add("문자열");
raw.add(42);
typed.add(42);
```

- `raw` 와 `typed` 의 추론된 타입은 각각 무엇인가?
- 세 `add` 중 컴파일되는 것은 무엇이고 안 되는 것은 무엇인가?
- 이 함정을 피하는 규칙을 한 줄로 말하면 무엇인가?

### 4. 이 여섯 줄은 왜 컴파일되지 않고, 에러 문구는 각각 어떻게 다른가 (예측)

```java
var a = null;
var b;
var c = {1, 2, 3};
var d = () -> {};
var e = String::length;
var f = f + 1;
```

- 여섯 줄이 내는 에러의 **첫 줄**은 같은가 다른가?
- 괄호 안에 붙는 **이유 한 줄**은 각각 무엇인가?
- `c`·`d`·`e` 셋의 이유가 같은 까닭은 무엇인가?

### 5. `var` 를 쓸 수 없는 자리는 어디까지인가 (경계)

- 필드·파라미터·반환 타입·`catch` 파라미터·제네릭 인자에 쓰면 어떤 에러가 나는가?
- 그 에러의 첫 줄은 4번의 에러와 무엇이 다른가?
- 필드·파라미터·반환 타입이 막힌 **이유**는 무엇인가?
- 반대로 허용된 자리 여섯 곳은 무엇인가?

### 6. 이 두 메서드의 바이트코드는 같은가 다른가 (예측)

```java
static void withVar()   { var i = 1; var s = "hi"; var raw = new ArrayList<>(); }
static void withTypes() { int i = 1; String s = "hi"; ArrayList<Object> raw = new ArrayList<Object>(); }
```

- `javap -c -p` 로 찍은 명령열은 같은가?
- `javac -g` 로 컴파일한 뒤 `LocalVariableTable` 에는 `var` 라는 흔적이 남는가?
- 이 결과에서 "`var` 의 런타임 비용"에 대해 무엇을 말할 수 있는가?

### 7. 람다 파라미터의 `var` 는 어디까지 허용되는가 (경계)

- `(var a, var b) -> a + b` 는 몇 버전부터 되는가?
- `(var a, b)` 와 `(var a, Integer b)` 는 각각 어떤 에러가 나는가?
- `var x -> x + 1` 처럼 괄호를 빼면 어떻게 되는가?
- 람다 파라미터에 `var` 를 쓰는 **실익**은 무엇인가?

### 8. `var` 는 `final` 인가 (경계)

- `var n = 1; n = 2;` 는 컴파일되는가?
- 코틀린의 `val` 에 해당하는 것을 자바에서 쓰려면 어떻게 적는가?
- 람다 캡처가 막히는 조건은 `var` 와 관계가 있는가?

### 9. 익명 클래스와 함께 쓰면 무엇이 달라지는가 (예측)

```java
var    anon1 = new Object() { int count = 1; };
Object anon2 = new Object() { int count = 1; };
System.out.println(anon1.count);
System.out.println(anon2.count);
```

- 두 `println` 중 컴파일되는 것은 어느 쪽인가?
- `anon1` 의 타입을 컴파일러는 뭐라고 부르는가?
- 그 타입을 메서드 밖으로 내보낼 수 있는가?

### 10. `var` 는 키워드인가 (경계)

- `int var = 3;` 은 컴파일되는가?
- `class var { }` 는 컴파일되는가?
- 두 답이 갈리는 이유를 한 문장으로 말하면 무엇인가?

### 11. 어디에 쓰고 어디에 안 쓰나 (왜)

- 「타입이 오른쪽에 보이면 쓴다」를 판정하는 실제 기준은 무엇인가?
- `var r = compute();` 를 안 쓰는 이유는 무엇인가?
- `var x = 0;` 이 나중에 문제가 될 수 있는 상황은 무엇인가?

### 12. 다른 주제와 잇기 (연결)

- `final var` 와 effectively final 은 어떤 관계인가?
- `var f = () -> ...` 가 막힐 때 무엇을 적어야 하는가?
- `var` 가 붙잡을 수 있는 "손으로 못 적는 타입" 둘은 무엇인가?
