```java
Thread a = Thread.ofVirtual().name("x").unstarted(() -> {});

```

- 셋의 도입 버전은 각각 무엇이고, 무엇으로 확인했는가?
- `b.getName()` 은 무엇인가?
- 가상 스레드의 `toString()` 은 어떤 모양인가 — 거기서 무엇을 읽을 수 있는가?
- JDK 17 에서 이 코드를 컴파일하면 어떤 에러가 나는가?

### 2. 플랫폼 스레드와 무엇이 다른가 (예측)

### 5. ★ 언제 값이 나나 (예측)

```text

(C) 플랫폼 고정 풀 2000  (D) 가상 스레드
```

### 7. ★★ `synchronized` 안에서 블로킹하면 (예측)

```java

(B) synchronized (myLock) { sleep(200); }
(C) rl.lock(); try { sleep(200); } finally { rl.unlock(); }
```

- **JDK 25** 에서는?
- 하나씩 줄서면 몇 ms 이고, 안 줄서면 몇 ms 인가?
- 무엇이 21 과 25 를 갈랐는가 — 어느 JEP 인가?
- JDK 21 에서의 처방은 무엇인가?
