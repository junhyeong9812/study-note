# c/syntax/11 — 비트 연산과 시프트: 자리를 다루는 법과 **넘으면 안 되는 선** — 질문

> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.

> ★★ **이 주제는 UB 가 본체다.** 바로 앞 [10번 형제](../10-evaluation-order-and-sequence-points/)에서 한 줄도 안 냈던 UBSan 이 여기서는 말을 한다 —\

> ★ **값을 맞히는 것보다 「어느 층인가」와 「누가 말해 주나」를 맞히는 것이 중요하다.**
> 선행 — [02번 형제](../02-basic-types-sizes-and-fixed-width-integers/) · [03번 형제](../03-integer-promotion-and-usual-arithmetic-conversions/).

## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. 마스크 관용구 넷 (예측)

```c
unsigned flags = 0x0Au;            /* 0000 1010 */
unsigned MASK  = 0x04u;            /* 0000 0100 */
/* 아래 다섯 값을 8비트 2진으로 찍는다 */
flags | MASK
flags & ~MASK
flags ^ MASK
(flags & MASK) != 0
~flags
```

- 앞 세 값은 각각 무엇인가?
- `(flags & MASK) != 0` 은 무엇이고, 그 괄호를 빼면 무슨 일이 나는가?
- `~flags` 를 **하위 8비트만** 보면 무엇이고 **전체**로 보면 무엇인가?
- `flags |= MASK` 를 세 번 반복하면 결과가 달라지는가?

### 2. 작은 타입을 뒤집으면 (예측) ★★

```c
unsigned char c = 0xFF;
/* 아래 여섯 개를 찍는다 */
sizeof c
sizeof (~c)
~c                      /* %d 로 */
(unsigned char)~c
~c == 0
c << 8
```

- 여섯 값은 각각 무엇인가?
- `sizeof c` 와 `sizeof (~c)` 가 같은가 다른가 — 왜 그런가?
- 이 프로그램에서 경고가 몇 건 나고 **어느 플래그**의 것인가 — 문구를 그대로 쓰면?
- `if (~c)` 로 쓰면 어떻게 되는가?

### 3. 시프트량이 변수일 때 셋 (예측) ★★★ 이 주제의 축

```c
volatile int n = -1;      volatile int m = 32;
volatile int v = 1;       volatile int big = 1073741824;   /* 2^30 */
volatile int neg = -8;
/* v << n · v << m · big << 2 · neg >> 1 을 찍는다 */
```

- 네 값은 각각 무엇인가?
- `-Wall -Wextra -pedantic` 으로 경고가 몇 건 나는가?
- `-fsanitize=undefined` 로 돌리면 **몇 줄**이 나오고 각각 무슨 문구인가?
- ★ `-fno-sanitize-recover=all` 을 붙이면 **몇 줄**이 나오는가 — 왜 그런가?
- 넷 중 **UB 가 아닌 것**이 하나 있다 — 어느 것이고 무슨 층인가?

### 4. `u` 한 글자를 붙이면 (예측) ★

```c
printf("%d\n", 1 << 31);
printf("%u\n", 1u << 31);
printf("%d\n", (int)(1u << 31));
printf("%d\n", (int)(1u << 31) == INT_MIN);
```

- 네 값은 각각 무엇인가?
- 첫 줄은 **`-Wall -Wextra -pedantic` 에서 몇 건**인가?
- 그것을 말하게 하려면 어느 플래그가 더 필요한가 — 그리고 **UBSan 은 무엇이라 하는가?**
- 셋째 줄의 변환은 무슨 층인가?

### 5. 음수를 오른쪽으로 밀면 (예측)

```c
volatile int n = -1, m = -8, neg7 = -7;
volatile unsigned u = 0xFFFFFFFFu;
/* n >> 1 · m >> 1 · m / 2 · u >> 1 · neg7 >> 1 · neg7 / 2 를 찍는다 */
```

- 여섯 값은 각각 무엇인가?
- `neg7 >> 1` 과 `neg7 / 2` 가 같은가 — 그 이유는?
- UBSan 은 이 프로그램에 대해 무엇을 말하는가?
- 이 동작이 **이 컴파일러에서 그렇다**는 것을 어떻게 **어셈블리로** 보일 수 있는가?

### 6. 같은 UB 를 일곱 벌로 돌리면 (예측) ★★

```c
static int sum_bits(int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += (1 << i);
    return s;
}
/* sum_bits(4) 와 sum_bits(40) 을 찍는다 */
```

- `gcc -O0 -O1 -O2 -O3 -Os` · `clang -O0 -O2` **일곱 벌**에서 두 값이 각각 무엇인가?
- 일곱 벌이 전부 같은가?
- `-O2 -Wall -Wextra -pedantic` 의 경고 건수는?
- ★ UBSan 진단은 **몇 줄**인가 — 루프가 UB 를 **몇 번** 지나는가?

### 7. 경고가 상수와 변수를 다르게 잡는 것 (경계) ★★

- `int b = 1 << 32;` 는 **플래그를 하나도 안 줘도** 경고가 나는가?
- 같은 시프트를 변수로 쓰면 `-Wall -Wextra -pedantic -O2` 에서 몇 건인가?
- 이 차이가 나는 **이유**는 무엇인가?
- 그래서 변수 시프트량은 **무엇으로** 잡아야 하는가?

### 8. sanitizer 가 침묵한 자리 (경계) ★★

- `-1 >> 1` 에서 UBSan 이 아무 말도 안 했다 — **버그인가 설계인가?**
- 이 침묵은 [10번 형제](../10-evaluation-order-and-sequence-points/)에서 인자 평가 순서에 대해 침묵한 것과 **같은 종류인가?**
- UBSan 이 **같은 소스 위치**를 여러 번 만나면 몇 번 보고하는가?
- 「진단 한 줄」에서 **주장할 수 없는 것**은 무엇인가?

### 9. 비트필드는 어디까지 믿나 (경계)

```c
struct Flags { unsigned a:1; unsigned b:3; signed c:4; int d:4; };
struct Flags f = { 1, 5, -3, 7 };
/* sizeof · 네 필드 값 · f.b = 9 · f.d = 8 · 앞 4바이트 */
```

- `sizeof(struct Flags)` 와 네 필드 값은 무엇인가?
- `f.b = 9`·`f.d = 8` 을 넣으면 각각 무엇이 되고, 경고는 나는가?
- 앞 4바이트를 gcc 와 clang 에서 각각 찍으면 **같은가?**
- `int d : 4` 의 **부호**는 누가 정하는가?

### 10. 「경고 0건」이 두 가지 뜻인 자리 (경계) ★★

- `0b1011`(C23 2진 리터럴)을 `-std=c89 -Wall -Wextra` 로 컴파일하면 몇 건인가?
- 그것을 드러내려면 무엇이 필요한가?
- ★ `gcc -std=c23` 으로 돌리면 경고 건수와 **종료 코드**가 각각 무엇인가?
- 경고만 세었다면 무엇이라고 기록됐겠는가?

### 11. 다섯 층으로 갈라 보기 (연결) ★★
