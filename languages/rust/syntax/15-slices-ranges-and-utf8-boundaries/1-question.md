### 1. ★★ `len()` 과 `chars().count()` 와 사람이 세는 글자 수 (예측)

```rust
fn main() {
    let samples: [(usize, &str, &str); 7] = [
        (2, "Hi", "ASCII 두 글자"),
        (1, "한", "한글 한 글자(완성형)"),
        (2, "한글", "한글 두 글자(완성형)"),
        (1, "\u{1112}\u{1161}\u{11AB}", "한글 한 글자(조합형 자모 셋)"),
        (1, "e\u{0301}", "e + 결합 악센트"),
        (1, "\u{1F1F0}\u{1F1F7}", "국기 이모지(지역 표시자 둘)"),
        (1, "\u{1F468}\u{200D}\u{1F469}\u{200D}\u{1F467}", "가족 이모지(ZWJ 로 이은 셋)"),
    ];
    println!("{:>4} {:>6} {:>6} {:>6}  {}", "len", "chars", "bytes", "사람", "설명");
    for (human, s, desc) in samples {
        println!("{:>4} {:>6} {:>6} {:>6}  {}",
                 s.len(), s.chars().count(), s.bytes().count(), human, desc);
    }
}
```

- 일곱 줄의 `len` · `chars` · `bytes` 칸을 **전부** 채울 수 있는가?
- `len()` 과 `bytes().count()` 가 **다를 수 있는** 문자열이 있는가?
- 세 칸이 **전부 같아지는** 줄은 몇 번째이고, 그 조건은 무엇인가?
- 마지막 네 줄에서 **`chars` 칸과 「사람」 칸이 갈리는 이유**를 각각 한 줄로 말할 수 있는가?

### 2. ★★ `&s[0..1]` 을 실행하면 (예측)

```rust
fn main() {
    let s = "한글 abc";
    println!("자르기 전: {}", s);
    let first = &s[0..1];
    println!("여기는 안 찍힌다: {}", first);
}
```

- **컴파일**은 되는가? 실행하면 무엇이 나오는가?
- 메시지가 말해 주는 것이 **몇 가지**인가 — 하나씩 짚어 보라.
- 「자르기 전」 줄은 찍히는가?
- **종료 코드**는 무엇인가? 그리고 이 블록에서 **다시 돌리면 바뀌는 칸**은 어디인가?
- 이 자리를 **패닉 없이** 넘기려면 인덱스를 몇으로 바꾸면 되는가 — 메시지 어디에 적혀 있나?

### 3. ★ 같은 인덱스를 `get` 으로 던지면 (예측)

```rust
fn main() {
    let s = "한글 abc";
    let v: Vec<i32> = vec![10, 20, 30];
    let sl: &[i32] = &v[..];

    println!("s.get(0..1)  = {:?}", s.get(0..1));
    println!("s.get(0..3)  = {:?}", s.get(0..3));
    println!("s.get(0..99) = {:?}", s.get(0..99));
    println!("s.get(4..2)  = {:?}", s.get(4..2));
    println!("sl.get(7)    = {:?}", sl.get(7));
    println!("sl.get(1..2) = {:?}", sl.get(1..2));
    println!("sl.get(2..1) = {:?}", sl.get(2..1));
}
```

- 일곱 줄의 출력을 전부 적을 수 있는가?
- `sl.get(1)` 과 `sl.get(1..2)` 의 **타입이 어떻게 다른가**?
- `[]` 가 패닉하는 **세 가지 경우** 중 `get` 이 `None` 을 주지 **않는** 것이 있는가?
- 그럼 언제 `[]` 를 쓰고 언제 `get` 을 쓰는가 — 판단 기준 한 줄.

### 4. ★★ 배열·`Vec`·슬라이스의 범위 밖 인덱스 (예측)

```rust
fn main() {
    let arr = [10, 20, 30, 40, 50];
    let i = 7;
    println!("배열 길이 {}", arr.len());
    println!("{}", arr[i]);
}
```

- 이 프로그램은 **어느 단계**에서 무엇을 내는가?
- `arr` 를 `vec![10, 20, 30, 40, 50]` 으로 바꾸면 무엇이 달라지는가?
- 잡아 주는 것이 **경고인가 에러인가**, 그리고 그 **린트 이름**은 무엇인가?
- 같은 파일에 `&"한글"[0..1]` 을 함께 두면 컴파일러가 **둘 다** 짚는가?
- 런타임 패닉 메시지와 컴파일 타임 메시지의 **문구가 한 글자 다르다.** 어디인가?

### 5. ★ 길이 7 을 3 으로 나누면 (예측)

```rust
fn main() {
    let v: Vec<i32> = (0..7).collect();
    let s: &[i32] = &v[..];
    println!("split_at(3)     -> {:?}", s.split_at(3));
    println!("chunks(3)       -> {:?}", s.chunks(3).collect::<Vec<_>>());
    println!("chunks_exact(3) -> {:?}", s.chunks_exact(3).collect::<Vec<_>>());
    println!("rchunks(3)      -> {:?}", s.rchunks(3).collect::<Vec<_>>());
    println!("windows(3)      -> {:?}", s.windows(3).collect::<Vec<_>>());
    println!("windows(8)      -> {:?}", s.windows(8).collect::<Vec<_>>());
}
```

- 여섯 줄의 출력을 전부 적을 수 있는가?
- `chunks(3)` 의 **마지막 조각**과 `rchunks(3)` 의 **첫 조각**은 각각 무엇인가?
- `chunks_exact(3)` 가 버린 것을 되찾는 메서드 이름은 무엇인가?
- `windows(3)` 의 개수를 **길이와 n 으로** 계산하는 식을 쓸 수 있는가?
- `windows(0)` · `chunks(0)` · `split_at(8)` 을 던지면 각각 무엇이 나오는가?

### 6. ★★ `&Vec<i32>` 를 받는 함수에 배열 슬라이스를 넘기면 (예측)

```rust
fn sum_vec(v: &Vec<i32>) -> i32 { v.iter().sum() }

fn main() {
    let arr: [i32; 3] = [1, 2, 3];
    println!("{}", sum_vec(&arr));
    println!("{}", sum_vec(&arr[..]));
}
```

- 컴파일되는가? 안 되면 **에러 번호**와 두 줄의 `expected` / `found` 를 적어 보라.
- 에러가 **몇 개** 나는가?

- 반대 방향(`&[i32]` 를 `&Vec<i32>` 로)은 어떤 강제가 있는가?
- 이 논리가 **14번 주제의 무엇과 같은 논리**인지 한 문장으로 잇을 수 있는가?
