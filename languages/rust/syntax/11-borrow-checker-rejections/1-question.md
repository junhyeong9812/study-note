# rust/syntax/11 — 빌림 검사기가 거부하는 전형 코드와 고치는 법 — 질문

> 복습은 항상 이 파일에서 시작한다. **맨기억으로 답을 시도**하고,
> 막히면 [2-summary.md](2-summary.md)를 힌트로, 최후에만 [3-answer.md](3-answer.md)를 연다.
> 정답까지 봤던 질문은 아래 복습 기록에 "틀림"으로 표시한다.
> 이 주제의 질문은 **예측형 위주**다 — 아는지가 아니라 **어느 줄이 거부되는지**와
> **어느 열쇠를 꺼내야 하는지**를 맞힐 수 있는지 묻는다.
> ★ 답을 모르겠으면 **던져 보라.** `rustc --edition 2021 ex.rs -o /tmp/ex && /tmp/ex`.

> ★ 에러가 났을 때 **`= help:` 줄을 꼭 보라** — 이 주제에서는 컴파일러가 **열쇠 이름을 직접 대 주는** 자리가 있다.

## 질문

### 1. ★ 순회하면서 같은 벡터에 넣으면 (예측)

```rust
let mut v = vec![1, 2, 3];
for x in &v {
    if *x % 2 == 1 { v.push(*x * 10); }
}
println!("{:?}", v);
```

- 컴파일되는가? 안 되면 에러 번호는 무엇인가?
- 라벨이 **같은 줄에 둘** 붙는다. 왜 그런가?
- 이 거부는 **정말 위험해서**인가, **검사기가 증명 못 해서**인가 — 어느 쪽이고 그 근거는?
- 고치는 길을 셋 들 수 있는가?

### 2. ★★ 같은 벡터의 0번과 2번을 동시에 고치면 (예측)

```rust
let mut v = vec![1, 2, 3];
let a = &mut v[0];
let b = &mut v[2];
*a += *b;
println!("{:?}", v);
```

- 인덱스가 겹치지 않는데도 거부되는가? 에러 번호는?
- 컴파일러가 판정에 쓴 것은 **인덱스 값**인가 **`IndexMut` 의 시그니처**인가?
- 이 진단의 `= help:` 줄이 무엇을 권하는가 — 한 글자도 안 틀리게 댈 수 있는가?
- 1번의 거부와 **성격이 같은가 다른가**?

### 3. ★★ 접근자 메서드 둘을 나란히 부르면 (예측)

```rust
struct Doc { title: String, body: String }

impl Doc {
    fn title_mut(&mut self) -> &mut String { &mut self.title }
    fn body_mut(&mut self) -> &mut String { &mut self.body }
}

// (가)
let t = d.title_mut();
let b = d.body_mut();

// (나)
let t = &mut d.title;
let b = &mut d.body;
```

- (가)와 (나) 중 통과하는 쪽은 어느 것인가?
- 에러가 짚는 것은 `d` 인가 `d.title` 인가 — 그리고 왜인가?
- 캡슐화를 안 깨면서 (가)를 통과시키는 방법이 있는가?
- 빌림 검사기는 `title_mut` 의 **몸통**을 읽는가?

### 4. ★ `&mut self` 에서 `String` 을 꺼내면 (예측)

```rust
struct Buf { data: String }

impl Buf {
    fn take_all(&mut self) -> String {
        self.data
    }
}
```

- 컴파일되는가? 안 되면 에러 번호와 그 이유 한 구절은?
- 컴파일러가 권하는 고침은 무엇이고, 그것이 **이 목적에 맞는 답**인가?
- `mem::take` 는 자리에 무엇을 두는가? `mem::replace` 와 무엇이 다른가?
- `mem::take` 가 요구하는 트레이트 경계는 무엇인가?

### 5. ★★★ 같은 모양의 두 코드 (예측)

```rust
use std::collections::HashMap;

// (가) main 안에서
match counts.get_mut("가") {
    Some(c) => *c += 1,
    None => { counts.insert("가", 1); }
}

// (나) 함수가 참조를 반환한다
fn bump<'m>(counts: &'m mut HashMap<&'static str, i32>, k: &'static str) -> &'m i32 {
    match counts.get_mut(k) {
        Some(c) => { *c += 1; c }
        None => { counts.insert(k, 1); counts.get(k).unwrap() }
    }
}
```

- 둘 중 통과하는 쪽이 있는가? 있다면 어느 쪽인가?
- 갈린 원인을 **패턴의 모양**이 아닌 다른 말로 설명할 수 있는가?
- (나)에서 나는 에러는 **몇 개**인가?
- 이 맵 작업의 표준 열쇠는 무엇인가?

### 6. ★ `RefCell` 을 두 번 빌리면 (예측)

```rust
use std::cell::RefCell;

let c = RefCell::new(vec![1, 2, 3]);
let a = c.borrow_mut();
println!("첫 빌림 성공: {:?}", *a);
let b = c.borrow_mut();
println!("{:?}", *b);
```

- 이 코드를 컴파일하면 어떻게 되는가?
- 실행하면 어떻게 되는가 — 출력이 **하나라도 나오는가**?
- 종료 코드는 무엇인가?
- `borrow_mut` 중에 `borrow()` 를 부르면 문구가 같은가 다른가?
