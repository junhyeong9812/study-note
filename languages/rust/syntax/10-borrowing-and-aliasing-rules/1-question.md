## 질문

### 1. ★ 읽기 하나와 쓰기 하나 (예측)

```rust
let mut v = vec![1, 2, 3];
let first = &v[0];
v.push(4);
println!("첫 원소 = {}", first);
```

- 컴파일되는가? 안 되면 에러 번호와 제목 줄은 무엇인가?
- `v.push(4)` 가 왜 **가변 빌림**인가 — 무엇을 보고 그렇게 판정하는가?
- 에러가 붙이는 라벨이 셋이다. 세 번째 라벨은 어느 줄에 붙고 무슨 뜻인가?
- 이 코드를 **한 글자도 안 지우고** 통과시키는 방법이 있는가?

### 2. ★ 쓰기 둘 (예측)

```rust
let mut s = String::from("안녕");
let a = &mut s;
let b = &mut s;
a.push('!');
b.push('?');
println!("{a} {b}");
```

- 에러 번호는 무엇이고 1번과 왜 다른 번호인가?
- `rustc --explain` 이 별칭 규칙을 **한 문장**으로 어떻게 적는가?
- 이 규칙이 금지하는 상태와 허용하는 상태를 각각 그림으로 그릴 수 있는가?
- `a.push('!')` 줄을 `let b = &mut s;` **위로** 올리면 어떻게 되는가?

### 3. ★★ 같은 네 줄, 순서만 다르다 (예측)

```rust
// (가)
let mut v = vec![1, 2, 3];
let first = &v[0];
println!("첫 원소 = {}", first);
v.push(4);

// (나)
let mut v = vec![1, 2, 3];
let first = &v[0];
v.push(4);
println!("첫 원소 = {}", first);
```

- 둘 중 컴파일되는 것은 어느 쪽인가?
- 두 파일에서 `first` **이름의 스코프**는 다른가?
- 그렇다면 무엇이 통과와 거부를 갈랐는가 — 그 규칙의 이름은 무엇인가?
- 블록(`{ }`)으로 감싸는 흔한 처방은 이 규칙으로 보면 무엇을 하는 것인가?

### 4. ★ `&mut` 를 함수에 두 번 넘기면 (예측)

```rust
fn bump(r: &mut i32) { *r += 1; }

let mut n = 0;
let r = &mut n;
bump(r);
bump(r);
println!("n = {}", *r);
```

- `&mut i32` 는 `Copy` 가 아니다. 그런데 두 번째 `bump(r)` 은 왜 막히지 않는가?
- 컴파일러가 `bump(r)` 을 실제로 무엇으로 읽는가?
- `let inn = &mut *out;` 을 해 놓고 `*out += 1;` 을 쓰면 무엇이 나는가 — 에러 번호는?
- 안쪽 빌림이 끝나면 바깥 참조는 다시 쓸 수 있는가?

### 5. ★ 참조를 다른 이름에 담으면 (예측)

```rust
// (가)
let n = 1;
let r1 = &n;
let r2 = r1;
println!("{} {}", r1, r2);

// (나)
let mut m = 1;
let w1 = &mut m;
let w2 = w1;
*w2 += 1;
println!("{} {}", w1, w2);
```

- 둘 중 거부되는 쪽은 어느 것이고 에러 번호는 무엇인가?
- 에러가 대는 **이유 한 구절**은 무엇인가?
- `&T` 를 `Copy` 로 둬도 **안전한 이유**를 별칭 규칙으로 설명할 수 있는가?
- `&mut T` 가 `Copy` 였다면 무엇이 무너지는가?

### 6. ★ 두 필드를 동시에 만지면 (예측)

```rust
struct S { a: String, b: String }

impl S {
    fn a_mut(&mut self) -> &mut String { &mut self.a }
    fn b_ref(&self) -> &String { &self.b }
}

// (가)
let ra = &mut s.a;
let rb = &s.b;

// (나)
let ra = s.a_mut();
let rb = s.b_ref();
```

- 둘 중 통과하는 쪽은 어느 것인가?
- 갈리는 이유를 **시그니처**라는 낱말로 설명할 수 있는가?
- 빌림 검사기는 `a_mut` 의 **몸통**을 보는가?
- 이 벽을 푸는 길 세 가지를 들 수 있는가?

### 7. 가변 빌림 중에 원본 이름을 쓰면 (경계)

- `let r = &mut s;` 뒤에 `println!("{}", s);` 를 쓰면 통과하는가?
- 「주인이니까 읽는 건 되겠지」가 왜 안 통하는가?
- 그때 나는 에러 번호는 1번과 같은가 2번과 같은가?
- `let s = ...;`(`mut` 없이) 에 `&mut s` 를 하면 나는 에러는 또 다른 번호인가?

### 8. `*` 는 언제 필요한가 (경계)

- `r: &mut i32` 일 때 `r += 1` 과 `*r += 1` 중 되는 것은?
- `rs: &&&String` 에 `rs.len()` 을 부르면 되는가 — 몇 겹까지 벗겨 주는가?
- `a: &i32`, `b: &i32` 일 때 `a + b` 는 되는가? `&&i32` 끼리는?
- 그 차이가 말해 주는 것은 무엇인가 — 연산자도 자동 역참조를 하는가?

### 9. 여섯 식의 타입 (경계)

- `let _: () = 식;` 을 쓰면 컴파일러가 무엇을 알려 주는가?
- `v: Vec<i32>`, `s: String` 일 때 `&v` · `&mut v` · `&v[0]` · `&s` · `&&s` · `&*s` 의 타입은 각각 무엇인가?
- 그중 **`&str`** 이 나오는 것은 어느 식이고 왜 그런가?
- 여섯 줄을 한 함수에 나란히 써도 빌림 충돌이 안 나는 이유는 무엇인가?
