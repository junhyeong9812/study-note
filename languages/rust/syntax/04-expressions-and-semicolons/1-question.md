## 질문

### 1. ★ 세미콜론 하나 차이 (예측)

```rust
let y = {
    let a = 3;
    a + 1
};
let z = {
    let a = 3;
    a + 1;
};
```

- `y` 와 `z` 의 **값**과 **타입**은 각각 무엇인가?
- 이 프로그램은 컴파일되는가 — 에러인가, 경고인가, 아무것도 없나?
- 경고가 난다면 **린트 이름**은 무엇이고 무엇을 지적하는가?
- `z` 의 크기(`size_of_val`)는 얼마인가?

### 2. ★ 함수 끝의 세미콜론 (예측)

```rust
fn plus_one(a: i32) -> i32 {
    a + 1;
}
```

- 컴파일되는가? 안 된다면 **에러 번호**는?
- 「expected … found …」 부분은 무엇인가?
- 컴파일러가 붙이는 설명 한 줄(`implicitly returns …`)은 무엇을 말하는가?
- `help:` 는 무엇을 가리키는가 — 1번과 이 문항의 **차이**를 한 문장으로 말할 수 있는가?

### 3. `if` 를 값으로 쓰면 (예측)

```rust
let a = if c { 1 } else { 2 };
let b = if c { 1 } else { "둘" };
let d = if c { 1 };
let e = if c { println!("참"); };
```

- 네 줄 중 컴파일되는 것은 어느 것인가?
- 안 되는 것들의 **에러 번호**는 각각 무엇인가?
- `E0317` 의 `note` 한 줄은 무엇을 말하는가?
- `e` 는 왜 되는가 — 그 값과 크기는?

### 4. `match` 팔 하나에만 세미콜론 (예측)

```rust
let n = 1;
let s = match n {
    1 => "하나",
    _ => { "많음"; }
};
```

- 컴파일되는가? 안 된다면 **에러 번호**와 메시지의 제목 줄은?
- 컴파일러는 소스의 **어디를** 가리키는가?
- 고치는 방법은 무엇인가?
- `match` 팔들에 요구되는 규칙을 한 문장으로 말할 수 있는가?

### 5. `loop` 에서 값 꺼내기 (예측)

```rust
let mut i = 0;
let found = loop {
    i += 1;
    if i * i > 50 { break i; }
};

let v = loop {
    i += 1;
    if i == 1 { break 1; }
    if i == 2 { break "둘"; }
};
```

- `found` 의 값은 얼마인가?
- 아래쪽 `v` 는 컴파일되는가 — 안 된다면 에러 번호와 메시지는?
- `break` 가 **하나도 없는** `loop` 의 타입은 무엇인가?
- 그 타입 덕분에 `fn never() -> i32 { loop {} }` 가 컴파일되는가?

### 6. 유닛 타입을 만나는 자리 (예측)

```rust
fn nothing() {}
fn nothing2() -> () {}

let a = nothing();
let b = nothing2();
let c = println!("println! 도 값을 낸다");
let mut x = 0;
let d = { x = 5 };
```

- `a` `b` `c` `d` 의 값은 각각 무엇인가?
- 넷의 **크기**는 각각 얼마인가?
- `a == b` 는 컴파일되는가, 결과는?
- `d` 의 결과가 말하는 것은 무엇인가 — C 의 `a = b = 5` 가 Rust 에서 되는가?

### 7. 반복문에서 값을 꺼내려면 (경계)

```rust
let mut i = 0;
let x: i32 = while i < 3 { i += 1; };
```

- 컴파일되는가? 안 된다면 에러 번호와 「found」 부분은?
- `while`·`for` 는 식인가 문인가 — 그리고 그 타입은?
- 값을 내는 반복을 쓰려면 무엇을 써야 하는가?
- 값을 **모으고** 싶으면 어느 주제로 가야 하는가?

### 8. `let` 은 식인가 (경계)

```rust
let x = (let y = 5);
```

- 컴파일되는가? 에러 메시지의 첫 줄은 무엇인가?
- 메시지의 `note` 가 말하는 **예외 두 곳**은 어디인가?
- 그 예외를 다루는 주제는 목록의 몇 번인가?
- 어떤 식의 타입이 궁금할 때 컴파일러에게 물어보는 한 줄짜리 수법은 무엇인가?

### 9. `()` 는 무엇인가 (왜)

- `()` 를 「값이 없음」이라고 읽으면 어디가 틀리는가?
- `()` 의 크기가 0인 이유를 한 문장으로 말할 수 있는가?
- 반환 타입을 안 적은 함수의 실제 반환 타입은 무엇인가?
- Rust 에 `void` 같은 특수 개념이 없는 이유를 설명할 수 있는가?

### 10. `return` 과 꼬리 표현식 (경계)

- 함수의 마지막 줄에 `return` 을 쓰면 `rustc` 가 뭐라고 하는가?
- `clippy` 는 뭐라고 하는가 — 기본 설정에서도 잡는가?
- `return` 은 문인가 식인가, 그 타입은 무엇인가?
- `let b: i32 = if a < 0 { return -1 } else { a };` 가 컴파일되는 이유는?

### 11. 다른 주제와 잇기 (연결)
