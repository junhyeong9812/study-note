### 1. ★ 이 네 줄에서 `$` 는 언제 보간되는가 (예측)

```kotlin
println("가격: $100")       // [A]
println("끝에 달러: 100$")   // [B]
println("공백 뒤: $ name")   // [C]
val 값 = "한글 식별자"
println("$값")              // [D]
```

- 네 줄의 출력은 각각 무엇인가?
- 보간이 일어나는 조건을 한 문장으로 말하면 무엇인가?
- `"$100"` 에 이스케이프가 필요한가?
- 한글 변수명은 보간되는가?

### 2. ★ `$` 를 글자로 쓰는 방법 셋 중 raw string 에서 못 쓰는 것은 (예측)

```kotlin
println("\$name")               // [A]
println("""${'$'}name""")       // [B]
println($$"""$name""")          // [C]
println("""\$name""")           // [D]
```

- 네 줄의 출력은 각각 무엇인가?
- `[D]` 가 `[A]` 와 다른 이유는 무엇인가?
- `[C]` 는 어느 버전부터 되는가? 그 이전에는 무엇을 쓰는가?
- `$$$"""..."""` 로 적으면 무엇이 보간되고 무엇이 글자로 남는가?

### 3. ★★ 이 함수는 무엇으로 컴파일되는가 (예측)

```kotlin
fun tmpl(name: String, n: Int): String = "이름=$name 개수=$n"
```

- `kotlinc cat.kt` 만 하고 `javap -c` 를 찍으면 어떤 호출이 보이는가?
- `kotlinc cat.kt -jvm-target 21` 로 찍으면 어떻게 달라지는가?
- **둘이 다른 이유**는 무엇이고, 무엇으로 확인하는가?
- 그래서 "Kotlin 템플릿은 `StringBuilder` 다" 는 맞는 문장인가?

### 4. ★ 보간 안의 값이 `null` 이면 무슨 일이 일어나는가 (예측)

```kotlin
class Money(val won: Int) { override fun toString(): String = "${won}원" }

val m = Money(1000)
val s: String? = null
val arr = intArrayOf(1, 2)

println("객체: $m")
println("null: [$s]  길이=${s?.length}")
println("배열: $arr")
```

- 세 줄의 출력은 각각 무엇인가?
- 보간 자리에서 NPE 가 나는가?
- `javap` 로 보면 `String?` 과 `Any?` 가 각각 어느 `append` 로 가는가?
- 이 함수에 `Intrinsics.checkNotNullParameter` 가 있는가, 없다면 왜인가?

### 5. ★★ `trimIndent()` 가 언제 아무 일도 안 하는가 (예측)

```kotlin
val a = """
    가
    나
""".trimIndent()        // [A]

val b = """가
    나
""".trimIndent()        // [B]

val d = """
    가
      나
""".trimIndent()        // [D]

val h = """
    가

    나
""".trimIndent()        // [H]
```

- 네 값의 **줄 수와 각 줄의 앞 공백**은 각각 무엇인가?
- `[B]` 가 `[A]` 와 다른 이유는 무엇인가?
- `[B]` 에서 `trimIndent()` 가 **전혀 아무 일도 안 한 것**인가?
- `[H]` 의 가운데 빈 줄은 최소 공통 들여쓰기 계산에 들어가는가?

### 6. ★ raw string 에서 이 넷은 어떻게 나오는가 (예측)

```kotlin
println("""C:\temp\n 은 그대로다  "따옴표"도 그대로""")   // [A]
println("""raw 안에서도 보간은 된다: $name""")            // [B]
println("""따옴표 셋을 raw 안에: ${"\"\"\""}""")          // [C]
println("""raw 는 이스케이프가 없다: \n \t \\ 그대로""")   // [D]
```

- 네 줄의 출력은 각각 무엇인가?
- raw string 에서 "raw" 가 걸리는 범위는 무엇이고 걸리지 **않는** 것은 무엇인가?
- 여는 구분자와 같은 `"""` 를 raw 안에 넣는 방법은 무엇인가?
- Java 텍스트 블록은 같은 문제를 어떻게 푸는가?
