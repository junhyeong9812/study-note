## 질문

<!-- 질문 하나 = "?" 하나 = 한 줄. 유형: (왜) / (예측) / (경계) / (연결) -->

### 1. ★ `val` 은 무엇을 막고 무엇을 못 막는가 (예측)

```kotlin
val list = mutableListOf(1, 2)
list.add(3)          // [A]
list = mutableListOf(9)   // [B]

val x = 1
x = 2                // [C]
```

- `[A]`·`[B]`·`[C]` 중 컴파일되는 것은 무엇인가?
- 안 되는 것의 에러 메시지는 각각 무엇인가?
- `[A]` 가 통과한 뒤 `list` 의 내용은 무엇인가?
- 그래서 "`val` 이니까 불변" 이라는 문장은 어디서 깨지는가?

### 2. ★★ 이 네 줄 중 어느 것이 에러이고 메시지는 무엇인가 (예측)

```kotlin
val i: Int = 1
val l: Long = i       // [A]
val d: Double = i     // [B]
val b: Byte = 1       // [C]
val i2: Int = b       // [D]
val c: Char = 'a'
val n: Int = c        // [E]
```

- 다섯 중 통과하는 것은 무엇인가?
- 에러 메시지의 형태는 무엇인가 — 어떤 낱말 두 개가 들어가는가?
- Java 였다면 몇 개가 통과하는가?
- 정보 손실이 없는 `[A]` 까지 막는 진짜 이유는 무엇인가?

### 3. ★★ 리터럴은 왜 예외처럼 보이는가 — 넷의 결과를 예측하라 (예측)

```kotlin
val b: Byte = 1        // [A]
val big: Byte = 200    // [B]
val l: Long = 1        // [C]
val f: Float = 1.0     // [D]
val d: Double = 1f     // [E]
```

- 다섯 중 통과하는 것은 무엇인가?
- `[B]` 의 에러 메시지에서 `actual` 로 적히는 타입은 무엇이고, 그것이 무엇을 알려 주는가?
- **정수 리터럴과 실수 리터럴이 왜 다르게 구는가?**
- 2번 문항의 결론("암묵 변환이 없다")을 어떻게 고쳐 말해야 하는가?

### 4. ★ `Char` 는 수인가 — 이 넷의 값과 타입은 무엇인가 (예측)

```kotlin
'a' + 1        // [A]
'b' - 'a'      // [B]
'a'.code       // [C]
val n: Int = 'a'   // [D]
```

- `[A]`·`[B]`·`[C]` 의 **값과 타입**은 각각 무엇인가?
- `[D]` 는 되는가?
- 같은 네 줄을 Java 로 쓰면 어느 것이 달라지는가?
- `Char.toInt()` 는 왜 안 쓰는가?

### 5. ★★ `Int` 와 `Int?` 는 바이트코드에서 같은 타입인가 (예측)

```kotlin
fun plain(a: Int, b: Int): Int = a + b
fun nullable(a: Int?, b: Int?): Int? = if (a == null || b == null) null else a + b

fun boxIt(n: Int): Int? = n
```

- `javap -s` 로 두 함수의 **디스크립터**를 찍으면 각각 무엇인가?
- `boxIt` 의 본문은 `return n` 한 줄인데 `javap -c` 에는 무엇이 더 들어 있는가?
- 그 호출은 누가 넣었는가?
- 그래서 `Int?` 는 "`Int` 에 null 을 더한 것" 인가?

### 6. ★ 이 다섯 줄의 출력과 컴파일러 경고는 무엇인가 (예측)

```kotlin
val a: Int = 127;  val b: Int = 127
val c: Int? = 127; val d: Int? = 127
val e: Int? = 128; val f: Int? = 128

a === b    // [A]
c === d    // [B]
e === f    // [C]
c == d     // [D]
e == f     // [E]
```

- 다섯의 출력은 각각 무엇인가?
- `[A]` 와 `[B]` 에 붙는 **경고 문구가 서로 다르다** — 각각 무엇인가?
- 경고가 `prohibited` 인데도 컴파일이 통과하는가?
- 이 현상의 원인은 Kotlin 에 있는가 Java 에 있는가 — 정본은 어느 문서인가?

### 7. `val` 은 런타임 보장인가 컴파일 검사인가 (경계)

- 클래스의 `val` 프로퍼티는 `javap` 에서 무엇으로 보이는가?
- 함수 안의 지역 `val` 은 `javap` 에서 `var` 와 구별되는가?
- 그래서 두 `val` 의 **보장 범위**는 어떻게 다른가?
- Java 코드에서 Kotlin 의 `val` 프로퍼티를 고칠 수 있는가?

### 8. 대입은 막는데 산술은 왜 되는가 (왜)

- `val l: Long = anInt` 는 에러인데 `anInt + aLong` 은 왜 통과하는가?
- `1 + 2L` 과 `1 + 2.0` 의 타입은 각각 무엇인가?
- 이것을 "자동 승격" 이라고 부르면 왜 틀리는가?
- `Int.MAX_VALUE + 1` 은 예외인가 감김인가?

### 9. 명시 변환 함수는 무엇을 안 막아 주는가 (경계)

- `300.toByte()` 의 결과는 무엇인가?
- `1.9.toInt()` 과 `(-1.9).toInt()` 는 각각 무엇인가 — 반올림인가?
- 컴파일러가 막는 것과 변환 함수가 통과시키는 것의 경계는 어디인가?
- 그래서 좁히는 변환 앞에서 직접 해야 할 일은 무엇인가?

### 10. 어느 것이 언어 보장이고 어느 것이 JVM 구현인가 (경계)

- "`val` 재대입은 컴파일 에러다" 는 어느 쪽인가?
- "`val` 프로퍼티가 `final` 필드가 된다" 는 어느 쪽인가?
- "`Int?` 는 `java.lang.Integer` 다" 는 어느 쪽인가?
- "`-128\~127` 은 `===` 가 `true` 다" 는 어느 쪽이고 무엇으로 뒤집히는가?
