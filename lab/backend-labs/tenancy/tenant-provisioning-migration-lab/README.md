## Questions

1. 1,000개 스키마에 컬럼과 인덱스를 추가하는 데 얼마나 걸리는가?
2. 마이그레이션이 500번째 테넌트에서 실패하면 롤백할까, 전진할까?
3. 테넌트마다 스키마 버전이 다를 때 애플리케이션은 어떻게 동작해야 하나?
4. 신규 테넌트 생성(스키마 생성 + 마이그레이션 + 초기 데이터)은 몇 초 안에 끝나야 하나?
5. 큰 테넌트를 다른 샤드·셀로 무중단 이전할 수 있나?
6. 마이그레이션 중 운영 트래픽의 p99는 얼마나 흔들리는가?

## Architecture

```
Admin API
 ├── POST /tenants ── Provisioner (스키마 생성 → 마이그레이션 → 시드)
 └── POST /migrations/run
        ↓
   Migration Runner
    ├── 테넌트 레지스트리 조회
    ├── 스키마별 버전 원장 + 스키마별 락
    ├── 동시 실행 수 제한 (배치 크기)
    └── 실패 시 중단 / 건너뛰기 / 재시도 정책
        ↓
   Tenant Schemas (1 ~ N)

Tenant Mover ── 복제 → 따라잡기 → 쓰기 잠금 → 라우팅 전환
```
