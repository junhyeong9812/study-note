## Questions

1. 잔액 1,000P에 1,000P 사용 요청이 동시에 두 번 오면?
2. 유효기간이 다른 적립 5건 중 무엇부터 차감할까?
3. 5,000P 중 2,000P만 사용 취소하면 어느 적립 건으로 되돌릴까?
4. 되돌릴 적립 건이 이미 만료됐다면?
5. 적립 취소 이벤트가 적립보다 먼저 도착했다면?
6. 잔액 컬럼과 이력 합계가 어긋났다면 무엇이 진실인가?
7. (확장) 송금 요청이 타임아웃이라 은행 처리 결과를 모른다면?

## Architecture

```
Point API
 ├── Use (동기) ────────→ Point Ledger (Insert-only)
 │                          ├── point_event  (적립/사용/취소/만료)
 │                          └── point_detail (적립 건별 차감 내역)
 └── Earn / Cancel (비동기)
        ↓
     Command Queue ── 실패 N회 → DLQ
        ↓
     Worker → Point Ledger
        ↓
     Balance Updater → Redis (잔액 캐시)

Expiry Batch → 만료 이벤트 Insert
Audit Batch  → 잔액 = Σ 적립 건 잔여 검증

(확장) Transfer → Mock Bank (펌뱅킹 모사)
```
