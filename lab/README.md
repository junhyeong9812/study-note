# lab — 실험 프로젝트 기록

직접 설계·실행한 실험 프로젝트들의 **포트폴리오형 정리**. 프로젝트 = 폴더, 폴더 안 README 하나가 그 실험의 단일 정리 문서다(배포 서버가 폴더+README를 그대로 렌더링).

성격은 [세미나/](../세미나/)·[독후감/](../독후감/)과 같은 "기록" 갈래 — 인출 훈련(cs/)이 아니다. 실험에서 나온 CS 지식은 cs/로 추출하고 각 README의 "cs/ 추출 후보"에 링크를 남긴다.

## README 골격 (프로젝트 공통)

```markdown
# <프로젝트명> — <한 줄 요약>
- 원본 repo · 기간 · 스택 · 상태(완료/부분/설계만)
## 무엇을 알고 싶었나 — 질문·가설
## 실험 환경과 방법
## 결과 — 페이즈/시나리오별   ← 수치는 원본 문서에서 복사, 표마다 출처 경로 명기
## 종합 결론
## 한계·남은 질문
## 원본 문서 지도
```

- **수치는 원본에서 복사만** — 재측정·추정 금지. 원본에 없는 값은 "문서에 없음".
- 원본 문서의 자체 경고(측정 오염 등)는 그대로 전달한다.
