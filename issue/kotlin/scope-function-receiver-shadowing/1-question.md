# issue/kotlin/scope-function-receiver-shadowing — 스코프 함수 안의 같은 이름은 수신자 쪽을 먼저 가리킨다 — 질문

## 질문
1. (예측) 테스트 클래스에 `private val schema = "engine_test"` 가 있고, 준비 코드가 `PoolConfig().apply { url = base + "?currentSchema=$schema" }` 다. `PoolConfig` 는 Java 클래스이고 `getSchema()/setSchema()` 를 가진다. `url` 에는 무엇이 들어가는가?
2. (왜) Kotlin 은 `apply` 블록 안의 이름을 어떤 순서로 찾는가? Java 의 getter/setter 쌍이 왜 이 충돌에 끼어드는가?
3. (왜) 이 결함은 컴파일 오류도, 경고도 없이 지나갔다. 타입이 맞아떨어진 까닭과 null 이 문자열 템플릿에서 어떻게 보이는지를 설명하라.
4. (방법) 바깥 클래스의 값을 확실히 가리키는 방법은 무엇인가? 같은 종류의 결함이 다른 곳에 없는지는 어떻게 확인했는가?
5. (경계) 테스트 준비 코드의 결함을 구현 쪽 작업자가 발견했을 때, 그 테스트를 직접 고치지 않고 보고만 한 까닭은 무엇인가?
6. (연결) `apply` 대신 `also`(람다 인자 `it`)를 쓰거나, 값을 블록 밖에서 먼저 계산해 두면 이 결함은 어떻게 되는가?
