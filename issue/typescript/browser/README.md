# typescript/browser — 브라우저 입력

브라우저의 입력 이벤트 모델에서 나오는 패턴이다.\
공통 원리: **입력은 이벤트 하나가 아니라 생명주기다** — IME 조합·전파·포커스 소유를 확인한 뒤 처리한다.

## 공통 원리

```
  keydown ──▶ compositionstart ──▶ ...조합 중... ──▶ compositionend
     │
     └─ 조합 중 Enter를 제출로 처리 → 글자 잘림·중복 제출
```

## 패턴 카드

- [input-event-model](input-event-model/) — 브라우저 입력 이벤트(IME 조합·키 전파·포커스 소유·DnD 생명주기)는 라이브러리 "처리됨" 반환·단일 이벤트 가정과 다르게 흐른다 — 조합 중 값 덮어쓰기 금지·전파 차단·창 단위 백스톱.
