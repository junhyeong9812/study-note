# 독후감

책을 읽으며 남기는 기록. 책 목록·진행 상태는 [index.md](index.md)에 기록한다. **인출 훈련(cs/)이 아니라 생각의 기록**이다 — 성격은 [세미나/](../세미나/)와 같은 갈래.

## 구조

```text
독후감/
├── README.md                ← 이 파일 (규칙 + 템플릿)
└── <책-제목>/               ← 책 = 폴더 (kebab-case 한글 허용)
    ├── README.md            ← 책 정보 · 읽은 동기 · 챕터 색인 · (완독 후) 총평 · cs/ 추출 목록
    ├── 01-챕터명.md          ← 읽으면서 그때그때 기록
    └── 02-챕터명.md
```

- **기술서·공부하며 읽는 책**: 챕터별 파일로 쓴다 — 읽는 시점의 생각을 남기고, 챕터가 커밋 단위가 된다.
- **에세이·가볍게 읽는 책**: 폴더 안 README 하나로 충분. 챕터를 의무로 만들지 않는다.

## 경계 — 여기는 생각, 정리는 cs/

- 챕터 파일에 내용 요약을 길게 쓰지 않는다. **내용 정리(서머리·질문·정답)는 cs/의 몫** — 책에서 건진 지식 주제는 cs/에 폴더를 만들어 추출하고, 책 README의 "cs/ 추출 목록"에 링크만 남긴다. (예: jun-bank → cs/solid-principles 이관과 같은 흐름)
- 작성 흐름: 내가 읽으며 정리 → 그 원고를 바탕으로 Claude에게 구조 정리·cs 추출을 요청한다.

## 챕터 파일 템플릿

```markdown
# NN. 챕터명

## 핵심 내용 (2~3줄)

## 내 생각 — 경험과의 연결

## 동의 안 되는 점 / 질문

## cs/ 추출 후보
- (없으면 "없음")
```

```markdown
- 읽은 동기:

| 챕터 | 파일 | 상태 | 한 줄 소감 |
|------|------|------|-----------|
| 1. | [01-...md](01-...md) | 읽는 중 | |

## cs/ 추출 목록

- (책에서 추출해 cs/로 보낸 주제 링크)

## 총평 (완독 후)
```
