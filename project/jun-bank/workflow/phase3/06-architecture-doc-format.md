# 아키텍처 기술서 양식

---

## 1. 목적

**앞의 다섯 문서를 하나의 읽는 순서로 묶는다.**

기술서는 **내용을 새로 만들지 않는다.** 제약·품질 속성·시나리오·ADR·뷰가 이미 정본이고,
기술서는 *"어디서부터 읽어야 하는가"* 와 *"이 결정들이 서로 맞는가"* 를 답한다.

> ★ **내용을 복사하면 그 순간 둘로 갈라진다.** Phase 2에서 열 라운드에 걸쳐 확인한 것이다 —
> **기술서는 링크와 요약만 갖는다.**

## 4. 작성법

### §1 한 장 요약 — **포기한 것**을 반드시 넣는다

신규 참여자가 가장 먼저 묻는 것은 *"왜 이건 안 되나"* 다.
채택만 적으면 그 질문에 답할 수 없고, 매번 같은 논의가 반복된다.

### §4 되돌리는 조건 모음 — 흩어진 것을 한 곳에

각 ADR의 §5에 있는 조건을 **전부 모은다.** 흩어져 있으면 아무도 안 본다.

```
| p99 500ms 2회 연속        | ADR-04 | QS-04 대시보드      |
| 유스케이스가 3개 서비스 동기 호출 | ADR-02 | 코드 리뷰 체크리스트 |
| M9~M15 주 1회 이상 적재    | ADR-07 | 대사 배치 알림      |
```

> ★ **관찰 방법이 비면 그 조건은 안 켜진다.** *"누가 어디서 보는가"* 까지 적는다.

### §6 정합성 점검 — 이 문서가 하는 유일한 **새 일**

앞 문서들이 **서로 맞는지**는 아무도 안 본다. 여기서 본다.

| # | 점검 | 어긋나면 |
|---|---|---|
| 1 | 채택한 품질 속성마다 **시나리오**가 있는가 | 측정 못 하는 품질을 선언했다 |
| 2 | ADR의 근거가 **제약·시나리오**를 가리키는가 | 취향으로 결정했다 |
| 3 | **제약에 걸리는 안**을 고르지 않았는가 | 못 하는 것을 하기로 했다 |
| 4 | ★ **트랜잭션 경계(E1~En)가 서비스를 넘지 않는가** | 분산 트랜잭션이 생겼다 |
| 5 | ★ **데이터 소유권**과 저장 위치가 일치하는가 | 소유자 아닌 곳이 원본을 쥔다 |
| 6 | 포기한 품질을 **요구하는 시나리오**가 없는가 | 포기 선언이 거짓이다 |
| 7 | ★ Phase 2 인계의 **수치 미확정**이 대장에 전부 있는가 | 구현자가 임의로 정한다 |
| 8 | ADR끼리 **모순**되지 않는가 | 한쪽은 강한 일관성, 다른 쪽은 최종 일관성 |

> ★ **4·5는 Phase 2가 만든 것을 지키는 점검이다.** 아키텍처가 도메인 경계를 깨는 것은
> 아키텍처 문서 안에서는 안 보인다 — **대조해야 보인다.**

### §7 열린 것 — 미결을 숨기지 않는다

Phase 3에서 못 닫은 것을 적고 **언제 닫는지**를 쓴다.
안 적으면 Phase 4~5에서 **구현자가 임의로 정한다.**

## 5. 흔한 실수

| # | 실수 | 왜 문제인가 | 고치는 법 |
|---|---|---|---|
| 1 | **내용을 복사** | 정본이 둘이 되고 반드시 갈라진다 | 링크와 요약만 |
| 2 | **포기한 것 누락** | *"왜 이건 안 되나"* 에 매번 다시 답한다 | §1에 필수 |
| 3 | **되돌리는 조건이 흩어짐** | 아무도 안 본다 | §4에 모으고 관찰 방법까지 |
| 4 | **정합성 점검 생략** | 문서끼리 어긋난 채 확정된다 | §6 8항목 전수 |
| 5 | **열린 것 숨김** | 구현자가 임의로 정한다 | §7에 적고 닫는 시점을 |
| 6 | ★ **Phase 2와 대조 안 함** | 트랜잭션 경계·소유권이 깨진다 | §6의 4·5·7 |
| 7 | **한 장 요약이 한 장이 아님** | 신규 참여자가 못 읽는다 | 표 하나로 줄인다 |

## 6. 완료 기준

- [ ] §1이 **한 장**이고 **포기한 것**이 들어 있다
- [ ] 모든 절이 **정본 문서를 링크**하고 내용을 복사하지 않았다
- [ ] §3 결정 색인에 **모든 ADR**이 있고 되돌리기 난이도가 표시돼 있다
- [ ] §4에 **모든 ADR의 되돌리는 조건**이 모여 있고 **관찰 방법**이 있다
- [ ] §6 **정합성 점검 8항목**이 전부 판정돼 있다 (통과/불통과 + 근거)
- [ ] §6의 4·5·7이 **Phase 2 산출물과 실제로 대조**됐다
- [ ] §7 열린 것마다 **닫는 시점**이 있다
