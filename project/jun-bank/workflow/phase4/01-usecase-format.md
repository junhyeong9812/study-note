# 유스케이스 기술서 — 양식과 작성법

- 상태: ★ **확정 v1.1** (파일럿 작성 + 듀얼 1패스 리뷰 반영 — 2026-08-05)

---

## 1. 목적

**도메인 조작(내부 언어)을 액터의 목표(외부 언어)로 묶는다.**

Phase 2가 만든 조작 62개는 시스템의 어휘다. 유스케이스는 그 어휘로 **누가 무엇을 이루는가**를 적고,
Phase 5 구현·테스트의 단위가 된다. **조작의 재나열이면 유스케이스가 아니다.**

> ★ **"사용자 목표" 수준을 지킨다** (phase-backlog) — *"버튼을 누른다"* 수준으로 내려가면 화면 명세가 되고,
> 화면이 바뀔 때마다 유스케이스가 바뀐다. 화면 없는 액터(매입사·배치)도 목표는 있다.

> ★ **예외 시나리오가 본문이다.** 결제 도메인은 정상 경로가 짧고 예외가 길다 —
> Phase 2 치명의 대부분이 예외 경로(망취소·부분 실패·재전달)에서 나왔다.

## 2. 독자

| 독자 | 얻는 것 |
|---|---|
| 구현자 (Phase 5) | 시나리오 단위 · 어느 조작을 어떤 순서로 |
| 테스트 설계자 | **예외 전수** — 시나리오마다 검증 대상 |
| QA · 리뷰어 | 액터 관점의 완결성 — 목표가 이뤄지거나, 왜 안 되는지가 드러나거나 |

## 3. 양식

> 유스케이스 **하나당 파일 하나**. `docs/usecases/UC-nn-<이름>.md` · 색인은 `docs/usecases/README.md`(§5).

```markdown
# UC-nn. <액터의 목표를 동사로>

- 작성일: <YYYY-MM-DD>
- 상태: 작성중 | 검토대기 | 확정
- 액터: <주체 유형 — 고객 / 운영자 / 시스템·외부 (BR-54)>
- 권한 요건: <단계·스코프 (BR-55) · 2인 승인 대상이면 BR-56 번호>
- 트랜잭션 경계: <E1~E5 또는 "조회 — 경계 없음">
- 관련 규칙: <BR-nn 나열 — 규칙 문장 복사 금지, 참조만 (F-24)>

## 1. 목표 (한 문장)
## 2. 사전 조건 / 사후 조건 (성공·실패 각각 — 실패 시 시스템이 어떤 상태로 남는가)
## 3. 주요 성공 시나리오 (번호 단계 — 단계마다 [조작 · BR] 참조)
## 4. 예외 시나리오 ★ (예외마다: 트리거 → 시스템 반응 → 종결/복구 → [BR·M유형·금지 전이])
## 5. 대체 시나리오 (목표는 같고 경로가 다른 것)
## 6. 인가·감사 ★ (주체 판정 시점 · 거절 응답 — L7 · 감사에 남는 것 · 승인 흐름이면 요청/승인/소비)
## 7. 계약 (이 유스케이스가 요구하는 API·이벤트 — 02 양식의 계약 블록)
## 8. 규칙 연결 표 (단계 ↔ BR/INV/조작 — 양방향 역참조 가능해야)
## 9. 열린 의문
```

## 4. 작성 규칙

| # | 규칙 | 왜 |
|---|---|---|
| U-1 | **한 유스케이스 = 한 목표.** 목표가 둘이면 파일을 나눈다 | 테스트·구현 단위가 흐려진다 |
| U-2 | **액터 없는 유스케이스는 없다.** 순수 배치(대사·만료)는 유스케이스가 아니라 **운영 절차**다 — 배치가 액터의 목표를 대신 이룰 때만(예: 재처리) 그 액터의 유스케이스에 속한다 | "시스템이 시스템에게"는 목표가 아니다 |
| U-3 | **예외 시나리오는 상태 머신의 금지 전이·M유형과 대응**시킨다 — 없는 예외를 만들지도, 있는 금지를 빠뜨리지도 않는다 | 정본과의 양방향 검증 |
| U-4 | **인가·감사 절은 생략 불가** (2026-08-05 멀티테넌시 이후) — 주체·단계·L7 응답·감사 항목이 빈 유스케이스는 미완 | G-1~G-4의 재발 방지 |
| U-5 | 규칙 문장을 **복사하지 않는다** — `BR-nn` 참조만 | F-24 (복사 = 갈라짐) |
| U-6 | **빈 칸 = 결함.** "해당 없음"도 근거 1줄과 함께 적는다 | 형식적 충족 차단 (검산 원칙) |
| U-7 | ★ **공유 계약의 거처는 하나다** — 여러 UC가 쓰는 계약(예: BR-56 공통 승인 API)은 최초 정의한 UC가 정본이고, 다른 UC는 **참조만** 한다. 색인이 정본 위치를 표시한다 | F-24가 계약 층에서 재발하는 것 차단 (리뷰 F-12) |
