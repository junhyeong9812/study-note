# 기능명세 — API·이벤트 계약 양식 (화면은 전환도 수준)

- 상태: ★ **확정 v1.1** (파일럿 작성 + 듀얼 1패스 리뷰 반영 — 2026-08-05)

---

## 1. 목적

**구현·QA가 그대로 실행할 수 있는 계약을 고정한다.** 이 프로젝트는 백엔드 설계 연습이므로
정본은 화면이 아니라 **API와 이벤트**다(2026-08-05 인터뷰 확정). 화면은 전환도 수준만 —
실질 UI는 운영자 화면(승인 대기·불일치 목록)뿐이다.

> ★ **이 양식으로 쓰는 계약이 S-6a의 "최초 설계" 창구다** (ADR-015 · IS-5 · AD-7).
> 여기서 굳은 뒤의 의미 필드 추가는 **새 타입**이다 — 축·행위자 필드를 지금 넣는다.

## 2. 계약 블록 양식 (UC 파일 §7에 인라인)

### 2.1 API

```markdown
#### `<METHOD> <경로>` — <한 줄 요약>

| 항목 | 내용 |
|---|---|
| 주체 | ★ 필수 (AU-1) — <고객(본인) / 운영자(단계·스코프) / 시스템(경로)> · 판정 시점 = 진입 1회 (AU-4) |
| 요청 | <필드 · 타입 · 검증 — 금액은 BR-07(통화+최소단위 정수)> |
| 응답(성공) | <필드 — ★ 반환 범위가 주체 스코프 안인가 (BR-58: 단건·목록·집계 동일)>
| 오류 표 ★ | <코드 · 조건 · L7: 범위 밖·부재는 **같은 형태**(존재 비노출). 거절도 감사 기록 (BR-57)> |
| 멱등 | <키·범위 — 없으면 "비멱등 + 왜 안전한가"> |
| 예산 | <상속 응답 예산 — E1 계열이면 내부 2.5초 (T-11). 아니면 "실시간 아님"> |
| 감사 | <남는 것: 주체·대상·스코프·결과 (AD-8) — 조회도 남는다. ★ **경로 규칙**: 조작 성공 = 커밋 내 outbox(AD-2) · 거절/실패 = 독립 커밋(AD-2) · 조회 = 비동기 적재(AD-4) · C8 자기 조작 = 직접 append(AD-5)> |
```

### 2.2 이벤트

```markdown
#### `<EventName>` — <발생 시점>

| 항목 | 내용 |
|---|---|
| payload | <필드 — ★ 행위자: 운영 이벤트만 포함, 자금 이벤트 비포함 (AD-7 선) · 축 필드 = 이 시점에 최초 설계 (IS-5)>
| 구독 | <구독자 — 감사 수집은 구독이 아니라 감사 전용 outbox 레코드 (AD-2)>
| 멱등 키 | <수신측 유일 제약 — at-least-once 전제 (INV-8·INV-9·AD-3 형태)>
| 스키마 버전 | S-9 — 버전 필드 명시
```

### 2.3 화면 (해당 시에만 — 전환도 수준)

```markdown
#### 화면 전환도
<텍스트 다이어그램: 화면 → 조건 → 화면. 레이아웃·항목 정의는 하지 않는다 — 화면이 바뀌어도 계약은 불변>
```

## 3. 작성 규칙

| # | 규칙 | 왜 |
|---|---|---|
| C-1 | **주체 없는 API 금지** (AU-1) — 시스템 경로도 경로 식별자를 적는다 | BR-54 |
| C-2 | **오류 응답 두 형태 금지** — "없음"과 "권한 없음"이 구별되면 존재가 샌다 (L7). ★ **적용 채널 = 사람 주체(고객·운영자) API** — 시스템 채널(매입사 전문)은 해당 정본(BR-15·36)이 **사유 구분을 명시 요구**한다(파일럿 UC-01이 확정한 경계). ★ **판정 순서 = 스코프·존재 먼저** — 순서 없이는 상태 오류가 ID 탐색 채널이 된다(UC-02 확정) | BR-58 · BR-36 |
| C-3 | 목록·집계·조인도 **같은 소유자 조건** — 단건만 막고 합계가 새는 것도 위반 | BR-58 (L3·L4) |
| C-4 | **자금 이벤트 payload에 행위자 금지** — 행위자는 감사 수집이 나른다 | AD-7 |
| C-5 | 수치는 전부 **확정/[미검증] 표기** — 근거 없는 수는 쓰지 않는다 | 수치 정책 |
| C-6 | 신설 엔드포인트는 **색인(usecases/README.md)에 같은 커밋으로 등재** | 전수 시험 입력 — 사람이 세면 빠진다 |

## 4. 완료 기준
