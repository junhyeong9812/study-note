## 한눈에 — 쉽게 말하면

**사인파 움직임은 「그네」다.**
그네는 가운데를 지나 앞으로 갔다가 다시 가운데를 지나 뒤로 가고, 이것을 끝없이 되풀이한다.
얼마나 높이 올라가느냐가 크기이고, 얼마나 자주 오가느냐가 빠르기다.
그네 여러 개를 조금씩 늦게 밀기 시작하면, 옆에서 볼 때 물결이 흘러가는 것처럼 보인다.
`Math.sin` 으로 만드는 움직임도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 그네가 가운데에서 가장 멀리 가는 거리 | `amplitude` (진폭) |
| 그네가 얼마나 자주 오가나 | `frequency` (주파수 · 빠르기) |
| 그네를 언제 밀기 시작했나 | `phase` (위상 · 시작 오프셋) |
| 흘러가는 시간 | `time` |
| 그네 줄을 매단 자리 | 중심 좌표 `cy` |

```text
  y
  ↑            +amplitude
  |    .-'''-.                .-'''-.
  |  .'       '.            .'       '.
──+-'-----------'.--------.'-----------'.---→ time   (중심)
  |                '.    .'
  |                  '--'   -amplitude
  |<------ 한 주기 ------->|
```

## 이 주제가 답하려는 질문

1. 시간 하나만으로 「되풀이되는 왕복 운동」을 어떻게 만드나?
2. 크기 · 빠르기 · 시작 시점을 어느 숫자가 맡나?
3. 점 여러 개에 위상을 조금씩 다르게 주면 왜 물결이 흘러가 보이나?
4. 같은 사인 값으로 위치 말고 크기(호흡 · 펄스)도 움직일 수 있나?

## 동작 방식

### (1) 사인 함수 하나로 왕복 운동 만들기

**언제 쓰나** — 파도 · 호흡 · 펄스처럼 같은 움직임이 끝없이 되풀이되어야 할 때 쓴다.
이 항목의 설명대로 사인 함수는 주기적 왕복 운동의 기본이다.

```text
입력:  y = amplitude * Math.sin(time * frequency + phase)

time 이 커진다
  → 괄호 안의 각도(time*frequency+phase)가 계속 커진다
  → Math.sin(각도) 는 -1 ~ 1 사이를 오르내린다 (2π 마다 같은 값으로 돌아온다)
  → amplitude 를 곱하면 -amplitude ~ +amplitude 사이를 오르내린다

결과:  y 가 끝없이 왕복한다
```

- `Math.sin` 은 어떤 각도(라디안)를 넣어도 -1 이상 1 이하의 값을 돌려준다.
- 각도가 2π 늘어날 때마다 값이 처음으로 돌아오므로 움직임이 되풀이된다.
- `amplitude` 를 곱하면 흔들리는 폭이 그만큼 넓어진다.
- 그래서 시간만 계속 흘려 넣으면 따로 「방향을 바꿔라」는 코드 없이 왕복이 생긴다.

> **사인 함수(sine)** — 각도를 받아 -1 ~ 1 사이의 값을 돌려주며, 2π 마다 같은 값을 되풀이하는 함수.\
> 예: `Math.sin(0)` 은 0, `Math.sin(Math.PI / 2)` 는 1 이다.

> **라디안(radian)** — 각도의 단위로, 한 바퀴(360°)가 2π 이다.\
> 예: 90° 는 π/2 라디안이다.

### (2) 세 손잡이 — amplitude · frequency · phase

**언제 쓰나** — 같은 공식에서 움직임의 크기 · 빠르기 · 시작 시점만 바꾸고 싶을 때 쓴다.

```text
amplitude  ↑  →  위아래로 더 크게 흔들린다        (크기)
frequency  ↑  →  각도가 더 빨리 커진다 → 더 자주 왕복 (빠르기)
phase      +  →  곡선 전체가 시간 축에서 미리 앞서 간다 (시작 오프셋)

한 번 왕복하는 시간(주기) = 2π / frequency   (time 이 초 단위일 때, 초)
```

- `amplitude` 는 결과에 곱해지므로 흔들림의 폭만 바꾼다.
- `frequency` 는 `time` 에 곱해지므로 각도가 커지는 속도를 바꾼다.
- 각도가 2π 늘어야 한 번 왕복하므로, 주기는 `2π / frequency` 다.
- 예를 들어 `frequency` 가 2 이면 주기는 2π / 2 = π, 약 3.14 초다.
- `phase` 는 각도에 더해지므로 같은 순간에도 다른 자리의 값을 보게 만든다.
- 이 코드의 `frequency` 는 「1초에 몇 번」(Hz)이 아니라 「1초에 몇 라디안」이다 — 슬라이더 이름은 「주파수」지만 2 를 넣는다고 1초에 두 번 왕복하지 않는다.

> **주기(period)** — 움직임이 한 번 왕복해 처음 상태로 돌아오는 데 걸리는 시간.\
> 예: `frequency` 가 2 이면 주기는 약 3.14 초다.

> **위상(phase)** — 사인 곡선에서 「지금 어느 자리에 있나」를 정하는 각도, 또는 그 출발점을 미리 옮겨 두는 오프셋.\
> 예: 위상 π/2 를 더하면 시간 0 에서 이미 꼭대기 값 1 에서 출발한다.

### (3) 점마다 위상을 나누면 진행파가 된다

**언제 쓰나** — 한 점의 왕복이 아니라 여러 점이 물결처럼 흘러가는 모양을 만들 때 쓴다.

```text
입력 (발췌):
  phase = (i / dotCount) * Math.PI * 2
  y     = cy + amp * Math.sin(t * freq + phase)

i = 0      → phase = 0
i = 1      → phase = 2π/25
...
i = 24     → phase = 2π·24/25   (한 바퀴에서 한 칸 모자람)

같은 순간 t 에서 점마다 사인 곡선의 다른 자리에 있다
  → 가로로 늘어놓으면 화면에 사인 곡선 한 마디가 그려진다
  → t 가 커지면 모든 점이 같은 빠르기로 곡선을 따라 앞으로 간다
  → 위상이 큰 점(오른쪽)이 같은 자리에 먼저 닿고, 위상이 작은 점(왼쪽)이 뒤따른다

결과: 물결 모양이 오른쪽에서 왼쪽으로 흘러간다
```

- 위상을 0 에서 2π 까지 25 등분해 나눠 주므로 25개 점이 사인 곡선 한 주기를 나눠 맡는다.
- 마지막 점은 2π 에서 한 칸 모자란 자리라서, 화면 왼쪽 끝과 오른쪽 끝이 자연스럽게 이어지는 모양이 된다.
- 모든 점의 각도는 `t * freq` 만큼 똑같이 커진다.
- 오른쪽 점일수록 위상이 커서 각도가 앞서 있으므로, 어떤 높이에 오른쪽 점이 먼저 닿고 왼쪽 점이 나중에 닿는다.
- 그래서 같은 높이(예: 가장 아래)가 오른쪽에서 왼쪽으로 옮겨 가고, 물결이 왼쪽으로 흐르는 것처럼 보인다.

> **진행파(travelling wave)** — 매질의 각 점은 제자리에서 왕복만 하는데, 모양이 한 방향으로 옮겨 가는 파동.\
> 예: 경기장의 파도타기 응원에서 사람은 앉았다 일어설 뿐인데 물결은 관중석을 따라 돈다.

### (4) 화면 좌표에 얹기 — 중심 · 간격 · 아래쪽이 +

**언제 쓰나** — 계산한 사인 값을 실제 픽셀 자리로 옮길 때 쓴다.

```text
입력 (발췌):
  cy = container.offsetHeight / 2
  x  = (i + 0.5) / dotCount * cw
  y  = cy + amp * Math.sin(...)

cy  → 컨테이너 세로 가운데를 흔들림의 중심으로 삼는다
x   → 가로를 25칸으로 나눠 각 칸의 한가운데에 점을 둔다
y   → 가운데에서 위아래로 amp 만큼까지 흔들린다
       (화면 좌표는 아래로 갈수록 y 가 크다 → sin 이 1 일 때 가장 아래)

결과: 점이 컨테이너 안에서 cy - amp ~ cy + amp 사이를 오르내린다
```

- `cy` 를 더하지 않으면 흔들림의 중심이 컨테이너 맨 위(0)가 되어 점 절반이 위로 잘려 나간다.
- `(i + 0.5) / dotCount` 는 0.02, 0.06, … 0.98 처럼 칸의 한가운데를 가리키므로 양 끝에 반 칸씩 여백이 남는다.
- 화면 좌표는 y 가 클수록 아래이므로, 수학 그래프와 달리 `sin` 이 1 일 때 점이 가장 아래에 있다.
- 높이 250 인 컨테이너면 `cy` 는 125 이고, 진폭 40 이면 점의 중심은 85 ~ 165 사이를, 진폭 80 이면 45 ~ 205 사이를 오간다.

### (5) 같은 사인 값을 크기에도 — 호흡감

**언제 쓰나** — 위치와 함께 크기도 맥박처럼 커졌다 작아지게(펄스 · 호흡) 할 때 쓴다.

```text
입력 (발췌):
  scale = 0.7 + 0.3 * Math.sin(t * freq + phase)
  dot.style.transform = `translate(-50%, -50%) scale(${scale})`

sin 이  1 → scale = 0.7 + 0.3 = 1.0
sin 이  0 → scale = 0.7
sin 이 -1 → scale = 0.7 - 0.3 = 0.4

결과: 점이 가장 아래에 있을 때 가장 크고, 가장 위에 있을 때 가장 작다
```

- 공식은 위치와 같지만 중심이 0.7, 진폭이 0.3 이다.
- 그래서 scale 은 0.4 에서 1.0 사이를 오간다.
- 위치와 같은 각도를 쓰므로, 아래로 내려간 점이 커지고 위로 올라간 점이 작아져 깊이감이 생긴다.
- `transform` 에 `translate(-50%, -50%)` 를 함께 다시 적는 이유는 (6) 에 있다.

### (6) 매 프레임 다시 계산하기 — `requestAnimationFrame`

**언제 쓰나** — 위의 계산을 화면이 새로 그려질 때마다 되풀이해 움직임을 만들 때 쓴다.

```text
requestAnimationFrame(animate)
  → 브라우저가 다음 그리기 직전에 animate(time) 를 부른다 (time 은 밀리초)
  → t = time * 0.001        밀리초 → 초
  → 슬라이더에서 amp, freq 를 읽는다 (parseFloat)
  → 컨테이너 크기에서 cy, cw 를 읽는다
  → 25개 점의 left / top / transform 을 새로 쓴다
  → 끝에서 다시 requestAnimationFrame(animate) 를 건다

결과: 프레임마다 각도가 조금씩 커지며 점들이 끊김 없이 움직인다
```

- 밀리초를 그대로 쓰면 각도가 1000배 빨리 커져 움직임이 알아볼 수 없을 만큼 빨라지므로 초로 바꾼다.
- 슬라이더 값은 문자열이므로 `parseFloat` 로 숫자로 바꿔 곱셈에 쓴다.
- 슬라이더와 컨테이너 크기를 매 프레임 다시 읽으므로, 슬라이더를 움직이거나 창 크기를 바꾸면 다음 프레임부터 바로 반영된다.
- 각도를 「지금까지 쌓인 값」이 아니라 매번 `t * freq` 로 새로 계산한다.
- 그래서 주파수를 바꾸는 순간 `t * freq` 가 한꺼번에 크게 달라지고, 점이 곡선의 엉뚱한 자리로 건너뛰듯 움직일 수 있다(t 가 클수록 더 크게 건너뛴다).
- 슬라이더 옆 숫자는 `input` 이벤트에서 따로 갱신한다.

> **`requestAnimationFrame`** — 다음 화면 그리기 직전에 콜백을 한 번 불러 주는 브라우저 함수로, 콜백은 시각(밀리초)을 인자로 받는다.\
> 예: 콜백 끝에서 자기 자신을 다시 넘기면 매 프레임 불리는 고리가 된다.

## 문법 — 형태와 규칙

기본 공식은 이것이다.

```javascript
y = amplitude * Math.sin(time * frequency + phase)
```

점 하나를 가운데에서 위아래로 흔드는 최소 예제다.

```html demo
<div id="box" style="position:relative;height:200px;background:#0f172a">
  <div id="dot" style="position:absolute;left:50%;width:16px;height:16px;
       border-radius:50%;background:#38bdf8;transform:translate(-50%,-50%)"></div>
</div>
<script>
  const box = document.getElementById('box');
  const dot = document.getElementById('dot');
  function tick(time) {
    const t = time * 0.001;                                  // 밀리초 → 초
    const y = box.offsetHeight / 2 + 50 * Math.sin(t * 2);   // 중심 + 진폭 * sin
    dot.style.top = y + 'px';
    requestAnimationFrame(tick);
  }
  requestAnimationFrame(tick);
</script>
```

> **보이는 것** — 어두운 상자 가운데 파란 점 하나가 위아래 50 만큼씩 약 3.14 초 주기로 왕복한다 (코드에서 읽은 것 — 렌더 실측 아님)

- `Math.sin` 에 넣는 값은 라디안이다.
- 결과는 -1 ~ 1 이므로 `amplitude` 를 곱해 폭을 정하고, 중심 좌표를 더해 자리를 정한다.
- 일반형은 `중심 + 진폭 * Math.sin(시간 * 빠르기 + 위상)` 이다 — 위치에도, 크기(`scale`)에도, 투명도에도 같은 꼴로 쓴다.
- 시간은 `requestAnimationFrame` 이 주는 밀리초에 0.001 을 곱해 초로 쓴다.
- 여러 점을 물결로 만들려면 점의 번호에 비례한 위상을 준다 — `phase = (i / n) * 2π` 면 n 개 점이 정확히 한 주기를 나눠 맡는다.
- 점 요소는 `position: absolute` 로 두고 `left` · `top` 으로 자리를 옮긴다.
- 점의 중심이 (x, y) 에 오게 하려면 `transform: translate(-50%, -50%)` 를 쓴다 — 자바스크립트로 `transform` 을 다시 쓸 때도 이 부분을 함께 적어야 한다.
- 여러 사인파를 더하면 복잡한 파형을 만들 수 있다 — 예: `a1 * sin(t*f1) + a2 * sin(t*f2 + p2)`.

## 어디서 틀리나

### 1. 밀리초를 그대로 넣는다

`requestAnimationFrame` 의 시각은 밀리초다.
그대로 `Math.sin(time * freq)` 에 넣으면 1초에 각도가 1000배 커져 움직임이 뭉개진다.
`time * 0.001` 로 초로 바꾼다.

### 2. 중심을 더하지 않는다

`amp * Math.sin(...)` 만 `top` 에 쓰면 0 을 중심으로 흔들려 점 절반이 컨테이너 위로 나간다.
`cy` 처럼 중심을 더한다.

### 3. `transform` 을 덮어써서 가운데 정렬을 잃는다

CSS 에서 `.sine-dot` 에 `translate(-50%, -50%)` 를 주었어도, 자바스크립트가 `style.transform` 에 `scale(...)` 만 쓰면 그 값이 CSS 의 `transform` 을 통째로 대신한다.
그러면 점의 왼쪽 위 모서리가 (x, y) 에 놓여 곡선이 반 점만큼 어긋난다.
그래서 원본은 `translate(-50%, -50%) scale(${scale})` 로 둘을 함께 쓴다.

### 4. 「주파수」를 Hz 로 읽는다

`Math.sin(t * freq)` 에서 `freq` 는 1초에 커지는 각도(라디안)다.
1초에 `freq` 번 왕복하는 것이 아니라, 주기가 `2π / freq` 초다.
Hz 로 쓰고 싶으면 `Math.sin(2 * Math.PI * f * t)` 꼴로 쓴다.

### 5. 주파수를 바꾸면 점이 건너뛴다

각도를 매 프레임 `t * freq + phase` 로 새로 계산하므로, `freq` 가 바뀌는 순간 각도가 `t × (바뀐 양)` 만큼 한꺼번에 달라진다.
페이지가 오래 열려 t 가 클수록 건너뜀이 크다.
매끄럽게 하려면 각도를 변수에 쌓아 두고 프레임마다 `각도 += freq * dt` 로 더해 가는 방법이 있다 (원본에 근거 없음 — 추론).

### 6. 화면의 y 는 아래가 + 다

수학 그래프에서는 sin 이 1 일 때 위에 있지만, 화면에서는 `top` 이 클수록 아래다.
그래서 이 예제에서 sin 이 1 인 점은 가장 아래에 있고, 크기(`scale`)도 가장 크다.

### 7. 원본 주석의 범위 두 가지

- 원본 주석은 「크기도 sin으로 변동: 0.7~1.0 사이」라고 한다 → `0.7 + 0.3 * sin` 은 sin 이 -1 일 때 0.4 이므로 실제 범위는 0.4 ~ 1.0 이다. 0.7 ~ 1.0 은 sin 이 0 이상인 절반뿐이다.
- 원본 주석은 hue 를 「180~380」이라 한다 → `i` 는 24 까지이므로 `(24/25)*200 + 180 = 372` 가 가장 크다. 360 을 넘는 hue 를 한 바퀴 돌려 해석한다는 주석의 설명은 CSS 의 각도 처리에 기댄 것이다 (확인 필요).

### 8. CSS `@keyframes` 로도 되지만

이 항목의 팁대로 `@keyframes` 로도 비슷한 왕복을 만들 수 있다.
다만 사인 곡선을 정확히 따르게 하기, 슬라이더 값으로 진폭 · 빠르기를 실시간으로 바꾸기, 여러 사인파 더하기, 25개 점에 위상을 계산해 나누기 같은 일은 자바스크립트가 더 유연하다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `Math.sin` 은 -1 ~ 1 값을 돌려주고 2π 마다 되풀이한다 | 수학적 성질 · ECMAScript 가 `Math.sin` 을 정의한다. 소수 끝자리 정확도는 엔진마다 근사일 수 있다 (확인 필요) |
| `requestAnimationFrame` 콜백이 밀리초 시각을 받는다 | 브라우저 표준(HTML) — 자바스크립트 언어가 아니라 브라우저가 제공한다 |
| 콜백이 1초에 몇 번 불리나 | 브라우저 · 화면 주사율에 달렸다 — 이 문서는 수치를 정하지 않는다 |
| 화면 y 는 아래로 갈수록 커진다 | CSS 좌표계 규칙 |
| hue 가 360 을 넘으면 한 바퀴 돌려 해석한다 | CSS 색 규칙 (확인 필요) |
| 슬라이더 값은 문자열이다 | 브라우저 DOM 규칙 — `input.value` 는 문자열 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 끝없이 되풀이되는 흔들림 · 호흡 · 펄스 | `중심 + 진폭 * Math.sin(t * 빠르기 + 위상)` | 방향을 직접 뒤집는 `if` 분기 |
| 여러 점이 물결처럼 흐르는 모양 | 점 번호에 비례한 `phase` | 점마다 따로 만든 시작 타이머 |
| 진폭 · 빠르기를 사용자가 실시간으로 바꿈 | 자바스크립트 + 매 프레임 값 읽기 | 고정된 CSS `@keyframes` |
| 단순한 고정 왕복 하나 | CSS `@keyframes` 도 충분 | 굳이 매 프레임 스크립트 |
| 복잡한 파형 | 사인파 여러 개의 합 | 사인파 하나에 억지로 맞추기 |

## 핵심 문장

1. **`Math.sin` 에 시간을 흘려 넣으면 -1 ~ 1 을 끝없이 오가는 값이 나오고, 진폭을 곱하고 중심을 더하면 왕복 운동이 된다.**
2. **amplitude 는 크기, frequency 는 빠르기(주기 = 2π / frequency), phase 는 시작 오프셋이다.**
3. **점마다 위상을 0 ~ 2π 로 나눠 주면 각 점은 제자리에서 오르내리기만 해도 물결이 흘러가 보인다.**
4. **같은 사인 값을 위치에도 크기에도 쓸 수 있다 — `0.7 + 0.3 * sin` 은 0.4 ~ 1.0 을 오간다.**
5. **시각은 밀리초라 초로 바꾸고, `transform` 을 스크립트로 쓸 때는 가운데 정렬 `translate` 도 함께 쓴다.**

## 용어 풀이

- **사인 함수** — 각도를 받아 -1 ~ 1 을 돌려주며 2π 마다 되풀이하는 함수.
- **라디안** — 한 바퀴를 2π 로 재는 각도 단위.
- **진폭(amplitude)** — 중심에서 가장 멀리 가는 거리, 곧 흔들림의 크기.
- **주파수(frequency)** — 이 코드에서는 1초에 커지는 각도(라디안), 곧 빠르기.
- **위상(phase)** — 사인 곡선에서 시작 자리를 옮기는 각도 오프셋.
- **주기(period)** — 한 번 왕복하는 데 걸리는 시간, `2π / frequency`.
- **파동 · 진동(oscillation)** — 같은 움직임이 되풀이되는 것.
- **진행파** — 점은 제자리에서 왕복하는데 모양이 한 방향으로 옮겨 가는 파동.
- **호흡 · 펄스** — 크기나 밝기가 커졌다 작아지기를 되풀이하는 효과.
- **`requestAnimationFrame`** — 다음 화면 그리기 직전에 콜백을 부르는 브라우저 함수.
- **`offsetHeight` · `offsetWidth`** — 요소가 화면에서 차지하는 세로 · 가로 크기.
- **`translate(-50%, -50%)`** — 요소를 자기 크기의 절반만큼 왼쪽 위로 옮겨 중심을 기준점에 맞추는 변환.
- **`scale()`** — 요소를 배율만큼 키우거나 줄이는 변환.
- **hue** — `hsl()` 색에서 색상환의 각도.

## 더 들어가면

- 사인과 코사인을 함께 쓰면 원 운동이 된다 — `x = r*cos(θ)`, `y = r*sin(θ)` (확인 필요).
- 주파수를 매끄럽게 바꾸려면 각도를 누적하는 방식(`angle += freq * dt`)이 흔히 쓰인다 — 바뀌는 순간 건너뜀이 없다 (확인 필요).
- 진폭을 시간에 따라 줄여 가면(예: 지수적으로 작아지는 값을 곱하기) 점점 잦아드는 감쇠 진동이 된다 (확인 필요).
- `left` · `top` 을 매 프레임 바꾸는 대신 `transform: translate()` 로 위치를 옮기면 레이아웃 계산을 덜 일으킨다고 알려져 있다 (확인 필요).
- 아무리 복잡한 주기 파형도 사인파의 합으로 나타낼 수 있다는 것이 푸리에 급수의 생각이다 (확인 필요).
