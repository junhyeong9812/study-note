## 한눈에 — 쉽게 말하면

**보간은 「징검다리 사이에 판자 놓기」다.**
돌(측정한 점)은 몇 개뿐이고, 그 사이를 건너려면 판자(곡선)를 놓아야 한다.
판자를 곧게 놓을 수도(선형), 휘어지게 놓을 수도(3차 스플라인) 있다.
돌이 흔들려 높이가 들쭉날쭉하면 돌을 모두 밟지 않고 평평하게 지나가는 판자(평활 스플라인)를 놓는다.
돌이 마당에 흩어져 있으면 판자 대신 천막(2차원 보간)을 덮는다.
`scipy.interpolate` 도 똑같은 구조다.

> **보간(interpolation)** — 알려진 점들 사이의 값을 그 점들로 추정하는 것.\
> 예: (1, 1)과 (2, 4)를 알 때 x=1.5 의 값을 추정한다.

| 비유 | 실체 |
|---|---|
| 돌 | 원본 데이터 점 `(x, y)` |
| 곧은 판자 | `interp1d(kind='linear')` |
| 휘어진 판자 | `interp1d(kind='cubic')` · `CubicSpline` |
| 돌을 다 밟지 않는 평평한 판자 | `UnivariateSpline(s>0)` |
| 흩어진 돌 위 천막 | `griddata` |
| 바둑판 위 천막 | `RegularGridInterpolator` |
| 마지막 돌 너머로 판자 내밀기 | 외삽(`fill_value='extrapolate'`) |

```text
 y
 16 |                    ●        ● 측정한 점
  9 |               ●             ─ 보간 곡선
  4 |          ●
  1 |     ●
  0 ●─────┴────┴────┴────┴── x
    0     1    2    3    4
          ↑ 점 사이(예: 1.5)는 곡선에서 읽는다
```

## 이 주제가 답하려는 질문

1. 점 몇 개만 알 때, 그 사이의 값은 어떻게 구하나?
2. 곡선을 곧게 이을 때와 부드럽게 이을 때 결과는 어떻게 다른가?
3. 데이터 범위 밖이나 노이즈가 있는 데이터는 어떻게 다루나?
4. 점이 2차원에 있을 때(흩어진 점 · 바둑판 격자)는 무엇을 쓰나?

## 동작 방식

### (1) `interp1d` — 1차원 보간 함수 만들기

**언제 쓰나** — 1차원 점이 몇 개 있고, 그 사이 값을 함수처럼 불러 쓰고 싶을 때.

```text
x = [0,1,2,3,4], y = [0,1,4,9,16]
        │
        ▼  interp1d(x, y, kind='linear')
  함수 f 를 돌려준다 (아직 계산 안 함)
        │
        ▼  f(1.5)
  1.5 를 품은 구간 [1, 2] 를 찾는다 → 양 끝 y=1, y=4 를 직선으로 잇는다
        │
        ▼
  (1 + 4) / 2 = 2.5
```

- `interp1d` 는 값을 바로 내지 않고 **호출할 수 있는 함수 객체**를 돌려준다.
- 그 함수에 x 를 넣으면, x 를 품은 구간을 찾는다.
- `kind='linear'` 면 그 구간의 양 끝을 직선으로 이어 값을 읽는다.
- 구간 정중앙이면 양 끝 y 의 평균이 된다.

`kind='cubic'` 이면 직선 대신 3차 곡선 조각을 이어 붙인다.
원본 데이터가 `y = x²` 일 때 원본 주석은 3차 보간 f(1.5) 가 약 2.25, f(2.5) 가 약 6.25 라고 적는다.
참값 1.5² = 2.25, 2.5² = 6.25 와 같다.
선형 보간은 곡선을 현(직선)으로 잘라 지나가므로, 아래로 볼록한 `x²` 에서는 참값보다 크게 나온다(2.5, 6.5).

`kind` 의 값은 다섯 가지다.

| `kind` | 뜻 |
|---|---|
| `'linear'` | 선형 — 기본값 |
| `'nearest'` | 가장 가까운 점의 값 |
| `'zero'` | 0차 — 계단 모양 |
| `'quadratic'` | 2차 |
| `'cubic'` | 3차 |

함수에 배열을 넣으면 여러 점을 한 번에 계산한다.
`np.linspace(0, 4, 20)` 처럼 20개 점을 만들어 넣으면 길이 20 의 배열이 돌아온다.

> **외삽(extrapolation)** — 데이터 범위 바깥의 값을 추정하는 것.\
> 예: x 가 0~4 인 데이터로 x=5 의 값을 구한다.

### (2) 범위 밖 처리 — `bounds_error` 와 `fill_value`

**언제 쓰나** — 데이터 범위(최솟값~최댓값) 밖의 x 를 넣을 수 있을 때.

```text
x 범위 [0, 4] 인 f 에 f(5.0)
        │
        ├─ 기본 설정         → 에러 (범위 밖)
        ├─ bounds_error=False → NaN 을 돌려준다
        └─ fill_value='extrapolate' → 마지막 곡선 조각을 연장해 값을 낸다
```

- 기본 `interp1d` 는 범위 밖 값에서 에러를 낸다.
- `bounds_error=False` 를 주면 에러 대신 `NaN` 을 돌려준다.
- `fill_value='extrapolate'` 를 주면 외삽을 허용한다.
- 원본 주석은 `y = x²` 데이터에 `kind='cubic'` + 외삽으로 f(5.0) 이 약 25.0 이라고 적는다.

### (3) `CubicSpline` — 미분 · 적분 · 근까지

**언제 쓰나** — 점을 부드럽게 잇는 데 더해, 그 곡선의 기울기 · 넓이 · 0이 되는 자리가 필요할 때.

```text
x = [0..5], y = [0, 0.8, 0.9, 0.1, -0.8, -1.0]
        │
        ▼  cs = CubicSpline(x, y, bc_type='natural')
  구간마다 3차식 하나, 이음매에서 값 · 1차 · 2차 미분이 이어진다
        │
        ├─ cs(0.5)          → 보간값
        ├─ cs(1.0, 1)       → x=1 에서 1차 미분 f'
        ├─ cs(1.0, 2)       → x=1 에서 2차 미분 f''
        ├─ cs.integrate(0,5) → ∫₀⁵ f(x)dx
        └─ cs.roots()       → f(x)=0 인 x 들
```

- `CubicSpline` 은 구간마다 3차식을 두고, 이음매에서 매끄럽게 잇는다.
- 호출할 때 두 번째 인자 n 을 주면 n차 미분값을 돌려준다.
- `integrate(a, b)` 는 a~b 구간의 정적분을 돌려준다.
- `roots()` 는 곡선이 0 이 되는 x 들을 배열로 돌려준다.
- 원본 데이터의 y 는 0.9 에서 0.1, -0.8 로 내려가므로, x=2~3 사이에서 곡선이 0 을 지난다.

> **스플라인(spline)** — 구간마다 다항식 조각을 두고 이음매를 매끄럽게 이어 붙인 곡선.\
> 예: 0~1, 1~2, … 구간마다 3차식을 하나씩 둔다.

양 끝에는 조건이 하나 더 필요하다. `bc_type` 으로 정한다.

| `bc_type` | 양 끝 조건 |
|---|---|
| `'natural'` | 양 끝에서 f'' = 0 (자연 스플라인) |
| `'clamped'` | 양 끝에서 f' = 0 |
| `'not-a-knot'` | 기본값 — 원본 설명은 「연속 3차 미분」 |

> **경계 조건(boundary condition)** — 곡선의 양 끝에서 지켜야 할 조건.\
> 예: 자연 스플라인은 양 끝에서 휘는 정도(f'')가 0 이다.

### (4) `UnivariateSpline` — 노이즈를 눌러 펴는 평활 스플라인

**언제 쓰나** — 측정값에 노이즈가 있어, 모든 점을 정확히 지나면 오히려 들쭉날쭉해질 때.

```text
y = sin(x) + 노이즈 (30개 점)
        │
        ▼  UnivariateSpline(x, y, s=1)
  s 만큼의 오차를 허용하며 부드러운 곡선을 고른다
        │
        ├─ get_knots()    → 매듭점 배열 (적을수록 단순한 곡선)
        ├─ get_residual() → 곡선과 점 사이의 잔차
        └─ spline(np.pi)  → 원본 주석: ≈ 0 (sin(π) = 0 근처)

  s=0 으로 바꾸면 → 모든 점을 정확히 통과 → 노이즈까지 따라간다(과적합)
```

- `s` 는 평활 인자(smoothing factor)다. 클수록 곡선이 부드럽다.
- `s=0` 이면 모든 점을 정확히 지난다. 노이즈까지 따라가므로 과적합이다.
- `s=0` 이면 곡선이 꺾여야 할 곳이 많아져 매듭점이 늘어난다.

> **매듭점(knot)** — 스플라인의 다항식 조각이 바뀌는 x 위치.\
> 예: 매듭점이 3개면 곡선은 그 자리들에서 다른 다항식으로 넘어간다.

> **잔차(residual)** — 데이터 값과 곡선 값의 차이를 모은 크기.\
> 예: 곡선이 모든 점을 지나면 잔차는 0 이다.

> **과적합(overfitting)** — 노이즈까지 맞추느라 본래 경향을 놓치는 것.\
> 예: 사인 곡선 데이터에 `s=0` 을 써서 지그재그 곡선이 나온다.

### (5) `griddata` — 흩어진 점에서 격자로

**언제 쓰나** — 2차원 점이 규칙 없이 흩어져 있고(산재 데이터), 그것을 바둑판 격자 값으로 바꾸고 싶을 때.

```text
points: (x, y) 100개 (0~1 사이 무작위)   values: 각 점의 값
        │
        ▼  np.mgrid[0:1:50j, 0:1:50j]  → 50×50 격자 grid_x, grid_y
        │
        ▼  griddata(points, values, (grid_x, grid_y), method=...)
  ┌──────────────────────────────────────────┐
  │ ·  ·    ·   ·  ·   ← 흩어진 점들          │
  │   ┌─────────────┐                        │
  │ · │ 점들이 둘러싼 │ ·  ← 볼록 껍질 밖      │
  │   │ 안쪽 영역    │                        │
  │   └─────────────┘                        │
  └──────────────────────────────────────────┘
  nearest → 어디서나 가장 가까운 점의 값 → NaN 없음
  linear/cubic → 점들이 둘러싼 안쪽만 계산 → 바깥 격자칸은 NaN
```

- `np.mgrid[0:1:50j, 0:1:50j]` 의 `50j` 는 「간격」이 아니라 「점 개수 50개」라는 뜻이다. 그래서 결과는 50×50 격자다.
- `method='nearest'` 는 가장 가까운 점의 값을 쓰므로 모든 격자칸에 값이 있다.
- `method='linear'` 와 `'cubic'` 은 흩어진 점들이 둘러싼 영역 안에서만 값을 낸다.
- 그 바깥 격자칸(네 모서리 근처 등)은 `NaN` 이 된다. 원본 예제는 `np.isnan(...).sum()` 으로 그 개수를 센다.

> **볼록 껍질(convex hull)** — 점들을 모두 감싸는 가장 작은 볼록 다각형.\
> 예: 점들 바깥에 고무줄을 걸고 놓으면 고무줄이 만드는 모양.

### (6) `RegularGridInterpolator` — 바둑판 격자에서 보간

**언제 쓰나** — 값이 이미 바둑판(정규 격자) 위에 있고, 격자 사이 임의의 점에서 값을 읽고 싶을 때.

```text
x = [0,1,2,3,4], y = [0,1,2,3,4]
data[i][j] = i + j   (격자점 (x, y) 의 값 = x + y)
        │
        ▼  RegularGridInterpolator((x, y), data, method='linear')
        │
        ▼  interp([[1.5, 1.5], [2.5, 3.5]])
  각 점을 둘러싼 격자칸 네 꼭짓점의 값으로 선형 보간
        │
        ▼
  점 2개 → 값 2개짜리 배열
```

- 격자 축(`x`, `y`)과 격자 값(`data`)을 넘겨 보간기를 만든다.
- 질의 점은 `[[x1, y1], [x2, y2], …]` 꼴로 여러 개를 한 번에 넣는다.
- 질의 점마다 값 하나가 나오므로 결과는 점 개수만큼의 배열이다.
- 격자 값이 x, y 에 대한 1차식이면 선형 보간은 그 식을 그대로 되살린다. 직선을 직선으로 이으면 같은 직선이기 때문이다.

> **정규 격자(regular grid)** — 축마다 점이 정해진 자리에 늘어선 바둑판 꼴 격자.\
> 예: x 0~4, y 0~4 를 1 간격으로 나눈 5×5 격자.

## 문법 — 형태와 규칙

```python
import numpy as np
from scipy.interpolate import interp1d, CubicSpline, UnivariateSpline

x = np.array([0, 1, 2, 3])
y = np.array([1, 3, 2, 5])

f = interp1d(x, y, kind='linear', bounds_error=False)  # 범위 밖은 NaN
f2 = interp1d(x, y, kind='cubic', fill_value='extrapolate')  # 외삽 허용

cs = CubicSpline(x, y, bc_type='natural')
slope = cs(1.5, 1)          # 1차 미분
area = cs.integrate(0, 3)   # 정적분
zeros = cs.roots()          # 근

sp = UnivariateSpline(x, y, s=0.5)  # 평활 스플라인
```

- `interp1d(x, y, kind=...)` → 함수 객체. 부르면 값(또는 배열)이 나온다.
- `kind` 기본값은 `'linear'`.
- 범위 밖: 기본은 에러 · `bounds_error=False` 는 `NaN` · `fill_value='extrapolate'` 는 외삽.
- `CubicSpline(x, y, bc_type=...)` → `cs(x)` 값, `cs(x, n)` n차 미분, `cs.integrate(a, b)`, `cs.roots()`.
- `UnivariateSpline(x, y, s=...)` → `get_knots()`, `get_residual()`. `s=0` 이면 모든 점 통과.
- `griddata(points, values, (grid_x, grid_y), method='nearest'|'linear'|'cubic')` → 격자 모양 배열.
- `RegularGridInterpolator((x, y), data, method='linear')` → 보간기. `interp([[x, y], …])` 로 부른다.
- 설치는 `pip install scipy numpy`.

## 어디서 틀리나

### 1. 범위 밖 x 를 넣고 에러에 놀란다

`interp1d` 는 기본 설정에서 범위 밖 값에 에러를 낸다.
외삽이 필요하면 `fill_value='extrapolate'`, 값이 없다는 표시만 필요하면 `bounds_error=False`(→ `NaN`)를 준다.
외삽은 마지막 곡선 조각을 연장할 뿐이라, 범위에서 멀어질수록 믿기 어렵다.

### 2. 노이즈 데이터에 정확히 지나는 보간을 쓴다

`interp1d` · `CubicSpline` · `UnivariateSpline(s=0)` 은 모든 점을 지난다.
노이즈가 있으면 그 노이즈까지 곡선이 따라가 과적합이 된다.
노이즈 데이터에는 `UnivariateSpline` 에 `s>0` 을 준다.

### 3. `griddata` 의 `NaN` 을 버그로 여긴다

`linear` · `cubic` 은 점들의 볼록 껍질 밖에서 `NaN` 을 낸다.
격자 전체에 값이 필요하면 `nearest` 를 쓰거나, `NaN` 자리를 따로 채운다.

### 4. `50j` 를 간격으로 읽는다

`np.mgrid[0:1:50j]` 의 허수 단위 `j` 는 「점 50개」라는 뜻이다.
`np.mgrid[0:1:0.02]` 처럼 실수를 주면 그것은 간격이다.

### 5. 원본 주석의 숫자를 실측값으로 믿는다

원본 예제는 계산 코드를 `print("""...""")` 문자열로 **보여 줄 뿐** 실행하지 않는다.
그래서 주석의 `# 2.5` · `# ≈ 2.25` · `# ≈ 25.0` 같은 값은 코드가 계산해 찍은 값이 아니라 주석에 적힌 예상이다.
값을 확인하려면 문자열 안의 코드를 따로 돌려야 한다.

### 6. `'not-a-knot'` 설명을 그대로 외운다

원본 주석은 `'not-a-knot'` 을 「기본값, 연속 3차 미분」이라고 적는다.
원본의 주장 → 이음매 전부에서 3차 미분이 이어진다는 뜻으로 읽힐 수 있다.
왜 의심스러운가 → 모든 이음매에서 3차 미분까지 이어지면 곡선 전체가 3차식 하나가 되어 버린다. 3차 미분이 이어지는 이음매는 일부(양 끝 쪽)로 한정될 가능성이 크다(확인 필요).

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `interp1d` 의 `kind` 기본값이 `'linear'`, 범위 밖에서 기본적으로 에러 | SciPy 라이브러리의 API 정의 — 파이썬 언어와 무관, SciPy 버전에 따라 바뀔 수 있다(확인 필요) |
| `griddata` 의 `linear`·`cubic` 이 볼록 껍질 밖에서 `NaN` | SciPy 의 `griddata` 동작 정의(확인 필요) |
| 원본 주석의 수치(2.25, 6.25, 25.0, f(π)≈0) | 원본 주석의 주장 — 부동소수 계산이라 끝자리는 구현 · 버전에 따라 다를 수 있다 |
| `np.random.seed(42)` 로 같은 난수가 나온다 | NumPy 난수 생성기의 구현 — 버전 사이 재현성 범위는 (확인 필요) |
| 1차식 격자 값을 선형 보간하면 그 식이 그대로 나온다 | 수학(선형 보간의 성질) — 부동소수 오차 범위 안에서 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 1D, 점 몇 개, 정확한 값 | `interp1d(kind='cubic')` 또는 `CubicSpline` | `UnivariateSpline(s>0)` (점을 비켜 간다) |
| 1D, 노이즈 있는 데이터 | `UnivariateSpline(s>0)` | `s=0` · `interp1d` (과적합) |
| 2D, 흩어진 점 | `griddata()` | `RegularGridInterpolator` (격자가 아니다) |
| 2D, 바둑판 격자 | `RegularGridInterpolator()` | `griddata` (격자 구조를 버린다) |
| 미분 · 적분 · 근 필요 | `CubicSpline` (`roots`, `integrate`) | `interp1d` (값만 준다) |
| 범위 밖 값이 들어올 수 있음 | `fill_value='extrapolate'` 또는 `bounds_error=False` | 기본 설정 그대로 |

## 핵심 문장

1. **보간은 아는 점 사이를 곡선으로 이어 값을 읽는 일이다** — 선형은 직선, 3차는 매끄러운 곡선으로 잇는다.
2. **`interp1d` 는 범위 밖에서 에러가 기본이다** — `fill_value='extrapolate'` 는 외삽, `bounds_error=False` 는 `NaN`.
3. **`CubicSpline` 이 가장 다목적이다** — 값 · n차 미분 · 적분 · 근을 모두 준다.
4. **노이즈에는 평활 스플라인이다** — `s` 가 클수록 부드럽고, `s=0` 은 모든 점을 지나 과적합이다.
5. **2D 는 점 배치로 고른다** — 흩어진 점은 `griddata`, 바둑판은 `RegularGridInterpolator`.

## 용어 풀이

- **보간(interpolation)** — 알려진 점들 사이의 값을 추정하는 것.
- **외삽(extrapolation)** — 데이터 범위 바깥의 값을 추정하는 것.
- **선형 보간** — 이웃한 두 점을 직선으로 이어 값을 읽는 것.
- **스플라인(spline)** — 구간마다 다항식 조각을 두고 매끄럽게 이은 곡선.
- **3차 스플라인** — 조각이 3차식인 스플라인.
- **경계 조건(boundary condition)** — 곡선 양 끝에서 지킬 조건(`bc_type`).
- **자연 스플라인** — 양 끝에서 2차 미분이 0 인 3차 스플라인.
- **평활 스플라인** — 모든 점을 지나지 않고 오차를 허용해 부드럽게 만든 스플라인.
- **평활 인자 `s`** — 평활 스플라인이 허용하는 오차의 크기. 클수록 부드럽다.
- **매듭점(knot)** — 스플라인의 다항식 조각이 바뀌는 자리.
- **잔차(residual)** — 데이터 값과 곡선 값의 차이를 모은 크기.
- **과적합(overfitting)** — 노이즈까지 맞추느라 본래 경향을 놓치는 것.
- **근(root)** — 곡선이 0 이 되는 x.
- **산재 데이터(scattered data)** — 규칙 없이 흩어진 점에 놓인 데이터.
- **정규 격자(regular grid)** — 축마다 정해진 자리에 늘어선 바둑판 격자.
- **볼록 껍질(convex hull)** — 점들을 모두 감싸는 가장 작은 볼록 다각형.
- **`NaN`** — 「숫자가 아님」을 나타내는 부동소수 값. 값이 없다는 표시로 쓴다.

## 더 들어가면

- 최근 SciPy 문서는 `interp1d` 를 레거시로 두고, `make_interp_spline` · `CubicSpline` · `np.interp` 같은 대안을 권한다고 알려져 있다(확인 필요).
- `CubicSpline` 의 `bc_type` 에는 `'periodic'`(주기 경계)도 있고, `((1, 값), (1, 값))` 처럼 양 끝 미분값을 직접 줄 수도 있다(확인 필요).
- not-a-knot 조건은 첫 두 조각과 마지막 두 조각을 같은 3차식으로 만드는 조건이라, 점이 4개 이상이면 3차 이하 다항식 데이터를 정확히 되살린다(확인 필요).
- `UnivariateSpline` 의 `s` 를 주지 않으면 점 개수에 맞춘 기본값이 쓰인다(확인 필요).
- 2D 이상 산재 데이터에는 `RBFInterpolator` 같은 방사 기저 함수 보간도 있다(확인 필요).
- `griddata` 의 `linear` 는 점들을 삼각형으로 나누는(들로네 삼각분할) 방식으로 계산한다(확인 필요).
