## 한눈에 — 쉽게 말하면

**SymPy 는 「분수와 루트를 그대로 남겨 두는 칠판 풀이」다.**
계산기에 `√8` 을 넣으면 `2.828…` 처럼 소수로 잘라 낸다.
칠판에서 손으로 풀면 `2√2` 라고 적고, `1/3 + 1/6` 은 `1/2` 로 정리한다.
`x` 는 숫자가 아니라 글자로 남긴 채 전개 · 인수분해 · 미분 · 적분을 한다.
SymPy 도 똑같은 구조다.
수를 근사하지 않고 식을 식 그대로 다루며, 소수가 필요할 때만 마지막에 바꾼다.

| 비유 | 실체 |
|---|---|
| 칠판에 쓴 글자 `x` | `symbols('x')` 로 만든 심볼 |
| `2√2` · `1/2` 처럼 정리된 답 | `sqrt(8)` · `Rational(1,3) + Rational(1,6)` 의 기호 결과 |
| 식 정리 (전개 · 인수분해) | `expand` · `factor` · `simplify` · `collect` |
| 방정식 풀이 · 미분 · 적분 | `solve` · `diff` · `integrate` |
| 마지막에 계산기로 소수 구하기 | `.evalf()` |

```text
  계산기 방식                     SymPy 방식
  sqrt(8)  ──▶ 2.828427…          sqrt(8)  ──▶ 2*sqrt(2)   (정확한 식)
  (오차가 섞인 근사값)                         │
                                               └─ .evalf() ──▶ 소수 근사값
```

> **심볼릭 계산(기호 계산)** — 값을 숫자로 바꾸지 않고 식 자체를 대상으로 변형 · 풀이하는 계산.\
> 예: `(x + y)**3` 을 숫자 없이 `x**3 + 3*x**2*y + …` 로 펼친다.

## 이 주제가 답하려는 질문

1. 숫자가 아닌 「글자」를 변수로 두고 계산하려면 무엇을 먼저 만들어야 하나?
2. 식을 펼치고 · 묶고 · 줄이고 · 방정식을 푸는 함수는 각각 무엇이고 어떤 꼴로 답을 돌려주나?
3. 미분 · 적분 · 극한 · 급수 합 · 행렬 계산을 기호로 하려면 인자를 어떻게 넘기나?
4. 정확한 기호 답과 소수 근사값은 어떻게 오가나?

## 동작 방식

### (1) 심볼 만들기 — `symbols`

**언제 �르나** — 모든 SymPy 계산의 첫 줄이다.
`x` 라는 이름의 파이썬 변수에 「수학 글자 x」를 담아야 식을 쓸 수 있다.

```text
x, y, z = symbols('x y z')                         ──▶ 글자 세 개 (제약 없음)
a, b, c = symbols('a b c', real=True)              ──▶ 실수라고 약속한 글자
n = symbols('n', integer=True, positive=True)      ──▶ 양의 정수라고 약속한 글자
```

- 첫 줄은 공백으로 나눈 이름마다 심볼 하나를 만들어 차례대로 돌려준다.
- 둘째 줄은 「이 글자는 실수다」라는 제약(가정)을 함께 붙인다.
- 셋째 줄은 「정수이고 양수다」라는 제약 둘을 붙인다.
- 원본의 함수 정리는 심볼을 만드는 길로 `symbols()` · `Symbol()` · `var()` 셋을 든다.

> **심볼(Symbol)** — SymPy 식 안에서 값이 정해지지 않은 글자를 나타내는 객체.\
> 예: `x = symbols('x')` 뒤의 `x**2` 는 숫자가 아니라 식이다.

> **가정(assumption)** — 심볼에 붙이는 성질 약속(`real=True` · `integer=True` · `positive=True` 등).\
> 예: `symbols('n', integer=True, positive=True)` 는 양의 정수 `n`.

### (2) 정확한 수 — `sqrt` · `Rational` · `.evalf()`

**언제 쓰나** — 부동소수점 오차 없이 루트 · 분수를 정확히 들고 가야 할 때.

```text
sqrt(8)                           ──▶ 원본 주석: 2*sqrt(2)
Rational(1,3) + Rational(1,6)     ──▶ 원본 주석: 1/2
(정확한 식).evalf()               ──▶ 소수 근사값
```

- `sqrt(8)` 은 소수로 바꾸지 않고 `8 = 4·2` 를 써서 `2*sqrt(2)` 로 정리한다.
- `Rational(1,3)` 은 「1을 3으로 나눈 소수」가 아니라 분수 1/3 그 자체다.
- 두 분수를 더하면 통분해 정확히 1/2 이 된다.
- 팁: 수치 결과가 필요하면 `.evalf()` 로 바꾼다.

> **`Rational`** — 분자 · 분모를 정수로 들고 있는 정확한 유리수.\
> 예: `Rational(1, 3)` 은 1/3.

> **`.evalf()`** — 기호 결과를 소수 근사값으로 바꾸는 메서드.\
> 예: `sqrt(8).evalf()` 는 2.828… 꼴의 근사값.

### (3) 식 변형 — `expand` · `factor` · `simplify` · `collect`

**언제 쓰나** — 같은 식을 보기 좋은 다른 꼴로 바꿀 때.

```text
expand((x + y)**3)                           ──▶ 곱을 풀어 항들의 합으로
factor(x**3 + 3*x**2*y + 3*x*y**2 + y**3)    ──▶ 합을 다시 곱 꼴 (x + y)**3 로
simplify(sin(x)**2 + cos(x)**2)              ──▶ 원본 주석: 1
collect(x**2*y + x*y + x**2 + x, x)          ──▶ x 의 거듭제곱끼리 묶은 꼴
```

- `expand` 는 괄호를 풀어 항을 늘어놓는다.
- `factor` 는 그 반대로 인수분해해 곱으로 묶는다.
- `simplify` 는 항등식 같은 규칙을 써서 더 짧은 꼴을 찾는다(`sin² + cos² = 1`).
- `collect(식, x)` 는 `x` 의 같은 거듭제곱을 가진 항끼리 모은다.

### (4) 방정식 풀기 — `solve` · `Eq`

**언제 쓰나** — 식이 0 이 되는 값, 연립방정식의 해, 부등식의 범위를 구할 때.

```text
solve(x**2 - 5*x + 6, x)             ──▶ 「식 = 0」으로 보고 풂  ──▶ 원본 주석: [2, 3]  (리스트)
solve([2*x + y - 5, x - y - 1], [x, y]) ─▶ 연립                  ──▶ 원본 주석: {x: 2, y: 1} (딕셔너리)
solve(Eq(x**3 - 1, 0), x)            ──▶ Eq 로 등식을 명시       ──▶ 원본 주석: [1, 복소근...]
solve(x**2 - 4 < 0, x)               ──▶ 부등식                  ──▶ 원본 주석: -2 < x < 2 (범위 조건)
```

- 등호 없이 식만 주면 SymPy 는 그 식이 0 과 같다고 보고 푼다.
- 등식을 드러내고 싶으면 `Eq(좌변, 우변)` 객체를 넘긴다.
- 연립방정식은 식 리스트와 미지수 리스트를 넘기고, 원본 주석은 「심볼 → 값」 딕셔너리로 답한다고 적는다.
- `x**3 = 1` 은 실근 1 말고 복소수 근도 함께 나온다.
- 부등식은 해가 낱개 값이 아니라 범위 조건으로 나온다.
- 원본의 함수 정리는 풀이 함수로 `solve()` · `solveset()` · `dsolve()`(미분방정식) 셋을 든다.

> **`Eq`** — 「좌변 = 우변」 등식을 나타내는 SymPy 객체(파이썬의 `=` 은 대입이라 등식으로 쓸 수 없다).\
> 예: `Eq(x**3 - 1, 0)`.

### (5) 미분 — `diff`

**언제 쓰나** — 도함수 · 고차 도함수 · 편도함수를 기호로 구할 때.

```text
diff(x**3, x)          ──▶ 3*x**2 꼴      (한 번)
diff(x**4, x, 2)       ──▶ 12*x**2 꼴     (x 로 두 번)
diff(sin(x), x, 3)     ──▶ -cos(x)        (x 로 세 번)
f = x**2*y + x*y**3
diff(f, x)             ──▶ 2xy + y³        (y 는 상수 취급)
diff(f, y)             ──▶ x² + 3xy²       (x 는 상수 취급)
diff(f, x, y)          ──▶ 2y              (x 로, 이어서 y 로)
```

- `diff(식, 변수)` 는 한 번 미분한다.
- 변수 뒤에 정수 `n` 을 주면 그 변수로 `n` 번 미분한다.
- 변수를 여럿 늘어놓으면 앞에서부터 차례로 그 변수로 미분한다(편미분).
- 한 변수로 미분할 때 나머지 심볼은 상수로 다룬다.
- 기본 미분 예(원본 주석): `sin → cos` · `exp(x) → exp(x)` · `log(x) → 1/x`.

### (6) 적분 — `integrate`

**언제 쓰나** — 부정적분 · 정적분 · 무한 구간 적분 · 다중적분.

```text
integrate(x**2, x)                    ──▶ x**3/3          (부정적분, 적분상수 없이)
integrate(x**2, (x, 0, 1))            ──▶ 1/3             (정적분)
integrate(sin(x), (x, 0, pi))         ──▶ 2
integrate(exp(-x), (x, 0, oo))        ──▶ 1               (oo = 무한대)
integrate(x*y, (x, 0, 1), (y, 0, 2))  ──▶ 1               (x 먼저, 그다음 y)
```

- 변수만 주면 부정적분이고, 원본 주석의 결과에는 적분상수 `+C` 가 붙어 있지 않다.
- `(변수, 아래끝, 위끝)` 튜플을 주면 정적분이다.
- 끝에 `oo`(무한대)를 두면 이상적분이다.
- 튜플을 여럿 주면 앞의 것부터 차례로 적분한다.
- `pi` 는 소수 3.14… 가 아니라 기호 π 다.

> **`oo`** — SymPy 의 무한대 기호(알파벳 o 두 개).\
> 예: `(x, 0, oo)` 는 0 부터 ∞ 까지.

### (7) 그 밖의 도구 — `limit` · `summation` · `Matrix` · `latex` · `pprint`

**언제 쓰나** — 극한, 급수의 합, 행렬 연산, 식을 문서용으로 내보낼 때.

```text
limit(sin(x)/x, x, 0)            ──▶ 1
limit((1+1/n)**n, n, oo)         ──▶ E (자연상수)
summation(1/n**2, (n, 1, oo))    ──▶ π²/6
summation(n, (n, 1, 10))         ──▶ 55
Matrix([[1, 2], [3, 4]]).det()   ──▶ -2       .inv() 역행렬 · .eigenvals() 고유값
latex(x**2 / (x + 1))            ──▶ LaTeX 문자열
```

- `limit(식, 변수, 다가갈 값)` 은 극한을 기호로 구한다.
- `summation(식, (변수, 시작, 끝))` 은 적분과 같은 튜플 꼴로 합의 범위를 준다.
- `Matrix` 는 행렬을 정확한 수로 다루어 행렬식 · 역행렬 · 고유값을 기호로 낸다.
- `latex()` 는 식을 LaTeX 문자열로, `pprint()` 는 터미널에 보기 좋게 찍는다.

### (8) 이 항목의 예제 프로그램이 실제로 하는 일

**언제 쓰나** — 원본 예제와 실습 정답을 읽을 때 꼭 알아야 한다.

```text
print("=== 미분 (diff) ===")      ──▶ 제목 한 줄
print("""                        ──▶ 세 따옴표 문자열 = 코드 모양의 글자
x = symbols('x')
print(f"d/dx(x³): {diff(x**3, x)}")   # 3x²
""")                             ──▶ 그 글자가 화면에 그대로 찍힘
print()                          ──▶ 빈 줄
```

- 예제는 SymPy 코드를 **실행하지 않는다**.
- 코드 조각을 세 따옴표 문자열(`"""…"""`)에 담아 `print` 로 찍을 뿐이다.
- 바깥 문자열에는 `f` 접두사가 없으므로 안쪽의 `f"…{diff(x**3, x)}…"` 도 그냥 글자다 — 중괄호 속 식은 계산되지 않는다.
- 문자열이 줄바꿈으로 시작하므로 제목 바로 아래에 빈 줄이 하나 생긴다.
- 문자열이 줄바꿈으로 끝나고 이어서 `print()` 가 빈 줄을 하나 더 찍으므로 섹션 사이에 빈 줄이 둘 생긴다.
- 그래서 이 문서의 「→ 값」들은 실행해서 본 값이 아니라 **원본 주석이 적은 값**이다.
- SymPy 를 깔지 않아도 이 예제는 그대로 돈다(문자열만 찍으므로).

## 문법 — 형태와 규칙

```python
from sympy import symbols, sqrt, Rational, Eq, solve, diff, integrate, oo, pi, sin

x, y = symbols('x y')                 # 1. 심볼 먼저

print(sqrt(8))                        # 정확한 루트
print(Rational(1, 3) + Rational(1, 6))  # 정확한 분수
print(sqrt(8).evalf())                # 소수가 필요할 때만

print(solve(Eq(x**2, 4), x))          # 등식은 Eq
print(diff(x**2 * y, x, y))           # x 로, 이어서 y 로
print(integrate(sin(x), (x, 0, pi)))  # (변수, 아래, 위)
print(integrate(x**2, (x, 0, oo)) if False else integrate(x**2, x))  # 부정적분
```

- 심볼은 `symbols('이름 이름 …')` 로 먼저 만든다 — 만들지 않은 이름을 식에 쓰면 파이썬이 그 이름을 모른다.
- 거듭제곱은 파이썬 문법 그대로 `**` 다(`^` 가 아니다).
- 등식은 `=` 나 `==` 이 아니라 `Eq(좌, 우)` 로 쓰거나, 「식 = 0」 꼴로 바꿔 식만 넘긴다.
- 구간은 `(변수, 시작, 끝)` 튜플 — `integrate` · `summation` 이 같은 꼴을 쓴다.
- 극한은 튜플이 아니라 `limit(식, 변수, 값)` 처럼 인자를 늘어놓는다.
- 미분 횟수는 `diff(식, 변수, 횟수)`, 편미분은 `diff(식, 변수1, 변수2)`.
- 함수(`sin` · `cos` · `exp` · `log`)도 SymPy 의 것을 import 해서 써야 기호로 다뤄진다.
- `from sympy import *` 보다 쓸 이름만 골라 import 한다(팁).

## 어디서 틀리나

### 1. 원본 예제는 계산하지 않는다

예제는 SymPy 호출을 문자열 안에 넣어 찍기만 한다.
돌리면 계산 결과가 아니라 코드 글자가 나온다.
안쪽의 `f"…{…}"` 도 바깥이 일반 문자열이라 중괄호가 그대로 찍힌다.
주석의 `# 2*sqrt(2)` · `# [2, 3]` 같은 값은 원본 저자의 주장이지 이 프로그램이 낸 값이 아니다.

### 2. 첫 블록은 그대로 꺼내 돌리면 이름이 모자란다

첫 섹션 문자열의 import 줄은 `symbols, sqrt, Rational, pi, oo, I` 와 `expand, factor, simplify, collect` 뿐이다.
그런데 아래에서 `sin(x)` · `cos(x)` 를 쓴다.
문자열에서 꺼내 그대로 실행하면 `sin` 이라는 이름이 없어 멈춘다(`NameError` — 원본에 근거 없음, 코드를 읽어 추론).
문자열 안에 있는 동안에는 실행되지 않으므로 드러나지 않는 실수다.
반대로 쓰지 않는 이름을 import 한 곳도 있다(`from sympy import S`, 미분 블록의 `cos` · `ln`).

### 3. `collect` 주석의 「x² 기준 정리」

원본 주석 → `collect(x**2*y + x*y + x**2 + x, x)  # x² 기준 정리`.
왜 의심스러운가 → `collect(식, x)` 는 「x² 기준」이 아니라 `x` 의 거듭제곱마다(`x²` 항끼리, `x` 항끼리) 묶는다.
손으로 묶으면 `x²(y + 1) + x(y + 1)` 꼴이 되어야 한다(정확한 찍힘 꼴은 확인 필요).

### 4. 부등식 해의 꼴

원본 주석은 `x² < 4` 의 답을 `-2 < x < 2` 로 적는다.
이것은 수학적 의미를 적은 것이고, SymPy 가 이 글자 그대로 찍는다는 뜻은 아니다(확인 필요).
부등식 답은 리스트가 아니라 범위 조건이라는 점이 핵심이다.

### 5. 부동소수점이 끼어들면 정확성이 깨진다

`Rational(1, 3)` 대신 파이썬 나눗셈 `1/3` 을 넣으면 이미 소수 근사값이 들어간 뒤다.
정확한 답을 원하면 처음부터 `Rational` · `sqrt` 같은 SymPy 객체로 수를 만든다.
소수는 마지막에 `.evalf()` 로만 만든다.

### 6. `from sympy import *` 를 피한다 (팁)

SymPy 는 `sin` · `log` · `pi` · `E` 처럼 흔한 이름을 많이 내놓는다.
`*` 로 다 끌어오면 `math.sin` 같은 다른 모듈의 같은 이름이나 내가 만든 변수를 덮어쓰거나 덮어쓰일 수 있다(원본에 근거 없음 — 추론).
필요한 것만 import 하면 어떤 이름이 어디서 왔는지 한눈에 보인다.

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `sqrt(8)` 이 `2*sqrt(2)` 로 정리되는 것 · 결과가 찍히는 글자 꼴 | SymPy 라이브러리의 동작 — 버전마다 찍히는 꼴이 다를 수 있다(확인 필요). 파이썬 언어는 관여하지 않는다 |
| `solve` 가 리스트 · 딕셔너리 · 범위 조건 꼴로 답하는 것 | SymPy 라이브러리의 설계(원본 주석 기준, 확인 필요) |
| 부정적분 결과에 `+C` 가 없는 것 | SymPy 라이브러리의 관례(원본 주석 기준) |
| 일반 문자열 안의 `{…}` 가 계산되지 않는 것 | 파이썬 언어 — `f` 접두사가 붙은 문자열만 중괄호를 계산한다 |
| `print()` 가 줄 끝에 줄바꿈을 붙이는 것 | 파이썬 언어(내장 `print` 의 기본 `end='\n'`) |
| 파이썬 `float` 이 근사값이라 오차가 생기는 것 | `float` 이 2진 부동소수점이라는 것은 파이썬 문서가 밝히는 바이고, 정밀도는 플랫폼의 C `double` 에 따른다 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 공식 유도 · 손계산 검산 · 정확한 분수 답 | `symbols` + `simplify` · `solve` · `diff` · `integrate` | 소수 근사 계산 |
| 도함수를 식으로 얻어 다른 곳에 쓰기 | `diff` | 수치 미분(차분) |
| 방정식의 정확한 근 · 복소근까지 | `solve(Eq(...), x)` | 반복 근사법 |
| 최종 값을 소수로 보고 싶을 때 | `.evalf()` | 처음부터 `float` 를 섞기 |
| 보고서 · 논문에 식 싣기 | `latex()` · `pprint()` | 식을 손으로 옮겨 적기 |
| 큰 배열의 대량 수치 계산 | 수치 계산 도구(원본에 근거 없음 — 추론) | SymPy 기호 계산 |

## 핵심 문장

1. **SymPy 는 수치가 아니라 기호를 계산한다** — 식을 식으로 남기므로 부동소수점 오차가 없다.
2. **모든 계산은 `symbols` 로 글자를 만드는 데서 시작한다** — 가정(`real` · `integer` · `positive`)을 붙일 수 있다.
3. **변형은 `expand` · `factor` · `simplify` · `collect`, 풀이는 `solve`, 미적분은 `diff` · `integrate` · `limit` · `summation`** 이다.
4. **구간은 `(변수, 시작, 끝)` 튜플, 무한대는 `oo`, 소수는 마지막에 `.evalf()`.**
5. **이 항목의 예제는 코드를 문자열로 찍을 뿐이다** — 주석의 값은 계산 결과가 아니라 원본의 주장이다.

## 용어 풀이

- **심볼릭 계산** — 숫자로 바꾸지 않고 식 자체를 변형 · 풀이하는 계산.
- **심볼(Symbol)** — 값이 정해지지 않은 수학 글자를 나타내는 SymPy 객체.
- **가정(assumption)** — 심볼에 붙이는 성질(실수 · 정수 · 양수 등).
- **`Rational`** — 정수 분자 · 분모로 나타내는 정확한 유리수.
- **`.evalf()`** — 기호 결과를 소수 근사값으로 바꾸는 메서드.
- **`expand`** — 곱을 풀어 합으로 펼친다.
- **`factor`** — 합을 곱으로 인수분해한다.
- **`simplify`** — 더 간단한 동치식을 찾는다.
- **`collect`** — 지정한 변수의 같은 거듭제곱 항끼리 묶는다.
- **`solve`** — 방정식 · 연립방정식 · 부등식을 푼다.
- **`Eq`** — 등식 객체.
- **`diff`** — 미분(고차 · 편미분 포함).
- **편미분** — 여러 변수 함수에서 한 변수로만 미분하고 나머지는 상수로 보는 것.
- **`integrate`** — 적분(부정 · 정 · 이상 · 다중).
- **이상적분** — 구간 끝이 무한대인 적분.
- **`oo`** — SymPy 의 무한대.
- **`limit`** — 극한.
- **`summation`** — 급수의 합.
- **`Matrix`** — 정확한 수로 다루는 행렬(`det` · `inv` · `eigenvals`).
- **`latex`** — 식을 LaTeX 문자열로 바꾼다.
- **`pprint`** — 식을 터미널에 보기 좋게 찍는다.
- **f-string** — `f` 접두사가 붙어 `{…}` 안의 식을 계산해 넣는 파이썬 문자열.
