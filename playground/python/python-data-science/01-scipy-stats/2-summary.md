## 한눈에 — 쉽게 말하면

**`scipy.stats` 는 「통계 도구 상자와 판정표」다.**
도구 상자 칸에는 모양이 정해진 확률 분포(정규 · t · 이항 · 포아송 · 카이제곱)가 들어 있다.
분포를 꺼내면 「이 값이 나올 확률은?」「아래쪽 95% 경계는 어디?」를 바로 물어볼 수 있다.
판정표 쪽에는 검정 함수가 있다.
데이터를 넣으면 「이 차이가 우연으로 나올 만한가」를 숫자 하나(p값)로 돌려준다.
`scipy.stats` 도 똑같은 구조다.
분포 객체로 확률을 계산하고, 검정 함수로 데이터를 판정한다.

| 비유 | 실체 |
|---|---|
| 도구 상자의 칸 하나 | 분포 객체 (`stats.norm(...)`, `stats.binom(...)`) |
| 칸에 붙은 손잡이 | 메서드 (`.pdf` · `.pmf` · `.cdf` · `.ppf` · `.rvs`) |
| 판정표 | 검정 함수 (`ttest_ind` · `chi2_contingency` · `pearsonr` …) |
| 판정 점수 | p값 |
| 합격선 | 유의수준 (보통 0.05) |

```text
 [분포 객체]                       [검정 함수]
 stats.norm(0,1)                   데이터 ──▶ ttest_ind(a, b)
   ├─ .pdf(x)  밀도                            │
   ├─ .cdf(x)  누적확률                         ▼
   ├─ .ppf(p)  누적확률→값             (통계량, p값)
   └─ .rvs(n)  난수                            │
                                       p < 0.05 ? ──▶ 귀무가설 기각
                                                 └──▶ 기각하지 못함
```

## 이 주제가 답하려는 질문

1. 정해진 분포에서 어떤 값의 확률 · 누적확률 · 경계값을 어떻게 구하나?
2. 두 집단(또는 전후, 또는 기준값)의 평균 차이가 우연인지 어떻게 판정하나?
3. 범주형 자료(찬반 × 성별 같은 표)가 서로 관련이 있는지, 기대한 비율에 맞는지 어떻게 판정하나?
4. 두 변수가 함께 움직이는 정도를 어떻게 재고, 어떤 상관계수를 골라야 하나?

## 동작 방식

### (1) 분포 객체 — 모양을 정해 두고 질문하기

**언제 쓰나** — 「표준정규분포에서 1.96 아래일 확률」처럼 분포가 정해진 상태에서 확률이나 경계값을 구할 때 쓴다.
검정의 임계값(합격선)을 구할 때도 쓴다.

```text
stats.norm(loc=0, scale=1)      ← 평균 0, 표준편차 1 로 고정한 분포 객체
        │
        ├─ .pdf(0)      → x=0 에서의 확률밀도
        ├─ .cdf(1.96)   → P(X ≤ 1.96)  ≈ 0.975
        ├─ .ppf(0.975)  → 누적확률이 0.975 가 되는 x ≈ 1.96
        └─ .rvs(size=5) → 이 분포에서 뽑은 난수 5개
```

1. `stats.norm(loc=0, scale=1)` 은 모수(평균 · 표준편차)를 정해 둔 분포 객체를 만든다.
2. `.pdf(x)` 는 연속분포에서 x 위치의 밀도(곡선 높이)를 준다.
3. `.cdf(x)` 는 x 이하가 나올 누적확률을 준다.
4. `.ppf(p)` 는 `.cdf` 를 거꾸로 돌린다 — 누적확률 p 를 넣으면 그 확률이 되는 x 를 준다.
5. `.rvs(size=n)` 은 그 분포에서 n 개를 무작위로 뽑는다.

> **동결 분포(frozen distribution)** — 모수를 미리 넣어 고정한 분포 객체.\
> 예: `stats.t(df=10)` 은 자유도 10 으로 굳힌 t분포다.

원본이 다루는 분포는 다섯 가지다.

| 분포 | 만드는 법 | 종류 | 원본에서 묻는 것 |
|---|---|---|---|
| 정규분포 | `stats.norm(loc=0, scale=1)` | 연속 | `pdf(0)`, `cdf(1.96)`, `ppf(0.975)`, `rvs(size=5)` |
| t분포 | `stats.t(df=10)` | 연속 | `ppf(0.975)` — 양측 95% 임계값 |
| 이항분포 | `stats.binom(n=10, p=0.5)` | 이산 | `pmf(5)` = P(X=5), `cdf(5)` = P(X≤5) |
| 포아송분포 | `stats.poisson(mu=3)` | 이산 | `pmf(2)` = P(X=2) |
| 카이제곱분포 | `stats.chi2(df=5)` | 연속 | `ppf(0.95)` — 위쪽 5% 임계값 |

이산분포(이항 · 포아송)는 한 점의 확률이 바로 의미가 있으므로 `.pmf` 를 쓴다.
연속분포(정규 · t · 카이제곱)는 한 점의 확률이 0 이라 높이만 의미가 있으므로 `.pdf` 를 쓴다.
`.cdf` 는 둘 다에 있다.
이항분포 `binom(n=10, p=0.5)` 의 `pmf(5)` 는 손으로도 구할 수 있다 — 10번 중 5번을 고르는 경우의 수 252 를 전체 경우의 수 2¹⁰ = 1024 로 나눈 값이다.
`cdf(5)` 는 0~5 의 `pmf` 를 모두 더한 것이라 언제나 `pmf(5)` 이상이다.

> **확률질량함수(PMF)** — 이산분포에서 특정 값이 나올 확률.\
> 예: 동전 10번에서 앞면이 정확히 5번 나올 확률.

> **확률밀도함수(PDF)** — 연속분포에서 그 위치의 곡선 높이. 구간 넓이가 확률이다.\
> 예: 표준정규분포 곡선은 x=0 에서 가장 높다.

> **누적분포함수(CDF)** — x 이하가 나올 확률.\
> 예: `norm.cdf(1.96)` ≈ 0.975.

> **역CDF(PPF)** — 누적확률을 넣으면 그 확률에 해당하는 x 를 주는 함수.\
> 예: `norm.ppf(0.975)` ≈ 1.96.

`ppf(0.975)` 가 「95% 임계값」인 까닭은 양쪽 꼬리에 2.5% 씩 남기면 가운데가 95% 이기 때문이다.
카이제곱은 오른쪽 꼬리 하나만 보므로 `ppf(0.95)` 를 쓴다.

### (2) t-검정 — 평균 차이가 우연인가

**언제 쓰나** — 평균을 비교할 때 쓴다.
무엇과 무엇을 비교하느냐에 따라 함수가 셋으로 갈린다.

```text
group_a (30명) ─┐
                ├─▶ ttest_ind(a, b)        서로 다른 두 집단
group_b (30명) ─┘

before[i] ─▶ after[i] ─▶ ttest_rel(before, after)   같은 대상의 전후 (짝)

group_a ─▶ ttest_1samp(group_a, popmean=100)        한 집단 대 기준값
                    │
                    ▼
            (t-통계량, p값)
```

1. `ttest_ind` 는 서로 독립인 두 집단의 평균이 같다는 귀무가설을 검정한다.
2. `ttest_rel` 은 같은 대상을 두 번 잰 짝 데이터에서 「차이의 평균이 0」이라는 귀무가설을 검정한다.
3. `ttest_1samp` 은 한 집단의 평균이 주어진 값(`popmean`)과 같다는 귀무가설을 검정한다.
4. 셋 다 `(t-통계량, p값)` 을 돌려주고, p값을 0.05 와 비교해 판정한다.

원본에서 `before = [85, 90, 78, 92, 88]`, `after = [90, 95, 82, 96, 91]` 은 같은 다섯 사람의 전후 점수다.
i 번째 `before` 와 i 번째 `after` 가 같은 사람이라 짝이 있다.
짝을 무시하고 `ttest_ind` 를 쓰면 사람마다 다른 실력 차(개인차)가 잡음으로 섞여 들어간다.
`ttest_rel` 은 사람마다 「후 − 전」을 먼저 빼서 개인차를 지우고 그 차이만 본다.

원본 예제의 `group_a` · `group_b` 는 `np.random.normal(loc=100, scale=15, size=30)` 처럼 평균 100 과 110 인 정규분포에서 30개씩 뽑은 가짜 데이터다.
`np.random.seed(42)` 로 씨앗을 고정해 다시 돌려도 같은 난수가 나오게 했다.

> **귀무가설** — 「차이가 없다 · 관련이 없다」처럼 기본으로 두는 가설.\
> 예: 「A 반과 B 반의 평균은 같다」.

> **t-통계량** — 평균 차이를 그 흔들림(표준오차)으로 나눈 값. 클수록 차이가 뚜렷하다.\
> 예: 부호가 음수면 첫 집단 평균이 더 작다.

### (3) 카이제곱 검정 — 범주가 기대대로 나뉘었나

**언제 쓰나** — 숫자 크기가 아니라 「몇 명이 어느 칸에 들어갔나」(빈도)를 다룰 때 쓴다.

```text
관측 교차표                  행합                기대빈도 = 행합 × 열합 / 총합
        찬성  반대
남성     50    30            80          ──▶   남성: 80×85/160, 80×75/160
여성     35    45            80                여성: 80×85/160, 80×75/160
열합     85    75          총합 160
                   │
                   ▼
chi2_contingency(observed) → (카이제곱 통계량, p값, 자유도, 기대빈도)
```

1. `chi2_contingency(observed)` 는 교차표를 받아 「두 범주 변수(성별 · 찬반)가 독립이다」라는 귀무가설을 검정한다.
2. 독립이라면 각 칸에 들어갈 기대빈도는 「행합 × 열합 ÷ 총합」이다.
3. 관측빈도가 기대빈도에서 멀수록 카이제곱 통계량이 커지고 p값이 작아진다.
4. 자유도는 「(행 수 − 1) × (열 수 − 1)」이다.
5. 반환값 네 개를 `chi2, p_value, dof, expected` 로 받는다.

`chisquare(observed_freq, expected_freq)` 는 적합도 검정이다.
표가 아니라 한 줄의 빈도(요일별 방문자 `[18, 22, 20, 25, 15]`)가 기대한 분포(균등 `[20, 20, 20, 20, 20]`)에 맞는지 본다.
반환값은 `(통계량, p값)` 두 개다.

> **기대빈도** — 귀무가설이 참일 때 각 칸에 들어갈 것으로 계산한 빈도.\
> 예: 성별과 찬반이 독립이면 남성 찬성 칸의 기대빈도는 80×85/160.

> **자유도** — 통계량을 계산할 때 자유롭게 변할 수 있는 칸의 수. 분포 모양을 정한다.\
> 예: 2×2 교차표의 자유도는 (2−1)×(2−1).

### (4) 상관 분석과 정규성 검정 — 함께 움직이는가

**언제 쓰나** — 두 연속 변수가 같이 오르내리는 정도를 숫자 하나로 잴 때 쓴다.

```text
x ~ 정규(0,1) 100개
y = 2x + 작은 잡음          ← 거의 직선 위
        │
        ├─▶ pearsonr(x, y)   → (r, p)     값 자체로 직선 관계를 잰다
        ├─▶ spearmanr(x, y)  → (rho, p)   순위로 바꿔서 잰다
        ├─▶ kendalltau(x, y) → (tau, p)   두 점 쌍의 순서가 일치하는 정도
        └─▶ shapiro(x)       → (stat, p)  x 가 정규분포에서 왔는가
```

1. `pearsonr` 은 두 변수의 선형(직선) 관계 강도를 −1~1 로 준다.
2. `spearmanr` 은 값을 순위로 바꾼 뒤 피어슨과 같은 계산을 한다 — 한쪽이 커질 때 다른 쪽도 (직선이 아니어도) 커지기만 하면 잡는다.
3. `kendalltau` 는 점 두 개를 골랐을 때 x 의 순서와 y 의 순서가 같은 쌍과 다른 쌍의 비율로 일치도를 잰다.
4. 셋 다 `(계수, p값)` 을 돌려주며, 여기의 p값은 「상관이 0 이다」라는 귀무가설에 대한 것이다.
5. `shapiro(x)` 는 「x 는 정규분포에서 왔다」를 귀무가설로 둔다 — 그래서 p > 0.05 일 때 원본은 「정규분포 따름」으로 판정한다.

원본의 `y = 2 * x + np.random.normal(0, 0.5, 100)` 은 직선 위에 작은 잡음을 얹은 데이터라 강한 양의 상관을 만든다.

> **단조 관계** — 한 변수가 커질 때 다른 변수가 (빠르든 느리든) 늘 커지거나 늘 작아지는 관계.\
> 예: y = x³ 은 직선은 아니지만 단조 증가다.

> **정규성 검정** — 데이터가 정규분포를 따르는지 보는 검정.\
> 예: `shapiro()`, `normaltest()`, `kstest()`.

### (5) p값으로 판정하는 흐름 — 모든 검정의 공통 틀

**언제 쓰나** — 위의 모든 검정 결과를 읽을 때 쓴다.

```text
귀무가설 세우기 → 통계량 계산 → p값 = 「귀무가설이 참일 때 이만큼 또는 더 극단적인 결과가 나올 확률」
                                         │
                       p < 0.05 ─────────┼──▶ 우연이라 보기 어렵다 → 귀무가설 기각
                       p ≥ 0.05 ─────────┴──▶ 증거가 부족하다 → 기각하지 못함
```

1. p값은 귀무가설이 참이라고 가정했을 때 지금 같은 결과(또는 더 극단적인 결과)가 나올 확률이다.
2. 이 확률이 아주 작으면 「귀무가설이 참이라면 거의 안 일어날 일이 일어났다」는 뜻이라 귀무가설을 버린다.
3. 기준선(유의수준)은 관례상 0.05 이다.
4. 같은 판정을 임계값으로도 할 수 있다 — 통계량이 분포 객체의 `ppf` 로 구한 임계값을 넘으면 p값이 유의수준보다 작다는 뜻이다.
5. 그래서 (1) 의 `stats.chi2(df=...).ppf(0.95)` 나 `stats.t(df=...).ppf(0.975)` 는 (2) · (3) 검정의 합격선 역할을 한다.

> **p값** — 귀무가설이 참일 때 관측 결과만큼(또는 더) 극단적인 결과가 나올 확률.\
> 예: p = 0.01 이면 귀무가설 아래에서 100번 중 1번꼴로 나올 결과다.

> **유의수준** — 귀무가설을 기각할 p값의 기준선. 미리 정한다.\
> 예: 0.05.

## 문법 — 형태와 규칙

```python
from scipy import stats
import numpy as np

d = stats.norm(loc=50, scale=10)       # 분포 객체 (평균 50, 표준편차 10)
print(d.cdf(60), d.ppf(0.5))           # 누적확률, 역CDF

a = np.array([3.1, 2.9, 3.4, 3.0])
b = np.array([3.6, 3.8, 3.5, 3.9])
t, p = stats.ttest_ind(a, b)           # 두 독립 집단

table = np.array([[10, 20], [30, 40]])
chi2, p, dof, expected = stats.chi2_contingency(table)

r, p = stats.pearsonr(a, b)            # 상관계수와 p값
```

- 분포는 `stats.이름(모수=값)` 으로 만들고 메서드로 묻는다.
- 분포 메서드: `.pdf()` · `.pmf()` · `.cdf()` · `.ppf()` · `.rvs()` · `.mean()` · `.var()`.
- 정규는 `loc`(평균) · `scale`(표준편차), t · 카이제곱은 `df`(자유도), 이항은 `n` · `p`, 포아송은 `mu`(λ) 로 모수를 준다.
- 검정 함수는 결과를 튜플처럼 풀어 받는다 — 대부분 `(통계량, p값)`, `chi2_contingency` 만 `(통계량, p값, 자유도, 기대빈도)` 넷이다.

| 목적 | 함수 |
|---|---|
| 분포 생성 | `stats.norm()`, `stats.t()`, `stats.binom()`, `stats.poisson()`, `stats.chi2()` |
| 평균 비교 | `ttest_ind()`(독립 두 집단), `ttest_rel()`(대응 · 전후), `ttest_1samp()`(한 집단 대 기준값) |
| 범주 빈도 | `chi2_contingency()`(교차표 독립성), `chisquare()`(적합도) |
| 상관 | `pearsonr()`(선형), `spearmanr()`(순위), `kendalltau()`(순서 일치) |
| 정규성 | `shapiro()`, `normaltest()`, `kstest()` |

## 어디서 틀리나

### 1. 원본 예제는 통계를 계산하지 않고 코드를 글자로 찍는다

원본 예제는 각 절의 코드를 `print("""...""")` 의 세 따옴표 문자열 안에 넣었다.
그래서 실행하면 `scipy` 가 불리지 않고, 코드 글자가 화면에 그대로 나온다.
숫자 결과를 보려면 문자열 안의 코드를 꺼내 따로 실행해야 한다.
또 하나 — 문자열 안에 적은 `\n` 은 평범한(raw 가 아닌) 문자열에서 진짜 줄바꿈 문자로 바뀐다.
그래서 `print(f"기대빈도:\n{expected}")` 라는 줄은 화면에 두 줄로 쪼개져 찍힌다.

### 2. p < 0.05 면 귀무가설을 기각한다 — 그 반대는 「채택」이 아니다

원본 팁대로 p값이 유의수준(보통 0.05)보다 작으면 귀무가설을 기각한다.
원본 예제는 반대쪽을 「귀무가설 채택」이라고 찍는다.
원본의 주장 → 왜 의심스러운가: p ≥ 0.05 는 「차이를 보일 증거가 부족하다」일 뿐 「차이가 없음이 확인됐다」가 아니다.
표본이 작으면 실제 차이가 있어도 p값이 클 수 있다.
그래서 「귀무가설을 기각하지 못함」이 정확한 표현이다.
카이제곱 절의 「독립 (관련 없음)」도 같은 이유로 「관련이 있다고 말할 증거가 부족함」으로 읽어야 한다.

### 3. `shapiro()` 의 p > 0.05 도 「정규분포를 따른다」의 증명이 아니다

원본 팁은 t-검정 전에 `shapiro()` 로 정규성을 확인하라고 권한다.
`shapiro` 의 귀무가설은 「정규분포다」라서, p > 0.05 면 원본은 「따름」이라 찍는다.
이것도 2번과 같다 — 정규성을 부정할 증거를 못 찾았다는 뜻이다.
t-검정은 데이터가 정규분포에 가깝다고 가정하므로 이 확인이 의미가 있다.

### 4. 피어슨은 직선만 본다 — 스피어만은 「단조」까지

원본 팁: 피어슨은 선형 관계만 측정하므로 비선형 관계에는 스피어만을 쓴다.
피어슨은 y = x³ 처럼 굽었지만 꾸준히 오르는 관계를 직선 기준으로 재서 약하게 볼 수 있다.
스피어만은 순위를 쓰므로 단조 관계면 완전한 관계로 잡는다.
원본의 주장 → 왜 의심스러운가: 원본 주석은 스피어만이 「비선형에도 유효」하다고 하지만, 순위가 함께 오르내리는 단조 관계일 때만 그렇다.
y = x² 를 x 가 음수에서 양수까지 걸쳐 그리면(U자) 순위도 오르다 내리므로 스피어만도 관계를 거의 못 잡는다.

### 5. 짝이 있는 데이터에 `ttest_ind` 를 쓰지 않는다

같은 사람의 전후는 `ttest_rel` 이다.
`ttest_ind` 를 쓰면 짝 정보(같은 사람)를 버려서 개인차가 잡음으로 남는다.
반대로 짝이 없는 두 집단에 `ttest_rel` 을 쓰면 아무 의미 없는 짝을 만들어 낸 셈이 된다.

### 6. 이산분포에는 `pmf`, 연속분포에는 `pdf`

이항 · 포아송은 `.pmf`, 정규 · t · 카이제곱은 `.pdf` 다.
연속분포의 `.pdf` 값은 확률이 아니라 밀도라서 1 보다 클 수도 있다.

### 7. `ppf(0.975)` 와 `ppf(0.95)` 를 헷갈리지 않는다

t분포의 양측 95% 임계값은 양쪽 꼬리 2.5% 씩이라 `ppf(0.975)` 다.
카이제곱 검정은 오른쪽 꼬리만 보므로 95% 임계값이 `ppf(0.95)` 다.

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 서로 다른 두 반의 평균 비교 | `ttest_ind` | `ttest_rel` |
| 같은 사람의 전후 점수 비교 | `ttest_rel` | `ttest_ind` |
| 한 집단 평균이 기준값(100)과 다른지 | `ttest_1samp(popmean=100)` | `ttest_ind` 에 기준값을 억지로 넣기 |
| 성별 × 찬반 같은 교차표 | `chi2_contingency` | t-검정 (평균이 아니라 빈도다) |
| 요일별 빈도가 균등한지 | `chisquare` | `chi2_contingency` |
| 직선에 가까운 관계 | `pearsonr` | — |
| 굽었지만 꾸준히 오르는 관계 | `spearmanr` · `kendalltau` | `pearsonr` 만 믿기 |
| 정해진 분포의 확률 · 임계값 | 분포 객체의 `.cdf` · `.ppf` | 표를 손으로 찾아 옮기기 |

## 핵심 문장

1. **분포 객체는 모수를 굳혀 두고 `.pdf/.pmf` · `.cdf` · `.ppf` · `.rvs` 로 묻는다** — `ppf` 는 `cdf` 의 역이다.
2. **검정은 「귀무가설 → 통계량 → p값」 틀이고, p < 유의수준이면 귀무가설을 기각한다** — 크다고 귀무가설이 참이 되지는 않는다.
3. **평균은 t-검정(독립 · 대응 · 단일), 범주 빈도는 카이제곱(독립성 · 적합도)** 으로 판정한다.
4. **피어슨은 직선, 스피어만은 순위(단조), 켄달은 순서 일치** 를 잰다.
5. **원본 예제는 코드를 문자열로 찍을 뿐이라** 숫자 결과는 코드를 꺼내 실행해야 나온다.

## 용어 풀이

- **동결 분포** — 모수를 미리 넣어 고정한 SciPy 분포 객체.
- **PDF(확률밀도함수)** — 연속분포에서 위치별 곡선 높이.
- **PMF(확률질량함수)** — 이산분포에서 특정 값이 나올 확률.
- **CDF(누적분포함수)** — x 이하가 나올 확률.
- **PPF(역CDF)** — 누적확률에 해당하는 x 를 돌려주는 함수.
- **자유도** — 분포 모양을 정하는, 자유롭게 변할 수 있는 값의 수.
- **임계값** — 검정 통계량이 이것을 넘으면 귀무가설을 기각하는 경계.
- **귀무가설** — 「차이 · 관련이 없다」는 기본 가설.
- **p값** — 귀무가설 아래에서 관측 결과 이상으로 극단적인 결과가 나올 확률.
- **유의수준** — 기각 기준으로 미리 정한 p값의 선(보통 0.05).
- **독립 표본** — 서로 다른 대상으로 이루어진 두 집단.
- **대응 표본** — 같은 대상을 두 번 잰 짝 데이터.
- **교차표** — 두 범주 변수의 조합별 빈도를 담은 표.
- **기대빈도** — 귀무가설이 참일 때 각 칸에 예상되는 빈도.
- **적합도 검정** — 관측 빈도가 기대 분포에 맞는지 보는 검정.
- **단조 관계** — 한쪽이 커지면 다른 쪽이 늘 같은 방향으로 움직이는 관계.
- **정규성 검정** — 데이터가 정규분포를 따르는지 보는 검정.

## 더 들어가면

- `chi2_contingency` 는 2×2 표(자유도 1)에서 기본으로 Yates 연속성 보정을 적용한다고 알려져 있다 — `correction=False` 로 끌 수 있다 (확인 필요).
- `ttest_ind` 는 기본으로 두 집단의 분산이 같다고 가정하고, `equal_var=False` 를 주면 Welch t-검정이 된다 (확인 필요).
- 표준정규분포의 `pdf(0)` 은 1/√(2π) ≈ 0.3989 이다.
- 자유도 10 인 t분포의 `ppf(0.975)` 는 약 2.228, 자유도 5 인 카이제곱의 `ppf(0.95)` 는 약 11.07 로 통계표에 실려 있다 (확인 필요).
- 포아송 `mu=3` 의 `pmf(2)` 는 e⁻³·3²/2! 로 약 0.224 다 (확인 필요).
- 분포 객체의 `.rvs()` 는 `random_state` 를 주지 않으면 NumPy 의 전역 난수 상태를 쓴다고 알려져 있다 (확인 필요).
- 검정을 여러 번 하면 우연히 p < 0.05 가 나올 확률이 커지므로 다중 비교 보정(본페로니 등)을 쓴다 (확인 필요).
- 정규성이 의심되면 t-검정 대신 `mannwhitneyu` · `wilcoxon` 같은 비모수 검정을 쓸 수 있다 (확인 필요).
