## 한눈에 — 쉽게 말하면

**시계열은 「아이스크림 가게의 월별 매출 장부」다.**
가게가 자리를 잡으면서 매출은 해마다 조금씩 는다.
여름에는 오르고 겨울에는 내리는 일이 해마다 되풀이된다.
그 위에 비 온 주말이나 단체 손님 같은 우연이 얹힌다.
이 항목의 합성 데이터도 똑같은 구조다.
상승 트렌드, 12개월 주기 계절성, 노이즈를 더해서 만든다.

> **시계열** — 시간 순서대로 늘어선 관측값의 열이다.\
> 예: 120개월 동안 매달 하나씩 적은 매출.

| 비유 | 실체 |
|---|---|
| 해마다 조금씩 느는 매출 | 트렌드 `100 + 0.5 * t` |
| 여름에 오르고 겨울에 내리는 매출 | 계절성 `20 * sin(2π t / 12)` |
| 비 온 주말 · 단체 손님 | 노이즈 `random.gauss(0, 5)` |
| 장부를 보고 내년 매출 짐작하기 | ARIMA · SARIMA 의 `forecast()` |

```text
 원본 Y        =   트렌드 T    +   계절성 S       +   잔차 R
   /\  /\/             ___/         /\  /\  /\          . ' , .
  /  \/              _/               \/  \/           ' . ' ,
 들쭉날쭉           큰 흐름         12달마다 반복       남은 우연
```

## 이 주제가 답하려는 질문

1. 들쭉날쭉한 시계열에서 큰 흐름을 어떻게 꺼내나? — 이동 평균
2. 큰 흐름 · 주기 · 우연을 어떻게 나눠 보나? — 가법 분해
3. 주기가 있는지 숫자로 어떻게 확인하나? — 자기상관
4. 미래를 예측하는 모델은 어떤 순서로 세우나? — ARIMA 워크플로우

## 동작 방식

### (1) 합성 시계열 만들기

**언제 쓰나** — 정답(트렌드 · 주기 · 노이즈 크기)을 이미 아는 데이터로 분석 기법을 시험할 때 쓴다.

```text
t = 0, 1, ..., 119   (월, 10년치)
  trend    = 100 + 0.5 * t          → 100 에서 159.5 까지 곧게 오른다
  seasonal = 20 * sin(2π t / 12)    → 12달마다 같은 모양, -20 ~ +20
  noise    = random.gauss(0, 5)     → 평균 0, 표준편차 5
  data[t]  = round(trend + seasonal + noise, 2)
```

- `random.seed(42)` 로 시드를 고정해 같은 실행 환경이면 같은 데이터가 나오게 한다.
- 트렌드는 달마다 0.5 씩 오른다.
- 계절성은 `t / 12` 가 1 늘 때마다 사인파가 한 바퀴 돈다 — 즉 12달이 한 주기다.
- 노이즈는 종 모양 분포에서 뽑은 우연이다.
- 세 값을 **더해서** 만들었으므로 이 데이터는 가법 모형을 따른다.

> **트렌드** — 시계열의 장기적인 오르내림 방향이다.\
> 예: 매달 0.5 씩 오르는 기본 매출.

> **계절성** — 정해진 주기로 되풀이되는 패턴이다.\
> 예: 해마다 여름에 오르고 겨울에 내리는 매출.

### (2) 단순 이동 평균 (`moving_average`)

**언제 쓰나** — 노이즈를 눌러 큰 흐름(트렌드)을 보고 싶을 때 쓴다.

```text
data :  d0  d1  d2  d3  d4  ...
창 3 : [d0  d1  d2]               → ma[0] = (d0+d1+d2)/3
           [d1  d2  d3]           → ma[1]
               [d2  d3  d4]       → ma[2]
결과 길이 = len(data) - window + 1   (120개 → MA(3) 118개, MA(12) 109개)
```

- 창을 한 칸씩 밀며 창 안 값의 평균을 낸다.
- `ma[i]` 는 원본 `i` 번째**부터** `window` 개의 평균이다 — 결과의 자리가 창의 왼쪽 끝에 붙는다.
- 창이 클수록 더 많은 값을 섞으므로 선이 부드러워진다.
- 대신 결과는 `window - 1` 개만큼 짧아지고, 갑작스러운 변화에 늦게 반응한다.
- 창을 주기와 같은 12 로 잡으면 한 창에 열두 달이 한 번씩 들어가 계절성이 서로 상쇄된다.

> **이동 평균** — 일정한 크기의 창을 밀며 창 안 값의 평균을 구한 열이다.\
> 예: 3개월치씩 묶어 평균한 MA(3).

### (3) 지수 이동 평균 (`exponential_moving_average`)

**언제 쓰나** — 최근 값에 더 무게를 두고 흐름을 따라가고 싶을 때 쓴다.

```text
ema[0] = d0
ema[1] = α·d1 + (1-α)·ema[0]
ema[2] = α·d2 + (1-α)·ema[1]
 ...
α = 0.3 → 새 값 30% + 지금까지의 평균 70%
```

- 첫 값은 원본 첫 값을 그대로 쓴다.
- 다음 값부터는 「새 관측값 × α + 직전 EMA × (1 − α)」 점화식으로 구한다.
- 오래된 값은 단계마다 (1 − α) 가 곱해져 무게가 점점 줄어든다.
- α 가 크면 새 값의 몫이 커져 원본 변화에 더 민감하게 따라붙는다.
- 결과 길이는 원본과 같다 — 창이 없으므로 앞쪽이 잘리지 않는다.

> **α (평활 계수)** — EMA 에서 새 관측값에 주는 몫(0~1)이다.\
> 예: α=0.3 이면 새 값 30%, 과거 70%.

### (4) 가법 분해 (`decompose_additive`)

**언제 쓰나** — 원본을 트렌드 · 계절성 · 잔차로 나눠 각각 보고 싶을 때 쓴다.

```text
Y = Trend + Seasonal + Residual        (period = 12, half = 6)

1. trend[i]        = mean(data[i-6 : i+6])     i = 6 .. 113   (나머지는 None)
2. detrended[i]    = data[i] - trend[i]        trend 가 None 이면 None
3. seasonal_avg[m] = mean(detrended[m], detrended[m+12], detrended[m+24], ...)   m = 0..11
   seasonal[i]     = round(seasonal_avg[i % 12], 2)       ← 120칸 모두 채워진다
4. residual[i]     = round(data[i] - trend[i] - seasonal[i], 2)   trend 가 None 이면 None
```

- 1단계: 슬라이스 `data[i-6:i+6]` 는 끝을 빼므로 인덱스 `i-6` ~ `i+5` 의 정확히 12개다.
  그 12개의 평균을 트렌드로 삼는다.
  `range(6, 114)` 만 돌므로 앞쪽 6칸(0~5)과 뒤쪽 6칸(114~119)은 `None` 으로 남는다.
- 2단계: 원본에서 트렌드를 빼면 계절성 + 잔차만 남는다.
- 3단계: 같은 달끼리(1월은 1월끼리) 모아 평균하면 우연은 서로 상쇄되고 해마다 되풀이되는 몫만 남는다.
  그 12개 평균을 `i % 12` 로 120칸에 되풀이해 깐다.
  모은 값이 하나도 없으면 0 을 넣어 0 으로 나누기를 막는다.
- 4단계: 원본에서 트렌드와 계절성을 둘 다 빼고 남은 것이 잔차다.
- 표를 찍을 때 `if trend[i]` · `if residual[i]` 로 값이 있나 보고, 없으면 `N/A` 를 찍는다.
- 결과 계절성은 생성할 때 넣은 `20 * sin(2π t / 12)` 를 데이터만 보고 되찾은 추정치다.

> **가법 분해** — 원본을 「트렌드 + 계절성 + 잔차」의 합으로 나누는 방법이다.\
> 예: 104.66 = 102.75 + 0.28 + 1.63 꼴.

> **잔차** — 모형이 설명하고 남은 나머지다.\
> 예: 원본 − 트렌드 − 계절성.

### (5) 자기상관 (`autocorrelation`)

**언제 쓰나** — 시계열이 `lag` 칸 전의 자기 자신과 얼마나 닮았는지, 즉 주기가 있는지 숫자로 확인할 때 쓴다.

```text
mean = 전체 평균,   var = Σ(x - mean)² / n
cov(lag) = Σ (d[i] - mean)(d[i+lag] - mean) / n      i = 0 .. n-lag-1
acf(lag) = round(cov / var, 4)        1 에 가까울수록 lag 칸 떨어진 값끼리 닮았다
막대     = '█' × int(|acf| × 30),  부호 = '+' (acf ≥ 0) 또는 '-'
```

- 분산이 0 이면(모든 값이 같으면) 나눗셈 대신 0 을 돌려준다.
- 공분산은 `n - lag` 개 쌍만 더하지만 `n` 으로 나눈다.
- 주기가 12 인 데이터는 `lag=12` 에서 같은 계절끼리 짝지어져 상관이 커진다.
- `lag=6` 은 반 주기라 여름과 겨울이 짝지어진다 — 계절성끼리는 반대로 움직인다.
- 트렌드가 있으면 가까운 시점끼리 값이 비슷하므로 모든 lag 에 양의 상관이 얹힌다.
- 그래서 `lag=6` 은 계절성의 음의 상관과 트렌드의 양의 상관이 맞서 작아진다.

> **lag (시차)** — 비교하는 두 시점 사이의 칸 수다.\
> 예: lag=12 는 올해 3월과 작년 3월을 짝짓는다.

> **ACF (자기상관 함수)** — lag 마다 자기상관 값을 늘어놓은 것이다.\
> 예: lag 1, 2, 3, 6, 12, 24 의 값과 막대.

### (6) ARIMA 개념과 워크플로우

**언제 쓰나** — 과거 값으로 미래 값을 예측하는 모델을 세울 때 쓴다.

```text
1. 시각화      트렌드 · 계절성 · 이상치 확인
2. 정상성 검정  adfuller(data) → p < 0.05 면 정상
3. 차분        비정상이면 d=1 차분 적용
4. ACF/PACF    p, q 결정
5. 피팅        ARIMA(data, order=(1,1,1)).fit()
               계절성 있으면 SARIMAX(order=(1,1,1), seasonal_order=(1,1,1,12)).fit(disp=False)
               차수를 자동으로: auto_arima(data, seasonal=True, m=12, suppress_warnings=True)
6. 진단        잔차가 정규분포인가, 잔차에 자기상관이 없나
7. 예측        fitted.forecast(steps=12)  → 12개월 앞
```

- ARIMA(p, d, q) 의 세 글자는 다음과 같다.
  - **p** — AR(자기회귀) 차수: 과거 p 개 시점의 값에 의존한다.
  - **d** — I(차분) 횟수: 비정상 시계열을 정상 시계열로 바꾸는 차분을 몇 번 하나.
  - **q** — MA(이동평균) 차수: 과거 q 개 오차에 의존한다.
- SARIMA 는 여기에 계절 부분 `(P, D, Q, s)` 를 더한다 — `s` 는 계절 주기(월별이면 12)다.
- `auto_arima` 는 `pmdarima` 패키지의 함수로, 차수를 자동으로 골라 `order` · `seasonal_order` 로 알려 준다.
- **이 예제에서 ARIMA 절은 세 겹 따옴표 문자열을 `print` 한 것이다.**
  안의 `import statsmodels ...` 줄은 파이썬 코드로 실행되지 않고 글자로만 찍힌다.

> **정상성** — 평균 · 분산 같은 통계적 성질이 시간에 따라 변하지 않는 성질이다.\
> 예: 오르기만 하는 트렌드가 있으면 평균이 변하므로 비정상이다.

> **차분** — 이웃한 두 값의 차 `y[t] − y[t−1]` 로 바꾸는 것이다.\
> 예: 매달 0.5 씩 오르는 트렌드는 한 번 차분하면 거의 일정한 0.5 가 된다.

## 문법 — 형태와 규칙

```python
xs = [10, 12, 11, 15, 14]
w = 3
ma = [sum(xs[i:i+w]) / w for i in range(len(xs) - w + 1)]   # 창 3 → 3개

alpha = 0.5
ema = [xs[0]]                       # 첫 값은 그대로
for x in xs[1:]:
    ema.append(alpha * x + (1 - alpha) * ema[-1])

period = 2
same_slot = [xs[i] for i in range(1, len(xs), period)]   # 인덱스 1, 3 → 같은 「달」끼리
```

손으로 따지면 `ma` 는 `[11.0, 12.67, 13.33]` 쯤, `ema` 는 `[10, 11.0, 11.0, 13.0, 13.5]` 다(손 계산).

- `a[i:j]` 는 `i` 부터 `j-1` 까지 정확히 `j - i` 개를 꺼낸다 — 창 크기를 맞추는 핵심이다.
- `range(len(data) - window + 1)` 이 단순 이동 평균의 창 시작점 전부다.
- `range(m, n, period)` 는 `m, m+period, m+2·period, …` 로 같은 계절의 자리만 고른다.
- `i % period` 로 짧은 패턴(12개)을 긴 열(120개)에 되풀이해 깐다.
- 계산할 수 없는 자리는 `[None] * n` 으로 먼저 채워 두고, 값이 있는지 확인한 뒤 쓴다.
- `round(x, 2)` 로 소수 둘째 자리까지 반올림하고, 출력은 `f"{x:>8.2f}"` 처럼 폭 · 정렬 · 자릿수를 정한다.
- `print("""...""")` 는 여러 줄 문자열을 그대로 찍는다 — 안의 글이 코드처럼 보여도 실행되지 않는다.

## 어디서 틀리나

### 1. 이동 평균을 쓰되 짧아지고 밀리는 것을 잊는다

이동 평균은 트렌드 추출과 노이즈 제거의 기본이다.
그러나 단순 이동 평균은 결과가 `window - 1` 개 짧고, `ma[i]` 가 창의 왼쪽 끝 자리에 붙는다.
원본과 같은 인덱스로 나란히 그리면 흐름이 앞으로 당겨져 보인다.

### 2. 정상성을 확인하지 않고 ARIMA 를 맞춘다

ARIMA 를 적용하기 전에 반드시 정상성을 확인해야 한다.
ADF 검정에서 p < 0.05 면 정상으로 보고, 아니면 차분(d)을 한다.
이 항목의 데이터처럼 오르는 트렌드가 있으면 평균이 시간에 따라 변하므로 비정상이다.

### 3. 계절성이 있는데 ARIMA 만 쓴다

계절성이 있으면 SARIMA 를 쓴다.
`SARIMAX(..., seasonal_order=(P, D, Q, s))` 의 `s` 에 주기(월별이면 12)를 넣는다.
ACF 가 `lag=12` 에서 높게 튀는 것이 그 주기의 단서다.

### 4. 차수를 손으로만 고른다

`auto_arima`(pmdarima)로 최적 파라미터를 자동 선택할 수 있다.
`seasonal=True, m=12` 로 계절 주기를 알려 주면 계절 차수까지 고른다.
고른 결과는 `best_model.order` 와 `best_model.seasonal_order` 로 본다.

### 5. `0.0` 을 「값 없음」으로 찍는다

표를 찍는 줄은 `f"{trend[i]:.2f}" if trend[i] else "N/A"` 다.
`None` 만이 아니라 `0.0` 도 거짓이다.
잔차가 반올림해서 정확히 `0.0` 이 되면 값이 있는데도 `N/A` 로 찍힌다.
`if residual[i] is not None` 처럼 `None` 만 따로 걸러야 한다.

### 6. 짝수 창의 「가운데」가 반 칸 앞쪽이다

`data[i-6:i+6]` 는 인덱스 `i-6` ~ `i+5` 라 그 가운데는 `i` 가 아니라 `i - 0.5` 다.
그래서 `trend[i]` 는 `i` 보다 반 칸 앞 시점의 트렌드다.
결과적으로 `trend[6]` 은 `data[0:12]` 의 평균, 즉 `MA(12)` 의 첫 값과 같은 수다.
매달 0.5 씩 오르는 데이터에서는 트렌드가 약 0.25 낮게 잡힌다(원본에 근거 없음 — 추론).

### 7. 계절성 12개를 더해도 0 이 아니다

출력된 계절성 패턴 12개 값을 더하면 2.92 로 0 이 아니다.
이 코드는 같은 달끼리의 평균을 그대로 쓰고, 합이 0 이 되도록 다시 맞추는 단계가 없다.
6번의 반 칸 치우침이 달마다 약 0.25 씩 계절성에 얹혀 12달이면 약 3 이 된다(원본에 근거 없음 — 추론).

### 8. ARIMA 절이 실행되는 줄로 안다

ARIMA 절은 문자열을 찍을 뿐이라 `statsmodels` · `pmdarima` 가 없어도 오류 없이 지나간다.
그 코드를 떼어 내 실제로 돌리려면 두 패키지를 설치하고 `data` 를 미리 만들어 둬야 한다.
또 `from collections import deque` 는 import 만 하고 쓰지 않는다.

### 9. 자기상관 분모가 lag 마다 같다는 것을 놓친다

공분산은 `n - lag` 쌍만 더하지만 `n` 으로 나눈다.
lag 가 클수록 더하는 항이 줄어 값이 0 쪽으로 기운다.
`lag=24` 가 `lag=12` 보다 작게 나오는 데에는 이 몫도 있다(원본에 근거 없음 — 추론).

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 노이즈 속 큰 흐름만 보고 싶다 | 단순 이동 평균(창을 주기와 맞춤) | 원본을 그대로 보고 흐름을 눈대중하기 |
| 최근 변화에 빨리 반응하는 평균이 필요하다 | 지수 이동 평균(α 조절) | 창이 큰 단순 이동 평균 |
| 트렌드 · 계절성 · 우연을 따로 보고 싶다 | 가법 분해 | 이동 평균 하나만 |
| 주기가 몇인지 확인하고 싶다 | ACF 에서 튀는 lag 찾기 | 눈으로 그래프 봉우리 세기만 |
| 트렌드가 있는 데이터를 예측한다 | ADF 검정 → 차분(d) → ARIMA | 정상성 확인 없이 바로 ARIMA |
| 12개월 주기가 뚜렷하다 | SARIMA(`s=12`) 또는 `auto_arima(seasonal=True, m=12)` | 계절 부분이 없는 ARIMA |

## 핵심 문장

1. **시계열은 트렌드 + 계절성 + 잔차의 합으로 볼 수 있다** — 가법 분해는 이 셋을 차례로 떼어 낸다.
2. **이동 평균은 창 크기가 부드러움과 반응 속도를 맞바꾼다** — 단순 MA 는 짧아지고, EMA 는 α 로 민감도를 정한다.
3. **자기상관이 특정 lag 에서 튀면 그 lag 가 주기다** — 월별 데이터의 `lag=12` 처럼.
4. **ARIMA 앞에는 정상성 검정이 먼저다** — 비정상이면 차분하고, 계절성이 있으면 SARIMA 로 간다.
5. **손으로 짠 분해에는 함정이 있다** — 짝수 창의 반 칸 치우침, `0.0` 을 `N/A` 로 보는 진리값 검사.

## 용어 풀이

- **시계열** — 시간 순서대로 늘어선 관측값의 열.
- **트렌드** — 장기적인 오르내림 방향.
- **계절성** — 정해진 주기로 되풀이되는 패턴.
- **노이즈** — 규칙 없이 끼어드는 우연한 흔들림.
- **잔차** — 원본에서 트렌드와 계절성을 빼고 남은 것.
- **이동 평균(MA)** — 창을 밀며 창 안 값을 평균한 열.
- **창(window)** — 이동 평균에서 한 번에 평균하는 값의 개수.
- **지수 이동 평균(EMA)** — 새 값에 α, 직전 평균에 1 − α 의 무게를 주는 평균.
- **α** — EMA 의 평활 계수, 클수록 최근 값에 민감하다.
- **가법 분해** — 원본을 트렌드 + 계절성 + 잔차의 합으로 나누는 방법.
- **자기상관 / ACF** — 시계열이 lag 칸 떨어진 자기 자신과 닮은 정도 / 그것을 lag 마다 늘어놓은 것.
- **lag** — 비교하는 두 시점 사이의 칸 수.
- **PACF** — 워크플로우에서 ACF 와 함께 p, q 를 정하는 데 쓰는 그래프.
- **정상성** — 평균 · 분산 같은 성질이 시간에 따라 변하지 않는 성질.
- **차분** — 이웃한 두 값의 차로 바꾸는 것.
- **ADF 검정** — 정상성을 검정하는 방법, p < 0.05 면 정상으로 본다.
- **ARIMA(p, d, q)** — 자기회귀(p) · 차분(d) · 이동평균 오차(q)로 미래를 예측하는 모델.
- **SARIMA** — ARIMA 에 계절 부분 `(P, D, Q, s)` 를 더한 모델.
- **auto_arima** — `pmdarima` 의 함수로, ARIMA · SARIMA 차수를 자동으로 고른다.

## 더 들어가면

- ADF 검정의 귀무가설은 「단위근이 있다(비정상이다)」이다 — 그래서 p 가 작으면 귀무가설을 기각하고 정상으로 본다(확인 필요).
- 주기가 짝수일 때 고전적 분해는 12개 창 평균을 한 번 더 2개 창으로 평균하는 「2×12 중심 이동 평균」으로 반 칸 치우침을 없앤다(확인 필요).
- 고전적 분해는 계절성 추정치의 합이 0 이 되도록 평균을 빼서 맞춘다(확인 필요).
- `statsmodels` 에는 `seasonal_decompose` 가 있고, 계절성의 진폭이 트렌드에 비례하면 곱셈 모형(`model="multiplicative"`)을 쓴다(확인 필요).
- `pandas` 로는 `Series.rolling(window).mean()` 이 단순 이동 평균, `Series.ewm(alpha=…).mean()` 이 지수 이동 평균이다(확인 필요).
- PACF 는 중간 lag 들의 영향을 걸러 낸 자기상관이다. 흔히 PACF 가 끊기는 자리로 p 를, ACF 가 끊기는 자리로 q 를 어림한다(확인 필요).
