## 한눈에 — 쉽게 말하면

**`caret-color` 는 「형광펜 뚜껑 색」이 아니라 「펜 끝 색」을 고르는 일이다.**
글자를 쓸 자리를 가리키는 깜빡이는 세로 막대가 펜 끝이다.
쓴 글자의 색(`color`)과 펜 끝의 색(`caret-color`)은 따로 정할 수 있다.
따로 정하지 않으면 펜 끝은 대개 글자 색을 따라간다.
입력칸의 캐럿도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 펜 끝 | 캐럿(텍스트 입력 커서) |
| 펜 끝 색 | `caret-color` 값 |
| 쓴 글자의 색 | `color` 값 |
| 펜 끝 색을 안 고르면 글자 색을 따름 | `auto` → `currentcolor` 또는 브라우저 기본값 |
| 투명 펜 끝 | `transparent` → 캐럿이 안 보임 |

```text
 ┌──────────────────────────────┐
 │ 안녕하세요|                    │   ← | 가 캐럿
 └──────────────────────────────┘
   글자 색 = color      | 의 색 = caret-color
```

## 이 주제가 답하려는 질문

1. 입력칸에서 깜빡이는 캐럿의 색만 따로 바꾸려면 무엇을 쓰나?
2. 값을 주지 않았을 때(`auto`) 캐럿 색은 어디서 오나?
3. 부모에 준 값이 안쪽 입력칸까지 내려가나?
4. 캐럿을 아예 숨길 수 있나, 숨기면 무엇이 문제인가?

## 동작 방식

### (1) 캐럿 색만 따로 정하기

**언제 쓰나** — 입력칸의 글자 색은 그대로 두고 캐럿만 브랜드 색 등으로 눈에 띄게 하고 싶을 때 쓴다.

```text
입력 코드                         무엇이 일어나나                    결과
.red-caret {                     요소가 포커스를 받아               글자는 color 대로,
  caret-color: #ef4444;    →     캐럿이 그려질 때                →  캐럿만 빨강으로
}                                caret-color 값을 칠한다             깜빡인다
```

- 요소에 `caret-color` 를 선언한다.
- 사용자가 그 입력칸을 클릭해 포커스가 가면 캐럿이 나타난다.
- 브라우저는 캐럿을 그릴 때 `caret-color` 의 색을 쓴다.
- 글자 색(`color`)은 이 속성과 상관없이 그대로다.

캐럿은 글자를 입력할 수 있는 곳에만 생긴다.
`<input type="text">` · `<textarea>` · `contenteditable` 요소가 그런 곳이다.
글자를 입력할 수 없는 평범한 `<div>` 에는 캐럿이 없으니, 값을 줘도 눈에 보이는 변화가 없다.

> **캐럿** — 텍스트를 입력할 위치를 가리키는, 깜빡이는 세로 막대다.\
> 예: 메모장을 클릭하면 글자 사이에서 깜빡이는 `|`.

> **contenteditable** — 일반 요소를 사용자가 직접 편집할 수 있게 만드는 HTML 속성이다.\
> 예: `<div contenteditable>여기를 고칠 수 있다</div>`.

### (2) `auto` — 값을 주지 않았을 때

**언제 쓰나** — 특별히 정하지 않으면 늘 이 값이다(기본값이 `auto`).

```text
입력 코드                         무엇이 일어나나                    결과
input {                          caret-color 를 지정하지 않음        캐럿이 글자 색(파랑)을
  color: blue;             →     = auto                        →   따르거나,
}                                → currentcolor 또는 브라우저 기본값   브라우저 기본 캐럿 색
```

- 기본값 `auto` 는 「`currentcolor` 또는 브라우저 기본값」이다.
- `currentcolor` 는 그 요소의 `color` 값을 가리키므로, 많은 경우 캐럿이 글자 색과 같아진다.
- 다만 어느 쪽을 고를지는 브라우저가 정하므로 「반드시 글자 색」이라고 말할 수는 없다.

> **currentcolor** — 그 요소의 현재 `color` 값을 가리키는 CSS 키워드다.\
> 예: `border: 1px solid currentcolor;` 는 테두리를 글자 색으로 칠한다.

### (3) 상속 — 부모에 한 번 주기

**언제 쓰나** — 폼 전체의 입력칸 캐럿 색을 한 번에 맞추고 싶을 때 쓴다.

```text
입력 코드                         무엇이 일어나나                    결과
form { caret-color: green; }     caret-color 는 상속되는 속성이라   form 안의 input,
<form>                     →     안쪽 요소가 자기 값을 갖지 않으면  →  textarea 캐럿이
  <input> <textarea>             부모 값을 물려받는다                  모두 초록
</form>
```

- `caret-color` 는 상속되는 속성이다.
- 안쪽 입력칸에 따로 값이 없으면 부모의 값을 물려받는다.
- 안쪽 입력칸에 자기 값을 주면 그 값이 이긴다.

> **상속** — 부모 요소에 준 속성 값이 자식 요소로 내려가 적용되는 것이다.\
> 예: `body { color: navy; }` 를 주면 안쪽 문단 글자도 남색이 된다.

### (4) `transparent` — 캐럿 숨기기, 그리고 색 바꾸기 애니메이션

**언제 쓰나** — 캐럿을 직접 그린 장식으로 대신할 때처럼 기본 캐럿을 감추고 싶을 때 쓴다.

```text
입력 코드                         무엇이 일어나나                    결과
input {                          캐럿을 투명색으로 칠한다            입력은 되지만
  caret-color: transparent; →    → 자리는 있지만 보이지 않음     →  어디에 쓰이는지
}                                                                    가리키는 막대가 없다
```

- `transparent` 도 색 값이라 캐럿에 칠할 수 있다.
- 투명하게 칠하니 캐럿이 보이지 않는다.
- 글자 입력 자체는 막히지 않는다 — 보이는 표시만 사라진다.

`caret-color` 는 애니메이션 가능한 속성이다.
값이 색이므로 한 색에서 다른 색으로 조금씩 바뀌게 할 수 있다(원본에 근거 없음 — 추론: 색 값은 사이 값을 계산할 수 있다).

```html demo
<input type="text" placeholder="클릭해 보세요" style="color:#334155; caret-color:#ef4444; padding:8px 12px; border:2px solid #e2e8f0; border-radius:6px;">
```

> **보이는 것** — 입력칸을 클릭하면 회색 글자 사이에서 빨간 캐럿이 깜빡인다 (코드에서 읽은 것 — 렌더 실측 아님)

## 문법 — 형태와 규칙

```css
/* 최소 예제 */
.form          { caret-color: #3b82f6; }    /* 안쪽 입력칸 모두 파랑 캐럿(상속) */
.form .danger  { caret-color: #ef4444; }    /* 이 칸만 빨강으로 덮어씀 */
.plain         { caret-color: auto; }       /* 기본값으로 되돌림 */
.hidden-caret  { caret-color: transparent; }/* 캐럿 숨김 — 접근성 주의 */
[contenteditable] { caret-color: #22c55e; } /* 편집 가능한 div 에도 작동 */
```

- 형태: `caret-color: auto | <color>`
- 기본값: `auto`
- 상속: 된다.
- 애니메이션: 가능하다.

| 값 | 뜻 | 쓰는 때 |
|---|---|---|
| `auto` | `currentcolor` 또는 브라우저 기본값 | 따로 정할 것이 없을 때(기본) |
| `<color>` | 아무 CSS 색 값(`#ef4444` · `rgb()` · 이름 색 등) | 캐럿을 특정 색으로 칠할 때 |
| `transparent` | 투명 — 캐럿이 보이지 않음 | 캐럿을 감출 때(접근성 주의) |

## 어디서 틀리나

### 1. 캐럿을 숨기면 사용자가 길을 잃는다

`transparent` 로 두면 캐럿이 보이지 않는다.
캐럿은 「지금 어디에 글자가 들어가나」를 알려 주는 유일한 표시다.
키보드로만 움직이는 사용자나 눈이 불편한 사용자는 입력 위치를 알 수 없게 된다.
그래서 숨길 때는 접근성에 주의해야 한다 — 대신할 표시를 직접 그리지 않는다면 숨기지 않는 편이 낫다.

### 2. 「커서 색」이라는 말에 속지 않는다

`caret-color` 가 바꾸는 것은 글자 입력 위치의 막대다.
마우스 포인터(화살표 · 손가락 모양)는 `cursor` 속성이 다루며, `caret-color` 와 관계없다.
키워드에 「커서색상」이 있어 헷갈리기 쉽다.

### 3. 입력할 수 없는 요소에 줘도 보이지 않는다

캐럿은 입력 가능한 곳에만 생긴다.
평범한 `<div>` 에 줘도 그 자체로는 보이는 변화가 없다.
다만 상속되므로, 그 `div` 안에 입력칸이나 `contenteditable` 요소가 있으면 그쪽 캐럿에 값이 내려간다.

### 4. `auto` 를 「늘 글자 색」으로 믿지 않는다

`auto` 는 `currentcolor` 또는 브라우저 기본값이다.
어느 쪽인지는 브라우저가 고른다.
캐럿 색이 꼭 특정 색이어야 하면 `auto` 에 기대지 말고 색을 적는다.

### 5. 글자 색과 같은 배경에서 캐럿이 묻힌다

캐럿 색을 배경색과 비슷하게 고르면 `transparent` 와 다를 바 없이 안 보인다.
배경과 대비가 큰 색을 고른다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 기본값은 `auto`, 상속된다, 애니메이션 가능하다 | CSS 속성 정의(원본 재료의 속성 정보) |
| `auto` 일 때 `currentcolor` 를 쓸지 브라우저 기본값을 쓸지 | 브라우저(사용자 에이전트)가 고른다 — 언어가 한 색을 못 박지 않는다 |
| `transparent` 면 캐럿이 보이지 않는다 | 색 값의 정의(투명색)에서 나온다 |
| 캐럿의 모양 · 굵기 · 깜빡임 속도 | 이 속성의 범위 밖 — 브라우저와 운영체제가 정한다 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 입력칸 캐럿을 브랜드 색으로 | `caret-color: <color>` | `color` 를 바꿔 글자까지 같이 물들이기 |
| 폼 전체 캐럿 색 통일 | 부모에 `caret-color` 한 번(상속) | 입력칸마다 같은 값 반복 |
| 마우스 포인터 모양 · 색 바꾸기 | `cursor` | `caret-color` |
| 캐럿을 직접 그린 장식으로 대신 | `caret-color: transparent` + 대신할 표시 | 대신할 표시 없이 `transparent` 만 |
| 특별한 요구가 없을 때 | `auto`(기본값 그대로) | 배경과 대비가 낮은 색 |

## 핵심 문장

1. **`caret-color` 는 입력 위치를 가리키는 캐럿만 칠한다** — 글자 색도, 마우스 포인터도 건드리지 않는다.
2. **기본값 `auto` 는 `currentcolor` 또는 브라우저 기본값이다** — 어느 쪽인지는 브라우저가 고른다.
3. **상속되므로 부모에 한 번 주면 안쪽 입력칸이 물려받는다.**
4. **`input` · `textarea` 뿐 아니라 `contenteditable` 요소에서도 작동한다.**
5. **`transparent` 는 캐럿을 감추므로 접근성을 해친다** — 대신할 표시 없이 쓰지 않는다.

## 관련 자료

- `color` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `accent-color` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **캐럿(caret)** — 텍스트를 입력할 위치를 가리키는 깜빡이는 세로 막대.
- **`caret-color`** — 캐럿의 색을 정하는 CSS 속성.
- **`color`** — 요소의 글자 색을 정하는 CSS 속성.
- **`currentcolor`** — 그 요소의 현재 `color` 값을 가리키는 키워드.
- **`transparent`** — 완전히 투명한 색 값.
- **`cursor`** — 마우스 포인터의 모양을 정하는 CSS 속성.
- **contenteditable** — 일반 요소를 편집 가능하게 만드는 HTML 속성.
- **상속** — 부모의 속성 값이 자식에게 내려가는 것.
- **포커스** — 키보드 입력을 받을 요소로 선택된 상태.
- **접근성** — 장애가 있거나 다른 방식으로 기기를 쓰는 사람도 쓸 수 있게 하는 성질.

## 더 들어가면

- `:focus` 와 `transition` 을 함께 써서, 입력칸에 포커스가 갈 때 캐럿 색이 서서히 바뀌게 할 수 있다 (확인 필요).
- 명세는 `auto` 일 때 브라우저가 배경과 대비가 충분한 색을 고르도록 권한다는 설명이 있다 (확인 필요).
- 캐럿의 모양(막대 · 블록 등)을 정하는 별도 속성이 제안된 적이 있다 (확인 필요).
- 비밀번호 입력칸이나 숫자 입력칸에서도 같은 방식으로 작동하는지는 브라우저마다 다를 수 있다 (확인 필요).
