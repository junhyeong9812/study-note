## 한눈에 — 쉽게 말하면

**`forced-color-adjust` 는 「선글라스를 낀 손님에게 그림을 보여 줄 때의 표지판」이다.**
어떤 손님(사용자)은 눈이 편하도록 자기만의 색 안경(강제 색상 모드)을 끼고 들어온다.
대부분의 그림은 그 안경 너머로 보여도 괜찮다(`auto`).
하지만 색 자체가 정보인 지도나 그래프는 「이 그림만은 원래 색으로 보세요」라는 표지판(`none`)을 붙여 둔다.
웹 페이지의 요소도 똑같은 구조다.
사용자가 고대비 모드 같은 강제 색상 모드를 켜면 브라우저가 페이지 색을 바꾸고, 이 속성은 그 바뀜을 받을지 말지를 요소마다 정한다.

> **강제 색상 모드** — 사용자가 고른 제한된 색 묶음으로 페이지 색을 브라우저가 강제로 바꾸는 상태.\
> 예: 고대비 모드를 켜면 배경과 글자색이 시스템이 정한 색으로 바뀐다.

| 비유 | 실체 |
|---|---|
| 손님의 색 안경 | 강제 색상 모드(고대비 모드 등) |
| 안경 너머로 보여도 되는 그림 | `forced-color-adjust: auto` 인 요소 |
| 「원래 색으로 보세요」 표지판 | `forced-color-adjust: none` |
| 「글자 잉크만 옆 그림과 맞추세요」 | `forced-color-adjust: preserve-parent-color` |

```text
 사용자: 강제 색상 모드 켬
          │
          ▼
 ┌──────────────── 브라우저 ────────────────┐
 │ 요소마다 forced-color-adjust 를 본다      │
 │   auto  ─────────────► 색을 자동 조정     │
 │   none  ─────────────► 지정한 색 그대로   │
 │   preserve-parent-color ► color 는 부모 것 │
 │                          나머지는 자동 조정 │
 └──────────────────────────────────────────┘
```

## 이 주제가 답하려는 질문

1. 강제 색상 모드가 켜졌을 때 요소의 색은 누가, 어떻게 바꾸나?
2. 색을 바꾸지 말아야 하는 요소는 어떻게 표시하나, 그리고 그 표시는 언제만 써야 하나?
3. 이 설정은 자식 요소에 어떻게 퍼지나?

## 동작 방식

### (1) `auto` — 기본값, 자동 조정을 받아들인다

**언제 쓰나** 거의 모든 요소다.
아무것도 적지 않아도 기본값이 `auto` 라서 대부분은 따로 쓸 일이 없다.

```text
 입력 코드                          강제 색상 모드에서 일어나는 일        결과
 .auto-box {                       브라우저가 forced-color-adjust 를 본다   지정한 파란 배경 · 흰 글씨 대신
   forced-color-adjust: auto;  ─►  → auto 이므로 색을 자동 조정한다    ─►  사용자/시스템이 정한 색으로 보인다
   background: #3b82f6;
   color: white;
 }
```

- 사용자가 강제 색상 모드를 켠다.
- 브라우저는 요소의 `forced-color-adjust` 가 `auto` 인 것을 본다.
- 작성자가 지정한 배경색 · 글자색 대신 강제 색상 모드의 색으로 조정한다.
- 강제 색상 모드가 꺼져 있으면 아무 일도 일어나지 않고 지정한 색 그대로 보인다.

### (2) `none` — 자동 조정을 끈다

**언제 쓰나** 그라디언트 · 데이터 시각화처럼 색이 의미를 담고 있어 바뀌면 안 되는 요소에만 쓴다.

```text
 입력 코드                                     강제 색상 모드에서 일어나는 일      결과
 .none-box {                                  브라우저가 none 을 본다              분홍→보라 그라디언트와
   forced-color-adjust: none;            ─►   → 이 요소의 색은 건드리지 않는다 ─►  흰 글씨가 그대로 남는다
   background: linear-gradient(135deg,
               #f43f5e, #8b5cf6);
   color: white;
 }
```

- 사용자가 강제 색상 모드를 켠다.
- 브라우저는 `none` 을 보고 이 요소의 색 조정을 건너뛴다.
- 작성자가 지정한 그라디언트와 글자색이 유지된다.
- 대신 그 요소는 사용자가 고른 색 묶음의 도움을 받지 못한다 — 그래서 남용하면 접근성을 해친다.

### (3) `preserve-parent-color` — 글자색만 부모를 따른다

**언제 쓰나** 요소의 `color` 만큼은 부모와 같은 색이어야 하고, 배경 같은 나머지는 자동 조정되어도 될 때다.

```text
 입력 코드                                강제 색상 모드에서 일어나는 일          결과
 .child {                                color      → 부모의 color 를 상속    ─►  글자색은 부모와 같고
   forced-color-adjust:              ─►  나머지 색  → 자동 조정                   배경 등은 시스템 색
     preserve-parent-color;
 }
```

- 사용자가 강제 색상 모드를 켠다.
- 이 요소의 `color` 는 부모의 `color` 를 이어받는다.
- 배경색처럼 `color` 가 아닌 나머지 색은 `auto` 처럼 자동 조정된다.

### (4) 상속 — 부모에 적으면 자식도 따른다

**언제 쓰나** 차트 컨테이너처럼 안쪽 요소 전체를 한꺼번에 묶어 다룰 때다.

```text
 입력 코드                              일어나는 일                          결과
 .chart { forced-color-adjust: none; }  .chart 의 값 none 이 상속된다     ─►  자식 .bar 도 강제 색상 모드에서
 .chart .bar { background: red; }       .bar 는 값을 적지 않았으므로 none      지정한 색을 유지한다
```

- `forced-color-adjust` 는 상속되는 속성이다.
- 자식이 값을 따로 적지 않으면 부모의 값을 물려받는다.
- 그래서 부모 하나에 `none` 을 적으면 그 아래 모든 요소가 조정에서 빠진다 — 범위를 좁게 잡아야 한다.
- 자식에 `auto` 를 다시 적으면 그 자식만 다시 자동 조정을 받는다.

> **상속** — 자식 요소가 값을 적지 않았을 때 부모의 값을 그대로 이어받는 성질.\
> 예: `color` 처럼 `forced-color-adjust` 도 부모에 적으면 자식에게 퍼진다.

### (5) 애니메이션 불가

이 속성은 애니메이션 가능하지 않다.
`auto` 와 `none` 사이에 중간 단계가 없으므로 `transition` 을 걸어도 서서히 바뀌는 일은 없다.

## 문법 — 형태와 규칙

```html demo
<div class="auto-box">auto: 강제 색상 모드에서 조정됨</div>
<div class="none-box">none: 원래 색상 유지</div>
<style>
  .auto-box { forced-color-adjust: auto; background: #3b82f6; color: white; padding: 12px; margin-bottom: 8px; }
  .none-box { forced-color-adjust: none; background: linear-gradient(135deg, #f43f5e, #8b5cf6); color: white; padding: 12px; }
</style>
```

> **보이는 것** — 평소에는 파란 상자와 분홍→보라 그라디언트 상자가 위아래로 놓인다. 강제 색상 모드에서는 위 상자의 색만 시스템 색으로 바뀌고 아래 상자는 그대로다. (코드에서 읽은 것 — 렌더 실측 아님)

- 형태: `forced-color-adjust: auto | none | preserve-parent-color`
- 기본값: `auto`
- 상속: 된다
- 애니메이션: 안 된다
- 효과가 나는 때: 강제 색상 모드가 켜져 있을 때만이다.

| 값 | 강제 색상 모드에서 | 쓰는 자리 |
|---|---|---|
| `auto` | 색이 자동 조정된다 (기본값) | 일반 텍스트 · 버튼 · 카드 등 거의 전부 |
| `none` | 색 조정을 끈다 — 지정한 색 유지 | 색이 의미를 담는 그라디언트 · 데이터 시각화 |
| `preserve-parent-color` | `color` 는 부모 것을 상속, 나머지는 자동 조정 | 글자색을 부모와 맞춰야 하는 요소 |

## 어디서 틀리나

### 1. `none` 을 남용한다

원본의 팁: `none` 은 그라디언트 · 데이터 시각화처럼 색이 의미를 담고 있어 변경되면 안 되는 경우에만 쓴다.
남용하면 접근성을 해친다.
강제 색상 모드를 켠 사람은 대개 눈으로 구분하기 쉬운 색이 필요해서 켠 것이다.
「디자인이 흐트러져서」라는 이유로 `none` 을 붙이면 그 사람이 고른 색을 빼앗는 셈이다.

### 2. 부모에 `none` 을 적어 범위가 너무 넓어진다

상속되므로 `body` 나 큰 레이아웃 상자에 `none` 을 적으면 그 안의 글자 · 버튼까지 모두 조정에서 빠진다.
의미를 담은 그림 상자 하나에만 좁게 적는다.

### 3. 평소 화면에서 차이를 찾는다

강제 색상 모드가 꺼져 있으면 `auto` 와 `none` 은 겉보기 차이가 없다.
차이를 보려면 강제 색상 모드를 켠 상태에서 봐야 한다.

### 4. 전환 효과를 기대한다

애니메이션 가능하지 않으므로 값을 바꾸는 `transition` 은 효과가 없다.

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 값 셋 · 기본값 `auto` · 상속됨 · 애니메이션 불가 | CSS 명세 (원본 재료의 서술) |
| 강제 색상 모드에서 실제로 어떤 색이 쓰이나 | 운영체제 · 사용자 설정 · 브라우저 |
| 강제 색상 모드를 켜는 방법 | 운영체제 · 브라우저 (확인 필요) |
| 어느 브라우저가 이 속성을 지원하나 | 브라우저마다 다름 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 일반 텍스트 · 버튼 · 카드 | 아무것도 안 적음(`auto`) | `none` |
| 색이 범례와 맞물린 차트 · 지도 | 그 차트 상자에만 `none` | 페이지 전체에 `none` |
| 의미를 담은 그라디언트 | 그 요소에만 `none` | 장식용 그라디언트에 `none` |
| 글자색이 부모와 같아야 하는 요소 | `preserve-parent-color` | `none` (나머지 조정까지 잃는다) |
| 값을 서서히 바꾸고 싶을 때 | — | `transition` (애니메이션 불가) |

## 핵심 문장

1. **`forced-color-adjust` 는 강제 색상 모드에서 요소의 색을 자동 조정받을지 정한다** — 평소 화면에는 영향이 없다.
2. **기본값 `auto` 는 조정을 받아들이고, `none` 은 지정한 색을 지킨다.**
3. **`preserve-parent-color` 는 `color` 만 부모 것을 잇고 나머지는 자동 조정한다.**
4. **상속되므로 부모에 적은 값이 자식 전체에 퍼진다** — `none` 은 좁게 적는다.
5. **`none` 은 색이 의미를 담을 때만** — 남용하면 접근성을 해친다.

- `color-scheme` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **강제 색상 모드** — 사용자가 고른 제한된 색 묶음으로 브라우저가 페이지 색을 강제로 바꾸는 상태.
- **고대비 모드** — 강제 색상 모드의 대표 예로, 배경과 글자의 대비를 크게 만든 색 묶음을 쓰는 모드.
- **자동 조정** — 강제 색상 모드에서 작성자 색을 시스템 · 사용자 색으로 바꾸는 일.
- **상속** — 값을 적지 않은 자식이 부모의 값을 이어받는 성질.
- **그라디언트** — 두 색 이상이 점점 섞이며 이어지는 배경(`linear-gradient` 등).
- **데이터 시각화** — 차트 · 그래프처럼 색과 모양으로 값을 나타낸 그림.
- **접근성** — 시력 · 장애 등 조건이 다른 사람도 내용을 쓸 수 있게 하는 성질.

## 더 들어가면

- 강제 색상 모드인지는 미디어 쿼리 `@media (forced-colors: active)` 로 알아낼 수 있다 (확인 필요).
- 강제 색상 모드에서 쓰이는 색은 `Canvas` · `CanvasText` · `LinkText` · `ButtonText` 같은 시스템 색 키워드로 CSS 에서 참조할 수 있다 (확인 필요).
- 명세상 조정 대상에는 `color` · `background-color` · `border-color` · `outline-color` 등이 들어가고, `box-shadow` · `text-shadow` 는 없어지며, `background-image` 는 `url()` 이미지만 남고 그라디언트는 지워진다고 알려져 있다 (확인 필요).
- 대표적인 강제 색상 모드는 Windows 의 고대비(대비 테마) 기능이다 (확인 필요).
- 브라우저 개발자 도구에서 `forced-colors` 를 흉내 내어 켜 볼 수 있는 경우가 있다 (확인 필요).
