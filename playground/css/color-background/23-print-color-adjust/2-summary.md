## 한눈에 — 쉽게 말하면

**`print-color-adjust` 는 「인쇄소에 맡기는 원고에 붙이는 메모」다.**
메모가 「알아서 잉크 아껴 주세요」(`economy`)이면 인쇄소는 배경 바탕색을 빼고 글자만 찍을 수 있다.
메모가 「원고 그대로 찍어 주세요」(`exact`)이면 인쇄소는 바탕색과 그림까지 원고대로 찍는다.
브라우저의 인쇄도 똑같은 구조다.
화면에 그린 페이지를 종이로 보낼 때, 브라우저는 배경색이나 배경 이미지를 손볼 수 있다.
이 속성은 그 손보기를 허용할지 막을지를 요소마다 적어 두는 메모다.

| 비유 | 실체 |
|---|---|
| 원고 | 화면에 그려진 페이지 |
| 인쇄소 | 인쇄를 처리하는 브라우저 |
| 「알아서 아껴 주세요」 메모 | `print-color-adjust: economy` (기본값) |
| 「그대로 찍어 주세요」 메모 | `print-color-adjust: exact` |
| 바탕색 · 바탕 그림 | `background` 의 색 · 이미지 |

```text
            화면                         종이 (인쇄)
  ┌──────────────────────┐      economy ┌──────────────────────┐
  │███ 파란 배경 상자 ███│  ──────────▶ │   배경을 조정/제거할  │
  └──────────────────────┘   (브라우저  │   수 있음 (브라우저 몫)│
                              판단)     └──────────────────────┘
  ┌──────────────────────┐      exact   ┌──────────────────────┐
  │▓▓ 그라디언트 상자 ▓▓▓│  ──────────▶ │▓▓ 작성한 색 그대로 ▓▓│
  └──────────────────────┘              └──────────────────────┘
```

## 이 주제가 답하려는 질문

1. 화면에서 멀쩡히 보이던 배경색이 인쇄하면 왜 사라질 수 있나?
2. 배경색이 정보인 표나 차트를 인쇄할 때 색을 어떻게 지키나?
3. 이 설정은 자식 요소에 어떻게 퍼지고, 옛 브라우저에는 어떻게 대비하나?

## 동작 방식

### (1) `economy` — 브라우저에게 맡긴다

**언제 쓰나** — 따로 적지 않았을 때의 기본 동작이다.
배경이 꾸밈일 뿐이라 인쇄에서 빠져도 내용이 그대로 전달될 때 그대로 둔다.

```text
.box { print-color-adjust: economy; background: 파랑; }
        │
        ▼  인쇄 명령
브라우저: 「인쇄 최적화를 해도 된다」
        │
        ▼
배경을 조정하거나 제거할 수 있다 → 어떻게 할지는 브라우저가 정한다
```

- 첫 줄에서 요소는 파란 배경을 가진다.
- 인쇄가 시작되면 브라우저는 이 요소에 최적화가 허용된 것을 본다.
- 브라우저는 잉크 절약 등을 위해 배경을 바꾸거나 뺄 수 있다.
- 「할 수 있다」이지 「반드시 한다」가 아니다 — 최종 판단은 브라우저 몫이다.

### (2) `exact` — 작성한 그대로

**언제 쓰나** — 배경색이 정보 전달에 꼭 필요할 때다.
예를 들어 칸 색으로 상태를 나누는 표, 색 막대로 값을 보이는 차트가 그렇다.

```text
.chart { print-color-adjust: exact; background: linear-gradient(...); }
        │
        ▼  인쇄 명령
브라우저: 「이 요소는 최적화하지 말라」
        │
        ▼
배경색 · 배경 이미지(그라디언트 포함)를 작성한 대로 인쇄
```

- 요소에 그라디언트 배경이 있다.
- 인쇄 때 브라우저는 `exact` 를 보고 최적화를 하지 않는다.
- 배경색과 배경 이미지가 유지된다.
- `linear-gradient()` 는 CSS 에서 배경 이미지로 취급되므로 여기에 포함된다.

> **그라디언트** — 두 색 이상이 부드럽게 이어지는 배경 이미지.\
> 예: `linear-gradient(135deg, #f43f5e, #8b5cf6)` 는 135도 방향으로 분홍에서 보라로 바뀐다.

### (3) 상속 — 부모에 한 번 적으면 자식까지

**언제 쓰나** — 표 전체나 차트 묶음처럼 여러 요소를 한꺼번에 지킬 때다.

```text
<table style="print-color-adjust: exact">
   └─ <tr>            (적지 않음) → 부모 값 exact 를 물려받음
        └─ <td class="red">  (적지 않음) → exact
```

- 이 속성은 상속된다.
- 자식에 따로 적지 않으면 부모의 값을 그대로 쓴다.
- 그래서 표 바깥 요소 하나에 `exact` 를 적으면 안쪽 칸들도 `exact` 가 된다.
- 자식이 `economy` 를 직접 적으면 그 자식부터는 다시 `economy` 다.

> **상속** — 값을 적지 않은 요소가 부모 요소의 값을 그대로 받는 성질.\
> 예: `body { color: red; }` 이면 그 안의 `<p>` 도 빨간 글씨가 된다.

## 문법 — 형태와 규칙

```html demo
<div class="economy">economy: 인쇄 시 브라우저가 최적화</div>
<div class="exact">exact: 화면 그대로 인쇄</div>
<style>
  .economy { print-color-adjust: economy; background: #3b82f6; color: white; padding: 16px; }
  .exact {
    -webkit-print-color-adjust: exact;  /* 옛 이름 — 호환용 */
    print-color-adjust: exact;
    background: linear-gradient(135deg, #f43f5e, #8b5cf6); color: white; padding: 16px;
  }
</style>
```

> **보이는 것** — 화면에서는 파란 상자와 분홍→보라 그라디언트 상자가 둘 다 색을 띤 채 보인다. 차이는 인쇄할 때만 생긴다 (코드에서 읽은 것 — 렌더 실측 아님)

| 값 | 뜻 |
|---|---|
| `economy` | 브라우저가 인쇄 최적화를 위해 배경 등을 조정하거나 제거할 수 있다 (기본값) |
| `exact` | 작성된 색상을 그대로 인쇄한다 — 배경색 · 배경 이미지를 유지한다 |

- 문법은 `print-color-adjust: economy | exact` 다.
- 기본값은 `economy` 다.
- 상속된다.
- 애니메이션할 수 없다 — `transition` 이나 `@keyframes` 로 두 값 사이를 옮겨 갈 수 없다.
- 옛 이름 `-webkit-print-color-adjust` 를 함께 적으면 호환성을 넓힐 수 있다.
- 접두사 붙은 줄을 먼저, 표준 줄을 뒤에 적는 것이 흔한 순서다 — 둘 다 알아듣는 브라우저에서는 뒤의 표준 값이 남는다.

> **벤더 접두사** — 표준이 굳기 전에 브라우저가 제 이름을 앞에 붙여 내놓은 속성 이름.\
> 예: `-webkit-print-color-adjust` 는 `print-color-adjust` 의 옛 접두사 판이다.

## 어디서 틀리나

### 1. 화면에서 시험하고 「아무 차이가 없다」고 결론 내린다

이 속성은 인쇄 때 동작을 정한다.
화면에서는 `economy` 와 `exact` 가 똑같이 보인다.
차이를 보려면 인쇄 미리보기에서 확인해야 한다.

### 2. 정보를 담은 배경을 기본값에 맡긴다

팁 그대로, 배경색이 정보 전달에 필수인 표 · 차트에는 `exact` 를 쓴다.
기본값 `economy` 에서는 브라우저가 배경을 뺄 수 있다.
배경이 빠지면 「빨간 칸 = 위험」 같은 뜻이 종이에서 사라진다.

### 3. `economy` 가 배경을 「반드시 지운다」고 믿는다

`economy` 는 조정 · 제거를 **허용**할 뿐이다.
실제로 지울지, 어떻게 바꿀지는 브라우저가 정한다.
그래서 「economy 면 배경이 사라진다」를 전제로 설계하면 안 된다.

### 4. 흰 글씨 위의 배경이 빠지는 경우를 잊는다

예제처럼 색 배경 위에 흰 글씨를 쓴 상자는 배경이 빠지면 읽기 어려워질 수 있다.
브라우저가 글자색도 함께 조정하는지는 브라우저마다 다를 수 있다 (확인 필요).
배경과 글자가 짝을 이루는 디자인이면 `exact` 를 고려한다.

### 5. 표준 이름만 적는다

팁에 따르면 구형 `-webkit-print-color-adjust` 도 함께 지정해야 호환성이 확보된다.
어떤 브라우저 버전부터 표준 이름을 받는지는 이 문서의 재료에 없다 (확인 필요).

### 6. 자식마다 일일이 적는다

상속되므로 묶음의 바깥 요소 하나에 적으면 된다.
반대로 부모에 `exact` 를 적어 두고 일부 자식만 아끼고 싶으면, 그 자식에 `economy` 를 직접 적는다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 기본값 `economy` · 상속됨 · 애니메이션 불가 | 속성 정의 (원본 데이터) |
| `economy` 에서 배경을 실제로 지우는지, 어떻게 조정하는지 | 브라우저 구현 — 속성은 허용만 한다 |
| `-webkit-print-color-adjust` 가 동작함 | 이 이름을 아는 브라우저 구현 — 표준 이름이 아니다 |
| 배경이 빠질 때 글자색도 바뀌는지 | 브라우저 구현 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 칸 색이 상태를 나타내는 표 | 표에 `exact` (상속으로 칸까지) | 기본값 방치 |
| 색 막대 · 범례가 있는 차트 | `exact` + `-webkit-` 판 | 표준 이름만 |
| 배경이 꾸밈뿐인 카드 · 배너 | 기본값 `economy` | 무조건 `exact` (잉크 낭비) |
| 화면에서 색 차이를 보고 싶을 때 | 다른 색 속성 | 이 속성 (화면에선 차이 없음) |
| 값이 부드럽게 바뀌는 효과 | — | `transition` 대상으로 쓰기 (애니메이션 불가) |

## 핵심 문장

1. **`print-color-adjust` 는 인쇄 때 배경 최적화를 허용할지 막을지 정한다** — 화면 모습은 바꾸지 않는다.
2. **기본값 `economy` 는 「조정 · 제거해도 된다」는 허락이다** — 무엇을 할지는 브라우저가 정한다.
3. **`exact` 는 배경색 · 배경 이미지를 작성한 대로 인쇄하게 한다** — 색이 정보인 표 · 차트에 쓴다.
4. **상속되므로 바깥 요소 하나에 적으면 안쪽까지 덮는다.**
5. **옛 `-webkit-print-color-adjust` 를 함께 적어 호환성을 확보한다.**

## 관련 자료

- `color` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `background-color` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `background-image` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **인쇄 최적화** — 잉크 절약 등을 위해 브라우저가 인쇄물의 배경 등을 손보는 일.
- **`economy`** — 인쇄 최적화를 허용하는 값, 기본값.
- **`exact`** — 작성한 색을 그대로 인쇄하게 하는 값.
- **상속** — 값을 적지 않은 요소가 부모의 값을 받는 성질.
- **그라디언트** — 색이 부드럽게 이어지는 배경 이미지, `linear-gradient()` 로 만든다.
- **벤더 접두사** — `-webkit-` 처럼 브라우저 이름을 앞에 붙인 옛 속성 이름.
- **인쇄 미리보기** — 종이로 내보내기 전에 인쇄 결과를 화면에 보여 주는 창.

## 더 들어가면

- 많은 브라우저의 인쇄 대화상자에는 「배경 그래픽 인쇄」 같은 사용자 옵션이 있고, 이 옵션과 `print-color-adjust` 가 함께 결과를 정한다 (확인 필요).
- 명세에서는 이 속성이 인쇄뿐 아니라 사용자 에이전트의 색 최적화 전반에 대한 힌트로 정의되어 있다는 설명이 있다 (확인 필요).
- 예전에는 `color-adjust` 라는 이름도 쓰였다 (확인 필요).
- 인쇄 전용 스타일은 흔히 `@media print { … }` 안에 모아 둔다 — 이 속성과 함께 쓰면 인쇄용 규칙을 한곳에서 관리할 수 있다 (확인 필요).
- 고대비 모드처럼 사용자가 색을 강제하는 상황은 `forced-color-adjust` 라는 별도 속성이 다룬다 (확인 필요).
