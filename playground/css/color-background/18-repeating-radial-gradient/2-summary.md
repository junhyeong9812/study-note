## 한눈에 — 쉽게 말하면

**`repeating-radial-gradient()` 는 「잔잔한 물에 돌을 던졌을 때 퍼지는 물결」이다.**
돌이 떨어진 한 점에서 같은 간격의 고리가 바깥으로 되풀이해 퍼진다.
고리 하나(마루 하나 + 골 하나)의 모양만 정하면 나머지는 저절로 이어진다.
`repeating-radial-gradient()` 도 똑같은 구조다.
중심점에서 바깥으로, 색 정지점 목록이 정한 「한 마디」를 계속 되풀이해 동심원을 그린다.

| 비유 | 실체 |
|---|---|
| 돌이 떨어진 점 | 그라디언트의 중심 (`at <position>`, 생략하면 상자 가운데) |
| 물결 고리 한 쌍 | 색 정지점 목록이 정의하는 반복 단위 |
| 고리의 간격 | 첫 정지점과 마지막 정지점 사이의 거리 |
| 동그란 물결 / 길쭉한 물결 | `circle` / `ellipse` |

```text
        중심에서 바깥으로 반복 단위가 되풀이된다

   반복 단위(한 마디)       ┌──────────── 상자 ────────────┐
   ┌───────┬───────┐        │   ( ( ( ( ● ) ) ) )          │
   │ 색 A  │ 색 B  │  ───▶  │   A B A B ● B A B A          │
   0     10px    20px       │   ←── 반복 ── 중심 ── 반복 ──→│
                            └──────────────────────────────┘
```

## 이 주제가 답하려는 질문

1. 색 정지점 목록이 어떻게 「반복 단위」가 되고, 그것이 어떻게 동심원이 되나?
2. 띠와 띠의 경계를 날카롭게 끊거나 부드럽게 잇는 것은 무엇이 정하나?
3. 원(`circle`)과 타원(`ellipse`), 중심 위치(`at`)는 결과를 어떻게 바꾸나?
4. 반복하지 않는 `radial-gradient()` 와는 무엇이 다른가?

## 동작 방식

### (1) 색 정지점 목록이 반복 단위가 된다

**언제 쓰나** — 같은 두께의 고리를 여러 겹 그리고 싶을 때, 고리를 하나하나 적지 않고 한 마디만 적는다.

```text
입력:  repeating-radial-gradient(circle, #3b82f6 0px, #3b82f6 10px, #1e40af 10px, #1e40af 20px)

반복 단위 길이 = 마지막 정지점(20px) − 첫 정지점(0px) = 20px

중심으로부터 거리:  0───10───20───30───40───50───60───70───80 ...
칠해지는 색:        밝   진   밝   진   밝   진   밝   진  ...
                    └ 1마디 ┘└ 2마디 ┘└ 3마디 ┘└ 4마디 ┘
```

- 브라우저는 정지점 목록이 덮는 구간(0px~20px)을 한 마디로 본다.
- 중심에서의 거리가 20px 을 넘으면 거리를 20px 단위로 되감아 같은 색을 다시 칠한다.
- 그래서 21px 지점은 1px 지점과 같은 색이 되고, 결과는 일정한 간격의 동심원이다.

### (2) 같은 위치에 두 색을 두면 경계가 끊긴다

**언제 쓰나** — 과녁처럼 색이 「뚝」 바뀌는 줄무늬 고리를 그릴 때.

```text
입력:  #ef4444 0px, #ef4444 15px, white 15px, white 30px

0px ──── 15px │ 15px ──── 30px
 빨강 → 빨강  │ 흰색 → 흰색
   (색 변화 없음)  ↑ 같은 위치에서 색이 바뀜 = 섞일 구간 길이 0
```

- 정지점 사이에서는 원래 앞 색에서 뒤 색으로 서서히 섞인다.
- 빨강 0px → 빨강 15px 구간은 양 끝 색이 같으니 섞여도 계속 빨강이다.
- 빨강 15px → 흰색 15px 는 섞일 거리가 0 이라 그 자리에서 색이 즉시 바뀐다.
- 그래서 「단색 띠 + 날카로운 경계」의 줄무늬가 생긴다.

### (3) 반복 단위의 시작 색과 끝 색이 이음매를 정한다

**언제 쓰나** — 물결처럼 끊김 없이 부드럽게 출렁이는 고리를 그릴 때(원본 팁).

```text
A) 끝 색 ≠ 시작 색:   파랑 0px → 흰색 20px | 파랑 0px → ...
                                         ↑ 마디가 바뀌는 곳에서 흰색→파랑으로 뚝 끊김

B) 끝 색 = 시작 색:   파랑 0px → 흰색 10px → 파랑 20px | 파랑 0px → ...
                                                    ↑ 같은 색끼리 이어져 이음매가 안 보임
```

- 한 마디의 끝은 다음 마디의 시작과 맞닿는다.
- 끝 색과 시작 색이 다르면 맞닿는 곳에 날카로운 선이 생긴다.
- 같게 맞추면 맞닿는 곳의 색이 이어져 반복이 매끄럽다.
- 원본 예제(`.circles`, `.target`)는 일부러 다르게 두어 또렷한 띠를 만든 경우다.

```html demo
<div style="width:160px;height:160px;border-radius:50%;
  background:repeating-radial-gradient(circle, #3b82f6 0px, white 10px, #3b82f6 20px);"></div>
```

> **보이는 것** — 파랑과 흰색이 경계 없이 번갈아 출렁이는 동심원 물결 (코드에서 읽은 것 — 렌더 실측 아님)

### (4) 모양과 중심

**언제 쓰나** — 상자가 정사각형이 아니거나 중심을 옮기고 싶을 때(레이더를 한쪽 구석에서 퍼지게 하는 등).

```text
circle  : 어느 방향이든 같은 거리 → 동그란 고리
ellipse : 가로와 세로의 거리 비율이 다름 → 길쭉한 고리 (긴 상자에서 두드러짐)
at 25% 75% : 중심이 왼쪽 아래 쪽으로 옮겨짐 → 고리가 그 점에서 퍼짐
```

- `circle` 은 원형 반복, `ellipse` 는 타원형 반복이다.
- `at <position>` 은 중심점의 위치를 정하며, 생략하면 상자 가운데가 중심이다.
- 원본 예제는 정사각형 상자에 `circle` 을 써서 고리가 동그랗다.

### (5) 상자 밖 모양은 `border-radius` 가 자른다

**언제 쓰나** — 과녁처럼 배경 자체를 둥근 판으로 보이게 할 때.

- 그라디언트는 상자 전체(정사각형)를 칠한다.
- `border-radius: 50%` 가 배경을 원 모양으로 잘라 둥근 판처럼 보이게 한다.
- 160px 정사각형을 원으로 자르면 중심에서 가장자리까지 80px 이다.

## 문법 — 형태와 규칙

```css
.ring {
  width: 160px;
  height: 160px;
  border-radius: 50%;
  /* 모양, 중심 위치, 그리고 반복 단위가 될 색 정지점 목록 */
  background: repeating-radial-gradient(
    circle at center,
    #ef4444 0px, #ef4444 15px,   /* 빨강 띠 15px */
    white 15px, white 30px       /* 흰 띠 15px → 반복 단위 30px */
  );
}
```

- 꼴: `repeating-radial-gradient([<shape> <size> at <position>,]? <color-stop-list>)`.
- 앞의 모양 · 크기 · 위치 부분은 통째로 생략할 수 있다.
- 결과는 이미지라서 `background` 또는 `background-image` 에 넣는다.
- 기본값은 「해당 없음」 — 속성이 아니라 함수이기 때문이다.
- 상속되지 않는다.
- 애니메이션 가능하지 않다(원본 데이터).

| 값 | 뜻 | 쓰는 예 |
|---|---|---|
| `circle` | 원형 반복 | 과녁, 동심원 |
| `ellipse` | 타원형 반복 | 긴 상자에 맞춘 물결 |
| `at <position>` | 중심점 위치 | `at top left`, `at 30% 40%` |
| `<color-stop>` | 색과 위치 — 반복 단위를 정의 | `red 0px, red 15px` |

## 어디서 틀리나

### 1. 정지점에 위치를 안 적는다

위치가 없으면 정지점이 0~100% 로 고르게 퍼져 한 마디가 이미 전체를 덮는다.
그러면 반복이 보이지 않아 `radial-gradient()` 와 다를 바 없어 보인다.
반복 단위의 길이가 드러나도록 위치(`px` 등)를 적는다.

### 2. 경계가 흐릿하다

색이 다른 두 정지점의 위치가 다르면 그 사이에서 색이 섞인다.
줄무늬를 원하면 앞 띠의 끝과 뒤 띠의 시작을 같은 위치(`#3b82f6 10px, #1e40af 10px`)로 둔다.

### 3. 마디 사이에 원치 않는 선이 생긴다

반복 단위의 끝 색과 시작 색이 다르면 마디가 바뀌는 곳에서 색이 끊긴다.
부드러운 물결을 원하면 원본 팁대로 시작 색과 끝 색을 맞춘다.

### 4. 반복하지 않는 함수와 헷갈린다

`radial-gradient()` 는 마지막 정지점 바깥을 마지막 색으로 끝까지 채운다.
같은 정지점 목록이라도 고리가 한 번만 그려지고 바깥은 단색이 된다.

### 5. 고리가 찌그러진다

`ellipse` 를 쓰거나 모양을 안 적은 채 정사각형이 아닌 상자에 쓰면 고리가 길쭉해질 수 있다.
동그란 고리가 필요하면 `circle` 을 적는다.

### 6. 바꿔 끼우기를 부드럽게 움직이려 한다

애니메이션 가능하지 않으므로 `transition` 으로 그라디언트를 다른 그라디언트로 바꿔도 서서히 변하지 않는다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 정지점이 덮는 구간이 반복 단위가 되어 바깥으로 되풀이된다 | CSS 명세(그라디언트 정의) |
| 같은 위치의 두 정지점 사이에서 색이 즉시 바뀐다 | CSS 명세 |
| `at` 생략 시 중심이 상자 가운데다 | CSS 명세 (확인 필요) |
| 애니메이션 가능하지 않다 | 원본 데이터의 주장 — 명세 세부는 확인 필요 |
| 날카로운 경계가 얼마나 매끈하게(계단 없이) 보이는가 | 브라우저 렌더러마다 다름 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 과녁 · 동심원 줄무늬 | `repeating-radial-gradient()` + 같은 위치 정지점 | 고리마다 `div` 를 겹쳐 그리기 |
| 레이더 · 물결 효과 | 시작 색 = 끝 색으로 맞춘 반복 | 끝 색이 다른 반복(이음매가 보임) |
| 가운데가 밝고 바깥으로 한 번 흐려지는 빛 | `radial-gradient()` | 반복 버전 |
| 곧은 줄무늬 | `repeating-linear-gradient()` | 방사형 |
| 무늬가 서서히 바뀌는 애니메이션 | 다른 수단(겹친 요소의 `opacity` 등) | 그라디언트 값의 `transition` |

## 핵심 문장

1. **색 정지점 목록은 한 마디다** — 첫 정지점부터 마지막 정지점까지의 길이로 중심에서 바깥까지 되풀이된다.
2. **같은 위치의 두 정지점은 날카로운 경계를 만든다** — 과녁 줄무늬의 비결이다.
3. **반복 단위의 시작 색과 끝 색을 맞추면 이음매 없이 매끄럽다.**
4. **`circle` / `ellipse` 는 고리 모양을, `at` 은 중심을 정한다** — 둥근 판 모양은 `border-radius` 가 만든다.
5. **반복하지 않는 `radial-gradient()` 는 마지막 색으로 바깥을 채울 뿐 고리를 되풀이하지 않는다.**

## 관련 자료

- `radial-gradient` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `repeating-linear-gradient` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `repeating-conic-gradient` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- 원본: study-site 항목 데이터 `data/css/color-background.json` 의 `repeating-radial-gradient`

## 용어 풀이

- **방사형 그라디언트** — 한 점에서 바깥으로 색이 바뀌는 그라디언트.
- **색 정지점(color stop)** — 「이 거리에서 이 색」을 정하는 표시.
- **반복 단위** — 첫 정지점부터 마지막 정지점까지의 구간, 되풀이되는 한 마디.
- **하드 스톱** — 같은 위치에 둔 두 정지점, 색이 즉시 바뀌는 경계.
- **이음매** — 한 마디의 끝과 다음 마디의 시작이 맞닿는 곳.
- **`circle` / `ellipse`** — 고리의 모양, 원형 / 타원형.
- **`at <position>`** — 그라디언트 중심점의 위치.
- **`border-radius`** — 상자 모서리를 둥글게 깎는 속성, `50%` 면 정사각형이 원이 된다.

## 더 들어가면

- 모양을 생략하면 기본값은 `ellipse` 라고 알려져 있다 (확인 필요).
- `<size>` 자리에는 `closest-side` · `farthest-corner` 같은 키워드나 길이를 넣으며, 생략하면 `farthest-corner` 다 (확인 필요).
- 첫 정지점이 0 이 아니면 반복은 중심 쪽으로도 거꾸로 이어진다고 명세가 정한다 (확인 필요).
- 반복 단위가 매우 짧으면(1~2px) 모아레(물결 간섭 무늬)처럼 보일 수 있다 (확인 필요).
- `conic-gradient()` 계열과 겹쳐 쓰면 레이더의 회전 바늘 같은 효과를 낼 수 있다 (확인 필요).
- 그라디언트 대신 `@property` 로 등록한 사용자 정의 속성을 정지점 위치에 넣으면 움직이는 물결을 만들 수 있다고 알려져 있다 (확인 필요).
