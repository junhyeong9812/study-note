## 한눈에 — 쉽게 말하면

**`:paused` 는 「일시정지 버튼을 누르면 켜지는 표시등」이다.**
리모컨으로 영상을 멈추면 화면 구석에 일시정지 표시가 뜨고, 다시 재생하면 사라진다.
CSS 의 `:paused` 도 똑같은 구조다.
`audio` · `video` 가 멈춰 있는 동안에만 규칙이 걸리고, 재생이 시작되면 규칙이 풀린다.

> **의사 클래스(pseudo-class)** — 요소의 이름이나 속성이 아니라 「지금 어떤 상태인가」로 요소를 고르는 선택자 조각이다.\
> 예: `:hover` 는 마우스가 올라가 있는 동안, `:paused` 는 재생이 멈춰 있는 동안 맞는다.

| 비유 | 실체 |
|---|---|
| 영상 플레이어 | `<video>` · `<audio>` 요소 |
| 일시정지 버튼 누르기 | 재생 상태가 「멈춤」으로 바뀜 |
| 켜지는 표시등 | `:paused` 규칙의 선언(투명도 · 테두리 색 등) |
| 다시 재생하면 꺼짐 | 상태가 바뀌어 규칙이 더는 맞지 않음 |

```text
  [재생 중] ──(정지)──▶ [멈춤]  ← :paused 맞음 → 반투명 + 주황 테두리
     ▲                    │
     └──────(재생)────────┘     ← :paused 안 맞음 → 원래 모습
```

## 이 주제가 답하려는 질문

1. 재생 가능한 요소가 멈춰 있을 때만 모양을 바꾸려면 어떻게 고르나?
2. 상태가 바뀔 때 모양 변화가 부드럽게 일어나게 하려면 규칙을 어디에 두나?
3. 멈춤 상태에 어떤 시각적 피드백을 주는 것이 알맞나?

## 동작 방식

### (1) 상태로 요소를 고른다

**언제 쓰나** — 영상이나 소리가 멈췄다는 사실을 화면에서 알아보게 하고 싶을 때 쓴다.
JS 로 클래스를 붙였다 뗐다 하지 않고, 브라우저가 아는 재생 상태를 선택자로 바로 쓴다.

```text
.player2:paused { opacity: 0.7; }
        │
        ▼
브라우저: 이 .player2 는 지금 멈춰 있나?
   ├─ 예   → 선언 적용 → 70% 불투명
   └─ 아니오 → 선언 무시 → 기본 규칙의 모습
```

- 선택자 `.player2:paused` 는 「클래스 `player2` 를 가졌고」 「지금 일시정지 상태인」 요소를 고른다.
- 브라우저는 요소의 재생 상태를 보고 조건이 맞는지 판단한다.
- 맞으면 선언이 적용되고, 맞지 않으면 그 규칙은 없는 것처럼 다뤄진다.
- 재생 상태가 바뀌면 판단도 다시 이뤄진다.

### (2) 기본 규칙과 상태 규칙이 겹친다

**언제 쓰나** — 평소 모습은 기본 규칙에, 멈췄을 때 달라질 부분만 상태 규칙에 적을 때.

```text
.player2         { border: 3px solid #d1d5db; }   명시도: 클래스 1개
.player2:paused  { border-color: #f59e0b; }        명시도: 클래스 1개 + 의사 클래스 1개
        │
        ▼
멈춤 상태: 두 규칙 모두 맞음 → 명시도가 높은 :paused 쪽 border-color 가 이김
재생 상태: 기본 규칙만 맞음 → 회색 테두리
```

- 멈춤 상태에서는 두 규칙이 모두 같은 요소에 맞는다.
- 의사 클래스는 클래스와 같은 무게로 명시도에 더해진다.
- 그래서 `.player2:paused` 가 `.player2` 보다 명시도가 높고, 겹치는 `border-color` 는 상태 규칙 값이 쓰인다.
- 겹치지 않는 선언(`border-radius` · 테두리 두께 · 선 모양)은 기본 규칙 값이 그대로 남는다.

> **명시도(specificity)** — 같은 요소에 맞는 규칙들이 같은 속성을 다툴 때 누가 이기는지 정하는 무게다.\
> 예: `.a:hover` 는 `.a` 보다 무겁다.

### (3) 전이는 기본 규칙에 둔다

**언제 쓰나** — 멈춤 ↔ 재생이 바뀔 때 모양이 툭 바뀌지 않고 서서히 바뀌게 하려 할 때.

```text
.player2 { transition: all 0.3s; }   ← 기본 규칙에 있음 → 상태와 상관없이 늘 걸려 있음
        │
재생 → 멈춤: opacity 1 → 0.7, 테두리 회색 → 주황  (0.3초에 걸쳐)
멈춤 → 재생: opacity 0.7 → 1, 테두리 주황 → 회색  (0.3초에 걸쳐)
```

- `transition` 은 값이 바뀔 때 그 사이를 시간에 걸쳐 채우라는 지시다.
- 기본 규칙에 두면 멈춤 상태든 재생 상태든 늘 적용돼 있다.
- 그래서 멈출 때와 다시 재생할 때 양쪽 방향 모두 0.3초에 걸쳐 바뀐다.
- `all` 이라 바뀌는 속성 전부(여기서는 `opacity` 와 `border-color`)가 전이 대상이다.

> **전이(transition)** — 속성 값이 바뀔 때 새 값으로 바로 뛰지 않고 정해진 시간 동안 사이 값을 거쳐 가게 하는 CSS 기능이다.\
> 예: `transition: opacity 0.3s` 는 투명도 변화를 0.3초에 걸쳐 보여 준다.

```html demo
<video class="pv" controls width="240"></video>
<style>
  .pv { border: 3px solid #d1d5db; border-radius: 12px; transition: all 0.3s; }
  .pv:paused { opacity: 0.7; border-color: #f59e0b; }
</style>
```

> **보이는 것** — 멈춤 상태로 인식되면 플레이어가 조금 흐려지고 테두리가 주황으로 바뀐다 (코드에서 읽은 것 — 렌더 실측 아님)

## 문법 — 형태와 규칙

```css
/* 평소 모습 + 전이 */
video.clip {
  border: 2px solid gray;
  transition: opacity 0.3s, border-color 0.3s;
}

/* 멈춰 있을 때만 */
video.clip:paused {
  opacity: 0.6;
  border-color: orange;
}
```

- 꼴은 `selector:paused { }` 다.
- 앞의 `selector` 는 `audio` · `video` 같은 재생 가능한 요소를 가리켜야 의미가 있다.
- 콜론은 하나(`:`)다 — 의사 클래스이기 때문이다.
- 다른 선택자와 이어 붙일 수 있다(`.player2:paused`, `video.clip:paused`).

| 쓰임 | 예 | 효과 |
|---|---|---|
| 투명도 낮추기 | `opacity: 0.7` | 멈춘 요소가 흐려져 「쉬는 중」으로 보인다 |
| 테두리 색 바꾸기 | `border-color: …` | 멈춤을 색으로 표시한다 |
| 오버레이 표시 | (원본 팁) | 멈춤 상태 위에 덮개를 보여 준다 |
| 전이와 함께 | 기본 규칙에 `transition` | 상태 변화가 부드럽게 보인다 |

> **재생 가능한 요소** — 재생 · 일시정지 상태를 가지는 미디어 요소로, 원본은 `audio` 와 `video` 를 든다.\
> 예: `<video controls>`.

## 어디서 틀리나

### 1. 재생 요소가 아닌 것에 붙인다
`div:paused` 처럼 재생 상태가 없는 요소에 붙이면 맞을 일이 없다.
원본 설명대로 `audio` · `video` 같은 재생 가능한 요소에 쓴다.

### 2. 전이를 상태 규칙에만 둔다
`transition` 을 `:paused` 규칙 안에만 적으면, 멈출 때는 그 규칙이 맞아 전이가 걸리지만 다시 재생할 때는 그 규칙이 풀리면서 전이도 함께 사라진다.
양쪽 방향을 다 부드럽게 하려면 원본처럼 기본 규칙에 둔다.

### 3. 숨기는 쪽으로 피드백을 준다
원본 팁의 피드백은 「오버레이 표시」나 「투명도 낮추기」다.
멈춘 영상은 여전히 보여야 다시 재생할 수 있으므로, 아예 숨기는 선언은 피드백이 아니라 기능을 망가뜨린다 (원본에 근거 없음 — 추론).

### 4. 기본 규칙과 상태 규칙의 다툼을 잊는다
상태 규칙에는 「달라질 부분」만 적는다.
원본도 `border` 전체가 아니라 `border-color` 만 바꿔서, 두께와 선 모양은 기본 규칙에서 그대로 물려받는다.

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `:paused` 는 재생 가능한 요소가 멈춰 있을 때 맞는다 | CSS 선택자 명세 (확인 필요 — 브라우저마다 지원 여부가 다를 수 있다) |
| 의사 클래스는 클래스와 같은 무게로 명시도에 더해진다 | CSS 명세 |
| `transition` 을 기본 규칙에 두면 양방향 전이가 된다 | CSS 명세 |
| 재생한 적 없는 영상도 처음부터 멈춤 상태로 본다 | 미디어 요소 명세의 초기 상태에 기댄 추론 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 영상이 멈췄음을 표시 | `video:paused` 에 투명도 · 테두리 색 | JS 로 클래스 토글(CSS 만으로 되는 일) |
| 상태 변화를 부드럽게 | 기본 규칙에 `transition` | `:paused` 규칙에만 `transition` |
| 재생 상태가 없는 요소 | 그 요소에 맞는 다른 선택자 | `div:paused` |
| 멈춘 영상을 알아보게 | 흐리게 · 오버레이 | `display: none` 으로 숨기기 |

## 핵심 문장

1. **`:paused` 는 `audio` · `video` 가 일시정지 상태일 때만 맞는 의사 클래스다.**
2. **상태가 바뀌면 규칙이 걸렸다 풀렸다 한다** — JS 없이 재생 상태를 따라간다.
3. **상태 규칙은 명시도가 더 높아 겹치는 속성을 이긴다** — 달라질 부분만 적는다.
4. **전이는 기본 규칙에 둔다** — 그래야 멈출 때와 다시 재생할 때 모두 부드럽다.
5. **피드백은 흐리게 · 오버레이로** — 숨기지 않는다.

## 용어 풀이

- **의사 클래스** — 요소의 상태로 고르는 선택자 조각(`:hover`, `:paused`).
- **일시정지 상태** — 미디어가 재생을 멈추고 있는 상태.
- **재생 가능한 요소** — 재생 · 멈춤 상태를 가지는 `audio` · `video`.
- **명시도** — 같은 속성을 다투는 규칙들 사이의 우선순위 무게.
- **전이(`transition`)** — 값 변화를 시간에 걸쳐 보여 주는 기능.
- **`opacity`** — 요소의 불투명도, 1 이 완전 불투명이고 0.7 은 70% 불투명.
- **오버레이** — 요소 위에 덮어 보이는 반투명한 층.

## 더 들어가면

- `:paused` 와 짝을 이루는 `:playing` 의사 클래스가 있고, 같은 무리에 미디어 상태를 고르는 다른 의사 클래스들도 있다고 알려져 있다 (확인 필요).
- 브라우저가 모르는 의사 클래스가 선택자에 들어 있으면 그 선택자 전체가 무효가 되어 규칙 하나가 통째로 버려진다. 지원하지 않는 브라우저에서는 `:paused` 규칙이 아무 효과 없이 무시될 것이다 (확인 필요).
- 원본 예제의 `<source src="">` 는 빈 경로라 실제로 재생할 파일이 없다. 재생 ↔ 멈춤을 눈으로 확인하려면 재생 가능한 파일 경로가 필요하다 (확인 필요).
