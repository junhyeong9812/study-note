## 퀴즈 정답

### 1. 두 `p` 만 강조된다 — `h3` 과 `span` 은 그대로다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
`형제 단락 1` 과 `형제 단락 2` 두 `p` 만 연보라 배경을 받는다. (코드에서 읽은 것 — 렌더 실측 아님)

**왜 그런가**
- 두 `p` 는 모두 `.gen-demo` 의 자식이고, 앞쪽 형제 중에 `h3` 이 있다.
- 사이에 낀 `span` 은 매칭을 막지 않는다 — `~` 는 바로 다음일 필요가 없다.
- `span` 은 `p` 가 아니라 대상이 아니고, `h3` 은 기준일 뿐 스타일을 받지 않는다.
- 근거: 2-summary 「동작 방식 (1)」.

### 2. `단락 0` 은 그대로, `단락 1` 만 보라색이다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
`단락 0` 은 기본 글자색 그대로이고, `단락 1` 만 보라색이다. (코드에서 읽은 것 — 렌더 실측 아님)

**왜 그런가**
- `~` 는 문서 순서상 뒤쪽만 본다.
- `단락 0` 은 `h3` 보다 앞에 있어서, 같은 부모의 형제여도 고르지 않는다.
- 근거: 2-summary 「동작 방식 (2)」, 「어디서 틀리나 1」.

### 3. `바깥 단락` 만 보라색이다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
`바깥 단락` 만 보라색이 되고, `안쪽 단락` 은 그대로다. (코드에서 읽은 것 — 렌더 실측 아님)

**왜 그런가**
- `안쪽 단락` 의 부모는 `section` 이라 `h3` 의 형제가 아니다 — 형제의 자식일 뿐이다.
- `section` 은 `h3` 뒤의 형제지만 `p` 가 아니라 대상이 아니다.
- `바깥 단락` 은 `h3` 과 같은 부모 아래, `h3` 뒤에 있으므로 맞는다.
- 근거: 2-summary 「동작 방식 (2)」, 「어디서 틀리나 4」.

### 4. `~` 는 기준보다 뒤쪽 형제만 고르기 때문이다

`input:checked ~ .panel` 은 「앞쪽 형제 중에 체크된 `input` 이 있는 `.panel`」을 고른다.
`input` 이 `.panel` 보다 뒤에 있으면, `.panel` 의 앞쪽 형제 중에 `input` 이 없으므로 체크 여부와 상관없이 규칙이 맞지 않는다.
같은 까닭으로 `input` 과 `.panel` 은 같은 부모 아래 있어야 한다.
근거: 2-summary 「동작 방식 (3)」, 「어디서 틀리나 5」.

### 5. 명시도가 더 높기 때문이다 — `~` 자체는 0점이다

`.gen-demo p` 는 클래스 1 · 태그 1 로 (0,1,1) 이다.
`.gen-demo h3 ~ p` 는 클래스 1 · 태그 2 로 (0,1,2) 다 — 태그 `h3` 하나가 더 있다.
결합자 `~` 는 점수를 더하지 않으므로, 차이는 오직 `h3` 에서 나온다.
점수가 높은 쪽이 이기므로 `color` 는 `h3 ~ p` 쪽 값이 된다(게다가 이 규칙은 뒤에 적혀 있어 점수가 같았어도 이겼다).
근거: 2-summary 「동작 방식 (4)」.

### 6. 둘 다 선택되지 않는다

`h3` 은 `~` 왼쪽, 즉 조건일 뿐이고 스타일을 받는 것은 오른쪽 `p` 뿐이다.
다른 `div` 안의 `p` 는 부모가 달라 `h3` 의 형제가 아니므로 앞뒤와 상관없이 고르지 않는다.
근거: 2-summary 「동작 방식 (1)」 · 「동작 방식 (2)」, 「어디서 틀리나 3」.

### 7. `+` 로 바꾸면 아무 단락도 강조되지 않는다 — `+` 는 `~` 의 「바로 다음 하나」판이다

원본 예제에서 `h3` 바로 다음 형제는 `span` 이다.
`h3 + p` 는 「`h3` 바로 다음 형제가 `p` 일 때 그 하나」만 고르므로 맞는 요소가 없다.
`~` 는 뒤의 모든 형제를 보고, `+` 는 바로 다음 하나만 본다 — 둘 다 같은 부모의 뒤쪽 형제만 본다는 점은 같다.
근거: 2-summary 「문법 — 형태와 규칙」 결합자 표, 「어디서 틀리나 2」.

### 8. 공백은 「안에 들어 있나(조상-자손)」, `~` 는 「같은 부모 아래 뒤에 있나(형제)」를 본다

`.gen-demo p` 는 `.gen-demo` 안의 모든 깊이의 `p` 를 고른다 — 원본 예제에서는 두 단락 모두다.
`.gen-demo h3 ~ p` 는 그중에서도 `h3` 의 뒤쪽 형제인 `p` 만 고른다.
원본 예제에서는 고르는 요소가 같지만, `h3` 앞에 `p` 가 있거나 `p` 가 더 깊이 들어 있으면 둘의 결과가 갈린다.
근거: 2-summary 「문법 — 형태와 규칙」 결합자 표, 「동작 방식 (2)」.

## 실습 정답

### 실습 1. 제목 뒤의 형제 단락만 강조하기

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 1. `h3` → `span` → `p` → `p` 순서의 형제 | `<div class="gen-demo">` 안의 `<h3>` · `<span>` · `<p>형제 단락 1</p>` · `<p>형제 단락 2</p>` |
| 2. 기본 꾸밈 규칙 유지, `span` 은 블록 | `.gen-demo h3 { … }` · `.gen-demo span { display: block; … }` · `.gen-demo p { … }` |
| 3. `h3` 뒤의 모든 형제 `p` 를 고르는 선택자 | `.gen-demo h3 ~ p` |
| 4. 두 단락에만 강조 배경 · 글자색 | `.gen-demo h3 ~ p { background: …; color: …; }` |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/selectors/reference/combinator-general-sibling.html`

```html
<!DOCTYPE html>
<!-- 문서 타입 선언: HTML5 -->
<html lang="ko">
<head>
<meta charset="utf-8">
<title>~ 일반 형제 결합자 - 첫 번째 요소 이후의 모든 형제 요소를 선택한다 (바로 다음이 아니어도 됨).</title>
<!--
  [선택자] ~ 일반 형제 결합자
  설명: 첫 번째 요소 이후의 모든 형제 요소를 선택한다 (바로 다음이 아니어도 됨).
  구문: A ~ B { }
  팁: CSS-only 인터랙션에서 ~ 결합자를 활용하면 체크박스 상태에 따라 떨어져 있는 형제 요소를 스타일링할 수 있다.
-->
<style>
  /* .gen-demo h3: .gen-demo의 자손인 h3 매칭 */
  .gen-demo h3 {
    margin: 0 0 4px;             /* 아래만 4px 마진 */
    color: #1f2937;              /* 진한 회색 텍스트 */
  }
  /* .gen-demo span: .gen-demo의 자손인 span 매칭 */
  .gen-demo span {
    display: block;              /* 블록 형태로 표시 */
    padding: 4px 8px;            /* 안쪽 여백 위아래 4, 좌우 8 */
    color: #6b7280;              /* 회색 텍스트 */
  }
  /* .gen-demo p: .gen-demo의 자손인 p 매칭 */
  .gen-demo p {
    margin: 4px 0;               /* 위아래 4px 마진 */
    padding: 8px;                /* 안쪽 여백 8px */
    border-radius: 4px;          /* 4px 둥근 모서리 */
  }
  /* .gen-demo h3 ~ p: .gen-demo 안에서 h3 이후에 오는 모든 형제 p 매칭 (인접하지 않아도 됨) */
  .gen-demo h3 ~ p {
    background: #ede9fe;         /* 연보라 배경 */
    color: #5b21b6;              /* 보라색 텍스트 */
  }
</style>
</head>
<body>
  <div class="gen-demo">
    <!-- 제목 -->
    <h3>제목</h3>
    <!-- 중간에 끼어있는 span (형제) -->
    <span>중간 요소</span>
    <!-- h3 이후 형제 p (강조) -->
    <p>형제 단락 1</p>
    <!-- h3 이후 형제 p (강조) -->
    <p>형제 단락 2</p>
  </div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.gen-demo h3 { margin: 0 0 4px; color: #1f2937; }
.gen-demo span { display: block; padding: 4px 8px; color: #6b7280; }
.gen-demo p { margin: 4px 0; padding: 8px; border-radius: 4px; }
.gen-demo h3 ~ p { background: #ede9fe; color: #5b21b6; }
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- 핵심은 선택자 한 줄 `.gen-demo h3 ~ p` 다 — 스타일을 받는 것은 `~` 오른쪽 `p` 뿐이다.
- 사이에 `span` 이 끼어 있어도 `~` 는 뒤의 모든 형제 `p` 를 고른다(`+` 였다면 하나도 못 고른다).
- `h3` 과 `span` 은 강조 규칙의 대상이 아니라 자기 기본 규칙의 색을 그대로 쓴다.
- 강조 규칙의 명시도 (0,1,2) 가 `.gen-demo p` 의 (0,1,1) 보다 높아 `color` 다툼에서 이긴다.
- 단락을 `h3` 위로 옮기면 그 단락은 「앞쪽 형제」가 되어 강조가 빠진다 — `~` 는 뒤쪽만 본다.
