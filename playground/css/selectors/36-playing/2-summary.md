## 한눈에 — 쉽게 말하면

**`:playing` 은 「방송 중」 빨간 불이다.**
녹음실 문 위의 「ON AIR」 등은 방송이 나가는 동안에만 켜지고, 방송이 멈추면 꺼진다.
누가 손으로 켜고 끄는 게 아니라, 방송 상태가 곧 불의 상태다.
`:playing` 도 똑같은 구조다.
`<video>` · `<audio>` 가 재생 중일 때만 이 선택자에 걸린 스타일이 켜지고, 멈추면 꺼진다.

> **의사 클래스(pseudo-class)** — 요소의 이름이나 속성이 아니라 「지금 어떤 상태인가」로 요소를 고르는 선택자 꼴이다.\
> 예: `:hover` 는 마우스가 올라간 상태, `:playing` 은 미디어가 재생 중인 상태를 고른다.

| 비유 | 실체 |
|---|---|
| 녹음실 | `<video>` · `<audio>` 요소 |
| 방송이 나가는 중 | 미디어가 재생 중인 상태 |
| ON AIR 등 | `.player:playing { … }` 에 적은 스타일 |
| 방송이 멈춤 | 일시정지 상태(`:paused` 의 몫) |

```text
  [▶ 재생]           [⏸ 일시정지]
     │                    │
     ▼                    ▼
 ┌─────────┐         ┌─────────┐
 │ 재생 중  │ ──────▶ │ 멈춤     │
 │ :playing │ ◀────── │ :paused  │
 └─────────┘         └─────────┘
  녹색 테두리           회색 테두리
```

## 이 주제가 답하려는 질문

1. 미디어가 「지금 재생 중이다」라는 상태를 CSS 만으로 어떻게 고르나?
2. 재생이 시작되고 멈출 때 스타일은 언제 켜지고 꺼지나?
3. 어떤 요소에 붙여야 뜻이 있고, 어떤 조건에서는 아예 걸리지 않나?
4. `:paused` 와 함께 쓰면 무엇을 만들 수 있나?

## 동작 방식

### (1) 재생이 시작되면 스타일이 켜진다

**언제 쓰나** — 재생 중인 플레이어만 눈에 띄게(테두리 · 후광 등) 표시하고 싶을 때.

```text
입력 코드
  .player         { border: 3px solid #d1d5db; }
  .player:playing { border-color: #22c55e; }

무엇이 일어나나
  ① 처음: 재생 전 → :playing 에 안 걸림 → .player 규칙만 적용
  ② 사용자가 재생 버튼을 누름 → 미디어가 재생 중이 됨
  ③ 브라우저가 상태를 다시 판단 → .player:playing 이 걸림
  ④ border-color 가 #22c55e 로 덮어써짐

결과
  재생 전: 회색 테두리 → 재생 중: 녹색 테두리
```

① 페이지를 막 열었을 때 비디오는 재생 전이라 `.player` 의 회색 테두리만 보인다.
② 재생은 사용자의 조작(여기서는 `controls` 의 재생 버튼)으로 시작된다.
③ 재생이 시작되면 그 요소가 `:playing` 상태가 되어 두 번째 규칙이 걸린다.
④ 두 번째 규칙은 `border-color` 만 바꾸므로 두께 · 선 모양 · 둥근 모서리는 첫 규칙 그대로 남는다.

> **`controls` 속성** — `<video>` · `<audio>` 에 브라우저 기본 재생 막대(재생 · 일시정지 · 시간 표시)를 붙이는 불리언 속성이다.\
> 예: `<video controls>` 라고만 쓰면 재생 버튼이 화면에 생긴다.

### (2) 멈추면 스타일이 꺼진다

**언제 쓰나** — 재생 상태가 바뀔 때마다 표시가 따라 바뀌어야 할 때.

```text
입력 코드
  (1) 과 같은 두 규칙

무엇이 일어나나
  ① 재생 중 → :playing 걸림 (녹색)
  ② 사용자가 일시정지 → 재생 중이 아님
  ③ :playing 이 풀림 → .player 규칙만 남음

결과
  녹색 → 회색으로 돌아간다
```

① 재생 중에는 녹색 규칙이 걸려 있다.
② 일시정지를 누르면 상태가 「재생 중」에서 벗어난다.
③ 의사 클래스는 상태가 사라지면 같이 풀리므로, 따로 「되돌리는」 코드를 쓰지 않아도 원래 스타일로 돌아간다.

### (3) `transition` 이 걸린 속성만 서서히 바뀐다

**언제 쓰나** — 상태 전환을 부드럽게 보이고 싶을 때.

```text
입력 코드
  .player         { transition: border-color 0.3s; }
  .player:playing { border-color: #22c55e;
                    box-shadow: 0 0 12px rgba(34,197,94,0.3); }

무엇이 일어나나
  ① :playing 이 걸림 → 두 속성 값이 바뀌어야 함
  ② border-color 는 transition 목록에 있음 → 0.3초에 걸쳐 바뀜
  ③ box-shadow 는 목록에 없음 → 그 자리에서 바로 바뀜

결과
  테두리는 서서히 녹색으로, 후광은 즉시 나타난다
```

① 상태가 바뀌면 두 속성의 값이 한꺼번에 바뀌어야 한다.
② `transition` 에 이름이 적힌 `border-color` 만 시간을 두고 바뀐다.
③ `box-shadow` 는 목록에 없으니 전이 없이 바로 켜지고, 멈출 때도 바로 꺼진다.

> **`transition`** — 속성 값이 바뀔 때 정해진 시간 동안 중간값을 거쳐 바뀌게 하는 속성이다.\
> 예: `transition: border-color 0.3s;` 는 테두리 색만 0.3초에 걸쳐 바뀌게 한다.

```html demo
<video class="player" controls width="280">
  <source src="" type="video/mp4" />
  Your browser does not support video.
</video>
<style>
  .player { border-radius: 12px; border: 3px solid #d1d5db; transition: border-color 0.3s; }
  .player:playing { border-color: #22c55e; box-shadow: 0 0 12px rgba(34,197,94,0.3); }
</style>
```

> **보이는 것** — 회색 테두리에 모서리가 둥근 280 너비의 비디오 틀과 재생 막대가 보인다. `src` 가 비어 있어 재생되지 않으므로 녹색 테두리는 나타나지 않는다. (코드에서 읽은 것 — 렌더 실측 아님)

## 문법 — 형태와 규칙

```css
/* 기본 상태 */
audio, video {
  outline: 2px solid gray;
}

/* 재생 중일 때만 */
audio:playing,
video:playing {
  outline-color: green;
}
```

- 꼴은 `selector:playing { }` 다.
- 앞의 `selector` 는 재생 가능한 요소, 곧 `<audio>` · `<video>` 를 가리켜야 뜻이 있다.
- 클래스와 붙여 `.player:playing` 처럼 특정 플레이어만 고를 수 있다.
- 기본 규칙과 `:playing` 규칙을 나눠 쓰고, `:playing` 쪽에는 **바뀌는 속성만** 적는다.
- 반대 상태인 일시정지는 `:paused` 로 고른다.

| 선택자 | 걸리는 때 |
|---|---|
| `video:playing` | 비디오가 재생 중일 때 |
| `video:paused` | 비디오가 일시정지 상태일 때 |
| `.player:playing` | `class="player"` 인 미디어가 재생 중일 때 |

## 어디서 틀리나

### 1. `:playing` 만 쓰고 `:paused` 는 잊는다

원본 팁은 「`:playing` 과 `:paused` 를 함께 쓰면 미디어 플레이어의 상태에 따라 커스텀 UI 를 CSS 로 만들 수 있다」이다.
재생 중 표시만 만들고 멈춘 상태의 표시를 따로 설계하지 않으면, 「멈춤」을 보여 줄 수단이 기본 스타일뿐이다.
두 상태를 짝으로 생각하고 규칙을 나눠 두면 상태별 UI 를 JS 없이 꾸밀 수 있다.

### 2. 미디어가 아닌 요소에 붙인다

`div:playing` 처럼 재생할 수 없는 요소에 붙이면 「재생 중」이라는 상태 자체가 없으므로 걸리지 않는다.
재생 상태는 `<audio>` · `<video>` 의 것이다.

### 3. 소스가 비어 있으면 영영 걸리지 않는다

원본 예제의 `<source src="" …>` 는 주소가 비어 있다.
불러올 미디어가 없으니 재생 버튼을 눌러도 재생이 시작되지 않고, 따라서 `:playing` 도 걸리지 않는다.
녹색 테두리를 직접 보려면 `src` 에 실제 영상 파일 경로를 넣어야 한다.

### 4. 재생 수단이 없다

`controls` 를 빼면 화면에 재생 버튼이 생기지 않는다.
사용자가 재생을 시작할 방법이 없으면 `:playing` 을 눈으로 확인할 기회도 없다.

### 5. 전이가 일부 속성에만 걸린다

`transition: border-color 0.3s` 는 테두리 색에만 시간을 준다.
`box-shadow` 도 부드럽게 바꾸고 싶다면 그 속성도 `transition` 에 넣어야 한다.
원본은 그러지 않았으므로 후광은 즉시 켜지고 꺼진다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `:playing` 은 재생 중인 `<audio>` · `<video>` 를 고른다 | CSS 선택자 명세의 정의 (명세 단계와 세부 조건은 확인 필요) |
| `:playing` 이 실제로 지원되는가 | 브라우저마다 다르다 — 지원 범위는 확인 필요 |
| 상태가 풀리면 스타일이 저절로 되돌아간다 | 의사 클래스 일반의 동작 (CSS 가 보장) |
| `transition` 목록의 속성만 전이된다 | CSS Transitions 의 규칙 |
| 재생 막대의 생김새 | 브라우저 구현마다 다르다 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 재생 중인 플레이어를 강조 | `.player:playing` | 재생 이벤트마다 JS 로 클래스 붙였다 떼기 |
| 멈춘 상태도 따로 꾸밈 | `:paused` 와 짝으로 | `:playing` 하나로 두 상태 처리 |
| 재생 상태에 따라 계산 · 저장이 필요 | JS 의 미디어 이벤트 | CSS 선택자만으로 해결 시도 |
| 미디어가 아닌 요소의 상태 | 그 요소에 맞는 의사 클래스(`:hover` 등) | `:playing` |

## 핵심 문장

1. **`:playing` 은 `<audio>` · `<video>` 가 재생 중인 동안에만 걸리는 의사 클래스다.**
2. **재생이 멈추면 저절로 풀려 기본 스타일로 돌아간다** — 되돌리는 코드가 필요 없다.
3. **`:paused` 와 짝으로 쓰면 플레이어 상태별 UI 를 CSS 만으로 만든다.**
4. **불러올 미디어나 재생 수단이 없으면 `:playing` 은 영영 걸리지 않는다.**
5. **부드러운 전환은 `transition` 에 적힌 속성에만 생긴다.**

## 용어 풀이

- **의사 클래스** — 요소의 상태로 요소를 고르는 선택자 꼴(`:hover` · `:playing`).
- **미디어 요소** — 소리나 영상을 재생하는 `<audio>` · `<video>`.
- **`:paused`** — 미디어가 일시정지 상태일 때 걸리는 의사 클래스.
- **`controls`** — 브라우저 기본 재생 막대를 붙이는 속성.
- **`<source>`** — 미디어 요소 안에서 재생할 파일 주소(`src`)와 형식(`type`)을 적는 요소.
- **대체 내용(fallback)** — 브라우저가 `<video>` 를 지원하지 않을 때 대신 보이는 안쪽 글(`Your browser does not support video.`).
- **`transition`** — 속성 값이 바뀔 때 시간을 두고 바뀌게 하는 속성.
- **`box-shadow`** — 요소 둘레에 그림자를 그리는 속성. 흐림 값만 주면 후광처럼 보인다.
- **`rgba()`** — 빨강 · 초록 · 파랑과 투명도로 색을 적는 꼴.

## 더 들어가면

- `:playing` · `:paused` 는 Selectors Level 4 의 「리소스 상태 의사 클래스」 묶음에 속한다고 알려져 있다 (확인 필요).
- 같은 묶음에 `:seeking` · `:buffering` · `:stalled` · `:muted` · `:volume-locked` 같은 상태가 있다고 한다 (확인 필요).
- 명세상 「재생 중」은 「일시정지가 아님」을 뜻해서, 버퍼링으로 화면이 멈춰 있는 동안에도 `:playing` 이 걸린 채일 수 있다고 한다 (확인 필요).
- 이 의사 클래스들은 비교적 최근에 브라우저에 들어오기 시작해 지원이 고르지 않다 — 지원하지 않는 브라우저에서는 규칙 전체가 무시되므로 JS 의 `play` · `pause` 이벤트로 클래스를 붙이는 대안을 함께 두는 경우가 있다 (확인 필요).
