## 퀴즈 정답

### 1. 두 p 가 모두 꾸며진다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
직접 자식 `p` 와 손자 `p` 둘 다 파란 글자·연한 파란 배경이 붙는다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
자손 결합자는 깊이를 묻지 않는다.
직접 자식 `p` 는 위로 한 칸, 손자 `p` 는 위로 두 칸에 `.parent-d` 가 있어 둘 다 조건을 채운다.
근거: 2-summary 「동작 방식 (2)」.

### 2. 직접 자식 p 만 꾸며진다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
「직접 자식 p」만 꾸며지고 「손자 p」는 꾸밈 없이 남는다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
`>` 는 바로 위 부모 하나만 본다.
손자 `p` 의 부모는 중간 `div` 라서 조건을 채우지 못한다.
근거: 2-summary 「동작 방식 (3)」.

### 3. 가만 p 를 고른다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
가(`.parent-d p`)만 두 `p` 를 고른다.
나와 다는 1번 HTML 에서 아무 요소도 고르지 않는다.

**왜 그런가**
- 가: 공백이 자손 결합자라 「`.parent-d` 안의 `p`」다.
- 나: 공백이 없어 「클래스 `parent-d` 와 `p` 를 함께 가진 한 요소」다 — 그런 요소가 없다.
- 다: 순서가 뒤집혀 「`p` 안에 있는 `.parent-d`」다 — `p` 안에 `.parent-d` 가 없다.

근거: 2-summary 「문법 — 형태와 규칙」의 표, 「어디서 틀리나 2」.

### 4. 부모만이 아니라 조상 전체를 보기 때문이다

자손 결합자는 `p` 의 부모 하나가 아니라 위쪽 조상을 문서 맨 위까지 거슬러 보며, 그 가운데 하나라도 `.parent-d` 면 매칭한다.
손자 `p` 는 부모가 `div` 지만 그 위가 `.parent-d` 라서 조건을 채운다.
근거: 2-summary 「동작 방식 (1)」·「동작 방식 (2)」.

### 5. 바깥 p 는 안 되고, 열 겹이어도 결과는 같다

- `.parent-d` 바깥의 `p` 는 조상 가운데 `.parent-d` 가 없으므로 매칭되지 않는다.
- 감싸는 층이 열 겹이어도 위쪽 어딘가에 `.parent-d` 가 있으면 매칭된다 — 깊이는 따지지 않는다.

근거: 2-summary 「동작 방식 (1)」, 「동작 방식 (2)」의 마지막 해설.

### 6. 바뀌지 않는다 — 꾸밈 대상은 맨 오른쪽 p 다

`.parent-d p` 의 선언은 맨 오른쪽 `p` 에 붙는다.
`.parent-d` 는 「이 안에 있어야 한다」는 조건일 뿐이라, 상자 자신의 배경은 따로 `.parent-d { }` 규칙으로 준다.
근거: 2-summary 「동작 방식 (1)」, 「어디서 틀리나 3」.

### 7. 배경과 여백은 상속되지 않기 때문이다

`color` 는 상속되어 부모에 준 값이 안쪽 `p` 로 내려간다.
`background` · `padding` 은 상속되지 않아 `.parent-d` 에 주면 `.parent-d` 에만 붙는다.
`p` 마다 배경과 여백을 주려면 `p` 를 직접 고르는 `.parent-d p` 가 필요하다.
근거: 2-summary 「어디서 틀리나 4」, 「언제 쓰고 언제 안 쓰나」 표.

### 8. `>` 를 고른다

공백은 나중에 끼워진 부품 속 `p` 까지 모든 깊이로 번진다.
「카드 바로 아래 `p`」로 범위가 정해져 있으면 바로 위 부모만 보는 `>` 가 원하지 않는 곳을 건드리지 않는다.
근거: 2-summary 「어디서 틀리나 5」, 「언제 쓰고 언제 안 쓰나」 표.

## 실습 정답

### 실습 1. 회색 상자 안의 모든 p 를 깊이 상관없이 강조하기

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 1. 클래스 `parent-d` 를 가진 `div` | `<div class="parent-d">` |
| 2. 직접 자식 `p` | `.parent-d` 바로 아래의 `<p>직접 자식 p</p>` |
| 3. 중간 `div` 안의 손자 `p` | `<div><p>손자 p</p></div>` |
| 4. 바깥 상자 꾸밈 | `.parent-d { padding; background; border-radius }` 규칙 |
| 5. 모든 깊이의 `p` 를 고르는 선택자 | `.parent-d p` (공백 = 자손 결합자) |
| 6. 규칙 하나로 두 `p` 모두 강조 | `.parent-d p { color; font-weight; … }` 한 규칙 |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/selectors/reference/combinator-descendant.html`

```html
<!DOCTYPE html>
<!-- 문서 타입 선언: HTML5 -->
<html lang="ko">
<head>
<meta charset="utf-8">
<title>(공백) 자손 결합자 - 첫 번째 요소의 자손(모든 깊이)인 두 번째 요소를 선택한다.</title>
<!--
  [선택자] (공백) 자손 결합자
  설명: 첫 번째 요소의 자손(모든 깊이)인 두 번째 요소를 선택한다.
  구문: A B { }
  팁: 자손 결합자는 모든 깊이의 자손을 선택한다. 직접 자식만 선택하려면 > (자식 결합자)를 사용하자.
-->
<style>
  /* .parent-d: class 속성에 parent-d를 가진 요소 매칭 */
  .parent-d {
    padding: 16px;               /* 안쪽 여백 16px */
    background: #f3f4f6;         /* 회색 배경 */
    border-radius: 8px;          /* 8px 둥근 모서리 */
  }
  /* .parent-d p: .parent-d의 모든 깊이의 자손 p 매칭 (직계 자식 + 손자 모두) */
  .parent-d p {
    color: #2563eb;              /* 파란색 텍스트 */
    font-weight: bold;           /* 굵게 */
    padding: 8px;                /* 안쪽 여백 8px */
    margin: 4px 0;               /* 위아래 4px 마진 */
    background: #dbeafe;         /* 연한 파란 배경 */
    border-radius: 4px;          /* 4px 둥근 모서리 */
  }
</style>
</head>
<body>
  <div class="parent-d">
    <!-- 직접 자식 p (자손에 포함됨) -->
    <p>직접 자식 p</p>
    <!-- 중간 div -->
    <div>
      <!-- 손자 p (자손에 포함됨) -->
      <p>손자 p</p>
    </div>
  </div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.parent-d { padding: 16px; background: #f3f4f6; border-radius: 8px; }
.parent-d p { color: #2563eb; font-weight: bold; padding: 8px; margin: 4px 0; background: #dbeafe; border-radius: 4px; }
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- 핵심은 선택자 한 줄 `.parent-d p` 다 — 두 선택자 사이의 공백이 결합자다.
- 손자 `p` 는 부모가 중간 `div` 지만 조상 가운데 `.parent-d` 가 있어 함께 강조된다.
- 선택자를 `.parent-d > p` 로 바꾸면 손자 `p` 의 강조가 빠진다 — 공백과 `>` 의 차이가 여기서 드러난다.
- 상자 자신의 꾸밈은 `.parent-d` 규칙이, `p` 의 꾸밈은 `.parent-d p` 규칙이 따로 맡는다.
- 배경·여백은 상속되지 않으므로 `p` 를 직접 고르는 규칙이 있어야 `p` 마다 붙는다.
