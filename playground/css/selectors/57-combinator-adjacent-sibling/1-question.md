## 실습

### 실습 1. 제목 바로 다음 단락만 강조하기

**만들 것** — 제목 하나와 단락 둘이 든 상자에서, 제목 바로 다음 단락에만 강조 모양을 입힌다.

**요구 조건**
1. `.adj-demo` 상자 안에 `h3` 제목 하나, 그 뒤에 `p` 단락 둘을 차례로 둔다.
2. 상자 안의 `h3` 에는 기본 제목 스타일(여백 · 글자색)을 준다.
3. 상자 안의 모든 `p` 에는 공통 단락 스타일(여백 · 안쪽 여백 · 둥근 모서리)을 준다.
4. 인접 형제 결합자를 써서, 상자 안 `h3` 바로 다음에 오는 `p` 하나에만 배경 · 굵은 글씨 · 글자색 강조를 준다.
5. 두 번째 단락은 강조를 받지 않고 공통 단락 스타일만 받는다.

**시작 코드**

```html
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>+ 인접 형제 결합자</title>
<style>
  .adj-demo h3 {
    margin: 0 0 4px;
    color: #1f2937;
  }
  .adj-demo p {
    margin: 4px 0;
    padding: 8px;
    border-radius: 4px;
  }
  /* TODO: .adj-demo 안에서 h3 바로 다음에 오는 p 하나만 고르는 선택자를 쓴다 */
  /* 선택자 */ {
    background: #fef3c7;
    font-weight: bold;
    color: #92400e;
  }
</style>
</head>
<body>
  <div class="adj-demo">
    <!-- TODO: 제목 h3 하나, 그 뒤에 단락 p 둘을 차례로 넣는다 -->
  </div>
</body>
</html>
```

**확인 방법** — 브라우저로 열어 제목 바로 아래 첫 단락만 노란 배경 · 굵은 갈색 글씨이고 두 번째 단락은 평범한지 본다. 제목과 첫 단락 사이에 `<hr>` 을 넣어 강조가 사라지는지도 본다.
