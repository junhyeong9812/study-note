## 한눈에 — 쉽게 말하면

**`||` 열 결합자는 「출석부에서 세로 한 줄(같은 날짜 칸)을 통째로 집는 손가락」이다.**
출석부는 학생마다 가로줄로 적혀 있다.
그래서 「3일차 칸만 전부」를 집으려면 가로줄을 따라가서는 안 되고, 세로 격자를 봐야 한다.
HTML 표도 똑같은 구조다.
셀(`td`)은 행(`tr`) 안에 가로로 들어 있고, 열은 `<colgroup>` 안의 `<col>` 로 따로 정의된다.
`col || td` 는 그 `<col>` 이 나타내는 세로줄에 놓인 셀을 고르는 선택자다.

| 비유 | 실체 |
|---|---|
| 출석부의 가로줄(학생 한 명) | `<tr>` 한 행 |
| 칸 하나 | `<td>` 셀 |
| 머리말에 적힌 날짜 하나 | `<col>` 한 열 정의 |
| 세로 한 줄을 집는 손가락 | `col \|\| td` |

```text
         col(1)   col(2)
          │        │
 tr ─→  [A1]     [B1]
 tr ─→  [A2]     [B2]
          ↑
   col(1) || td  → A1, A2
```

## 이 주제가 답하려는 질문

1. 표의 「어떤 열에 속한 셀」을 CSS 로 어떻게 고르나?
2. 왜 보통의 자손 결합자(공백)로는 열의 셀을 고를 수 없나?
3. `||` 를 쓸 수 없는 지금, 열을 꾸미려면 무엇을 쓰나?
4. 지원하지 않는 브라우저에서 `||` 를 쓴 규칙은 어떻게 되나?

## 동작 방식

### (1) 표는 「행 트리」와 「열 정의」가 따로 있다

**언제 쓰나** — 열 단위로 꾸미고 싶을 때, 먼저 표의 문서 구조를 알아야 한다.

```text
<table>
 ├─ <colgroup>
 │    ├─ <col class="highlight-col">   ← 1열 정의
 │    └─ <col>                         ← 2열 정의
 ├─ <tr> ─ <td>A1</td> <td>B1</td>
 └─ <tr> ─ <td>A2</td> <td>B2</td>
```

- `<td>` 의 부모는 `<tr>` 이다.
- `<col>` 은 `<colgroup>` 안에 있고 `<td>` 를 자식으로 갖지 않는다.
- 그래서 문서 트리에서 `<col>` 과 `<td>` 는 조상·자손 사이가 아니다.
- 둘을 잇는 것은 트리가 아니라 「같은 세로 위치에 놓인다」는 표 격자의 관계다.

> **결합자** — 두 선택자 사이에 놓여 두 요소의 관계를 정하는 기호다.\
> 예: 공백(자손), `>`(자식), `+`(바로 다음 형제), `||`(열).

### (2) `||` 는 격자 관계로 고른다

**언제 쓰나** — 「이 `<col>` 이 나타내는 열의 셀」을 고르고 싶을 때다.

```text
col.highlight-col || td { … }
   │                  │
   │                  └─ 고를 대상: 셀
   └─ 기준: 1열 정의
        ↓
   1열에 놓인 td → A1, A2 에 규칙 적용
```

- 왼쪽 선택자는 열을 정의하는 요소(`col`)를 가리킨다.
- 오른쪽 선택자는 셀(`td`)을 가리킨다.
- 결과는 오른쪽의 셀 중 왼쪽 열에 속한 것이다.
- 다른 결합자는 문서 트리를 따라가지만, `||` 는 표의 세로줄을 따라간다는 점이 다르다.

> **열 결합자** — `A || B` 꼴로, A 가 나타내는 표 열에 속한 B 를 고르는 결합자다.\
> 예: `col.price || td` 는 가격 열의 셀만 고른다.

원본은 이 기능을 「실험적 기능, 브라우저 지원 제한적」이라고 적는다.
팁은 「아직 실험적 기능이며 브라우저 지원이 거의 없다」고 한다.

> **실험적 기능** — 명세에 제안은 되었지만 브라우저가 아직 널리 구현하지 않은 기능이다.\
> 예: 열 결합자 `||`.

### (3) 지금 쓰는 방법 — `<col>` 에 클래스를 단다

**언제 쓰나** — 실제 페이지에서 열 하나를 강조하고 싶을 때다(원본 팁이 권하는 방법).

```text
<col class="highlight-col" />
.col-demo .highlight-col { background: … }
        ↓
매칭되는 것은 col 요소 자신 (td 가 아니다)
        ↓
col 의 배경이 그 열의 셀 뒤에 깔려 → A1, A2 가 강조된 듯 보인다
```

- `.col-demo .highlight-col` 은 자손 결합자다 — 표 안에 있는 `highlight-col` 클래스 요소, 곧 `<col>` 을 고른다.
- 셀을 고른 것이 아니라 열 정의 요소에 배경을 준 것이다.
- 그 배경이 그 열에 놓인 셀 아래로 비쳐서, 화면에는 1열 셀이 칠해진 것처럼 보인다.

```html demo
<table style="border-collapse: collapse; width: 200px;">
  <colgroup>
    <col style="background: #dbeafe;" />
    <col />
  </colgroup>
  <tr><td style="padding: 10px; border: 1px solid #e5e7eb; text-align: center;">A1</td><td style="padding: 10px; border: 1px solid #e5e7eb; text-align: center;">B1</td></tr>
  <tr><td style="padding: 10px; border: 1px solid #e5e7eb; text-align: center;">A2</td><td style="padding: 10px; border: 1px solid #e5e7eb; text-align: center;">B2</td></tr>
</table>
```

> **보이는 것** — 2×2 표에서 A1 · A2 가 있는 왼쪽 열만 연한 파란 배경이고 B 열은 배경이 없다 (코드에서 읽은 것 — 렌더 실측 아님)

### (4) 지원하지 않는 브라우저는 규칙을 통째로 버린다

**언제 쓰나** — `||` 를 시험 삼아 써 볼 때 반드시 알아야 한다.

```text
col.x || td, .note { color: red; }
        ↓
브라우저가 || 를 모른다 → 선택자 목록 전체가 무효
        ↓
규칙 전체를 버림 → .note 에도 적용되지 않는다
```

- CSS 는 선택자를 해석하지 못하면 그 규칙 하나를 통째로 버린다.
- 쉼표로 묶은 선택자 목록에서 하나만 무효여도 목록 전체가 무효가 된다.
- 그래서 `||` 는 다른 선택자와 쉼표로 묶지 말고 따로 규칙을 써야 한다.

## 문법 — 형태와 규칙

```html
<table class="t">
  <colgroup>
    <col class="name" />
    <col class="price" />
  </colgroup>
  <tr><td>사과</td><td>1000</td></tr>
  <tr><td>배</td><td>2000</td></tr>
</table>
<style>
  /* 지금 쓰는 방법: col 자체를 꾸민다 */
  .t .price { background: #fef3c7; }
  /* 실험적 방법: 가격 열의 셀을 고른다 (지원이 거의 없다) */
  col.price || td { text-align: right; }
</style>
```

- 꼴: `열선택자 || 셀선택자 { }` — 원본 문법은 `col || td { }` 다.
- 왼쪽은 열을 정의하는 요소(보통 `col`), 오른쪽은 셀(보통 `td`)이다.
- `||` 를 쓴 규칙은 다른 선택자와 쉼표로 묶지 않는다(4절).
- 실사용은 `<colgroup>` 안 `<col>` 에 클래스를 달고 그 클래스를 꾸민다.
- `.col-demo .highlight-col` 처럼 쓰면 매칭 대상은 `<col>` 이다 — `<td>` 가 아니다.

## 어디서 틀리나

### 1. `||` 를 그냥 써 버린다

원본 팁: 열 결합자는 아직 실험적이고 브라우저 지원이 거의 없다.
지원하지 않는 브라우저에서는 규칙이 무시된다.
지금은 `<col>` 요소에 클래스를 적용하는 방식을 쓴다.

### 2. 자손 결합자로 열의 셀을 고르려 한다

`col.x td` 는 「`col.x` 안에 든 `td`」를 찾는다.
`<td>` 는 `<col>` 안에 들어 있지 않으므로 아무것도 고르지 못한다.

### 3. `<col>` 의 스타일이 셀로 상속된다고 믿는다

상속은 문서 트리의 부모 → 자식으로 흐른다.
`<td>` 의 부모는 `<tr>` 이지 `<col>` 이 아니다.
그래서 `<col>` 에 `color` 를 줘도 셀 글자색으로 물려 내려가지 않는다.
원본 예제가 `<col>` 에 준 것도 배경뿐이다.

### 4. `:nth-child()` 로 열을 흉내 내다 `colspan` 에 걸린다

`td:nth-child(2)` 는 「행 안에서 두 번째 형제 셀」이지 「두 번째 열」이 아니다.
앞 셀이 `colspan="2"` 로 두 칸을 차지하면, 두 번째 형제 셀은 실제로 세 번째 열에 놓인다.
열 결합자는 이 어긋남 없이 격자 위치로 고르려고 제안된 것이다.

### 5. `||` 를 쉼표 목록에 섞는다

무효 선택자 하나가 목록 전체를 버리게 한다(동작 방식 4).

### 6. 셀에 자체 배경을 주면 `<col>` 배경이 가려진다 (확인 필요)

`<col>` 배경은 셀 뒤에 깔리는 층이라, 셀(`td`)에 배경색이 있으면 그것이 위에 그려진다고 알려져 있다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `\|\|` 가 열에 속한 셀을 고른다 | CSS 선택자 명세의 제안(실험적) — 실제 동작은 브라우저가 구현해야 생긴다 |
| `\|\|` 의 브라우저 지원이 거의 없다 | 브라우저마다의 구현 현황 — 원본 팁의 서술, 범위는 (확인 필요) |
| 해석 못 하는 선택자가 있으면 규칙을 통째로 버린다 | CSS 문법 규칙(모든 브라우저가 따르는 오류 처리) |
| `<col>` 배경이 그 열 셀 뒤에 비친다 | CSS 표 그리기 규칙 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 실제 페이지에서 열 하나 배경 강조 | `<col class>` + 클래스 규칙 | `col \|\| td` |
| 열 셀의 글자색 · 정렬을 바꾸기 | 셀마다 클래스 또는 `td:nth-child()` (병합 셀 없을 때) | `<col>` 에 `color` (상속 안 됨) |
| `colspan` 이 섞인 표에서 열 고르기 | 셀에 직접 클래스 | `:nth-child()` |
| 새 선택자 기능을 시험해 보기 | `\|\|` 를 단독 규칙으로 | 쉼표로 다른 선택자와 묶기 |

## 핵심 문장

1. **`col || td` 는 그 `<col>` 이 나타내는 열의 셀을 고른다** — 문서 트리가 아니라 표 격자를 따라간다.
2. **`<col>` 과 `<td>` 는 조상·자손이 아니다** — 그래서 공백 결합자로는 열의 셀을 못 고르고, 상속도 흐르지 않는다.
3. **`||` 는 실험적이라 지원이 거의 없다** — 지금은 `<col>` 에 클래스를 달아 배경을 준다.
4. **해석 못 하는 선택자는 규칙 전체를 버리게 한다** — `||` 는 쉼표 목록에 섞지 않는다.

## 용어 풀이

- **결합자** — 두 선택자 사이에서 요소 관계를 정하는 기호(공백 · `>` · `+` · `~` · `||`).
- **열 결합자** — `A || B` 꼴로 A 열에 속한 B 를 고르는 결합자.
- **`<colgroup>`** — 표의 열 정의를 묶는 요소.
- **`<col>`** — 표의 열 하나(또는 `span` 만큼)를 정의하는 빈 요소.
- **`border-collapse: collapse`** — 이웃한 셀 테두리를 하나로 합치는 표 속성.
- **선택자 목록** — 쉼표로 이어 쓴 여러 선택자; 하나가 무효면 목록 전체가 무효다.
- **상속** — 부모 요소의 일부 속성값이 자식에게 물려 내려가는 것.
- **실험적 기능** — 명세에 제안됐지만 널리 구현되지 않은 기능.

## 더 들어가면

- 열 결합자는 CSS Selectors Level 4 초안에 들어 있다 (확인 필요).
- `colspan` 으로 여러 열에 걸친 셀은 걸친 열 각각에 속한 것으로 본다고 명세가 정한다 (확인 필요).
- `<col>` 에 적용되는 속성은 `background` · `border` · `width` · `visibility` 정도로 제한된다 (확인 필요).
- 짝 의사 클래스로 `:nth-col()` · `:nth-last-col()` 가 함께 제안되어 있다 (확인 필요).
