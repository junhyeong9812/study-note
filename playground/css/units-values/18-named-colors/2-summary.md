## 한눈에 — 쉽게 말하면

**이름 색상(named color)은 「물감 상자에 미리 이름표가 붙은 물감」이다.**
물감을 섞지 않아도 「토마토」 칸을 집으면 늘 같은 빨강이 나온다.
CSS 도 똑같은 구조다.
`tomato` 라고 쓰면 브라우저가 미리 정해 둔 표에서 그 이름을 찾아 정해진 색 하나로 칠한다.

> **이름 색상(named color)** — CSS 가 미리 이름을 붙여 둔 색 키워드.\
> 예: `red` · `blue` · `tomato` · `cornflowerblue`.

| 비유 | 실체 |
|---|---|
| 물감 상자 | CSS 가 미리 정의한 148개 색 이름의 목록 |
| 이름표 | `tomato` · `coral` 같은 `<color-name>` 키워드 |
| 칸에서 물감을 꺼내 칠하기 | `background: tomato` 처럼 색이 들어갈 자리에 이름을 쓰기 |
| 상자에 없는 물감 | 목록에 없는 단어 — 색이 되지 않는다 |

```text
  background: tomato
              │
              ▼
  ┌───────────────────────────┐
  │ 미리 정의된 색 이름 목록    │
  │  tomato        → 색 하나   │
  │  cornflowerblue → 색 하나  │
  │  ... (148개)               │
  └───────────────────────────┘
              │
              ▼
     그 색으로 배경을 칠한다
```

## 이 주제가 답하려는 질문

1. 색 이름 하나를 쓰면 브라우저는 무엇을 하는가?
2. 이름 색상 위에 글자를 얹을 때, 배경이 옅으면 어떻게 읽히게 하는가?
3. 이름 색상은 어디에 편리하고, 실제 서비스(프로덕션)에서는 왜 다른 방식을 권하는가?

## 동작 방식

### (1) 이름이 색 하나로 바뀐다

**언제 쓰나** — 색 코드를 외우지 않고 빨리 색을 넣고 싶을 때 쓴다.
프로토타이핑이나 학습에 편하다.

```text
입력:  .swatch { background: mediumseagreen; }
         │
         ▼  브라우저가 「mediumseagreen」을 미리 정의된 목록에서 찾는다
         │
         ▼  목록에 있다 → 정해진 색 하나로 바꾼다
결과:  그 칸의 배경이 초록 계열 한 가지 색으로 칠해진다
```

- 이름은 색 값을 받는 자리(`<color>`)라면 어디에나 쓸 수 있다.
- 브라우저는 이름을 목록에서 찾는다.
- 찾은 이름은 늘 같은 색 하나에 대응한다.
- 그래서 같은 이름을 두 곳에 쓰면 두 곳이 같은 색이 된다.

> **프로토타이핑** — 완성품 전에 모양과 흐름을 빠르게 확인하려고 대충 만들어 보는 일.\
> 예: 색 코드를 고르기 전에 `tomato` · `coral` 로 칸만 칠해 보기.

### (2) 칸마다 인라인 `style` 로 다른 이름을 준다

**언제 쓰나** — 예제처럼 칸 하나하나에 서로 다른 색을 붙일 때 쓴다.

```text
입력:  <div class="swatch" style="background: tomato">tomato</div>
       <div class="swatch" style="background: coral">coral</div>
         │
         ▼  class="swatch" 는 공통 모양(여백·글자)을 준다
         ▼  style="background: …" 는 그 칸에만 배경색을 준다
결과:  모양은 같고 배경색만 다른 칸들이 생긴다
```

- `class` 는 여러 요소가 같이 쓰는 규칙을 고른다.
- `style` 속성(인라인 스타일)은 그 요소 하나에만 붙는다.
- 인라인 스타일은 클래스 선택자 규칙보다 우선한다.
- 그래서 `.swatch` 에 배경을 따로 적어도 인라인 `background` 가 이긴다.

> **인라인 스타일** — HTML 요소의 `style` 속성에 직접 적은 CSS 선언.\
> 예: `<div style="background: tomato">`.

### (3) 글자색 — 기본은 흰색, 옅은 배경은 `.dark` 가 덮는다

**언제 쓰나** — 배경색이 칸마다 다를 때 글자가 모든 칸에서 읽히게 하려고 쓴다.

```text
입력:  .swatch       { color: white;   text-shadow: …; }
       .swatch.dark  { color: #1e293b; text-shadow: none; }
       <div class="swatch dark" style="background: papayawhip">
         │
         ▼  이 칸은 두 규칙에 모두 걸린다
         ▼  .swatch.dark(클래스 둘)가 .swatch(클래스 하나)보다 구체적이다
         ▼  color 와 text-shadow 는 .swatch.dark 값으로 덮인다
결과:  papayawhip 칸만 어두운 글자 · 그림자 없음, 나머지는 흰 글자 · 그림자
```

- 진한 배경(`tomato` · `slateblue` 등)에는 흰 글자가 잘 보인다.
- `papayawhip` 은 매우 옅은 색이라 흰 글자를 얹으면 읽기 어렵다.
- 그래서 그 칸에만 `dark` 클래스를 붙여 어두운 글자로 바꾼다.
- 선택자가 더 구체적인 규칙이 같은 속성을 덮어쓴다.
- 덮어쓰지 않은 속성(`font-weight` 등)은 `.swatch` 값이 그대로 남는다.

> **명시도(specificity)** — 같은 요소에 걸린 규칙이 부딪칠 때 어느 쪽이 이기는지 정하는 선택자의 「구체적인 정도」.\
> 예: `.swatch.dark` 는 `.swatch` 보다 명시도가 높다.

### (4) 칸 배치 — 줄마다 같은 너비로 나눈다

**언제 쓰나** — 색 견본을 한 줄에 고르게 늘어놓을 때 쓴다.

```text
입력:  .row { display: flex; gap: 8px; margin-bottom: 8px; }
       .row:last-child { margin-bottom: 0; }
       .swatch { flex: 1; }
         │
         ▼  .row 안의 칸들이 가로로 놓인다
         ▼  flex: 1 이라 남는 너비를 칸끼리 똑같이 나눈다
         ▼  gap 은 칸 사이에만 간격을 둔다
         ▼  마지막 줄은 아래 여백이 0 이다
결과:  3칸짜리 줄 두 개, 칸 너비는 줄마다 같다
```

```html demo
<div style="display:flex; gap:8px;">
  <div style="flex:1; background:tomato; color:white; padding:12px;">tomato</div>
  <div style="flex:1; background:papayawhip; color:#1e293b; padding:12px;">papayawhip</div>
</div>
```

> **보이는 것** — 같은 너비의 두 칸이 나란히 놓이고, 왼쪽은 빨강 계열 바탕에 흰 글자, 오른쪽은 매우 옅은 바탕에 어두운 글자다 (코드에서 읽은 것 — 렌더 실측 아님).

## 문법 — 형태와 규칙

```css
/* 이름 색상은 색이 들어가는 어느 자리에나 쓴다 */
.a { color: tomato; }
.b { background: cornflowerblue; }
.c { border: 2px solid slateblue; }

/* 프로덕션 쪽 방식: 이름(또는 다른 표기)을 변수 한 곳에 두고 가져다 쓴다 */
:root { --color-accent: coral; }
.button { background: var(--color-accent); }
```

- 문법은 `<color-name>` — 따옴표 없이 이름 키워드 하나를 쓴다.
- CSS 에는 148개의 미리 정의된 이름이 있다(원본 설명).
- 예: `red` · `blue` · `tomato` · `cornflowerblue` · `mediumseagreen` · `slateblue` · `coral` · `papayawhip`.
- 이름 하나는 고정된 색 하나다 — 이름으로 「조금 더 밝게」를 줄 수는 없다.
- 목록에 없는 단어는 색 값이 아니다.
- 이름은 CSS 변수(디자인 토큰)의 값으로도 넣을 수 있다.

> **디자인 토큰** — 색 · 간격 같은 디자인 값에 이름을 붙여 한 곳에서 관리하는 것. CSS 에서는 주로 사용자 정의 속성(변수)으로 둔다.\
> 예: `--color-accent: coral;` 을 정의하고 `var(--color-accent)` 로 쓴다.

## 어디서 틀리나

### 1. 프로덕션 코드 곳곳에 이름을 직접 흩뿌린다

원본 팁: 이름 색상은 프로토타이핑이나 학습용으로 편리하지만, 프로덕션에서는 디자인 토큰(변수)을 쓰는 편이 유지보수에 유리하다.
`tomato` 를 스무 군데에 적어 두면, 브랜드 색을 바꿀 때 스무 군데를 고쳐야 한다.
변수 한 곳에 두면 한 줄만 바꾸면 된다.
또 `tomato` 라는 이름은 「무슨 색인가」만 말하고 「무엇에 쓰는 색인가」(강조색 · 경고색)는 말하지 않는다.

### 2. 옅은 이름 색 위에 흰 글자를 얹는다

`papayawhip` 처럼 매우 옅은 색에 흰 글자를 쓰면 글자가 배경에 묻힌다.
예제는 그 칸에만 `.dark` 를 붙여 어두운 글자로 바꾸고 그림자를 없앤다.
이름만 보고는 밝기를 짐작하기 어렵다 — 실제로 칠해 보고 글자 대비를 확인해야 한다.

### 3. 목록에 없는 이름을 지어낸다

이름 색상은 미리 정의된 목록에서만 고른다.
`banana` 처럼 그럴듯한 단어라도 목록에 없으면 색이 되지 않는다.

### 4. 이름 하나로 미세한 색을 맞추려 한다

이름 하나는 고정된 색 하나다.
「`coral` 보다 살짝 어둡게」가 필요하면 다른 이름을 찾거나 다른 색 표기로 바꿔야 한다.

### 5. `.dark` 를 `.swatch` 없이 쓴다

예제의 규칙은 `.swatch.dark` — 두 클래스를 모두 가진 요소만 고른다.
`class="dark"` 만 붙이면 이 규칙에 걸리지 않는다.

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|

| CSS 를 배우며 예제 만들기 | 이름 색상 — 읽기 쉽다 | — |

## 핵심 문장

1. **이름 색상은 CSS 가 미리 정의한 색 키워드다** — 이름 하나가 정해진 색 하나로 바뀐다.
2. **목록 밖의 이름은 색이 아니다** — 이름은 지어내는 것이 아니라 고르는 것이다.
3. **배경 밝기에 따라 글자색을 덮어쓴다** — 예제는 옅은 `papayawhip` 칸에만 `.swatch.dark` 를 건다.
4. **프로토타입에는 이름, 프로덕션에는 토큰** — 값을 한 곳에 모아야 고치기 쉽다.

## 관련 자료

- `hex` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `rgb-rgba` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `currentcolor` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **이름 색상(named color)** — CSS 가 미리 이름을 붙여 둔 색 키워드.
- **`<color-name>`** — 이름 색상이 들어가는 자리를 가리키는 문법 표기.
- **프로토타이핑** — 완성 전에 빠르게 만들어 모양과 흐름을 확인하는 일.
- **프로덕션** — 실제 사용자가 쓰는 서비스 환경.
- **디자인 토큰** — 디자인 값에 이름을 붙여 한 곳에서 관리하는 것.
- **CSS 변수(사용자 정의 속성)** — `--이름: 값;` 으로 정의하고 `var(--이름)` 으로 쓰는 값.
- **인라인 스타일** — 요소의 `style` 속성에 직접 쓴 CSS.
- **명시도(specificity)** — 부딪치는 규칙 중 어느 쪽이 이길지 정하는 선택자의 구체적인 정도.
- **스와치(swatch)** — 색 하나를 보여 주는 견본 칸.
- **`flex: 1`** — flex 아이템이 남는 공간을 다른 아이템과 같은 비율로 나눠 갖게 하는 값.
- **`gap`** — flex 아이템 사이에만 두는 간격.
- **`:last-child`** — 부모의 마지막 자식인 요소를 고르는 의사 클래스.
