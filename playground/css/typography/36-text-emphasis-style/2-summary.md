## 한눈에 — 쉽게 말하면

**`text-emphasis-style` 은 「글자마다 찍는 도장의 모양 고르기」다.**
시험지에서 중요한 낱말에 밑줄 대신 글자 하나하나 위에 작은 도장을 찍는다고 하자.
도장을 찍을지 말지, 속을 칠한 도장인지 테두리만 있는 도장인지, 무늬가 점인지 원인지를 고른다.
마음에 드는 무늬가 없으면 도장을 직접 판다 — 다만 도장에는 글자 한 자만 새길 수 있다.
`text-emphasis-style` 도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 도장을 안 찍는다 | `none` (기본값) |
| 속을 칠한 도장 / 테두리 도장 | `filled` / `open` |
| 도장 무늬 | `dot` · `circle` · `double-circle` · `triangle` · `sesame` |
| 직접 판 도장(한 자만 새김) | `<string>` — 첫 글자만 쓰인다 |
| 위 문단에서 찍은 도장이 아래 줄에도 이어짐 | 상속(`True`) |

```text
 ●  ●  ●  ●          ← 강조 마크 (filled dot)
 강 조 문 장
```

> **강조 마크** — 글자 하나하나에 붙어 그 글자를 강조하는 작은 기호.\
> 예: 「강조」의 두 글자 위에 각각 점이 하나씩 찍힌다.

> **방점** — 우리 글에서 글자 옆이나 위에 찍어 강조하던 점. 원본 키워드에 있는 이름이다.\
> 예: 옛 교과서에서 중요한 낱말 위에 찍힌 점.

## 이 주제가 답하려는 질문

1. 강조 마크의 모양은 어떤 조각을 조합해 정하나?
2. 조각을 일부 빼거나 문자열을 쓰면 무엇이 쓰이나?
3. 부모에 준 강조 모양은 자식 요소에 어떻게 퍼지나?
4. 모양을 바꿀 때 부드럽게 바뀌게 할 수 있나?

## 동작 방식

### (1) 두 축의 조합 — 채움 × 모양

**언제 쓰나** — 미리 정해진 기호 가운데 하나로 글자를 강조할 때.

```text
text-emphasis-style: open circle;
        │                 │
        ├─ 채움 축: filled | open ── open → 속이 빈 마크
        └─ 모양 축: dot | circle | double-circle | triangle | sesame ── circle → 원
                                                         │
                                        결과: 글자마다 속 빈 원 ○
```

채움 축은 마크의 속을 칠할지(`filled`) 테두리만 그릴지(`open`) 정한다.
모양 축은 마크의 꼴을 정한다.
두 축의 값을 하나씩 골라 붙이면 마크 하나가 정해진다.
문법의 `||` 는 「둘 다 쓰거나 하나만 쓰고, 순서는 상관없다」는 뜻이다.

> **`||` (값 조합 기호)** — CSS 문법 표기에서 양쪽 값을 하나 이상, 아무 순서로나 쓸 수 있다는 뜻.\
> 예: `open circle` 과 `circle open` 이 같은 선언이다.

> **sesame (깨 마크)** — 깨알처럼 가늘고 기울어진 작은 마크.\
> 예: `filled sesame` 은 속을 채운 깨 모양이 글자마다 붙는다.

### (2) 채움 축을 빼면 — `filled` 가 기본

**언제 쓰나** — 속이 찬 마크를 원할 때 `filled` 를 생략해 짧게 쓴다.

```text
text-emphasis-style: dot;
   채움 축 비어 있음 → filled 로 채움
   결과: filled dot 과 같다 → 글자마다 ●
```

채움 축이 없으면 브라우저가 `filled` 를 넣는다.
그래서 `dot` 과 `filled dot` 은 같은 결과를 낸다.
`open` 을 원하면 반드시 적어야 한다.

### (3) 문자열 — 첫 글자만 마크가 된다

**언제 쓰나** — 다섯 모양에 없는 기호(별, 하트 등)를 마크로 쓰고 싶을 때.

```text
text-emphasis-style: '★☆';
   문자열 '★☆' → 첫 글자 '★' 만 사용, '☆' 는 버려짐
   결과: 글자마다 ★
```

문자열을 주면 그 문자가 그대로 마크가 된다.
문자열이 여러 글자여도 첫 번째 문자만 쓰인다.
문자열은 채움·모양 조합과 **다른 갈래**다 — 문법에서 `|` 로 나뉘어 있어 `open '★'` 처럼 섞을 수 없다.

> **무효 선언** — 문법에 맞지 않아 브라우저가 통째로 버리는 선언.\
> 예: `text-emphasis-style: open '★';` 는 버려지고 상속값이나 앞선 규칙의 값이 남는다.

### (4) 상속 — 부모가 고르면 자식도 따른다

**언제 쓰나** — 문단 하나 전체에 강조를 걸 때. 안쪽 일부만 끄고 싶을 때도 이 성질을 안다.

```text
<p style="text-emphasis-style: dot">
  앞 글자 <span>안쪽 글자</span>
</p>
   p   → dot
   span → 자기 값 없음 → 부모의 dot 을 물려받음
   결과: 「앞 글자」와 「안쪽 글자」 모두 마크가 붙는다
```

이 속성은 상속된다(`True`).
자식 요소가 따로 값을 주지 않으면 부모의 모양을 그대로 쓴다.
안쪽 일부만 마크를 빼려면 그 자식에 `none` 을 준다.

> **상속** — 자식 요소가 값을 지정하지 않으면 부모의 계산된 값을 물려받는 성질.\
> 예: `color` 처럼 `p` 에 준 값이 안쪽 `span` 에도 적용된다.

### (5) 애니메이션 불가 — 모양은 한순간에 바뀐다

**언제 쓰나** — 마우스를 올렸을 때 마크 모양을 바꾸는 효과를 만들 때.

```text
.a        { text-emphasis-style: dot; transition: all 1s; }
.a:hover  { text-emphasis-style: circle; }
   dot → circle 사이의 중간 모양이 없다
   결과: 1초에 걸쳐 바뀌지 않고 즉시 바뀐다
```

애니메이션 가능 여부가 `False` 다.
「점」과 「원」 사이에 중간 단계가 정의되지 않으므로 `transition` 을 걸어도 보간되지 않는다.
모양이 바뀌는 순간 곧장 새 마크로 갈아 끼워진다.

## 문법 — 형태와 규칙

```html demo
<p style="font-size:20px; text-emphasis-style: filled dot;">채워진 점</p>
<p style="font-size:20px; text-emphasis-style: open circle;">비어 있는 원</p>
<p style="font-size:20px; text-emphasis-style: sesame;">깨 마크</p>
<p style="font-size:20px; text-emphasis-style: '★';">별 문자</p>
```

> **보이는 것** — 네 문단의 글자마다 각각 ●, ○, 깨 모양, ★ 마크가 붙는다 (코드에서 읽은 것 — 렌더 실측 아님)

```text
text-emphasis-style: none | [filled | open] || [dot | circle | double-circle | triangle | sesame] | <string>
```

| 값 | 뜻 |
|---|---|
| `none` | 강조 마크 없음 (기본값) |
| `filled dot` | 채워진 점 |
| `open circle` | 비어 있는 원 |
| `filled sesame` | 채워진 깨 마크 |
| `double-circle` | 이중 원 (채움 생략 → `filled`) |
| `triangle` | 삼각형 (채움 생략 → `filled`) |
| `<string>` | 커스텀 문자 — 첫 글자만 사용 |

- 기본값은 `none` 이다.
- 채움 축(`filled` · `open`)에서는 하나만 고른다.
- 모양 축에서도 하나만 고른다.
- 두 축은 `||` 로 묶여 순서가 자유롭다.
- 채움 축을 생략하면 `filled` 다.
- `<string>` 은 `none` · 키워드 조합과 따로 쓰는 갈래다.
- 상속된다 · 애니메이션되지 않는다.

## 어디서 틀리나

### 1. `filled` 를 꼭 써야 한다고 생각한다

채움 축을 생략하면 `filled` 가 기본이다.
`dot` 만 써도 `filled dot` 과 같다.
반대로 속 빈 마크를 원하면서 `open` 을 빼먹으면 채워진 마크가 나온다.

### 2. 문자열을 길게 준다

커스텀 문자열은 첫 번째 문자만 쓰인다.
`'★☆'` 를 줘도 ★ 만 마크가 된다.
여러 기호를 번갈아 찍는 기능은 이 속성에 없다.

### 3. 문자열에 `filled` · `open` 을 붙인다

`<string>` 은 키워드 조합과 `|` 로 나뉜 다른 갈래다.
`open '★'` 은 문법에 맞지 않아 선언이 통째로 버려진다.

### 4. 같은 축에서 두 값을 고른다

`filled open dot` · `dot circle` 처럼 한 축에서 둘을 쓰면 문법 위반이다.
축마다 하나씩만 고른다.

### 5. 자식까지 마크가 붙어 당황한다

상속되므로 문단에 준 강조가 안쪽 `span` · `a` 등에도 퍼진다.
일부만 빼려면 그 요소에 `text-emphasis-style: none` 을 준다.

### 6. `transition` 으로 부드럽게 바꾸려 한다

애니메이션 불가 속성이라 모양은 즉시 바뀐다.
점점 나타나는 효과가 필요하면 이 속성이 아닌 다른 속성(예: 색이나 투명도 쪽)으로 꾸며야 한다 (원본에 근거 없음 — 추론).

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 채움 축을 생략하면 `filled` 다 | 원본 팁 — CSS 명세의 규칙으로 보인다 (확인 필요) |
| 문자열은 첫 문자만 쓰인다 | 원본 팁 — 명세가 「잘라야 한다」인지 「잘라도 된다」인지 확인 필요 |
| 기본값 `none` · 상속 · 애니메이션 불가 | 원본 데이터 — 명세의 속성 정의 표 항목 |
| 마크의 실제 크기 · 위치 · 글꼴 모양 | 브라우저와 글꼴이 정한다 — 렌더 실측 아님 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 낱말의 글자 하나하나를 강조(방점 느낌) | `text-emphasis-style` | 글자 사이에 기호 문자를 직접 끼워 넣기 |
| 줄 하나로 문장을 강조 | `text-decoration` 의 밑줄 | `text-emphasis-style` |
| 다섯 모양에 없는 기호로 강조 | `<string>` (한 글자) | 여러 글자 문자열 |
| 마우스 올림 때 서서히 나타나는 강조 | 애니메이션 가능한 다른 속성 | `text-emphasis-style` 의 `transition` |
| 강조된 문단 안 일부만 강조 해제 | 자식에 `none` | 부모 값 지우기(문단 전체가 사라진다) |

## 핵심 문장

1. **마크 모양 = 채움 축(`filled`/`open`) × 모양 축(다섯 가지)** — 또는 한 글자 문자열.
2. **채움 축을 빼면 `filled`** — `dot` 은 `filled dot` 이다.
3. **문자열은 첫 글자만 쓰이고, 키워드와 섞을 수 없다.**
4. **상속되므로 자식에도 퍼진다** — 끄려면 자식에 `none`.
5. **애니메이션되지 않는다** — 모양은 즉시 바뀐다.

## 용어 풀이

- **강조 마크** — 글자 하나하나에 붙는 강조용 작은 기호.
- **방점** — 글자 옆이나 위에 찍어 강조하는 점, 이 속성의 우리말 별칭.
- **채움 축** — `filled`(속을 칠함) · `open`(테두리만) 중 하나를 고르는 자리.
- **모양 축** — `dot` · `circle` · `double-circle` · `triangle` · `sesame` 중 하나를 고르는 자리.
- **sesame** — 깨알 모양 마크.
- **`||`** — 값 문법에서 하나 이상을 아무 순서로 쓸 수 있다는 표기.
- **`|`** — 값 문법에서 여러 갈래 중 정확히 하나를 고른다는 표기.
- **무효 선언** — 문법에 맞지 않아 브라우저가 버리는 선언.
- **상속** — 값을 지정하지 않은 자식이 부모 값을 물려받는 성질.
- **보간** — 두 값 사이의 중간값을 계산해 부드럽게 이어 주는 일.

## 더 들어가면

- 모양 축만 빼고 `filled` 나 `open` 만 쓰면, 가로쓰기에서는 `circle`, 세로쓰기에서는 `sesame` 가 쓰인다고 알려져 있다 (확인 필요).
- 마크의 색은 `text-emphasis-color`, 위치(글자 위·아래·옆)는 `text-emphasis-position` 이 정하고, `text-emphasis` 는 모양과 색을 한 번에 적는 단축 속성이다 (확인 필요).
- 공백이나 일부 문장부호에는 마크가 붙지 않는다고 알려져 있다 (확인 필요).
- 일부 브라우저에서는 `-webkit-text-emphasis-style` 처럼 접두어가 붙은 이름이 필요했던 때가 있다 (확인 필요).
- 마크가 위쪽에 붙으면 줄 간격이 좁을 때 윗줄과 겹쳐 보일 수 있어 `line-height` 를 넉넉히 두는 편이 낫다 (확인 필요).
