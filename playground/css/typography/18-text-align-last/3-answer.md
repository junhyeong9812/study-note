# css/typography/18 — text-align-last — 정답

> 복습 때 이 파일은 **맨 마지막에만** 연다.\
> 집필 — `claude-opus-5-5` 가 원본 재료를 뼈대로 쓴 **검수 전 초안**이다(2026-11-28).

## 퀴즈 정답

### 1. 시작 쪽(한국어에서는 왼쪽)에 붙는다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
세 번째 줄은 양쪽으로 벌어지지 않고 왼쪽에 붙는다. (코드에서 읽은 것 — 렌더 실측 아님)

**왜 그런가**
`text-align-last` 를 주지 않았으니 기본값 `auto` 다.
`auto` 는 `text-align` 을 따르지만 그 값이 `justify` 면 `start` 가 된다.
한국어는 왼쪽에서 오른쪽으로 쓰므로 `start` 는 왼쪽이다.
근거: 2-summary 「동작 방식 (2)」 · 「동작 방식 (5)」.

### 2. `<br>` 앞 줄도 오른쪽에 놓인다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
`<br>` 바로 앞 줄은 양쪽 정렬되지 않고 오른쪽에 놓인다. (코드에서 읽은 것 — 렌더 실측 아님)
문단 끝 줄도 오른쪽에 놓이고, 나머지 줄은 양쪽 정렬된다.

**왜 그런가**
강제 줄바꿈 직전 줄은 마지막 줄과 같은 대접을 받아 `text-align-last` 를 따른다.
근거: 2-summary 「동작 방식 (3)」.

### 3. 가운데에 놓인다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
「짧은 글」은 400px 상자의 가운데에 놓인다. (코드에서 읽은 것 — 렌더 실측 아님)

**왜 그런가**
줄이 하나뿐이면 그 줄이 곧 마지막 줄이라 `text-align-last: center` 가 적용된다.
마지막이 아닌 줄이 없으니 `text-align: left` 는 보이는 효과가 없다.
근거: 2-summary 「동작 방식 (4)」.

### 4. 여러 줄을 만들어야 마지막 줄과 다른 줄의 차이가 보이기 때문이다

폭이 넓어 글이 한 줄로 끝나면 「마지막이 아닌 줄」이 없어 `text-align` 과 `text-align-last` 의 차이를 볼 수 없다.
정답 코드의 주석도 `max-width` 를 「여러 줄을 만들기 위한 폭 제한」이라 적는다.
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 5」.

### 5. 오른쪽에서 왼쪽으로 쓰는 글에서다

`start` 는 쓰기 방향의 시작 쪽이고 `left` 는 언제나 화면 왼쪽이다.
오른쪽에서 왼쪽으로 쓰는 글에서는 `start` 가 오른쪽이 되어 `left` 와 갈라진다.
한국어처럼 왼쪽에서 오른쪽으로 쓰는 글에서는 둘이 같은 자리다.
근거: 2-summary 「동작 방식 (5)」.

### 6. 몇 글자가 상자 폭 전체로 벌어져 간격이 휑해진다

`justify` 는 마지막 줄도 양 끝에 맞추므로, 짧은 마지막 줄의 글자 사이가 크게 벌어질 수 있다. (원본에 근거 없음 — 추론)
그래서 마지막 줄이 짧을 수 있는 문단에는 `auto` · `start` · `center` 가 낫다.
근거: 2-summary 「어디서 틀리나 4」 · 「언제 쓰고 언제 안 쓰나」.

### 7. `<p>` 의 마지막 줄도 가운데에 놓인다

`text-align-last` 는 상속되는 속성이다.
`<p>` 가 따로 지정하지 않았으므로 부모 `article` 의 `center` 를 물려받는다.
근거: 2-summary 「문법 — 형태와 규칙」.

### 8. 미끄러지지 않고 새 자리로 한 번에 옮겨진다

`text-align-last` 는 애니메이션되지 않는 속성이라 `transition` 이 사이 단계를 만들지 못한다.
마우스를 올리는 순간 마지막 줄이 가운데로 곧바로 옮겨진다. (코드에서 읽은 것 — 렌더 실측 아님)
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 6」.

## 실습 정답

### 실습 1. 양쪽 정렬 문단의 마지막 줄만 가운데 두기

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| `text` 클래스 `<p>` 와 긴 글 | `<p class="text">이것은 양쪽 정렬된 긴 문단 텍스트입니다. …</p>` |
| 마지막이 아닌 줄은 양쪽 정렬 | `.text { text-align: justify; }` |
| 마지막 줄만 가운데 | `.text { text-align-last: center; }` |
| 폭 제한으로 여러 줄 | `.text { max-width: 300px; }` (시작 코드에 미리 있음) |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/typography/reference/text-align-last.html`

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <title>text-align-last - 블록 요소의 마지막 줄(또는 강제 줄바꿈 직전 줄)의 정렬 방식을 설정</title>
  <!--
    [타이포그래피] text-align-last
    설명: 블록 요소의 마지막 줄(또는 강제 줄바꿈 직전 줄)의 정렬 방식을 설정
    구문: text-align-last: auto | start | end | left | right | center | justify
    팁: text-align: justify와 함께 사용하여 마지막 줄만 가운데 또는 오른쪽 정렬 가능.
  -->
  <style>
    /* .text: 양쪽 정렬 + 마지막 줄만 가운데 정렬 */
    .text {
      text-align: justify;        /* 양쪽 정렬 (마지막 줄 제외) */
      text-align-last: center;    /* 마지막 줄만 가운데 정렬 */
      font-size: 16px;            /* 본문 크기 */
      max-width: 300px;           /* 여러 줄을 만들기 위한 폭 제한 */
      background: #e2e8f0;        /* 박스 시각화 */
      padding: 12px;              /* 안쪽 여백 */
      border-radius: 4px;         /* 모서리 둥글게 */
    }
  </style>
</head>
<body>
  <!-- 양쪽 정렬 단락, 마지막 줄만 가운데 정렬됨 -->
  <p class="text">이것은 양쪽 정렬된 긴 문단 텍스트입니다. 마지막 줄의 정렬 방식을 별도로 지정할 수 있습니다. 충분히 긴 텍스트가 필요합니다.</p>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.text { text-align: justify; text-align-last: center; font-size: 16px; max-width: 300px; background: #e2e8f0; padding: 12px; border-radius: 4px; }
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- 두 속성은 일을 나눠 맡는다 — `text-align` 은 마지막이 아닌 줄, `text-align-last` 는 마지막 줄.
- `text-align-last` 를 빼면 `auto` 가 되어 마지막 줄은 가운데가 아니라 시작 쪽(왼쪽)에 붙는다.
- 폭 제한이 없으면 글이 한 줄로 끝나 차이가 보이지 않는다.
- 배경 · 안쪽 여백 · 둥근 모서리는 상자 경계를 보이게 하는 꾸밈일 뿐 정렬과는 상관이 없다.
- 끝줄을 오른쪽에 두고 싶으면 `text-align-last` 값만 `right` 나 `end` 로 바꾸면 된다.
