## 한눈에 — 쉽게 말하면

**`tab-size` 는 「원고지에서 Tab 한 번에 몇 칸을 비울지」 정하는 약속이다.**
원고지에 글을 옮겨 적을 때 「들여쓰기 표시 하나 = 두 칸 비우기」라고 미리 정해 두면, 같은 원고도 약속에 따라 들여쓰기 폭이 달라진다.
브라우저도 똑같은 구조다.
글 속의 탭 문자는 「여기서 들여쓴다」는 표시일 뿐이다.
그 표시를 화면에서 얼마나 넓게 그릴지는 `tab-size` 가 정한다.

| 비유 | 실체 |
|---|---|
| 원고 속 「들여쓰기 표시」 | 탭 문자(U+0009) |
| 「표시 하나 = 몇 칸」 약속 | `tab-size` 값 |
| 한 칸 | 공백 문자 하나의 너비(정수 값일 때) |
| 자로 잰 고정 폭 | 길이 값(예: `32px`) |
| 칸을 무시하고 붙여 쓰는 원고지 | `white-space: normal`(공백을 접는 모드) |

```text
원본 텍스트 :  [TAB]indented line

tab-size: 2 →  ␣␣indented line
tab-size: 4 →  ␣␣␣␣indented line
tab-size: 8 →  ␣␣␣␣␣␣␣␣indented line
(␣ = 공백 하나의 너비)
```

## 이 주제가 답하려는 질문

1. 탭 문자 하나는 화면에서 얼마나 넓게 그려지나?
2. 그 너비를 「공백 몇 개」로 정하는 것과 「고정 길이」로 정하는 것은 무엇이 다른가?
3. `tab-size` 를 걸었는데 아무 변화가 없다면 왜인가?
4. 부모에 건 `tab-size` 는 자식에게 전해지나?

## 동작 방식

### (1) 정수 값 — 「공백 몇 개 너비」

**언제 쓰나** — 코드 블록의 들여쓰기를 「공백 2칸」「공백 4칸」처럼 글자 단위로 맞추고 싶을 때 쓴다.

```text
pre { tab-size: 4; }
본문: [TAB][TAB]double indented
        │
        ▼  탭 하나 = 공백 4개 너비
화면: ␣␣␣␣␣␣␣␣double indented   (들여쓰기 = 공백 8개 너비)
```

- 정수는 공백 문자의 개수를 뜻한다.
- `4` 면 탭 하나가 공백 4개만큼의 너비로 그려진다.
- 탭이 두 개 이어지면 그만큼 두 번 들여쓰인다.
- 공백 하나의 너비는 글꼴과 글자 크기를 따르므로, 정수 값은 글자 크기가 커지면 함께 넓어진다.

### (2) 길이 값 — 「고정 폭」

**언제 쓰나** — 글꼴이나 글자 크기와 상관없이 들여쓰기 폭을 일정한 길이로 고정하고 싶을 때 쓴다.

```text
pre { tab-size: 32px; font-size: 14px; }   pre { tab-size: 32px; font-size: 28px; }
        │                                          │
        ▼                                          ▼
탭 하나 = 32px                               탭 하나 = 그대로 32px
```

- `32px` 처럼 길이를 주면 탭 하나의 폭은 그 길이다.
- 글자가 커져도 탭 폭은 그대로다.

### (3) 공백을 유지하는 모드에서만 효과가 난다

**언제 쓰나** — `tab-size` 를 걸었는데 변화가 없을 때 가장 먼저 확인할 조건이다.

```text
white-space: pre / pre-wrap 등 (공백 유지)    white-space: normal (공백 접기)
        │                                            │
        ▼                                            ▼
탭 문자가 탭으로 남는다                         탭·공백·줄바꿈이 한 칸 공백으로 접힌다
        │                                            │
        ▼                                            ▼
tab-size 만큼 넓게 그려진다                    tab-size 는 아무 일도 하지 않는다
```

- `tab-size` 는 탭 문자가 살아 있을 때만 쓸모가 있다.
- `white-space: normal` 에서는 연속된 공백 문자(탭 포함)가 공백 하나처럼 접혀 버려서, 그릴 탭이 남지 않는다.
- `<pre>` 요소는 브라우저 기본 스타일로 `white-space: pre` 를 가진다.
- 그래서 `<pre>` 안의 탭에는 `white-space` 를 따로 쓰지 않아도 `tab-size` 가 먹는다.

> **white-space** — 요소 안의 공백 · 탭 · 줄바꿈을 그대로 둘지 접을지 정하는 CSS 속성.\
> 예: `white-space: pre` 는 공백과 줄바꿈을 원본 그대로 유지한다.

### (4) 상속 — 부모에 걸면 자식이 받는다

**언제 쓰나** — 페이지 안의 모든 코드 블록 탭 폭을 한곳에서 정하고 싶을 때 쓴다.

```text
body { tab-size: 2; }
   │  상속
   ▼
<pre> (따로 지정 없음) → 탭 = 공백 2개 너비
```

- `tab-size` 는 상속되는 속성이다.
- 부모(예: `body`)에 걸면, 따로 값을 받지 않은 자손 요소가 같은 값을 쓴다.
- 자식에 다른 값을 주면 그 값이 이긴다.

> **상속** — 부모 요소의 속성 값이 따로 지정하지 않은 자식 요소에게 그대로 전해지는 것.\
> 예: `body { color: red; }` 면 안쪽 `<p>` 도 빨갛다.

## 문법 — 형태와 규칙

```html demo
<pre class="a">a
	one tab
		two tabs</pre>
<pre class="b">b
	one tab
		two tabs</pre>
<style>
  pre { background: #f3f4f6; padding: 8px; }
  .a { tab-size: 2; }      /* 탭 = 공백 2개 너비 */
  .b { tab-size: 32px; }   /* 탭 = 고정 32px */
</style>
```

> **보이는 것** — 위 블록은 들여쓰기가 공백 2개 · 4개 폭으로 얕고, 아래 블록은 탭 하나마다 32px 씩 들어간다 (코드에서 읽은 것 — 렌더 실측 아님).

```text
tab-size: <integer> | <length>
```

| 값 | 뜻 | 예 |
|---|---|---|
| `<integer>` | 공백 문자 개수 단위 | `4` = 공백 4개 너비 |
| `<length>` | 고정 길이 | `32px` |

- **기본값**은 `8` 이다 — 아무것도 정하지 않으면 탭 하나가 공백 8개 너비다.
- **상속**된다.
- **애니메이션 가능** 속성이다 — 값의 변화를 `transition` 등으로 이어 그릴 수 있다.
- 탭 문자에만 작용한다 — 공백 문자로 들여쓴 줄은 바뀌지 않는다.
- `white-space` 가 `pre` · `pre-wrap` 처럼 공백을 유지하는 모드일 때만 효과가 난다.

## 어디서 틀리나

### 1. 공백을 접는 요소에 걸었다

`<div>` · `<p>` 처럼 `white-space: normal` 인 요소에 `tab-size` 를 걸면 아무 변화가 없다.
탭이 이미 공백 하나로 접혔기 때문이다.
`<pre>` 를 쓰거나 `white-space: pre` / `pre-wrap` 을 함께 준다.
코드 표시에서 쓸모가 큰 까닭도 코드 블록이 대개 공백을 유지하기 때문이다.

### 2. 들여쓰기가 탭이 아니라 공백이었다

편집기가 Tab 키를 공백 여러 개로 바꿔 저장했다면, 문서에는 탭 문자가 없다.
그러면 `tab-size` 를 몇으로 바꿔도 들여쓰기가 그대로다.

### 3. 기본값 8 을 잊었다

따로 정하지 않은 `<pre>` 의 탭은 공백 8개 너비라서, 탭으로 들여쓴 코드가 오른쪽으로 크게 밀린다.
코드 블록에 `tab-size: 2` 나 `4` 를 주는 까닭이 이것이다.

### 4. 정수 값은 글꼴을 따라 변한다

정수 값의 단위는 공백 하나의 너비라서, 글자 크기나 글꼴이 바뀌면 탭 폭도 바뀐다.
글꼴과 상관없이 폭을 고정해야 하면 길이 값을 쓴다.

### 5. 원본 주석의 「탭 = 공백 N칸으로 렌더링」

원본의 주장 → 탭 문자를 공백 N개 너비로 그린다.
왜 의심스러운가 → 탭은 고정 폭을 더하는 것이 아니라 「다음 탭 위치」까지 건너뛴다는 설명이 흔하다 (확인 필요).
그 설명이 맞다면, 줄 중간의 탭(앞에 글자가 있는 탭)은 N칸보다 좁게 보일 수 있다.
줄 맨 앞에서 연달아 쓴 탭은 어느 설명으로 보든 「탭 개수 × N칸」이다.

### 6. 원본 주석의 「8 = `<pre>` 의 브라우저 기본」 · 「4 = 많은 언어의 권장 들여쓰기」

원본의 주장 → `8` 은 `<pre>` 의 브라우저 기본이고, `4` 는 많은 언어가 권하는 값이다.
왜 의심스러운가 → `8` 은 `tab-size` 속성 자체의 기본값이라 `<pre>` 에만 해당하는 값이 아니다.
`4` 는 언어 · 팀의 관례일 뿐 CSS 가 권하는 값이 아니고, 언어마다 관례가 다르다 (확인 필요).

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 기본값은 `8` 이다 | CSS 명세의 초깃값 (원본 재료의 기본값 `8`) |
| 상속된다 · 애니메이션 가능하다 | CSS 명세 (원본 재료) |
| 정수 = 공백 개수, 길이 = 고정 폭 | CSS 명세 (원본 재료) |
| 공백을 유지하는 모드에서만 효과가 난다 | CSS 명세 — `white-space` 처리 규칙 (원본 재료의 팁) |
| `<pre>` 는 `white-space: pre` 를 가진다 | 브라우저 기본 스타일시트 — 작성자 CSS 로 덮어쓸 수 있다 (확인 필요) |
| 탭은 다음 탭 위치까지 건너뛴다 | CSS 명세로 알려져 있다 (확인 필요) |
| `4` 가 일반적인 들여쓰기다 | 언어 · 팀 관례 — CSS 와 무관하다 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 탭으로 들여쓴 코드를 `<pre>` 로 보여 준다 | `tab-size: 2` 또는 `4` | 기본값 `8` 을 그대로 두기 |
| 글꼴과 상관없이 폭을 고정해야 한다 | 길이 값(`32px` 등) | 정수 값 |
| 글자 크기에 맞춰 들여쓰기도 커져야 한다 | 정수 값 | 길이 값 |
| 공백으로 들여쓴 텍스트 | (효과 없음 — 다른 방법) | `tab-size` 에 기대기 |
| 일반 문단(`white-space: normal`) | (탭이 접힌다) | `tab-size` 만 걸고 기다리기 |
| 페이지 전체 코드 블록을 한 번에 | 부모(`body` 등)에 걸어 상속 | 블록마다 같은 값 반복 |

## 핵심 문장

1. **`tab-size` 는 탭 문자 하나를 화면에서 얼마나 넓게 그릴지 정한다** — 기본은 공백 8개 너비다.
2. **정수는 「공백 몇 개」, 길이는 「고정 폭」** — 정수는 글꼴을 따라 변하고 길이는 그대로다.
3. **공백을 유지하는 모드(`pre` · `pre-wrap` 등)에서만 효과가 난다** — `normal` 에서는 탭이 접혀 사라진다.
4. **탭 문자에만 작용하고, 상속된다** — 공백 들여쓰기는 그대로이고, 부모에 걸면 자식이 받는다.

## 용어 풀이

- **탭 문자(U+0009)** — Tab 키로 넣는 보이지 않는 문자, 들여쓰기 표시로 쓰인다.
- **공백 문자** — 스페이스 키로 넣는 빈칸 문자(U+0020).
- **`tab-size`** — 탭 문자의 표시 너비를 정하는 CSS 속성.
- **`<integer>`** — 정수 값, `tab-size` 에서는 공백 개수를 뜻한다.
- **`<length>`** — `px` 같은 단위를 붙인 길이 값.
- **기본값(초깃값)** — 아무도 값을 정하지 않았을 때 속성이 갖는 값.
- **상속** — 부모의 속성 값이 지정 없는 자식에게 전해지는 것.
- **`white-space`** — 공백 · 탭 · 줄바꿈을 유지할지 접을지 정하는 속성.
- **공백 접기** — 연속된 공백 문자(탭 포함)를 공백 하나로 합치는 처리.
- **`<pre>`** — 서식을 미리 갖춘 텍스트를 담는 HTML 요소, 공백과 줄바꿈을 그대로 보인다.
- **애니메이션 가능** — 값이 바뀔 때 중간값을 이어 그릴 수 있다는 뜻.

## 더 들어가면

- 탭은 고정 폭을 더하는 대신 「탭 크기의 배수 위치(탭 스톱)」까지 건너뛴다고 알려져 있다 (확인 필요).
- 음수 값은 허용되지 않는다고 알려져 있다 (확인 필요).
- 옛 Firefox 는 접두사가 붙은 `-moz-tab-size` 만 알아들었다는 이야기가 있다 (확인 필요).
- 정수 값의 「공백 너비」에 `letter-spacing` · `word-spacing` 이 더해지는지는 명세 세부를 봐야 한다 (확인 필요).
- `white-space: pre-line` 은 줄바꿈은 지키지만 공백과 탭은 접으므로 `tab-size` 가 먹지 않는다 (확인 필요).
- `<textarea>` 는 기본으로 공백을 유지해서 `tab-size` 가 입력 칸 안의 탭에도 작용한다 (확인 필요).
