## 한눈에 — 쉽게 말하면

**`text-shadow` 는 「글자 모양으로 오린 셀로판지를 글자 뒤에 깔아 두는 것」이다.**
셀로판지를 오른쪽 아래로 조금 밀면 그림자처럼 보이고, 셀로판지 가장자리를 문지르면 흐릿해진다.
셀로판지를 여러 장 겹쳐 깔 수도 있다.
CSS 의 `text-shadow` 도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 글자 모양 셀로판지 | 글자 윤곽을 본뜬 그림자 한 장 |
| 오른쪽으로 미는 거리 | `<offset-x>` (양수: 오른쪽) |
| 아래로 미는 거리 | `<offset-y>` (양수: 아래) |
| 가장자리를 문지른 정도 | `<blur-radius>` (0 = 선명) |
| 셀로판지 색 | `<color>` (생략하면 `currentcolor`) |
| 여러 장 겹치기 | 쉼표로 이은 그림자 목록 |

```text
   글자 "A"            그림자 (2px 오른쪽, 2px 아래)
   ┌───┐
   │ A │──┐
   └───┘  │  ← 글자 뒤에 깔린 같은 모양
      └───┘
```

## 이 주제가 답하려는 질문

1. 그림자 한 장의 위치 · 흐림 · 색은 어떤 값으로 정하나?
2. 그림자를 여러 장 겹치면 어떤 순서로 쌓이나?
3. 「빛나는 글자(네온)」는 그림자로 어떻게 만드나?
4. 값을 생략하거나 부모에 걸면 어떤 일이 생기나?

## 동작 방식

### (1) 그림자 한 장 — 오프셋과 색

**언제 쓰나** — 글자를 바탕에서 살짝 띄워 또렷하게 보이고 싶을 때 쓴다.

```text
text-shadow: 2px 2px #94a3b8;
      │
      ▼
글자 윤곽을 복사 → 오른쪽 2px, 아래 2px 이동 → 회색으로 칠함 → 글자 뒤에 깔기
      │
      ▼
글자 오른쪽 아래에 선명한 회색 테두리 같은 그림자
```

- 브라우저는 글자의 윤곽을 그대로 본떠 그림자 한 장을 만든다.
- 첫 번째 길이만큼 가로로, 두 번째 길이만큼 세로로 옮긴다(양수면 오른쪽 · 아래, 음수면 왼쪽 · 위).
- 세 번째 값(흐림)이 없으면 흐림은 0 이어서 가장자리가 선명하다.
- 그림자는 글자 **뒤**에 그려지므로 글자를 가리지 않는다.

> **오프셋(offset)** — 그림자를 원래 글자 자리에서 옮기는 거리.\
> 예: `2px 2px` 는 오른쪽으로 2px, 아래로 2px 옮긴다.

### (2) 흐림 반경 — 가장자리를 번지게

**언제 쓰나** — 딱딱한 그림자 대신 부드럽고 자연스러운 그림자를 원할 때 쓴다.

```text
text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
                     │        │
                     │        └ 검정, 불투명도 30%
                     └ 흐림 반경 4px
      ▼
옮긴 그림자의 가장자리를 4px 남짓 번지게 함
      ▼
글자 아래에 연한 회색 안개 같은 그림자
```

- 흐림 반경은 세 번째 길이다.
- 값이 클수록 그림자가 넓게 번지고 옅어진다.
- 반투명 색(`rgba`)을 쓰면 바탕이 비쳐 더 자연스럽다.

> **흐림 반경(blur radius)** — 그림자 가장자리를 얼마나 번지게 할지 정하는 길이.\
> 예: `0` 이면 칼로 자른 듯 선명하고, `10px` 이면 넓게 퍼진다.

### (3) 여러 장 겹치기 — 쉼표 목록

**언제 쓰나** — 입체 글자, 색 띠, 발광처럼 그림자 한 장으로는 안 되는 효과를 만들 때 쓴다.

```text
text-shadow: 1px 1px #ef4444, 2px 2px #3b82f6, 3px 3px #22c55e;
             └── 1장(빨강) ─┘ └── 2장(파랑) ─┘ └── 3장(초록) ─┘
      ▼
맨 위(글자 바로 뒤): 1장 → 그 아래: 2장 → 맨 아래: 3장
      ▼
글자 오른쪽 아래로 빨강 · 파랑 · 초록 띠가 계단처럼 이어짐
```

- 쉼표로 이은 그림자는 각각 독립된 한 장이다.
- 목록의 **첫 그림자가 맨 위**(글자에 가장 가까운 층)에 그려지고, 뒤로 갈수록 아래에 깔린다(CSS 명세의 규칙 — 원본에는 없는 서술).
- 오프셋을 1px · 2px · 3px 로 늘리면 각 장이 앞 장에 가려지고 남은 1px 만큼씩만 드러나 띠처럼 보인다.

### (4) 네온 — 오프셋 0, 흐림만 크게

**언제 쓰나** — 글자 둘레가 고르게 빛나는 효과를 원할 때 쓴다.

```text
text-shadow: 0 0 10px #8b5cf6, 0 0 20px #8b5cf6, 0 0 40px #8b5cf6;
color: #c4b5fd;
      ▼
그림자를 옮기지 않음(0 0) → 글자 바로 뒤에서 사방으로 번짐
같은 색을 10 · 20 · 40px 로 세 번 → 안쪽은 진하고 바깥으로 갈수록 옅게 퍼짐
      ▼
옅은 보라 글자 둘레에 보라 빛무리
```

- 오프셋이 0 이면 그림자가 한쪽으로 치우치지 않아 사방으로 고르게 퍼진다.
- 흐림이 없다면 그림자는 글자 바로 뒤에 완전히 숨는다 — 흐림이 있어야 비로소 글자 밖으로 번진다.
- 같은 색을 흐림만 달리해 겹치면 빛이 진한 중심부와 넓은 외곽을 함께 얻는다.
- 글자색을 옅게 하면 글자 자체가 빛나는 광원처럼 보인다.

```html demo
<p style="font-size:28px; font-weight:bold; color:#c4b5fd; background:#111;
          text-shadow: 0 0 10px #8b5cf6, 0 0 20px #8b5cf6;">Glow</p>
```

> **보이는 것** — 어두운 바탕 위 옅은 보라 글자 둘레에 보라 빛무리가 퍼진다 (코드에서 읽은 것 — 렌더 실측 아님)

### (5) 상속과 애니메이션

**언제 쓰나** — 한 영역의 글자 전체에 같은 그림자를 주거나, 그림자가 서서히 바뀌게 할 때 쓴다.

```text
.card { text-shadow: 1px 1px gray; }
   ├─ <h2>  → 물려받음 (그림자 있음)
   └─ <p>   → 물려받음 (그림자 있음)
        └─ <span style="text-shadow:none"> → 끊음 (그림자 없음)
```

- `text-shadow` 는 상속되는 속성이라 부모에 걸면 안쪽 글자 모두에 적용된다.
- 자식에서 `none` 을 주면 그 자식부터 그림자를 끈다.
- 애니메이션 가능한 속성이라 `transition` · `@keyframes` 로 값을 바꾸며 움직일 수 있다.

> **상속(inheritance)** — 부모에 지정한 값을 자식이 따로 지정하지 않아도 물려받는 성질.\
> 예: `body` 에 건 `text-shadow` 가 그 안의 모든 문단에 나타난다.

## 문법 — 형태와 규칙

```css
/* 형태: text-shadow: <offset-x> <offset-y> [<blur-radius>] [<color>] */
h1   { text-shadow: 2px 2px; }                     /* 색 생략 → 글자색 */
h2   { text-shadow: 2px 2px 4px rgba(0,0,0,0.3); } /* 네 값 모두 */
h3   { text-shadow: -1px -1px #fff; }              /* 음수 → 왼쪽 위 */
.glow {
  text-shadow: 0 0 8px gold, 0 0 16px gold;        /* 쉼표로 여러 장 */
}
.plain { text-shadow: none; }                      /* 끄기 */
```

| 값 | 뜻 | 생략하면 |
|---|---|---|
| `none` | 그림자 없음 (기본값) | — |
| `<offset-x>` | 가로 이동 거리, 양수면 오른쪽 | 생략 불가 |
| `<offset-y>` | 세로 이동 거리, 양수면 아래 | 생략 불가 |
| `<blur-radius>` | 흐림 반경, 0 이면 선명 | 0 |
| `<color>` | 그림자 색 | `currentcolor` (글자색) |

- 기본값은 `none` 이다.
- 두 오프셋은 반드시 함께 쓴다.
- 흐림과 색은 선택 사항이다.
- 여러 그림자는 **쉼표**로 잇는다 — 첫 그림자가 맨 위에 그려진다.
- 상속된다 · 애니메이션 가능하다.

> **`currentcolor`** — 요소의 현재 `color` 값을 가리키는 키워드.\
> 예: `color: navy` 인 글자에 색을 뺀 그림자를 주면 그림자도 navy 다.

## 어디서 틀리나

### 1. 여러 그림자를 공백으로 이어 쓴다

`1px 1px red 2px 2px blue` 처럼 쉼표를 빼면 한 장의 그림자 값으로 읽혀 문법 오류가 되고, 선언 전체가 무시된다.
원본 팁대로 여러 그림자는 **쉼표로 구분**한다.

### 2. 오프셋 0 에 흐림도 없다

`text-shadow: 0 0 red;` 는 그림자가 글자 바로 뒤에 정확히 겹쳐 글자에 가려진다.
원본 팁의 네온 공식은 「offset 0, **blur 만 크게**」다 — 흐림이 빠지면 아무것도 보이지 않는다.

### 3. 색을 빼서 그림자가 글자와 같은 색이 된다

색을 생략하면 기본이 `currentcolor` 라 그림자가 글자색과 같다.
오프셋이 작고 흐림이 없으면 그림자가 글자를 두껍게 만든 것처럼 보일 뿐, 그림자로 읽히지 않을 수 있다.

### 4. 흐림을 「넓히기」로 착각한다

흐림 반경은 가장자리를 번지게 할 뿐, 그림자를 단단하게 키우지 않는다.
흐림이 클수록 넓어지지만 그만큼 옅어진다.
네온 예제가 같은 색을 10 · 20 · 40px 로 세 번 겹치는 까닭이 여기에 있다 — 한 장으로는 넓으면서 진한 빛을 얻기 어렵다.

### 5. 부모에 걸었더니 모든 글자에 번진다

상속되는 속성이라 컨테이너에 걸면 안쪽 버튼 · 작은 글씨까지 그림자가 생긴다.
원치 않는 자식에는 `text-shadow: none` 을 준다.

### 6. 그림자가 공간을 차지한다고 여긴다

그림자는 레이아웃에 자리를 만들지 않는다(원본에 없는 서술 — CSS 명세 기준).
그래서 큰 흐림이나 큰 오프셋을 주면 이웃 요소 위로 겹치거나, `overflow: hidden` 인 부모 가장자리에서 잘릴 수 있다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 색을 생략하면 `currentcolor` 다 | CSS 명세 (원본 재료에도 있음) |
| 쉼표 목록의 첫 그림자가 맨 위에 그려진다 | CSS 명세 |
| 그림자는 레이아웃에 자리를 차지하지 않는다 | CSS 명세 |
| 흐림이 화면에 정확히 몇 픽셀까지 어떤 농도로 퍼지나 | 브라우저 구현 — 명세는 근사만 정하고 실제 픽셀은 엔진마다 다를 수 있다 (확인 필요) |
| 네온 · 띠 효과가 「빛나 보인다」「입체로 보인다」 | 보는 사람의 인상 — 어떤 명세도 보장하지 않는다 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 사진 위 제목을 또렷하게 | 반투명 검정, 작은 오프셋 + 흐림 | 흐림 없는 진한 그림자(글자가 지저분해짐) |
| 빛나는 제목 · 배너 | 오프셋 0 + 큰 흐림 여러 겹 | 오프셋 0 에 흐림 없음 |
| 레트로 입체 글자 | 오프셋을 조금씩 늘린 여러 색 그림자 | 공백으로 이은 목록 |
| 박스(카드) 자체의 그림자 | `box-shadow` | `text-shadow` (글자에만 그려진다) |
| 긴 본문 | 그림자 없음 | 큰 흐림 그림자(읽기 어려워짐) |

## 핵심 문장

1. **`text-shadow` 는 글자 윤곽을 본뜬 그림자를 글자 뒤에 깐다** — 두 오프셋은 필수, 흐림과 색은 선택이다.
2. **색을 빼면 글자색(`currentcolor`), 흐림을 빼면 0(선명)이다.**
3. **쉼표로 여러 장을 겹치고, 첫 장이 맨 위에 그려진다.**
4. **네온은 오프셋 0 + 큰 흐림** — 흐림이 없으면 그림자가 글자 뒤에 숨는다.
5. **상속되고 애니메이션 가능하다** — 부모에 걸면 퍼지고, `none` 으로 끊는다.

## 관련 자료

- `box-shadow` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `color` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- 원본: study-site 항목 데이터 `data/css/typography.json` 의 `text-shadow`

## 용어 풀이

- **`text-shadow`** — 글자에 그림자를 그리는 CSS 속성.
- **오프셋(offset)** — 그림자를 글자 자리에서 옮기는 거리(가로 · 세로).
- **흐림 반경(blur radius)** — 그림자 가장자리를 번지게 하는 정도.
- **`currentcolor`** — 요소의 현재 글자색을 가리키는 키워드.
- **`rgba()`** — 빨강 · 초록 · 파랑과 불투명도로 색을 적는 함수.
- **상속(inheritance)** — 부모의 값을 자식이 물려받는 성질.
- **네온(neon) 효과** — 글자 둘레가 고르게 빛나 보이게 하는 꾸밈.
- **`box-shadow`** — 글자가 아니라 요소의 박스에 그림자를 그리는 속성.

## 더 들어가면

- 명세상 색은 그림자 값의 맨 앞에 써도 된다(`#000 2px 2px`) — 원본 문법은 맨 뒤에만 적는다 (확인 필요).
- `box-shadow` 와 달리 `text-shadow` 에는 퍼짐(spread) 값과 `inset` 이 없다 (확인 필요).
- 흐림 반경에 음수는 쓸 수 없다 (확인 필요).
- 명세는 흐림을 가우스 흐림에 가깝게, 표준편차를 흐림 반경의 절반쯤으로 그리라고 적는다 (확인 필요).
- 그림자 목록끼리 애니메이션할 때 개수가 다르면 짧은 쪽을 투명한 그림자로 채워 보간한다 (확인 필요).
- 그림자가 많고 흐림이 크면 그리는 비용이 커져 애니메이션이 버벅일 수 있다 (확인 필요).
