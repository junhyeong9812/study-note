## 퀴즈

### 1. `.red` 단락의 글자와 마크 (예측)

```css
/* 질문용 발췌 */
p { color: #111827; }
.red { text-emphasis: filled dot; text-emphasis-color: #ef4444; }
```

- `.red` 단락에서 글자는 무슨 색이고, 마크는 무슨 색인가?

### 2. 색을 먼저 쓰고 단축 속성을 뒤에 쓰면 (예측)

```css
/* 질문용 발췌 */
.x {
  color: #111827;
  text-emphasis-color: #ef4444;
  text-emphasis: filled dot;
}
```

- `.x` 의 마크는 무슨 색으로 칠해지는가?

### 3. 마크 모양 없이 색만 준 단락 (예측)

```css
/* 질문용 발췌 */
.y { text-emphasis-color: #3b82f6; }
```

- `.y` 단락에서 파랑으로 칠해진 무언가가 보이는가?

### 4. 마크 색을 안 정했을 때 글자색을 바꾸면 마크도 같이 바뀌는 까닭 (왜)

- `text-emphasis-color` 를 쓰지 않은 요소에서 `color` 만 바꿨는데 마크 색까지 바뀌는 것은 왜인가?

### 5. 마크 색을 글자색과 다르게 고르는 까닭 (왜)

- 마크를 글자와 같은 색으로 두지 않고 일부러 다른 색으로 칠하는 것은 무엇을 얻으려는 것인가?

### 6. 부모에 정한 마크 색이 미치는 범위 (경계)

- 부모 `p` 에만 마크 색을 정하고 안쪽 `span` 에는 모양만 주면, `span` 의 마크 색은 어떻게 정해지는가?

### 7. 마크 색을 서서히 바꾸기 (경계)

- 마우스를 올렸을 때 `transition` 으로 마크 색이 중간 색을 거치며 바뀌게 할 수 있는가?

### 8. `color` · `text-emphasis` · `text-emphasis-color` 의 몫 (연결)

- 세 속성은 각각 글자의 무엇을 정하고, 마크가 보이려면 어느 것이 꼭 있어야 하는가?

## 실습

### 실습 1. 빨간 점과 파란 원 강조 마크 달기

**만들 것** — 두 단락에 서로 다른 모양의 강조 마크를 달고, 글자색은 그대로 둔 채 마크의 색만 단락마다 다르게 칠한다.

**요구 조건**
1. 「빨간 강조 마크」 단락(`.red`)과 「파란 강조 마크」 단락(`.blue`)을 둔다.
2. `.red` 단락의 글자마다 채워진 점(`filled dot`) 마크가 붙는다.
3. `.red` 의 마크만 빨강으로 칠하고 글자색은 바꾸지 않는다.
4. `.blue` 단락의 글자마다 채워진 원(`filled circle`) 마크가 붙는다.
5. `.blue` 의 마크만 파랑으로 칠하고 글자색은 바꾸지 않는다.
6. 마크 색은 마크 모양을 정한 단축 속성 **뒤에** 따로 적는 `text-emphasis-color` 로 정한다.

**시작 코드**

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <title>text-emphasis-color 연습</title>
  <style>
    .red {
      /* TODO: 채워진 점 마크를 단다 */
      /* TODO: 마크 색만 #ef4444 로 (글자색은 그대로) */
      font-size: 20px;
      margin-bottom: 12px;
    }

    .blue {
      /* TODO: 채워진 원 마크를 단다 */
      /* TODO: 마크 색만 #3b82f6 로 (글자색은 그대로) */
      font-size: 20px;
    }
  </style>
</head>
<body>
  <p class="red">빨간 강조 마크</p>
  <p class="blue">파란 강조 마크</p>
</body>
</html>
```

**확인 방법** — 파일을 브라우저로 열어, 첫 단락은 글자마다 빨간 점이, 둘째 단락은 글자마다 파란 원이 붙고 두 단락의 글자색은 원래 색 그대로인지 본다.
