## 한눈에 — 쉽게 말하면

**`text-emphasis-color` 는 「방점 도장의 잉크 색」이다.**
교과서에서 중요한 글자 위에 작은 점(방점)을 찍을 때, 도장 모양과 잉크 색은 따로 고를 수 있다.
잉크를 따로 고르지 않으면 글씨를 쓴 펜과 같은 색으로 찍힌다.
CSS 의 강조 마크도 똑같은 구조다.

> **강조 마크** — 글자 하나하나 옆(가로쓰기에서는 보통 위)에 찍히는 작은 표시(점 · 원 따위)다.\
> 예: `text-emphasis: filled dot;` 을 주면 글자마다 채워진 점이 하나씩 붙는다.

> **방점** — 글자 옆에 찍어 강조를 나타내는 점이다. 강조 마크를 우리말로 부르는 이름이다.\
> 예: 「중요」 두 글자 위에 점 두 개를 찍는다.

| 비유 | 실체 |
|---|---|
| 방점 도장의 모양 | `text-emphasis`(또는 그 안의 모양 값 `filled dot` · `filled circle`) |
| 도장 잉크 색 | `text-emphasis-color` 값 |
| 글씨를 쓴 펜 색 | `color` 값 |
| 잉크를 따로 안 고르면 펜 색으로 찍힘 | 기본값 `currentcolor` |

```text
   ●  ●  ●  ●        ← 마크  : text-emphasis-color 가 칠한다
   빨 간 강 조        ← 글자  : color 가 칠한다
```

## 이 주제가 답하려는 질문

1. 강조 마크의 색은 무엇이 정하고, 아무것도 안 정하면 무슨 색이 되나?
2. 마크 색만 바꾸고 글자색은 그대로 둘 수 있나?
3. 부모에 정한 마크 색은 자식에게도 이어지나, 시간에 따라 바뀌게 할 수 있나?

## 동작 방식

### (1) 기본값 `currentcolor` — 마크가 글자색을 따른다

**언제 쓰나** — 마크 색을 따로 정할 필요가 없을 때 그냥 둔다.
글자색과 마크색이 늘 같아야 할 때도 이 값이 알맞다.

> **`currentcolor`** — 「지금 이 요소의 `color` 값」을 가리키는 색 키워드다.\
> 예: `color: green` 인 요소에서 `currentcolor` 는 초록이다.

```text
.note { text-emphasis: filled dot; color: green; }
        │
        ├─ text-emphasis-color 를 안 썼다 → 기본값 currentcolor
        │
        └─ currentcolor = 이 요소의 color = green
                │
                ▼
   글자: 초록   마크: 초록
```

- 마크 모양은 `text-emphasis` 로 정했지만 색은 정하지 않았다.
- 그러면 `text-emphasis-color` 는 기본값 `currentcolor` 를 쓴다.
- `currentcolor` 는 그 요소의 `color` 를 가리키므로 마크가 글자와 같은 초록이 된다.
- 나중에 `color` 를 바꾸면 마크도 같이 바뀐다.

### (2) 색을 따로 정하면 마크만 바뀐다

**언제 쓰나** — 마크를 글자와 다른 색으로 칠해 눈에 띄게 할 때 쓴다.
원본 팁이 말하는 「시각적 대비 효과」가 이 쓰임이다.

```text
.red {
  text-emphasis: filled dot;      ① 마크 모양: 채워진 점
  text-emphasis-color: #ef4444;   ② 마크 색: 빨강
}                                  (color 는 건드리지 않음)
        │
        ▼
   글자: 원래 글자색 그대로   마크: 빨강
```

- ①이 글자마다 채워진 점을 붙인다.
- ②가 그 점의 색만 빨강으로 바꾼다.
- `color` 는 그대로이므로 글자는 원래 색을 유지한다.
- 마크와 글자가 서로 다른 색이 되어 대비가 생긴다.

### (3) 상속 — 부모에 정하면 자식에게 이어진다

**언제 쓰나** — 한 구역 전체의 마크 색을 한 번에 맞출 때 부모에 한 번만 쓴다.

> **상속** — 부모 요소에 정한 속성 값이 자식 요소로 이어지는 성질이다.\
> 예: `<p>` 에 정한 값이 그 안의 `<span>` 에도 적용된다.

```text
<p style="text-emphasis-color: #3b82f6">
   └─ <span style="text-emphasis: filled circle">강조</span>
        │
        ├─ span 에는 마크 색을 안 썼다
        ├─ text-emphasis-color 는 상속되는 속성이다
        └─ 부모 p 의 파랑을 물려받는다
                │
                ▼
   span 의 원 마크: 파랑
```

- `span` 은 마크 모양만 정했다.
- 마크 색은 정하지 않았지만 이 속성은 상속된다(원본: 상속 `True`).
- 그래서 부모 `p` 에 적은 파랑이 `span` 의 마크 색이 된다.

### (4) 애니메이션 가능 — 마크 색을 서서히 바꿀 수 있다

**언제 쓰나** — 마우스를 올렸을 때 마크 색이 부드럽게 바뀌게 하고 싶을 때 쓴다.

```text
.mark { text-emphasis: filled dot; text-emphasis-color: #9ca3af;
        transition: text-emphasis-color 0.3s; }
.mark:hover { text-emphasis-color: #ef4444; }
        │
        ▼
   마우스 올림 → 0.3초 동안 회색 → 빨강으로 이어지며 바뀜
```

- 이 속성은 애니메이션 가능한 속성이다(원본: 애니메이션 가능 `True`).
- 그래서 `transition` 에 이름을 적으면 두 색 사이가 이어지며 바뀐다.
- 한순간에 툭 바뀌는 것이 아니라 중간 색을 거친다.

## 문법 — 형태와 규칙

```html demo
<p class="a">기본 마크</p>
<p class="b">파란 마크</p>
<style>
  .a { text-emphasis: filled dot; color: #111827; font-size: 20px; }
  .b { text-emphasis: filled circle; text-emphasis-color: #3b82f6;
       color: #111827; font-size: 20px; }
</style>
```

> **보이는 것** — 첫 줄은 글자와 점 마크가 모두 짙은 색, 둘째 줄은 글자는 짙은 색이고 원 마크만 파랑이다 (코드에서 읽은 것 — 렌더 실측 아님)

형태:

```css
text-emphasis-color: <color>;
```

| 값 | 뜻 |
|---|---|
| `currentcolor` | 텍스트 색상과 같다 (기본값) |
| `<color>` | CSS 색상 값 — `#ef4444` · `rgb(...)` · `blue` 등 어떤 색 표기든 된다 |

| 성질 | 값 |
|---|---|
| 기본값 | `currentcolor` |
| 상속 | 된다 |
| 애니메이션 | 된다 |

규칙:

- 이 속성은 **마크의 색만** 정한다. 글자색(`color`)은 건드리지 않는다.
- 마크 모양은 이 속성이 정하지 않는다. `text-emphasis` 로 모양을 줘야 칠할 마크가 생긴다.
- `text-emphasis` 는 모양과 색을 함께 받는 단축 속성이다. 그래서 같은 규칙 안에서 쓰는 순서가 중요하다(「어디서 틀리나」 2).

> **단축 속성** — 여러 속성을 한 줄에 묶어 정하는 속성이다. 빠뜨린 부분은 기본값으로 되돌린다.\
> 예: `text-emphasis: filled dot;` 은 모양을 `filled dot` 으로, 색은 기본값으로 정한다.

## 어디서 틀리나

### 1. 색만 정하고 마크 모양을 안 정했다

`text-emphasis-color: #ef4444;` 만 쓰면 아무 변화가 없다.
이 속성은 이미 있는 마크에 색을 칠할 뿐, 마크를 만들지 않는다.
마크 모양의 기본은 「없음」이라 칠할 대상이 없다.
반드시 `text-emphasis`(모양)와 짝으로 쓴다.

### 2. 단축 속성을 색 뒤에 썼다

```css
.x {
  text-emphasis-color: #ef4444;   /* 먼저 빨강으로 정함 */
  text-emphasis: filled dot;      /* 단축 속성이 색을 기본값으로 되돌림 */
}
```

`text-emphasis` 는 색까지 정하는 단축 속성이다.
색을 적지 않은 단축 속성은 색을 기본값 `currentcolor` 로 돌려놓는다.
뒤에 쓴 선언이 이기므로 마크가 빨강이 아니라 글자색이 된다.
원본 예제처럼 **단축 속성을 먼저, `text-emphasis-color` 를 그 뒤에** 쓴다.

### 3. 대비를 노렸는데 색이 글자와 비슷하다 (원본 팁)

원본 팁은 「강조 마크 색상을 텍스트와 다르게 설정하여 시각적 대비 효과를 줄 수 있다」고 말한다.
마크는 글자보다 훨씬 작다.
그래서 글자와 비슷한 색이면 따로 칠한 효과가 거의 드러나지 않는다.
대비를 노린다면 글자색과 확실히 다른 색을 고른다.

### 4. 글자색을 바꿨는데 마크가 따라오지 않는다

마크 색을 고정 값으로 정해 두면 그 뒤 `color` 를 바꿔도 마크는 그대로다.
글자와 늘 같은 색이길 원한다면 이 속성을 쓰지 말고 기본값 `currentcolor` 에 맡긴다.

### 5. 부모 색이 자식으로 새어 들어간다

이 속성은 상속된다.
부모에 정한 마크 색은, 자식이 따로 정하지 않는 한 자식의 마크에도 쓰인다.
자식만 다른 색을 원하면 자식에 직접 적는다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 기본값은 `currentcolor` | CSS 명세의 속성 정의 (원본 재료 기준) |
| 상속된다 · 애니메이션 가능하다 | CSS 명세의 속성 정의 (원본 재료 기준) |
| `text-emphasis` 단축 속성이 색을 기본값으로 되돌린다 | CSS 의 단축 속성 규칙 |
| 마크가 실제 화면에 어떻게 그려지나(크기 · 위치 · 글꼴과 어울림) | 각 브라우저 렌더러 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 마크를 글자와 다른 색으로 눈에 띄게 | `text-emphasis-color: <색>` | 글자색까지 바꾸는 `color` |
| 마크가 늘 글자색을 따라야 | 기본값 `currentcolor` (아무것도 안 씀) | 고정 색 값 |
| 한 구역의 마크 색을 한 번에 | 부모에 한 번 정하고 상속에 맡김 | 자식마다 반복해 적기 |
| 마우스를 올리면 마크 색이 서서히 바뀌게 | `transition: text-emphasis-color …` | 모양을 바꾸는 방법 |
| 마크 자체를 새로 붙이기 | `text-emphasis`(모양) | `text-emphasis-color` 만 |

## 핵심 문장

1. **`text-emphasis-color` 는 강조 마크의 색만 칠한다** — 글자색은 건드리지 않는다.
2. **기본값 `currentcolor` 때문에 따로 안 정하면 마크는 글자색을 따른다.**
3. **마크를 만드는 것은 `text-emphasis` 다** — 모양 없이 색만 주면 보이는 것이 없다.
4. **단축 속성 `text-emphasis` 는 색을 되돌리므로 색은 그 뒤에 쓴다.**
5. **상속되고 애니메이션된다** — 부모에 한 번 정할 수 있고, 색을 서서히 바꿀 수 있다.

## 용어 풀이

- **강조 마크** — 글자마다 옆에 찍히는 작은 표시(점 · 원 등).
- **방점** — 강조 마크를 우리말로 부르는 이름. 글자 옆에 찍는 점.
- **`currentcolor`** — 지금 요소의 `color` 값을 가리키는 색 키워드.
- **단축 속성** — 여러 속성을 한 줄에 묶어 정하는 속성. 빠진 부분은 기본값으로 돌린다.
- **상속** — 부모 요소의 속성 값이 자식에게 이어지는 성질.
- **`transition`** — 속성 값이 바뀔 때 중간 값을 거쳐 서서히 바뀌게 하는 속성.
- **대비** — 두 색이 서로 얼마나 뚜렷이 달라 보이는가.

## 더 들어가면

- 강조 마크 관련 속성들은 일부 브라우저에서 `-webkit-` 접두사가 붙은 이름으로 먼저 지원되었다 (확인 필요).
- 마크가 글자의 위에 찍히나 아래에 찍히나는 `text-emphasis-position` 이 정한다 (확인 필요).
- `currentcolor` 가 상속될 때는 계산된 색이 아니라 키워드 자체가 이어져, 자식의 마크가 자식의 `color` 를 따른다고 알려져 있다 (확인 필요).
- 강조 마크는 원래 한중일 문자에서 쓰는 방점 관습을 옮겨 온 기능이다 (확인 필요).
