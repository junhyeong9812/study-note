## 한눈에 — 쉽게 말하면

**`text-shadow` 는 「글자 모양의 도장을 한 번 더 찍는 것」이다.**
글자를 다 쓴 뒤 같은 모양의 도장을 조금 옆으로 밀어서 찍고, 잉크를 번지게 하거나 색을 바꿀 수 있다.
도장은 한 번만 찍을 필요가 없다.
쉼표로 이어 쓰면 여러 번 찍는다.
`text-shadow` 도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 글자 모양 도장 | 그림자 한 겹 (`<shadow>`) |
| 도장을 옆으로 미는 거리 | `<offset-x> <offset-y>` |
| 잉크가 번지는 정도 | `<blur-radius>` |
| 잉크 색 | `<color>` |
| 도장을 여러 번 찍기 | 쉼표로 이은 그림자 목록 (`<shadow>#`) |

```text
  원래 글자        그림자(오른쪽·아래로 밀림)
   ┌───┐
   │ A │──┐
   └───┘  │  ← offset-x, offset-y 만큼 이동
      ┌───┐
      │ A │  ← blur 가 크면 가장자리가 번진다
      └───┘
```

## 이 주제가 답하려는 질문

1. 글자에 그림자를 붙이려면 무엇을 어떤 차례로 적나?
2. 그림자를 여러 겹 쌓으면 어떤 효과(네온 · 엠보스 · 외곽선)를 만들 수 있나?
3. `box-shadow` 와는 무엇이 다른가?
4. 부모에 준 그림자는 자식 글자에도 붙나?

## 동작 방식

### (1) 그림자 한 겹 — 위치 · 흐림 · 색

**언제 쓰나** — 글자를 배경에서 살짝 띄우거나 읽기 쉽게 할 때.

```text
text-shadow: 2px 2px 4px black;
             │   │   │   └ 색: 검정
             │   │   └ 흐림 4px
             │   └ 아래로 2px
             └ 오른쪽으로 2px
        ↓
글자와 같은 모양의 검은 복사본이 오른쪽 아래로 2px 밀려
가장자리가 번진 채로 글자 뒤에 깔린다
```

- 첫 길이는 가로 이동이고, 양수면 오른쪽, 음수면 왼쪽이다.
- 둘째 길이는 세로 이동이고, 양수면 아래, 음수면 위다.
- 셋째 길이는 흐림이고, 0 이면 가장자리가 또렷하다.
- 그림자는 글자 뒤에 깔리므로 글자를 가리지 않는다.

> **오프셋(offset)** — 그림자를 원래 글자 자리에서 옮기는 거리.\
> 예: `-1px -1px` 은 왼쪽 위로 1px 씩 옮긴다.

> **흐림 반경(blur-radius)** — 그림자 가장자리를 얼마나 넓게 번지게 할지 정하는 길이.\
> 예: `0` 이면 칼로 자른 듯하고, `60px` 이면 멀리까지 옅게 퍼진다.

### (2) 여러 겹 — 쉼표로 잇기

**언제 쓰나** — 한 겹으로 못 내는 효과(빛 번짐 · 입체 · 테두리)를 만들 때.

```text
text-shadow: 0 0 10px #ff00ff, 0 0 30px #ff00ff, 0 0 60px #ff00ff;
             └── 1겹 ──┘        └── 2겹 ──┘        └── 3겹 ──┘
        ↓
세 겹 모두 오프셋 0 → 글자 바로 뒤에 겹쳐 깔림
흐림이 10 → 30 → 60 으로 커짐 → 가까운 곳은 진하고 먼 곳은 옅은 빛
        ↓
네온 사인처럼 글자 둘레가 빛나 보인다
```

- 문법의 `<shadow>#` 에서 `#` 은 「쉼표로 이은 목록」을 뜻한다.
- 오프셋이 0 이면 그림자가 한쪽으로 치우치지 않고 사방으로 고르게 번진다.
- 같은 색을 흐림만 달리해 겹치면 가운데는 진하게, 바깥은 옅게 쌓인다.
- 이것이 원본 팁의 「네온 효과는 여러 겹의 blur가 큰 그림자로 구현」이다.

> **글로우(glow)** — 오프셋 없이 흐림만 준 그림자로 글자 둘레가 빛나 보이게 하는 효과.\
> 예: `0 0 10px #ff00ff`.

### (3) 방향이 반대인 두 겹 — 엠보스

**언제 쓰나** — 글자가 바탕에서 솟거나 파인 듯한 입체감을 줄 때.

```text
text-shadow: 1px 1px 0 rgba(255,255,255,0.3),   ← 오른쪽 아래, 반투명 흰색
            -1px -1px 0 rgba(0,0,0,0.5);         ← 왼쪽 위, 반투명 검정
        ↓
한쪽 가장자리에는 밝은 선, 반대쪽 가장자리에는 어두운 선
        ↓
빛이 한 방향에서 비친 것처럼 읽혀 입체로 보인다
```

- 밝은 그림자와 어두운 그림자를 서로 반대 방향으로 민다.
- 흐림 0 이라 선이 또렷하다.
- 색에 알파(투명도)를 주어 바탕색과 섞이게 한다.

> **엠보스(emboss)** — 밝은 면과 어두운 면을 반대쪽에 두어 글자가 돋거나 파인 듯 보이게 하는 효과.\
> 예: 흰 그림자는 오른쪽 아래로, 검은 그림자는 왼쪽 위로 민다.

### (4) 네 방향 네 겹 — 외곽선

**언제 쓰나** — 글자에 테두리(스트로크)를 두르고 싶을 때의 대체 수단.

```text
(-1,-1)   ( 1,-1)
     ╲     ╱
       글자          ← 같은 색, 흐림 0, 대각선 네 방향으로 1px 씩
     ╱     ╲
(-1, 1)   ( 1, 1)
        ↓
네 복사본이 글자 둘레를 1px 씩 덮어 테두리처럼 보인다
```

- 네 그림자는 색이 모두 같고 흐림은 0 이다.
- 대각선 네 방향으로 밀어 글자 가장자리 바깥을 둘러싼다.

```html demo
<div style="background:#1a1a2e; padding:16px; text-align:center;">
  <span style="color:#fff; font-size:28px; font-weight:bold;
               text-shadow: 0 0 10px #ff00ff, 0 0 30px #ff00ff;">GLOW</span>
  <span style="color:white; font-size:22px; font-weight:bold;
               text-shadow: -1px -1px 0 #3b82f6, 1px -1px 0 #3b82f6, -1px 1px 0 #3b82f6, 1px 1px 0 #3b82f6;">Line</span>
</div>
```

> **보이는 것** — 어두운 바탕에 핑크로 번져 빛나는 흰 「GLOW」와 파란 테두리를 두른 흰 「Line」 (코드에서 읽은 것 — 렌더 실측 아님)

### (5) 상속 — 부모에 주면 자식 글자에도

**언제 쓰나** — 영역 안의 모든 글자에 같은 그림자를 줄 때.

```text
<div style="text-shadow: 1px 1px 2px gray">   ← 부모에만 지정
  <p>안녕</p>                                  ← 자식은 지정 안 함
</div>
        ↓
text-shadow 는 상속되는 속성
        ↓
자식 <p> 의 글자에도 같은 그림자가 붙는다
```

- 자식이 따로 `text-shadow` 를 지정하면 그 값이 상속값을 대신한다.
- 자식에서 그림자를 없애려면 `text-shadow: none` 을 준다.

> **상속(inheritance)** — 자식 요소가 값을 지정하지 않았을 때 부모의 계산된 값을 이어받는 것.\
> 예: `color` 와 `text-shadow` 는 상속되고, `box-shadow` 는 상속되지 않는다.

### (6) 애니메이션 — 그림자도 부드럽게 바뀐다

**언제 쓰나** — 마우스를 올리면 빛이 강해지는 버튼 글자처럼, 그림자를 서서히 바꿀 때.

```text
.a        { text-shadow: 0 0 0 #ff00ff;  transition: text-shadow .3s; }
.a:hover  { text-shadow: 0 0 20px #ff00ff; }
        ↓
text-shadow 는 애니메이션 가능한 속성
        ↓
흐림 0 → 20px 사이 값이 0.3초 동안 채워진다
```

## 문법 — 형태와 규칙

```css
/* 최소 예제 */
.plain  { text-shadow: none; }                         /* 기본값: 그림자 없음 */
.one    { text-shadow: 2px 2px 4px rgba(0,0,0,.4); }   /* x y blur color */
.sharp  { text-shadow: 2px 2px 0 black; }              /* 흐림 0: 또렷한 복사본 */
.many   { text-shadow: 0 0 8px cyan, 0 0 24px cyan; }  /* 쉼표로 여러 겹 */
.parent { text-shadow: 1px 1px 1px gray; }             /* 자식 글자에도 상속 */
.child  { text-shadow: none; }                         /* 상속된 그림자 끄기 */
```

| 값 | 뜻 | 비고 |
|---|---|---|
| `none` | 그림자 없음 | 기본값 |
| `<offset-x> <offset-y>` | 그림자 위치 | 양수 = 오른쪽 · 아래, 음수 = 왼쪽 · 위, 0 = 제자리 |
| `<blur-radius>` | 흐림 정도 | 0 이면 또렷한 가장자리, 클수록 넓고 옅게 퍼진다 |
| `<color>` | 그림자 색상 | 알파를 주면 바탕과 섞인다 |
| `<shadow>#` | 위 그림자를 쉼표로 여러 개 | 네온 · 엠보스 · 외곽선의 바탕 |

- 문법: `text-shadow: none | <shadow>#`.
- 기본값은 `none` 이다.
- 상속된다.
- 애니메이션할 수 있다.
- `spread-radius`(그림자 크기를 키우는 값)는 없다 — `box-shadow` 와의 차이다.

## 어디서 틀리나

### 1. `box-shadow` 처럼 spread 를 넣으려 한다

`box-shadow` 에는 그림자를 넓히는 `spread-radius` 가 있지만 `text-shadow` 에는 없다.
글자 그림자를 굵게 하고 싶으면 spread 대신 흐림을 키우거나, 그림자를 여러 방향으로 여러 겹 겹친다.
외곽선 효과(동작 방식 (4))가 바로 그렇게 spread 없이 두께를 만든 예다.

### 2. 네온을 한 겹으로 만들려 한다

한 겹만 주면 흐림이 작을 때는 번짐이 좁고, 클 때는 글자 근처가 너무 옅어진다.
원본 팁대로 흐림이 큰 그림자를 여러 겹 쌓아야 가운데는 진하고 바깥은 넓게 퍼진 빛이 된다.
네온은 어두운 바탕 위에서 대비가 커져 두드러진다 — 원본 예제가 어두운 남보라 배경을 쓴 까닭이다.

### 3. 상속을 잊는다

`text-shadow` 는 상속되므로 부모에 준 그림자가 자식 글자에도 붙는다.
원하지 않는 자식에는 `text-shadow: none` 을 따로 준다.
반대로, 여러 요소에 같은 그림자를 주려면 공통 부모에 한 번만 주면 된다.

### 4. 엠보스의 「양각」이라는 이름을 그대로 믿는다

원본 정답 코드 주석은 `.emboss` 를 「입체 양각」이라 부르고, 소제목에서는 「양각/음각 느낌」이라 한다.
왜 의심스러운가: 이 코드는 어두운 그림자를 왼쪽 위에, 밝은 그림자를 오른쪽 아래에 둔다.
빛이 왼쪽 위에서 온다고 읽으면 이 배치는 솟은 글자보다 파인 글자(음각)에 가깝게 보일 수 있다.
입체감이 솟아 보이는지 파여 보이는지는 보는 사람이 빛 방향을 어떻게 읽느냐에 달려 있다 (확인 필요).
양각과 음각을 바꾸고 싶으면 두 그림자의 방향을 서로 맞바꾼다.

### 5. 외곽선을 두껍게 하려고 오프셋만 키운다

네 대각선 방향 복사본으로 테두리를 흉내 내는 방식이라, 오프셋을 키우면 위 · 아래 · 좌 · 우 가운데가 비어 끊겨 보일 수 있다 (원본에 근거 없음 — 추론).
1px 정도의 얇은 외곽선에 알맞은 방식이다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 문법 `none \| <shadow>#`, 기본값 `none` | CSS 사양 |
| 상속된다 · 애니메이션 가능하다 | CSS 사양 |
| `spread-radius` 가 없다 | CSS 사양(문법에 자리가 없다) |
| 여러 겹을 쌓으면 「네온처럼」 · 「양각처럼」 · 「테두리처럼」 보인다 | 사양이 아니라 렌더링 결과를 사람이 읽은 인상이다. 흐림의 정확한 모양은 브라우저의 그리기 방식에 따른다 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 글자에 그림자 · 빛 번짐 | `text-shadow` | `box-shadow`(상자 둘레에 그려진다) |
| 카드 · 버튼 상자 둘레 그림자 | `box-shadow` | `text-shadow`(글자 모양만 따른다) |
| 네온 글자 | 같은 색 · 오프셋 0 · 흐림을 키운 여러 겹 | 흐림 큰 한 겹 |
| 얇은 글자 테두리 | 네 대각선 방향 1px 그림자 | spread 값(없다) |
| 영역 전체 글자에 같은 그림자 | 공통 부모에 한 번 | 자식마다 반복 지정 |
| 특정 자식만 그림자 빼기 | 그 자식에 `text-shadow: none` | 부모 값을 지우기 |

## 핵심 문장

1. **`text-shadow` 는 글자 모양의 복사본을 `x y blur color` 로 옮기고 번지게 해 글자 뒤에 깐다.**
2. **쉼표로 여러 겹을 쌓을 수 있고, 네온 · 엠보스 · 외곽선은 모두 「겹 쌓기」의 응용이다.**
3. **`spread-radius` 가 없다 — `box-shadow` 와 가장 크게 다른 점이다.**
4. **상속되므로 부모에 주면 자식 글자에도 붙고, 끄려면 `none` 을 준다.**
5. **애니메이션할 수 있어 `transition` 으로 빛이 서서히 커지게 할 수 있다.**

## 관련 자료

- `box-shadow` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `color` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `filter` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- 원본: study-site 항목 데이터 `data/css/visual.json` 의 `visual--text-shadow`

## 용어 풀이

- **그림자(`<shadow>`)** — 오프셋 · 흐림 · 색으로 이루어진 그림자 한 겹.
- **오프셋(offset)** — 그림자를 원래 자리에서 옮기는 가로 · 세로 거리.
- **흐림 반경(blur-radius)** — 그림자 가장자리를 번지게 하는 정도.
- **spread-radius** — `box-shadow` 에서 그림자 크기를 키우는 값. `text-shadow` 에는 없다.
- **글로우(glow)** — 오프셋 없이 흐림만 준 빛 번짐 효과.
- **네온(neon)** — 같은 색 글로우를 흐림을 키워 여러 겹 쌓은 효과.
- **엠보스(emboss)** — 밝은 그림자와 어두운 그림자를 반대쪽에 두어 입체로 보이게 하는 효과.
- **외곽선(outline)** — 네 방향 그림자로 글자 테두리를 흉내 낸 효과.
- **상속(inheritance)** — 지정하지 않은 자식이 부모의 값을 이어받는 것.
- **애니메이션 가능** — `transition` · `animation` 으로 두 값 사이를 부드럽게 바꿀 수 있다는 뜻.
- **`<shadow>#`** — 문법 표기에서 `#` 은 쉼표로 이은 목록을 뜻한다.
