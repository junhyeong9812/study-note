## 한눈에 — 쉽게 말하면

**`scroll-margin` 은 「주차 칸 앞에 그어 둔 정지선」이다.**
차(스크롤)는 주차 칸(카드) 모서리에 딱 붙어 서지 않고, 정지선만큼 떨어진 자리에 선다.
정지선은 칸마다 따로 그을 수 있고, 주차장 전체의 벽(컨테이너)은 건드리지 않는다.
스크롤 스냅도 똑같은 구조다.
스크롤이 멈출 자리를 정할 때, 카드의 테두리 대신 카드 바깥으로 `scroll-margin` 만큼 부풀린 상자를 기준으로 삼는다.

| 비유 | 실체 |
|---|---|
| 주차장 | 스크롤 컨테이너 (`scroll-snap-type` 을 단 요소) |
| 주차 칸 | 스냅 대상 자식 (`scroll-snap-align` 을 단 요소) |
| 정지선까지의 거리 | `scroll-margin` 값 |
| 차가 서는 자리 | 스냅 위치 |

```text
 컨테이너 왼쪽 끝
 │
 │◀─16px─▶┌──────── 카드 ────────┐
 │        │                      │
 │        └──────────────────────┘
 └ 스냅이 끝나면 카드는 왼쪽 끝에서 16px 안쪽에 멈춘다
```

> **스크롤 스냅** — 스크롤이 끝났을 때 미리 정한 자리(스냅 위치)로 끌어당겨 멈추게 하는 CSS 기능.\
> 예: 가로 캐러셀에서 손을 떼면 카드 하나가 딱 맞춰 멈춘다.

> **스냅 영역** — 스냅 위치를 계산할 때 기준으로 쓰는 자식의 상자. 자식의 테두리 상자에 `scroll-margin` 을 바깥으로 더한 것이다.\
> 예: 너비 180px 카드에 좌우 `scroll-margin: 16px` 이면 스냅 영역은 좌우로 16px 씩 넓다.

## 이 주제가 답하려는 질문

1. 스냅된 카드를 컨테이너 가장자리에서 조금 떨어뜨려 멈추게 하려면 어디에 무엇을 적나?
2. `scroll-margin` 은 카드 배치(카드 사이 간격)를 바꾸나?
3. 컨테이너에 다는 `scroll-padding` 과 자식에 다는 `scroll-margin` 은 무엇이 다른가?
4. 계산된 스냅 위치로 스크롤할 수 없을 때(첫 카드 · 마지막 카드)는 어떻게 되나?

## 동작 방식

### (1) 스냅 영역이 바깥으로 부푼다

**언제 쓰나** — 카드 하나하나의 멈출 자리를 미세하게 옮기고 싶을 때 쓴다.

```text
.snap-item { scroll-snap-align: start; scroll-margin: 0 16px; }

   ┌16┐┌────── 카드 180px ──────┐┌16┐
   ╔══╧╧════════════════════════╧╧══╗
   ║        스냅 영역 212px         ║
   ╚════════════════════════════════╝
   ▲
   └ 스냅 영역의 시작 모서리 = 카드 왼쪽 모서리 - 16px
```

- `scroll-margin: 0 16px` 은 위아래 0, 좌우 16px 이다.
- 카드의 테두리 상자 바깥으로 좌우 16px 씩 붙인 상자가 스냅 영역이 된다.
- 카드 자체의 크기와 자리는 그대로다.
- 바뀌는 것은 「어디에 멈출지 계산할 때 쓰는 상자」뿐이다.

### (2) 스냅 정렬은 스냅 영역의 모서리를 맞춘다

**언제 쓰나** — `scroll-snap-align` 과 함께 멈출 자리를 정할 때 이 계산이 일어난다.

```text
scroll-snap-align: start  →  스냅 영역의 시작 모서리를 컨테이너 시작 모서리에 맞춘다

 컨테이너 [            200px            ]
          ╔16╗┌──── 카드 2 ────
          ║  ║│
          ╚══╝└────────────────
          ▲
          └ 스냅 영역 시작이 여기 맞춰지므로 카드 2 는 16px 안쪽에 멈춘다
```

- `start` 는 스냅 영역의 시작 모서리(가로 · 왼쪽에서 오른쪽 문서라면 왼쪽)를 컨테이너의 시작 모서리에 맞춘다.
- 스냅 영역이 카드보다 16px 앞에서 시작하므로, 카드는 컨테이너 왼쪽 끝에서 16px 떨어진다.
- 그래서 `start` 정렬일 때는 왼쪽 `scroll-margin` 만 멈출 자리에 영향을 준다.
- 오른쪽 `scroll-margin` 은 `end` 정렬일 때 쓰인다(`center` 는 양쪽을 다 넣은 상자의 가운데를 맞춘다).

> **스냅포트** — 스냅 정렬의 기준이 되는 컨테이너 쪽 상자. 컨테이너의 보이는 영역에서 `scroll-padding` 만큼 안으로 줄인 것이다.\
> 예: `scroll-padding` 이 없으면 스냅포트는 컨테이너의 보이는 영역 그대로다.

### (3) `mandatory` 는 반드시 스냅 위치에 멈추게 한다

**언제 쓰나** — 캐러셀처럼 카드 사이에 어중간하게 멈추면 안 될 때 쓴다.

```text
.snap-container { scroll-snap-type: x mandatory; overflow-x: auto; }

손을 뗌 → 가장 가까운 스냅 위치를 고름 → 그 자리로 끌려가 멈춤
```

- `x` 는 가로 방향으로만 스냅한다는 뜻이다.
- `mandatory` 는 스크롤이 끝나면 언제나 스냅 위치 가운데 하나에 멈추게 한다.
- `overflow-x: auto` 로 컨테이너가 가로 스크롤을 가져야 스냅이 일어날 곳이 생긴다.
- 원본 데모에서 컨테이너는 200px, 카드는 180px 이고 `flex-shrink: 0` 이라 카드가 줄어들지 않는다. 그래서 카드 셋이 컨테이너보다 넓어 스크롤이 생긴다.

### (4) 계산된 위치로 갈 수 없으면 끝에서 멈춘다

**언제 쓰나** — 첫 카드와 마지막 카드의 모습을 예상할 때 필요하다.

```text
카드 왼쪽 위치(콘텐츠 기준):  카드1 = 0   카드2 = 180   카드3 = 360
원하는 스크롤 위치(-16)    :  -16          164           344
스크롤할 수 있는 범위       :  0 ~ 340  (콘텐츠 540 - 컨테이너 200)
실제로 멈추는 자리          :  0            164           340
```

- 스크롤 위치는 0 보다 작아질 수 없으므로, 카드 1 은 왼쪽 끝에 붙은 채로 남는다.
- 카드 2 는 164 에 멈추어 16px 안쪽에 자리 잡는다.
- 카드 3 이 원하는 344 는 최대 340 을 넘으므로 340 에서 멈춘다. 이때 카드 3 은 왼쪽 끝에서 20px 안쪽에 보인다.
- 위 수치는 원본 데모의 크기로 계산한 것이다 `(코드에서 읽은 것 — 렌더 실측 아님)`.

## 문법 — 형태와 규칙

```html demo
<div class="row">
  <div class="card">1</div>
  <div class="card">2</div>
  <div class="card">3</div>
</div>
<style>
  .row  { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; width: 200px; }
  .card { flex-shrink: 0; min-width: 180px; height: 80px; background: #8b5cf6; color: white;
          scroll-snap-align: start; scroll-margin: 0 16px; }
</style>
```

> **보이는 것** — 카드 셋이 틈 없이 가로로 붙어 있고, 스크롤해 손을 떼면 두 번째 카드는 컨테이너 왼쪽 끝에서 16px 안쪽에 멈춘다 (코드에서 읽은 것 — 렌더 실측 아님)

- 꼴은 `scroll-margin: <length>{1,4}` 이다. 값 1~4개를 `margin` 과 같은 차례(위 · 오른쪽 · 아래 · 왼쪽)로 푼다.
- 기본값은 `0` 이고, 상속되지 않는다.
- 원본 자료는 애니메이션 가능한 속성으로 적는다.
- 스냅 대상인 **자식**에 단다. 컨테이너에 달아서는 자식의 멈출 자리가 바뀌지 않는다.
- 자식에 `scroll-snap-align` 이 있고, 부모가 `scroll-snap-type` 을 가진 스크롤 컨테이너여야 스냅에서 의미가 있다.

| 값 | 뜻 |
|---|---|
| `0` | 마진 없음 (기본값). 스냅 영역 = 자식의 테두리 상자 |
| `<length>` | 길이 단위. 그만큼 스냅 영역을 바깥으로 넓힌다. 원본은 「음수 불가」로 적는다 |
| 값 2개 (`0 16px`) | 위아래 0, 좌우 16px |
| 값 4개 | 위 · 오른쪽 · 아래 · 왼쪽 차례 |

> **단축 속성** — 여러 개별 속성을 한 번에 적는 속성.\
> 예: `scroll-margin` 은 위 · 오른쪽 · 아래 · 왼쪽 네 방향의 `scroll-margin-*` 를 한 줄로 적는다.

## 어디서 틀리나

### 1. 이름이 margin 이라 카드 사이가 벌어질 거라 여긴다

`scroll-margin` 은 배치에 쓰는 `margin` 이 아니다.
카드의 자리와 카드 사이 간격은 그대로이고, 멈출 자리 계산만 바뀐다.
원본 데모의 카드 셋은 틈 없이 붙어 있다.

### 2. `scroll-padding` 과 자리를 바꿔 단다

원본 팁: 「`scroll-padding` 은 컨테이너, `scroll-margin` 은 자식 요소에 설정하는 차이」.
`scroll-padding` 은 컨테이너 쪽 스냅포트를 안으로 줄여 모든 자식의 멈출 자리를 한꺼번에 옮긴다.
`scroll-margin` 은 자식 하나의 스냅 영역을 넓혀 그 자식만 옮긴다.
그래서 원본 팁대로 「개별 자식 요소의 스냅 위치를 미세 조정」하는 데는 `scroll-margin` 을 쓴다.

> **`scroll-padding`** — 스크롤 컨테이너에 다는 속성으로, 스냅포트를 안쪽으로 줄인다.\
> 예: 컨테이너에 `scroll-padding-left: 16px` 를 달면 모든 카드가 16px 안쪽에 멈춘다.

### 3. 정렬 방향과 맞지 않는 쪽 마진을 바꾼다

`start` 정렬에서는 시작 쪽(가로 · 왼쪽) 마진만 멈출 자리를 바꾼다.
원본의 `0 16px` 에서 오른쪽 16px 은 `start` 정렬일 때 멈출 자리에 드러나지 않는다.

### 4. 첫 카드와 마지막 카드도 똑같이 옮겨질 거라 여긴다

스크롤 위치는 0 과 최대값 사이에만 있을 수 있다.
첫 카드를 16px 안쪽으로 보내려면 스크롤이 -16 이어야 하므로 이루어지지 않는다.
마지막 카드도 최대 스크롤 위치에 막혀 계산과 다른 자리에 선다.

### 5. 스냅 설정 없이 `scroll-margin` 만 단다

부모에 `scroll-snap-type` 이 없거나 자식에 `scroll-snap-align` 이 없으면 스냅 자체가 일어나지 않는다.
그러면 손으로 스크롤할 때 `scroll-margin` 의 효과가 보이지 않는다.

### 6. 원본 주석 「스냅 위치를 16px 안쪽으로 조정」

원본의 주장 → 「좌우 16px 로 스냅 위치를 16px 안쪽으로 조정」.
왜 의심스러운가 → 카드 2 에서는 맞지만, 카드 1 은 스크롤이 0 아래로 못 가서 옮겨지지 않고, 카드 3 은 최대 스크롤에 막혀 20px 안쪽에 선다(「동작 방식 (4)」).
모든 카드에 똑같이 적용되는 말은 아니다.

| 이 문서의 서술 | 누가 보장하나 |

| 음수 값 불가 | 원본 자료의 주장. 명세가 음수를 금지하는지는 확인하지 않았다 — 음수 불가는 `scroll-padding` 쪽 규칙과 섞였을 수 있다 (확인 필요) |
| 애니메이션 가능 | 원본 자료의 주장 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 카드 하나만 멈출 자리를 조금 옮긴다 | 그 카드에 `scroll-margin` | 컨테이너의 `scroll-padding` (전부 옮겨진다) |
| 모든 카드를 같은 만큼 안쪽에 멈추게 한다 | 컨테이너의 `scroll-padding` | 카드마다 같은 `scroll-margin` 반복 |
| 카드 사이에 눈에 보이는 틈을 만든다 | `gap` 이나 `margin` | `scroll-margin` (배치를 안 바꾼다) |
| `start` 정렬에서 멈출 자리를 옮긴다 | 시작 쪽 `scroll-margin` | 끝 쪽 `scroll-margin` |

## 핵심 문장

1. **`scroll-margin` 은 스냅 대상 자식에 달아 그 자식의 스냅 영역을 바깥으로 넓힌다.**
2. **배치는 바뀌지 않는다** — 멈출 자리 계산만 바뀐다.
3. **`scroll-snap-align` 이 맞추는 쪽의 마진만 멈출 자리를 바꾼다.**
4. **컨테이너 전체는 `scroll-padding`, 자식 하나는 `scroll-margin`.**
5. **스크롤 범위 밖의 스냅 위치는 끝에서 막힌다** — 첫 카드 · 마지막 카드는 계산과 다르게 선다.

## 관련 자료

- `scroll-snap-type` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `scroll-snap-align` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `scroll-padding` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- 원본: study-site 항목 데이터 `data/css/visual.json` 의 `scroll-margin`

## 용어 풀이

- **스크롤 컨테이너** — 넘치는 내용을 스크롤로 보여 주는 요소. 여기서는 `overflow-x: auto` 를 단 `.snap-container`.
- **스크롤 스냅** — 스크롤이 끝났을 때 정한 자리로 끌어당겨 멈추게 하는 기능.
- **스냅 위치** — 스크롤이 멈출 수 있는 스크롤 위치.
- **스냅 영역** — 자식의 테두리 상자에 `scroll-margin` 을 더한 상자. 스냅 계산의 자식 쪽 기준.
- **스냅포트** — 컨테이너의 보이는 영역에서 `scroll-padding` 만큼 줄인 상자. 스냅 계산의 컨테이너 쪽 기준.
- **`scroll-snap-type`** — 컨테이너에 달아 스냅 방향(`x`)과 강도(`mandatory`)를 정한다.
- **`mandatory`** — 스크롤이 끝나면 반드시 스냅 위치에 멈추게 하는 강도.
- **`scroll-snap-align`** — 자식에 달아 스냅 영역의 어느 쪽(`start` · `center` · `end`)을 맞출지 정한다.
- **`scroll-padding`** — 컨테이너에 달아 스냅포트를 안쪽으로 줄이는 속성.
- **단축 속성** — 네 방향 개별 속성을 한 줄로 적는 속성.
- **`flex-shrink: 0`** — flex 아이템이 컨테이너보다 넓어도 줄어들지 않게 한다.

## 더 들어가면

- `scroll-margin` 은 스냅뿐 아니라 `#id` 링크로 이동하거나 `scrollIntoView()` 로 요소를 보여 줄 때도 그 요소의 멈출 자리를 옮긴다고 알려져 있다. 위에 붙은 고정 헤더에 제목이 가리지 않게 `scroll-margin-top` 을 주는 용도로 흔히 쓴다 (확인 필요).
- 방향별 개별 속성(`scroll-margin-top` 등)과 글쓰기 방향 기준의 논리 속성(`scroll-margin-inline-start` 등)도 있다 (확인 필요).
- `scroll-margin` 의 값은 `margin` 과 달리 퍼센트를 받지 않는다는 설명이 있다 (확인 필요).
