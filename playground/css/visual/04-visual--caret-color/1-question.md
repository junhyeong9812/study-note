## 퀴즈

### 1. 부모에만 쓴 캐럿 색 (예측)

```css
/* 질문용 발췌 */
.form { caret-color: teal; }
.form input { color: #333; }
```

- `.form` 안의 `input` 을 클릭했을 때 캐럿은 무슨 색일까?

### 2. 글자색만 바꾼 입력 칸의 캐럿 (예측)

```css
/* 질문용 발췌 */
input { color: blue; }
```

- `caret-color` 를 쓰지 않은 이 입력 칸에서 캐럿은 대개 무슨 색일까?

### 3. 편집 가능한 `div` 에 준 캐럿 색 (예측)

```html
<!-- 질문용 발췌 -->
<div contenteditable style="caret-color: #f43f5e; color: #111;">메모</div>
```

- 이 `div` 를 클릭해 글을 쓸 때 캐럿과 새로 쓴 글자는 각각 무슨 색일까?

### 4. 캐럿과 `:focus` 테두리를 같은 색으로 맞추는 까닭 (왜)

- 원본 정답 코드는 왜 `:focus` 의 테두리 색을 캐럿 색과 같게 두었을까?

### 5. `outline: none` 을 쓴 뒤에도 `:focus` 테두리가 필요한 까닭 (왜)

- 캐럿 색을 바꿨는데도 기본 외곽선을 지웠다면 왜 따로 포커스 표시를 둬야 할까?

### 6. `caret-color` 가 바꾸지 못하는 것 (경계)

- `caret-color` 로 placeholder 의 색이나 마우스 포인터의 모양까지 바꿀 수 있을까?

### 7. `auto` 가 정확히 어떤 색인지 (경계)

- `auto` 의 색은 CSS 가 하나로 못 박은 값일까, 브라우저가 고르는 값일까?

### 8. `caret-color` 와 `color` · `currentColor` 의 관계 (연결)

- 글자색을 바꾸면 캐럿도 따라 바뀌는 경우와 따라 바뀌지 않는 경우는 각각 언제일까?

## 실습

### 실습 1. 브랜드 색 캐럿이 깜빡이는 입력 칸 만들기

**만들 것** — 클릭하면 브랜드 색 캐럿이 깜빡이고, 테두리도 같은 색으로 부드럽게 바뀌는 입력 칸 하나를 만든다.

**요구 조건**

1. 한 줄 텍스트 입력 칸 하나를 놓고 안내 문구(`placeholder`)를 단다.
2. 입력 칸을 클릭하면 깜빡이는 캐럿이 브라우저 기본색이 아니라 브랜드 색으로 보인다.
3. 브라우저 기본 포커스 외곽선은 지운다.
4. 포커스가 들어오면 테두리 색이 캐럿과 같은 브랜드 색으로 바뀌어 지운 외곽선을 대신한다.
5. 테두리 색 변화는 한순간에 바뀌지 않고 짧은 시간에 걸쳐 부드럽게 바뀐다.
6. 입력 칸은 블록으로 놓여 화면 가로 가운데에 선다.

**시작 코드**

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <title>caret-color 실습</title>
  <style>
    /* 브랜드 색: #f43f5e */
    .styled-input {
      /* TODO: 캐럿 색을 브랜드 색으로 */
      border: 2px solid #e2e8f0;
      padding: 12px 16px;
      border-radius: 8px;
      font-size: 16px;
      width: 220px;
      display: block;
      margin: 30px auto;
      /* TODO: 기본 포커스 외곽선 지우기 */
      /* TODO: 테두리 색 변화를 0.2초에 걸쳐 부드럽게 */
    }
    .styled-input:focus {
      /* TODO: 포커스 때 테두리 색을 캐럿과 같은 색으로 */
    }
  </style>
</head>
<body>
  <!-- TODO: 클래스 styled-input 의 한 줄 텍스트 입력 칸 + 안내 문구 -->
</body>
</html>
```

**확인 방법** — 파일을 브라우저로 열어 입력 칸을 클릭한다. 캐럿이 핑크로 깜빡이는지, 테두리가 회색에서 핑크로 부드럽게 바뀌는지, 기본 파란 외곽선이 사라졌는지 본다. 바깥을 클릭하면 테두리가 다시 회색으로 돌아오는지도 본다.
