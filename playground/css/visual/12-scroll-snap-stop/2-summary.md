## 한눈에 — 쉽게 말하면

**`scroll-snap-stop: always` 는 「모든 정류장에 서는 완행열차」다.**
보통 열차(`normal`)는 승객이 서두르면 몇 정거장을 그냥 지나칠 수 있다.
완행열차(`always`)는 아무리 급해도 정거장마다 한 번씩 반드시 멈춘다.
스크롤 스냅도 똑같은 구조다.
사용자가 손가락으로 세게 밀어도, `always` 가 붙은 아이템은 하나씩 차례로 멈춰 보여 준다.

| 비유 | 실체 |
|---|---|
| 선로 | 스크롤 컨테이너(`scroll-snap-type` 이 걸린 요소) |
| 정거장 | 스냅 포인트(`scroll-snap-align` 이 걸린 아이템의 정렬 위치) |
| 승객이 서두름 | 빠른 스와이프 · 세게 미는 스크롤 |
| 급행(정거장 통과 가능) | `scroll-snap-stop: normal` |
| 완행(정거장마다 정차) | `scroll-snap-stop: always` |

```text
normal (빠르게 밀면)          always (빠르게 밀어도)
[1] ───────────▶ [3]          [1] ──▶ [2]
     [2] 를 지나칠 수 있다          한 칸에서 멈춘다
```

## 이 주제가 답하려는 질문

1. 빠르게 스크롤할 때 스냅 포인트를 건너뛸 수 있게 둘 것인가, 막을 것인가?
2. 이 속성은 컨테이너와 아이템 가운데 어디에 달아야 하는가?
3. 이 속성이 효과를 내려면 무엇이 먼저 갖춰져 있어야 하는가?
4. `always` 는 언제 쓸모 있고, 언제 오히려 방해가 되는가?

## 동작 방식

### (1) 스냅이 먼저 있어야 「멈춤 규칙」도 있다

**언제 쓰나** — 스크롤 스냅 캐러셀을 이미 만들었고, 그 위에 「건너뛰기 허용 여부」를 정하고 싶을 때다.

```text
컨테이너: scroll-snap-type: x mandatory     ← 가로 축으로, 반드시 스냅
아이템:   scroll-snap-align: start          ← 아이템의 시작 가장자리가 스냅 포인트
아이템:   scroll-snap-stop: always          ← 그 스냅 포인트를 건너뛰지 못하게
        │
        ▼
스크롤이 끝날 때 → 가장 가까운 스냅 포인트로 맞춰짐
빠르게 밀 때     → always 가 붙은 포인트에서 먼저 멈춤
```

- 컨테이너의 `scroll-snap-type` 이 「이 상자는 스냅하는 스크롤 상자다」를 정한다.
- 아이템의 `scroll-snap-align` 이 「어느 위치가 정거장인가」를 정한다.
- 아이템의 `scroll-snap-stop` 은 「그 정거장을 지나칠 수 있나」만 정한다.
- 그래서 앞의 두 속성이 없으면 `scroll-snap-stop` 은 기댈 정거장이 없어 아무 일도 하지 않는다.

> **스냅 포인트** — 스크롤이 멈출 때 맞춰지는 위치.\
> 예: `scroll-snap-align: start` 인 카드의 왼쪽 끝이 컨테이너 왼쪽 끝에 맞는 위치.

### (2) `normal` — 건너뛸 수 있다 (기본값)

**언제 쓰나** — 사진첩 · 상품 목록처럼 사용자가 여러 장을 휙휙 넘겨 원하는 곳으로 빨리 가야 할 때다.

```text
아이템 [1][2][3][4][5]  모두 scroll-snap-stop: normal
사용자가 [1] 에서 세게 민다
        │
        ▼
스크롤이 관성으로 멀리 간다 → 중간 포인트를 지나칠 수 있다
        │
        ▼
멈추는 곳 = 관성이 끝난 근처의 스냅 포인트 (예: [3] 이나 [4])
```

- 기본값이라 아무것도 쓰지 않으면 이 동작이다.
- 「건너뛸 수 있다」는 허용일 뿐, 몇 칸을 건너뛰는지는 미는 세기와 브라우저에 달려 있다.

### (3) `always` — 반드시 각 포인트에서 멈춘다

**언제 쓰나** — 튜토리얼 단계 · 이야기형 캐러셀처럼 한 장이라도 놓치면 안 되는 콘텐츠일 때다.

```text
아이템 [1][2][3]  모두 scroll-snap-stop: always
사용자가 [1] 에서 세게 민다
        │
        ▼
다음 포인트 [2] 를 지나치지 못한다
        │
        ▼
멈추는 곳 = [2]   (한 번 밀면 한 칸)
```

- 원본 팁 그대로, 빠른 스와이프에서도 각 아이템을 하나씩 보여 준다.
- 중요한 콘텐츠를 놓치지 않게 할 때 쓸모 있다.

### (4) 아이템 너비와 함께 맞물리는 것

**언제 쓰나** — 「한 화면에 카드 한 장」 캐러셀을 만들 때다.

```text
컨테이너 너비 = W,  overflow-x: auto,  display: flex
아이템   min-width = W,  flex-shrink: 0
        │
        ▼
카드 한 장이 창을 꽉 채우고, 나머지는 오른쪽으로 넘쳐 스크롤이 생긴다
        │
        ▼
always + 한 장 = 한 칸 → 「한 번 밀면 다음 한 장」
```

- `flex-shrink: 0` 이 없으면 flex 가 카드를 줄여 컨테이너 안에 다 넣어 버릴 수 있다.
- 그러면 넘침이 없어 스크롤 자체가 생기지 않고, 스냅도 멈춤 규칙도 쓸 데가 없다.
- 카드 너비를 컨테이너와 같게 두면 「한 칸 이동」이 곧 「한 장 넘김」이 된다.

## 문법 — 형태와 규칙

```html demo
<div class="steps">
  <section>1단계</section>
  <section>2단계</section>
  <section>3단계</section>
</div>
<style>
  .steps { display: flex; overflow-x: auto; width: 200px;
           scroll-snap-type: x mandatory; }
  .steps section { flex-shrink: 0; min-width: 200px; height: 80px;
                   scroll-snap-align: start;
                   scroll-snap-stop: always; }
</style>
```

> **보이는 것** — 200px 창에 「1단계」 한 장만 보이고, 가로로 밀 때마다 다음 단계 한 장씩 맞춰 멈춘다. (코드에서 읽은 것 — 렌더 실측 아님)

```css
scroll-snap-stop: normal | always;
```

| 값 | 뜻 | 쓸 곳 |
|---|---|---|
| `normal` | 스냅 포인트를 건너뛸 수 있음 (기본값) | 빨리 훑는 목록 · 사진첩 |
| `always` | 반드시 각 스냅 포인트에서 멈춤 | 튜토리얼 · 단계 안내 · 이야기형 캐러셀 |

| 성질 | 값 |
|---|---|
| 기본값 | `normal` |
| 상속 | 되지 않음 |
| 애니메이션 | 되지 않음 |

- 스냅 아이템(스크롤 컨테이너의 자식)에 단다.
- 상속되지 않으므로 컨테이너에 달아도 자식 아이템에는 전해지지 않는다.
- 컨테이너에 `scroll-snap-type`, 아이템에 `scroll-snap-align` 이 함께 있어야 의미가 생긴다.
- 애니메이션되지 않으므로 `transition` 으로 `normal` 과 `always` 사이를 부드럽게 오갈 수 없다.
- 관련 키워드: 스냅 멈춤 · 스크롤 정지 · 강제 스냅.

## 어디서 틀리나

### 1. 컨테이너에 달고 「안 먹는다」고 한다
`scroll-snap-stop` 은 상속되지 않는다.
`.snap-container { scroll-snap-stop: always; }` 만 쓰면 자식 카드는 여전히 `normal` 이다.
아이템 선택자(`.snap-item`)에 달아야 한다.

### 2. 스냅 없이 이것만 쓴다
`scroll-snap-type` 이나 `scroll-snap-align` 이 빠지면 스냅 포인트가 없다.
멈출 정거장이 없으니 「정거장마다 멈춤」도 아무 일을 하지 않는다.

### 3. 카드가 줄어들어 스크롤이 안 생긴다
flex 아이템은 기본으로 줄어들 수 있다.
`flex-shrink: 0` 과 `min-width` 로 카드 너비를 지키지 않으면 넘침이 없어 스크롤도 없다.

### 4. 팁의 뜻 — 빠른 스와이프에서도 하나씩
원본 팁: `always` 는 빠른 스와이프에서도 각 아이템을 하나씩 보여 준다.
중요한 콘텐츠를 놓치지 않게 할 때 쓸모 있다.
뒤집어 말하면, 아이템이 많은 목록에서 끝까지 가려면 그만큼 여러 번 밀어야 한다. (원본에 근거 없음 — 추론)
「빨리 훑기」가 중요한 목록에 `always` 를 걸면 사용자를 답답하게 만든다.

### 5. 전환 효과를 걸어 본다
애니메이션되지 않는 속성이라 `transition: scroll-snap-stop 0.3s` 같은 것은 중간값을 만들지 못한다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `normal` 은 건너뛰기를 허용하고 `always` 는 각 포인트에서 멈춘다 | CSS 속성의 값 정의(원본 재료 기준) |
| `normal` 일 때 실제로 몇 칸을 건너뛰는가 | 브라우저 · 입력 장치(터치 · 트랙패드 · 휠)의 관성 처리 — 명세가 칸 수를 정하지 않는다 (확인 필요) |
| 기본값 `normal` · 상속 안 됨 · 애니메이션 안 됨 | CSS 속성 정의(원본 재료 기준) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 온보딩 · 튜토리얼 단계 | `always` | `normal` (단계를 건너뛸 수 있다) |
| 이야기형 · 순서가 중요한 캐러셀 | `always` | `normal` |
| 사진 수십 장을 훑는 갤러리 | `normal` | `always` (끝까지 가기 답답하다) |
| 스냅이 없는 일반 스크롤 | 아무것도 | `scroll-snap-stop` 단독 사용 |

## 핵심 문장

1. **`scroll-snap-stop` 은 빠른 스크롤이 스냅 포인트를 건너뛸 수 있는지를 정한다** — `normal` 은 허용, `always` 는 금지.
2. **기본값은 `normal` 이다** — 아무것도 쓰지 않으면 건너뛸 수 있다.
3. **아이템에 단다** — 상속되지 않으므로 컨테이너에 달면 자식에 전해지지 않는다.
4. **스냅이 먼저다** — `scroll-snap-type` 과 `scroll-snap-align` 이 정거장을 만들어야 멈춤 규칙이 의미를 가진다.
5. **놓치면 안 되는 콘텐츠에 `always`** — 빨리 훑어야 하는 목록에는 쓰지 않는다.

## 관련 자료

- `scroll-snap-type` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `scroll-snap-align` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **스크롤 스냅** — 스크롤이 끝날 때 정해 둔 위치에 맞춰 멈추게 하는 CSS 기능.
- **스냅 컨테이너** — `scroll-snap-type` 이 걸린 스크롤 상자.
- **스냅 포인트** — 스크롤이 맞춰 멈추는 위치. `scroll-snap-align` 이 정한다.
- **`scroll-snap-type`** — 스냅할 축(`x` · `y`)과 엄격함(`mandatory` 등)을 정하는 컨테이너 속성.
- **`mandatory`** — 스크롤이 끝나면 반드시 어떤 스냅 포인트에 맞춰지게 하는 엄격함 값.
- **`scroll-snap-align`** — 아이템의 어느 가장자리(`start` 등)를 스냅 포인트로 삼을지 정하는 속성.
- **스와이프** — 터치 화면을 손가락으로 빠르게 밀어 넘기는 동작.
- **상속** — 부모에 준 속성 값이 자식에게 저절로 전해지는 것.
- **`flex-shrink`** — flex 아이템이 공간이 모자랄 때 줄어드는 정도. `0` 이면 줄지 않는다.

## 더 들어가면

- 스냅 엄격함에는 `mandatory` 말고 `proximity` 도 있다 — 스냅 포인트 가까이서 멈췄을 때만 맞춰진다 (확인 필요).
- `proximity` 와 `always` 를 함께 쓸 때 체감이 어떻게 달라지는지는 브라우저마다 다를 수 있다 (확인 필요).
- 키보드(화살표 · Page Down)나 스크립트의 `scrollBy` 같은 스크롤에도 `always` 가 같은 방식으로 적용되는지는 구현에 따라 다를 수 있다 (확인 필요).
- 아이템 일부에만 `always` 를 걸면, 그 아이템만 「반드시 서는 정거장」이 되고 나머지는 지나칠 수 있는 정거장이 된다 (확인 필요).
- 지원 브라우저 범위는 원본에 없다 — 쓰기 전에 대상 브라우저에서 확인해야 한다 (확인 필요).
