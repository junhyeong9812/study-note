## 한눈에 — 쉽게 말하면

**`place-items` 는 「사물함 칸마다 물건을 어디에 둘지 정하는 한 장짜리 규칙」이다.**
사물함(그리드)은 칸이 여러 개고, 칸마다 물건(아이템)이 하나씩 들어간다.
칸이 물건보다 크면 물건을 위·아래 어디에 둘지, 왼쪽·오른쪽 어디에 둘지 정해야 한다.
규칙 두 장(세로용 `align-items` · 가로용 `justify-items`)을 따로 붙여도 되고, 한 장(`place-items`)에 둘을 함께 적어도 된다.
그리드 컨테이너도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 사물함 | 그리드 컨테이너 |
| 칸 하나 | 그리드 셀(아이템이 차지한 영역) |
| 칸 안의 물건 | 그리드 아이템 |
| 세로 위치 규칙 | `align-items` (블록축) |
| 가로 위치 규칙 | `justify-items` (인라인축) |
| 두 규칙을 한 장에 | `place-items` |

```text
 칸(셀)                       place-items: center
 ┌──────────────┐            ┌──────────────┐
 │[1]           │   ──────▶  │              │
 │              │            │     [1]      │
 │              │            │              │
 └──────────────┘            └──────────────┘
  물건이 구석에                 칸 정중앙에
```

## 이 주제가 답하려는 질문

1. `place-items` 에 값을 하나만 주면 두 축은 어떻게 되나?
2. 값을 둘 주면 어느 값이 어느 축으로 가나?
3. 셀 안의 아이템 정렬(`place-items`)과 트랙 자체의 정렬(`place-content`)은 어떻게 다른가?
4. 정렬 효과가 눈에 보이려면 무엇이 필요한가?

## 동작 방식

### (1) 값 하나 — 두 축에 같은 값

**언제 쓰나** — 두 축을 똑같이 정렬하고 싶을 때다.
가장 흔한 쓰임은 `place-items: center` 로 아이템을 셀 정중앙에 두는 것이다.

```text
입력                      펼쳐짐                         결과
place-items: center  ──▶  align-items:   center    ──▶  세로 가운데
                          justify-items: center         가로 가운데
                                                        = 셀 정중앙
```

- 문법의 두 번째 값(`<justify-items>?`)은 물음표가 붙어 있어 생략할 수 있다.
- 생략하면 첫 번째 값이 두 축에 모두 쓰인다.
- 그래서 `center` 하나가 「양 축 모두 가운데」가 된다.

### (2) 값 둘 — 첫째는 블록축, 둘째는 인라인축

**언제 쓰나** — 세로와 가로를 다르게 정렬하고 싶을 때다.

```text
입력                          펼쳐짐                        결과 (가로쓰기 문서)
place-items: end start  ──▶   align-items:   end     ──▶   세로: 셀의 아래 끝
                              justify-items: start         가로: 셀의 왼쪽
                                                           = 셀 왼쪽 아래
```

- 첫 번째 값은 `align-items` 로 간다.
- `align-items` 는 블록축(가로쓰기 문서에서는 세로)을 맡는다.
- 두 번째 값은 `justify-items` 로 간다.
- `justify-items` 는 인라인축(가로쓰기 문서에서는 가로)을 맡는다.
- 순서를 「가로, 세로」로 착각하기 쉬우니 「align 먼저」로 외운다.

> **블록축** — 블록(문단)이 쌓이는 방향의 축.\
> 예: 한국어 가로쓰기 문서에서는 위→아래, 곧 세로다.

> **인라인축** — 한 줄 안에서 글자가 흘러가는 방향의 축.\
> 예: 한국어 가로쓰기 문서에서는 왼쪽→오른쪽, 곧 가로다.

### (3) 정렬은 「셀 안에 남는 자리」가 있어야 보인다

**언제 쓰나** — 정렬을 걸었는데 아무 변화가 없어 보일 때 이것부터 확인한다.

```text
셀이 아이템보다 큼              셀이 아이템과 같음
┌──────────────┐               ┌─────┐
│              │               │ [1] │
│     [1]      │               └─────┘
│              │                남는 자리 0
└──────────────┘                → center 를 걸어도 위치가 그대로
 남는 자리가 있음 → center 가 보인다
```

- 정렬은 셀 안에서 아이템을 남는 자리 위에 어디 놓을지 정하는 일이다.
- 원본 예제는 `grid-auto-rows: 100px` 로 행을 아이템보다 높게 만든다(주석: 「셀이 아이템보다 큼」).
- 열은 `1fr 1fr` 로 컨테이너 너비를 반씩 나누므로 아이템보다 넓다.
- 그래서 두 축 모두 남는 자리가 생기고 `center` 효과가 보인다.

### (4) `place-items` 대 `place-content` — 무엇을 움직이나

**언제 쓰나** — 둘 중 무엇을 써야 할지 고를 때다.

```text
place-items                     place-content
(셀 안의 아이템을 움직임)         (트랙 묶음 전체를 움직임)
┌─────────────────────┐         ┌─────────────────────┐
│┌───────┐┌───────┐   │         │                     │
││  [1]  ││  [2]  │   │         │   ┌─────┐┌─────┐    │
│└───────┘└───────┘   │         │   │ [1] ││ [2] │    │
│ 셀 테두리는 그대로     │         │   └─────┘└─────┘    │
│ 아이템만 셀 안에서 이동 │         │ 트랙 자체가 컨테이너 │
└─────────────────────┘         │ 안에서 이동          │
                                └─────────────────────┘
```

- `place-items` 는 각 셀 안에서 아이템의 위치를 정한다.
- `place-content` 는 트랙(행·열) 자체를 컨테이너 안에서 정렬한다.
- 원본 팁이 바로 이 둘을 혼동하지 말라고 경고한다.

> **트랙** — 그리드의 한 행 또는 한 열.\
> 예: `grid-template-columns: 1fr 1fr` 은 열 트랙 두 개를 만든다.

## 문법 — 형태와 규칙

```html demo
<div class="box">
  <div>A</div><div>B</div><div>C</div><div>D</div>
</div>
<style>
  .box {
    display: grid;
    grid-template-columns: 1fr 1fr;
    grid-auto-rows: 80px;
    place-items: center;        /* = align-items: center; justify-items: center; */
    gap: 6px;
    background: #eef2f7;
  }
  .box > div { padding: 8px 14px; background: #60a5fa; color: white; }
</style>
```

> **보이는 것** — 2열 2행 격자의 각 칸 정중앙에 작은 파란 상자 A·B·C·D 가 하나씩 놓인다 (코드에서 읽은 것 — 렌더 실측 아님)

- 형태: `place-items: <align-items> <justify-items>?`
- 기본값은 `normal` 이다.
- 상속되지 않는다 — 컨테이너에 건 값이 자식의 자식(안쪽 그리드)에 전해지지 않는다.
- 애니메이션 가능하지 않다 — 값 사이를 부드럽게 보간하지 않는다.
- 그리드 컨테이너에 건다(아이템에 거는 속성이 아니다).

| 값 | 뜻 |
|---|---|
| `normal` | 기본 동작 (기본값) |
| `stretch` | 양 축 모두 늘림 — 아이템이 셀을 채운다 |
| `center` | 양 축 모두 가운데 |
| `start` | 양 축 모두 시작 — 가로쓰기에서 셀 왼쪽 위 |
| `end` | 양 축 모두 끝 — 가로쓰기에서 셀 오른쪽 아래 |
| `baseline` | 기준선 정렬 — 글자 기준선을 맞춘다 |
| `<align> <justify>` | 블록축과 인라인축을 각각 지정 |

> **단축 속성** — 여러 속성을 한 줄로 함께 정하는 속성.\
> 예: `place-items` 하나가 `align-items` 와 `justify-items` 를 함께 정한다.

## 어디서 틀리나

### 1. `place-content` 와 혼동한다

원본 팁: `place-items: center` 는 셀 내부의 아이템을 정중앙에 둔다.
`place-content` 는 트랙 자체를 정렬한다.
「그리드 전체를 컨테이너 가운데로 모으고 싶다」면 `place-content` 쪽이고, 「각 칸 안에서 가운데」면 `place-items` 쪽이다.

### 2. 두 값의 순서를 거꾸로 읽는다

`place-items: end start` 를 「가로 end, 세로 start」로 읽으면 틀린다.
첫째가 `align-items`(블록축), 둘째가 `justify-items`(인라인축)다.

### 3. 셀에 남는 자리가 없어 효과가 안 보인다

셀 크기가 아이템 크기와 같으면 어느 값을 주어도 위치가 같다.
원본 예제가 행 높이를 아이템보다 크게(100px) 잡은 까닭이다.

### 4. 상속될 거라고 기대한다

상속이 `False` 다.
아이템 안에 또 그리드를 만들면 그 안쪽 그리드에는 따로 `place-items` 를 걸어야 한다.

### 5. 정렬 변화를 전환(transition)으로 미끄러지게 하려 한다

애니메이션 가능이 `False` 다.
`start` 에서 `end` 로 바꾸면 중간 위치를 거치지 않고 한 번에 바뀐다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `place-items` 는 `align-items` 와 `justify-items` 의 단축이다 | CSS 명세 (Box Alignment 모듈 — 모듈 이름은 확인 필요) |
| 두 번째 값을 생략하면 첫 번째 값이 두 축에 쓰인다 | CSS 명세 — 문법의 `?` 가 생략 가능을 뜻한다 |
| 상속되지 않고, 애니메이션 가능하지 않다 | CSS 명세의 속성 정의 (원본 재료 기준) |
| 블록축이 세로, 인라인축이 가로다 | 쓰기 모드에 달림 — 가로쓰기 문서일 때만 참이다 |
| 각 브라우저가 이 속성을 지원하는 범위 | 이 문서는 다루지 않는다 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 모든 칸에서 아이템을 정중앙에 | `place-items: center` | `place-content: center` |
| 세로·가로를 다르게 정렬 | `place-items: <align> <justify>` | 값 하나 |
| 격자 전체를 컨테이너 가운데로 | `place-content` | `place-items` |
| 아이템이 칸을 꽉 채우게 | `place-items: stretch` | `center` |
| 정렬 위치를 부드럽게 옮기기 | 다른 방법(예: `transform`) | `place-items` 전환 |

## 핵심 문장

1. **`place-items` = `align-items` + `justify-items`** — 첫 값은 블록축, 둘째 값은 인라인축이다.
2. **값이 하나면 두 축에 같은 값이 쓰인다** — 그래서 `center` 하나로 정중앙이 된다.
3. **움직이는 것은 셀 안의 아이템이다** — 트랙을 움직이는 것은 `place-content` 다.
4. **셀에 남는 자리가 있어야 정렬이 보인다.**
5. **상속되지 않고 애니메이션되지 않는다.**

## 관련 자료

- `align-items` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `justify-items` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `place-self` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- 원본: study-site 항목 데이터 `data/css/grid.json` 의 `grid--place-items`

## 용어 풀이

- **단축 속성** — 여러 속성을 한 줄로 함께 정하는 속성.
- **그리드 컨테이너** — `display: grid` 가 걸린 요소.
- **그리드 아이템** — 그리드 컨테이너의 직계 자식.
- **셀** — 행과 열이 만나 생기는 칸 하나.
- **트랙** — 그리드의 한 행 또는 한 열.
- **블록축** — 블록이 쌓이는 방향의 축, 가로쓰기에서는 세로.
- **인라인축** — 줄 안에서 글자가 흐르는 방향의 축, 가로쓰기에서는 가로.
- **`align-items`** — 아이템을 블록축으로 정렬하는 속성.
- **`justify-items`** — 아이템을 인라인축으로 정렬하는 속성.
- **기준선(baseline)** — 글자가 올라앉는 가상의 선.
- **`fr`** — 그리드에서 남은 공간을 나누는 비율 단위.

## 더 들어가면

- 그리드에서 `normal` 은 크기가 정해지지 않은 아이템에 대해 대개 `stretch` 처럼 동작한다 (확인 필요).
- 아이템 하나만 다르게 정렬하려면 그 아이템에 `place-self`(`align-self` + `justify-self`)를 건다 (확인 필요).
- 플렉스박스에서는 `justify-items` 가 쓰이지 않으므로 `place-items` 의 두 번째 값은 효과가 없다 (확인 필요).
- 세로쓰기(`writing-mode: vertical-rl` 등) 문서에서는 블록축과 인라인축이 바뀌어, 첫 값이 가로를 맡는다 (확인 필요).
- 두 번째 값으로 `legacy` 같은 `justify-items` 전용 키워드도 문법상 존재한다 (확인 필요).
