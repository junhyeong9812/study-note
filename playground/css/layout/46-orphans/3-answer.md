# css/layout/46 — orphans — 정답

> 복습 때 이 파일은 **맨 마지막에만** 연다.\

## 퀴즈 정답

### 1. 열 1 에 0줄, 열 2 에 5줄 — 단락 시작 전에서 자른다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
열 1 에는 이 단락의 줄이 놓이지 않고, 5줄 모두 열 2 위쪽부터 놓인다.
열 1 하단의 2줄 자리는 비어 보인다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
열 1 끝에서 자르면 앞 조각 하단에 남는 줄은 2줄이다.
`orphans: 3` 은 최소 3줄을 요구하므로 그 분절 위치는 허용되지 않는다.
브라우저는 더 앞의 자리, 곧 단락 시작 전에서 자른다.
근거: 2-summary 「동작 방식 (2)」.

### 2. 열 1 에 2줄, 열 2 에 3줄

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
열 1 하단에 단락의 첫 2줄이 놓이고, 나머지 3줄은 열 2 로 넘어간다.

**왜 그런가**
앞 조각 하단에 남는 줄이 2줄이고, 최소 줄 수도 2 라서 조건을 채운다.
그러므로 열 1 끝에서 그대로 자를 수 있다.
근거: 2-summary 「동작 방식 (1)」 · 「동작 방식 (2)」.

### 3. 아니다 — 차례로 바뀌지 않는다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
값이 2 → 3 → 4 → 5 로 1초에 걸쳐 바뀌지 않는다.
중간 값을 거치지 않고 바뀐다.

**왜 그런가**
원본 재료에 `orphans` 는 애니메이션할 수 없다고 되어 있다.
그래서 `transition` 이 중간 값을 만들어 내지 않는다.
근거: 2-summary 「문법 — 형태와 규칙」.
값이 바뀌는 순간이 언제인지(즉시인지 등)는 원본에 없다 (원본에 근거 없음 — 추론).

### 4. 일반 화면에는 분절이 없어서다

일반 화면은 내용을 잘라 나누지 않고 스크롤로 이어 보여 준다.
`orphans` 가 셀 「분절 직전 앞 조각」이 없으니 효과도 없다.
인쇄 미리보기는 내용을 페이지로 나누므로 분절이 생겨 효과가 드러난다.
근거: 2-summary 「동작 방식 (3)」.

### 5. 열에 들어갈 양을 묶어 분절을 일으키려고

높이를 고정하면 각 열에 들어갈 줄 수가 묶여, 단락이 열 끝에서 잘리는 상황이 생긴다.
원본 주석도 「고정 높이로 분할 유발」이라고 적는다.
분절이 있어야 `orphans` 가 작용할 수 있다.
근거: 2-summary 「동작 방식 (3)」.

### 6. 둘 다 올바르지 않은 값이라 선언이 무시된다

`orphans` 의 값은 양의 정수다.
`0` 은 양수가 아니고, `3px` 는 정수가 아니라 길이다.
선언이 무시되면 상속값(없으면 기본값 `2`)이 쓰인다.
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 4 · 5」.

### 7. 달라지지 않는다

앞 조각 하단에 이미 4줄이 남으므로 최소 2줄이든 3줄이든 조건을 채운다.
허용되는 분절 위치가 바뀌지 않으니 결과도 같다.
근거: 2-summary 「어디서 틀리나 2」 (원본에 근거 없음 — 추론).

### 8. `orphans` 가 상속되는 속성이라서

원본 재료에 `orphans` 는 상속된다고 되어 있다.
`.multicol` 에 준 값을 안쪽 `p` 가 물려받고, 줄은 `p` 안에 있으므로 그 단락의 줄을 셀 때 3 이 쓰인다.
근거: 2-summary 「동작 방식 (4)」.

## 실습 정답

### 실습 1. 고아 줄을 막는 2단 상자

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 1. 단락이 두 열로 흐른다 | `.multicol { column-count: 2; }` |
| 2. 앞 열 하단에 단락 줄이 3줄 미만 남지 않게 | `.multicol { orphans: 3; }` |
| 3. 값은 `.multicol` 에, 단락은 상속으로 | `orphans: 3` 이 `.multicol` 규칙에 있고 `p` 규칙에는 없다 |
| 4. 단락의 기본 바깥 여백 제거 | `p { margin: 0; }` |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/layout/reference/orphans.html`

```html
<!DOCTYPE html>
<!-- HTML5 문서 선언 -->
<html lang="ko">
<head>
<meta charset="utf-8">
<title>orphans - 페이지/열 나누기 전에 남겨야 할 최소 줄 수를 설정합니다</title>
<!--
  [레이아웃] orphans
  설명: 페이지/열 나누기 전에 남겨야 할 최소 줄 수를 설정합니다
  구문: orphans: <integer>
  팁: 타이포그래피에서 orphan은 페이지/열 하단에 홀로 남은 단락 첫 줄을 의미합니다. 인쇄 미리보기에서 효과를 확인할 수 있습니다.
-->
<style>
  /* .multicol: 2단 + 고아 최소 3줄 */
  .multicol {
    column-count: 2;             /* 2개 열 */
    height: 100px;               /* 고정 높이로 분할 유발 */
    orphans: 3;                  /* 열 끝에 단락 첫 부분이 3줄 미만 남지 않도록 */
    background: #f1f5f9;         /* 회색 배경 */
    padding: 16px;               /* 안쪽 여백 */
    border-radius: 4px;          /* 모서리 둥글게 */
  }
  /* p: 단락 스타일 */
  p {
    margin: 0;                   /* 기본 마진 제거 */
    line-height: 1.6;            /* 줄 높이 */
  }
</style>
</head>
<body>
<!-- 열 나누기 시 고아 줄 방지 -->
<div class="multicol">
  <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco.</p>
</div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.multicol {
  column-count: 2;
  height: 100px;
  orphans: 3;
  background: #f1f5f9;
  padding: 16px;
  border-radius: 4px;
}
p {
  margin: 0;
  line-height: 1.6;
}
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- `column-count: 2` 가 다단을 만들어 분절이 생길 바탕을 깐다.
- 시작 코드의 `height: 100px` 가 열 하나에 들어갈 양을 묶어 단락이 열 끝에서 잘리게 한다.
- `orphans: 3` 은 열 1 하단에 단락 줄이 3줄 미만 남는 분절 위치를 막는다.
- `orphans` 는 상속되므로 `.multicol` 에만 주어도 `p` 의 줄에 적용된다.
- 이 예제는 단락이 하나뿐이라 열 1 에 걸리는 줄 수에 따라 `orphans` 값을 바꿔도 차이가 안 보일 수 있다 — 글 길이나 높이를 바꿔 확인한다 (원본에 근거 없음 — 추론).
