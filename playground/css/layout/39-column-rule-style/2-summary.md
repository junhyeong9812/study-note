## 한눈에 — 쉽게 말하면

**`column-rule-style` 은 「신문 지면의 단 사이 세로줄을 어떤 펜으로 긋는가」다.**
신문은 기사를 여러 단으로 나누고, 단과 단 사이에 세로줄을 긋기도 한다.
그 줄을 실선으로 긋는지, 점으로 찍는지, 짧은 막대를 이어 긋는지를 고르는 것이 이 속성이다.
CSS 다단 레이아웃도 똑같은 구조다.
`column-count` 로 단을 나누고, `column-rule-style` 로 단 사이 줄의 모양을 고른다.

| 비유 | 실체 |
|---|---|
| 신문 지면 | 다단 컨테이너(`.multicol`) |
| 단 | 열(column) |
| 단 사이 세로줄 | 열 구분선(column rule) |
| 펜의 종류(실선 · 점 · 막대) | `column-rule-style` 값 |
| 펜의 굵기 · 잉크 색 | `column-rule-width` · `column-rule-color` |
| 펜을 들지 않음 | 기본값 `none` |

```text
 ┌──────────────────────────────────────┐
 │  열 1     ╎   열 2     ╎   열 3       │
 │  글 글 글 ╎   글 글 글 ╎   글 글 글   │
 │  글 글 글 ╎   글 글 글 ╎   글 글      │
 └──────────────────────────────────────┘
            ↑            ↑
       구분선 1      구분선 2   ← 모양을 column-rule-style 이 정한다
```

> **다단 레이아웃** — 한 상자의 내용을 신문처럼 여러 열로 나눠 흘리는 배치 방식이다.\
> 예: `column-count: 3;` 을 주면 내용이 세 열로 나뉘어 흐른다.

> **열 구분선(column rule)** — 다단 레이아웃에서 이웃한 열 사이에 긋는 세로줄이다.\
> 예: 세 열이면 열 1·2 사이와 열 2·3 사이에 하나씩 그어진다.

## 이 주제가 답하려는 질문

1. 다단 레이아웃의 열 사이 선은 어떤 모양을 가질 수 있나?
2. 아무것도 지정하지 않으면 선이 생기나?
3. 두께와 색만 정하면 선이 보이나, 모양은 왜 따로 정해야 하나?
4. 이 속성은 `border-style` 과 어떤 관계인가?

## 동작 방식

### (1) 다단 컨테이너에 선 모양을 지정한다

**언제 쓰나** — 여러 열로 나눈 글에서 열의 경계를 눈으로 구분하고 싶을 때 쓴다.

```text
입력 코드                         무엇이 일어나나                    결과
.multicol {                       ① 내용을 세 열로 나눈다
  column-count: 3;          ──▶   ② 이웃한 열 사이마다 선 자리가  ──▶  열 사이에 파란
  column-rule-style: dashed;        생긴다(열 3개 → 자리 2개)          대시선 두 개
  column-rule-width: 2px;         ③ 선 모양 = dashed(대시선)
  column-rule-color: #3b82f6;     ④ 굵기 2px, 색 파랑
}
```

- ① `column-count` 가 컨테이너의 내용을 여러 열로 나눈다.
- ② 구분선은 이웃한 열 사이에만 그어진다 — 첫 열 앞과 마지막 열 뒤에는 없다.
- ③ `column-rule-style` 이 그 선을 어떤 모양으로 그릴지 정한다.
- ④ 굵기와 색은 다른 두 속성이 맡는다 — 세 속성이 합쳐 선 하나가 된다.

```html demo
<div style="column-count: 3; column-rule-style: dashed; column-rule-width: 2px; column-rule-color: #3b82f6; column-gap: 20px; background: #f1f5f9; padding: 16px;">
  <p style="margin: 0;">가나다라마바사 아자차카타파하 가나다라마바사 아자차카타파하 가나다라마바사 아자차카타파하</p>
</div>
```

> **보이는 것** — 회색 상자 안의 글이 세 열로 나뉘고, 열 사이에 파란 대시선이 세로로 두 줄 그어진다 (코드에서 읽은 것 — 렌더 실측 아님)

### (2) 기본값은 `none` — 모양을 고르지 않으면 선이 없다

**언제 쓰나** — 두께와 색을 줬는데 선이 안 보일 때, 이 단계를 떠올린다.

```text
입력 코드                          무엇이 일어나나                     결과
.multicol {                        ① column-rule-style 지정 없음
  column-count: 3;           ──▶   ② 기본값 none 이 쓰인다       ──▶   구분선이 보이지 않는다
  column-rule-width: 2px;          ③ none = 구분선 없음
  column-rule-color: #3b82f6;      ④ 굵기·색은 그릴 선이 없어
}                                    아무 효과가 없다
```

- ① 모양을 적지 않았다.
- ② 기본값 `none` 이 적용된다.
- ③ `none` 은 「구분선 없음」이다.
- ④ 선 자체가 없으므로 굵기와 색을 정해도 화면에 아무것도 생기지 않는다.

### (3) 값 고르기 — 열 가지 모양

**언제 쓰나** — 선의 느낌(차분한 실선, 가벼운 점선, 입체감)을 고를 때 쓴다.

```text
none / hidden   → 선 없음
dotted          → · · · · ·   (점)
dashed          → - - - - -   (짧은 막대)
solid           → ─────────   (실선)
double          → ═════════   (두 줄)
groove / ridge  → 음각 / 양각처럼 보이는 입체 선
inset / outset  → 안쪽 / 바깥쪽 그림자처럼 보이는 입체 선
```

- 앞의 두 값은 선을 없앤다.
- 가운데 네 값은 평면 선의 무늬를 바꾼다.
- 마지막 네 값은 입체처럼 보이는 효과를 낸다.
- 이 목록은 `border-style` 이 받는 값과 같다.

## 문법 — 형태와 규칙

```css
.news {
  column-count: 2;              /* 두 열로 나눈다 */
  column-gap: 24px;             /* 열 사이 간격 */
  column-rule-style: solid;     /* 구분선 모양: 실선 */
  column-rule-width: 1px;       /* 구분선 굵기 */
  column-rule-color: #94a3b8;   /* 구분선 색 */
}
.news p {
  margin: 0;                    /* 단락 기본 바깥 여백 제거 */
}
```

- 형태: `column-rule-style: none | hidden | dotted | dashed | solid | double | groove | ridge | inset | outset`
- 다단 컨테이너(열로 나뉘는 요소)에 준다.
- 기본값은 `none` 이다.
- 상속되지 않는다 — 자식 요소는 부모의 값을 물려받지 않는다.
- 애니메이션되지 않는다 — 값이 바뀔 때 중간 모양을 거쳐 부드럽게 바뀌지 않는다.

| 값 | 뜻 |
|---|---|
| `none` | 기본값. 구분선 없음 |
| `hidden` | 구분선 숨김 (`none` 과 동일) |
| `dotted` | 점선 |
| `dashed` | 대시선 |
| `solid` | 실선 |
| `double` | 이중선 |
| `groove` | 음각 효과 |
| `ridge` | 양각 효과 |
| `inset` | 안쪽 그림자 효과 |
| `outset` | 바깥쪽 그림자 효과 |

> **상속** — 부모에게 준 속성 값이 자식에게 자동으로 넘어가는 것이다.\
> 예: `color` 는 상속되어 자식 글자색도 바뀌지만, `column-rule-style` 은 상속되지 않는다.

> **애니메이션 가능** — 두 값 사이를 `transition` 등으로 부드럽게 이어 바꿀 수 있는 성질이다.\
> 예: `opacity` 는 0에서 1로 서서히 바뀌지만, `column-rule-style` 은 그렇지 않다.

## 어디서 틀리나

### 1. 굵기와 색만 주고 모양을 빠뜨린다

기본값이 `none` 이라 모양을 적지 않으면 선이 없다.
`column-rule-width` 와 `column-rule-color` 를 정성껏 줘도 화면에는 아무것도 나오지 않는다.
선이 안 보이면 가장 먼저 `column-rule-style` 이 있는지 본다.

### 2. `dotted` 와 `dashed` 를 섞어 부른다

`dotted` 는 점선(점), `dashed` 는 대시선(짧은 막대)이다.
원본 예제 주석은 `column-rule-style: dashed;` 옆에 「점선 스타일」이라고 적었다.
원본의 주장 → 「`dashed` = 점선」.
왜 의심스러운가 → 같은 원본의 값 목록은 `dotted` 를 「점선」, `dashed` 를 「대시선」으로 나눠 적었다.
값 목록을 따르면 그 줄이 그리는 것은 대시선이다.

### 3. `hidden` 을 「선은 있는데 감춰진 상태」로 오해한다

원본은 `hidden` 을 「`none` 과 동일」이라고 적었다.
열 구분선에서는 둘 다 선이 없다는 뜻으로 읽으면 된다.

### 4. 자식에게 물려줄 수 있다고 생각한다

상속되지 않으므로 바깥 다단 상자에 준 모양이 안쪽 다단 상자로 넘어가지 않는다.
안쪽에도 선이 필요하면 안쪽에 따로 적는다.

### 5. 모양을 바꾸며 부드럽게 전환하려 한다

애니메이션 가능하지 않은 속성이다.
`solid` 에서 `dashed` 로 바꿀 때 「반쯤 끊긴 선」 같은 중간 단계는 없다.

### 6. 새로운 값을 외우려 한다

팁: `border-style` 과 동일한 값들을 사용한다.
테두리 모양 값을 알면 열 구분선 모양 값도 이미 아는 것이다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 받는 값의 목록 · 기본값 `none` · 상속 안 됨 · 애니메이션 불가 | CSS 명세가 정한다 (원본 재료 기준) |
| `hidden` 은 `none` 과 동일 | 원본의 서술이다 — 명세의 정확한 문구는 (확인 필요) |
| `groove` · `ridge` · `inset` · `outset` 의 입체 효과가 정확히 어떤 색 조합으로 보이나 | 브라우저 구현에 따라 다를 수 있다 (확인 필요) |
| 점 · 대시의 길이와 간격 | 브라우저 구현이 정한다 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 신문 · 잡지처럼 여러 열로 나눈 글에 경계선이 필요하다 | `column-rule-style` + 굵기 · 색 | 각 열마다 `border` 를 따로 붙이려는 시도 |
| 열 사이를 가볍게 구분하고 싶다 | `dotted` · `dashed` | 두꺼운 `double` |
| 열 사이에 선이 필요 없다 | 지정하지 않음(기본 `none`) | 굵기를 0으로 두고 모양은 남기는 우회 |
| 선 모양을 서서히 바꾸고 싶다 | 선을 겹쳐 `opacity` 를 바꾸는 등 다른 방법 | `column-rule-style` 의 `transition` |

## 핵심 문장

1. **`column-rule-style` 은 다단 레이아웃의 열 사이 선 모양을 정한다** — 선은 이웃한 열 사이에만 생긴다.
2. **기본값은 `none` 이다** — 모양을 고르지 않으면 굵기 · 색을 줘도 선이 없다.
3. **값은 `border-style` 과 같다** — 점 · 대시 · 실선 · 이중선 · 입체 효과.
4. **상속되지 않고 애니메이션되지 않는다** — 필요한 요소마다 적고, 모양은 단번에 바뀐다.

## 용어 풀이

- **다단 레이아웃** — 한 상자의 내용을 여러 열로 나눠 흘리는 배치다.
- **열(column)** — 다단 레이아웃에서 나뉜 세로 칸 하나다.
- **열 구분선(column rule)** — 이웃한 열 사이에 긋는 세로줄이다.
- **`column-count`** — 내용을 몇 개 열로 나눌지 정하는 속성이다.
- **`column-gap`** — 열과 열 사이 간격을 정하는 속성이다.
- **`column-rule-width`** — 열 구분선의 굵기를 정하는 속성이다.
- **`column-rule-color`** — 열 구분선의 색을 정하는 속성이다.
- **`border-style`** — 테두리의 모양을 정하는 속성으로, 같은 값 목록을 쓴다.
- **상속** — 부모의 속성 값이 자식에게 자동으로 넘어가는 것이다.
- **애니메이션 가능** — 두 값 사이를 부드럽게 이어 바꿀 수 있는 성질이다.
- **음각 · 양각** — 파인 듯 · 솟은 듯 보이게 하는 입체 표현이다.

## 더 들어가면

- 세 속성을 한 줄로 묶는 단축 속성 `column-rule` 이 있다 — 예: `column-rule: 2px dashed #3b82f6;` (확인 필요).
- 명세상 모양이 `none` 이나 `hidden` 이면 `column-rule-width` 의 계산값이 0이 된다고 알려져 있다 (확인 필요).
- 구분선은 `column-gap` 의 가운데에 그려지고, 선 자체가 열 사이 공간을 더 차지하지 않는다 (확인 필요).
- 표 테두리에서 `hidden` 은 테두리 충돌 규칙에서 `none` 과 다르게 우선하지만, 열 구분선에는 충돌이 없어 차이가 드러나지 않는다 (확인 필요).
- `groove` · `ridge` · `inset` · `outset` 은 색을 밝게 · 어둡게 섞어 입체감을 내므로 굵기가 얇으면 효과가 잘 안 보일 수 있다 (확인 필요).
- 애니메이션 불가 속성은 `transition` 을 걸어도 값이 단번에 바뀐다 (확인 필요 — 바뀌는 시점은 브라우저와 명세 버전에 따라 다를 수 있다).
