## 한눈에 — 쉽게 말하면

**`break-before` 는 「공책에 붙이는 '여기서부터 새 쪽' 포스트잇」이다.**
글을 이어 쓰다가 어떤 제목 앞에 포스트잇이 붙어 있으면, 그 쪽이 아직 남아 있어도 넘기고 새 쪽 맨 위에서 제목을 시작한다.
반대로 「여기서는 쪽을 넘기지 마」라는 포스트잇도 있다.
CSS 의 다단 레이아웃과 인쇄 페이지도 똑같은 구조다.
내용이 열이나 페이지로 잘려 흘러갈 때, 어떤 요소 **바로 앞**에서 잘리게 할지 잘리지 않게 할지를 그 요소에 적어 둔다.

| 비유 | 실체 |
|---|---|
| 공책의 한 쪽 | 열 상자 하나 또는 인쇄 페이지 하나 |
| 글이 다음 쪽으로 넘어감 | 나누기(조각화) |
| 「여기서부터 새 쪽」 포스트잇 | `break-before: column` · `page` · `always` |
| 「여기서 넘기지 마」 포스트잇 | `break-before: avoid` · `avoid-column` · `avoid-page` |
| 포스트잇 없음 | `break-before: auto`(기본값) |

```text
 포스트잇 없음(auto)            포스트잇 "새 쪽"(column)
┌─────────┬─────────┐        ┌─────────┬─────────┐
│ 문단 A  │ 제목 B  │        │ 문단 A  │ 제목 B  │
│ 제목 B? │ 문단 C  │        │         │ 문단 C  │
│ (어디서 │         │        │ (남아도 │         │
│ 잘릴지  │         │        │  비운다)│         │
│ 브라우저 │        │        │         │         │
│ 가 정함)│         │        │         │         │
└─────────┴─────────┘        └─────────┴─────────┘
```

> **나누기(조각화)** — 하나로 이어진 내용이 열 · 페이지 같은 여러 조각으로 잘려 흘러가는 일.\
> 예: 긴 글을 인쇄하면 1쪽 · 2쪽으로 잘리는 것.

## 이 주제가 답하려는 질문

1. 다단 레이아웃에서 특정 요소를 반드시 새 열 맨 위에서 시작하게 하려면 어떻게 하나?
2. 반대로 어떤 요소 앞에서 잘리지 않게 하려면 어떻게 하나 — 열과 페이지를 따로 막을 수 있나?
3. 인쇄할 때 페이지를 강제로 넘기거나, 다음 페이지가 왼쪽 · 오른쪽이 되게 하려면 어떻게 하나?
4. 예전의 `page-break-before` 와는 무슨 관계인가?

## 동작 방식

### (1) 강제 나누기 — 이 요소 앞에서 반드시 자른다

**언제 쓰나** — 다단 글에서 소제목을 새 열 맨 위에 두고 싶을 때, 인쇄할 때 장 제목마다 새 페이지로 시작하고 싶을 때.

```text
입력                                   무엇이 일어나나                       결과
<div class="multicol">                 1. 컨테이너가 2단 조각화 맥락이 된다   ┌──────┬──────────┐
  <p>A</p>                             2. p A 를 첫 열에 놓는다              │  A   │ 제목(B)  │
  <h3 class="break">B</h3>             3. h3 앞에 열 나누기가 강제되어 있다   │      │  C       │
  <p>C</p>                             4. 첫 열이 남아도 끊고 둘째 열로 간다  └──────┴──────────┘
</div>                                 5. h3 · p C 는 둘째 열에서 이어진다
.break { break-before: column; }
```

- `.multicol` 에 `column-count` 가 있어서 안의 내용이 열로 잘려 흐를 수 있는 상태가 된다.
- 내용은 위에서부터 차례로 첫 열에 쌓인다.
- `.break` 를 만난 순간, 브라우저는 「이 요소 앞에서 열을 끊어라」는 지시를 읽는다.
- 첫 열에 빈자리가 남아 있어도 거기서 끊는다 — 이것이 「강제」의 뜻이다.
- 그래서 h3 은 둘째 열 맨 위에서 시작하고, 뒤따르는 내용도 둘째 열로 간다.

값마다 무엇을 끊나:

- `column` — 열을 끊는다.
- `page` — 페이지를 끊는다.
- `always` — 원본 설명 그대로 「요소 앞에서 강제로 나누기」 한다.
- `left` · `right` — 페이지를 끊되, 다음 페이지가 왼쪽(또는 오른쪽) 페이지가 되도록 강제한다.

> **강제 나누기** — 나눌 자리에 공간이 남아 있어도 반드시 그 자리에서 자르는 것.\
> 예: 책에서 새 장은 앞 쪽이 반쯤 비어도 새 쪽에서 시작한다.

### (2) 나누기 피하기 — 이 요소 앞에서는 자르지 마라

**언제 쓰나** — 설명 문단이 앞 그림과 떨어져 다른 열 · 다른 페이지로 밀려나지 않게 하고 싶을 때.

```text
입력                          무엇이 일어나나                              결과
<figure>그림</figure>          1. 브라우저가 자를 자리를 찾는다               그림과 설명이
<p class="cap">설명</p>         2. 설명 앞은 「피하라」로 표시되어 있다         같은 열·페이지에
.cap { break-before: avoid; }  3. 가능하면 다른 자리에서 자른다               붙어 있으려 한다
```

- `avoid` 는 요소 앞의 **모든** 나누기(열 · 페이지 등)를 막으라는 뜻이다.
- `avoid-column` 은 열 나누기만, `avoid-page` 는 페이지 나누기만 막는다.
- 「피하라」는 요청이다 — 강제 나누기처럼 반드시 그렇게 되는 지시가 아니다 (원본에 근거 없음 — 추론).

### (3) 기본값 `auto` — 브라우저에 맡긴다

**언제 쓰나** — 따로 지시가 없을 때. 아무것도 쓰지 않으면 이것이다.

```text
입력                              무엇이 일어나나                         결과
<h3>B</h3>  (break-before 없음)    1. 값은 auto                           h3 이 첫 열 아래쪽에 올지
                                  2. 나누기를 허용하지만 강제하지 않는다    둘째 열에 올지는
                                  3. 브라우저가 열 높이에 맞춰 자른다       브라우저가 정한다
```

- `auto` 는 「여기서 잘라도 되고 안 잘라도 된다」는 뜻이다.
- 그래서 같은 제목이 내용 길이에 따라 첫 열에 남기도 하고 다음 열로 넘어가기도 한다.

### (4) 조각화 맥락이 있어야 의미가 있다

**언제 쓰나** — 효과가 안 보일 때 원인을 찾는 기준.

```text
입력                                       무엇이 일어나나                        결과
<div>  (column-count 없음, 화면)            1. 내용이 열로도 페이지로도 안 잘린다     아무 변화 없음
  <h3 style="break-before: column">         2. 자를 「열」이 없다                     (평범하게 이어짐)
</div>
```

- 열 나누기는 다단 컨테이너(`column-count` 등) 안에서만, 페이지 나누기는 인쇄처럼 페이지가 있는 상황에서만 일어난다.
- 화면의 평범한 블록 안에서는 잘릴 곳 자체가 없으므로 `column` 도 `page` 도 보이는 변화가 없다.

> **다단 레이아웃** — 신문처럼 내용을 여러 세로 열로 나눠 흘려 놓는 배치.\
> 예: `column-count: 2` 를 준 상자는 내용이 두 열로 나뉜다.

## 문법 — 형태와 규칙

```html demo
<div class="cols">
  <p>첫 문단. 짧다.</p>
  <h3 class="new">둘째 열 제목</h3>
  <p>둘째 열 내용.</p>
</div>
<style>
  .cols { column-count: 2; column-gap: 20px; padding: 12px; background: #f1f5f9; }
  .new  { break-before: column; margin: 0; }
</style>
```

> **보이는 것** — 왼쪽 열에는 「첫 문단」만 있고, 「둘째 열 제목」과 그 아래 내용은 오른쪽 열 맨 위부터 놓인다 (코드에서 읽은 것 — 렌더 실측 아님).

| 값 | 뜻 | 종류 |
|---|---|---|
| `auto` | 기본값. 나누기를 허용하지만 강제하지 않는다 | 맡김 |
| `avoid` | 요소 앞의 모든 나누기를 막는다 | 피하기 |
| `avoid-page` | 페이지 나누기만 막는다 | 피하기 |
| `avoid-column` | 열 나누기만 막는다 | 피하기 |
| `always` | 요소 앞에서 강제로 나눈다 | 강제 |
| `column` | 요소 앞에서 열 나누기를 강제한다 | 강제 |
| `page` | 요소 앞에서 페이지 나누기를 강제한다 | 강제 |
| `left` | 다음 페이지가 왼쪽 페이지가 되도록 강제한다 | 강제(페이지) |
| `right` | 다음 페이지가 오른쪽 페이지가 되도록 강제한다 | 강제(페이지) |

- 꼴: `break-before: <키워드>;` — 키워드 하나만 쓴다.
- 기본값은 `auto` 다.
- 상속되지 않는다 — 컨테이너에 준 값이 안쪽 자식에게 내려가지 않는다.
- 애니메이션되지 않는다 — 값이 키워드라 중간값이 없다.
- 나누기를 걸고 싶은 **그 요소 자신**에 쓴다(새 열에서 시작할 요소에 준다).

> **상속** — 부모에 준 CSS 값이 자식에게 저절로 적용되는 성질.\
> 예: `color` 는 상속되어 부모의 글자색이 자식에게도 간다.

## 어디서 틀리나

### 1. `page-break-before` 를 아직 쓴다

원본 팁: `break-before` 는 레거시 `page-break-before` 속성의 현대적 대체다.
`page-break-before` 는 이름 그대로 페이지 나누기 중심의 옛 속성이다.
열 나누기까지 한 속성으로 다루려면 `break-before` 를 쓴다.

> **레거시 속성** — 예전에 쓰이던, 지금은 새 속성으로 대체된 속성.\
> 예: `page-break-before` 는 `break-before` 의 옛 형태다.

### 2. 다단 레이아웃인데 `page` 를 쓴다

원본 팁: 다단 레이아웃에서 열 나누기를 제어할 때는 `break-before: column` 을 쓴다.
`page` 는 페이지를 끊는 값이라, 화면의 다단 상자 안에서 열을 넘기려는 목적과 맞지 않는다.

### 3. 컨테이너에 준다

`break-before` 는 상속되지 않는다.
`.multicol` 에 `break-before: column` 을 줘도 안쪽 h3 이 새 열로 가지 않는다.
그 값은 컨테이너 자신의 앞자리에 대한 지시다.
새 열에서 시작할 요소에 직접 준다.

### 4. 조각화 맥락 없이 쓴다

`column-count` 를 빼먹으면 `break-before: column` 은 아무 일도 하지 않는다.
열이 없으니 끊을 열도 없다.

### 5. `avoid` 를 「반드시」로 믿는다

피하기 값은 「가능하면 여기서 자르지 마라」는 요청이다 (원본에 근거 없음 — 추론).
내용이 너무 길면 어딘가에서는 잘려야 한다.

### 6. 트랜지션을 건다

애니메이션 가능 속성이 아니다.
`transition` 으로 `auto` 에서 `column` 으로 부드럽게 넘어가는 일은 없다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 값의 목록과 뜻, 기본값 `auto`, 상속 안 됨, 애니메이션 안 됨 | CSS 명세(원본 재료 기준) |
| 피하기 값이 항상 지켜지지는 않는다 | 명세상 요청 성격으로 보이나 원본에 없음 (확인 필요) |
| 값마다 실제로 지원되는 정도(예: 다단 안의 `avoid-column`) | 브라우저 구현 — 브라우저마다 다를 수 있다 (확인 필요) |
| 화면(페이지 없는 매체)에서 `page` · `left` · `right` 가 보이는 변화가 없다 | 페이지가 없는 매체의 성질에서 나온 추론 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 다단 글에서 소제목을 새 열 맨 위에 | `break-before: column` | `page` · `page-break-before` |
| 인쇄할 때 장 제목마다 새 페이지 | `break-before: page` | `column` |
| 책처럼 새 장을 오른쪽 페이지에서 | `break-before: right` | `page` 만 쓰기 |
| 앞 요소와 떨어지지 않게 | `avoid` · `avoid-column` · `avoid-page` | 강제 값 |
| 그냥 자연스럽게 흐르게 | 아무것도 안 쓴다(`auto`) | 불필요한 `always` |
| 다단도 인쇄도 아닌 평범한 화면 배치 | 쓰지 않는다 | `break-before` 로 줄 바꾸기 흉내 |

## 핵심 문장

1. **`break-before` 는 요소 바로 앞에서 열 · 페이지를 자를지 정한다** — 그 요소 자신에 쓴다.
2. **값은 셋으로 나뉜다** — 맡김(`auto`), 강제(`always` · `column` · `page` · `left` · `right`), 피하기(`avoid` · `avoid-column` · `avoid-page`).
3. **조각화 맥락이 있어야 의미가 있다** — 열은 다단 컨테이너 안, 페이지는 인쇄 같은 페이지 매체.
4. **상속되지 않고 애니메이션되지 않는다.**
5. **`page-break-before` 의 현대적 대체이고, 다단의 열 나누기는 `column` 으로 한다.**

## 용어 풀이

- **나누기(조각화)** — 이어진 내용이 열 · 페이지 같은 조각으로 잘려 흐르는 일.
- **조각화 맥락** — 내용이 잘릴 수 있는 환경. 다단 컨테이너나 인쇄 페이지.
- **강제 나누기** — 공간이 남아도 그 자리에서 반드시 자르는 것.
- **다단 레이아웃** — 내용을 여러 세로 열로 나눠 흘리는 배치.
- **열 상자** — 다단 컨테이너 안의 열 하나.
- **상속** — 부모의 CSS 값이 자식에게 저절로 적용되는 성질.
- **레거시 속성** — 새 속성으로 대체된 옛 속성.
- **`column-count`** — 다단 컨테이너의 열 개수를 정하는 속성.
- **`column-gap`** — 열과 열 사이 간격을 정하는 속성.

## 더 들어가면

- 짝이 되는 `break-after` 는 요소 **뒤**에서의 나누기를, `break-inside` 는 요소 **안**에서의 나누기를 다룬다 (확인 필요).
- 명세에는 `recto` · `verso` · `region` · `avoid-region` 같은 값도 있다고 알려져 있다 (확인 필요).
- `page-break-before: always` 는 `break-before: page` 로 옮겨 적는 식의 대응이 있다고 알려져 있다 (확인 필요).
- 높이가 자동인 다단 컨테이너에서 강제 나누기를 열 개수보다 많이 넣으면 열이 넘쳐 추가로 생길 수 있다 (확인 필요).
- 인쇄 결과는 브라우저의 인쇄 미리보기로 확인하는 경우가 많다 (확인 필요).
