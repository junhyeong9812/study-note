## 한눈에 — 쉽게 말하면

**`break-inside: avoid` 는 책에 붙인 「찢지 마시오」 딱지다.**
두 칸짜리 책꽂이에 책을 차례로 꽂는다고 하자.
왼쪽 칸이 거의 찼는데 두꺼운 사전이 남았다면, 사전을 반으로 찢어 양 칸에 나눠 꽂을 수도 있다.
딱지가 붙은 책은 찢지 않고 통째로 오른쪽 칸으로 넘긴다.
다단 레이아웃의 카드도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 책꽂이 | 다단 컨테이너(`column-count` 를 준 요소) |
| 칸 | 열(column) |
| 칸과 칸의 경계 | 열 나누기가 일어나는 자리 |
| 책 | 카드 같은 자식 요소 |
| 「찢지 마시오」 딱지 | `break-inside: avoid` |

```text
 딱지 없음 (auto)            딱지 있음 (avoid)
┌──────────┬──────────┐     ┌──────────┬──────────┐
│ Card 1 윗│ 1 아랫부분│     │ Card 2   │ Card 1   │
│ 부분...  │ Card 2   │     │ ...      │ (통째로) │
└──────────┴──────────┘     └──────────┴──────────┘
  카드 하나가 두 열에 걸침     카드가 한 열 안에 온전히
```

> 오른쪽 그림은 「통째로 옮겨질 수 있다」는 뜻을 보이는 개념도다 — 실제 배치는 내용 높이에 따라 달라진다.

## 이 주제가 답하려는 질문

1. 다단 레이아웃에서 요소는 왜 중간에 쪼개지나?
2. 쪼개지지 않게 하려면 어느 요소에 무엇을 거나?
3. 페이지 · 열 · 영역 나누기 가운데 하나만 막으려면 어떻게 하나?
4. 이 속성은 상속되나, 애니메이션 되나?

## 동작 방식

내용이 여러 조각으로 나뉘어 흐르는 곳에서는 브라우저가 「어디서 끊을지」를 정한다.
이렇게 내용을 끊는 일을 나누기라고 한다.

> **나누기(break)** — 흐르던 내용을 한 조각에서 끊고 다음 조각(다음 열 · 다음 페이지 · 다음 영역)으로 넘기는 일.\
> 예: 2단 신문에서 왼쪽 단 끝의 문장이 오른쪽 단 맨 위로 이어지는 것.

`break-inside` 는 **그 요소의 안쪽**에서 나누기가 일어나도 되는지를 정한다.
요소와 요소 **사이**가 아니라 요소 **내부**다.

### (1) `auto` — 나누기를 허용한다

**언제 쓰나** — 긴 본문 문단처럼 열 경계에서 끊겨도 읽는 데 문제가 없는 요소다.
기본값이라 따로 쓰지 않으면 이 상태다.

```text
.card { /* break-inside 없음 = auto */ }
        │
        ▼
열 1 끝에 닿았을 때 카드 안쪽에서도 끊을 수 있다
        │
        ▼
카드 윗부분은 열 1, 아랫부분은 열 2 에 놓일 수 있다
```

- 브라우저는 열 높이를 맞추려고 끊을 자리를 고른다.
- 카드 내부도 후보가 되므로 카드가 두 열에 걸칠 수 있다.
- 걸칠지 말지는 내용 길이와 열 너비에 따라 달라진다.

### (2) `avoid` — 내부의 모든 나누기를 피한다

**언제 쓰나** — 카드 · 이미지와 캡션 묶음처럼 쪼개지면 뜻이 흐트러지는 덩어리다.

```text
.card { break-inside: avoid; }
        │
        ▼
카드 안쪽은 끊을 후보에서 빠진다 (열 · 페이지 · 영역 모두)
        │
        ▼
끊는 자리는 카드 앞이나 뒤로 밀리고, 카드는 한 열에 온전히 놓인다
```

- 카드 내부를 끊을 자리에서 뺀다.
- 그러면 브라우저는 카드 경계에서 끊는다.
- 결과로 카드 전체가 같은 열에 들어간다.

### (3) `avoid-page` · `avoid-column` · `avoid-region` — 한 종류만 피한다

**언제 쓰나** — 막고 싶은 나누기의 종류가 하나뿐일 때다.

```text
break-inside: avoid-column;   → 열 나누기만 막는다   (페이지 경계에선 끊길 수 있다)
break-inside: avoid-page;     → 페이지 나누기만 막는다 (열 경계에선 끊길 수 있다)
break-inside: avoid-region;   → 영역 나누기만 막는다
break-inside: avoid;          → 셋 다 막는다
```

- `avoid-column` 은 다단 화면에서 카드를 지키지만, 인쇄할 때 페이지 경계는 지키지 않는다.
- `avoid-page` 는 인쇄 페이지 경계만 지킨다.
- `avoid` 는 셋을 한꺼번에 지킨다.

> **페이지 나누기** — 인쇄(또는 인쇄 미리보기)에서 내용이 다음 쪽으로 넘어가는 일.\
> 예: 표가 1쪽 끝에서 끊겨 2쪽으로 이어지는 것.

> **영역(region)** — 내용이 여러 상자를 차례로 흘러 채우게 하는 레이아웃에서의 한 상자.\
> 예: 잡지 지면에서 기사가 상자 A 를 채우고 상자 B 로 이어지는 것.

### (4) 상속되지 않고, 애니메이션 되지 않는다

**언제 쓰나** — 어느 요소에 거느냐를 정할 때, 그리고 전환 효과를 기대할 때 떠올린다.

```text
.multicol { break-inside: avoid; }   ← 컨테이너에만 걸었다
        │
        ▼  상속: 아니다
.card 는 여전히 auto
        │
        ▼
카드는 여전히 열 경계에서 쪼개질 수 있다
```

- 상속되지 않으므로 부모에 건 값이 자식에게 내려가지 않는다.
- 지켜야 할 요소(카드)에 직접 걸어야 한다.
- 애니메이션 가능이 아니므로 `transition` 을 걸어도 값은 중간 단계 없이 바로 바뀐다.

## 문법 — 형태와 규칙

```html demo
<div class="cols">
  <div class="item">짧은 카드</div>
  <div class="item">조금 더 긴 카드입니다. 이 카드는 열 경계에서 반으로 잘리지 않아야 합니다.</div>
  <div class="item">마지막 카드</div>
</div>
<style>
  .cols { column-count: 2; column-gap: 12px; }
  .item {
    break-inside: avoid;          /* 카드 안쪽에서는 열을 나누지 않는다 */
    border: 1px solid #ccc;
    padding: 8px;
    margin-bottom: 8px;
  }
</style>
```

> **보이는 것** — 카드 셋이 두 열로 나뉘어 놓이고, 어느 카드도 두 열에 걸쳐 잘리지 않는다 (코드에서 읽은 것 — 렌더 실측 아님)

```text
break-inside: auto | avoid | avoid-page | avoid-column | avoid-region
```

| 값 | 뜻 | 막는 나누기 |
|---|---|---|
| `auto` | 기본값. 나누기를 허용한다 | 없음 |
| `avoid` | 요소 내부의 모든 나누기를 막는다 | 페이지 · 열 · 영역 |
| `avoid-page` | 요소 내부의 페이지 나누기를 막는다 | 페이지 |
| `avoid-column` | 요소 내부의 열 나누기를 막는다 | 열 |
| `avoid-region` | 요소 내부의 영역 나누기를 막는다 | 영역 |

- 기본값은 `auto` 다.
- 상속되지 않는다.
- 애니메이션 되지 않는다.
- 쪼개지면 안 되는 **자식 요소**에 건다 — 다단 컨테이너가 아니다.
- 다단 컨테이너는 `column-count`(열 개수)와 `column-gap`(열 사이 간격)으로 만든다.

> **다단 레이아웃(multi-column layout)** — 한 요소의 내용을 신문처럼 여러 열로 나눠 흘리는 배치.\
> 예: `column-count: 2` 를 준 `div` 의 내용이 왼쪽 열을 채운 뒤 오른쪽 열로 이어진다.

## 어디서 틀리나

### 1. 다단 컨테이너에 걸어 놓고 카드가 지켜지길 기대한다

`break-inside` 는 상속되지 않는다.
`.multicol` 에 `avoid` 를 걸어도 `.card` 는 `auto` 그대로다.
카드를 지키려면 `.card` 에 건다.

### 2. 관련된 덩어리를 감싸지 않고 따로 둔다

원본 팁: 다단 레이아웃에서 카드나 이미지+캡션 같은 관련 콘텐츠가 분리되지 않도록 할 때 `break-inside: avoid` 를 쓴다.
이미지와 캡션이 형제로 따로 있으면 「내부」가 없어 지킬 대상이 없다.
둘을 한 요소(예: `figure` 나 `div`)로 감싸고 그 요소에 건다.

### 3. `avoid-column` 으로 인쇄까지 지켜진다고 생각한다

`avoid-column` 은 열 나누기만 막는다.
인쇄할 때 페이지 경계에서는 카드가 끊길 수 있다.
화면과 인쇄 둘 다 지키려면 `avoid` 를 쓴다.

### 4. 나뉘지 않는 곳에서 효과를 찾는다

열 · 페이지 · 영역처럼 내용이 조각으로 나뉘는 곳이 아니면 끊을 자리 자체가 없다.
평범한 한 열 화면에서는 `avoid` 를 걸어도 달라지는 것이 없다.

### 5. 값이 부드럽게 바뀌길 기대한다

애니메이션 가능이 아니므로 `transition` 으로 `auto` → `avoid` 를 천천히 바꿀 수 없다.
값은 즉시 바뀌고, 그에 따라 배치도 한 번에 바뀐다.

### 6. 열보다 긴 요소도 반드시 한 조각에 들어간다고 믿는다

`avoid` 는 「피하라」는 뜻이다.
요소가 한 열(또는 한 페이지)보다 길면 끊지 않고는 담을 방법이 없으므로 결국 나뉠 수 있다 (확인 필요).

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 기본값 `auto` · 상속 안 됨 · 애니메이션 불가 | 원본 데이터의 속성 정의 (CSS 명세의 값 정의와 같다고 본다 — 확인 필요) |
| `avoid` 는 내부 나누기를 피한다 | 명세는 「피하려고 시도」로 정의한다고 알려져 있다 — 강제 보장은 아니다 (확인 필요) |
| `auto` 일 때 카드가 실제로 어디서 끊기나 | 브라우저의 열 균형 계산에 달려 있다 — 명세가 정확한 위치를 정하지 않는다 (확인 필요) |
| `avoid-region` 의 실제 효과 | 영역 레이아웃을 지원하는 브라우저에서만 의미가 있다 — 지원 범위 확인 필요 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 다단 레이아웃의 카드가 열에 걸쳐 잘린다 | 카드에 `break-inside: avoid` | 컨테이너에만 거는 것 |
| 이미지와 캡션이 떨어진다 | 둘을 감싼 요소에 `avoid` | 이미지에만 거는 것 |
| 인쇄할 때 표 행이 쪽 사이로 잘린다 | `avoid-page` 또는 `avoid` | `avoid-column` |
| 긴 본문 문단 | `auto`(그대로) | `avoid` — 큰 빈칸이 생기기 쉽다 |
| 다단 화면에서만 지키면 된다 | `avoid-column` | — |

## 핵심 문장

1. **`break-inside` 는 요소 안쪽에서 끊어도 되는지를 정한다** — 요소 사이가 아니라 내부다.
2. **`avoid` 는 페이지 · 열 · 영역 나누기를 모두 막고, `avoid-*` 는 한 종류만 막는다.**
3. **상속되지 않으므로 지켜야 할 자식 요소에 직접 건다.**
4. **나뉘는 곳(다단 · 인쇄 페이지 · 영역)에서만 효과가 있다.**
5. **애니메이션 되지 않는다** — 값은 즉시 바뀐다.

## 용어 풀이

- **나누기(break)** — 흐르던 내용을 한 조각에서 끊고 다음 조각으로 넘기는 일.
- **다단 레이아웃** — 한 요소의 내용을 여러 열로 나눠 흘리는 배치.
- **열(column)** — 다단 레이아웃에서 내용이 흐르는 세로 칸 하나.
- **페이지 나누기** — 인쇄에서 내용이 다음 쪽으로 넘어가는 일.
- **영역(region)** — 내용이 여러 상자를 차례로 채우는 레이아웃의 한 상자.
- **`column-count`** — 다단 컨테이너의 열 개수를 정하는 속성.
- **`column-gap`** — 열과 열 사이의 간격을 정하는 속성.
- **상속** — 부모에 준 값이 자식에게 그대로 내려가는 성질.

## 더 들어가면

- 요소 **앞**과 **뒤**의 나누기는 `break-before` · `break-after` 가 맡는다 — 「제목 바로 뒤에서 끊지 말 것」 같은 규칙은 이쪽이다 (확인 필요).
- 예전 인쇄용 속성 `page-break-inside` 는 `break-inside` 의 옛 이름처럼 쓰였다 (확인 필요).
- 문단 안에서 쪽 끝 · 쪽 처음에 남길 최소 줄 수는 `orphans` · `widows` 가 정한다 (확인 필요).
- CSS Regions(영역)를 구현한 브라우저는 드물어서 `avoid-region` 은 대부분 환경에서 눈에 띄는 효과가 없을 수 있다 (확인 필요).
- 다단 안에서 `avoid` 카드가 많으면 열 높이가 고르지 않게 남을 수 있다 (확인 필요).
