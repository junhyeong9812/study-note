## 한눈에 — 쉽게 말하면

**`column-span: all` 은 「신문 지면을 가로지르는 큰 제목」이다.**
신문 기사는 좁은 단 여러 개로 나뉘어 흐르다가, 새 기사의 큰 제목이 나오면 그 제목은 단을 무시하고 지면 폭 전체를 차지한다.
제목 아래에서는 다시 새 단들이 시작된다.
다단 레이아웃의 요소도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 신문 지면 | 다단 컨테이너(`column-count` 등이 걸린 상자) |
| 좁은 단 | 열(column) |
| 단을 가로지르는 큰 제목 | `column-span: all` 이 걸린 요소 |
| 단 안에서 흐르는 본문 | `column-span: none`(기본값)인 보통 요소 |

```text
┌────────── 다단 컨테이너 ──────────┐
│ 본문 │ 본문 │ 본문 │   ← 위쪽 열들
│━━━━━━━━ 큰 제목 (all) ━━━━━━━━━│   ← 폭 전체
│ 본문 │ 본문 │ 본문 │   ← 아래쪽 열들 (새로 시작)
└───────────────────────────────────┘
```

## 이 주제가 답하려는 질문

1. 다단 레이아웃 안의 한 요소가 열 하나에 갇히지 않고 폭 전체를 차지하게 하려면 어떻게 하나?
2. 그 요소의 앞과 뒤에 있는 내용은 각각 어디로 흐르나?
3. `column-span` 은 어떤 값을 받고, 상속 · 애니메이션은 어떻게 되나?

## 동작 방식

### (1) 기본값 `none` — 요소가 열 안에서 흐른다

**언제 쓰나** — 따로 쓸 일은 거의 없다.
아무것도 지정하지 않으면 이 상태다.

```text
입력:  .multicol { column-count: 3; }
       <p>A</p> <h3>제목</h3> <p>B</p>      (h3 에 column-span 없음)

무엇이 일어나나:
  A → 제목 → B 가 한 줄기 흐름으로 이어져
  열1 → 열2 → 열3 순서로 나뉘어 담긴다

결과:
  │ A A A │ 제목  │ B B B │
  │ A A   │ B B B │ B     │
  제목은 열 하나의 폭만 쓴다
```

- 컨테이너 안의 모든 내용은 한 줄기로 이어진다.
- 그 줄기가 열 개수만큼 잘려 왼쪽 열부터 차례로 담긴다.
- 제목도 그 줄기의 한 조각이라 열 하나의 좁은 폭 안에 들어간다.

> **다단 레이아웃** — 한 상자의 내용을 신문처럼 여러 세로 열로 나눠 흘리는 배치다.\
> 예: `column-count: 3` 이 걸린 `div` 의 글이 세 열로 나뉜다.

> **다단 컨테이너** — `column-count` 같은 다단 속성이 걸려 열을 만드는 상자다.\
> 예: 원본 예제의 `.multicol`.

### (2) `all` — 요소가 모든 열을 가로지른다

**언제 쓰나** — 다단 본문 사이에 섹션 제목 · 구분 띠 · 그림을 폭 전체로 넣고 싶을 때 쓴다.

```text
입력:  .spanning { column-span: all; }
       <p>A</p> <h3 class="spanning">제목</h3> <p>B</p>

무엇이 일어나나:
  ① 제목 앞의 A 만 모아 위쪽 열들에 나눠 담는다
  ② 제목을 컨테이너 내용 폭 전체에 한 줄로 놓는다
  ③ 제목 뒤의 B 는 제목 아래에서 열1부터 새로 나눠 담는다

결과:
  │ A A A │ A A   │       │
  │━━━━━━━━━━ 제목 ━━━━━━━━━━│
  │ B B B │ B B B │ B     │
```

- 제목이 흐름을 위아래 두 덩어리로 끊는다.
- 위 덩어리는 제목 위에서만 열을 이룬다.
- 제목은 열 경계와 열 사이 간격을 무시하고 폭 전체를 쓴다.
- 아래 덩어리는 제목 위에서 이어 흐르지 않고, 제목 아래 첫 열에서 다시 시작한다.

원본 팁의 말로 하면 「`column-span: all` 인 요소는 다단 콘텐츠를 위아래로 분리한다」.

> **스패너** — `column-span: all` 이 걸려 모든 열을 가로지르는 요소를 흔히 이렇게 부른다.\
> 예: 원본 예제의 `h3.spanning`.

### (3) 걸 자리 — 다단 컨테이너 안의 요소에 건다

**언제 쓰나** — 속성을 어디에 써야 할지 헷갈릴 때.

```text
.multicol (컨테이너)  ← column-count, column-gap
   └ h3.spanning (안쪽 요소) ← column-span: all
```

- 열을 만드는 속성(`column-count` · `column-gap`)은 컨테이너에 건다.
- `column-span` 은 컨테이너 **안쪽 요소**에 건다.
- 다단 컨테이너 밖에 있는 요소에는 가로지를 열이 없으니 `all` 을 걸어도 보이는 변화가 없다.

```html demo
<div style="column-count:3; column-gap:20px; background:#f1f5f9; padding:16px">
  <p>위쪽 문단이 세 열로 나뉘어 흐른다. 위쪽 문단이 세 열로 나뉘어 흐른다.</p>
  <h3 style="column-span:all; background:#3b82f6; color:white; padding:8px 16px">가로지르는 제목</h3>
  <p>아래쪽 문단은 제목 아래에서 다시 첫 열부터 흐른다. 아래쪽 문단은 다시 흐른다.</p>
</div>
```

> **보이는 것** — 회색 상자 위쪽에 첫 문단이 열들로 나뉘고, 그 아래 파란 제목 띠가 상자 폭 전체를 채우며, 띠 아래에서 둘째 문단이 첫 열부터 다시 열을 이룬다 (코드에서 읽은 것 — 렌더 실측 아님)

## 문법 — 형태와 규칙

```css
.multicol {
  column-count: 3;      /* 컨테이너: 열 3개 */
  column-gap: 20px;     /* 컨테이너: 열 간격 */
}
.multicol .section-title {
  column-span: all;     /* 안쪽 요소: 모든 열을 가로지름 */
}
.multicol .note {
  column-span: none;    /* 기본값: 열 안에서 흐름 */
}
```

| 값 | 뜻 |
|---|---|
| `none` | 기본값이다. 요소가 여러 열에 걸쳐지지 않고 열 하나 안에서 흐른다 |
| `all` | 요소가 모든 열에 걸쳐 배치된다. 앞뒤 다단 내용을 위아래로 나눈다 |

- 문법은 `column-span: none | all` 이다 — 키워드 두 개뿐이다.
- 「열 2개만 걸치기」 같은 숫자 값은 이 문법에 없다. 문법에 없는 값을 쓴 선언은 무효가 되어 무시되고, 요소는 기본값 `none` 처럼 남는다.
- 기본값은 `none` 이다.
- 상속되지 않는다 — 부모에 `all` 을 걸어도 자식의 계산값은 `none` 이다. 다만 자식은 이미 폭 전체를 쓰는 부모 상자 안에 들어 있으니 함께 넓게 보인다.
- 애니메이션 가능하지 않다 — `transition` 으로 `none` 과 `all` 사이를 부드럽게 바꿀 수 없다.

> **상속** — 부모에 지정한 속성값이 자식에게 저절로 이어지는 것이다.\
> 예: `color` 는 상속되고 `column-span` 은 상속되지 않는다.

## 어디서 틀리나

### 1. 컨테이너에 `column-span` 을 건다

`column-span` 은 컨테이너 안쪽의 요소가 「나는 열을 가로지르겠다」고 선언하는 속성이다.
`.multicol` 자체에 걸면 원하는 제목은 여전히 열 안에 갇힌다.

### 2. 제목 아래 내용이 위에서 이어 흐를 거라 기대한다

스패너는 흐름을 끊는다.
위쪽 열의 마지막 열이 비어 있어도 스패너 뒤 내용은 그 빈칸으로 올라가지 않고, 스패너 아래 첫 열에서 새로 시작한다.

### 3. 「두 열만 걸치기」를 하려 한다

값은 `none` 과 `all` 뿐이다.
`column-span: 2` 처럼 쓰면 선언이 무시된다.
일부 열만 걸치는 배치가 필요하면 다단 레이아웃이 아니라 다른 배치 방식을 고른다.

### 4. 켜고 끄기를 애니메이션하려 한다

애니메이션 가능하지 않은 속성이라 `transition` 을 걸어도 중간 단계가 생기지 않는다 (원본에 근거 없음 — 추론: 값이 즉시 바뀐다).

### 5. 섹션 제목 쓰임을 놓친다 (원본 팁)

원본 팁은 「섹션 제목에 유용하다」고 한다.
긴 다단 글을 여러 섹션으로 나눌 때 각 섹션 제목에 `column-span: all` 을 주면, 섹션마다 제목 → 그 섹션만의 열들 차례로 읽히게 된다.
제목 없이 한 줄기로 흘리면 앞 섹션 끝과 다음 섹션 시작이 같은 열에 섞인다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 값은 `none` · `all`, 기본값 `none`, 상속 안 됨, 애니메이션 불가 | CSS 명세(원본 재료) |
| `all` 인 요소가 앞뒤 다단 내용을 위아래로 나눈다 | CSS 명세(원본 팁) |
| 문법에 없는 값의 선언은 무시된다 | CSS 명세의 일반 규칙 |
| 브라우저마다 지원 시점 · 세부 배치 차이 | 각 브라우저 구현 (확인 필요) |
| 위쪽 열들에 내용이 어떤 비율로 나뉘어 보이나 | 브라우저 렌더링 (렌더 실측 아님) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 다단 글 사이의 섹션 제목 | `column-span: all` | 제목을 열 안에 그대로 두기 |
| 다단 글 중간의 넓은 그림 · 인용 띠 | `column-span: all` | 컨테이너를 둘로 쪼개 손으로 맞추기 |
| 다단 글 안의 작은 주석 · 본문 문단 | 기본값 `none` | `all` (흐름이 자꾸 끊긴다) |
| 몇 개의 열만 걸치는 배치 | 다른 배치 방식 | `column-span: 2` 같은 없는 값 |
| 다단 컨테이너가 아닌 곳의 요소 | 아무것도 | `column-span` (효과가 없다) |

## 핵심 문장

1. **`column-span: all` 은 다단 컨테이너 안의 요소가 모든 열을 가로지르게 한다.**
2. **스패너는 흐름을 끊는다** — 앞 내용은 위쪽 열들에, 뒤 내용은 아래쪽 새 열들에 담긴다.
3. **값은 `none`(기본) 과 `all` 둘뿐이다** — 일부 열만 걸치기는 없다.
4. **열은 컨테이너가 만들고, 가로지르기는 안쪽 요소가 선언한다.**
5. **상속되지 않고 애니메이션되지 않는다.**

## 용어 풀이

- **다단 레이아웃** — 한 상자의 내용을 여러 세로 열로 나눠 흘리는 배치.
- **다단 컨테이너** — `column-count` 등이 걸려 열을 만드는 상자.
- **열(column)** — 다단 컨테이너가 내용을 나눠 담는 세로 칸 하나.
- **스패너** — `column-span: all` 이 걸려 모든 열을 가로지르는 요소.
- **`column-count`** — 다단 컨테이너의 열 개수를 정하는 속성.
- **`column-gap`** — 열과 열 사이 간격을 정하는 속성.
- **상속** — 부모의 속성값이 자식에게 저절로 이어지는 것.
- **계산값** — 캐스케이드와 상속을 거쳐 요소에 최종으로 정해진 속성값.

## 더 들어가면

- 명세상 `column-span` 은 다단 컨테이너 안의 흐름 속(in-flow) 블록 요소에 적용된다. 떠 있는(`float`) 요소나 절대 위치 요소에는 적용되지 않는다 (확인 필요).
- 스패너가 컨테이너의 직계 자식이 아니어도 될 수 있지만, 중간 조상이 새 블록 서식 맥락을 만들면 가로지르지 못한다고 알려져 있다 (확인 필요).
- 스패너 위쪽 열들은 높이를 맞추도록 내용을 고르게 나누는(열 균형) 경향이 있다 (확인 필요).
- 다단 명세의 다음 단계에서 정수 값(몇 개 열만 걸치기)을 논의한 적이 있다고 하나, 현재 문법은 `none | all` 이다 (확인 필요).
- 일부 브라우저는 이 속성을 늦게 지원했다고 알려져 있다 — 정확한 버전은 (확인 필요).
