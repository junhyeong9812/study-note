## 퀴즈 정답

### 1. 달라지지 않는다 — 기본값이 이미 2다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
줄의 배치는 지우기 전과 같다.

**왜 그런가**
`widows` 의 기본값은 `2` 다.
`.multicol` 의 부모가 다른 값을 주지 않았다면, 줄을 지워도 `.multicol` 과 그 안의 `<p>` 의 값은 그대로 2다.
효과를 보려면 3 이상처럼 기본값과 다른 값을 넣어 비교해야 한다.
근거: 2-summary 「어디서 틀리나 1」 · 「문법 — 형태와 규칙」.

### 2. 분절 자리를 앞으로 당겨 줄을 하나 더 넘긴다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
앞 열의 줄 하나를 다음 열로 더 넘겨, 다음 열 맨 위가 문단의 줄 2개로 시작하게 한다.
앞 열의 아래쪽에는 한 줄만큼 빈 공간이 생길 수 있다.

**왜 그런가**
새 조각에 넘어가는 줄 수(1)가 `widows` 값(2)보다 적어 조건 위반이다.
브라우저는 분절 자리를 앞으로 옮겨 조건을 채운다.
근거: 2-summary 「동작 방식 (1)」.

### 3. `widows` 는 상속되는 속성이다

`widows` 는 상속된다.
`<p>` 에 값을 따로 적지 않았으므로 부모 `.multicol` 의 값 2 를 물려받는다.
줄 나눔 규칙은 줄을 가진 문단에서 작용하므로, 물려받은 값으로 `<p>` 의 분절이 다뤄진다.
근거: 2-summary 「동작 방식 (2)」.

### 4. 잘못된 값이라 선언이 무시된다

`widows` 의 값은 양의 정수만 허용하므로 0 과 음수는 잘못된 값이다.
CSS 는 잘못된 값의 선언을 통째로 버린다.
따라서 그 줄은 없는 것과 같고, 상속받은 값이나 기본값 `2` 가 그대로 쓰인다.
근거: 2-summary 「문법 — 형태와 규칙」.

### 5. 아무것도 달라지지 않는다

`widows` 는 분절이 있을 때만 의미가 있다.
보통 블록은 열이나 페이지로 나뉘지 않으므로 「새 조각의 맨 위」가 없고, 보이는 변화가 없다.
근거: 2-summary 「동작 방식 (4)」 · 「어디서 틀리나 3」.

### 6. 서서히 바뀌지 않는다 — 애니메이션 불가 속성이다

`widows` 는 애니메이션이 되지 않는 속성이다.
`transition` 을 걸어도 3 · 4 같은 사이 값을 거치지 않는다.
근거: 2-summary 「문법 — 형태와 규칙」.

### 7. `orphans` 는 앞 조각의 아래, `widows` 는 뒤 조각의 위

`orphans` 는 분절 앞 조각 맨 아래에 남아야 할 최소 줄 수다.
`widows` 는 분절 뒤 새 조각 맨 위에 있어야 할 최소 줄 수다.
둘을 함께 쓰면 문단이 어느 쪽에서도 한두 줄만 따로 떨어지지 않아 인쇄 품질이 좋아진다.
근거: 2-summary 「동작 방식 (3)」 · 「어디서 틀리나 2」.

### 8. 나눌 수 없다 — 통째로 밀리거나 규칙이 깨질 수 있다

3줄을 나누면 한쪽은 많아야 2줄, 다른 쪽은 1줄이 된다.
앞 조각 2줄 · 뒤 조각 2줄을 동시에 채우려면 4줄이 필요하므로 두 조건을 다 지키는 분절 자리는 없다.
이때 브라우저는 문단을 통째로 다음 조각으로 넘기거나, 그럴 공간이 없으면 규칙을 어기고 나눌 수 있다 (확인 필요 — 구체적인 선택은 구현에 달려 있다).
근거: 2-summary 「동작 방식 (3)」 · 「어디서 틀리나 5」.

## 실습 정답

### 실습 1. 2단 상자에서 새 열 상단 최소 줄 수 지정하기

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 1. 두 열로 나누기 | `.multicol { column-count: 2; }` |
| 2. 높이 고정 | `.multicol { height: 100px; }` |
| 3. 새 열 상단 최소 2줄 | `.multicol { widows: 2; }` |
| 4. 단락 기본 마진 제거 | `p { margin: 0; }` |
| 5. 줄 높이 1.6배 | `p { line-height: 1.6; }` |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/layout/reference/widows.html`

```html
<!DOCTYPE html>
<!-- HTML5 문서 선언 -->
<html lang="ko">
<head>
<meta charset="utf-8">
<title>widows - 페이지/열 나누기 후에 표시해야 할 최소 줄 수를 설정합니다</title>
<!--
  [레이아웃] widows
  설명: 페이지/열 나누기 후에 표시해야 할 최소 줄 수를 설정합니다
  구문: widows: <integer>
  팁: 타이포그래피에서 widow는 새 페이지/열 상단에 홀로 남은 단락 마지막 줄을 의미합니다. orphans와 함께 사용하면 인쇄 품질이 향상됩니다.
-->
<style>
  /* .multicol: 2단 + 과부 최소 2줄 */
  .multicol {
    column-count: 2;             /* 2개 열 */
    height: 100px;               /* 고정 높이로 분할 유발 */
    widows: 2;                   /* 새 열 상단에 단락 끝부분이 2줄 미만 남지 않도록 */
    background: #f1f5f9;         /* 회색 배경 */
    padding: 16px;               /* 안쪽 여백 */
    border-radius: 4px;          /* 모서리 둥글게 */
  }
  /* p: 단락 스타일 */
  p {
    margin: 0;                   /* 기본 마진 제거 */
    line-height: 1.6;            /* 줄 높이 */
  }
</style>
</head>
<body>
<!-- 열 나누기 시 과부 줄 방지 -->
<div class="multicol">
  <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco.</p>
</div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.multicol {
  column-count: 2;
  height: 100px;
  widows: 2;
  background: #f1f5f9;
  padding: 16px;
  border-radius: 4px;
}
p {
  margin: 0;
  line-height: 1.6;
}
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**

- 열 나누기를 만드는 것은 `column-count: 2` 다 — 분절이 있어야 `widows` 가 할 일이 생긴다.
- `widows` 는 `.multicol` 에 적어도 상속으로 `<p>` 에 닿는다.
- `widows: 2` 는 기본값과 같으므로, 효과를 비교하려면 3 이상으로 바꿔 본다.
- `line-height` 에 단위 없는 1.6 을 주면 줄 높이가 글자 크기의 1.6배가 된다.
- 배경 · 안쪽 여백 · 둥근 모서리는 꾸밈일 뿐 `widows` 동작과는 관계없다.
