## 한눈에 — 쉽게 말하면

**`column-count` 는 「신문 지면을 몇 단으로 나눌지 정하는 편집장의 지시」다.**
편집장이 「이 기사는 3단으로」라고 하면, 기사는 첫 단을 위에서 아래로 채운다.
그다음 둘째 단, 셋째 단으로 이어 흘러간다.
기사 원고(HTML)를 고쳐 쓸 필요는 없고, 지면 배치만 바뀐다.
CSS 다단 레이아웃도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 신문 지면 | 다단 컨테이너(`column-count` 를 준 요소) |
| 단(칸) | 열(column) |
| 「3단으로」라는 지시 | `column-count: 3` |
| 단 사이 여백 | `column-gap` |
| 기사 원고 | 컨테이너 안의 내용(문단 등) |

```text
원고: 가나다라마바사아자차카타파하...

column-count: 3
┌───────────────────────────────┐
│ 가나다   │ 라마바   │ 사아자   │
│ ↓        │ ↓        │ ↓        │
│ (1열)  → │ (2열)  → │ (3열)    │
└───────────────────────────────┘
  위→아래로 채우고, 다 차면 다음 열로
```

## 이 주제가 답하려는 질문

1. 한 덩어리 글을 HTML 을 나누지 않고 여러 열로 흘려 보내려면 무엇을 쓰나?
2. 열 수를 숫자로 정하면 열 하나의 너비는 어떻게 정해지나?
3. `column-width` 와 함께 쓰면 `column-count` 의 뜻은 어떻게 바뀌나?
4. `auto` 와 잘못된 값은 어떻게 동작하나?

## 동작 방식

### (1) 숫자를 주면 — 내용이 그 수만큼의 열로 흐른다

**언제 쓰나** — 긴 본문을 신문처럼 여러 단으로 읽히게 할 때 쓴다.
열 수를 딱 정하고 싶을 때 쓴다.

```text
입력:  .multicol { column-count: 3; column-gap: 20px; }
       <div class="multicol"><p>긴 문단 ...</p></div>

일어나는 일:
  ① 컨테이너가 다단 컨테이너가 된다
  ② 안쪽 너비를 열 3개 + 사이 간격 2개로 나눈다
  ③ 문단을 1열 위→아래로 채운다
  ④ 넘치는 부분이 2열, 3열로 이어진다

결과:  ┌──────┐ ┌──────┐ ┌──────┐
       │ 앞부분│ │ 중간 │ │ 뒷부분│
       └──────┘ └──────┘ └──────┘
          ↑20px↑   ↑20px↑
```

- ① `column-count` 에 양의 정수가 들어오면 그 요소는 다단 컨테이너가 된다.
- ② 열 너비는 직접 주지 않아도 정해진다 — 안쪽 너비에서 간격을 뺀 나머지를 열 수로 나눈다.
- ③ 내용은 가로가 아니라 세로 방향으로 먼저 채워진다.
- ④ HTML 은 문단 하나 그대로이고, 나뉘는 것은 화면 배치뿐이다.

예를 들어 안쪽 너비가 700px, 간격이 20px, 열이 3개면 간격이 2개라서 열 하나는 `(700 − 2×20) ÷ 3 = 220px` 이다.

```html demo
<div style="column-count: 3; column-gap: 20px; background: #f1f5f9; padding: 16px;">
  <p style="margin: 0;">첫 문장이 왼쪽 열 위에서 시작한다. 글이 길어지면 아래로 내려가다가 다음 열 맨 위로 넘어간다. 세 번째 열까지 이어서 흐른다. 원고는 문단 하나뿐이다.</p>
</div>
```

> **보이는 것** — 한 문단이 세 열로 나뉘어 왼쪽 열부터 위→아래로 이어 읽힌다 (코드에서 읽은 것 — 렌더 실측 아님)

### (2) `auto` — 열 수를 다른 속성에 맡긴다

**언제 쓰나** — 기본값이라 따로 쓰지 않으면 이 상태다.
열 수를 `column-width` 같은 다른 속성으로 정하게 할 때 쓴다.

```text
column-count: auto + column-width: auto   → 다단이 아님(보통 한 덩어리)
column-count: auto + column-width: 200px  → 200px 이상 열이 들어가는 만큼
```

- `auto` 는 「열 수를 내가 정하지 않는다」는 뜻이다.
- 다른 속성도 열을 정하지 않으면 다단이 생기지 않고 평소처럼 한 덩어리로 놓인다.

### (3) `column-width` 와 함께 — `column-count` 는 「최대 열 수」가 된다

**언제 쓰나** — 화면이 넓을 땐 열을 늘리되 어느 이상은 늘리지 않고, 좁을 땐 열 너비가 너무 줄지 않게 하고 싶을 때 쓴다.

```text
.box { column-width: 200px; column-count: 3; }

컨테이너가 넓다  (예: 1000px) → 200px 열이 4개 이상 들어가도 최대 3열
컨테이너가 중간  (예: 500px)  → 200px 열이 2개만 들어감 → 2열
컨테이너가 좁다  (예: 300px)  → 200px 열이 1개만 들어감 → 1열
```

- `column-width` 는 「열이 이 정도 너비는 되어야 한다」는 바람이다.
- 그 너비로 열이 몇 개 들어가는지가 먼저 정해진다.
- `column-count` 는 그 수가 넘지 못하는 천장이 된다.
- 그래서 원본은 `<integer>` 를 「이상적인 열 수」라고 부른다 — 늘 그 수가 나온다는 보장이 아니라 목표다.

## 문법 — 형태와 규칙

```css
.article {
  column-count: 3;      /* 3열 */
  column-gap: 20px;     /* 열 사이 간격 */
}
.article p {
  margin: 0;            /* 단락 기본 바깥 여백 제거 */
}
.responsive {
  column-width: 200px;  /* 열은 200px 이상 */
  column-count: 4;      /* 최대 4열 */
}
```

| 값 | 뜻 |
|---|---|
| `auto` | 기본값. 열 수를 `column-width` 등 다른 속성에 맡긴다 |
| `<integer>` | 양의 정수. 이상적인 열 수(목표)를 지정한다 |

- 문법은 `column-count: auto | <integer>` 이다.
- 기본값은 `auto` 다.
- 상속되지 않는다 — 다단 컨테이너 안의 자식 요소가 저절로 다단 컨테이너가 되지는 않는다.
- 애니메이션이 가능한 속성이다.
- 정수만 받는다 — `2.5` 같은 소수, `0`, 음수는 「양의 정수」가 아니다.
- 열 사이 간격은 `column-gap` 으로 따로 준다.
- 찾을 때 쓰는 말: 열 수, 컬럼 수, 다단 수, 단 수.

## 어디서 틀리나

### 1. `column-width` 와 같이 쓰고 「항상 3열」이라고 믿는다

원본 팁 그대로, `column-width` 도 설정하면 `column-count` 는 최대 열 수로 동작한다.
좁은 화면에서는 3보다 적은 열이 나온다.
「몇 열이 나오지?」는 컨테이너 너비까지 알아야 답할 수 있다.

### 2. 내용이 가로로 채워진다고 생각한다

다단은 1열을 위→아래로 다 채운 뒤 2열로 넘어간다.
카드를 왼쪽→오른쪽 차례로 놓는 격자와 읽는 순서가 다르다.

### 3. `0` · 음수 · 소수를 넣는다

값은 양의 정수만 된다.
허용되지 않는 값을 쓴 선언은 무시되고, 다른 규칙이 없으면 기본값 `auto` 가 남는다 (원본에 근거 없음 — 추론).

### 4. 자식에도 다단이 적용되리라 기대한다

상속되지 않는 속성이다.
자식은 부모가 만든 열 속으로 흘러 들어갈 뿐, 자식 안의 내용이 다시 3열로 나뉘지는 않는다.

### 5. 단락의 기본 여백을 잊는다

원본 예제는 `p { margin: 0; }` 으로 단락의 기본 바깥 여백을 없앤다.
여백을 남기면 글이 컨테이너의 안쪽 여백(`padding`)보다 더 떨어진 자리에서 시작한다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `column-count` 의 값은 `auto` 또는 양의 정수다 | CSS 명세(Multi-column Layout) |
| `column-width` 와 함께 쓰면 최대 열 수가 된다 | CSS 명세 (원본 팁) |
| 상속되지 않는다 · 기본값 `auto` | CSS 명세 |
| 열 높이를 고르게 맞추는 방식, 글이 열 사이에서 끊기는 정확한 자리 | 브라우저 렌더링 엔진마다 다를 수 있다 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 긴 본문을 신문처럼 나눠 읽게 | `column-count` (+ `column-gap`) | 문단을 손으로 쪼개 여러 `div` 에 나눠 넣기 |
| 화면 너비에 따라 열 수가 바뀌게 | `column-width` + 최대치로 `column-count` | `column-count` 하나만(늘 같은 수) |
| 카드를 왼쪽→오른쪽 차례로 줄 세우기 | 격자(`grid`) 나 `flex` | `column-count` (읽는 순서가 위→아래라 어긋난다) |

## 핵심 문장

1. **`column-count` 는 내용이 흘러 들어갈 열의 수를 정한다** — HTML 은 그대로, 배치만 나뉜다.
2. **내용은 1열 위→아래부터 채우고 다음 열로 넘어간다.**
3. **열 너비는 따로 안 줘도 된다** — 안쪽 너비에서 간격을 빼고 열 수로 나눈다.
4. **`column-width` 와 함께면 `column-count` 는 최대 열 수다** — 좁으면 더 적게 나온다.
5. **값은 `auto` 또는 양의 정수뿐이고, 상속되지 않는다.**

## 용어 풀이

- **다단 레이아웃** — 한 덩어리 내용을 여러 열로 나눠 흐르게 하는 배치.
- **다단 컨테이너** — `column-count` 나 `column-width` 로 열이 생긴 요소.
- **열(column)** — 다단 컨테이너 안의 세로 칸 하나.
- **`column-gap`** — 열과 열 사이의 간격을 정하는 속성.
- **`column-width`** — 열이 가졌으면 하는 너비를 정하는 속성.
- **상속** — 부모의 속성 값이 자식에게 저절로 넘어가는 것.
- **`auto`** — 값을 직접 정하지 않고 다른 조건에 맡긴다는 키워드.

## 더 들어가면

- 열 높이는 기본적으로 고르게 맞춰진다 — `column-fill` 의 기본값이 `balance` 라서다 (확인 필요).
- `column-gap` 을 주지 않으면 다단 컨테이너에서 `normal` 이 쓰이고, 보통 `1em` 정도가 된다 (확인 필요).
- `column-width` 와 함께일 때 열 수는 대략 `min(column-count, floor((너비 + 간격) ÷ (column-width + 간격)))` 로 정해진다 (확인 필요).
- 정수 값을 애니메이션하면 중간값도 정수로 반올림되어 열 수가 계단처럼 바뀐다 (확인 필요).
- 두 속성을 한 번에 쓰는 줄임 속성 `columns` 가 있다 (예: `columns: 200px 3`) (확인 필요).
- 열 사이 세로 구분선은 `column-rule`, 모든 열을 가로지르는 제목은 `column-span: all` 로 만든다 (확인 필요).
