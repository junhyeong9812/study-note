# css/layout/34 — column-count — 정답

> 복습 때 이 파일은 **맨 마지막에만** 연다.\
> 집필 — `claude-opus-5-5` 가 원본 재료를 뼈대로 쓴 **검수 전 초안**이다(2026-11-28).

## 퀴즈 정답

### 1. 첫 부분은 왼쪽 열 위에서 아래로, 이어지는 부분은 다음 열 맨 위부터

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)

글의 첫 부분은 왼쪽(1열) 맨 위에서 시작해 아래로 내려간다.
1열이 차면 이어지는 부분이 가운데(2열) 맨 위로 넘어가고, 다시 3열로 이어진다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**

다단 레이아웃은 내용을 가로가 아니라 세로 방향으로 먼저 채운다.
문단은 하나지만 화면 배치만 세 열로 나뉜다.
근거: 2-summary 「동작 방식 (1)」.

### 2. 2열 — `column-count` 가 천장이다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)

열은 2개 생긴다.

**왜 그런가**

1000px 이면 200px 열이 2개보다 많이 들어갈 수 있다.
하지만 `column-width` 와 함께 쓴 `column-count` 는 최대 열 수라서 2를 넘지 못한다.
근거: 2-summary 「동작 방식 (3)」, 원본 팁.

### 3. 1열 — 다단이 생기지 않는다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)

다단이 생기지 않고, 내용은 평소처럼 한 덩어리(한 열)로 놓인다.

**왜 그런가**

`auto` 는 열 수를 `column-width` 등 다른 속성에 맡긴다는 뜻이다.
다른 속성도 열을 정하지 않으니 열을 나눌 근거가 없다.
근거: 2-summary 「동작 방식 (2)」.

### 4. 열 수가 먼저 `column-width` 로 정해지고, `column-count` 는 그 위를 막기 때문이다

`column-width` 는 「열이 이 정도 너비는 되어야 한다」는 바람이다.
컨테이너 너비 안에 그 너비의 열이 몇 개 들어가는지가 먼저 정해진다.
좁으면 적게, 넓으면 많이 들어가는데, `column-count` 는 넓을 때 그 수가 지나치게 늘지 않게 막는 천장이 된다.
그래서 원본은 `<integer>` 를 「이상적인 열 수」라고 부른다.
근거: 2-summary 「동작 방식 (3)」 · 「어디서 틀리나 1」.

### 5. 열은 화면 배치일 뿐이고, 내용은 열 속으로 저절로 흘러가기 때문이다

다단 컨테이너는 안의 내용을 1열부터 차례로 흘려 채운다.
열 수를 바꾸면 그 흐름을 나누는 칸의 수만 바뀌고, 열 너비도 안쪽 너비에서 간격을 빼고 열 수로 나눠 다시 정해진다.
HTML 의 문단을 열마다 쪼갤 필요가 없다.
근거: 2-summary 「한눈에」 · 「동작 방식 (1)」.

### 6. 양의 정수가 아니라서 허용되지 않는다

`column-count` 는 `auto` 또는 양의 정수만 받는다.
`0` 은 양수가 아니고, `2.5` 는 정수가 아니다.
허용되지 않는 값을 쓴 선언은 무시되고, 다른 규칙이 없으면 기본값 `auto` 가 남는다 (원본에 근거 없음 — 추론).
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 3」.

### 7. 나누지 않는다 — 상속되지 않는 속성이다

자식 `div` 는 부모가 만든 열 속으로 흘러 들어갈 뿐이다.
`column-count` 는 상속되지 않으므로 자식이 저절로 다단 컨테이너가 되지 않는다.
자식도 다단으로 만들려면 자식에 직접 `column-count` 를 줘야 한다.
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 4」.

### 8. 다단은 위→아래, 격자는 왼쪽→오른쪽

다단 3열에서는 카드 1, 2 가 1열에 위아래로 쌓이고, 3, 4 가 2열로 넘어가는 식으로 세로로 먼저 채워진다.
격자 3열에서는 카드 1, 2, 3 이 첫 줄에 왼쪽→오른쪽으로 놓이고 4 부터 다음 줄로 내려간다.
그래서 카드를 차례대로 줄 세울 때는 격자(`grid`) 나 `flex` 가 맞고, 긴 글을 신문처럼 흘릴 때는 다단이 맞다.
근거: 2-summary 「어디서 틀리나 2」 · 「언제 쓰고 언제 안 쓰나」.

## 실습 정답

### 실습 1. 문단 하나를 3단으로 흘리기

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 문단이 세 열로 나뉘어 흐른다 | `.multicol { column-count: 3; }` |
| 열 사이에 간격을 둔다 | `.multicol { column-gap: 20px; }` |
| 문단의 기본 바깥 여백을 없앤다 | `p { margin: 0; }` |
| 배경 · 안쪽 여백 · 둥근 모서리는 그대로 | `.multicol` 의 `background` · `padding` · `border-radius` |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/layout/reference/column-count.html`

```html
<!DOCTYPE html>
<!-- HTML5 문서 선언 -->
<html lang="ko">
<head>
<meta charset="utf-8">
<title>column-count - 다단 레이아웃의 열 수를 설정합니다</title>
<!--
  [레이아웃] column-count
  설명: 다단 레이아웃의 열 수를 설정합니다
  구문: column-count: auto | <integer>
  팁: column-width도 함께 설정하면 column-count는 최대 열 수로 동작합니다.
-->
<style>
  /* .multicol: 3단 컨테이너 */
  .multicol {
    column-count: 3;             /* 3개 열로 콘텐츠 분할 */
    column-gap: 20px;            /* 열 사이 간격 */
    background: #f1f5f9;         /* 회색 배경 */
    padding: 16px;               /* 안쪽 여백 */
    border-radius: 4px;          /* 모서리 둥글게 */
  }
  /* p: 단락 기본 마진 제거 */
  p {
    margin: 0;                   /* 기본 마진 제거 */
  }
</style>
</head>
<body>
<!-- 텍스트가 3개 열로 자동 분배 -->
<div class="multicol">
  <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam.</p>
</div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.multicol {
  column-count: 3;
  column-gap: 20px;
  background: #f1f5f9;
  padding: 16px;
  border-radius: 4px;
}
p {
  margin: 0;
}
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- 핵심은 `column-count: 3` 한 줄이다 — 이것만으로 `.multicol` 이 다단 컨테이너가 된다.
- 열 너비는 직접 주지 않았다 — 안쪽 너비에서 간격 두 개를 빼고 3으로 나눠 정해진다.
- `column-width` 를 함께 주지 않았으므로 창 너비가 바뀌어도 열은 3개로 유지된다.
- HTML 은 문단 하나 그대로이고, 글은 1열 위→아래부터 이어 흐른다.
- `p { margin: 0; }` 은 단락의 기본 바깥 여백을 없애 글이 `padding` 바로 안에서 시작하게 한다.
