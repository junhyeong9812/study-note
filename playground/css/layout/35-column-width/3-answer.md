# css/layout/35 — column-width — 정답

> 복습 때 이 파일은 **맨 마지막에만** 연다.\
> 집필 — `claude-opus-5-5` 가 원본 재료를 뼈대로 쓴 **검수 전 초안**이다(2026-11-28).

## 퀴즈 정답

### 1. 한 열 · 150px 보다 좁다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)

상자 폭이 120px 이니 150px 짜리 열이 하나도 다 들어가지 않는다.
글은 열 하나에 모두 담기고, 그 열은 상자 폭을 넘지 못해 150px 보다 좁다.

**왜 그런가**

`column-width` 는 이상적 너비라서 공간이 부족하면 더 좁아진다.
2-summary 「동작 방식 (2)」.

### 2. 열 수가 늘고, 각 열은 150px 근처 이상으로 늘었다 줄었다 한다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)

아주 좁을 때는 열 하나이고 150px 보다 좁다.
폭이 커질수록 기준 너비의 열이 간격과 함께 더 들어가므로 열 수가 1, 2, 3 … 으로 늘어난다.
열 수가 바뀌지 않는 구간에서는 남는 폭을 열들이 나눠 가져 각 열이 150px 보다 넓어진다.

**왜 그런가**

열 수는 폭을 보고 그때그때 정해지고, 남는 폭은 열에 나눠 준다.
2-summary 「동작 방식 (1)」 · 「동작 방식 (3)」.

### 3. 실제 폭이 그 값보다 작아질 수도 있기 때문이다

최소 너비라면 열이 그 값보다 좁아지면 안 된다.
그런데 컨테이너가 기준보다 좁으면 열 하나가 기준보다 좁아진다.
반대로 남는 폭이 있으면 더 넓어지기도 한다.
그래서 값은 열 수를 정하는 「목표」일 뿐이다.
근거: 2-summary 「어디서 틀리나 1 · 2」 · 「동작 방식 (2)」.

### 4. 폭에 맞춰 열 수가 저절로 바뀐다

열 수를 고정하면 좁은 화면에서 열이 지나치게 가늘어져 읽기 어렵다.
열 너비를 기준으로 두면 넓은 화면에서는 열이 늘고 좁은 화면에서는 줄어, 한 열의 폭이 읽기 좋은 정도 근처로 유지된다.
미디어 쿼리 없이 이렇게 된다.
근거: 2-summary 「동작 방식 (3)」 · 「언제 쓰고 언제 안 쓰나」.

### 5. 선언이 무시되고 `auto` 로 남는다

길이 값은 양수만 허용된다.
허용되지 않는 값의 선언은 버려지므로 `column-width` 는 기본값 `auto` 그대로이고, 열 너비는 다른 속성이 정한다.
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 4」.

### 6. 나뉘지 않는다 — 상속되지 않는 속성이다

`column-width` 는 상속되지 않는다.
바깥 `div` 의 내용이 열로 흐를 뿐, 자식 `div` 가 제 안의 내용을 다시 다단으로 나누지는 않는다.
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 5」.

### 7. 다른 속성(`column-count` 등)과 컨테이너 폭이 정한다

`auto` 는 「이 속성으로 열 너비를 정하지 않는다」는 뜻이다.
그러면 열 수를 정하는 `column-count` 같은 다른 속성과 컨테이너 폭에 맡겨진다.
근거: 2-summary 「동작 방식 (4)」 · 「값 표」.

### 8. 열 수가 줄어들 수 있다

열 수를 셀 때 브라우저는 「기준 너비의 열 + 간격」이 몇 번 들어가는지 본다.
간격이 커지면 한 묶음이 차지하는 폭이 커져 같은 폭에 들어가는 열이 줄어든다.
근거: 2-summary 「동작 방식 (1)」.

## 실습 정답

### 실습 1. 폭에 따라 열 수가 바뀌는 글 상자

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 이상적 열 너비로 여러 열에 흘려 보내기 | `.multicol { column-width: 150px; }` |
| 열 사이 간격 | `.multicol { column-gap: 20px; }` |
| 문단 기본 여백 없애기 | `p { margin: 0; }` |
| 배경 · 안쪽 여백 · 모서리 유지 | `.multicol` 의 `background` · `padding` · `border-radius` |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/layout/reference/column-width.html`

```html
<!DOCTYPE html>
<!-- HTML5 문서 선언 -->
<html lang="ko">
<head>
<meta charset="utf-8">
<title>column-width - 다단 레이아웃에서 이상적인 열 너비를 설정합니다</title>
<!--
  [레이아웃] column-width
  설명: 다단 레이아웃에서 이상적인 열 너비를 설정합니다
  구문: column-width: auto | <length>
  팁: 설정한 값은 최소 너비가 아니라 이상적인 너비입니다. 공간이 부족하면 더 좁아지고, 남으면 더 넓어질 수 있습니다.
-->
<style>
  /* .multicol: 이상 너비 150px의 다단 */
  .multicol {
    column-width: 150px;         /* 이상적 열 너비 150px. 가용 공간에 따라 열 수 자동 결정 */
    column-gap: 20px;            /* 열 간격 */
    background: #f1f5f9;         /* 회색 배경 */
    padding: 16px;               /* 안쪽 여백 */
    border-radius: 4px;          /* 모서리 둥글게 */
  }
  /* p: 단락 기본 마진 제거 */
  p {
    margin: 0;                   /* 기본 마진 제거 */
  }
</style>
</head>
<body>
<!-- 너비 기반으로 열 수가 자동 결정됨 -->
<div class="multicol">
  <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam.</p>
</div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.multicol {
  column-width: 150px;
  column-gap: 20px;
  background: #f1f5f9;
  padding: 16px;
  border-radius: 4px;
}
p {
  margin: 0;
}
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- 열 수를 적는 줄은 없다 — `column-width` 하나로 열 수가 폭에 따라 정해진다.
- `150px` 은 목표일 뿐이어서 실제 열은 그보다 넓거나(남는 폭) 좁을(좁은 창) 수 있다.
- `column-gap` 은 열 사이 간격이자, 열 수를 셀 때 함께 자리를 차지하는 폭이다.
- `p { margin: 0; }` 은 문단의 기본 여백이 첫 열 머리를 밀어내지 않게 한다.
- 창 폭을 바꿔 보면 열 수가 바뀌는 모습을 확인할 수 있다 (코드에서 읽은 것 — 렌더 실측 아님).
