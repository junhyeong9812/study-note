## 퀴즈 정답

### 1. 가로(인라인 방향) 스크롤바가 생긴다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
문장이 한 줄로 이어져 200px 상자를 넘고, 상자는 가로 방향으로 스크롤된다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
`white-space: nowrap` 이 줄바꿈을 막아 인라인 방향 넘침이 생긴다.
`writing-mode` 지정이 없으니 수평 쓰기라 인라인 방향은 가로다.
`auto` 는 넘칠 때만 스크롤바를 단다.
근거: 2-summary 「동작 방식 (1)」·「(2)」·「(3)」.

### 2. 생기지 않는다 — 글이 줄바꿈되어 인라인 방향으로 넘치지 않는다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
문장이 상자 폭에 맞춰 여러 줄로 내려가고, 인라인 방향 스크롤바는 생기지 않는다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
줄바꿈이 허용되면 한 줄의 길이가 상자 폭을 넘지 않는다.
넘침이 없으니 `auto` 는 스크롤바를 만들지 않는다.
근거: 2-summary 「동작 방식 (1)」·「어디서 틀리나 2」.

### 3. 세로 축으로 스크롤된다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
글이 위에서 아래로 한 줄로 이어져 200px 높이를 넘고, 상자는 세로로 스크롤된다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
`vertical-rl` 에서는 글이 위→아래로 흐르므로 인라인 방향이 세로다.
`overflow-inline` 은 인라인 방향을 다루므로 세로 넘침에 걸린다.
근거: 2-summary 「동작 방식 (3)」.

### 4. 쓰기 방향이 바뀌어도 같은 CSS 가 「글이 흐르는 방향」에 맞게 동작하게 하려고

화면의 가로·세로로 정하면 세로쓰기에서 엉뚱한 축을 다루게 된다.
인라인 방향으로 정하면 `writing-mode` 에 따라 실제 축이 따라 바뀐다.
근거: 2-summary 「동작 방식 (3)」·「어디서 틀리나 1」.

### 5. `clip` 은 스크롤도 막는다

원본 설명은 `hidden` 에 「잘린다」만, `clip` 에 「잘리며 스크롤 불가」를 적는다.
잘린 부분에 스크롤로 다가갈 길까지 없애는 쪽이 `clip` 이다.
근거: 2-summary 「동작 방식 (2)」·「어디서 틀리나 3」.

### 6. `scroll` 은 스크롤바가 있고, `auto` 는 없다

`scroll` 은 넘침과 상관없이 인라인 방향 스크롤바를 늘 보인다.
`auto` 는 넘칠 때만 보이므로, 다 들어가면 스크롤바가 없다.
근거: 2-summary 「문법 — 형태와 규칙」 값 표·「어디서 틀리나 4」.

### 7. 같아지지 않는다 — 상속되지 않는다

부모에 준 값은 부모 상자에만 걸린다.
자식은 따로 지정하지 않으면 기본값 `visible` 이다.
덧붙여 이 속성은 애니메이션되지 않아 상태가 바뀌면 값이 즉시 바뀐다.
근거: 2-summary 「동작 방식 (4)」.

### 8. `overflow-x` 와 같은 일을 하고, 세로쓰기에선 세로 축(`overflow-y` 쪽)을 다룬다

수평 쓰기 모드에서 인라인 방향은 가로이므로 `overflow-x` 에 대응한다(원본 팁).
세로쓰기에서는 인라인 방향이 세로가 되므로 대응하는 물리 축도 세로로 바뀐다.
근거: 2-summary 「동작 방식 (3)」.

## 실습 정답

### 실습 1. 인라인 방향으로 넘칠 때만 스크롤되는 상자 만들기

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 1. `.box` 안에 긴 문장을 담은 `.content` | `<div class="box"><div class="content">…</div></div>` |
| 2. 줄바꿈 없이 한 줄 | `.content { white-space: nowrap; }` |
| 3. 논리적 속성으로 넘침 처리 | `.box { overflow-inline: … }` |
| 4. 넘칠 때만 스크롤바 | `overflow-inline: auto;` |
| 5. 고정 폭으로 넘침 유발 | `.box { width: 200px; }` |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/layout/reference/overflow-inline.html`

```html
<!DOCTYPE html>
<!-- HTML5 문서 선언 -->
<html lang="ko">
<head>
<meta charset="utf-8">
<title>overflow-inline - 인라인 방향의 넘침 처리 방식을 설정합니다</title>
<!--
  [레이아웃] overflow-inline
  설명: 인라인 방향의 넘침 처리 방식을 설정합니다
  구문: overflow-inline: visible | hidden | clip | scroll | auto
  팁: writing-mode에 따라 실제 적용 방향이 달라지는 논리적 속성입니다. 수평 쓰기 모드에서는 overflow-x에 대응합니다.
-->
<style>
  /* .box: 인라인 방향 자동 스크롤 박스 */
  .box {
    overflow-inline: auto;       /* 인라인 방향(수평 쓰기 모드 기준 가로) 자동 스크롤 */
    width: 200px;                /* 고정 너비로 넘침 유발 */
    background: #f1f5f9;         /* 회색 배경 */
    padding: 8px;                /* 안쪽 여백 */
    border: 2px solid #3b82f6;   /* 파란 테두리 */
    border-radius: 4px;          /* 모서리 둥글게 */
  }
  /* .content: 줄바꿈 금지 콘텐츠 */
  .content {
    white-space: nowrap;         /* 한 줄 강제 */
  }
</style>
</head>
<body>
<!-- 논리적 인라인 방향 넘침 처리 -->
<div class="box">
  <div class="content">인라인 방향으로 넘치는 매우 긴 콘텐츠입니다.</div>
</div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.box {
  overflow-inline: auto;
  width: 200px;
  background: #f1f5f9;
  padding: 8px;
  border: 2px solid #3b82f6;
  border-radius: 4px;
}
.content {
  white-space: nowrap;
}
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- 넘침을 만드는 두 조건은 고정 폭(`width`)과 줄바꿈 금지(`white-space: nowrap`)다.
- `overflow-inline: auto` 는 그 넘침이 있을 때만 인라인 방향 스크롤바를 단다.
- 이 문서는 `writing-mode` 를 지정하지 않으니 수평 쓰기이고, 그래서 결과는 `overflow-x: auto` 와 같다.
- `.box` 의 배경·여백·테두리·둥근 모서리는 꾸밈일 뿐 넘침 처리와 무관하다.
- `.content` 는 `.box` 의 값을 상속받지 않는다 — 스크롤되는 것은 `.box` 하나다.
