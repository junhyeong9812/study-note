## 한눈에 — 쉽게 말하면

**`column-fill` 은 「물 따르는 방식」이다.**
컵 세 개에 물을 나눌 때, 세 컵에 높이가 같아지도록 조금씩 나눠 따를 수 있다.
첫 컵을 가득 채운 다음 둘째 컵으로 넘어가도록 따를 수도 있다.
다단 레이아웃도 똑같은 구조다.
콘텐츠(물)를 열(컵)에 고르게 나누면 `balance`, 앞 열부터 차례로 채우면 `auto` 다.
다만 「가득 찼다」를 알려면 컵의 높이가 정해져 있어야 한다.
컨테이너에 높이가 없으면 `auto` 도 결국 고르게 나누는 것처럼 보인다.

| 비유 | 실체 |
|---|---|
| 컵 | 다단 컨테이너의 열 하나 |
| 물 | 컨테이너 안의 콘텐츠(글 · 단락) |
| 고르게 나눠 따르기 | `column-fill: balance` |
| 앞 컵부터 가득 채우기 | `column-fill: auto` |
| 컵의 높이 | 컨테이너의 `height` |

```text
balance (고르게)            auto (차례로, 높이 있음)
┌────┬────┬────┐            ┌────┬────┬────┐
│글글│글글│글  │            │글글│    │    │
│글글│글  │    │            │글글│    │    │
│    │    │    │            │글  │    │    │
└────┴────┴────┘            └────┴────┴────┘
```

## 이 주제가 답하려는 질문

1. 다단 컨테이너 안의 콘텐츠는 열마다 얼마씩 놓이나?
2. 앞 열부터 꽉 채우게 하려면 무엇이 필요한가?
3. 높이를 주지 않으면 `auto` 와 `balance` 는 어떻게 다른가?
4. `balance-all` 은 언제 쓰는 값이고, 지금 쓸 수 있나?

## 동작 방식

### (1) `balance` — 열마다 고르게 나눈다

**언제 쓰나** — 짧은 글을 여러 열에 펼쳐서 열 높이가 비슷하게 보이길 원할 때 쓴다.
기본값이라 아무것도 적지 않아도 이렇게 동작한다.

```text
입력                          일어나는 일                         결과
column-count: 3        →   콘텐츠 전체 길이를 잰다          →   세 열의 글 높이가
column-fill: balance   →   세 열에 비슷한 양씩 나눈다       →   거의 같다
height: 120px          →   (컨테이너 높이는 그대로 120px)   →   열 아래쪽은 남을 수 있다
```

- 콘텐츠 전체를 열 수만큼 나눠 각 열이 비슷한 양을 갖게 한다.
- 컨테이너에 높이가 있어도 그 높이까지 채우지 않고, 고르게 나눈 높이에서 멈춘다.
- 그래서 짧은 글이면 세 열 모두에 조금씩 글이 놓이고, 아래쪽은 비어 보인다.

```html demo
<div style="column-count: 3; column-fill: balance; height: 120px; column-gap: 20px; column-rule: 1px solid #cbd5e1; background: #f1f5f9; padding: 16px;">
  <p style="margin: 0;">Short text content that doesn't fill all columns evenly.</p>
</div>
```

> **보이는 것** — 한 문장이 세 열에 나뉘어 놓이고, 각 열의 글 높이가 비슷하다 (코드에서 읽은 것 — 렌더 실측 아님)

### (2) `auto` — 앞 열부터 차례로 채운다

**언제 쓰나** — 신문 지면처럼 첫 열을 끝까지 채운 뒤 다음 열로 넘어가야 할 때 쓴다.

```text
입력                          일어나는 일                         결과
column-count: 3        →   첫 열에 콘텐츠를 높이 끝까지     →   첫 열이 먼저 찬다
column-fill: auto      →   넘치는 부분만 둘째 열로          →   콘텐츠가 짧으면
height: 120px          →   그다음 셋째 열로                 →   뒤쪽 열이 비어 있다
```

- 첫 열을 컨테이너 높이까지 채운다.
- 첫 열에 다 들어가지 않는 부분만 다음 열로 넘긴다.
- 콘텐츠가 짧으면 둘째 · 셋째 열에는 아무것도 없을 수 있다 — 원본 설명의 「일부 열이 비어있을 수 있습니다」가 이 경우다.

```html demo
<div style="column-count: 3; column-fill: auto; height: 120px; column-gap: 20px; column-rule: 1px solid #cbd5e1; background: #f1f5f9; padding: 16px;">
  <p style="margin: 0;">Short text content that doesn't fill all columns evenly.</p>
</div>
```

> **보이는 것** — 문장이 첫 열에만 놓이고 둘째 · 셋째 열은 비어 있다 (코드에서 읽은 것 — 렌더 실측 아님)

### (3) 높이가 없을 때 — `auto` 가 `balance` 처럼 된다

**언제 쓰나** — `auto` 를 줬는데 기대와 달리 고르게 나뉘어 보일 때 이 소절을 떠올린다.

```text
입력                          일어나는 일                         결과
column-count: 3        →   「한 열이 가득 찼다」의 기준이   →   열 높이가 콘텐츠에 맞춰
column-fill: auto      →   되는 높이가 없다                 →   고르게 정해진다
(height 없음)          →   열 높이를 균형 맞춰 정한다       →   balance 와 같은 모습
```

- `auto` 는 「한 열을 끝까지 채운다」는 규칙인데, 끝이 어디인지 정해 주는 것이 컨테이너의 높이다.
- 높이가 없으면 그 끝이 없으므로 열 높이를 콘텐츠에 맞춰 고르게 정한다.
- 결과는 `balance` 와 같다 — 원본 팁이 말하는 내용이다.

### (4) `balance-all` — 분절된 곳에서도 모두 고르게

**언제 쓰나** — 원본은 「미지원」으로 적었다.
지금은 쓸 값이 아니라 이름만 알아 두는 값이다.

```text
입력                          일어나는 일                              결과
column-fill: balance-all →  콘텐츠가 여러 조각(예: 인쇄 페이지)  →   모든 조각의 열을
                         →  으로 나뉠 때도                        →   고르게 맞추려는 값
```

- `balance` 는 분절된 컨텍스트(콘텐츠가 페이지 같은 조각으로 끊기는 곳)에서 일부 조각만 고르게 맞출 수 있다.
- `balance-all` 은 그런 곳에서도 모든 열을 고르게 맞추겠다는 값이다.
- 원본은 이 값을 지원하지 않는다고 적었다(브라우저 지원 범위는 확인 필요).

## 문법 — 형태와 규칙

```css
.news {
  column-count: 3;     /* 다단 컨테이너로 만든다 */
  height: 200px;       /* auto 가 기준으로 삼을 높이 */
  column-fill: auto;   /* 앞 열부터 차례로 채운다 */
}

.intro {
  column-count: 2;
  column-fill: balance; /* 기본값 — 생략해도 같다 */
}
```

| 값 | 뜻 | 메모 |
|---|---|---|
| `balance` | 콘텐츠를 열마다 균등하게 배분한다 | 기본값 |
| `auto` | 콘텐츠를 앞 열부터 순차적으로 채운다 | 일부 열이 빌 수 있다 · 높이가 있어야 차이가 난다 |
| `balance-all` | 분절된 컨텍스트에서도 모든 열을 균등하게 배분한다 | 원본 기준 미지원 |

- 문법은 `column-fill: auto | balance | balance-all` 이다.
- 기본값은 `balance` 다.
- 상속되지 않는다 — 부모에 줘도 자식 요소가 물려받지 않는다.
- 애니메이션되지 않는다 — `transition` 을 걸어도 값 사이가 부드럽게 바뀌지 않는다.
- `column-count` 같은 다단 설정으로 다단 컨테이너가 된 요소에 주어야 뜻이 있다.
- 열 개수(`column-count`) · 열 사이 간격(`column-gap`) · 구분선(`column-rule`)은 따로 정한다 — `column-fill` 은 「어떻게 나누나」만 정한다.

## 어디서 틀리나

### 1. `auto` 를 줬는데 고르게 나뉜다

`column-fill: auto` 가 동작하려면 다단 컨테이너에 높이(`height`)가 있어야 한다.
높이가 없으면 `balance` 와 똑같이 동작한다.
`auto` 를 쓸 때는 높이를 함께 준다.

### 2. 다단이 아닌 요소에 준다

`column-count` 없이 `column-fill` 만 주면 나눌 열이 없다.
열이 하나뿐이니 나누는 방식이 달라도 보이는 차이가 없다.

### 3. 예제의 문장과 설정이 어긋난다

원본 예제의 문장은 「모든 열을 고르게 채우지 않는다」는 뜻인데, 설정은 `balance` 다.
그래서 화면에는 문장이 말하는 모습(뒤쪽 열이 빔)이 나오지 않는다.
그 모습을 보려면 `column-fill: auto` 로 바꿔야 한다(높이 `120px` 은 이미 있다).

### 4. `balance-all` 에 기대한다

원본은 `balance-all` 을 미지원으로 적었다.
써도 기대한 대로 동작하지 않을 수 있다(확인 필요).

### 5. 전환 효과를 기대한다

애니메이션 가능 값이 `False` 다.
`auto` 와 `balance` 사이를 `transition` 으로 부드럽게 옮길 수 없다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 기본값은 `balance` 다 · 상속되지 않는다 · 애니메이션되지 않는다 | 속성 정의(원본 재료) |
| 높이가 없으면 `auto` 가 `balance` 처럼 동작한다 | 원본 팁의 서술 — 명세 문구와 대조는 확인 필요 |
| `balance-all` 은 미지원이다 | 브라우저 구현 상태 — 언어 보장이 아니며 바뀔 수 있다(확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 짧은 소개 글을 열마다 고르게 펼치기 | `balance`(기본값) | `auto` — 뒤 열이 빈다 |
| 지면 높이가 정해진 신문식 배치 | `auto` + `height` | 높이 없는 `auto` |
| 인쇄 페이지마다 열을 모두 맞추기 | (원본 기준 지원되는 값 없음) | `balance-all` 에 기대기 |
| 열 채우기 방식을 부드럽게 바꾸기 | 다른 방법을 찾는다 | `transition` |

## 핵심 문장

1. **`column-fill` 은 콘텐츠를 열에 「어떻게 나누나」를 정한다** — 열 개수나 간격은 정하지 않는다.
2. **`balance` 는 고르게, `auto` 는 앞 열부터 차례로** 채운다.
3. **`auto` 는 높이가 있어야 의미가 있다** — 높이가 없으면 `balance` 와 같다.
4. **기본값 `balance` · 상속 안 됨 · 애니메이션 안 됨.**
5. **`balance-all` 은 원본 기준 미지원이다.**

## 용어 풀이

- **다단 레이아웃** — 콘텐츠를 신문처럼 여러 세로 열로 흘려 놓는 배치.
- **다단 컨테이너** — `column-count` 등으로 열을 갖게 된 요소.
- **열(column)** — 다단 컨테이너 안에서 콘텐츠가 놓이는 세로 칸 하나.
- **균등 배분** — 콘텐츠를 열마다 비슷한 양으로 나누는 방식(`balance`).
- **순차 채우기** — 앞 열을 끝까지 채운 뒤 다음 열로 넘어가는 방식(`auto`).
- **분절된 컨텍스트** — 콘텐츠가 인쇄 페이지 같은 여러 조각으로 끊겨 놓이는 환경.
- **상속** — 부모에 준 값을 자식이 저절로 물려받는 것.
- **애니메이션 가능** — `transition` · `animation` 으로 값 사이를 부드럽게 바꿀 수 있는가.
- **`column-count`** — 다단 컨테이너의 열 개수.
- **`column-gap`** — 열 사이 간격.
- **`column-rule`** — 열 사이에 긋는 구분선.

## 더 들어가면

- 다단 컨테이너가 높이를 가져도 `overflow` 가 생길 만큼 콘텐츠가 길면, 정한 열 수를 넘는 열이 옆으로 더 생길 수 있다(확인 필요).
- `height` 대신 `max-height` 를 줄 때 `auto` 와 `balance` 가 어떻게 갈리는지는 브라우저마다 다를 수 있다(확인 필요).
- 인쇄(페이지로 나뉘는 환경)에서는 `balance` 가 마지막 조각에서만 균형을 맞춘다는 설명이 있다(확인 필요).
