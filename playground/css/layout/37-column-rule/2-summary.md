## 한눈에 — 쉽게 말하면

**`column-rule` 은 「신문 지면에서 단과 단 사이에 인쇄된 가는 세로줄」이다.**
신문은 기사를 여러 단으로 나누고, 단 사이 여백 한가운데에 세로줄을 긋는다.
줄을 그었다고 여백이 넓어지거나 기사 폭이 좁아지지 않는다.
줄은 이미 있는 여백 위에 얹힐 뿐이다.
CSS 의 다단 레이아웃도 똑같은 구조다.

> **다단 레이아웃** — 한 요소의 내용을 신문처럼 여러 세로 열(단)로 나눠 흘리는 배치 방식이다.\
> 예: `column-count: 3;` 을 주면 문단 하나가 세 열로 나뉜다.

| 비유 | 실체 |
|---|---|
| 신문의 단 | 다단 컨테이너의 열 (`column-count` 로 개수를 정한다) |
| 단 사이 여백 | `column-gap` |
| 여백 한가운데의 세로줄 | `column-rule` |
| 줄의 굵기 · 모양 · 잉크 색 | `<column-rule-width>` · `<column-rule-style>` · `<column-rule-color>` |

```text
 ┌──────────┬───┬──────────┬───┬──────────┐
 │  열 1    │ │ │  열 2    │ │ │  열 3    │
 │  글…     │ │ │  글…     │ │ │  글…     │
 └──────────┴───┴──────────┴───┴──────────┘
             gap         gap
              ↑           ↑
        구분선은 간격의 가운데에 그려진다
```

## 이 주제가 답하려는 질문

1. 열 사이의 구분선은 정확히 어디에 그려지는가?
2. 구분선을 넣으면 열의 너비나 간격이 달라지는가?
3. 두께 · 스타일 · 색을 어떻게 한 줄로 주고, 하나를 빼면 무엇이 쓰이는가?
4. 구분선 설정은 자식에게 전해지는가, 그리고 애니메이션으로 바꿀 수 있는가?

## 동작 방식

### (1) 구분선은 열 간격의 가운데에 그려진다

**언제 쓰나** — 여러 열로 나눈 글에서 열의 경계를 눈에 띄게 하고 싶을 때 쓴다.

```text
입력:  column-count: 3; column-gap: 20px; column-rule: 2px solid #3b82f6;

무엇이 일어나나:
  열 1 | ←── 20px 간격 ──→ | 열 2 | ←── 20px 간격 ──→ | 열 3
                  ▲                            ▲
           간격의 한가운데               간격의 한가운데
           (2px 파란 실선)              (2px 파란 실선)

결과:  열이 셋이면 열 사이도 둘 → 세로선 2개
```

- 열이 셋이면 열과 열 사이의 간격은 둘이다.
- 구분선은 그 간격마다 하나씩, 간격의 한가운데에 그려진다.
- 그래서 세로선은 2개다.
- 첫 열의 바깥쪽과 마지막 열의 바깥쪽에는 간격이 없으므로 선도 없다.

### (2) 구분선은 공간을 차지하지 않는다

**언제 쓰나** — 구분선을 넣고 나서 열 너비가 왜 그대로인지, 간격을 어떻게 맞출지 판단할 때 떠올린다.

```text
입력:  같은 컨테이너에 column-rule 을 넣기 전 / 넣은 후

무엇이 일어나나:
  넣기 전:  [ 열 ][   gap   ][ 열 ][   gap   ][ 열 ]
  넣은 후:  [ 열 ][    │    ][ 열 ][    │    ][ 열 ]
                 선은 gap 위에 얹힐 뿐, gap 을 늘리지 않는다

결과:  열 너비 · 간격 너비는 그대로
```

- 구분선은 레이아웃 계산에 끼어들지 않는다.
- 열의 너비와 간격의 너비는 `column-count` · `column-gap` · 컨테이너 너비로 이미 정해진다.
- 구분선은 그렇게 정해진 간격 위에 덧그려진다.
- 그래서 선과 글자 사이를 띄우고 싶으면 선이 아니라 `column-gap` 을 넓힌다.

### (3) 세 값을 한 줄에 — 단축 속성과 기본값

**언제 쓰나** — 두께 · 스타일 · 색을 따로 쓰지 않고 한 번에 줄 때 쓴다.

> **단축 속성** — 관련된 여러 속성을 한 줄에 몰아 쓰는 속성이다.\
> 예: `column-rule: 2px solid #3b82f6;` 는 두께 · 스타일 · 색을 한꺼번에 정한다.

```text
입력:  column-rule: 2px solid #3b82f6;

무엇이 일어나나:
  2px      → <column-rule-width>   (두께)
  solid    → <column-rule-style>   (스타일)
  #3b82f6  → <column-rule-color>   (색)

결과:  2px 파란 실선
```

- 문법의 `||` 는 「셋 중 하나 이상을, 순서와 상관없이, 각각 한 번까지」 쓸 수 있다는 뜻이다.
- 그래서 `solid 2px #3b82f6` 처럼 순서를 바꿔도 같은 뜻이다.
- 기본값은 `medium none currentcolor` 다.
- 두께는 `medium`, 스타일은 `none`, 색은 `currentcolor` 다.
- 스타일 기본값이 `none` 이므로, 스타일을 정하지 않으면 선이 그려지지 않는다.
- 색을 빼면 `currentcolor`, 즉 그 요소의 글자색이 선 색이 된다.

> **currentcolor** — 그 요소의 `color`(글자색) 값을 그대로 쓰라는 키워드다.\
> 예: `color: #333` 인 요소에서 `currentcolor` 는 `#333` 이다.

### (4) 상속되지 않고, 애니메이션은 된다

**언제 쓰나** — 구분선을 어느 요소에 걸지, 마우스를 올렸을 때 선을 부드럽게 바꿀 수 있는지 정할 때 쓴다.

> **상속** — 부모에 준 속성 값이 따로 정하지 않은 자식에게 저절로 전해지는 것이다.\
> 예: `color` 는 상속되므로 부모의 글자색이 자식 문단에도 적용된다.

```text
입력:  .multicol { column-count: 3; column-rule: 2px solid #3b82f6; }
       .multicol > p { … }

무엇이 일어나나:
  .multicol  → 열을 만들고 열 사이에 선을 그린다
  p          → column-rule 을 물려받지 않는다 (상속: False)

결과:  선은 다단 컨테이너가 그린 열 사이에만 있다
```

- `column-rule` 은 상속되지 않는다.
- 그러니 선은 열을 만든 그 요소(다단 컨테이너)에 걸어야 한다.
- 애니메이션 가능 속성이므로 `transition` 으로 두께나 색이 바뀌는 과정을 이어 보일 수 있다.

## 문법 — 형태와 규칙

```html demo
<div class="news">
  <p>첫 기사 문단입니다. 이 글은 세 열로 나뉘어 흐르고, 열 사이에는 간격 한가운데에 세로 구분선이 그어집니다. 구분선은 간격을 넓히지 않습니다.</p>
</div>
<style>
  .news {
    column-count: 3;
    column-gap: 24px;
    column-rule: 1px dashed #94a3b8;
    padding: 12px;
  }
  .news p { margin: 0; }
</style>
```

> **보이는 것** — 문단이 세 열로 나뉘고, 열 사이 24px 간격의 한가운데에 회색 점선 세로줄이 두 개 보인다 (코드에서 읽은 것 — 렌더 실측 아님)

```text
column-rule: <column-rule-width> || <column-rule-style> || <column-rule-color>
```

| 자리 | 뜻 | 쓸 수 있는 값 | 빼면 |
|---|---|---|---|
| `<column-rule-width>` | 구분선의 두께 | `thin` · `medium` · `thick` 또는 길이(`2px` 등) | `medium` |
| `<column-rule-style>` | 구분선의 스타일 | `none` · `solid` · `dashed` · `dotted` 등 | `none` (선이 안 보인다) |
| `<column-rule-color>` | 구분선의 색 | 색 값 | `currentcolor` (글자색) |

- 세 값의 순서는 자유다.
- 세 값 중 하나 이상만 쓰면 된다.
- 다단 레이아웃(`column-count` 등)이 걸린 요소에 써야 의미가 있다.
- 상속되지 않는다.
- 애니메이션 가능하다.

## 어디서 틀리나

### 1. 스타일을 빼먹어 선이 안 보인다

`column-rule: 2px #3b82f6;` 처럼 두께와 색만 주면 스타일 자리는 기본값 `none` 이 된다.
`none` 은 선을 그리지 않는다는 뜻이라 아무것도 보이지 않는다.
선이 안 보이면 먼저 스타일(`solid` 등)이 들어 있는지 확인한다.

### 2. 구분선이 간격을 만들어 준다고 착각한다

원본 팁 그대로, 구분선은 공간을 차지하지 않는다.
선을 두껍게 해도 글과 선 사이가 벌어지지 않는다.
선 주변 여백은 `column-gap` 으로 정한다.

### 3. 선의 위치를 잘못 짐작한다

구분선은 열 간격(`column-gap`)의 한가운데에 그려진다.
열의 오른쪽 끝에 붙거나 간격의 한쪽 끝에 붙지 않는다.
열 바깥 가장자리에는 간격이 없으니 선도 없다.

### 4. 자식 요소에 건다

`column-rule` 은 상속되지 않고, 열 사이 선은 열을 만든 요소가 그린다.
안쪽 `p` 에 걸어도 바깥 컨테이너의 열 사이에는 선이 생기지 않는다.

### 5. 색을 빼면 검정이라고 짐작한다

색을 빼면 기본값 `currentcolor` 가 쓰인다.
그래서 선 색은 그 요소의 글자색을 따른다.
글자색이 회색이면 선도 회색이다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 구분선은 열 간격의 가운데에 그려지고 공간을 차지하지 않는다 | CSS 다단 레이아웃 명세 (원본 팁) |
| 기본값 `medium none currentcolor`, 상속 안 됨, 애니메이션 가능 | CSS 명세의 속성 정의 (원본 재료) |
| `medium` 이 정확히 몇 px 인가 | 명세가 고정하지 않는다 — 브라우저가 정한다 (확인 필요) |
| 화면에서 선이 몇 번째 픽셀에 찍히는가 | 브라우저의 렌더링 (렌더 실측 아님) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 다단 글의 열 경계를 보이고 싶다 | 다단 컨테이너에 `column-rule` | 각 열 요소에 `border-right` 를 흉내 내어 붙이기 |
| 선과 글 사이를 띄우고 싶다 | `column-gap` 을 넓힌다 | 선 두께를 키우기 |
| 선 색을 글자색과 맞추고 싶다 | 색을 빼서 `currentcolor` 에 맡긴다 | 같은 색을 두 곳에 따로 적기 |
| 다단이 아닌 일반 가로 배치에 구분선 | 다른 방법(테두리 등) | `column-rule` (다단이 없으면 그릴 열 사이가 없다) |

## 핵심 문장

1. **`column-rule` 은 다단 레이아웃의 열 사이 구분선을 두께 · 스타일 · 색 한 줄로 정하는 단축 속성이다.**
2. **선은 `column-gap` 의 한가운데에 그려지며 공간을 차지하지 않는다** — 열 너비도 간격도 바뀌지 않는다.
3. **기본값은 `medium none currentcolor` 다** — 스타일을 빼면 선이 없고, 색을 빼면 글자색이다.
4. **상속되지 않고 애니메이션은 된다** — 열을 만든 요소에 걸고, `transition` 으로 바꿀 수 있다.

## 용어 풀이

- **다단 레이아웃** — 요소의 내용을 여러 세로 열로 나눠 흘리는 배치다.
- **열(단)** — 다단 레이아웃에서 나뉜 세로 칸 하나다.
- **`column-count`** — 열의 개수를 정하는 속성이다.
- **`column-gap`** — 열과 열 사이 간격의 너비를 정하는 속성이다.
- **`column-rule`** — 열 간격 가운데에 그리는 구분선을 정하는 단축 속성이다.
- **단축 속성** — 여러 관련 속성을 한 줄에 몰아 쓰는 속성이다.
- **`||`** — CSS 문법 표기로, 나열된 것 중 하나 이상을 순서 상관없이 각각 한 번까지 쓴다는 뜻이다.
- **`currentcolor`** — 그 요소의 글자색을 가리키는 키워드다.
- **상속** — 부모의 속성 값이 자식에게 저절로 전해지는 것이다.
- **애니메이션 가능** — `transition` · `animation` 으로 값 사이의 변화를 이어 그릴 수 있다는 뜻이다.

## 더 들어가면

- `column-rule` 이 묶는 개별 속성의 이름은 `column-rule-width` · `column-rule-style` · `column-rule-color` 다 (확인 필요).
- 단축 속성에서 뺀 자리는 기본값으로 되돌아가므로, 앞서 `column-rule-color` 를 따로 줬어도 뒤에 쓴 `column-rule: 2px solid;` 가 색을 `currentcolor` 로 덮어쓴다 (확인 필요).
- 선 두께가 `column-gap` 보다 넓으면 선이 열의 글자 위로 넘어가 겹칠 수 있다 (확인 필요).
- 스타일 값에는 `double` · `groove` · `ridge` · `inset` · `outset` · `hidden` 처럼 `border-style` 과 같은 키워드를 쓸 수 있다 (확인 필요).
- 열이 비어 있는 자리에는 구분선을 그리지 않는다는 규칙이 있다 (확인 필요).
