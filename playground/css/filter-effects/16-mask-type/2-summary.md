## 한눈에 — 쉽게 말하면

**`mask-type` 은 「스텐실 판을 어떻게 읽을지 정하는 규칙」이다.**
스텐실 판 하나를 두고 두 가지로 읽을 수 있다.
하나는 「판이 하얄수록 많이 비치고 검을수록 가린다」는 규칙이다.
다른 하나는 「판의 색은 무시하고, 판이 있는 곳은 비치고 투명한 곳은 가린다」는 규칙이다.
SVG 의 `<mask>` 요소도 똑같은 구조다.

> **마스크** — 어떤 그림의 어느 부분을 얼마나 보일지 정하는 판이다.\
> 예: 사각형에 원 모양 마스크를 씌우면 원 모양만 남는다.

| 비유 | 실체 |
|---|---|
| 스텐실 판 | SVG `<mask>` 요소 안에 그린 내용 |
| 판을 대는 그림 | `mask="url(#id)"` 로 마스크를 건 요소 |
| 「밝기로 읽기」 규칙 | `mask-type: luminance` (기본값) |
| 「투명도로 읽기」 규칙 | `mask-type: alpha` |

```text
 마스크 내용          읽는 규칙            결과
 ┌────────┐       luminance → 흰 곳=보임, 검은 곳=가림
 │ 흰  ●검 │  ──▶
 └────────┘       alpha     → 칠해진 곳=보임(색 무관), 투명한 곳=가림
```

## 이 주제가 답하려는 질문

1. `<mask>` 안의 그림에서 무엇(밝기냐 투명도냐)을 보고 「보일 정도」를 정하나?
2. `mask-type` 은 어느 요소에 쓰는 속성이고, 다른 요소에 쓰면 어떻게 되나?
3. CSS 쪽의 비슷한 속성 `mask-mode` 와는 무엇이 같고 무엇이 다른가?

## 동작 방식

### (1) `luminance` — 밝기로 읽기 (기본값)

**언제 쓰나** — 흑백 그림을 마스크로 쓸 때다.
흰색으로 「보일 곳」, 검은색으로 「가릴 곳」을 그리는 전통적인 방식이다.

> **휘도(luminance)** — 색이 사람 눈에 얼마나 밝게 보이는지를 나타내는 값이다.\
> 예: 흰색은 휘도가 가장 높고 검은색은 가장 낮다.

```text
<mask id="m">                       마스크 내용의 각 점에서
  <rect fill="white"/>       ──▶    밝기를 잰다
  <circle fill="black"/>            흰색 → 완전히 보임
</mask>                             검은색 → 완전히 가림
                                    회색 → 그 사이만큼 비침
<rect fill="tomato" mask="url(#m)"/>  ──▶  사각형 가운데에 원 모양 구멍
```

- 마스크 내용의 점마다 밝기를 잰다.
- 밝기가 높을수록 마스크를 건 요소의 그 자리가 더 많이 보인다.
- 흰 사각형 자리는 보이고, 검은 원 자리는 가려져 구멍처럼 된다.
- `mask-type` 을 쓰지 않으면 이 방식으로 동작한다 — 기본값이 `luminance` 다.

### (2) `alpha` — 투명도로 읽기

**언제 쓰나** — 마스크 내용의 **모양**만 쓰고 색은 상관없을 때다.
색이 섞인 그림이나 아이콘을 그대로 마스크로 쓸 때 편하다.

> **알파(alpha)** — 픽셀이 얼마나 불투명한지를 나타내는 값이다.\
> 예: 완전 불투명은 1, 완전 투명은 0 이다.

```text
<mask id="a" style="mask-type: alpha">
  <rect fill="white"/>       ──▶    색은 무시하고 알파만 본다
  <circle fill="black"/>            흰색도 불투명, 검은색도 불투명
</mask>                             → 둘 다 완전히 보임
<rect fill="tomato" mask="url(#a)"/>  ──▶  구멍 없는 온전한 사각형
```

- 마스크 내용의 점마다 알파만 잰다.
- 검은색이라도 불투명하게 칠했으면 「보임」이다.
- 그래서 (1)과 같은 내용인데도 구멍이 생기지 않는다.
- 아무것도 칠하지 않은 곳(투명)만 가려진다.

### (3) 두 방식을 나란히

```html demo
<svg width="100" height="100">
  <mask id="lum">
    <rect width="100" height="100" fill="white"/>
    <circle cx="50" cy="50" r="30" fill="black"/>
  </mask>
  <rect width="100" height="100" fill="tomato" mask="url(#lum)"/>
</svg>
<svg width="100" height="100">
  <mask id="alp" style="mask-type: alpha">
    <rect width="100" height="100" fill="white"/>
    <circle cx="50" cy="50" r="30" fill="black"/>
  </mask>
  <rect width="100" height="100" fill="tomato" mask="url(#alp)"/>
</svg>
```

> **보이는 것** — 왼쪽은 가운데에 원 모양 구멍이 뚫린 붉은 사각형, 오른쪽은 구멍 없는 붉은 사각형이다 (코드에서 읽은 것 — 렌더 실측 아님)

- 마스크 내용은 두 쪽이 똑같다.
- 다른 것은 `<mask>` 에 쓴 `mask-type` 하나뿐이다.
- 같은 판을 다른 규칙으로 읽어 결과가 달라진다.

## 문법 — 형태와 규칙

```html
<svg width="120" height="120">
  <defs>
    <mask id="shape">
      <!-- 이 mask 의 내용을 어떻게 읽을지 정한다 -->
      <circle cx="60" cy="60" r="50" fill="orange"/>
    </mask>
  </defs>
  <style>
    #shape { mask-type: alpha; }  /* 색(주황) 무시, 원 모양만 사용 */
  </style>
  <rect width="120" height="120" fill="steelblue" mask="url(#shape)"/>
</svg>
```

```css
mask-type: luminance | alpha;
```

| 값 | 뜻 | 마스크 내용에서 보는 것 |
|---|---|---|
| `luminance` | 휘도(밝기) 기반 마스크 — 기본값 | 밝기: 흰색 = 보임, 검은색 = 가림 |
| `alpha` | 알파(투명도) 기반 마스크 | 불투명도: 칠한 곳 = 보임, 투명한 곳 = 가림 |

| 성질 | 값 |
|---|---|
| 기본값 | `luminance` |
| 상속 | 되지 않는다 |
| 애니메이션 | 되지 않는다 |
| 적용 대상 | SVG `<mask>` 요소 |

- 속성은 **마스크를 건 요소가 아니라 `<mask>` 요소 자신**에 쓴다.
- 상속되지 않으므로 `<svg>` 나 `<defs>` 에 써도 안쪽 `<mask>` 로 내려가지 않는다.
- 애니메이션되지 않으므로 두 값 사이를 부드럽게 넘어가는 전환은 없다.

## 어디서 틀리나

### 1. 일반 HTML 요소에 쓰고 효과를 기다린다

`mask-type` 은 SVG `<mask>` 요소 전용 속성이다.
`div` 같은 일반 요소에 써도 아무 일도 일어나지 않는다.
원본 예제가 시각 데모 대신 「SVG `<mask>` 요소에 적용되는 속성입니다」라는 안내 박스만 보이는 것도 이 때문이다 — SVG 맥락 밖에서는 보여 줄 효과가 없다.

### 2. 마스크를 건 요소에 쓴다

`mask="url(#m)"` 을 단 `rect` 에 `mask-type` 을 써도 소용없다.
읽는 규칙은 판(`<mask>`)의 성질이지, 판을 대는 그림의 성질이 아니다.

### 3. `mask-mode` 와 섞어 쓴다

팁에 따르면 CSS `mask-mode` 와 비슷하지만 `mask-type` 은 SVG 맥락에서만 쓴다.
두 속성 모두 알파 / 휘도 중 하나를 고르지만 **적용 대상이 다르다**.
`mask-mode` 는 CSS 쪽 마스크에, `mask-type` 은 SVG `<mask>` 요소에 쓴다.

### 4. 검은색으로 칠했는데 가려지지 않는다

`alpha` 모드에서는 색을 보지 않는다.
검은색이라도 불투명하면 「보임」이다.
검은색으로 가리고 싶다면 기본값 `luminance` 를 써야 한다.

### 5. `transition` 으로 모드를 바꾸려 한다

애니메이션 가능 속성이 아니므로 중간 단계 없이 바뀐다.

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 흑백 그라데이션으로 서서히 사라지게 | `luminance` (기본값) | `alpha` |
| 색 있는 아이콘·모양을 그대로 마스크로 | `alpha` | `luminance` (색마다 밝기가 달라 얼룩진다) |
| 일반 HTML 요소에 마스크 모드 지정 | `mask-mode` | `mask-type` |
| SVG `<mask>` 요소의 읽기 규칙 지정 | `mask-type` | `mask-mode` |

## 핵심 문장

1. **`mask-type` 은 SVG `<mask>` 요소의 내용을 무엇으로 읽을지 정한다** — 밝기(`luminance`)냐 투명도(`alpha`)냐.
2. **기본값은 `luminance`** — 흰색은 보이고 검은색은 가린다.
3. **`alpha` 는 색을 무시한다** — 칠한 곳은 색과 상관없이 보인다.
4. **`<mask>` 요소 자신에 쓴다** — 상속도, 애니메이션도 되지 않는다.
5. **CSS `mask-mode` 와 하는 일은 비슷하지만 대상이 다르다** — `mask-type` 은 SVG 맥락 전용이다.

## 관련 자료

- `mask` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `mask-mode` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `mask-image` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **마스크** — 어떤 그림의 어느 부분을 얼마나 보일지 정하는 판.
- **SVG `<mask>`** — SVG 에서 마스크 내용을 정의하는 요소. `mask="url(#id)"` 로 다른 요소에 건다.
- **휘도(luminance)** — 색이 눈에 보이는 밝기.
- **알파(alpha)** — 픽셀의 불투명한 정도.
- **휘도 마스크** — 마스크 내용의 밝기로 보일 정도를 정하는 마스크.
- **알파 마스크** — 마스크 내용의 불투명도로 보일 정도를 정하는 마스크.
- **`mask-mode`** — CSS 마스크 층에 알파 / 휘도 모드를 고르는 비슷한 속성.

## 더 들어가면

- 휘도 마스크는 밝기만이 아니라 밝기와 알파를 함께 반영한다고 알려져 있다 — 반투명한 흰색은 불투명한 흰색보다 덜 비친다 (확인 필요).
- `mask-mode` 에는 `match-source` 값이 있어, `mask-image` 가 SVG `<mask>` 를 가리키면 그 요소의 `mask-type` 을 따른다고 한다 (확인 필요).
- `mask-type` 은 CSS 속성뿐 아니라 `<mask mask-type="alpha">` 처럼 SVG 속성으로도 쓸 수 있다고 한다 (확인 필요).
- 휘도를 계산할 때 빨강·초록·파랑에 서로 다른 가중치를 준다 — 그래서 같은 채도라도 색마다 비치는 정도가 다르다 (확인 필요).
