## 한눈에 — 쉽게 말하면

**`shape-image-threshold` 는 「물 빠진 갯벌에서 어디까지를 땅으로 칠지 정하는 수위 표시」다.**
바닷물이 얕게 고인 곳부터 바싹 마른 곳까지, 갯벌은 젖은 정도가 조금씩 다르다.
「물이 이 정도보다 적으면 땅이다」라는 선을 정해야 지도에 땅의 윤곽을 그릴 수 있다.
CSS 도 똑같은 구조다.
`shape-outside` 에 이미지나 그라데이션을 주면, 브라우저는 픽셀마다 불투명한 정도(알파)를 보고 「어디까지가 도형인가」를 정한다.
그 경계선을 몇에 그을지가 `shape-image-threshold` 다.

| 비유 | 실체 |
|---|---|
| 갯벌 | `shape-outside` 에 준 이미지 · 그라데이션 |
| 젖은 정도 | 픽셀의 알파 값(0 = 완전 투명, 1 = 완전 불투명) |
| 수위 표시 | `shape-image-threshold` 의 숫자 |
| 지도에 그린 땅의 윤곽 | float 의 도형 — 글이 이 윤곽을 따라 감싼다 |

```text
  알파 값이 칸마다 다른 이미지          threshold 0.5            글이 감싸는 윤곽
  ┌───┬───┬───┐                    ┌───┬───┬───┐
  │1.0│0.8│0.4│                    │ ■ │ ■ │   │           ■■ 글글글
  ├───┼───┼───┤   →  0.5 와 비교 →  ├───┼───┼───┤   →       ■  글글글글
  │0.8│0.4│0.1│                    │ ■ │   │   │              글글글글글
  └───┴───┴───┘                    └───┴───┴───┘
```

## 이 주제가 답하려는 질문

1. 반투명한 이미지 · 그라데이션으로 도형을 만들 때, 어느 픽셀까지를 도형에 넣나?
2. 그 경계를 정하는 숫자는 어떤 범위이고, 기본값이면 어떻게 되나?
3. 이 속성은 무엇과 함께 있어야 효과를 내나?
4. 눈에 보이는 배경과 글이 감싸는 도형은 같은 것인가?

## 동작 방식

### (1) 알파로 도형을 뽑는다

**언제 쓰나** — `shape-outside` 에 사각형 · 원 같은 기본 도형이 아니라 이미지나 그라데이션을 줄 때 쓴다.
그 이미지가 반투명한 부분을 가지면 「어디까지 도형인가」를 정해야 한다.

```text
shape-outside: <이미지 또는 그라데이션>
shape-image-threshold: 0.5
        │
        ▼
픽셀마다 알파 값을 읽는다 (0.0 ~ 1.0)
        │
        ▼
알파를 임계값 0.5 와 비교한다
   ├─ 임계값 쪽을 넘는 픽셀 → 도형에 넣는다
   └─ 못 미치는 픽셀       → 빈 공간으로 본다
        │
        ▼
도형의 윤곽이 정해진다 → 옆 글이 그 윤곽을 따라 줄마다 시작 위치를 바꾼다
```

- 브라우저는 이미지의 색이 아니라 알파(불투명도)만 본다.
- 숫자 하나가 기준이 되어 각 픽셀이 도형 안 · 밖으로 갈린다.
- 도형 밖으로 갈린 픽셀 자리에는 글이 들어올 수 있다.
- 결과로 생긴 윤곽이 float 의 영역이 되고, 글은 그 영역을 피해 흐른다.

> **알파 채널** — 픽셀이 얼마나 불투명한지를 0(완전 투명)부터 1(완전 불투명)까지 나타내는 값.\
> 예: `rgba(0,0,0,0.5)` 의 마지막 `0.5` 가 알파다.

### (2) 그라데이션의 알파는 선을 따라 고르게 변한다

**언제 쓰나** — 이미지 파일 없이 `linear-gradient` 로 기울어진 도형을 만들 때 쓴다.
원본 예제가 이 방식이다.

```text
shape-outside: linear-gradient(135deg, rgba(0,0,0,1), rgba(0,0,0,0))

  좌상단 ─────────────── 우상단
   │ α=1.0    ╲            │        135deg = 좌상단 → 우하단 방향
   │      ╲  α=0.5 선       │        알파가 1 → 0 으로 줄어든다
   │  ╲           ╲        │
   │       α≈0.5    ╲  α=0 │        threshold 0.5:
  좌하단 ─────────────── 우하단       알파 0.5 인 곳을 잇는 선이 경계
```

- `135deg` 는 그라데이션이 좌상단에서 우하단 쪽으로 진행한다는 뜻이다.
- 시작색 `rgba(0,0,0,1)` 은 알파 1, 끝색 `rgba(0,0,0,0)` 은 알파 0 이다.
- 그래서 알파는 좌상단 모서리에서 1, 우하단 모서리에서 0, 그 사이에서 고르게 줄어든다.
- 알파가 같은 점들은 진행 방향에 수직인 선 위에 놓인다 — 정사각형에서 알파 0.5 인 선은 우상단과 좌하단을 잇는 대각선이 된다.
- 임계값 0.5 면 그 대각선의 좌상단 쪽 삼각형이 도형이 된다.
- 글은 위쪽 줄에서는 오른쪽 끝 가까이에서, 아래로 갈수록 왼쪽에서 시작한다(코드에서 읽은 것 — 렌더 실측 아님).

### (3) 숫자를 바꾸면 경계선이 움직인다

**언제 쓰나** — 같은 이미지로 도형을 더 크게 · 더 작게 잡고 싶을 때 쓴다.

```text
임계값      도형에 들어가는 것                   (2) 의 그라데이션에서
0.0        완전 투명을 뺀 거의 모든 픽셀          → 거의 정사각형 전체
0.5        절반 이상 불투명한 픽셀               → 좌상단 삼각형
1.0        완전 불투명한 픽셀만                  → 거의 없음(좌상단 끝점 근처)
```

- 숫자를 낮추면 더 투명한 픽셀까지 도형에 들어가 도형이 커진다.
- 숫자를 높이면 진하게 불투명한 픽셀만 남아 도형이 작아진다.
- 도형이 거의 없으면 글은 float 자리를 거의 피하지 않고 왼쪽 끝 가까이에서 시작한다(코드에서 읽은 것 — 렌더 실측 아님).

### (4) 보이는 배경과 도형은 따로다

**언제 쓰나** — 사용자가 도형을 눈으로 알아보게 하고 싶을 때 쓴다.

```text
.shape {
  shape-outside: linear-gradient(...)   ← 글이 피해 가는 윤곽 (눈에 안 보인다)
  background:    linear-gradient(...)   ← 눈에 보이는 색 (윤곽과 무관)
}
```

- `shape-outside` 의 그라데이션은 화면에 그려지지 않는다 — 윤곽 계산에만 쓰인다.
- 원본 예제는 같은 방향(`135deg`)의 그라데이션을 `background` 에 한 번 더 칠해, 도형이 어디쯤인지 보이게 한다.
- `border-radius` 도 보이는 모양만 다듬는다 — 글이 피해 가는 윤곽을 정하는 것은 `shape-outside` 쪽이다.

## 문법 — 형태와 규칙

```html demo
<div style="max-width:280px; font-size:14px; line-height:1.6;">
  <div style="float:left; width:120px; height:120px;
              shape-outside: linear-gradient(to right, black, transparent);
              shape-image-threshold: 0.5;
              background: linear-gradient(to right, #6366f1, transparent);"></div>
  <p>왼쪽 상자는 왼쪽이 불투명하고 오른쪽으로 갈수록 투명해진다. 임계값 0.5 면 상자의 왼쪽 절반만 도형이 되어, 글이 상자의 가운데쯤부터 시작한다.</p>
</div>
```

> **보이는 것** — 상자 왼쪽 절반만 도형이 되어 글 줄이 상자 가운데쯤에서 시작하고, 상자의 오른쪽 옅은 부분 위로 글이 겹친다 (코드에서 읽은 것 — 렌더 실측 아님)

- 형태: `shape-image-threshold: <number>` — 숫자 하나를 받는다.
- 기본값은 `0.0` 이다.
- 상속되지 않는다 — 부모에 줘도 자식 float 에는 영향이 없다.
- 애니메이션 가능하다 — 숫자이므로 `transition` 이 중간값을 거치며 바꿀 수 있다.
- `shape-outside` 가 이미지 · 그라데이션일 때만 뜻이 있다.
- `shape-outside` 는 float 요소에서 동작한다 — 원본 주석도 「float 필수」라고 적는다.

| 값 | 뜻 |
|---|---|
| `0.0` | 완전 투명 이상의 모든 픽셀 포함 (기본값) — 원본의 표현, 아래 「어디서 틀리나 3」 참고 |
| `0.5` | 50% 이상 불투명한 픽셀만 포함 |
| `1.0` | 완전 불투명한 픽셀만 포함 |
| 그 사이 숫자 | 숫자가 클수록 더 불투명한 픽셀만 남아 도형이 작아진다 |

## 어디서 틀리나

### 1. 그라데이션 · 반투명 이미지가 아니면 차이가 없다

원본 팁은 「그라디언트나 반투명 이미지를 `shape-outside` 로 사용할 때, 어느 정도의 투명도까지 도형에 포함할지 결정」한다고 한다.
알파가 0 아니면 1 뿐인 이미지(예: 배경이 완전히 투명한 아이콘)는 임계값을 0.1 로 하든 0.9 로 하든 윤곽이 같다.
값을 바꿨는데 아무 변화가 없으면, 이미지에 중간 알파가 있는지부터 본다.

### 2. float 가 없으면 아무 일도 없다

`shape-image-threshold` 는 `shape-outside` 의 도형을 다듬을 뿐이고, `shape-outside` 는 float 요소에서 동작한다.
`float: left` 를 빼면 글이 도형을 감싸지 않으므로 임계값도 보이는 효과가 없다.

### 3. 「이상」인가 「초과」인가

원본의 주장: `0.0` 은 「완전 투명 이상의 모든 픽셀 포함」, `0.5` 는 「50% 이상 불투명한 픽셀만 포함」.
의심스러운 점: 「이상」이 맞다면 `0.0` 에서는 완전히 투명한 픽셀(알파 0)까지 도형에 들어가 이미지의 사각형 전체가 도형이 된다.
그러면 기본값에서 투명한 배경을 가진 이미지로 윤곽을 따는 일이 안 된다.
명세는 「임계값보다 큰」 알파를 넣는다고 적는 것으로 기억한다 — 그렇다면 `0.0` 은 「조금이라도 불투명한 픽셀」, `1.0` 은 사실상 빈 도형이 된다 (확인 필요).
어느 쪽이든 정확히 경계값과 같은 픽셀만 달라질 뿐, 「숫자가 클수록 도형이 작아진다」는 큰 그림은 같다.

### 4. 보이는 그림이 곧 도형이라고 착각한다

`background` 에 칠한 그라데이션은 도형과 상관이 없다.
`shape-outside` 의 그라데이션과 방향이나 색 위치가 다르면, 눈에 보이는 모양과 글이 피해 가는 윤곽이 어긋난다.
또 임계값 밖의 옅은 부분 위로는 글이 겹쳐 지나간다.

### 5. 색이 아니라 알파만 본다

`rgba(0,0,0,1)` 을 `rgba(255,0,0,1)` 로 바꿔도 도형은 같다.
도형을 바꾸려면 알파(네 번째 숫자)나 임계값을 바꿔야 한다.

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 알파 값을 임계값과 비교해 도형을 정한다 | CSS Shapes 명세 (확인 필요) |
| 경계 비교가 「이상」인지 「초과」인지 | 명세가 정한다 — 원본은 「이상」, 이 문서는 「초과」로 기억함 (확인 필요) |
| 기본값 `0.0` · 상속 안 됨 · 애니메이션 가능 | 원본 재료의 속성 정의 — 명세의 속성 정의표 (확인 필요) |
| `shape-outside` 는 float 에서 동작 | 원본 주석 · 명세 (확인 필요) |
| 135deg 예제에서 좌상단 삼각형이 도형이 된다 | 그라데이션 정의에서 읽은 추론 — 실제 렌더는 브라우저마다 확인 필요 |
| 어느 브라우저가 지원하나 | 원본에 없음 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 그라데이션으로 기울어진 · 흐려지는 글 감싸기 | `shape-outside: linear-gradient(...)` + 임계값 | 임계값 없이 기본값에 맡기기(거의 사각형 전체가 될 수 있다) |
| 반투명 그림자가 있는 PNG 둘레로 글 감싸기 | 임계값을 올려 그림자를 도형에서 빼기 | 그림자까지 도형으로 잡히는 기본값 |
| 원 · 타원 · 다각형 윤곽 | `shape-outside: circle()` 같은 기본 도형 | `shape-image-threshold` (이미지가 없으면 쓸모없다) |
| float 이 아닌 요소 | 다른 배치 방법 | `shape-outside` · `shape-image-threshold` |

## 핵심 문장

1. **`shape-image-threshold` 는 이미지 · 그라데이션의 알파를 보고 「어디까지 도형인가」의 경계를 정하는 숫자다.**
2. **숫자가 클수록 더 불투명한 픽셀만 남아 도형이 작아지고, 기본값 `0.0` 은 거의 모든 불투명한 부분을 넣는다.**
3. **`shape-outside` 가 이미지 · 그라데이션이고 요소가 float 일 때만 뜻이 있다.**
4. **눈에 보이는 `background` 와 글이 피해 가는 윤곽은 따로 정한다.**
5. **색은 상관없고 알파만 본다 — 중간 알파가 없는 이미지에서는 숫자를 바꿔도 같다.**

## 용어 풀이

- **알파 채널** — 픽셀의 불투명도, 0(투명)~1(불투명).
- **임계값(threshold)** — 「이 값을 넘느냐」로 둘을 가르는 기준 숫자. 원본 키워드의 「도형 임계값 · 알파 임계값 · 쉐이프 쓰레숄드」가 모두 이것이다.
- **`shape-outside`** — float 요소 둘레로 글이 감쌀 윤곽을 정하는 속성.
- **이미지 도형** — `shape-outside` 에 이미지 · 그라데이션을 줘 알파로 뽑은 윤곽.
- **float** — 요소를 왼쪽이나 오른쪽에 띄워 글이 그 옆으로 흐르게 하는 배치.
- **`linear-gradient`** — 한 방향으로 색(과 알파)이 고르게 변하는 이미지를 만드는 함수.
- **상속** — 부모에 준 값이 자식에게 저절로 넘어가는 것. 이 속성은 상속되지 않는다.
- **애니메이션 가능** — `transition` · `animation` 이 값의 중간을 거치며 바꿀 수 있다는 뜻.

## 더 들어가면

- 0 보다 작거나 1 보다 큰 숫자는 0~1 범위로 잘린다 (확인 필요).
- 다른 출처(도메인)의 이미지를 `shape-outside` 에 쓰면 CORS 허용이 없을 때 도형이 만들어지지 않는다 (확인 필요).
- 도형과 글 사이에 여백을 두는 것은 `margin-right` 보다 `shape-margin` 이 맞다 — 이미지 도형은 margin 상자 안에서 잘리므로 `margin-right` 가 글과의 간격으로 보이지 않을 수 있다 (확인 필요).
- `shape-outside` 의 이미지 도형에서 기준 상자는 기본적으로 margin-box 다 (확인 필요).
