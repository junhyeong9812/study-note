## 한눈에 — 쉽게 말하면

**`aspect-ratio` 는 「액자 규격」이다.**
사진관에서 「4×6 규격」이라고 하면 가로를 정하는 순간 세로가 따라 정해진다.
액자를 크게 맞추든 작게 맞추든 가로와 세로의 비는 그대로다.
CSS 의 `aspect-ratio` 도 똑같은 구조다.
박스의 폭(또는 높이) 한쪽만 정해 두면 나머지 한쪽을 브라우저가 비율로 계산해 채운다.

| 비유 | 실체 |
|---|---|
| 액자 규격(4×6, 16:9 …) | `aspect-ratio: 16 / 9` 같은 비율 값 |
| 액자 가로 길이를 정함 | `width` 가 정해짐(직접 지정 또는 부모 · 그리드가 정함) |
| 세로가 저절로 정해짐 | `height` 가 비율로 계산됨 |
| 「세로는 이 이상 못 넘어」라는 벽 | `max-height` 같은 제약 — 비율을 깨뜨릴 수 있다 |

```text
  width = 320px  (정해짐)
  ┌────────────────────────────┐
  │                            │
  │      aspect-ratio: 16/9    │  height = 320 × 9 / 16 = 180px  (계산됨)
  │                            │
  └────────────────────────────┘
```

## 이 주제가 답하려는 질문

1. 폭만 정해진 박스의 높이를 어떻게 비율로 고정하나?
2. 한쪽 길이가 정해지면 다른 쪽은 어떤 식으로 계산되나?
3. 비율이 깨지는 때는 언제인가?
4. `aspect-ratio` 이전에 쓰던 `padding-top` 퍼센트 핵은 무엇이고 왜 동작했나?

## 동작 방식

### (1) 폭이 정해지면 높이를 계산한다

**언제 쓰나** — 비디오 임베드 · 이미지 카드 · 썸네일처럼 폭은 화면에 따라 늘고 줄지만 모양은 유지해야 할 때.

```text
입력 코드                         무엇이 일어나나                       결과
.video {                         ① width 가 320px 로 정해진다            320 × 180
  width: 320px;            →     ② height 는 지정이 없다          →
  aspect-ratio: 16 / 9;          ③ height = width × 9 ÷ 16
}                                   = 320 × 9 ÷ 16 = 180px
```

- ① 박스의 폭이 먼저 정해진다.
- ② 높이는 아무 값도 받지 않아 비어 있다.
- ③ 비어 있는 높이를 브라우저가 「폭 × 세로비 ÷ 가로비」로 채운다.

폭이 직접 지정되지 않아도 된다.
그리드 칸이나 부모가 폭을 정해 주면 그 폭을 기준으로 높이가 계산된다.
그래서 화면 폭이 바뀌어 칸 폭이 바뀌면 높이도 같이 바뀌고, 모양(비율)은 그대로다.

### (2) 높이가 정해지면 폭을 계산한다

**언제 쓰나** — 줄 높이를 맞춰야 하는 아이콘 · 아바타처럼 세로가 기준일 때.

```text
입력 코드                         무엇이 일어나나                       결과
.thumb {                         ① height 가 90px 로 정해진다            120 × 90
  height: 90px;            →     ② width 는 지정이 없다           →
  aspect-ratio: 4 / 3;           ③ width = height × 4 ÷ 3
}                                   = 90 × 4 ÷ 3 = 120px
```

- ① 이번에는 높이가 먼저 정해진다.
- ② 폭이 비어 있다.
- ③ 비어 있는 폭을 비율로 채운다 — 계산 방향만 (1)과 반대다.

### (3) 제약이 끼어들면 비율이 깨진다

**언제 쓰나** — 쓰는 기법이 아니라 피해야 할 함정이다.

```text
입력 코드                         무엇이 일어나나                       결과
.box {                           ① width = 400px                        400 × 150
  width: 400px;            →     ② 비율로 계산한 height = 225px    →    (16:9 가 아님)
  aspect-ratio: 16 / 9;          ③ max-height 150px 가 높이를 자른다
  max-height: 150px;             ④ width 는 400px 그대로 남는다
}
```

- ① 폭이 정해진다.
- ② 비율대로라면 높이는 400 × 9 ÷ 16 = 225px 다.
- ③ `max-height` 가 높이를 150px 로 누른다.
- ④ 폭은 따로 지정된 값이라 줄지 않으므로 결과는 400:150, 비율이 깨진다.

### (4) 예전 방식 — `padding-top` 퍼센트 핵

**언제 쓰나** — `aspect-ratio` 가 없던 때의 우회법이다. 옛 코드를 읽을 때 알아보면 된다.

```text
입력 코드                              무엇이 일어나나                         결과
.old-ratio {                          ① padding 의 퍼센트는 부모의 「폭」을      부모 폭 320px 일 때
  padding-top: 56.25%;          →        기준으로 계산된다                 →    높이 180px 인 빈 박스
  position: relative;                 ② 56.25% = 9 ÷ 16
}                                     ③ 그래서 높이가 늘 폭의 9/16 이 된다
```

- ① 세로 방향 여백인 `padding-top` 도 퍼센트일 때는 폭을 기준으로 잡힌다.
- ② 9 를 16 으로 나누면 0.5625, 곧 56.25% 다.
- ③ 박스 높이가 패딩만으로 「폭의 9/16」이 되어 16:9 모양이 된다.
- 다만 높이를 패딩이 차지하므로 내용물은 패딩 위에 겹쳐 놓아야 한다.
- 그래서 `position: relative` 를 두고 안쪽 내용을 `position: absolute` 로 덮어씌우는 짝으로 쓰였다.

> **padding-top 퍼센트 핵** — 퍼센트 패딩이 폭 기준이라는 점을 이용해 높이를 폭의 일정 비율로 만드는 옛 기법.\
> 예: `padding-top: 75%` 는 4:3 박스(3 ÷ 4 = 0.75).

원본의 팁에 따르면 이제 `aspect-ratio` 가 모든 모던 브라우저에서 지원되므로 새 코드에서는 핵을 쓸 까닭이 없다.

### (5) 비율 박스 안쪽을 채우기

예제에서 비율은 바깥 박스(`.ar-box`)가 갖고, 라벨은 안쪽 박스(`.ar-inner`)가 그린다.
안쪽 박스는 `width: 100%; height: 100%` 로 바깥 박스를 꽉 채운다.
바깥 박스의 높이가 비율로 정해졌으므로 `height: 100%` 는 「비율이 정한 높이」를 따라간다(원본 주석: 「부모 높이 채움(aspect-ratio가 정한 높이)」).
바깥 박스의 `overflow: hidden` 은 둥근 모서리 밖으로 안쪽 배경이 삐져나오지 않게 한다.

## 문법 — 형태와 규칙

```html demo
<div class="wrap">
  <div class="r169">16 : 9</div>
  <div class="r11">1 : 1</div>
</div>
<style>
  .wrap { display: grid; grid-template-columns: 1fr 1fr; gap: 12px; width: 320px; }
  .wrap div { display: flex; align-items: center; justify-content: center;
              color: white; background: #3b82f6; border-radius: 8px; }
  .r169 { aspect-ratio: 16 / 9; }
  .r11  { aspect-ratio: 1; }
</style>
```

> **보이는 것** — 같은 폭의 두 칸 가운데 왼쪽은 납작한 가로형 직사각형, 오른쪽은 정사각형이 놓인다 (코드에서 읽은 것 — 렌더 실측 아님)

| 값 | 뜻 | 흔한 쓰임 (원본 예제 주석) |
|---|---|---|
| `16 / 9` | 가로 16 : 세로 9 | 영상 · 유튜브 표준 |
| `4 / 3` | 가로 4 : 세로 3 | 클래식 사진 · 썸네일 |
| `1` | `1 / 1` 과 같다 — 정사각형 | 아바타 · 썸네일 |
| `21 / 9` | 가로 21 : 세로 9 | 시네마 · 울트라와이드 |

- 꼴은 `aspect-ratio: 가로 / 세로;` 다 — 가운데는 빗금(`/`)이다.
- 숫자 하나만 쓰면 `숫자 / 1` 로 읽는다 — `aspect-ratio: 1` 은 정사각형이다.
- 폭과 높이 중 **한쪽만** 정해져 있어야 나머지가 계산된다.
- 원본 예제는 반응형 그리드 `grid-template-columns: repeat(auto-fit, minmax(120px, 1fr))` 와 함께 쓴다 — 칸 폭은 120px 이상에서 컨테이너에 맞춰 늘고, 높이는 각 칸의 비율이 따라 정한다.

## 어디서 틀리나

### 1. `max-height` · `min-height` 같은 제약을 함께 걸면 비율이 깨진다

원본 팁의 경고다.
비율로 계산된 높이를 제약이 자르면, 폭은 그대로라 모양이 달라진다(동작 방식 (3)).
비율을 지키고 싶다면 높이 쪽을 묶지 말고 폭 쪽(`max-width` 등)으로 크기를 조절하는 편이 안전하다.

### 2. `width` 와 `height` 를 둘 다 지정하면 계산할 쪽이 없다

`aspect-ratio` 는 비어 있는 한쪽을 채우는 규칙이다.
두 쪽이 다 정해져 있으면 채울 자리가 없으므로 비율은 크기에 영향을 주지 못한다.
「비율을 줬는데 안 먹는다」면 높이나 폭이 다른 규칙에서 이미 지정돼 있지 않은지 본다.

### 3. 값에 콜론을 쓰지 않는다

라벨에는 「16 : 9」라고 써도 CSS 값은 `16 / 9` 다.
`aspect-ratio: 16:9` 는 올바른 값이 아니라서 선언이 버려진다.

### 4. 안쪽 요소가 박스를 채우지 않으면 비율이 안 보인다

비율은 바깥 박스가 가진다.
배경을 안쪽 요소에 칠했다면 안쪽 요소에 `width: 100%; height: 100%` 를 줘야 바깥 박스 모양 그대로 칠해진다.

### 5. 옛 `padding-top` 핵을 새 코드에 옮기지 않는다

원본 팁대로 핵은 `aspect-ratio` 이전의 방식이다.
핵은 높이를 패딩으로 만들기 때문에 내용을 절대 위치로 겹쳐야 하는 등 구조가 번거롭다.
`aspect-ratio` 한 줄이면 같은 결과를 얻는다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 한쪽 길이가 정해지면 다른 쪽을 비율로 계산한다 | CSS 명세(`aspect-ratio` 속성 정의) |
| `max-height` 등 제약이 비율보다 앞선다 | CSS 명세의 크기 계산 규칙 — 세부 조건은 (확인 필요) |
| 퍼센트 `padding` 은 폭을 기준으로 계산된다 | CSS 명세 |
| 「모든 모던 브라우저에서 지원된다」 | 원본의 주장 — 브라우저 구현 현황이지 명세의 보장이 아니다. 구체 버전은 (확인 필요) |
| `system-ui` 글꼴의 모양 | 운영체제 · 브라우저마다 다르다 |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 반응형 영상 임베드 | `aspect-ratio: 16 / 9` | 고정 `height` |
| 카드 썸네일을 같은 모양으로 | `aspect-ratio: 4 / 3` + 폭은 그리드에 맡김 | 칸마다 높이를 손으로 계산 |
| 원형 · 정사각 아바타 | `aspect-ratio: 1` | `width` · `height` 를 같은 값으로 두 번 쓰기(폭이 바뀌면 따로 고쳐야 함) |
| 높이 상한이 꼭 필요한 영역 | 폭 쪽 제약(`max-width`)으로 크기 조절 | `max-height` 로 비율 박스 높이 자르기 |
| 새로 쓰는 코드 | `aspect-ratio` | `padding-top` 퍼센트 핵 |

## 핵심 문장

1. **`aspect-ratio` 는 정해진 한쪽 길이로 비어 있는 다른 쪽을 계산한다** — 폭만 정하면 높이가, 높이만 정하면 폭이 나온다.
2. **폭이 반응형으로 바뀌어도 모양은 그대로다** — 그리드 칸 폭이 바뀌면 높이가 따라간다.
3. **높이나 폭을 묶는 제약(`max-height` 등)은 비율을 깨뜨릴 수 있다.**
4. **옛 `padding-top` 핵은 「퍼센트 패딩은 폭 기준」을 이용했다** — 16:9 는 9 ÷ 16 = 56.25%.

## 용어 풀이

> **종횡비(aspect ratio)** — 가로 길이와 세로 길이의 비.\
> 예: 16:9 는 가로가 16 일 때 세로가 9.

> **`aspect-ratio`** — 요소의 선호 종횡비를 정하는 CSS 속성.\
> 예: `aspect-ratio: 4 / 3;`.

> **padding-top 퍼센트 핵** — 퍼센트 패딩이 폭 기준인 점을 이용해 비율 박스를 만들던 옛 기법.\
> 예: `padding-top: 56.25%` 로 16:9 박스.

> **`auto-fit`** — `repeat()` 안에서 컨테이너 폭에 들어가는 만큼 칸 수를 자동으로 정하는 키워드.\
> 예: `repeat(auto-fit, minmax(120px, 1fr))`.

> **`minmax(최소, 최대)`** — 그리드 칸 크기의 아래 · 위 한계를 정하는 함수.\
> 예: `minmax(120px, 1fr)` 는 120px 이상, 남는 공간을 나눠 가질 만큼.

> **`fr`** — 그리드에서 남는 공간을 나누는 비율 단위.\
> 예: `1fr 1fr` 은 두 칸이 반반.

> **`overflow: hidden`** — 박스 밖으로 나간 자식 부분을 잘라 내는 설정.\
> 예: 둥근 모서리 밖 배경 감추기.

## 더 들어가면

- 내용물이 비율 박스보다 크면 박스가 비율을 넘어 늘어날 수 있다 — 자동 최소 크기와 관련된 규칙이다 (확인 필요).
- `aspect-ratio: auto 16 / 9` 처럼 `auto` 를 함께 쓰면 이미지 · 영상 같은 대체 요소는 자기 고유 비율을 먼저 쓰고, 고유 비율이 없을 때만 지정 비율을 쓴다 (확인 필요).
- `img` 에 `width` · `height` 속성(HTML)을 적어 두면 브라우저가 그 비로 자리를 미리 잡아 이미지 로딩 중 화면 밀림을 줄인다고 알려져 있다 (확인 필요).
- 비율로 계산된 높이가 소수 px 일 때 어떻게 반올림되는지는 엔진마다 다를 수 있다 (확인 필요).
