## 한눈에 — 쉽게 말하면

**반응형 그리드는 「긴 식탁에 의자 놓기」다.**
식탁 길이는 정해져 있고, 의자 한 자리는 최소 80cm 는 있어야 한다.
그래서 식탁에 들어가는 만큼 자리를 만들고, 남는 길이는 자리마다 고르게 나눠 준다.
손님이 자리보다 적게 오면 두 가지 방법이 있다.
빈 의자를 그대로 두는 방법(`auto-fill`)과 빈 의자를 치우고 손님들이 식탁을 넓게 나눠 쓰는 방법(`auto-fit`)이다.
CSS Grid 의 `repeat(auto-fill | auto-fit, minmax(최소, 1fr))` 도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 식탁 길이 | 그리드 컨테이너의 너비 |
| 의자 한 자리의 최소 폭 | `minmax()` 의 첫째 값(예: `80px`) |
| 남는 길이를 고르게 나눔 | `minmax()` 의 둘째 값 `1fr` |
| 의자 사이 틈 | `gap` |
| 손님 | 그리드 아이템 |
| 빈 의자를 그대로 둠 | `auto-fill` |
| 빈 의자를 치움 | `auto-fit` |

```text
식탁(컨테이너) 너비 ───────────────────────────────▶
auto-fill : [ 1 ][ 2 ][ 3 ][ 빈 ]     ← 빈 자리가 폭을 차지한다
auto-fit  : [  1  ][  2  ][  3  ]     ← 빈 자리가 0 이 되어 셋이 나눠 갖는다
```

## 이 주제가 답하려는 질문

1. 미디어 쿼리 없이 어떻게 열 개수가 화면 너비에 따라 바뀌나?
2. `auto-fill` 과 `auto-fit` 은 언제 다르게 보이고, 언제 똑같이 보이나?
3. `minmax(최소, 1fr)` 의 최소값이 컨테이너보다 크면 무슨 일이 생기고, 어떻게 막나?

## 동작 방식

### (1) 열 개수를 세는 법 — `repeat(auto-fill, minmax(80px, 1fr))`

**언제 쓰나** — 카드 목록처럼 「한 칸이 적어도 이만큼은 돼야 하고, 들어가는 만큼 한 줄에 놓고 싶을 때」 쓴다.

```text
입력: 컨테이너 너비 W, gap g, minmax(80px, 1fr)
  │
  ├─ ① 반복 횟수 n 을 센다: 각 열을 최소값 80px 로 치고
  │     n×80 + (n−1)×g ≤ W 를 만족하는 가장 큰 n
  │
  ├─ ② 열 n 개를 만든다
  │
  └─ ③ 남는 너비를 1fr 이 고르게 나눈다
        한 열 = (W − (n−1)×g) ÷ n
결과: W 가 바뀌면 n 이 바뀐다 → 열 개수가 저절로 바뀐다
```

- ① 횟수를 셀 때는 `1fr` 이 아니라 최소값 `80px` 로 센다.
  `1fr` 은 「남는 몫」이라 그 자체로는 길이가 정해지지 않은 값이어서 개수를 세는 잣대가 될 수 없기 때문이다.
- ① `gap` 도 계산에 들어간다.
  열 n 개 사이에는 틈이 n−1 개 생기므로, 틈이 클수록 들어가는 열이 줄어든다.
- ② 열 개수가 정해지면 그 개수만큼 열(트랙)을 만든다.
- ③ 각 열은 최대 `1fr` 이므로 남는 너비를 똑같이 나눠 80px 보다 넓어진다.
- 결과: 기준이 「컨테이너 너비」라서, 화면이 줄어 컨테이너가 좁아지면 열이 줄고 넓어지면 열이 는다.
  미디어 쿼리처럼 「몇 px 이상이면 몇 열」을 따로 적지 않아도 된다.

예를 들어 컨테이너 안쪽 너비가 400px, `gap: 8px` 이라고 하자(가정한 값이다).
4열이면 4×80 + 3×8 = 352 ≤ 400 이고, 5열이면 5×80 + 4×8 = 432 > 400 이다.
그래서 4열이 되고, 한 열은 (400 − 3×8) ÷ 4 = 94px 이다.

> **트랙** — 그리드에서 한 열(또는 한 행)이 차지하는 띠.\
> 예: `grid-template-columns: 100px 1fr` 은 열 트랙 두 개를 만든다.

> **`fr`** — 그리드에서 남는 공간을 나눠 갖는 몫의 단위.\
> 예: `1fr 2fr` 이면 남는 공간을 1:2 로 나눈다.

### (2) `auto-fill` 과 `auto-fit` — 빈 트랙을 어떻게 다루나

**언제 쓰나** — 아이템 수가 열 개수보다 적을 수 있을 때, 빈 자리를 남길지(`auto-fill`) 아이템을 늘릴지(`auto-fit`) 고른다.

```text
입력: 같은 조건(W=400, gap 8, minmax(80px,1fr)) + 아이템 3개 → 열 4개
  │
  ├─ auto-fill : 4번째 열은 비어 있지만 94px 를 그대로 차지한다
  │              [1:94][2:94][3:94][빈:94]
  │
  └─ auto-fit  : 아이템이 하나도 없는 열을 0 으로 접는다(옆 틈도 함께 접힌다)
                 남은 3열이 400 − 2×8 = 384 를 나눠 → 한 열 128px
                 [ 1:128 ][ 2:128 ][ 3:128 ]
```

- `auto-fill` 은 셌던 열을 모두 유지하므로, 빈 열이 오른쪽에 공간으로 남는다.
- `auto-fit` 은 빈 열을 0 너비로 접으므로, `1fr` 이 남은 공간을 아이템이 있는 열에만 나눈다.
  그래서 아이템이 넓어져 한 줄을 꽉 채운다.
- 「빈 열」이란 그 열에 아이템이 하나도 없는 열이다.
  아이템이 열 개수 이상이면 모든 열에 아이템이 들어가므로 빈 열이 없고, 두 방식은 똑같이 보인다.
  팁의 말대로 **차이는 아이템이 적을 때만 드러난다.**

```html demo
<div style="display:grid;gap:8px;grid-template-columns:repeat(auto-fill,minmax(80px,1fr));background:#f1f5f9;padding:8px">
  <div style="background:#3b82f6;color:#fff;padding:12px">1</div>
  <div style="background:#3b82f6;color:#fff;padding:12px">2</div>
</div>
<div style="display:grid;gap:8px;grid-template-columns:repeat(auto-fit,minmax(80px,1fr));background:#f1f5f9;padding:8px;margin-top:8px">
  <div style="background:#3b82f6;color:#fff;padding:12px">1</div>
  <div style="background:#3b82f6;color:#fff;padding:12px">2</div>
</div>
```

> **보이는 것** — 넓은 화면에서 위 줄은 두 칸이 왼쪽에 놓이고 오른쪽이 비며, 아래 줄은 두 칸이 한 줄을 반씩 채운다. (코드에서 읽은 것 — 렌더 실측 아님)

### (3) 최소값이 컨테이너보다 클 때 — `min(최소, 100%)`

**언제 쓰나** — 아주 좁은 화면(또는 좁은 상자)에서도 그리드가 가로로 넘치지 않게 할 때 쓴다.

```text
입력: 컨테이너 너비 60px, minmax(80px, 1fr)
  │
  ├─ 열은 적어도 1개는 생기고, 그 열은 최소 80px
  └─ 80px > 60px → 20px 만큼 컨테이너 밖으로 넘친다(오버플로우)

입력: 컨테이너 너비 60px, minmax(min(80px, 100%), 1fr)
  │
  ├─ min(80px, 100%) = min(80px, 60px) = 60px
  └─ 열 하나가 60px → 넘치지 않는다
결과: 넓을 때는 80px 기준 그대로, 좁을 때만 컨테이너 너비로 물러선다
```

- `minmax()` 의 최소값은 「이보다 작아지지 않는다」는 약속이라, 컨테이너가 그보다 좁으면 넘칠 수밖에 없다.
- `min(80px, 100%)` 는 둘 중 작은 값을 고른다.
  `100%` 는 컨테이너 너비이므로, 최소값이 컨테이너를 넘지 못하게 막는 안전장치가 된다.

> **오버플로우** — 내용이 상자 크기를 넘어 밖으로 삐져나오는 것.\
> 예: 60px 상자 안에 80px 열이 있으면 20px 가 넘친다.

## 문법 — 형태와 규칙

```css
/* 미디어 쿼리 없는 반응형 그리드 */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 16px;
}

/* 좁은 화면에서도 넘치지 않는 안전한 꼴 */
.grid-safe {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(150px, 100%), 1fr));
  gap: 16px;
}
```

| 조각 | 뜻 |
|---|---|
| `repeat(횟수, 트랙)` | 같은 트랙을 여러 번 되풀이한다 |
| `auto-fill` | 들어가는 만큼 되풀이하고, 빈 트랙도 남긴다 |
| `auto-fit` | 들어가는 만큼 되풀이하되, 빈 트랙은 0 으로 접는다 |
| `minmax(최소, 최대)` | 트랙 크기를 최소~최대 사이로 묶는다 |
| `1fr` | 최대값으로 쓰면 남는 공간을 고르게 나눠 갖는다 |
| `min(a, b)` | 둘 중 작은 값. `min(150px, 100%)` 로 최소값을 컨테이너 너비 안에 가둔다 |
| `gap` | 트랙 사이 간격. 열 개수 계산에도 들어간다 |

- 횟수 자리에 `auto-fill` 이나 `auto-fit` 을 쓰면 열 개수를 브라우저가 컨테이너 너비로 정한다.
- 반복 횟수는 각 열을 최소값으로 쳐서 센다.
- 아이템이 열 개수보다 많으면 다음 줄로 넘어가 같은 열에 맞춰 놓인다.

## 어디서 틀리나

### 1. 아이템이 많으면 `auto-fill` 과 `auto-fit` 의 차이가 안 보인다

모든 열에 아이템이 하나라도 있으면 빈 열이 없어서 둘이 같아 보인다.
차이를 보려면 아이템 수를 한 줄에 들어가는 열 개수보다 적게 둬야 한다(원본 데모가 아이템을 3개만 둔 까닭이다).

### 2. 최소값이 컨테이너보다 크면 넘친다

`minmax(150px, 1fr)` 은 컨테이너가 150px 보다 좁아도 열을 150px 아래로 줄이지 않는다.
`minmax(min(150px, 100%), 1fr)` 로 쓰는 것이 안전하다.

### 3. `gap` 을 빼고 셈하면 열 개수를 잘못 예측한다

400 ÷ 80 = 5 라고 5열을 기대하면 틀린다.
`gap: 8px` 이면 5열에 틈 4개(32px)가 더해져 432px 가 필요하므로 4열이 된다.

### 4. 기준은 화면이 아니라 컨테이너다

미디어 쿼리는 뷰포트(화면) 너비를 보지만, 이 방식은 그리드 컨테이너의 너비를 본다.
같은 화면이라도 사이드바 안처럼 좁은 상자에 넣으면 열이 적어진다.

> **뷰포트** — 브라우저에서 페이지가 보이는 창 영역.\
> 예: 휴대폰 화면 폭이 뷰포트 너비다.

> **미디어 쿼리** — 뷰포트 너비 같은 조건에 따라 다른 CSS 를 적용하는 규칙.\
> 예: `@media (min-width: 600px) { … }`.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `auto-fill` 은 빈 트랙을 남기고 `auto-fit` 은 0 으로 접는다 | CSS Grid 명세가 정한 동작(원본 팁과 일치) |
| 반복 횟수를 최소값과 `gap` 으로 센다 | CSS Grid 명세(원본에 근거 없음 — 추론) |
| `min()` 을 그리드 트랙 값 안에서 쓸 수 있는 브라우저 범위 | 원본에 없음 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 카드 수가 많고 열 수만 화면에 맞추면 될 때 | `repeat(auto-fill 또는 auto-fit, minmax(…, 1fr))` | 너비마다 미디어 쿼리 여러 개 |
| 아이템이 적을 때 한 줄을 꽉 채우고 싶다 | `auto-fit` | `auto-fill` |
| 아이템이 적어도 칸 크기를 일정하게 두고 싶다 | `auto-fill` | `auto-fit` |
| 아주 좁은 상자에도 들어갈 수 있다 | `minmax(min(최소, 100%), 1fr)` | `minmax(최소, 1fr)` 그대로 |
| 화면 크기에 따라 배치 자체(순서·영역)를 바꿔야 한다 | 미디어 쿼리 | 이 방식만으로 해결하려 하기 |

## 핵심 문장

1. **`repeat(auto-fill | auto-fit, minmax(최소, 1fr))` 은 컨테이너 너비로 열 개수를 정한다** — 그래서 미디어 쿼리가 필요 없다.
2. **열 개수는 최소값과 `gap` 으로 센다** — n×최소 + (n−1)×gap ≤ 너비 인 가장 큰 n.
3. **`auto-fill` 은 빈 열을 남기고 `auto-fit` 은 빈 열을 접는다** — 차이는 아이템이 적을 때만 보인다.
4. **최소값이 컨테이너보다 크면 넘친다** — `min(최소, 100%)` 로 막는다.

## 용어 풀이

- **트랙** — 그리드에서 한 열 또는 한 행이 차지하는 띠.
- **`fr`** — 남는 공간을 나눠 갖는 몫의 단위.
- **`repeat()`** — 같은 트랙 정의를 되풀이하는 함수.
- **`auto-fill`** — 들어가는 만큼 트랙을 만들고 빈 트랙도 남기는 반복 횟수.
- **`auto-fit`** — 들어가는 만큼 트랙을 만들되 빈 트랙을 0 으로 접는 반복 횟수.
- **`minmax()`** — 트랙 크기의 최소와 최대를 정하는 함수.
- **`min()`** — 주어진 값 중 가장 작은 값을 고르는 CSS 함수.
- **`gap`** — 트랙 사이 간격.
- **오버플로우** — 내용이 상자 밖으로 넘치는 것.
- **뷰포트** — 브라우저에서 페이지가 보이는 창 영역.
- **미디어 쿼리** — 뷰포트 조건에 따라 CSS 를 바꾸는 규칙.

## 더 들어가면

- `repeat(auto-fill, 1fr)` 처럼 최소와 최대가 모두 유연한 값이면 반복 횟수를 셀 수 없어 선언이 무효가 된다고 알려져 있다. (확인 필요)
- 한 `grid-template-columns` 안에 `auto-fill`/`auto-fit` 반복은 하나만 쓸 수 있다고 알려져 있다. (확인 필요)
- 컨테이너 너비 대신 「컨테이너 쿼리」(`@container`)로 상자 크기에 따라 스타일을 바꾸는 방법도 있다. (확인 필요)
