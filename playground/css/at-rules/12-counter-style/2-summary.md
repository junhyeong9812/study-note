## 한눈에 — 쉽게 말하면

**`@counter-style` 은 「이름표를 붙인 도장 세트」를 만드는 일이다.**
선생님이 공책 검사를 할 때 도장 네 개(빨강 · 노랑 · 초록 · 파랑)를 정해 두고 차례로 찍는다고 하자.
도장 세트를 만들어 서랍에 넣어 두기만 하면 공책에는 아무것도 찍히지 않는다.
「이 반 공책에는 그 세트를 쓴다」고 정해야 비로소 찍힌다.
목록 번호도 똑같은 구조다.
`@counter-style` 로 번호 모양 세트를 만들고 이름을 붙인 뒤, `list-style-type` 으로 그 이름을 불러야 목록에 나타난다.

| 비유 | 실체 |
|---|---|
| 도장 세트에 붙인 이름표 | `@counter-style emoji-counter` 의 이름 `emoji-counter` |
| 세트에 든 도장들 | `symbols` 에 나열한 기호 |
| 찍는 규칙(돌려 쓰기 · 한 번씩만) | `system` (`cyclic` · `fixed` …) |
| 도장 앞뒤에 덧붙이는 글자 | `prefix` · `suffix` |
| 「이 반은 이 세트를 쓴다」 | `list-style-type: emoji-counter;` |
| 세트가 바닥났을 때 꺼내는 기본 도장 | 폴백(fallback) 스타일 |

```text
 @counter-style emoji-counter { ... }      ← 세트를 만든다 (아직 아무 데도 안 찍힘)
                │
                ▼  이름으로 부른다
 ol { list-style-type: emoji-counter; }
                │
                ▼
 🔴 첫 번째
 🟡 두 번째
 🟢 세 번째
 🔵 네 번째
```

## 이 주제가 답하려는 질문

1. 목록 번호(마커)를 `1. 2. 3.` 이나 `•` 말고 내가 고른 기호로 바꾸려면 무엇을 어디에 써야 하나?
2. 기호의 수보다 목록 항목이 많아지면 마커는 어떻게 되나?
3. 마커 앞뒤에 괄호나 공백 같은 글자를 붙이려면 어떻게 하나?

## 동작 방식

### (1) 정의하고 이름으로 부른다

**언제 쓰나** — 브라우저가 기본으로 주는 번호 모양(숫자 · 점 등)이 마음에 들지 않아 마커를 직접 설계하고 싶을 때다.

```text
입력:
  @counter-style emoji-counter { system: cyclic; symbols: '🔴' '🟡' '🟢' '🔵'; suffix: ' '; }
  .custom-counter { list-style-type: emoji-counter; }

무엇이 일어나나:
  ① 브라우저가 emoji-counter 라는 이름의 카운터 스타일을 등록한다
  ② .custom-counter 목록이 마커를 그릴 때 list-style-type 에 적힌 이름을 찾는다
  ③ 등록된 emoji-counter 의 규칙으로 항목마다 마커 문자열을 만든다

결과:
  각 <li> 앞에 이모지 + 공백이 마커로 붙는다
```

① `@counter-style` 블록은 규칙(만드는 법)만 적어 두는 곳이다.
② 실제로 어느 목록에 쓸지는 `list-style-type` 이 정한다.
③ 두 줄이 이름 하나로 이어져야 화면이 바뀐다 — 정의만 있고 부르는 쪽이 없으면 목록은 그대로다.

> **카운터 스타일** — 번호(1, 2, 3 …)를 화면에 보일 문자열로 바꾸는 규칙 묶음.\
> 예: `decimal` 은 1을 「1」로, 직접 만든 `emoji-counter` 는 1을 「🔴」로 바꾼다.

> **마커** — 목록 항목 앞에 붙는 번호나 기호.\
> 예: `<ol>` 의 「1.」, `<ul>` 의 「•」.

> **디스크립터** — `@counter-style` 블록 안에 쓰는 `system` · `symbols` 같은 설정 항목.\
> 예: `suffix: ' ';` 은 디스크립터 `suffix` 에 값 `' '` 을 준 것이다.

### (2) `system: cyclic` — 기호를 돌려 쓴다

**언제 쓰나** — 항목이 몇 개든 정해 둔 기호들을 끝없이 반복해 붙이고 싶을 때다.

```text
입력:  system: cyclic;  symbols: '🔴' '🟡' '🟢' '🔵';   항목 6개

무엇이 일어나나:
  1번 → 🔴   2번 → 🟡   3번 → 🟢   4번 → 🔵
  5번 → (처음으로 돌아가) 🔴   6번 → 🟡

결과:  🔴 🟡 🟢 🔵 🔴 🟡
```

기호가 넷이면 다섯째 항목에서 다시 첫 기호로 돌아간다.
기호 목록 끝에 다다를 때마다 처음부터 다시 돈다.
그래서 항목이 아무리 많아도 마커가 비는 일은 없다.
대신 같은 마커가 되풀이되므로 마커만 보고는 몇 번째 항목인지 알 수 없다.

### (3) `system: fixed` — 한 번씩만 쓰고 폴백으로 넘긴다

**언제 쓰나** — 기호마다 정해진 번호가 하나씩만 있고, 그 뒤로는 기호를 되풀이하고 싶지 않을 때다.

```text
입력:  system: fixed;  symbols: '🔴' '🟡' '🟢' '🔵';   항목 6개

무엇이 일어나나:
  1번 → 🔴   2번 → 🟡   3번 → 🟢   4번 → 🔵
  5번 → 기호가 바닥남 → 폴백 스타일이 마커를 만든다
  6번 → 폴백 스타일이 마커를 만든다

결과:  🔴 🟡 🟢 🔵 (폴백 마커) (폴백 마커)
```

`fixed` 는 기호를 한 번씩만 쓴다.
기호를 다 쓰고 나면 이 카운터 스타일은 더 이상 마커를 만들지 않고 폴백 스타일에 일을 넘긴다.
그래서 다섯째 항목부터는 이모지가 아닌 다른 모양의 마커가 보인다.

> **폴백** — 지금 스타일이 맡을 수 없는 번호를 대신 그려 주는 예비 카운터 스타일.\
> 예: `fixed` 로 기호 넷을 정했을 때 다섯째 번호는 폴백이 그린다.

### (4) `prefix` · `suffix` — 마커 문자열의 앞뒤를 채운다

**언제 쓰나** — 기호를 괄호로 감싸거나, 기호와 항목 글자 사이에 간격을 두고 싶을 때다.

```text
입력:  symbols: '🔴' …;  prefix: '[';  suffix: '] ';

무엇이 일어나나:
  마커 문자열 = prefix + 기호 + suffix
             = '['    + '🔴' + '] '

결과:  [🔴] 첫 번째
```

마커는 `prefix` 문자열, 기호, `suffix` 문자열을 차례로 이어 붙여 만든다.
원본 예제는 `suffix: ' '` 로 기호 뒤에 공백 한 칸을 붙여 기호와 항목 글자가 붙지 않게 한다.
`prefix` 를 쓰지 않았으므로 기호 앞에는 아무것도 없다.

> **심볼** — 카운터 스타일이 마커를 만들 때 쓰는 재료 문자열.\
> 예: `symbols: '🔴' '🟡';` 에서 `'🔴'` 과 `'🟡'` 이 심볼이다.

### (5) `range` — 이 스타일이 맡을 번호의 범위

**언제 쓰나** — 특정 번호 구간에서만 이 카운터 스타일을 쓰고 싶을 때다.

`range` 는 이 카운터 스타일이 적용될 번호의 범위를 정한다.
범위 밖의 번호는 이 스타일이 맡지 않는다.

### (6) 마커 자리 확보

원본 예제는 목록에 `padding-left: 40px` 를 준다.
코드 주석이 밝히듯 마커가 들어갈 왼쪽 공간을 확보하려는 것이다.
이모지 마커는 숫자 한 글자보다 넓을 수 있으므로 왼쪽 여백을 넉넉히 두었다.

```html demo
<style>
  @counter-style emoji-counter {
    system: cyclic;
    symbols: '🔴' '🟡' '🟢' '🔵';
    suffix: ' ';
  }
  .demo { list-style-type: emoji-counter; padding-left: 40px; }
</style>
<ol class="demo">
  <li>하나</li><li>둘</li><li>셋</li><li>넷</li><li>다섯</li>
</ol>
```

> **보이는 것** — 항목 앞에 🔴 🟡 🟢 🔵 가 차례로 붙고, 다섯째 항목에는 다시 🔴 가 붙는다 (코드에서 읽은 것 — 렌더 실측 아님)

## 문법 — 형태와 규칙

```css
/* 정의: 이름을 짓고 규칙을 적는다 */
@counter-style my-marks {
  system: cyclic;          /* 알고리즘 */
  symbols: '★' '☆';        /* 쓸 기호, 공백으로 나열 */
  prefix: '(';             /* 기호 앞 */
  suffix: ') ';            /* 기호 뒤 */
}

/* 사용: 이름으로 부른다 */
ol.stars { list-style-type: my-marks; }
```

- 꼴은 `@counter-style <name> { system: <type>; symbols: <symbols>; }` 이다.
- `<name>` 은 내가 짓는 이름이고, `list-style-type` 에 같은 이름을 써야 연결된다.
- `symbols` 의 기호들은 따옴표로 감싼 문자열을 공백으로 나열한다.
- 블록 안의 디스크립터는 일반 선언처럼 `이름: 값;` 꼴이다.

| 디스크립터 | 하는 일 | 원본 예제의 값 |
|---|---|---|
| `system` | 카운터 알고리즘. `cyclic` · `numeric` · `alphabetic` · `fixed` 등 | `cyclic` |
| `symbols` | 카운터에 쓸 기호 | `'🔴' '🟡' '🟢' '🔵'` |
| `suffix` | 카운터 뒤에 붙일 문자열 | `' '` (공백 한 칸) |
| `prefix` | 카운터 앞에 붙일 문자열 | (쓰지 않음) |
| `range` | 카운터를 적용할 범위 | (쓰지 않음) |

| `system` 값 | 기호를 쓰는 방식 |
|---|---|
| `cyclic` | 기호를 순환 반복한다. 끝에 닿으면 처음으로 돌아간다 |
| `fixed` | 기호를 한 번씩만 쓴다. 기호가 바닥나면 폴백으로 넘어간다 |
| `numeric` · `alphabetic` | 원본에 이름만 나온다. 동작은 「더 들어가면」 참고 |

## 어디서 틀리나

### 1. 정의만 하고 부르지 않는다

`@counter-style` 블록을 써 놓고 `list-style-type` 에 그 이름을 적지 않으면 목록은 기본 모양 그대로다.
정의는 「만드는 법」일 뿐이고, 목록에 붙이는 일은 `list-style-type` 이 한다.
이름의 철자가 정의와 사용에서 다르면 연결이 끊긴다.

### 2. `cyclic` 과 `fixed` 를 헷갈린다

`cyclic` 은 심볼을 순환 반복한다.
`fixed` 는 심볼을 한 번만 사용하고 그 뒤로는 폴백으로 전환된다.
항목이 심볼보다 많아질 수 있는 목록에 `fixed` 를 쓰면 뒷부분 마커가 갑자기 다른 모양으로 바뀐다.

### 3. `cyclic` 마커로는 순서를 읽을 수 없다

`cyclic` 은 같은 마커를 되풀이한다.
기호가 넷이면 1번과 5번이 똑같이 보인다.
「몇 번째인가」가 중요한 목록(절차 · 순위)에는 맞지 않다.

### 4. `suffix` 를 잊어 기호와 글자가 붙는다

마커 문자열은 `prefix` + 기호 + `suffix` 다.
원본은 `suffix: ' '` 로 공백을 넣어 이모지와 항목 글자를 떨어뜨린다.
`suffix` 를 직접 정하면 그 문자열이 그대로 붙으므로 간격도 내가 넣어야 한다.

### 5. 마커 자리가 모자란다

원본은 `padding-left: 40px` 로 마커 공간을 확보한다.
이모지처럼 넓은 마커를 쓰면서 왼쪽 여백을 좁히면 마커가 들어갈 자리가 모자랄 수 있다 (확인 필요).

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `cyclic` 은 기호를 순환 반복한다 | CSS 규칙(카운터 스타일 명세)이 정한 동작 |
| `fixed` 는 기호를 한 번씩만 쓰고 뒤는 폴백이 맡는다 | CSS 규칙이 정한 동작 |
| 마커 = `prefix` + 기호 + `suffix` | CSS 규칙이 정한 동작 |
| 🔴 🟡 같은 이모지가 둥근 컬러 원으로 보인다 | 운영체제 · 글꼴이 정한다 — CSS 가 모양을 보장하지 않는다 |
| 어느 브라우저가 `@counter-style` 을 지원하나 | 브라우저 구현 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 항목 수에 상관없이 장식용 기호를 돌려 쓰기 | `system: cyclic` | `system: fixed` (뒷부분이 폴백으로 바뀜) |
| 정해진 몇 개 항목에만 특별한 기호 붙이기 | `system: fixed` | `cyclic` (넘치면 같은 기호가 반복됨) |
| 순서가 중요한 절차 목록 | 숫자 계열 마커 | `cyclic` 장식 마커 (순서를 못 읽음) |
| 기호를 괄호로 감싸거나 간격 두기 | `prefix` · `suffix` | 항목 글자 안에 기호를 직접 타이핑 |

## 핵심 문장

1. **`@counter-style` 은 마커 규칙에 이름을 붙여 정의하고, `list-style-type` 이 그 이름을 불러 목록에 적용한다.**
2. **`system` 이 기호를 쓰는 방식을 정한다** — `cyclic` 은 돌려 쓰고, `fixed` 는 한 번씩 쓰고 폴백으로 넘긴다.
3. **마커 문자열은 `prefix` + 기호 + `suffix` 로 이어 붙여 만든다.**
4. **`range` 는 이 스타일이 맡을 번호의 범위를 정한다.**
5. **이모지 마커의 생김새는 CSS 가 아니라 글꼴과 운영체제가 정한다.**

## 관련 자료

- `list-style-type` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `::marker` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- 원본: study-site 항목 데이터 `data/css/at-rules.json` 의 `counter-style`

## 용어 풀이

- **At-규칙** — `@` 로 시작하는 CSS 규칙. 선택자 규칙과 달리 CSS 에 지시나 정의를 준다.
- **카운터 스타일** — 번호를 화면에 보일 문자열로 바꾸는 규칙 묶음.
- **마커** — 목록 항목 앞에 붙는 번호나 기호.
- **디스크립터** — `@counter-style` 블록 안의 `system` · `symbols` 같은 설정 항목.
- **심볼** — 마커를 만들 때 쓰는 재료 문자열.
- **`system`** — 심볼을 어떤 알고리즘으로 쓸지 정하는 디스크립터.
- **`cyclic`** — 심볼을 순환 반복하는 `system` 값.
- **`fixed`** — 심볼을 한 번씩만 쓰는 `system` 값.
- **폴백** — 지금 스타일이 맡지 못하는 번호를 대신 그리는 예비 카운터 스타일.
- **`prefix` · `suffix`** — 마커의 앞 · 뒤에 붙는 문자열.
- **`range`** — 이 카운터 스타일이 적용될 번호 범위.
- **`list-style-type`** — 목록의 마커에 어떤 카운터 스타일을 쓸지 정하는 속성.

## 더 들어가면

- `fallback` 디스크립터로 폴백 스타일을 직접 고를 수 있고, 지정하지 않으면 `decimal` 이 폴백이 된다고 알려져 있다 (확인 필요).
- `range` 밖의 번호도 폴백 스타일이 그린다 (확인 필요).
- `suffix` 를 지정하지 않았을 때의 기본값은 마침표와 공백(`". "`)이다 (확인 필요).
- `numeric` 은 심볼을 자릿수 숫자처럼 쓴다 — 심볼이 `'0' '1'` 이면 이진수 꼴이 된다 (확인 필요).
- `alphabetic` 은 `a, b, …, z, aa, ab …` 처럼 심볼을 글자처럼 이어 붙인다 (확인 필요).
- 그 밖에 `symbolic` · `additive` · `extends` 같은 `system` 값과 `pad` · `negative` · `speak-as` 디스크립터가 있다 (확인 필요).
- `none` 이나 CSS 전역 키워드는 이름으로 쓸 수 없고, `decimal` · `disc` 같은 일부 내장 이름은 덮어쓸 수 없다고 알려져 있다 (확인 필요).
- 만든 카운터 스타일은 `counter()` 함수의 둘째 인자로도 쓸 수 있다 (확인 필요).
