## 한눈에 — 쉽게 말하면

**`@page` 는 「프린터에 넣을 종이를 고르고, 종이 가장자리에 빈칸을 얼마나 둘지 정하는 설정」이다.**
글을 쓰기 전에 종이 크기를 고르고 위아래 여백을 정하듯, `@page` 는 글자나 상자가 아니라 종이 한 장 한 장을 꾸민다.
표지에만 위쪽 여백을 넉넉히 두는 것처럼, 특정 쪽만 따로 설정할 수도 있다.
CSS 의 인쇄도 똑같은 구조다.
문서 내용(요소)은 종이 위에 흘러 들어가고, `@page` 는 그 종이의 크기와 여백을 정한다.

> **At-규칙** — `@` 로 시작해 CSS 에 특별한 지시를 내리는 규칙이다.\
> 예: `@media`, `@page`, `@keyframes`.

| 비유 | 실체 |
|---|---|
| 종이 한 장 | 인쇄될 한 페이지(페이지 박스) |
| 종이 크기 고르기 | `size: A4;` |
| 종이 가장자리 빈칸 | `margin: 2cm;` |
| 표지에만 따로 주는 설정 | `@page :first { … }` |
| 종이 위에 쓰는 글 | HTML 요소들 |

> **페이지 박스** — 인쇄할 때 내용이 나뉘어 담기는 종이 한 장 크기의 상자다.\
> 예: A4 로 인쇄하면 페이지 박스 하나가 A4 한 장이다.

```text
┌──────────── 종이(페이지 박스, size) ────────────┐
│          ↕ margin (여백)                        │
│    ┌──────────── 내용 영역 ────────────┐        │
│ ↔  │  HTML 요소들이 여기로 흘러 들어감 │  ↔     │
│    └────────────────────────────────────┘        │
│          ↕ margin                               │
└──────────────────────────────────────────────────┘
```

## 이 주제가 답하려는 질문

1. 인쇄할 때 종이 크기와 여백은 CSS 어디에서 정하나?
2. 첫 페이지나 왼쪽 · 오른쪽 페이지만 다르게 하려면 어떻게 하나?
3. `@page` 는 화면에도 영향을 주나?
4. 인쇄할 때 요소의 모양을 바꾸거나 페이지를 나누는 일은 누가 맡나?

## 동작 방식

### (1) `@page` 는 인쇄할 때만 읽힌다

**언제 쓰나** — 사용자가 페이지를 인쇄하거나 인쇄 미리보기(예: `Ctrl+P`)를 열 때를 대비한다.
화면에서 보는 모양을 바꾸려고 쓰는 규칙이 아니다.

```text
@page { size: A4; margin: 2cm; }
        │
        ├─ 화면에 표시할 때 ──→ 페이지라는 개념이 없음 ──→ 아무 변화 없음
        │
        └─ 인쇄 · 인쇄 미리보기 ─→ 내용을 A4 종이들로 나눔 ─→ 각 종이에 사방 2cm 여백
```

- 브라우저 화면은 하나로 이어진 긴 면이라 「페이지」가 없다.
- 그래서 화면에서는 `@page` 규칙이 적용될 곳이 없다.
- 인쇄할 때는 내용이 종이 크기만큼 잘려 여러 페이지로 나뉜다.
- 이때 각 페이지에 `@page` 의 크기와 여백이 적용된다.

### (2) 모든 페이지의 기본 규칙 — `size` 와 `margin`

**언제 쓰나** — 문서 전체를 정해진 용지와 여백으로 인쇄하고 싶을 때 쓴다.

```text
@page {
  size: A4;      ──→ 페이지 박스 크기 = A4
  margin: 2cm;   ──→ 위 · 오른쪽 · 아래 · 왼쪽 여백 = 2cm
}
        │
        ▼
 1쪽 [2cm 여백 + 내용]   2쪽 [2cm 여백 + 내용]   3쪽 [2cm 여백 + 내용] …
```

- 이름이나 의사 클래스가 없는 `@page` 는 모든 페이지에 적용된다.
- `size` 는 종이 크기를 정한다. `A4`, `letter` 같은 이름이나 직접 쓴 크기를 받는다.
- `margin` 은 종이 가장자리와 내용 사이의 여백이다.
- 인쇄는 실제 종이 길이를 다루므로 `cm` 같은 물리 단위가 잘 어울린다.

> **물리 단위** — 실제 길이에 맞춘 CSS 길이 단위다.\
> 예: `cm`, `mm`, `in`.

### (3) 의사 클래스로 특정 페이지만 덮어쓰기

**언제 쓰나** — 표지가 되는 첫 페이지, 양면 인쇄의 왼쪽 · 오른쪽 페이지, 빈 페이지만 다르게 꾸미고 싶을 때 쓴다.

> **페이지 의사 클래스** — `@page` 뒤에 붙여 특정 종류의 페이지만 고르는 표시다.\
> 예: `@page :first` 는 첫 페이지만 고른다.

```text
@page        { margin: 2cm; }
@page :first { margin-top: 4cm; }
        │
        ▼
 1쪽: 위 4cm · 오른쪽 2cm · 아래 2cm · 왼쪽 2cm   ← :first 가 margin-top 만 덮어씀
 2쪽: 위 2cm · 오른쪽 2cm · 아래 2cm · 왼쪽 2cm   ← 기본 규칙 그대로
 3쪽: (2쪽과 같음)
```

- 기본 `@page` 가 모든 페이지에 사방 2cm 여백을 준다.
- `@page :first` 는 첫 페이지에만 붙는다.
- 이 규칙은 `margin-top` 하나만 선언하므로 첫 페이지의 위쪽 여백만 4cm 로 바뀐다.
- 첫 페이지의 나머지 세 방향은 기본 규칙의 2cm 를 그대로 받는다.
- 둘째 페이지부터는 `:first` 에 해당하지 않으므로 기본 규칙만 적용된다.

| 의사 클래스 | 고르는 페이지 |
|---|---|
| `:first` | 첫 번째 페이지 |
| `:left` | 왼쪽(짝수) 페이지 |
| `:right` | 오른쪽(홀수) 페이지 |
| `:blank` | 빈 페이지(내용이 없는 페이지) |

- `:left` · `:right` 는 책처럼 양면으로 펼쳐 볼 문서에서 안쪽 · 바깥쪽 여백을 다르게 줄 때 쓴다.

### (4) 일을 나눠 맡는 셋 — `@page` · `@media print` · `break-*`

**언제 쓰나** — 인쇄용 레이아웃을 제대로 만들 때는 셋을 함께 쓴다.

```text
인쇄 시작
  │
  ├─ @page              → 종이: 크기 · 여백
  ├─ @media print { … } → 종이 위 요소: 숨기기 · 테두리 없애기 같은 인쇄용 모양
  └─ break-before /     → 요소 앞 · 뒤에서 페이지를 나누도록 지시
     break-after
  │
  ▼
인쇄 결과
```

- `@page` 는 페이지 박스를 다루고, 문서 안의 요소를 꾸미지 않는다.
- 요소를 인쇄할 때만 다르게 보이게 하려면 `@media print` 안에 보통 선택자 규칙을 쓴다.
- 예제에서는 화면에서 보이던 점선 테두리를 `@media print` 안에서 `border: none;` 으로 없앤다.
- 페이지를 어디서 나눌지는 `@page` 가 아니라 요소에 주는 `break-before` · `break-after` 가 정한다.

> **`@media print`** — 출력 매체가 인쇄일 때만 안의 규칙을 적용하는 미디어 쿼리다.\
> 예: `@media print { nav { display: none; } }` 는 인쇄할 때 내비게이션을 숨긴다.

## 문법 — 형태와 규칙

```css
@page [<name>] [:<pseudo>] { <declarations> }
```

```html demo
<div class="note">인쇄 미리보기 (Ctrl+P로 확인)</div>
<style>
  @page { size: A4; margin: 2cm; }
  @page :first { margin-top: 4cm; }
  .note { padding: 20px; border: 2px dashed #d1d5db; text-align: center; }
  @media print { .note { border: none; } }
</style>
```

> **보이는 것** — 화면에서는 가운데 정렬된 문구가 점선 상자 안에 보이고, `@page` 는 화면 모양을 바꾸지 않는다 (코드에서 읽은 것 — 렌더 실측 아님).

- `@page` 뒤의 이름(`<name>`)과 의사 클래스(`:<pseudo>`)는 둘 다 생략할 수 있다.
- 둘 다 없으면 모든 페이지에 적용된다.
- 중괄호 안에는 `size`, `margin` 같은 페이지 박스용 선언을 쓴다.
- 의사 클래스가 붙은 규칙은 기본 규칙 위에 덧씌워진다 — 선언하지 않은 속성은 기본 규칙 값을 그대로 쓴다.

| 값 · 키워드 | 뜻 | 예 |
|---|---|---|
| `size` | 페이지 크기 (A4, letter 또는 커스텀 크기) | `size: A4;` |
| `margin` | 페이지 여백 | `margin: 2cm;` |
| `:first` | 첫 번째 페이지 | `@page :first { margin-top: 4cm; }` |
| `:left` | 왼쪽(짝수) 페이지 | `@page :left { … }` |
| `:right` | 오른쪽(홀수) 페이지 | `@page :right { … }` |
| `:blank` | 빈 페이지 | `@page :blank { … }` |

## 어디서 틀리나

### 1. 화면에서 효과를 찾는다
`@page` 는 인쇄 전용이다.
화면을 아무리 들여다봐도 `size` 나 `margin` 의 변화는 보이지 않는다.
결과는 인쇄 미리보기(`Ctrl+P`)나 실제 인쇄에서 확인한다.

### 2. `@page` 안에 요소 스타일을 넣는다
`@page` 는 종이(페이지 박스)를 설정하는 규칙이다.
「인쇄할 때 테두리 없애기」 같은 요소의 모양은 `@media print` 안의 선택자 규칙으로 바꾼다.
그래서 팁대로 `@page` 와 `@media print` 를 함께 써야 인쇄 친화적인 레이아웃이 된다.

### 3. `:first` 가 여백 전체를 바꾼다고 생각한다
`@page :first { margin-top: 4cm; }` 는 위쪽 여백만 바꾼다.
나머지 세 방향은 기본 `@page` 의 값을 그대로 받는다.

### 4. 페이지 나누기를 `@page` 로 하려 한다
「이 제목은 새 페이지에서 시작」 같은 지시는 `@page` 가 아니다.
요소에 `break-before` · `break-after` 를 주어 페이지 나누기를 제어한다.

### 5. `:left` · `:right` 의 짝수 · 홀수를 거꾸로 기억한다
원본 기준으로 `:left` 는 왼쪽(짝수) 페이지, `:right` 는 오른쪽(홀수) 페이지다.
책을 펼치면 1쪽이 오른쪽에 오는 것을 떠올리면 기억하기 쉽다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| `@page` 는 인쇄할 때만 적용되고 화면 모양은 바꾸지 않는다 | CSS 명세(페이지 매체용 규칙) |
| `:first` 에 선언하지 않은 속성은 기본 `@page` 값을 쓴다 | CSS 캐스케이드 규칙 |
| `Ctrl+P` 로 인쇄 미리보기를 연다 | 브라우저 · 운영체제의 단축키 (macOS 는 다를 수 있다 — 확인 필요) |
| `size` · `:left` · `:right` · `:blank` 가 실제 인쇄에 반영되는 정도 | 브라우저 구현에 따라 다르다 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 인쇄 용지 크기 · 여백 지정 | `@page { size; margin; }` | 화면용 `body { margin }` |
| 표지만 위쪽 여백을 크게 | `@page :first` | 첫 요소에 큰 `margin-top` 을 주는 꼼수 |
| 양면 인쇄의 안쪽 · 바깥쪽 여백 | `@page :left` · `@page :right` | 모든 페이지에 같은 여백 |
| 인쇄할 때 버튼 · 테두리 숨기기 | `@media print { … }` | `@page` 안의 선언 |
| 특정 요소 앞에서 새 페이지 시작 | `break-before` · `break-after` | `@page` |

## 핵심 문장

1. **`@page` 는 종이(페이지 박스)를 설정한다** — 크기는 `size`, 여백은 `margin`.
2. **`@page` 는 인쇄 전용이다** — 화면 모양은 바뀌지 않는다.
3. **의사 클래스 `:first` · `:left` · `:right` · `:blank` 로 특정 페이지만 덮어쓴다** — 선언한 속성만 바뀐다.
4. **요소의 인쇄 모양은 `@media print`, 페이지 나누기는 `break-before` · `break-after` 가 맡는다.**

## 관련 자료

- `@media print` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- 원본: study-site 항목 데이터 `data/css/at-rules.json` 의 `page`

## 용어 풀이

- **At-규칙** — `@` 로 시작하는 CSS 의 특별한 규칙.
- **페이지 박스** — 인쇄 때 내용이 담기는 종이 한 장 크기의 상자.
- **`size`** — 페이지 박스의 크기를 정하는 선언.
- **`margin`(페이지 여백)** — 종이 가장자리와 내용 영역 사이의 빈칸.
- **페이지 의사 클래스** — `:first` · `:left` · `:right` · `:blank` 처럼 특정 페이지를 고르는 표시.
- **물리 단위** — `cm` · `mm` · `in` 처럼 실제 길이에 맞춘 단위.
- **`@media print`** — 인쇄 매체에서만 안의 규칙을 적용하는 미디어 쿼리.
- **`break-before` · `break-after`** — 요소 앞 · 뒤의 페이지 나누기를 제어하는 속성.
- **인쇄 미리보기** — 인쇄 전에 페이지로 나뉜 모양을 보여 주는 브라우저 화면.

## 더 들어가면

- 이름 붙은 페이지(`@page wide { … }`)는 요소에 `page: wide;` 를 주어 그 요소가 해당 페이지에 놓이게 하는 방식으로 쓴다 (확인 필요).
- `size` 는 `A4 landscape` 처럼 방향 키워드를 함께 받을 수 있다 (확인 필요).
- `@page` 안에 `@top-center` 같은 여백 상자 규칙을 넣어 머리말 · 꼬리말을 만드는 문법이 명세에 있다 — 브라우저 지원은 제각각이다 (확인 필요).
- 인쇄 대화상자의 여백 · 용지 설정이 `@page` 값보다 우선하는 경우가 있다 (확인 필요).
- 예전 속성 `page-break-before` · `page-break-after` 는 `break-before` · `break-after` 로 대체되는 흐름이다 (확인 필요).
