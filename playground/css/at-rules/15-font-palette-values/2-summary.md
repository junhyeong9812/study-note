## 한눈에 — 쉽게 말하면

**`@font-palette-values` 는 「색칠 공부 책에 딸린 물감 세트를 바꿔 끼우는 일」이다.**
색칠 공부 책(컬러 폰트)에는 그림마다 「1번 물감은 여기, 2번 물감은 저기」가 정해져 있다.
책에는 기본 물감 세트가 하나 이상 딸려 온다.
우리는 그중 한 세트를 고른 뒤, 몇 번 물감만 다른 색으로 바꿔 끼울 수 있다.
그림의 모양은 그대로이고 칠해지는 색만 바뀐다.
컬러 폰트의 색 팔레트도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 색칠 공부 책 | 컬러 폰트 (`font-family` 로 가리킨다) |
| 책에 딸린 물감 세트 | 폰트에 내장된 팔레트 |
| 세트 고르기 | `base-palette: <번호>` |
| 몇 번 물감만 바꿔 끼우기 | `override-colors: <색 번호> <색>` |
| 바꾼 세트에 붙인 이름표 | `--custom-palette` 같은 `--` 이름 |
| 그 세트로 칠하라고 지시하기 | 요소에 `font-palette: --custom-palette;` |

```text
 컬러 폰트 'Noto Color Emoji'
 ┌───────────────────────────────┐
 │ 내장 팔레트 0: [0]빨강 [1]초록 …│ ← base-palette: 0 으로 고름
 │ 내장 팔레트 1: [0]…   [1]…    │
 └───────────────────────────────┘
            │ override-colors: 0 #ff6b6b, 1 #4ecdc4
            ▼
 --custom-palette: [0]#ff6b6b [1]#4ecdc4 [2]그대로 …
            │ font-palette: --custom-palette;
            ▼
 .fpv-demo 안의 컬러 글리프가 바뀐 색으로 그려진다
```

## 이 주제가 답하려는 질문

1. 폰트 안에 이미 들어 있는 색을 CSS 에서 어떻게 바꾸나?
2. 「어느 폰트의」 「어느 팔레트의」 「몇 번 색」을 어떻게 짚어 내나?
3. 정의한 팔레트를 실제 글자에 어떻게 입히나?
4. 어떤 글꼴에서는 아무 일도 일어나지 않는 까닭은 무엇인가?

## 동작 방식

### (1) 팔레트를 정의한다 — 이름을 붙인 at-규칙

**언제 쓰나** — 컬러 폰트가 품고 있는 색을 내 디자인에 맞춰 바꾸고 싶을 때 먼저 「바뀐 팔레트」를 하나 만든다.

```text
@font-palette-values --custom-palette {     ← 이름: -- 로 시작
  font-family: 'Noto Color Emoji';          ← 대상 폰트
  base-palette: 0;                          ← 출발점이 될 내장 팔레트
  override-colors: 0 #ff6b6b, 1 #4ecdc4;    ← 바꿀 색 번호와 새 색
}
        │
        ▼
「--custom-palette」라는 이름의 팔레트 정의가 생긴다 (아직 아무 글자에도 안 입혀짐)
```

- `@font-palette-values` 는 스타일을 바로 입히는 규칙이 아니라 정의를 만드는 at-규칙이다.
- 이름은 문법상 `--<name>` 꼴로, 두 줄표로 시작한다.
- 블록 안의 세 서술자가 「어느 폰트 · 어느 팔레트 · 어느 색」을 정한다.

> **at-규칙** — `@` 로 시작해 CSS 에 선언 이외의 지시를 내리는 규칙.\
> 예: `@keyframes`, `@font-face`, `@font-palette-values`.

> **컬러 폰트** — 글리프 안에 여러 색을 담고 있어 글꼴 자체가 색을 가진 폰트.\
> 예: 컬러 이모지 폰트, OpenType-SVG 폰트.

### (2) 이름으로 불러 요소에 입힌다

**언제 쓰나** — 정의한 팔레트를 특정 글자에 실제로 적용할 때.

```text
.fpv-demo { font-palette: --custom-palette; }
        │
        ▼
.fpv-demo 의 글자 중, 정의에 적힌 font-family 로 그려지는 컬러 글리프를 찾는다
        │
        ▼
그 글리프의 색을 --custom-palette 의 색으로 그린다
```

- 정의만 하고 `font-palette` 로 부르지 않으면 화면은 바뀌지 않는다.
- 이는 `@keyframes 이름` 으로 정의하고 `animation-name: 이름` 으로 불러 쓰는 구조와 같다 — 「정의 따로, 사용 따로」다.
- 원본 예제에서는 정의와 `font-palette` 줄이 둘 다 주석 처리되어 있어 개념 시연에 머문다.

### (3) `base-palette` 로 고르고 `override-colors` 로 고친다

**언제 쓰나** — 내장 팔레트 대부분은 좋은데 몇 색만 바꾸고 싶을 때.

```text
base-palette: 0
  내장 팔레트 0 = [0]A [1]B [2]C [3]D
override-colors: 0 X, 1 Y
        │
        ▼
결과 팔레트   = [0]X [1]Y [2]C [3]D
```

- `base-palette` 의 번호는 「폰트 안의 몇 번째 팔레트인가」이며 0부터 센다.
- `override-colors` 의 앞 숫자는 「그 팔레트 안의 몇 번째 색인가」이다.
- 두 숫자는 같은 0이라도 가리키는 대상이 다르다 — 하나는 팔레트 번호, 하나는 색 번호다.
- `override-colors` 에 적지 않은 색 번호는 고른 내장 팔레트의 색을 그대로 쓴다.
- 여러 색을 바꿀 때는 `번호 색` 쌍을 쉼표로 이어 적는다.

> **팔레트** — 컬러 폰트 안에 번호 순서로 담긴 색들의 목록.\
> 예: 0번 색 = 빨강, 1번 색 = 초록 ….

### (4) `font-family` 가 짝을 정한다

**언제 쓰나** — 언제나 적는다. 색 번호의 뜻이 폰트마다 다르기 때문이다.

```text
팔레트 정의의 font-family = 'Noto Color Emoji'
요소의 글자가 이 폰트로 그려지나?
   ├─ 예  → 바뀐 색으로 그려진다
   └─ 아니오(다른 폰트 · 단색 폰트) → 아무 변화 없음
```

- 「0번 색」이 어떤 폰트에선 얼굴색이고 다른 폰트에선 배경색일 수 있다.
- 그래서 팔레트 정의는 반드시 하나의 대상 폰트 패밀리에 묶인다.
- 단색 폰트에는 바꿀 팔레트가 없으니 효과가 없다.

## 문법 — 형태와 규칙

```html demo
<p class="emoji">🎨 🌈 🍎</p>
<style>
  @font-palette-values --warm {
    font-family: 'Noto Color Emoji';
    base-palette: 0;
    override-colors: 0 #ff6b6b, 1 #4ecdc4;
  }
  .emoji {
    font-family: 'Noto Color Emoji';
    font-size: 32px;
    font-palette: --warm;
  }
</style>
```

> **보이는 것** — 'Noto Color Emoji' 가 쓰이고 그 폰트가 팔레트를 지원하는 환경이라면 이모지의 0번 · 1번 색이 바뀐 색으로 그려지고, 아니면 평소 이모지가 그대로 보인다 (코드에서 읽은 것 — 렌더 실측 아님)

| 서술자 | 값 | 뜻 |
|---|---|---|
| `font-family` | 폰트 패밀리 이름 | 이 팔레트를 적용할 대상 폰트 |
| `base-palette` | 0 이상의 정수 | 출발점이 될 내장 팔레트의 번호 (0부터) |
| `override-colors` | `<색 번호> <색>` 쌍, 쉼표로 여럿 | 그 번호의 색을 새 색으로 바꾼다 |

- 이름은 `--` 로 시작한다: `@font-palette-values --이름 { … }`.
- 적용은 요소에 `font-palette: --이름;` 을 단다.
- 색 값은 `#ff6b6b` 같은 보통 CSS 색 값을 쓴다.

## 어디서 틀리나

### 1. 정의만 하고 적용을 빼먹는다
`@font-palette-values` 는 정의다.
요소에 `font-palette: --이름;` 을 달지 않으면 아무 글자도 바뀌지 않는다.

### 2. 일반 텍스트 폰트에 쓴다
원본 팁대로 이 규칙은 주로 컬러 이모지 폰트나 OpenType-SVG 폰트에서 쓰인다.
팔레트가 없는 단색 폰트에는 바꿀 색이 없다.

### 3. 두 종류의 번호를 헷갈린다
`base-palette: 1` 은 「두 번째 팔레트」이고, `override-colors: 1 …` 은 「고른 팔레트의 두 번째 색」이다.

### 4. `font-family` 가 실제 쓰이는 폰트와 다르다
정의의 `font-family` 와 요소가 실제로 그려지는 폰트가 다르면 팔레트가 연결되지 않는다.
대상 폰트가 그 환경에 없을 때도 마찬가지다.

### 5. 색 번호의 뜻을 짐작으로 정한다
번호가 무엇을 칠하는지는 폰트가 정한다.
같은 번호라도 폰트마다 칠하는 부분이 다르다.

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 컬러 이모지의 색을 브랜드 색에 맞춘다 | `@font-palette-values` + `font-palette` | 이미지로 바꿔 끼우기 |
| 컬러 폰트의 몇 색만 바꾼다 | `base-palette` + `override-colors` | 폰트 파일 직접 수정 |
| 보통 글자 색을 바꾼다 | `color` | `@font-palette-values` |
| 대상 폰트가 없을 수 있는 환경 | 기본 색이 보여도 괜찮게 설계 | 팔레트 색에만 의미를 싣기 |

## 핵심 문장

1. **`@font-palette-values` 는 컬러 폰트 내장 팔레트를 고쳐 이름 붙인 정의를 만든다.**
2. **정의는 `font-palette: --이름;` 으로 불러야 글자에 입혀진다.**
3. **`base-palette` 로 출발 팔레트를 고르고, `override-colors` 로 그중 몇 색만 바꾼다.**
4. **`font-family` 가 정의를 한 폰트에 묶는다 — 색 번호의 뜻이 폰트마다 다르기 때문이다.**
5. **팔레트가 없는 단색 폰트에는 효과가 없다.**

## 관련 자료

- `@font-face` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `font-palette` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **at-규칙** — `@` 로 시작하는 CSS 규칙.
- **컬러 폰트** — 글리프 안에 색을 담은 폰트.
- **글리프** — 폰트 안에서 글자 하나를 그리는 모양.
- **팔레트** — 컬러 폰트 안에 번호 순서로 담긴 색 목록.
- **서술자** — at-규칙 블록 안에 쓰는 `이름: 값;` 항목(`font-family`, `base-palette`, `override-colors`).
- **`base-palette`** — 출발점이 될 내장 팔레트의 번호(0부터).
- **`override-colors`** — 색 번호와 새 색의 쌍으로 개별 색을 바꾸는 서술자.
- **`font-palette`** — 요소에 어떤 팔레트를 쓸지 정하는 속성.
- **OpenType-SVG 폰트** — 글리프를 SVG 로 담아 색을 표현하는 컬러 폰트 형식.

## 더 들어가면

- 컬러 폰트의 팔레트는 보통 폰트 안의 `CPAL` 테이블에 들어 있고, `COLR` 형식 글리프가 그 색 번호를 참조한다 (확인 필요).
- `font-palette` 속성은 `--이름` 말고도 `normal` · `light` · `dark` 같은 키워드를 받는다고 알려져 있다 (확인 필요).
- `base-palette` 를 생략하면 폰트의 기본 팔레트(0번)에서 출발한다고 알려져 있다 (확인 필요).
- 이모지 폰트는 버전 · 형식(비트맵 계열 · 벡터 계열)에 따라 팔레트 교체가 먹지 않을 수 있다 (확인 필요).
- 비트맵 이미지 기반 컬러 글리프는 색 번호를 쓰지 않으므로 팔레트로 바꿀 수 없을 수 있다 (확인 필요).
