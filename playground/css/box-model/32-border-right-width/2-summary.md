## 한눈에 — 쉽게 말하면

**`border-right-width` 는 「액자 오른쪽 틀의 두께」다.**
액자 틀은 네 변이 따로 있고, 그중 오른쪽 변만 골라 두께를 정할 수 있다.
하지만 틀의 재질(실선 · 점선 등)을 정하지 않으면 틀 자체가 없으니 두께를 아무리 적어도 두께는 0 이 된다.
CSS 상자의 오른쪽 테두리도 똑같은 구조다.

| 비유 | 실체 |
|---|---|
| 액자 | 요소의 상자 |
| 오른쪽 틀의 두께 | `border-right-width` 값 |
| 틀의 재질 | `border-right-style` |
| 틀의 색 | `border-right-color` |
| 재질을 안 고름 = 틀 없음 | `border-right-style: none` → 두께 0 |

```text
┌──────────────────┓
│                  ┃  ← 오른쪽 변만 두껍다
│   content        ┃     (border-right-width)
│                  ┃
└──────────────────┛
```

## 이 주제가 답하려는 질문

1. 오른쪽 테두리 하나의 두께는 어떻게 정하고, 어떤 값을 받나?
2. 두께를 적었는데 왜 테두리가 안 보일 수 있나?
3. 오른쪽 테두리 두께는 상자 전체 너비와 다른 테두리 속성들과 어떻게 엮이나?

## 동작 방식

### (1) 오른쪽 변 하나의 두께를 정한다

**언제 쓰나** — 네 변 중 오른쪽에만 선을 긋거나, 오른쪽만 두께를 다르게 하고 싶을 때 쓴다.
예: 사이드 메뉴의 경계선, 목록 항목 사이의 세로 구분선.

```text
입력                                   무엇이 일어나나                      결과
border-right-width: 5px;          →    오른쪽 테두리 두께 = 5px            오른쪽에 5px 실선
border-right-style: solid;        →    오른쪽 테두리를 실선으로 그린다      (다른 세 변은 없음)
border-right-color: #3b82f6;      →    선 색을 파랑으로
```

- 첫 줄은 두께만 정하고, 선이 그려질지는 정하지 않는다.
- 둘째 줄의 `solid` 가 있어야 선이 실제로 생긴다.
- 셋째 줄은 그 선의 색을 정한다.

```html demo
<div style="border-right-width: 5px; border-right-style: solid; border-right-color: #3b82f6; padding: 16px; background: #f8fafc;">
  오른쪽에만 테두리
</div>
```

> **보이는 것** — 옅은 회색 상자의 오른쪽 가장자리에만 파란 세로선이 그어진다 (코드에서 읽은 것 — 렌더 실측 아님)

> **롱핸드** — 여러 값을 한꺼번에 정하는 속성(단축 속성)의 한 조각만 따로 정하는 속성이다.\
> 예: `border-right-width` 는 `border-right` · `border-width` 의 한 조각이다.

### (2) 스타일이 `none` 이면 두께는 0 으로 계산된다

**언제 쓰나** — 「두께를 줬는데 선이 안 보인다」는 상황을 진단할 때 이 규칙을 떠올린다.

```text
입력                                   무엇이 일어나나                          결과
border-right-width: 5px;          →    선언된 값은 5px                          
(border-right-style 미지정)        →    스타일 기본값 none                       
                                  →    style 이 none → 계산된 두께 = 0          선 없음, 공간도 0
```

- 테두리 스타일의 기본값은 `none` 이다.
- 원본의 팁대로, 스타일이 `none` 이면 너비는 0 으로 계산된다.
- 그래서 선이 안 보일 뿐 아니라 상자 크기에도 테두리 몫이 더해지지 않는다.

> **계산된 값** — 브라우저가 선언을 해석해 최종으로 정한 값이다.\
> 예: 선언은 `5px` 이어도 스타일이 `none` 이면 계산된 두께는 `0` 이다.

### (3) 두께는 상자 크기에 더해진다

**언제 쓰나** — 테두리를 붙였더니 레이아웃이 몇 px 밀렸을 때 원인을 셈할 때 쓴다.

```text
box-sizing: content-box (기본) 일 때 가로 바깥 너비

  border-left + padding-left + width + padding-right + border-right
       0     +     16      +  200  +     16       +     5        = 237px
```

- 기본 상자(`content-box`)에서 `width` 는 내용 영역의 너비만 뜻한다.
- 안쪽 여백과 테두리 두께는 그 바깥에 더해진다.
- 그래서 오른쪽 테두리 5px 은 상자의 가로 크기를 5px 늘린다.

> **박스 모델** — 요소의 상자를 안에서부터 내용 · 안쪽 여백(padding) · 테두리(border) · 바깥 여백(margin) 으로 나눠 보는 틀이다.\
> 예: `padding: 16px` 은 내용과 테두리 사이에 16px 을 둔다.

### (4) 단축 속성이 뒤에 오면 두께가 덮인다

**언제 쓰나** — 두께를 따로 적은 뒤 `border-right` 나 `border` 단축 속성을 다시 쓸 때 조심한다.

```text
입력                                       무엇이 일어나나                              결과
border-right-width: 5px;              →    두께 5px                                     
border-right: solid red;              →    단축 속성은 빠진 조각(두께)을 기본값으로 되돌림   두께 = medium
```

- 단축 속성은 적지 않은 조각도 기본값으로 다시 정한다.
- `border-right-width` 의 기본값은 `medium` 이다.
- 같은 규칙 안에서는 뒤에 쓴 선언이 이기므로 5px 이 사라진다.

> **단축 속성** — 관련된 여러 롱핸드를 한 줄로 정하는 속성이다.\
> 예: `border-right: 5px solid #3b82f6;`

### (5) 상속되지 않고, 애니메이션은 된다

**언제 쓰나** — 자식 요소에도 테두리가 생길지, `transition` 으로 두께를 부드럽게 바꿀 수 있을지 판단할 때.

- 원본 재료에 따르면 상속되지 않는다 — 부모에 테두리를 줘도 자식 요소의 테두리는 기본값 그대로다.
- 원본 재료에 따르면 애니메이션 가능하다 — 길이 값 사이를 중간값으로 보간한다.
- 다만 (2)의 규칙 때문에 스타일이 `none` 이면 두께가 늘 0 이라 바뀌는 모습이 보이지 않는다.

> **상속** — 부모에 정한 값이 자식 요소에 저절로 넘어가는 것이다.\
> 예: `color` 는 상속되고 `border-right-width` 는 상속되지 않는다.

## 문법 — 형태와 규칙

```css
.panel {
  border-right-width: 5px;        /* 길이 값 */
  border-right-style: solid;      /* 이것이 없으면 두께 0 */
  border-right-color: #3b82f6;
}

.thin-line {
  border-right-width: thin;       /* 키워드 값 */
  border-right-style: dashed;
}
```

형태: `border-right-width: <line-width>`

| 값 | 뜻 | 비고 |
|---|---|---|
| `<length>` | 양수 길이 값 | 예: `5px`, `0.2em` |
| `thin` | 얇은 테두리 | 보통 1px |
| `medium` | 중간 테두리 | 보통 3px · **기본값** |
| `thick` | 두꺼운 테두리 | 보통 5px |

- 기본값은 `medium` 이다.
- 상속되지 않는다.
- 애니메이션 가능하다.
- 길이는 양수여야 한다 — 음수는 받아들여지지 않는다.
- 받아들여지지 않은 선언은 무시되고, 그 전에 적용되던 값이 남는다.

## 어디서 틀리나

### 1. 스타일 없이 두께만 적는다

원본의 팁: `border-right-style` 이 `none` 이면 너비가 0 으로 계산된다.
스타일 기본값이 `none` 이므로 두께만 적으면 아무것도 안 보인다.
늘 `border-right-style` 을 함께 정한다.

### 2. 키워드의 px 값을 정확한 값으로 믿는다

원본은 `thin` · `medium` · `thick` 을 「보통」 1px · 3px · 5px 라고 적었다.
「보통」이라는 말대로, 정확한 픽셀이 꼭 필요하면 길이 값을 직접 쓰는 편이 안전하다.

### 3. 테두리가 상자를 넓힌다는 걸 잊는다

`content-box` 에서는 두께만큼 상자가 넓어진다.
나란히 놓인 상자가 한 줄에 안 들어가거나 넘칠 수 있다.

### 4. 단축 속성을 나중에 써서 두께를 지운다

`border-right` · `border` 를 뒤에 쓰면 두께가 기본값 `medium` 으로 돌아간다.
단축 속성 뒤에 롱핸드를 두거나, 단축 속성 안에 두께를 함께 적는다.

### 5. 음수 두께를 준다

음수는 받아들여지지 않아 선언 전체가 무시된다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 스타일이 `none` 이면 두께가 0 으로 계산된다 | CSS 명세 (원본 팁) |
| 기본값 `medium` · 상속 안 됨 · 애니메이션 가능 | CSS 명세 (원본 재료) |
| `thin` = 1px · `medium` = 3px · `thick` = 5px | 원본은 「보통」이라고만 적었다 — 모든 환경에서 정확히 이 값인지는 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 오른쪽 선 두께만 바꾼다 | `border-right-width` | `border-width` 네 값 전부 다시 적기 |
| 오른쪽 선을 한 번에 다 정한다 | `border-right: 5px solid …` | 롱핸드 세 줄 뒤에 두께 없는 단축 속성 |
| 정확한 픽셀이 필요하다 | 길이 값(`2px`) | `thin` · `medium` · `thick` |
| 레이아웃 크기를 지켜야 한다 | 두께를 크기 계산에 넣기 | 두께를 무시한 `width` 계산 |

## 핵심 문장

1. **`border-right-width` 는 오른쪽 변 하나의 테두리 두께만 정한다.**
2. **스타일이 `none` 이면 두께는 0 이다** — 두께만 적으면 아무것도 안 보인다.
3. **값은 양수 길이 또는 `thin` · `medium` · `thick`, 기본값은 `medium` 이다.**
4. **두께는 `content-box` 상자의 바깥 크기에 더해진다.**
5. **상속되지 않고 애니메이션은 된다** — 단축 속성을 뒤에 쓰면 두께가 기본값으로 덮인다.

## 용어 풀이

- **테두리(border)** — 안쪽 여백과 바깥 여백 사이에 그려지는 선.
- **롱핸드** — 단축 속성의 한 조각만 따로 정하는 속성.
- **단축 속성** — 여러 롱핸드를 한 줄로 정하는 속성, 빠진 조각은 기본값으로 되돌린다.
- **계산된 값** — 브라우저가 선언을 해석해 최종으로 정한 값.
- **박스 모델** — 내용 · padding · border · margin 으로 상자를 나눠 보는 틀.
- **`content-box`** — `width` 가 내용 영역만 뜻하는 기본 상자 크기 방식.
- **상속** — 부모의 값이 자식에게 저절로 넘어가는 것.
- **`<line-width>`** — 테두리 두께로 쓸 수 있는 값의 묶음(길이 · `thin` · `medium` · `thick`).
