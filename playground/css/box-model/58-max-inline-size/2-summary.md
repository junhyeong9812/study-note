## 한눈에 — 쉽게 말하면

**`max-inline-size` 는 「글이 흘러가는 쪽에 쳐 둔 울타리」다.**
글자는 한 방향으로 줄을 따라 흘러가고, 울타리에 닿으면 다음 줄로 넘어간다.
울타리는 글이 흘러가는 방향에 붙어 있으므로, 글의 방향이 바뀌면 울타리도 함께 돌아간다.
CSS 박스도 똑같은 구조다.
글이 흘러가는 방향(인라인 방향)으로 박스가 커질 수 있는 최대치를 정한다.

| 비유 | 실체 |
|---|---|
| 글이 흘러가는 방향 | 인라인 방향(가로 쓰기에서는 가로) |
| 울타리까지의 거리 | `max-inline-size` 값 |
| 울타리 없음 | `none`(기본값) |
| 울타리에 닿아 줄을 바꿈 | 박스가 최대 크기에서 멈추고 글이 줄바꿈됨 |

```text
가로 쓰기 (글이 → 로 흐른다)

부모 ┌──────────────────────────────────────┐
     │ ┌───────────────┐                    │
     │ │ 글이 여기까지 │ ← 울타리(200px)    │
     │ │ 흐르고 줄바꿈 │                    │
     │ └───────────────┘                    │
     └──────────────────────────────────────┘
```

> **인라인 방향** — 한 줄 안에서 글자가 이어져 나가는 방향.\
> 예: 한국어 가로 쓰기에서는 왼쪽 → 오른쪽.

> **논리적 속성** — 위·아래·왼쪽·오른쪽 대신 글의 방향(인라인 · 블록)을 기준으로 이름 붙인 속성.\
> 예: `max-inline-size` 는 `max-width` 의 논리적 짝이다.

## 이 주제가 답하려는 질문

1. 박스가 글의 흐름 방향으로 얼마까지 커질 수 있는가를 어떻게 정하나?
2. 최대 크기에 닿으면 박스와 그 안의 글은 어떻게 되나?
3. 왜 `max-width` 대신 「인라인」이라는 이름을 쓰나 — 가로 쓰기에서는 무엇과 같은가?
4. 값으로 무엇을 쓸 수 있고, 각 값은 무엇을 기준으로 크기를 정하나?

## 동작 방식

### (1) 최대치를 넘으려는 박스를 잡아 둔다

**언제 쓰나** — 넓은 화면에서 글 상자가 끝없이 넓어져 한 줄이 너무 길어지는 것을 막을 때 쓴다.

```text
입력:  부모 내용 폭 600px, 자식 .box { max-inline-size: 200px; }

.box 가 원래 되려던 폭   : 부모를 가득 채움 → 600px
max-inline-size 검사     : 600 > 200 → 200px 로 잘라냄
결과                     : 내용 폭 200px, 글은 그 안에서 줄바꿈
```

- 블록 박스는 원래 부모의 인라인 크기를 가득 채우려 한다.
- `max-inline-size` 가 그 크기를 위에서 누른다.
- 넘친 만큼 박스는 줄고, 글은 좁아진 줄 안에서 줄을 바꾼다.

### (2) 최대치보다 작으면 아무 일도 하지 않는다

**언제 쓰나** — 좁은 화면에서는 박스가 부모에 맞춰 줄어들고, 넓은 화면에서만 상한이 걸리게 할 때 쓴다.

```text
입력:  부모 내용 폭 150px, 자식 .box { max-inline-size: 200px; }

.box 가 원래 되려던 폭   : 150px
max-inline-size 검사     : 150 ≤ 200 → 그대로
결과                     : 내용 폭 150px
```

- 「최대」는 상한일 뿐이다.
- 박스를 200px 로 늘리지 않는다.
- 원래 크기가 상한보다 작으면 이 속성은 결과에 아무 영향이 없다.

### (3) 방향은 쓰기 모드를 따른다

**언제 쓰나** — 가로 쓰기와 세로 쓰기를 함께 지원하는 문서에서 같은 규칙을 한 번만 쓰고 싶을 때 쓴다.

```text
가로 쓰기(horizontal-tb)        세로 쓰기
글 →→→                          글 ↓
인라인 방향 = 가로               인라인 방향 = 세로
max-inline-size ≈ max-width     max-inline-size ≈ max-height
```

- 원본 팁대로, 가로 쓰기에서는 `max-width` 에 대응한다.
- 「인라인 방향」은 글이 흘러가는 방향이므로, 세로 쓰기에서는 세로가 인라인 방향이 된다.
- 그래서 세로 쓰기에서는 박스의 세로 길이를 제한하게 된다(정의에서 따라 나오는 결론 — 원본에는 가로 쓰기 매핑만 적혀 있다).

> **쓰기 모드** — 글자가 어느 방향으로 흐르고 줄이 어느 쪽으로 쌓이는지를 정하는 설정.\
> 예: `horizontal-tb` 는 가로로 쓰고 줄이 위에서 아래로 쌓인다.

## 문법 — 형태와 규칙

```css
/* 최소 예제 */
.article {
  max-inline-size: 60ch;   /* 길이 */
}
.card {
  max-inline-size: 50%;    /* 포함 블록 인라인 크기의 절반 */
}
.tag {
  max-inline-size: fit-content;
}
.reset {
  max-inline-size: none;   /* 제한 없음 */
}
```

```html demo
<div style="background:#e2e8f0; padding:16px; border:2px dashed #94a3b8;">
  <div style="max-inline-size:200px; background:#3b82f6; padding:16px; color:white;">
    max-inline-size 로 가로 최대 크기를 200px 로 묶은 상자
  </div>
</div>
```

> **보이는 것** — 회색 점선 부모 안에서 파란 상자가 부모 폭을 다 채우지 않고 왼쪽에 좁게 서고, 글이 여러 줄로 꺾인다 (코드에서 읽은 것 — 렌더 실측 아님).

| 값 | 뜻 | 기준 |
|---|---|---|
| `none` | 최대 크기 제한 없음 (기본값) | — |
| `<length>` | 고정 최대 크기 | `200px`, `60ch`, `20rem` 같은 길이 그대로 |
| `<percentage>` | 백분율 최대 크기 | 포함 블록의 인라인 크기 |
| `min-content` | 콘텐츠의 고유 최소 크기 | 줄바꿈을 최대한 했을 때 가장 넓은 조각의 크기 |
| `max-content` | 콘텐츠의 고유 선호 크기 | 줄바꿈 없이 한 줄로 늘어놓았을 때의 크기 |
| `fit-content` | 가용 공간 안에서 콘텐츠에 맞춤 | 가용 공간과 콘텐츠 크기 중 알맞은 쪽 |

- 기본값은 `none` 이다.
- 상속되지 않는다 — 자식 요소는 자기 값으로 `none` 을 가진다.
- 애니메이션이 가능하다.
- 가로 쓰기에서는 `max-width` 에 매핑된다.

> **포함 블록** — 백분율 같은 상대 값의 기준이 되는 바깥 상자.\
> 예: 보통은 가장 가까운 블록 부모의 내용 영역이다.

> **고유 크기** — 바깥 공간과 상관없이 콘텐츠 자체가 정하는 크기.\
> 예: `max-content` 는 글 전체를 한 줄로 쓴 길이다.

## 어디서 틀리나

### 1. 가로 쓰기에서는 `max-width` 와 같은 자리다

원본 팁: 가로 쓰기에서 `max-width` 에 매핑된다.
그래서 가로 쓰기 문서에서 `max-inline-size: 200px` 와 `max-width: 200px` 은 같은 결과를 낸다.
차이는 쓰기 모드가 바뀔 때에만 드러난다.

### 2. 「최대」는 늘려 주지 않는다

`max-inline-size: 200px` 를 「폭을 200px 로 만든다」로 읽으면 틀린다.
원래 크기가 200px 보다 작으면 그 작은 크기가 그대로 남는다.
폭을 정하려면 `inline-size`(가로 쓰기에서 `width`)를 써야 한다.

### 3. 짧은 글이라고 블록 박스가 줄지 않는다

블록 박스는 글 길이와 상관없이 부모 폭을 채우려 한다.
그래서 글이 짧아도, 부모가 200px 보다 넓으면 박스 내용 폭은 200px 까지 간다.
글 길이에 맞춰 줄게 하려면 `fit-content` 같은 콘텐츠 기준 값을 따로 써야 한다.

### 4. 패딩은 제한 바깥에 붙는다

기본 상자 크기 계산(`box-sizing: content-box`)에서 이 제한은 내용 영역에 걸린다.
`padding: 16px` 이 있으면 화면에 보이는 파란 상자 폭은 200 + 16 + 16 = 232px 이다.
테두리가 있으면 그 두께도 더해진다.

### 5. 백분율의 기준은 부모의 인라인 크기다

`max-inline-size: 50%` 는 포함 블록의 인라인 크기의 50% 다.
가로 쓰기에서는 부모 가로 폭의 절반이다.
부모가 줄면 상한도 함께 준다.

### 6. 상속되지 않는다

`.box` 에 건 제한이 자식에게 값으로 넘어가지는 않는다.
다만 자식은 이미 좁아진 `.box` 안에 놓이므로 결과적으로 그 폭을 넘지 못한다.
「값이 물려졌다」와 「좁은 부모 안에 갇혔다」는 다른 이야기다.

## 구현 세부사항 대 언어 보장

| 이 문서의 서술 | 누가 보장하나 |
|---|---|
| 가로 쓰기에서 `max-width` 에 매핑된다 | CSS 논리적 속성 명세 |
| 인라인 방향은 쓰기 모드를 따른다 | CSS 쓰기 모드 명세 |
| 기본값 `none` · 상속 안 됨 · 애니메이션 가능 | CSS 명세(원본 재료 기준) |
| 예제의 화면 모습(상자 폭 · 줄바꿈 위치) | 각 브라우저의 렌더링 — 글꼴에 따라 줄바꿈 위치가 달라진다 |
| 어느 브라우저 몇 버전부터 지원하나 | 원본에 없음 (확인 필요) |

## 언제 쓰고 언제 안 쓰나

| 상황 | 쓸 것 | 쓰지 말 것 |
|---|---|---|
| 본문 한 줄이 너무 길어지는 것을 막기 | `max-inline-size: 60ch` 같은 길이 | 고정 `inline-size` — 좁은 화면에서 넘친다 |
| 가로 · 세로 쓰기를 함께 지원 | `max-inline-size` | `max-width` — 세로 쓰기에서 엉뚱한 축을 막는다 |
| 부모에 비례하는 상한 | 백분율 | 고정 길이 |
| 상자 폭을 딱 정하기 | `inline-size` | `max-inline-size` — 상한만 건다 |
| 상속받은 제한 풀기 | (필요 없음 — 상속되지 않는다) | 자식마다 `none` 쓰기 |

## 핵심 문장

1. **`max-inline-size` 는 인라인 방향 크기의 상한이다** — 넘으면 자르고, 모자라면 그대로 둔다.
2. **인라인 방향은 글이 흐르는 방향이다** — 가로 쓰기에서는 `max-width` 와 같다.
3. **백분율은 포함 블록의 인라인 크기가 기준이다.**
4. **기본값은 `none`, 상속되지 않고, 애니메이션된다.**
5. **패딩 · 테두리는 기본 상자 계산에서 상한 바깥에 더해진다.**

## 관련 자료

- `max-width` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `inline-size` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)
- `min-inline-size` — 같은 사이트의 관련 항목(이 폴더에 없어 링크를 걸지 않았다)

## 용어 풀이

- **인라인 방향** — 한 줄 안에서 글자가 이어져 나가는 방향.
- **블록 방향** — 줄이 쌓여 나가는 방향(가로 쓰기에서는 위 → 아래).
- **논리적 속성** — 물리 방향 대신 글의 방향을 기준으로 한 속성.
- **쓰기 모드** — 글자가 흐르는 방향과 줄이 쌓이는 방향의 설정.
- **포함 블록** — 백분율 값의 기준이 되는 바깥 상자.
- **고유 크기** — 콘텐츠 자체가 정하는 크기(`min-content` · `max-content`).
- **`fit-content`** — 가용 공간 안에서 콘텐츠에 맞춘 크기.
- **`box-sizing: content-box`** — 크기 속성이 내용 영역에만 걸리는 기본 계산 방식.

## 더 들어가면

- 같은 박스에 `min-inline-size` 와 `max-inline-size` 가 충돌하면 최소값이 이긴다 (확인 필요).
- 같은 규칙에 `max-width` 와 `max-inline-size` 를 함께 쓰면, 가로 쓰기에서는 같은 자리를 다투므로 나중에 선언된 쪽이 적용된다고 알려져 있다 (확인 필요).
- 애니메이션은 길이 · 백분율 사이에서 부드럽게 보간되지만 `none` 이나 키워드와 길이 사이는 부드럽게 이어지지 않을 수 있다 (확인 필요).
- `box-sizing: border-box` 를 쓰면 패딩 · 테두리까지 상한 안에 들어간다 (확인 필요).
- 블록 방향의 짝은 `max-block-size` 다(가로 쓰기에서 `max-height`).
