## 퀴즈

### 1. 넓은 부모 안의 패딩 있는 상자 (예측)

```css
/* 질문용 발췌 — 부모의 내용 폭은 600px, 가로 쓰기 */
.box { max-inline-size: 200px; padding: 16px; }
```

- 화면에 보이는 `.box` 의 가로 폭(패딩 포함)은 몇 px 이고, 글은 어떻게 놓이나?

### 2. 글이 아주 짧을 때 (예측)

```css
/* 질문용 발췌 — 부모의 내용 폭은 600px, .box 는 블록 div, 안의 글은 「짧은 글」 세 글자 */
.box { max-inline-size: 200px; }
```

- `.box` 의 내용 폭은 글 길이만큼인가, 다른 값인가?

### 3. 부모가 상한보다 좁을 때 (경계)

- 부모의 내용 폭이 150px 인데 자식에 `max-inline-size: 200px` 를 걸면 자식의 내용 폭은 어떻게 되나?

### 4. 「width」 대신 「inline-size」라는 이름을 쓰는 까닭 (왜)

- `max-width` 가 있는데 왜 `max-inline-size` 라는 논리적 속성을 따로 쓰나?

### 5. 세로 쓰기로 바꾸면 (경계)

- 쓰기 모드를 세로 쓰기로 바꾸면 `max-inline-size` 는 박스의 어느 방향 길이를 제한하게 되나?

### 6. 백분율 값의 기준 (연결)

- `max-inline-size: 50%` 의 50% 는 무엇의 50% 이고, 가로 쓰기에서는 어떤 길이와 이어지나?

### 7. 상속되지 않는데 자식도 좁아지는 까닭 (왜)

- `max-inline-size` 는 상속되지 않는데, `.box` 안의 자식 요소가 200px 를 넘지 못하는 까닭은 무엇인가?

### 8. 기본값과 `inline-size` 와의 관계 (연결)

- 기본값 `none` 일 때 박스 크기는 무엇이 정하고, 폭을 「딱 200px」로 정하려면 어떤 속성을 써야 하나?

## 실습

### 실습 1. 넓은 부모 안에서 최대 폭이 묶인 상자 만들기

**만들 것** — 점선 테두리를 가진 부모 상자 안에 파란 상자 하나를 두고, 파란 상자의 인라인 방향 최대 크기를 논리적 속성으로 제한한다.

**요구 조건**
1. 부모 상자(`.parent`) 안에 자식 상자(`.box`) 하나를 두고, 자식 안에 설명 글 한 문장을 넣는다.
2. 부모와 자식의 꾸밈(배경 · 여백 · 테두리 · 글자색 · 모서리)은 시작 코드에 채워진 그대로 둔다.
3. `.box` 의 인라인 방향 최대 크기를 `max-inline-size` 로 200px 로 제한한다(`max-width` 는 쓰지 않는다).
4. 부모가 넓어도 `.box` 는 부모를 다 채우지 않고, 글은 상자 안에서 여러 줄로 꺾여야 한다.

**시작 코드**

```html
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>max-inline-size 실습</title>
<style>
.parent {
  background: #e2e8f0;
  padding: 16px;
  border: 2px dashed #94a3b8;
}
.box {
  /* TODO: 인라인 방향 최대 크기를 논리적 속성으로 제한한다 */
  background: #3b82f6;
  padding: 16px;
  color: white;
  border-radius: 4px;
}
</style>
</head>
<body>
<div class="parent">
  <!-- TODO: .box 상자를 넣고 안에 설명 글을 쓴다 -->
</div>
</body>
</html>
```

**확인 방법** — 브라우저로 열어 창을 넓혔다 좁혔다 하면서, 넓을 때 파란 상자가 일정 폭에서 멈추고 글이 꺾이는지, 창이 아주 좁을 때는 상자가 부모에 맞춰 줄어드는지 본다.
