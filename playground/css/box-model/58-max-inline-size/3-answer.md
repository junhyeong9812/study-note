## 퀴즈 정답

### 1. 232px — 내용 200px 에 양쪽 패딩이 더해지고, 글은 그 안에서 줄바꿈된다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
`.box` 는 원래 부모 내용 폭 600px 을 채우려 하지만, 상한 200px 에 걸려 내용 폭이 200px 이 된다.
패딩 16px 이 양쪽에 붙어 보이는 폭은 200 + 16 + 16 = 232px 이다.
글은 200px 내용 폭 안에서 여러 줄로 꺾인다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
상한은 넘친 크기를 잘라낸다 — 2-summary 「동작 방식 (1)」.
기본 상자 계산에서 패딩은 상한 바깥에 더해진다 — 2-summary 「어디서 틀리나 4」.

### 2. 글 길이와 상관없이 200px 이다

**예상** (실행하지 않음 — 코드를 읽어 추론한 것이다)
`.box` 의 내용 폭은 200px 이고, 「짧은 글」은 그 왼쪽에 놓이며 오른쪽은 비어 있다 (코드에서 읽은 것 — 렌더 실측 아님).

**왜 그런가**
블록 박스는 글 길이가 아니라 부모 폭을 채우려 한다.
부모 600px 을 채우려다 상한 200px 에 걸린 것이다.
글 길이에 맞추려면 `fit-content` 같은 콘텐츠 기준 값이 필요하다 — 2-summary 「어디서 틀리나 3」.

### 3. 150px — 상한은 늘려 주지 않는다

원래 크기 150px 이 상한 200px 보다 작으므로 `max-inline-size` 는 아무 일도 하지 않는다.
자식은 부모 내용 폭 150px 을 그대로 채운다.
근거: 2-summary 「동작 방식 (2)」 · 「어디서 틀리나 2」.

### 4. 쓰기 모드가 바뀌어도 「글이 흐르는 방향」을 따라가게 하려고

`max-width` 는 언제나 물리적인 가로를 막는다.
`max-inline-size` 는 글이 흐르는 방향을 막으므로, 가로 쓰기에서는 `max-width` 와 같고 세로 쓰기에서는 축이 함께 돌아간다.
그래서 여러 쓰기 모드를 지원하는 문서에서 규칙을 한 번만 쓰면 된다.
근거: 2-summary 「동작 방식 (3)」 · 「언제 쓰고 언제 안 쓰나」.

### 5. 세로 길이를 제한한다

세로 쓰기에서는 글이 위에서 아래로 흐르므로 인라인 방향이 세로다.
그래서 `max-inline-size` 는 `max-height` 처럼 세로 길이의 상한이 된다.
근거: 2-summary 「동작 방식 (3)」 (원본에는 가로 쓰기 매핑만 있다 — 세로 쓰기 쪽은 「인라인 방향」 정의에서 따라 나오는 결론이다).

### 6. 포함 블록의 인라인 크기의 50% — 가로 쓰기에서는 부모 가로 폭의 절반

백분율은 포함 블록(보통 가장 가까운 블록 부모의 내용 영역)의 인라인 크기를 기준으로 한다.
가로 쓰기에서 인라인 크기는 가로 폭이므로 부모 폭의 절반이 상한이 되고, 부모가 줄면 상한도 함께 준다.
근거: 2-summary 「문법 — 형태와 규칙」 값 표 · 「어디서 틀리나 5」.

### 7. 값이 물려진 것이 아니라 이미 좁아진 부모 안에 놓였기 때문이다

자식의 `max-inline-size` 는 기본값 `none` 이다.
그래도 자식은 내용 폭 200px 인 `.box` 안에 들어 있으므로, 블록 자식은 그 200px 을 채울 뿐 넘지 않는다.
근거: 2-summary 「어디서 틀리나 6」.

### 8. `none` 이면 원래 크기 규칙이 그대로 정하고, 폭을 정하려면 `inline-size`(가로 쓰기에서 `width`)를 쓴다

`none` 은 상한이 없다는 뜻이라, 블록 박스는 부모 폭을 채우는 원래 규칙대로 크기가 정해진다.
`max-inline-size` 는 상한만 걸 뿐 크기를 정하지 않으므로, 딱 200px 로 만들려면 `inline-size` 를 써야 한다.
근거: 2-summary 「문법 — 형태와 규칙」 · 「어디서 틀리나 2」 · 「언제 쓰고 언제 안 쓰나」.

## 실습 정답

### 실습 1. 넓은 부모 안에서 최대 폭이 묶인 상자 만들기

**요구 조건 → 정답 코드의 자리**

| 요구 조건 | 정답 코드 |
|---|---|
| 부모 안에 자식 상자와 설명 글 | `<div class="parent">` 안의 `<div class="box">…</div>` |
| 꾸밈은 시작 코드 그대로 | `.parent` 의 `background` · `padding` · `border`, `.box` 의 `background` · `padding` · `color` · `border-radius` |
| 논리적 속성으로 최대 크기 제한 | `.box { max-inline-size: 200px; }` |
| 부모를 다 채우지 않고 글이 꺾임 | `.box` 의 `max-inline-size` 가 블록 박스의 폭을 상한에서 멈추게 함 |

**정답 코드** — study-practice 의 줄 단위 주석판이다(코드 동작은 원본 예제와 같다).

`css/box-model/reference/max-inline-size.html`

```html
<!DOCTYPE html>                                                <!-- HTML5 문서 선언 -->
<html lang="ko">                                              <!-- 루트 요소, 한국어 문서 -->
<head>                                                        <!-- 문서 메타정보 영역 -->
<meta charset="utf-8">                                        <!-- 문자 인코딩 UTF-8 -->
<title>max-inline-size - 인라인 방향의 최대 크기를 설정하는 논리적 속성</title>
<!--
  [박스 모델] max-inline-size
  설명: 인라인 방향의 최대 크기를 설정하는 논리적 속성
  구문: max-inline-size: none | <length> | <percentage> | min-content | max-content | fit-content
  팁: 가로 쓰기에서 max-width에 매핑.
-->
<style>
/* .parent: 부모 컨테이너 */
.parent {
  background: #e2e8f0;             /* 배경색: 옅은 회색 */
  padding: 16px;                   /* 사방 안쪽 여백 16px */
  border: 2px dashed #94a3b8;      /* 2px 점선 보더, 회색 */
}
/* .box: 인라인축 최대 크기 제한 시연 */
.box {
  max-inline-size: 200px;          /* 인라인축 최대 크기 200px - horizontal-tb면 max-width와 동일 */
  background: #3b82f6;             /* 배경색: 파란색 */
  padding: 16px;                   /* 안쪽 여백 16px */
  color: white;                    /* 글자색: 흰색 */
  border-radius: 4px;              /* 모서리 4px 둥글게 */
}
</style>
</head>
<body>
<div class="parent">                                          <!-- 부모 박스 -->
  <div class="box">max-inline-size는 인라인 방향 최대 크기를 제한합니다</div>  <!-- 최대 너비 제한 박스 -->
</div>

</body>
</html>
```

원본 예제의 나머지 조각(study-practice 에는 없고 study-site 항목 데이터에만 있다):

```css
.parent { background: #e2e8f0; padding: 16px; border: 2px dashed #94a3b8; }
.box { max-inline-size: 200px; background: #3b82f6; padding: 16px; color: white; border-radius: 4px; }
```

**실행 결과** — 실행하지 않음 — 브라우저 화면에서 결과를 보는 예제다 — 글로 옮길 출력이 없다.

**풀이 요점**
- 핵심 줄은 `max-inline-size: 200px;` 하나다 — 가로 쓰기에서는 `max-width: 200px` 와 같은 효과다.
- `.box` 는 블록 `div` 라서 원래 부모 폭을 채우려 하고, 상한이 그것을 200px 에서 멈춘다.
- 패딩 16px 이 양쪽에 더해져 보이는 파란 상자는 232px 쯤이 된다 (코드에서 읽은 것 — 렌더 실측 아님).
- 창을 200px 보다 좁게 줄이면 상한은 아무 일도 하지 않고 상자가 부모에 맞춰 줄어든다.
- 부모의 점선 테두리는 부모가 상자보다 넓다는 것을 눈으로 보이게 하는 장치다.
