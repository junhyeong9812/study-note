## 퀴즈

### 1. 짧은 글에 최소 크기와 안쪽 여백을 함께 주면 (예측)

```css
/* 질문용 발췌 — box-sizing 은 기본값, 가로 쓰기 */
.box { min-block-size: 100px; padding: 16px; }
/* .box 안에는 글 한 줄뿐이다 */
```

- 이 박스의 테두리까지의 세로 크기는 몇 px 로 잡히는가?

### 2. 최소 크기를 훌쩍 넘는 긴 글을 넣으면 (예측)

```css
/* 질문용 발췌 — 가로 쓰기, 안에 글 20줄 */
.box { min-block-size: 100px; }
```

- 글 20줄이 100px 보다 길 때 박스의 세로 크기는 어떻게 되는가?

### 3. `min-height` 가 있는데 논리적 이름을 따로 두는 까닭 (왜)

- 같은 일을 하는 `min-height` 가 있는데 왜 `min-block-size` 라는 속성이 따로 필요한가?

### 4. 세로 쓰기에서 막는 방향 (경계)

```css

```

- 이 박스에서 200px 의 바닥이 걸리는 쪽은 높이인가 너비인가?

## 실습

### 실습 1. 최소 블록 크기를 가진 파란 박스 만들기

**만들 것** — 글 한 줄짜리 박스가 블록 방향으로 일정 크기 아래로 줄지 않고, 그 안에서 글자가 세로 가운데에 놓이게 한다.

**요구 조건**

1. `box` 클래스를 가진 `div` 하나에 글 `min-block-size` 를 넣는다.
2. 논리적 속성으로 박스의 블록 방향 최소 크기를 100px 로 정한다.
3. 박스를 flex 컨테이너로 만든다.
4. 교차축 정렬로 글자를 박스의 세로 가운데에 놓는다.

**시작 코드**

```html

  padding: 16px;
  color: white;
  border-radius: 4px;
  /* TODO: flex 컨테이너로 만든다 */
  /* TODO: 교차축 가운데 정렬 */
}
</style>
```

**확인 방법** — 파일을 브라우저로 열어 박스가 글 한 줄보다 훨씬 높은지, 글자가 박스 세로 가운데에 있는지 본다. 개발자 도구에서 `min-block-size` 를 지워 박스가 글 높이로 줄어드는지도 본다.
