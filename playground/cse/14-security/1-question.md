## 실습

### 실습 1. 작은 수로 RSA 한 바퀴 돌리기
**문제** — 소수 p = 3, q = 11 과 공개 지수 e = 3 으로 RSA 키를 만들고, 평문 m = 4 를 암호화한 뒤 다시 복호화한다.
**요구 조건**
1. n 과 φ(n) 을 구한다.
2. e·d ≡ 1 (mod φ(n)) 을 만족하는 가장 작은 양의 d 를 구한다.
3. 공개키와 개인키를 `(n, e)` · `(n, d)` 꼴로 적는다.
4. 암호문 c = m^e mod n 을 구한다.
5. c^d mod n 을 계산해 m = 4 가 돌아오는지 확인한다(거듭제곱을 나눠 계산하는 과정을 적는다).

### 실습 2. 작은 수로 Diffie-Hellman 공유 비밀 만들기
**문제** — 공개 값 g = 5, p = 23 이다. 앨리스의 비밀은 a = 6, 밥의 비밀은 b = 15 이다.
**요구 조건**
1. 앨리스가 공개하는 A = g^a mod p 를 구한다.
2. 밥이 공개하는 B = g^b mod p 를 구한다.
3. 앨리스 쪽 계산 B^a mod p 와 밥 쪽 계산 A^b mod p 를 각각 구해 같은지 확인한다.
4. 도청자가 아는 값과 모르는 값을 나눠 적는다.

### 실습 3. 느린 해시가 무차별 대입을 얼마나 늦추나
**문제** — 공격자가 비밀번호 후보 10⁹ 개를 시도한다. 해시 한 번에 (가) 0.000001초(1µs)가 걸리는 경우와 (나) 0.1초가 걸리는 느린 해시인 경우를 비교한다.
**요구 조건**
1. (가)와 (나) 각각의 총 소요 시간을 초로 구한다.
2. (가)는 분, (나)는 일과 년으로 바꿔 적는다(1년 = 365일로 친다).
3. 두 시간이 몇 배 차이인지 적는다.
4. 정상 사용자의 로그인 1회에는 이 차이가 왜 문제가 되지 않는지 한 문장으로 적는다.
