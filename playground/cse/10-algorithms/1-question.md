### 9. 피보나치 재귀를 두 방식으로 (예측)

```python
# 질문용 발췌
def fib(n):
    if n <= 1: return n
    return fib(n-1) + fib(n-2)

memo = {}
def fib_memo(n):
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = fib_memo(n-1) + fib_memo(n-2)
    return memo[n]
```

- `fib(5)` 를 부르면 `fib(2)` 는 몇 번 계산되는가?
- `fib_memo(5)` 를 부르면 `fib_memo(2)` 의 값은 몇 번 계산되는가?

## 실습

### 실습 1. 머지 정렬을 손으로 따라가기
**문제** — 배열 `[5, 2, 8, 1, 9, 3]` 을 머지 정렬한다.
나눌 때 홀수 길이면 장 본문의 예(`[9, 82, 10]` → `[9, 82]` `[10]`)처럼 왼쪽에 하나 더 둔다.
**요구 조건**
1. 나누기 단계를 크기 1 이 될 때까지 레벨별로 적는다.
2. 합치기 단계를 레벨별로 적는다.
3. 마지막 합치기(`[2,5,8]` 쪽과 `[1,3,9]` 쪽)에서 비교를 몇 번 하는지 세고, 비교마다 무엇을 꺼냈는지 적는다.

### 실습 2. 다익스트라를 표로 돌리기
**문제** — 무방향 그래프의 간선이 `A–B 4`, `A–C 1`, `C–B 2`, `B–D 1`, `C–D 5` 이다.
시작점은 `A` 다.
**요구 조건**
1. 처음 거리표(`A` 는 0, 나머지는 ∞)를 적는다.
2. 노드를 하나 확정할 때마다 확정한 노드와 갱신된 거리표를 적는다.
3. 노드가 확정되는 차례와 각 노드의 최단 거리를 적는다.

### 실습 3. 0/1 배낭 — 그리디와 DP 비교
**문제** — 배낭 용량 `W = 4`, 물건은 (무게, 가치) = 1번 `(3, 5)`, 2번 `(2, 3)`, 3번 `(2, 3)` 이다.
**요구 조건**
1. 가치/무게 비율이 높은 것부터 넣는 그리디의 결과 가치를 구한다.
2. 점화식 `dp[i][w] = max(dp[i-1][w], dp[i-1][w-wᵢ] + vᵢ)` 로 `dp[i][w]` 표(`i = 0..3`, `w = 0..4`)를 채운다.
3. 최적 가치와 고른 물건을 적고 그리디 결과와 비교한다.
