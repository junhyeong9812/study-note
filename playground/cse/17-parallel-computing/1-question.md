## 실습

### 실습 1. 암달과 구스타프슨으로 속도 향상 계산하기
**문제** — 병렬화 가능 비율이 `p = 0.9` 인 프로그램이 있다.
프로세서 수는 `n = 10` 이다.
장 본문 1.2 의 공식을 써서 세 값을 손으로 구하라.
**요구 조건**
1. 암달의 법칙으로 `n = 10` 일 때의 Speedup 을 소수 둘째 자리까지 구한다.
2. 암달의 법칙으로 `n → ∞` 일 때의 상한을 구한다.
3. 구스타프슨의 법칙 `Speedup = n - (1-p)(n-1)` 로 `n = 10` 일 때의 값을 구하고, 근사식 `n·p + (1-p)` 와도 비교한다.
4. 두 법칙의 값이 왜 다른지 한두 문장으로 적는다.

### 실습 2. 단어 빈도를 MapReduce 세 단계로 손으로 처리하기
**문제** — 입력은 `["cat dog", "dog cat cat", "bird"]` 이다.
장 본문 5.1 의 단어 빈도 예처럼 세 단계를 손으로 처리하라.
**요구 조건**
1. Map — 입력 문자열마다 만들어지는 `(key, value)` 쌍 목록을 적는다.
2. Shuffle — key 마다 모인 값 목록을 적는다.
3. Reduce — key 마다 집계한 최종 빈도를 적는다.
4. 세 단계 가운데 노드 여러 개에 나눠 완전히 독립적으로 처리할 수 있는 단계가 어느 것인지 적는다.

### 실습 3. 해시 링에 노드를 하나 더하기
**문제** — 해시 값이 0~99 인 링이 있다.
노드는 위치 20 · 50 · 80 에 있다.
키의 해시 값은 10 · 30 · 55 · 85 · 95 이다.
「시계 방향」은 수가 커지는 쪽이고, 99 다음은 0 으로 돌아간다.
각 키는 시계 방향으로 가장 가까운 노드에 저장된다.
**요구 조건**
1. 키 다섯 개가 각각 어느 노드에 저장되는지 적는다.
2. 위치 65 에 새 노드를 더한 뒤 자리를 옮기는 키가 무엇인지 적는다.
3. 비교를 위해 단순 해싱 `키 % 노드 수` 로 노드 3개 → 4개가 될 때 나머지가 바뀌는 키가 몇 개인지 센다.
4. 두 방식의 재배치 수를 비교해 한 문장으로 적는다.
