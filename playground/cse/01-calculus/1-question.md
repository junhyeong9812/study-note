## 실습

### 실습 1. 테일러 근사로 e^0.1 과 sin(0.1) 어림하기
**문제** — e^x 와 sin(x) 의 x = 0 테일러 전개를 써서 x = 0.1 에서의 값을 손으로 어림한다.
**요구 조건**
1. e^0.1 을 3차 항(x³/3!)까지 더해 소수 일곱째 자리까지 적는다.
2. sin(0.1) 을 3차 항(x³/3!)까지 더해 적는다.
3. 1차 근사 sin(x) ≈ x 와 비교해 차이가 몇인지 적는다.

### 실습 2. 부분적분과 치환적분으로 정적분 두 개 구하기
**문제** — 장의 두 예시를 정적분으로 바꿔 값을 구한다.
**요구 조건**
1. ∫[0,1] x·e^x dx 를 부분적분으로 원시함수를 구한 뒤 기본정리로 값을 낸다.
2. ∫[0,√(π/2)] 2x·cos(x²) dx 를 치환적분(u = x²)으로 원시함수를 구한 뒤 값을 낸다.
3. 각 단계에서 u · dv(또는 치환 u) 를 무엇으로 골랐는지 적는다.

### 실습 3. 경사하강법 한 걸음과 헤시안 판정
**문제** — f(x, y) = x² + 3y² 를 θ₀ = (1, 1), 학습률 α = 0.1 로 한 걸음 줄인다.
**요구 조건**
1. ∇f 를 편미분으로 구하고 θ₀ 에서의 값을 적는다.
2. 한 걸음 뒤 θ₁ 을 구하고 f(θ₀) 와 f(θ₁) 을 비교한다.
3. 헤시안을 구해 임계점 (0, 0) 이 극소 · 극대 · 안장점 중 무엇인지 판정한다.
