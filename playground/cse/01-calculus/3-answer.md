## 퀴즈 정답

### 1. 0/0 이 되고, 극한은 a 에 「닿는 것」이 아니라 「다가가는 것」을 보기 때문이다
Δt 에 0 을 넣으면 거리도 0, 시간도 0 이 되어 0/0 이 된다.
이 문제를 풀려고 극한이라는 도구를 만들었고, 극한으로 정의한 순간 변화율이 미분이다.
`0 < |x - a|` 는 x = a 자체를 빼고 본다는 뜻이다.
극한은 a 에 다가갈 때의 행동만 보므로 f(a) 가 정의되지 않아도 극한은 있을 수 있다.
근거 — 장 본문 「1.1 미적분이 태어난 이유」 · 「2.2 극한의 정의」.

### 2. 중간값 정리(IVT) — 함수가 연속이어야 한다
[a, b] 에서 연속이고 f(a) < 0, f(b) > 0 이면 (a, b) 안에 f(c) = 0 인 c 가 반드시 있다.
연속이면 점프 없이 이어지므로 음수에서 양수로 가는 동안 0 을 뛰어넘을 수 없다.
그래서 가운데 값의 부호를 보고 부호가 바뀌는 절반만 남겨도 근을 놓치지 않는다.
연속이 아니면(펜을 떼야 그릴 수 있으면) 0 을 건너뛸 수 있어 이 보장이 깨진다.
근거 — 장 본문 「2.4 연속성」의 IVT 와 🔵 CS 연결.

### 3. f'(1) = 24
바깥 함수 u³ 와 안쪽 함수 u = x² + 1 의 합성이다.
연쇄 법칙으로 f'(x) = 3(x² + 1)² · (x² + 1)' = 3(x² + 1)² · 2x 이다.
x = 1 을 넣으면 x² + 1 = 2 이므로 3 · 2² · 2 = 3 · 4 · 2 = 24 이다.
(직접 계산한 값 — 실행하지 않음)
**왜 그런가**
변화율은 체인처럼 곱해진다.
바깥 단계의 변화율 3u² 와 안쪽 단계의 변화율 2x 를 곱한 것이다.
근거 — 장 본문 「3.3 연쇄 법칙」 · 「3.2 (x^n)' = n·x^(n-1)」.

### 4. 무한소끼리의 곱이라 훨씬 빨리 0 이 된다 — 거꾸로 쓰면 부분적분이다
Δf 와 Δg 가 모두 0 으로 갈 때 둘의 곱 Δf·Δg 는 각각보다 훨씬 빨리 0 에 접근한다.
그래서 Δx 로 나누고 극한을 취하면 이 항은 사라지고 f·g' + g·f' 만 남는다.
곱의 법칙 (uv)' = u'v + uv' 를 양변 적분해 정리하면 ∫u dv = uv − ∫v du, 곧 부분적분이 된다.
근거 — 장 본문 「3.3 곱의 법칙」 · 「4.3 부분적분」.

### 5. x = −1 은 극대, x = 1 은 극소
f'(x) = 3x² − 3 = 0 에서 x² = 1, 곧 x = ±1 이 임계점이다.
f''(x) = 6x 이다.
x = 1 에서 f''(1) = 6 > 0 이므로 ∪ 모양의 바닥, 곧 극소다(f(1) = 1 − 3 = −2).
x = −1 에서 f''(−1) = −6 < 0 이므로 ∩ 모양의 꼭대기, 곧 극대다(f(−1) = −1 + 3 = 2).
(직접 계산한 값 — 실행하지 않음)
**왜 그런가**
극값에서는 변화율이 0 이어야 하고, f'' 의 부호가 f' 이 증가 중인지 감소 중인지를 알려 준다.
근거 — 장 본문 「3.6 최적화」의 2차 도함수 판정법.

### 6. (x−a)ⁿ 을 n 번 미분하면 n! 이 튀어나오기 때문이다
P(x) 의 n 번째 도함수를 a 에서 f⁽ⁿ⁾(a) 와 맞추려 하면, (x−a)ⁿ 을 n 번 미분할 때 계수가 연쇄적으로 내려와 n! 이 곱해진다.
이 n! 을 상쇄하려고 c_n = f⁽ⁿ⁾(a)/n! 로 나눈다.
sin 의 도함수는 sin → cos → −sin → −cos → sin 으로 주기 4 로 돈다.
x = 0 에서 값이 0, 1, 0, −1, 0, … 이므로 0 이 아닌 값은 홀수 차수에만 나오고 부호가 번갈아 바뀐다.
근거 — 장 본문 「3.5 테일러 급수」.

### 7. 값은 8
3x² 의 원시함수는 F(x) = x³ 이다(F'(x) = 3x²).
기본정리로 ∫[0,2] 3x² dx = F(2) − F(0) = 8 − 0 = 8 이다.
(직접 계산한 값 — 실행하지 않음)
**왜 그런가**
리만 합을 직접 더하지 않고, 원시함수의 양 끝값 차이로 넓이를 구한다.
근거 — 장 본문 「4.2 미적분학의 기본정리」 · 「3.2 (x^n)'」.

### 8. 「넓이의 변화율 = 높이」이기 때문이다
x 가 Δx 만큼 늘면 누적 넓이는 폭 Δx, 높이 약 f(x) 인 얇은 직사각형만큼 늘어난다.
그래서 ΔF ≈ f(x)·Δx, 곧 ΔF/Δx ≈ f(x) 이고 극한에서 F'(x) = f(x) 이다.
F 가 f 의 원시함수이므로 넓이(정적분)와 역미분이 같은 것이 된다.
근거 — 장 본문 「4.2 왜 이것이 성립하는가」.

### 9. p > 1 일 때 수렴한다 — a_n → 0 만으로는 부족하다
p > 1 이면 수렴, p ≤ 1 이면 발산한다(p-판정법).
경계 p = 1 에서는 원시함수가 ln x 라 ∞ 로 발산하고, p = 2 에서는 −1/x 라 0 으로 수렴해 값이 1 이 된다.
a_n → 0 은 수렴의 필요조건일 뿐 충분조건이 아니다.
조화급수 1 + 1/2 + 1/3 + … 는 항이 0 으로 가지만 약 ln(n) 으로 매우 느리게 발산한다.
근거 — 장 본문 「4.4 이상적분」 · 「5.2 수렴 판정」.

### 10. −1 이 나오지만 |r| < 1 조건 밖이라 틀린 값이다
1/(1−2) = −1 이지만, 공식은 |r| < 1 일 때만 성립한다.
r = 2 면 항이 커지기만 해서 무한 합은 발산한다(항이 0 으로 가지 않는다).
이진 트리 노드 수는 유한 합이라 1 + 2 + 4 + … + 2^k = 2^(k+1) − 1 로 따로 구한다.
근거 — 장 본문 「5.2 기하급수」와 🔵 CS 연결.

### 11. 내적의 cos(θ) 가 θ = 0 에서 최대라서 — 줄이려면 반대로 가야 한다
단위 방향 u 로 Δ 만큼 가면 Δf ≈ |∇f| · cos(θ) · Δ 이다.
cos(θ) 가 가장 큰 θ = 0, 곧 u 가 ∇f 와 같은 방향일 때 f 가 가장 빨리 늘어난다.
손실은 줄여야 하므로 가장 빨리 줄어드는 −∇f 방향으로 α 만큼 옮긴다 — 그래서 빼기다.
근거 — 장 본문 「6.3 그래디언트」.

### 12. 안장점 — 고차원일수록 모든 고유값의 부호가 같을 확률이 낮다
고유값이 섞이면 어떤 방향으로는 ∪, 어떤 방향으로는 ∩ 인 말 안장 모양의 안장점이다.
모두 양수여야 극소, 모두 음수여야 극대인데, 차원이 높을수록 모든 고유값이 같은 부호일 확률이 기하급수적으로 낮아진다.
그래서 고차원 신경망에는 안장점이 훨씬 많고, SGD 는 노이즈 덕분에 이를 빠져나온다.
근거 — 장 본문 「6.4 헤시안」.

### 13. 둘 다 「경계에서 남는 것」의 논리다
라그랑주 — 최적점에서는 제약 곡선을 벗어나지 않고는 f 를 더 좋게 만들 수 없다.
그러니 ∇f 는 제약 곡선에 수직이고, ∇g 도 g = 0 의 등고선이라 곡선에 수직이다.
같은 곡선에 둘 다 수직이므로 평행하고, 그래서 ∇f = λ∇g 이다.
발산 정리 — 내부 한 지점에서 옆 지점으로 나간 양은 옆 지점에서 들어온 양과 상쇄된다.
상쇄되지 않는 것은 경계에서만 남으므로 내부에서 생긴 양 = 표면으로 나가는 양이다.
근거 — 장 본문 「6.5 라그랑주 승수법」 · 「7.3 그린/스토크스/발산 정리」.

### 14. 편미분 + 연쇄 법칙 + 경사하강법 / 수렴 속도가 차원에 무관하다
역전파는 편미분(각 가중치에 대한 손실의 변화율), 연쇄 법칙(층을 관통하는 전파), 경사하강법(그래디언트 반대로 이동)의 조합이다.
새 수학이 아니라 미적분 원리들의 효율적 조합이다.
몬테카를로 적분은 균일 랜덤 샘플의 평균으로 적분을 근사하고, 큰 수의 법칙에 따라 수렴한다.
수렴 속도 O(1/√N) 이 차원과 무관해서, 격자로 100^10 개 점을 찍어야 하는 고차원에서 유리하다.
근거 — 장 본문 「8.1 역전파」 · 「8.3 몬테카를로 적분」.

## 실습 정답

### 실습 1. 테일러 근사로 e^0.1 과 sin(0.1) 어림하기

**1단계 — e^0.1**
e^x = 1 + x + x²/2! + x³/3! + … 이다.
x = 0.1 이면 1 = 1, x = 0.1, x²/2 = 0.01/2 = 0.005, x³/6 = 0.001/6 = 0.0001666… 이다.
합은 1 + 0.1 + 0.005 + 0.0001667 ≈ 1.1051667 이다.

**2단계 — sin(0.1)**
sin(x) = x − x³/3! + … 이다.
0.1 − 0.0001666… ≈ 0.0998333 이다.

**3단계 — 1차 근사와 비교**
sin(0.1) ≈ 0.1 과의 차이는 약 0.0001667 이다.
|x| 가 작으면 x³ 항이 매우 작아 sin(x) ≈ x 가 잘 맞는다.

(직접 계산한 값 — 실행하지 않음)
기대는 절 — 장 본문 「3.5 테일러 급수」의 e^x · sin(x) 전개와 🔵 CS 연결.

### 실습 2. 부분적분과 치환적분으로 정적분 두 개 구하기

**1단계 — ∫[0,1] x·e^x dx (부분적분)**
u = x 로 고르면 du = dx 로 간단해진다.
dv = e^x dx 로 고르면 v = e^x 로 적분하기 쉽다.
∫x·e^x dx = x·e^x − ∫e^x dx = e^x(x − 1) + C 이다.
기본정리로 [e^x(x − 1)]₀¹ = e¹·0 − e⁰·(−1) = 0 + 1 = 1 이다.

**2단계 — ∫[0,√(π/2)] 2x·cos(x²) dx (치환적분)**
u = x² 로 치환하면 du = 2x dx 이다.
원시함수는 ∫cos(u) du = sin(u) = sin(x²) 이다.
x = √(π/2) 이면 x² = π/2 이므로 sin(π/2) − sin(0) = 1 − 0 = 1 이다.

(직접 계산한 값 — 실행하지 않음)

### 실습 3. 경사하강법 한 걸음과 헤시안 판정

**1단계 — 그래디언트**
y 를 고정하고 x 로 미분하면 ∂f/∂x = 2x, x 를 고정하고 y 로 미분하면 ∂f/∂y = 6y 이다.
∇f = (2x, 6y) 이고 θ₀ = (1, 1) 에서 ∇f = (2, 6) 이다.

**2단계 — 한 걸음**
θ₁ = θ₀ − α·∇f = (1 − 0.1·2, 1 − 0.1·6) = (0.8, 0.4) 이다.
f(θ₀) = 1 + 3 = 4 이다.
f(θ₁) = 0.64 + 3·0.16 = 0.64 + 0.48 = 1.12 이다.
손실이 4 에서 1.12 로 줄었다.

**3단계 — 헤시안 판정**
∂²f/∂x² = 2, ∂²f/∂y² = 6, ∂²f/∂x∂y = ∂²f/∂y∂x = 0 이다.
H = diag(2, 6) 이라 고유값은 2 와 6 으로 모두 양수다.
∇f = (0, 0) 인 임계점 (0, 0) 은 모든 방향으로 ∪ 모양이므로 극소다.

(직접 계산한 값 — 실행하지 않음)
