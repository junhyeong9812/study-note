## 퀴즈 정답

### 1. 셋 다 거짓 — 조건문 · `¬p ∨ q` · 대우는 동치다

(가) `p → q` 는 `p` 가 참이고 `q` 가 거짓인 유일한 경우라 거짓이다.
(나) `¬p ∨ q` 는 `F ∨ F` 이므로 거짓이다.
(다) `¬q → ¬p` 는 `¬q = T` · `¬p = F` 이므로 「앞이 참, 뒤가 거짓」이라 거짓이다.

**왜 그런가**
세 식은 모두 `p = T, q = F` 에서만 거짓이 된다.
거짓이 되는 경우가 같으므로 `p → q ≡ ¬p ∨ q ≡ ¬q → ¬p` 다.
근거: 장 본문 §2.2 진리표 · §2.3 「조건문의 동치」 · 「대우」.
(직접 계산한 값 — 실행하지 않음)

### 2. `p` 가 거짓이면 약속이 적용되지 않아 위반할 수 없다

`p → q` 는 「`p` 가 참인데 `q` 가 거짓인 경우」에만 거짓이다.
`p` 가 거짓이면 약속의 조건이 성립하지 않으므로 어겼다고 할 수 없고, 그래서 참으로 친다 — 이것을 「공허하게 참」이라 한다.
정렬되지 않은 입력에 대해서는 이 명제가 아무 말도 하지 않은 것이다.
이진탐색이 틀린 답을 내더라도 약속 위반이 아니다.
근거: 장 본문 §2.2 「p → q 에서 p 가 거짓이면 무조건 참인 이유」.

### 3. `x ∈ A` 를 명제로 보면 집합 연산이 논리 연산으로 번역된다

`∪` 는 `∨`, `∩` 는 `∧`, 여집합은 `¬` 에 대응한다.
원소 `x` 에 대해 「`x ∈ A`」를 명제로 보면 집합의 식이 그대로 논리식이 되므로, 같은 구조에서 같은 법칙이 성립한다.
코드의 `!(a && b)` 는 `(!a || !b)` 와 같다.
근거: 장 본문 §5.2 · §2.3 「드모르간 법칙」의 CS 연결.

### 4. 대우는 원래 명제와 논리적으로 동치이기 때문이다

`p → q ≡ ¬p ∨ q ≡ ¬q → ¬p` 이므로 두 명제는 언제나 같은 진리값을 갖는다.
그래서 한쪽을 증명하면 다른 쪽도 증명된다.
「n² 이 짝수」에서 출발하면 `n` 에 대해 다룰 식이 잘 나오지 않는다.
대우 「`n` 이 홀수이면 `n²` 도 홀수」는 `n = 2k + 1` 에서 출발해 `n² = 2(2k² + 2k) + 1` 로 바로 계산된다.
근거: 장 본문 §2.3 「대우」 · §4.3.

### 5. `∃x ∈ 학생, ¬합격(x)` — 합격하지 못한 학생이 적어도 한 명 있다

`¬(∀x P(x)) ≡ ∃x ¬P(x)` 를 적용하면 `∃x ∈ 학생, ¬합격(x)` 가 된다.
우리말로는 「합격하지 못한 학생이 적어도 한 명 있다」다.

**왜 그런가**
`∀` 는 무한 AND 이므로, 그 부정은 드모르간에 따라 부정들의 무한 OR, 곧 `∃¬` 가 된다.
근거: 장 본문 §3.1 「한정 기호의 부정」.
(직접 계산한 값 — 실행하지 않음)

### 6. 「기약분수」라는 가정과 「p 와 q 가 모두 짝수」라는 결론이 부딪힌다

`p² = 2q²` 에서 `p` 가 짝수이고, `p = 2k` 를 넣으면 `q² = 2k²` 라 `q` 도 짝수다.
그러면 `gcd(p, q) ≥ 2` 라서 `gcd(p, q) = 1` 이라는 가정과 모순이다.
모순이 나왔다는 것은 가정(`√2` 가 유리수)이 틀렸다는 뜻이므로, 그 부정인 원래 주장(`√2` 는 무리수)이 참이어야 한다.
근거: 장 본문 §4.4.

### 7. 기저 단계는 재귀의 기저 경우, 귀납 단계는 재귀 호출 경우다

기저 단계는 「입력 크기 0(또는 1)에서 올바르게 동작한다」, 귀납 단계는 「크기 `k` 에서 올바르면 크기 `k + 1` 에서도 올바르다」에 대응한다.
재귀 구조와 귀납법의 구조가 정확히 일치한다.
강한 귀납법은 귀납 단계에서 `P(k)` 하나가 아니라 `P(0), P(1), …, P(k)` 를 모두 가정한다.
그래서 「`n = ab` 이고 `a, b < n`」처럼 바로 앞이 아닌 더 작은 경우에 기대는 증명에 쓰기 쉽다.
근거: 장 본문 §4.5 「CS 연결」 · 「강한 귀납법」 · §11.1.

### 8. `⊆` 는 대칭이 아니고, 비교할 수 없는 쌍이 있다

동치 관계는 반사 · 대칭 · 추이를 모두 만족해야 한다.
`{1} ⊆ {1,2}` 이지만 `{1,2} ⊆ {1}` 은 아니므로 대칭이 아니다.
`⊆` 는 반사 · 반대칭 · 추이를 만족하는 부분 순서다.
그러나 `{1}` 과 `{2}` 는 어느 쪽도 다른 쪽에 포함되지 않아 비교할 수 없으므로 전순서가 아니다.
근거: 장 본문 §6.2 · §6.3.

### 9. 비둘기집 원리 때문에 충돌이 반드시 생긴다

입력(비둘기)이 출력(상자)보다 많으면 적어도 한 상자에 둘 이상이 들어간다.
곧 서로 다른 두 입력이 같은 출력을 가지므로 단사(`f(a₁) = f(a₂) → a₁ = a₂`)가 깨진다.
압축에서는 `n` 비트 문자열 `2ⁿ` 개를 모두 `n` 비트 미만으로 표현할 수 없으므로, 어떤 무손실 압축이든 일부 입력은 오히려 길어진다.
근거: 장 본문 §7.1 「CS 연결」 · §8.3.

### 10. `P(6, 2) = 30`, `C(6, 2) = 15`

`P(6, 2) = 6! / 4! = 6 × 5 = 30`.
`C(6, 2) = 6! / (2! · 4!) = 30 / 2 = 15`.
두 값의 비 `30 / 15 = 2 = 2!` 다.

**왜 그런가**
조합은 순서를 따지지 않으므로, 순열에서 같은 2명을 줄 세우는 `2!` 가지 중복을 나눠 없앤다 — `C(n,k) = P(n,k) / k!`.
장 본문의 `P(5,3) = 60` · `C(5,3) = 10` · 비 `6 = 3!` 과 같은 구조다.
근거: 장 본문 §8.2.
(직접 계산한 값 — 실행하지 않음)

### 11. 존재할 수 없다 — 차수의 합이 홀수다

차수의 합은 `5 × 3 = 15` 다.
악수 정리에 따라 차수의 합은 `2|E|` 로 언제나 짝수여야 하는데 15 는 홀수다.
같은 말로, 홀수 차수 정점의 수는 짝수여야 하는데 여기서는 5개다.
근거: 장 본문 §9.2 「악수 정리」.

### 12. 오일러는 지역적 조건, 해밀턴은 전역적 구조의 문제다

오일러 회로는 정점을 지날 때마다 들어오는 간선과 나가는 간선이 쌍을 이뤄야 하므로, 각 정점의 차수라는 지역적 조건만 보면 된다(모든 차수가 짝수 + 연결).
해밀턴 회로는 모든 정점을 정확히 한 번 방문해야 하는 전역적 구조라, 알려진 간단한 필요충분조건이 없어 모든 경우를 탐색해야 할 수도 있다.
그래서 해밀턴 회로는 NP-완전 문제이고, 그 최적화 판인 TSP 는 NP-hard 다.
근거: 장 본문 §9.4.

### 13. 토큰의 꼴이 Type 3(정규) 언어이기 때문이다

촘스키 위계에서 Type 3 정규 언어는 유한 오토마타로 인식된다.
정규 언어에 대해서는 DFA · NFA · 정규 표현식이 동치이므로, 정규식으로 적은 토큰 규칙을 DFA 로 바꿔 렉서를 만들 수 있다.
NFA 의 「동시에 있을 수 있는 상태의 집합」을 DFA 의 상태 하나로 보는 부분집합 구성법을 쓰며, 대가는 상태 수가 최대 `2^|Q|` 로 지수적으로 늘 수 있다는 것이다.
근거: 장 본문 §10.2 · §10.4.

### 14. `a = 2`, `b = 2`, `log_b(a) = 1` → Case 2 → `Θ(n log n)`

`T(n) = aT(n/b) + f(n)` 와 견주면 `a = 2`, `b = 2`, `f(n) = n` 이다.
`log_2(2) = 1` 이므로 `n^(log_b(a)) = n` 이다.
`f(n) = n = Θ(n^(log_b(a)))` 라서 Case 2 다.
따라서 `T(n) = Θ(n · log n)` 이고, 장 본문이 머지 정렬에 적은 `O(n log n)` 과 맞는다.
근거: 장 본문 §11.2 「마스터 정리」.
(직접 계산한 값 — 실행하지 않음)

## 실습 정답

### 실습 1. 세 원소 집합의 멱집합을 비트로 적기

**1단계 — 8줄 대응표** (왼쪽 비트부터 `a` · `b` · `c`)

```text
000 → ∅
001 → {c}
010 → {b}
011 → {b, c}
100 → {a}
101 → {a, c}
110 → {a, b}
111 → {a, b, c}
```

**2단계 — 개수 확인**
각 원소마다 「포함(1) / 안 함(0)」 두 갈래가 독립이므로 곱의 법칙으로 `2 × 2 × 2 = 8` 이다.
`|A| = 3` 이므로 `2^|A| = 2³ = 8` 과 같다.

**3단계 — 크기 2인 부분집합**
1 이 정확히 두 개인 비트열은 `011` · `101` · `110` 의 3개다 — `{b,c}` · `{a,c}` · `{a,b}`.
`C(3, 2) = 3! / (2! · 1!) = 6 / 2 = 3` 과 같다.
기대는 절: 장 본문 §5.3(멱집합과 비트 대응) · §8.1(곱의 법칙) · §8.2(`C(n,k)` 는 `k` 개짜리 부분집합의 수).
(직접 계산한 값 — 실행하지 않음)

### 실습 2. 홀수의 합을 귀납법으로 증명하기

**1단계 — `n = 4` 확인**
좌변: `1 + 3 + 5 + 7 = 16`.
우변: `4² = 16`.
같다.

**2단계 — 기저 단계 (`n = 1`)**
좌변은 첫 항 `2·1 − 1 = 1`, 우변은 `1² = 1` 이므로 성립한다.

**3단계 — 귀납 단계**
귀납 가정: `1 + 3 + … + (2k − 1) = k²` 이라 하자.
`n = k + 1` 일 때 마지막 항은 `2(k + 1) − 1 = 2k + 1` 이다.

```text
1 + 3 + … + (2k − 1) + (2k + 1)
= k² + (2k + 1)          ← 귀납 가정 사용
= k² + 2k + 1
= (k + 1)²               ← P(k+1) 의 꼴
```

기저와 귀납 단계가 모두 성립하므로 모든 `n ≥ 1` 에 대해 등식이 참이다.
기대는 절: 장 본문 §4.5(기저 단계 + 귀납 단계, `1 + 2 + … + n` 예시와 같은 구조).
(직접 계산한 값 — 실행하지 않음)

### 실습 3. 작은 그래프를 진단하기

**1단계 — 차수와 악수 정리**

```text
deg(1) = 2   (1-2, 1-3)
deg(2) = 3   (1-2, 2-5, 2-4)
deg(3) = 2   (1-3, 3-4)
deg(4) = 2   (2-4, 3-4)
deg(5) = 1   (2-5)
합 = 2 + 3 + 2 + 2 + 1 = 10
```

`|E| = 5` 이므로 `2|E| = 10` 이고 합과 같다 — 악수 정리가 성립한다.
홀수 차수 정점은 2 와 5, 두 개(짝수 개)다.

**2단계 — 오일러 판정**
홀수 차수 정점이 있으므로 오일러 회로는 없다.
홀수 차수 정점이 정확히 2개이므로 오일러 경로는 있고, 그 두 정점(5 와 2)이 시작점과 끝점이다.
경로 하나: `5 → 2 → 1 → 3 → 4 → 2` (간선 `2-5` · `1-2` · `1-3` · `3-4` · `2-4` 를 한 번씩 지난다).

**3단계 — 트리 판정**
정점 5개짜리 트리는 간선이 정확히 4개여야 하는데 이 그래프는 5개다.
실제로 `1 → 2 → 4 → 3 → 1` 사이클이 있으므로 트리가 아니다.

**4단계 — 이분 그래프 판정**
사이클은 `1-2-4-3-1` 하나뿐이고 길이가 4(짝수)이므로 홀수 길이 사이클이 없다 → 이분 그래프다.
두 그룹: `{1, 4, 5}` 와 `{2, 3}`.
간선 `1-2` · `2-5` · `1-3` · `2-4` · `3-4` 가 모두 두 그룹 사이를 잇고, 같은 그룹 안의 간선은 없다.
기대는 절: 장 본문 §9.2(차수 · 악수 정리) · §9.3(트리의 간선 수 `n − 1`, 이분 그래프 조건) · §9.4(오일러 경로 · 회로 조건).
