## 퀴즈

### 1. p 가 참이고 q 가 거짓일 때의 세 식 (예측)

```text
질문용 발췌
p = T, q = F
(가) p → q
(나) ¬p ∨ q
(다) ¬q → ¬p
```

- (가) · (나) · (다)의 진리값은 각각 무엇인가?
- 세 값을 견주면 어떤 동치 관계가 보이는가?

### 2. 조건문이 「공허하게 참」이 되는 까닭 (왜)

- `p → q` 에서 `p` 가 거짓이면 `q` 와 상관없이 전체가 참이 되는 까닭은 무엇인가?
- 「입력이 정렬되어 있으면 이진탐색이 정답을 찾는다」에서 정렬되지 않은 입력이 들어오면 이 명제는 어떻게 되는가?

### 3. 논리의 드모르간과 집합의 드모르간 (연결)

- `(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ` 가 논리의 `¬(p ∨ q) ≡ ¬p ∧ ¬q` 와 같은 법칙인 까닭은 무엇인가?
- 코드에서 `!(a && b)` 는 어떤 식과 같은가?

### 4. 대우로 증명해도 되는 까닭 (왜)

- `¬q → ¬p` 를 증명하면 `p → q` 를 증명한 셈이 되는 까닭은 무엇인가?
- 「n² 이 짝수이면 n 도 짝수」를 직접 증명하지 않고 대우로 증명하는 까닭은 무엇인가?

### 5. 「모든 학생이 합격했다」의 부정 (예측)

### 6. 귀류법에서 모순이 생기는 자리 (왜)

## 실습

### 실습 1. 세 원소 집합의 멱집합을 비트로 적기

**문제** — `A = {a, b, c}` 의 모든 부분집합을 3비트 이진수와 짝지어 적는다.
비트는 왼쪽부터 `a` · `b` · `c` 의 포함 여부다(장 본문의 `001 → {c}` · `010 → {b}` 대응을 따른다).

**요구 조건**
1. `000` 부터 `111` 까지 8줄로 「비트 → 부분집합」을 적는다.
2. 부분집합의 개수가 `2^|A|` 와 같은지 확인한다.
3. 원소가 정확히 2개인 부분집합의 수를 세고 `C(3, 2)` 와 견준다.

### 실습 2. 홀수의 합을 귀납법으로 증명하기

**문제** — `1 + 3 + 5 + … + (2n − 1) = n²` 을 수학적 귀납법으로 증명한다.

**요구 조건**
1. `n = 4` 일 때 양변을 직접 계산해 같은지 먼저 확인한다.
2. 기저 단계(`n = 1`)를 적는다.
3. 귀납 가정을 적고, 그것을 써서 `n = k + 1` 일 때 성립함을 식으로 보인다.

### 실습 3. 작은 그래프를 진단하기

**문제** — 정점 `{1, 2, 3, 4, 5}` 와 간선 `{1,2} · {2,5} · {1,3} · {2,4} · {3,4}` 로 된 무방향 그래프를 진단한다.

```text
1 — 2 — 5
|   |
3 — 4
```

**요구 조건**
1. 각 정점의 차수를 적고, 악수 정리가 성립하는지 확인한다.
2. 오일러 회로와 오일러 경로가 있는지 판정하고, 있으면 경로 하나를 적는다.
3. 이 그래프가 트리인지 판정한다.
4. 이 그래프가 이분 그래프인지 판정하고, 그렇다면 두 그룹을 적는다.
