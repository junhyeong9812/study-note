## 실습

### 실습 1. 수강 테이블을 3NF 까지 쪼개기

**문제** — 아래 테이블과 함수 종속이 주어졌다.

```text
R(student_id, course_id, student_name, dept, dept_head, grade)

FD1: student_id → student_name
FD2: student_id → dept
FD3: dept → dept_head
FD4: {student_id, course_id} → grade
```

**요구 조건** — (1) R 의 후보키를 구한다.
(2) 부분 함수 종속과 이행 함수 종속을 각각 찾아 적는다.
(3) 2NF 로, 이어서 3NF 로 분해한 테이블들을 `테이블(속성, …)` 꼴로 적고 각 테이블의 키를 밝힌다.
(4) 결과 테이블들이 BCNF 인지 판정한다.

같은 셈법(밑이 2 인 로그, 정수로 올림)으로 아래를 구한다.

**요구 조건** — (1) n = 1,000,000 일 때 순차 스캔의 최악 비교 횟수와 ⌈log₂ n⌉ 을 구한다.
(2) n = 100,000,000 (1억) 일 때 같은 두 값을 구한다.
(3) 행 수가 100배 늘었을 때 두 방식의 비교 횟수가 각각 얼마나 늘었는지 적는다.

### 실습 3. 시간표를 보고 이상 현상과 필요한 격리 수준 고르기

**문제** — 두 트랜잭션 T1 · T2 의 시간표 셋이 있다.

```text
(가) T2: 계좌 잔고 100 → 50 으로 UPDATE (아직 커밋 안 함)
     T1: 그 계좌 잔고를 읽음
     T2: ROLLBACK

(나) T1: 계좌 잔고를 읽음 (100)
     T2: 잔고를 50 으로 UPDATE 하고 COMMIT
     T1: 같은 계좌 잔고를 다시 읽음

(다) T1: SELECT COUNT(*) FROM students WHERE dept = 'CS'  (2)
     T2: CS 학생 한 명을 INSERT 하고 COMMIT
     T1: 같은 쿼리를 다시 실행
```

**요구 조건** — 각 시간표에서 (1) T1 이 읽는 값, (2) 일어난 이상 현상의 이름, (3) 그것을 막는 가장 낮은 격리 수준을 적는다.
