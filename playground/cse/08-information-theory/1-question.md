## 실습

### 실습 1. 허프만 코드 만들고 엔트로피와 견주기

**문제** — 네 기호의 확률이 `A: 0.5, B: 0.25, C: 0.125, D: 0.125` 다.
장 7.2 의 허프만 알고리즘(확률이 가장 낮은 두 기호를 합치기를 반복)으로 코드를 만들어라.

**요구 조건**
1. 합치는 차례를 단계마다 적는다.
2. 각 기호의 코드(0 · 1 열)를 적는다.
3. 평균 코드 길이 `Σ p(x) · length` 를 구한다.
4. 엔트로피 `H(X)` 를 구해 평균 코드 길이와 견주고, 장 본문 예(1.9 비트 대 1.846 비트)와 무엇이 다른지 한 줄로 적는다.

### 실습 2. 결정 트리 분할의 정보 이득

**문제** — 표본 8개 가운데 양성 4개, 음성 4개다.
특성 X 로 나눴더니 그룹 1 은 2개(양성 2, 음성 0), 그룹 2 는 6개(양성 2, 음성 4)가 됐다.

**요구 조건**
1. 분할 전 엔트로피 `H(Y)` 를 구한다.
2. 각 그룹의 엔트로피를 구한다(`log₂ 3 ≈ 1.585` 를 써도 된다).
3. 그룹 크기로 가중한 `H(Y|X)` 를 구한다.
4. 정보 이득 `IG = H(Y) − H(Y|X)` 를 소수 셋째 자리까지 적는다.

### 실습 3. 크로스 엔트로피 · KL-발산과 비대칭

**문제** — 참 분포 `P = (1/2, 1/2)`, 모델 분포 `Q = (1/4, 3/4)` 다(log 는 log₂).

**요구 조건**
1. `H(P)` 와 `H(P, Q)` 를 구한다.
2. `D_KL(P‖Q)` 를 정의식으로 구하고, `H(P, Q) = H(P) + D_KL(P‖Q)` 가 맞는지 확인한다.
3. `D_KL(Q‖P)` 를 구해 `D_KL(P‖Q)` 와 같은지 적는다(`log₂ 3 ≈ 1.585` 를 써도 된다).
