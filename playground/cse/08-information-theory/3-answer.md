### 2. 가산성 조건이 「곱을 합으로」 바꾸는 함수를 요구하기 때문이다

조건 3 은 독립 사건의 정보량이 더해지라는 요구, `I(p₁ · p₂) = I(p₁) + I(p₂)` 다.
확률은 곱해지는데 정보량은 더해져야 하므로, 곱을 합으로 바꾸는 함수가 필요하다.
그런 연속 함수는 로그뿐이다.
부호는 조건 1(확률이 작을수록 정보량이 크다)을 맞추려고 붙인 것이라 `I(p) = −log p` 가 된다.
조건 2(`I(1) = 0`)도 `log 1 = 0` 으로 저절로 맞는다.

근거 — 장 본문 「1.2」의 🟢 유도.

### 3. 6면 주사위가 가장 크고, 4면 주사위는 2 비트다

장 본문의 값으로 견주면 공정한 동전은 1 비트, 편향 동전은 약 0.081 비트, 공정한 6면 주사위는 `log₂ 6 ≈ 2.585` 비트다.

### 4. 결정적일 때 0, 균등분포일 때 `log₂ n` 이고, 미분 엔트로피는 음수가 될 수 있다

`H(X) = 0` 인 것은 X 가 결정적일 때(한 값만 확률 1)다.
최댓값 `log₂ n` 은 X 가 n 개 값 위의 균등분포일 때 나온다.
이산 엔트로피는 `p(x) ≤ 1` 이라 `−log p(x) ≥ 0` 이므로 늘 0 이상이다.
반면 연속 확률변수의 미분 엔트로피 `h(X) = −∫ f(x) log f(x) dx` 는 음수일 수 있다.

근거 — 장 본문 「2.1」의 성질 (1)~(3), 「9. 미분 엔트로피」.

### 5. 정보는 도움이 되거나 최소한 해가 되지 않는다

`H(X|Y)` 는 Y 를 알고 난 뒤 X 에 남은 불확실성이다.
Y 를 아는 것은 불확실성을 줄일 수만 있고 늘릴 수는 없다.
등호는 X 와 Y 가 독립일 때 성립한다 — Y 가 X 에 대해 아무것도 알려 주지 않으니 남은 불확실성이 그대로다.

근거 — 장 본문 「3.2 조건부 엔트로피」, 「12. 정리」 원리 3.

### 6. `I(X;Y) = 0.5` 비트, `H(X|Y) = 0.5` 비트 — 독립이 아니다

상호정보량은 `I(X;Y) = H(X) + H(Y) − H(X,Y) = 1 + 1 − 1.5 = 0.5` 비트다.
조건부 엔트로피는 연쇄 법칙 `H(X,Y) = H(Y) + H(X|Y)` 에서 `H(X|Y) = 1.5 − 1 = 0.5` 비트다.
확인하면 `I(X;Y) = H(X) − H(X|Y) = 1 − 0.5 = 0.5` 로 같다.
`I(X;Y) = 0` 이어야 독립이므로, 0.5 인 이 X 와 Y 는 독립이 아니다.

근거 — 장 본문 「3.1 연쇄 법칙」, 「4. 상호정보량」의 벤 다이어그램과 성질.

### 7. 「P 가 참인데 Q 를 쓰는 비용」과 「Q 가 참인데 P 를 쓰는 비용」이 다르기 때문이다

KL-발산은 참 분포 P 대신 Q 로 코드를 만들 때 드는 추가 비용 `H(P, Q) − H(P)` 다.
가중치 `P(x)` 가 참 분포 쪽에서 오므로, 어느 분포를 참으로 두느냐에 따라 값이 달라진다.
장 본문의 비유로는 우산이 필요한데 안 가져가는 비용(비 맞음)과 필요 없는데 가져가는 비용(짐)이 다른 것과 같다.
그래서 `D_KL(P‖Q) ≠ D_KL(Q‖P)` 이고 거리가 아니다.

근거 — 장 본문 「5. KL-발산」의 유도와 「왜 비대칭인가」.

### 8. 손실은 1 비트, 정답 확률이 1 이면 0 이다

P 가 원핫이면 크로스 엔트로피는 `L = −Σ P(x) log Q(x) = −log Q(정답 클래스)` 만 남는다.
정답 클래스(세 번째)의 Q 는 0.5 이므로 `L = −log₂ 0.5 = 1` 비트다.
나머지 항은 `P(x) = 0` 이 곱해져 사라진다.
정답 클래스에 확률 1 을 주면 `L = −log₂ 1 = 0` 이다.

근거 — 장 본문 「6. 크로스 엔트로피」의 분류 문제 설명.

(직접 계산한 값 — 실행하지 않음)

### 9. `H(P)` 가 고정이라서 KL 최소화와 같고, 이는 MLE 와 같다

`H(P, Q) = H(P) + D_KL(P‖Q)` 이다.
`H(P)` 는 참 분포 P 로 정해지는 상수이므로, Q 를 움직여 `H(P, Q)` 를 줄이는 것은 `D_KL(P‖Q)` 를 줄이는 것과 같다.
분류 문제에서 이 최소화는 Ch.03 의 MLE(최대가능도 추정)와 같다.
MSE 를 쓰지 않는 까닭은 MSE 가 확률의 기하학과 맞지 않아 그래디언트가 느리기 때문이다.
반면 크로스 엔트로피는 확률 분포 사이의 차이를 재는 데 정보이론적으로 자연스럽다.

근거 — 장 본문 「6. 크로스 엔트로피」.

### 10. 복원이 깨지고, 영어 텍스트는 이론상 5~8배 압축이 가능하다

`H(X)` 보다 적은 비트를 쓰면 서로 다른 메시지가 같은 코드를 받는다(비둘기집 원리).
그러면 원래 메시지를 되살릴 수 없어 무손실이 아니게 된다.
영어 텍스트의 문자당 엔트로피는 약 1~1.5 비트라 ASCII 8비트와 견주면 이론적으로 5~8배 압축할 수 있다.

근거 — 장 본문 「7.1 섀넌의 소스 코딩 정리」.

### 11. `ε = 0.5` 이면 0, `ε = 1` 이면 1 이다

이진 대칭 채널의 용량은 `C = 1 − H(ε)` 다(여기서 `H(ε)` 는 뒤집힐 확률 ε, 안 뒤집힐 확률 `1 − ε` 인 두 값 분포의 엔트로피).
`ε = 0.5` 이면 공정한 동전과 같아 `H(0.5) = 1` 이고 `C = 1 − 1 = 0` 이다 — 출력이 완전히 랜덤이라 아무 정보도 못 보낸다.
`ε = 1` 이면 늘 뒤집혀 결정적이므로 `H(1) = 0` 이고 `C = 1` 이다 — 받은 비트를 다시 뒤집으면 복원된다.

### 12. R < C 이면 오류를 0 에 가깝게, R > C 이면 오류를 피할 수 없다 — 대가는 지연이다

섀넌의 제2 정리에 따라 `R < C` 이면 적절한 코딩으로 오류 확률을 0 에 가깝게 만들 수 있다.
`R > C` 이면 어떤 코딩을 써도 오류를 피할 수 없다.
대가는 코드가 충분히 길어져야 한다는 것이고, 그만큼 지연(latency)이 늘어난다.

근거 — 장 본문 「8.1 채널 용량과 섀넌의 제2 정리」.

### 13. 정규분포이고, 사전 지식이 적을 때 정규분포를 가정하는 것을 정당화한다

분산이 σ² 로 고정됐을 때 미분 엔트로피를 최대로 만드는 분포는 정규분포다.
정규분포는 평균과 분산만 알 때 가장 불확실한(가정이 가장 적은) 분포다.
그래서 사전 지식이 적을 때 정규분포를 가정하는 것이 정보이론적으로 타당하고, 정규분포가 자연에서 자주 나타나는 이유 가운데 하나가 된다.

근거 — 장 본문 「9. 미분 엔트로피」의 최대 엔트로피 원리, 「11. 분야 간 연결」.

### 14. 정보 이득은 상호정보량, 퍼플렉서티는 크로스 엔트로피의 지수다

정보 이득은 `IG(Y, X) = H(Y) − H(Y|X) = I(X; Y)` 로 상호정보량과 같다.
ID3 · C4.5 는 라벨의 불확실성을 가장 많이 줄이는 특성으로 나눈다.
퍼플렉서티는 `PPL = 2^{H(P, Q)}` 로 크로스 엔트로피의 지수다.
낮을수록 좋은 모델이며, 1 이면 완벽한 예측, 어휘 크기 V 이면 완전 랜덤이다.

### 실습 1. 허프만 코드 만들고 엔트로피와 견주기

**합치는 차례** (장 본문 「7.2 허프만 코딩」)

1. 가장 낮은 두 기호 C(0.125)와 D(0.125)를 합친다 → `C+D = 0.25`.
2. 남은 것은 A(0.5), B(0.25), (C+D)(0.25)다. 가장 낮은 B 와 (C+D)를 합친다 → `B+C+D = 0.5`.
3. A(0.5)와 (B+C+D)(0.5)를 합친다 → `1.0`.

**코드** (각 합치기에서 한쪽에 0, 다른 쪽에 1 을 준다)

```text
A = 0
B = 10
C = 110
D = 111
```

**평균 코드 길이**

`0.5×1 + 0.25×2 + 0.125×3 + 0.125×3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75` 비트.

**엔트로피**

`H = 0.5·log₂2 + 0.25·log₂4 + 0.125·log₂8 + 0.125·log₂8`
`= 0.5×1 + 0.25×2 + 0.125×3 + 0.125×3 = 1.75` 비트.

**견주기** — 평균 길이와 엔트로피가 1.75 비트로 똑같다.
장 본문 예(1.9 대 1.846)에서는 차이가 남았지만, 이번 확률은 모두 `1/2` 의 거듭제곱이라 각 기호의 코드 길이가 정확히 `−log₂ p(x)` 와 같아져 차이가 없다.
소스 코딩 정리(「7.1」)의 하한 `H(X)` 에 정확히 닿은 경우다.

### 실습 3. 크로스 엔트로피 · KL-발산과 비대칭

먼저 쓸 값: `log₂ 4 = 2`, `log₂(4/3) = 2 − log₂3 ≈ 0.415`, `log₂(3/2) = log₂3 − 1 ≈ 0.585`.

1. **`H(P)`** — 균등분포 두 값이므로 `H(P) = 1` 비트.
   **`H(P, Q)`** (「6」) — `−(1/2)·log₂(1/4) − (1/2)·log₂(3/4) = (1/2)×2 + (1/2)×0.415 = 1 + 0.2075 ≈ 1.208` 비트.
2. **`D_KL(P‖Q)`** (「5」) — `(1/2)·log₂((1/2)/(1/4)) + (1/2)·log₂((1/2)/(3/4))`
   `= (1/2)·log₂2 + (1/2)·log₂(2/3) = 0.5 − 0.5×0.585 = 0.5 − 0.2925 ≈ 0.208` 비트.
   확인: `H(P) + D_KL(P‖Q) = 1 + 0.208 = 1.208` 로 `H(P, Q)` 와 같다.
3. **`D_KL(Q‖P)`** — `(1/4)·log₂((1/4)/(1/2)) + (3/4)·log₂((3/4)/(1/2))`
   `= (1/4)×(−1) + (3/4)×0.585 = −0.25 + 0.439 ≈ 0.189` 비트.
   `0.208 ≠ 0.189` 이므로 `D_KL(P‖Q) ≠ D_KL(Q‖P)` — KL-발산이 비대칭이라는 「5」의 성질과 맞는다.
   두 값 모두 0 이상이고, P ≠ Q 라 0 이 아닌 것도 깁스 부등식과 맞는다.
