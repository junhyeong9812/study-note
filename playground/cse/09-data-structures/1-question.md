## 퀴즈

### 1. `Map` 인터페이스와 `HashMap` · `TreeMap` 의 관계 (연결)
- ADT 와 자료구조의 구분으로 보면 Java 의 `Map` 과 `HashMap` · `TreeMap` 은 각각 어느 쪽에 해당하는가?
- 같은 `get(key)` 를 부르는데 구현에 따라 무엇이 달라지는가?

### 2. 배열 원소의 주소 계산 (예측)

```text
질문용 발췌 — 정수 배열 A, 원소 하나는 4바이트
시작 주소: 100
A = [10, 20, 30, 40, 50, 60]
```

- `A[5]` 는 몇 번지에 있는가?
- 이 계산에 드는 시간은 배열 길이가 100만으로 늘면 어떻게 달라지는가?

### 3. 가끔 통째로 복사하는데도 평균 O(1) 인 까닭 (왜)
- 동적 배열이 가득 차면 전체를 새 배열로 복사하는 O(n) 일이 생기는데, 왜 `append` 를 amortized O(1) 이라고 부를 수 있는가?

### 4. 연결 리스트가 빠르다는 연산의 조건 (경계)
- 연결 리스트의 중간 삽입 · 삭제가 O(1) 이라는 말에는 어떤 전제가 붙는가?
- 단일 연결 리스트에서 「이 노드를 지워라」가 O(n) 이 될 수 있는 까닭은 무엇이고, 이중 연결 리스트는 이것을 어떻게 피하는가?
- 표의 복잡도가 같을 때도 배열이 연결 리스트보다 실제로 빠른 까닭은 무엇인가?

### 5. 탐색 알고리즘과 스택 · 큐 (연결)
- DFS 와 BFS 는 각각 스택과 큐 중 어느 것과 짝을 이루며, 그 짝은 두 구조의 어떤 순서 규칙에서 나오는가?

### 6. 후위 표기식을 스택으로 계산하면 (예측)

```text
질문용 발췌 — 후위 표기식
2 3 4 × +
```

- 장 본문의 규칙(숫자는 push, 연산자는 두 개 pop 해서 계산한 뒤 결과를 push)대로 계산하면 마지막에 스택에 남는 값은 무엇인가?

### 7. 해시 충돌과 부하율 (왜)
- 해시 함수를 아무리 잘 만들어도 충돌을 완전히 없앨 수 없는 까닭은 무엇인가?
- 부하율 α 가 커지면 왜 성능이 떨어지며, 구현들은 이것을 어떻게 막는가?

### 8. 배열로 담은 최소 힙의 부모와 자식 (예측)

```text
질문용 발췌 — 0-based 배열로 담은 최소 힙
인덱스: 0  1  2  3  4  5
값:    [1, 3, 5, 7, 4, 8]
```

- 인덱스 5(값 8)의 부모는 어느 인덱스, 어떤 값인가?
- 인덱스 1(값 3)의 두 자식은 어느 인덱스, 어떤 값인가?

### 9. heapify 가 O(n log n) 이 아닌 까닭 (왜)

### 10. 정렬된 입력을 BST 에 넣으면 (경계)

## 실습

### 실습 1. 더블링 동적 배열의 복사 비용 세기
**문제** — 용량 1 인 빈 동적 배열에 원소 9개를 하나씩 `append` 한다.
배열이 가득 찬 상태에서 새 원소가 오면 용량을 2배로 늘린 새 배열을 만들고 기존 원소를 모두 복사한 뒤 새 원소를 넣는다.
원소 하나를 쓰는 데 1, 원소 하나를 복사하는 데 1 의 비용이 든다고 하자.

**요구 조건**
1. 몇 번째 삽입에서 복사가 일어나고 그때 몇 개를 복사하는지 표로 적는다.
2. 9번 삽입 후의 최종 용량, 총 복사 비용, 총 비용(쓰기 + 복사)을 구한다.
3. 삽입 하나당 평균 비용을 구하고, 장 본문의 「총 비용 ≈ 3n」과 비교한다.

### 실습 2. 최소 힙에 넣고 하나 빼기
**문제** — 배열로 담은 최소 힙 `[1, 3, 5, 7, 4, 8]`(0-based)에 값 2 를 insert 한 뒤 extractMin 을 한 번 한다.

**요구 조건**
1. insert 의 bubble up 을 단계마다 「비교한 두 인덱스 · 값 → 교환 여부 → 배열」꼴로 적는다.
2. extractMin 에서 반환되는 값과, 마지막 원소를 루트로 옮긴 뒤의 bubble down 을 같은 꼴로 적는다.
3. 최종 배열을 적고, 모든 부모 ≤ 자식인지 확인한다.

### 실습 3. 체이닝과 선형 탐사로 같은 키 넣기
**문제** — 크기 m = 5 인 해시 테이블에 키 `12, 7, 22, 3, 17` 을 이 순서로 넣는다.
해시 함수는 `h(k) = k mod 5` 로 정한다.

**요구 조건**
1. 체이닝으로 넣었을 때 각 버킷의 리스트를 적는다(같은 버킷이면 뒤에 붙인다).
2. 다 넣은 뒤의 부하율 α 를 구하고, Java `HashMap` 기준(α = 0.75)을 처음 넘는 것은 몇 번째 삽입 직후인지 적는다.
3. 선형 탐사(`h(k), h(k)+1, h(k)+2, …`, 4번을 넘으면 0번으로 돌아간다)로 넣었을 때 각 키가 들어가는 칸과 확인한 칸 수를 적고, 클러스터링이 어떻게 보이는지 한 줄로 말한다.
