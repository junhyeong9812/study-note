## 퀴즈 정답

### 1. 앞의 문장은 확률(모델 → 데이터), 뒤의 문장은 통계(데이터 → 모델)다
「공정한 동전이면 약 50번」은 모델(공정한 동전)이 주어져 있고 데이터가 어떻게 나올지 예측하므로 확률이다.
「73번 나왔으니 공정하지 않다」는 데이터가 주어져 있고 모델이 무엇인지 추론하므로 통계다.
둘은 방향이 반대지만 같은 수학 도구를 쓴다.
근거: 장 본문 「1.2 확률 vs 통계 — 방향이 반대다」.

### 2. P(홀수 | 3 이하) = 2/3 — 정보 없이 본 1/2보다 올라간다
B = 「3 이하」 = {1, 2, 3}, A = 「홀수」 = {1, 3, 5}다.
A ∩ B = {1, 3}이다.
P(A|B) = P(A∩B) / P(B) = (2/6) / (3/6) = 2/3이다.
아무 정보가 없을 때 P(A) = 3/6 = 1/2이므로, 「3 이하」라는 정보를 얻은 뒤 확률이 1/2에서 2/3로 올라갔다.
표본공간이 Ω에서 B로 줄어들고, 줄어든 공간에서 A가 차지하는 비율을 다시 센 것이다.
(직접 계산한 값 — 실행하지 않음)
근거: 장 본문 「2.3 조건부 확률」.

### 3. 독립일 수 없다 — 배반은 오히려 강한 종속이다
배반이면 A∩B = ∅이므로 P(A∩B) = 0이다.
독립이려면 P(A∩B) = P(A)·P(B)여야 하는데, 두 확률이 0보다 크면 곱이 0보다 커서 등식이 깨진다.
A가 일어나면 B는 절대 일어나지 않으므로 P(B|A) = 0 ≠ P(B)다 — A를 알면 B에 대한 정보가 생긴다.
근거: 장 본문 「2.4 독립」의 「주의: 독립 ≠ 배반」.

### 4. P(B | 불량) = 0.625 (62.5%)
먼저 전확률 정리로 증거 P(불량)을 구한다.
P(불량) = 0.02 × 0.6 + 0.05 × 0.4 = 0.012 + 0.020 = 0.032다.
베이즈 정리로 뒤집는다.
P(B | 불량) = P(불량 | B) · P(B) / P(불량) = 0.020 / 0.032 = 0.625다.
공장 B는 생산량의 40%뿐이지만 불량률이 높아서, 불량품 가운데서는 62.5%를 차지한다.
(직접 계산한 값 — 실행하지 않음)
근거: 장 본문 「3.1 베이즈 정리」 · 「3.2 전확률 정리」의 공장 예.

### 5. 점이 무한히 많아서 각 점에 양의 확률을 주면 합이 무한대가 되기 때문이다
연속이면 가능한 값이 무한히 많다.
각 값에 양의 확률을 주면 합이 무한대가 되어 전체 확률이 1이라는 공리와 어긋난다.
그래서 점 하나의 확률은 0이다 — 점 하나의 넓이가 0인 것과 같다.
f(x)는 확률이 아니라 「확률의 밀도」이고, 확률은 구간에서 적분해야 얻는다: P(a ≤ X ≤ b) = ∫[a,b] f(x) dx.
근거: 장 본문 「4.2 PMF, PDF, CDF」.

### 6. 편차의 평균은 항상 0이 되고, 절댓값은 미분이 안 되기 때문이다
E[X − μ] = E[X] − μ = μ − μ = 0이다 — 양수 편차와 음수 편차가 상쇄되어 퍼짐을 재지 못한다.
상쇄를 피하려면 부호를 없애야 하는데, 절댓값은 미분이 안 되어 수학적으로 불편하다.
제곱은 미분 가능하고 여러 좋은 수학적 성질을 가진다.
근거: 장 본문 「4.4 분산과 표준편차」.

### 7. 분산의 덧셈만 독립이 필요하다 — 교차항 Cov(X, Y) 때문이다
기댓값의 선형성 E[aX + bY] = aE[X] + bE[Y]는 기댓값이 합(적분)이고 적분이 선형이라서 항상 성립한다.
Var(X + Y)를 E[(X+Y)²] − (E[X+Y])²로 전개하면 교차항 E[XY] − E[X]E[Y] = Cov(X, Y)가 남는다.
독립이면 Cov(X, Y) = 0이라 이 항이 사라지고, 그때만 Var(X + Y) = Var(X) + Var(Y)가 된다.
근거: 장 본문 「4.3 기댓값」의 선형성, 「4.4」의 「독립일 때」.

### 8. 아니다 — 공분산 0은 「선형 관계가 없다」는 뜻일 뿐이다
독립이면 E[XY] = E[X]E[Y]이므로 Cov = 0이다.
그러나 역은 성립하지 않는다.
공분산은 선형 관계만 재므로, Cov = 0이어도 비선형 관계가 있으면 독립이 아니다.
근거: 장 본문 「6.2 공분산과 상관계수」.

### 9. 대기 시간은 Exponential(λ)를 따르고, 무기억성은 「이미 기다린 시간이 남은 대기에 영향을 주지 않는다」는 뜻이다
단위 시간당 사건 수가 Poisson(λ)이면 사건 사이 대기 시간은 Exponential(λ)다 — 같은 현상의 두 관점이다.
무기억성은 P(X > s+t | X > s) = P(X > t)다.
s만큼 기다렸어도 앞으로 t 이상 더 기다릴 확률은 처음부터 t 이상 기다릴 확률과 같다.
이는 e^(−λ(s+t)) / e^(−λs) = e^(−λt)라는 지수함수의 성질에서 나온다.
연속 분포 중 무기억성을 가진 것은 지수 분포뿐이다(이산에서는 기하분포).
근거: 장 본문 「5.1 이산 분포」의 포아송 · 「5.2 연속 분포」의 지수 분포.

### 10. 큰 수의 법칙은 「X̄ₙ → μ」, 중심극한정리는 「X̄의 분포 → 정규분포 N(μ, σ²/n)」을 말한다
큰 수의 법칙: iid이고 E[Xᵢ] = μ이면 n → ∞일 때 표본평균이 참 평균 μ에 수렴한다.
정량적으로는 Var(X̄ₙ) = σ²/n이 0으로 가서 X̄ₙ이 μ에 집중된다.
중심극한정리: 원래 분포가 무엇이든 n이 충분히 크면 X̄의 분포가 N(μ, σ²/n)에 가까워진다 — 표준화하면 N(0, 1)이다.
즉 큰 수의 법칙은 표본평균이 「어디로 가나」를, 중심극한정리는 그 주변에서 「어떤 모양으로 흩어지나」를 말한다.
근거: 장 본문 「5.2」의 중심극한정리 · 「7. 큰 수의 법칙」.

### 11. 폭은 원래의 1/2배가 된다
구간의 반폭은 1.96·σ/√n이다.
n을 4n으로 바꾸면 √(4n) = 2√n이므로 반폭이 1.96·σ/(2√n), 즉 절반이 된다.
폭 전체도 절반이다.
정밀도를 2배로 올리려면 데이터가 4배 필요하다는 뜻이다.
(직접 계산한 값 — 실행하지 않음)
근거: 장 본문 「8.2 구간 추정」의 「왜 √n으로 나누는가」.

### 12. 아니다 — p-value는 P(데이터 | H₀ 참)이지 P(H₀ 참 | 데이터)가 아니다
p-value는 「H₀가 참이라고 가정할 때, 관찰된 것만큼 또는 더 극단적인 데이터가 나올 확률」이다.
0.01이라는 것은 H₀가 참이면 이런 데이터가 100번 중 1번꼴로만 나온다는 뜻이다.
H₀가 참일 확률 P(H₀ | 데이터)는 이와 완전히 다른 값이며, 베이즈 정리를 거쳐야 구할 수 있다.
근거: 장 본문 「8.3 가설 검정」의 「p-value의 정확한 의미」.

### 13. MLE는 사전분포가 균등분포인 MAP이고, 정규분포 사전분포는 L2 정규화와 같다
MAP = argmax P(data|θ)·P(θ)이고 MLE = argmax P(data|θ)다.
P(θ)가 모든 θ에 같은 값(균등분포)이면 곱해도 최대점이 바뀌지 않아 MAP = MLE가 된다 — MLE는 「사전 지식 없는 MAP」이다.
P(θ)를 정규분포로 두면 log P(θ) ∝ −‖θ‖²이 되어 L2 정규화 항이 붙는다.
그래서 MLE + L2 정규화 = MAP이고, L2 정규화는 「파라미터가 0 근처에 있을 것」이라는 사전 믿음이다.
근거: 장 본문 「9.2 MAP 추정」.

### 14. 그렇다 — 「선형」은 x가 아니라 파라미터 β에 대해 선형이라는 뜻이다
선형 회귀의 「선형」은 파라미터 β₀, β₁에 대해 선형이라는 뜻이다.
x²을 새 변수로 보면 y = β₀ + β₁·(새 변수) + ε이 되어 똑같은 선형 회귀다.

## 실습 정답

### 실습 1. 주사위의 기댓값과 분산, 두 주사위 합으로 넓히기

**1단계 — E[X]와 E[X²]**
E[X] = (1 + 2 + 3 + 4 + 5 + 6) · (1/6) = 21/6 = 7/2 = 3.5다.
E[X²] = (1 + 4 + 9 + 16 + 25 + 36) · (1/6) = 91/6이다.

**2단계 — Var(X)**
(E[X])² = (7/2)² = 49/4이다.
Var(X) = 91/6 − 49/4 = 182/12 − 147/12 = 35/12다.
소수로는 35 ÷ 12 ≈ 2.92다.

**3단계 — 두 주사위의 합 S**
E[S] = E[X₁] + E[X₂] = 3.5 + 3.5 = 7이다 — 기댓값의 선형성(독립 불필요)을 썼다.
X₁, X₂가 독립이므로 Var(S) = Var(X₁) + Var(X₂) = 35/12 + 35/12 = 35/6 ≈ 5.83이다 — 독립일 때의 분산 덧셈을 썼다.

### 실습 2. 진단 검사의 양성 결과를 베이즈 정리로 해석하기

**1단계 — 전확률 정리로 P(양성)**
분할은 {병, 병 없음}이고 P(병) = 0.01, P(병 없음) = 0.99다.
P(양성) = P(양성|병)·P(병) + P(양성|병 없음)·P(병 없음)이다.
= 0.90 × 0.01 + 0.05 × 0.99 = 0.009 + 0.0495 = 0.0585다.

**2단계 — 베이즈 정리로 P(병 | 양성)**
P(병 | 양성) = 0.009 / 0.0585 = 90/585 = 2/13이다.
백분율로는 약 15.4%다.
검사가 양성이어도 병이 있을 확률은 약 15%에 그친다 — 사전확률 1%가 워낙 낮아서다.

**3단계 — 항의 이름 짝짓기**

| 베이즈 정리의 항 | 이 문제의 값 |
|---|---|
| 사전확률 P(A) | P(병) = 0.01 |
| 우도 P(B|A) | P(양성 | 병) = 0.90 |
| 증거 P(B) | P(양성) = 0.0585 |
| 사후확률 P(A|B) | P(병 | 양성) = 2/13 ≈ 0.154 |

### 실습 3. 이항분포 계산과 최대우도추정

**1단계 — P(X = 2)**
P(X=k) = C(n,k) · pᵏ · (1−p)ⁿ⁻ᵏ에 n = 4, k = 2, p = 0.5를 넣는다.
C(4,2) = 6이고 0.5² · 0.5² = 1/16이다.
P(X = 2) = 6/16 = 3/8 = 0.375다.

**2단계 — E[X]와 Var(X)**
E[X] = np = 4 × 0.5 = 2다.
Var(X) = np(1−p) = 4 × 0.5 × 0.5 = 1이다.

**3단계 — p̂_MLE**
n = 10, k = 7일 때 log L(p) = const + 7·log(p) + 3·log(1−p)다.
미분해 0으로 두면 7/p − 3/(1−p) = 0이다.
7(1−p) = 3p → 7 = 10p → p̂ = 7/10 = 0.7이다.
일반식 p̂ = k/n과 일치한다.
