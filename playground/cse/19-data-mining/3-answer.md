## 퀴즈 정답

### 1. 통계학은 추론, 데이터 마이닝은 발견, 머신러닝은 예측

방향은 이렇다.
통계학은 가설을 먼저 세우고 데이터로 검증한다(가설 → 데이터).
데이터 마이닝은 데이터에서 패턴을 찾아 가설을 얻는다(데이터 → 가설).
머신러닝은 데이터에서 모델을 학습한다(데이터 → 모델).
세 분야는 겹치지만 중점이 다르다 — 데이터 마이닝은 「발견」, 머신러닝은 「예측」, 통계학은 「추론」이다.

근거: 장 본문 「1. 출발점: 데이터 마이닝이란」.

### 2. 해석 가능성과 비선형 경계가 장점, 과적합이 약점

인기 있는 까닭은 둘이다.
첫째, 해석할 수 있다 — 「나이 > 30이고 소득 > 5000이면 승인」처럼 사람이 규칙을 읽을 수 있다.
둘째, 비선형 결정 경계를 만들 수 있다.

약점은 과적합에 취약하다는 것이다.
데이터가 조금만 바뀌어도 트리 구조가 크게 바뀐다.
이 약점은 앙상블(Random Forest, Gradient Boosting)로 보완한다.

근거: 장 본문 「2.1 핵심 알고리즘들 — 결정 트리」.

### 3. 학습 대신 예측 때 모든 데이터와 거리를 잰다

k-NN 은 미리 모델을 만들지 않는다.
새 데이터가 오면 그때 가장 가까운 k 개 이웃을 찾아 다수결로 분류한다.
가까운 이웃을 찾으려면 데이터 전체를 살펴야 하므로 예측이 O(n) 으로 느리다.
k-NN 이 기대는 가정은 「비슷한 것은 비슷한 종류일 것이다」다.

근거: 장 본문 「2.1 — k-NN」.

### 4. 마진이 클수록 일반화가 잘 되고, 비선형은 커널 트릭으로 푼다

마진이 크면 새 데이터가 경계 근처에 떨어져도 올바르게 분류될 가능성이 높다.
그래서 일반화 성능이 좋아지고, 장 본문은 이것이 통계적 학습 이론으로 증명된다고 적는다.

직선으로 나뉘지 않는 데이터에는 커널 트릭을 쓴다.
데이터를 고차원으로 매핑해 그 공간에서 선형으로 나뉘게 만든다.
선형대수의 내적을 커널 함수로 바꿔 끼우는 방식이다.

근거: 장 본문 「2.1 — SVM」.

### 5. 0.5, 그리고 1 에 다가간다

`z = wᵀx + b` 라 두면 `P(y=1|x) = 1/(1+e^{-z})` 다.

- `z = 0` 이면 `e^{0} = 1` 이므로 `1/(1+1) = 1/2 = 0.5` 다.
- `z` 가 아주 큰 양수면 `e^{-z}` 가 0 에 다가가므로 `1/(1+0)`, 곧 1 에 다가간다.

출력이 항상 0 과 1 사이에 머물러 확률로 읽을 수 있다는 것이 시그모이드를 쓰는 까닭이다.

근거: 장 본문 「2.1 — 로지스틱 회귀」의 식.
(직접 계산한 값 — 실행하지 않음)

### 6. 반드시 수렴하지만 전역 최적은 보장되지 않는다

수렴은 보장된다.
할당 단계와 중심 재계산 단계가 모두 클러스터 내 분산(비용)을 줄인다.
비용은 하한이 있는데 매 단계 줄어드므로 결국 멈출 수밖에 없다.

하지만 전역 최적은 보장되지 않는다.
지역 최적에 빠질 수 있으므로 여러 번 실행해 그중 나은 결과를 쓴다.

k 는 두 방법으로 정한다.
- Elbow method — k 를 늘려 가며 비용 그래프가 꺾이는 점을 본다.
- Silhouette score — 클러스터 안의 밀집도와 클러스터 사이의 분리도를 비교한다.

근거: 장 본문 「3. 클러스터링 — K-Means」.

### 7. DBSCAN 이 맞고, 계층적 클러스터링은 덴드로그램을 잘라 정한다

K-Means 는 구형 클러스터만 잘 찾고 k 를 미리 알아야 한다.
DBSCAN 은 밀도가 높은 영역을 클러스터로 보므로 임의 형태의 무리를 찾는다.
노이즈(이상치)도 따로 가려내고 k 도 필요 없다.
그래서 휜 모양 · 이상치 · k 미상이 겹친 이 상황에는 DBSCAN 이 맞다.

계층적 클러스터링은 데이터를 먼저 트리 구조로 만든다.
> **덴드로그램** — 데이터가 합쳐지거나 쪼개지는 차례를 그린 트리 그림.\
> 예: 맨 아래 잎이 개별 점이고 위로 갈수록 묶음이 커진다.

이 덴드로그램을 원하는 높이에서 잘라 클러스터 수를 정한다.
그러니 클러스터 수는 트리를 다 만든 뒤에 정한다.

근거: 장 본문 「3. 클러스터링 — DBSCAN · 계층적 클러스터링」.

### 8. 큰 집합은 부분집합보다 더 자주 나올 수 없다

`{맥주, 기저귀}` 가 나온 거래에는 반드시 `{맥주}` 도 들어 있다.
그러므로 `{맥주, 기저귀}` 의 등장 횟수는 `{맥주}` 의 등장 횟수를 넘을 수 없다.
`{맥주}` 가 이미 드물면 `{맥주, 기저귀}` 는 그보다 더 드물다.
그래서 드문 집합을 품은 더 큰 집합은 조기에 가지치기해 탐색 공간을 줄인다.
이것이 「빈번한 항목 집합의 부분집합도 빈번하다」는 Apriori 원리(하향 폐쇄)다.

근거: 장 본문 「4. 연관 규칙 — Apriori 알고리즘」.

### 9. 데이터가 희소해져 거리가 의미를 잃고, t-SNE 는 지역 구조를 지킨다

차원이 높을수록 데이터가 공간에 희소하게 흩어진다.
그러면 점 사이의 거리가 의미를 잃는다.
k-NN 과 클러스터링은 거리에 기대므로 성능이 급락한다.
이것이 차원의 저주다.

PCA 는 분산이 가장 큰 방향으로 투영하는 선형 기법이라 전역 구조를 보존한다.
그 대신 복잡한 다양체 구조를 놓칠 수 있다.
t-SNE 는 고차원에서의 이웃 관계를 저차원에서 보존하는 비선형 기법이다.
지역 구조를 잘 지키므로 클러스터가 그림에서 눈에 띄게 갈라진다.

근거: 장 본문 「5. 차원 축소」.

### 10. 68 은 이상치, 62 는 아니다

3σ 는 `3 × 5 = 15` 다.
평균에서 15 넘게 떨어지면 이상치로 보므로 정상 범위는 `35 ~ 65` 다.

- 68 은 평균에서 `68 − 50 = 18` 떨어졌다 → 15 보다 크므로 이상치다.
- 62 는 평균에서 `62 − 50 = 12` 떨어졌다 → 15 보다 작으므로 이상치가 아니다.

이 판정은 데이터가 정규분포를 따른다는 가정 위에서만 뜻이 있다.

근거: 장 본문 「6. 이상 탐지 — 통계 기반」.
(직접 계산한 값 — 실행하지 않음)

### 11. Bagging 이 맞고, 분산을 줄인다

과적합은 모델이 노이즈까지 학습한 상태, 곧 분산이 큰 상태다.
Bagging 은 복원 추출한 여러 데이터로 독립적인 모델을 학습하고 다수결 · 평균을 낸다.
그래서 분산을 줄여 과적합을 막고, 결정 트리처럼 불안정한 모델에 효과적이다.
결정 트리에 Bagging 과 랜덤 특성 선택을 더한 것이 Random Forest 다.

Boosting 은 앞 모델이 틀린 데이터에 가중치를 높여 순차적으로 보완하며 편향을 줄인다.
약한 모델을 강하게 만드는 쪽이라 이 상황의 주된 처방은 아니다.

근거: 장 본문 「7. 앙상블」, 「8.1 편향-분산 트레이드오프」.

### 12. 편향은 줄고 분산은 늘며, 총 오류는 U 자를 그린다

복잡도가 높아질수록 편향은 줄고 분산은 는다.
총 오류는 처음에는 편향이 줄어드는 덕에 내려간다.
어느 지점부터는 분산이 늘어나는 탓에 다시 올라간다.
그래서 총 오류 곡선은 U 자형이고, 바닥이 최적 복잡도다.
왼쪽 끝은 과소적합, 오른쪽 끝은 과적합 구간이다.

근거: 장 본문 「8.1 편향-분산 트레이드오프」의 그림.
(직접 계산한 값 — 실행하지 않음)

### 13. Accuracy 는 99%, Recall 은 0

모든 입력을 음성이라 하므로 혼동 행렬은 이렇다.

```text
TP = 0    FN = 10
FP = 0    TN = 990
```

- Accuracy = (TP+TN)/전체 = (0+990)/1000 = 0.99, 곧 99% 다.
- Recall = TP/(TP+FN) = 0/(0+10) = 0 이다.

양성을 하나도 찾지 못했는데 정확도는 99% 다.
이것이 불균형 데이터에서 Accuracy 만으로 부족한 까닭이다.
Precision 은 TP/(TP+FP) = 0/0 이라 정의되지 않는다(장 본문은 이 경우를 다루지 않는다 — 추론).

근거: 장 본문 「8.2 평가 지표」.
(직접 계산한 값 — 실행하지 않음)

### 14. 오류의 비용이 달라서이고, 교차 검증은 운을 평균으로 지운다

스팸 필터는 Precision 을 중시한다.
정상 메일을 스팸으로 잘못 분류하면 안 되기 때문이다 — 「스팸이라고 한 것」이 진짜 스팸이어야 한다.
암 진단은 Recall 을 중시한다.
암 환자를 놓치면 안 되기 때문이다 — 「진짜 환자」를 빠짐없이 찾아야 한다.

교차 검증은 데이터를 k 등분해 한 조각씩 돌아가며 테스트로 쓰고 나머지로 학습한 뒤 성능을 평균한다.
분할을 한 번만 하면 어떤 데이터가 테스트에 들어갔느냐는 운에 결과가 흔들린다.
k 번 평균하면 그 운이 고르게 섞여 평가가 안정된다.

근거: 장 본문 「8.2 평가 지표 — Precision vs Recall 트레이드오프 · 교차 검증」.

## 실습 정답

### 실습 1. 장바구니 다섯 건에서 연관 규칙 지표 구하기

**1단계 — 세기**
- 전체 거래: 5건
- `{맥주}` 가 든 거래: T1, T2, T3 → 3건
- `{기저귀}` 가 든 거래: T1, T2, T4 → 3건
- `{맥주, 기저귀}` 가 함께 든 거래: T1, T2 → 2건

**2단계 — 지지도**
지지도 = 함께 나온 거래 / 전체 거래 = 2/5 = 0.4

**3단계 — 신뢰도**
신뢰도 = P(기저귀 | 맥주) = 2/3 ≈ 0.667

**4단계 — 향상도**
P(기저귀) = 3/5 = 0.6
향상도 = 신뢰도 / P(기저귀) = (2/3) / (3/5) = 10/9 ≈ 1.111

**판단** — 향상도가 1 보다 크므로 맥주를 산 거래에서 기저귀가 평소보다 더 자주 나오는 양의 연관이다.

장 본문 「4. 연관 규칙」의 지지도 · 신뢰도 · 향상도 정의에 기댄다.
(직접 계산한 값 — 실행하지 않음)

### 실습 2. 혼동 행렬에서 네 지표 구하기

**1단계 — Accuracy**
(TP+TN)/전체 = (40+930)/1000 = 970/1000 = 0.970

**2단계 — Precision**
TP/(TP+FP) = 40/(40+10) = 40/50 = 4/5 = 0.800

**3단계 — Recall**
TP/(TP+FN) = 40/(40+20) = 40/60 = 2/3 ≈ 0.667

**4단계 — F1**
P·R = (4/5)·(2/3) = 8/15
P+R = 4/5 + 2/3 = 12/15 + 10/15 = 22/15
F1 = 2·(8/15)/(22/15) = 16/22 = 8/11 ≈ 0.727

**비교** — Accuracy 는 0.970 으로 높지만, 실제 양성 60건 중 20건을 놓쳐 Recall 이 0.667 이고 F1 도 0.727 에 그친다.
양성이 전체의 6% 뿐인 불균형 데이터라 Accuracy 는 대부분을 차지하는 음성 덕에 부풀려지고, 양성을 얼마나 놓쳤는지는 드러내지 못한다.

장 본문 「8.2 평가 지표」의 정의에 기댄다.
(직접 계산한 값 — 실행하지 않음)

### 실습 3. 1차원 K-Means 를 손으로 돌리기

비용은 각 점과 자기 중심 사이 거리 제곱의 합으로 센다.

**0단계 — 처음 할당 (c1 = 1, c2 = 4)**
- 1: c1 까지 0, c2 까지 3 → c1
- 2: c1 까지 1, c2 까지 2 → c1
- 3: c1 까지 2, c2 까지 1 → c2
- 8, 9, 10: c2 가 더 가깝다 → c2

클러스터: `{1, 2}` · `{3, 8, 9, 10}`
비용: (0² + 1²) + (1² + 4² + 5² + 6²) = 1 + 78 = 79

**1단계 — 중심 재계산**
c1 = (1+2)/2 = 1.5
c2 = (3+8+9+10)/4 = 30/4 = 7.5
비용: (0.5² + 0.5²) + (4.5² + 0.5² + 1.5² + 2.5²) = 0.5 + (20.25 + 0.25 + 2.25 + 6.25) = 0.5 + 29 = 29.5

**2단계 — 다시 할당 (c1 = 1.5, c2 = 7.5)**
- 3: c1 까지 1.5, c2 까지 4.5 → c1 로 옮겨 간다
- 1, 2 는 c1, 8, 9, 10 은 c2 그대로다

클러스터: `{1, 2, 3}` · `{8, 9, 10}`
비용: (0.5² + 0.5² + 1.5²) + (0.5² + 1.5² + 2.5²) = 2.75 + 8.75 = 11.5

**3단계 — 중심 재계산**
c1 = (1+2+3)/3 = 2
c2 = (8+9+10)/3 = 9
비용: (1² + 0² + 1²) + (1² + 0² + 1²) = 2 + 2 = 4

**4단계 — 다시 할당 (c1 = 2, c2 = 9)**
- 1, 2, 3 은 c1 까지 각각 1, 0, 1 이고 c2 까지 8, 7, 6 이다 → c1
- 8, 9, 10 은 c2 까지 1, 0, 1 이다 → c2

할당이 바뀌지 않으므로 수렴했다.

**비용의 흐름** — 79 → 29.5 → 11.5 → 4 로 단계마다 줄었다.
장 본문이 말한 「각 단계가 비용을 감소시키므로 반드시 수렴한다」와 맞는다.

**최종** — 클러스터 `{1, 2, 3}`(중심 2) · `{8, 9, 10}`(중심 9)

장 본문 「3. 클러스터링 — K-Means」의 (1) 할당 · (2) 재계산 · (3) 반복 흐름과 수렴 근거에 기댄다.
