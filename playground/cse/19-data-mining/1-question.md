## 퀴즈

### 1. 통계학 · 데이터 마이닝 · 머신러닝이 서로 어떻게 다른가 (연결)

- 세 분야는 각각 데이터와 가설(또는 모델) 사이를 어느 방향으로 오가나?
- 세 분야는 각각 무엇에 중점을 두나?

### 2. 결정 트리가 인기 있는 까닭과 그 약점 (왜)

- 결정 트리가 널리 쓰이는 까닭 두 가지는 무엇인가?
- 결정 트리는 어떤 약점이 있고, 그 약점을 무엇으로 보완하나?

### 3. 학습이 필요 없는 k-NN 의 대가 (왜)

- k-NN 이 「게으른 학습」으로 불리는데도 예측 단계가 느린 까닭은 무엇인가?
- k-NN 이 분류에 쓸모 있다는 믿음은 어떤 가정에 기대나?

### 4. SVM 이 마진을 최대로 하는 까닭 (왜)

- SVM 은 왜 아무 경계선이 아니라 마진이 가장 큰 경계선을 고르나?
- 직선으로 나뉘지 않는 데이터에 SVM 을 쓰려면 무엇을 하나?

### 5. 선형 부분이 0일 때 로지스틱 회귀의 출력 (예측)

- `wᵀx + b = 0` 인 입력에서 `P(y=1|x)` 는 얼마인가?
- `wᵀx + b` 가 아주 큰 양수가 되면 `P(y=1|x)` 는 어디로 다가가나?

### 6. K-Means 가 찾은 답을 얼마나 믿을 수 있나 (경계)

- K-Means 는 반드시 수렴하는가, 그렇다면 그 근거는 무엇인가?
- 수렴한 결과가 가장 좋은 답이라고 보장되는가, 보장되지 않으면 어떻게 대처하나?
- k 를 정할 때 쓰는 방법 두 가지는 무엇인가?

### 7. K-Means 로는 잘 안 되는 데이터 (경계)

- 초승달처럼 휜 모양의 무리가 있고 이상치가 섞여 있으며 무리의 개수도 모를 때, K-Means 와 DBSCAN 중 무엇이 맞나?
- 계층적 클러스터링은 클러스터 수를 언제 어떻게 정하나?

### 8. Apriori 가 탐색을 줄이는 원리 (왜)

- 항목 집합 `{맥주}` 가 드물다는 것을 알면 왜 `{맥주, 기저귀}` 는 살펴볼 필요가 없나?

### 9. 차원의 저주와 차원 축소 기법 (연결)

- 차원이 높아지면 k-NN 이나 클러스터링의 성능이 떨어지는 까닭은 무엇인가?
- 고차원 데이터의 클러스터를 2차원 그림으로 보고 싶을 때 PCA 대신 t-SNE 를 쓰는 까닭은 무엇인가?

### 10. 평균 50 · 표준편차 5 인 데이터의 두 값 (예측)

- 통계 기반 3σ 규칙으로 보면 값 68 과 값 62 는 각각 이상치인가?

### 11. 과적합된 결정 트리에 어떤 앙상블을 쓰나 (연결)

- 결정 트리가 학습 데이터에 과적합되어 있다면 Bagging 과 Boosting 중 무엇이 그 문제를 직접 겨누나?
- 그 선택은 편향-분산 트레이드오프의 어느 쪽을 줄이는 것인가?

### 12. 모델 복잡도를 높여 갈 때 (예측)

- 모델 복잡도를 아주 낮은 데서부터 계속 높이면 편향과 분산은 각각 어느 방향으로 움직이나?
- 그때 총 오류는 어떤 모양의 곡선을 그리나?

### 13. 1000건 중 양성 10건, 전부 음성이라 답하는 모델 (예측)

```text

전체 1000건 : 실제 양성 10건, 실제 음성 990건
모델        : 어떤 입력이든 「음성」이라고 예측
```

- 이 모델의 Accuracy 와 Recall 은 각각 얼마인가?

### 14. 지표 고르기와 교차 검증 (왜)

- 스팸 필터와 암 진단은 왜 서로 다른 지표를 더 중시하나?
- 데이터를 학습용과 테스트용으로 한 번만 나눠 평가하지 않고 k-Fold 교차 검증을 하는 까닭은 무엇인가?

## 실습

### 실습 1. 장바구니 다섯 건에서 연관 규칙 지표 구하기

**문제** — 아래 다섯 거래에서 규칙 「맥주 → 기저귀」를 평가한다.

```text
T1: {맥주, 기저귀}
T2: {맥주, 기저귀, 우유}
T3: {맥주, 빵}
T4: {기저귀, 우유}
T5: {우유, 빵}
```

**요구 조건**
1. `{맥주, 기저귀}` 의 지지도를 분수와 소수로 적는다.
2. 「맥주 → 기저귀」의 신뢰도를 분수와 소수(셋째 자리)로 적는다.
3. 향상도를 구하고, 양의 연관인지 판단해 한 문장으로 적는다.

### 실습 2. 혼동 행렬에서 네 지표 구하기

**문제** — 어떤 분류기를 1000건에 돌려 TP = 40, FP = 10, FN = 20, TN = 930 을 얻었다.

**요구 조건**
1. Accuracy · Precision · Recall · F1 을 각각 분수와 소수(셋째 자리)로 적는다.
2. Accuracy 와 F1 을 비교해, 이 데이터에서 Accuracy 만 보면 무엇을 놓치는지 한 문장으로 적는다.

### 실습 3. 1차원 K-Means 를 손으로 돌리기

**문제** — 점 `1, 2, 3, 8, 9, 10` 을 k = 2 로 묶는다.
처음 중심은 `c1 = 1`, `c2 = 4` 다.

**요구 조건**
1. 「할당 → 중심 재계산」을 할당이 더 바뀌지 않을 때까지 반복하고, 단계마다 각 클러스터의 원소와 새 중심을 적는다.
2. 각 할당 · 재계산 뒤의 비용(각 점과 자기 중심 사이 거리 제곱의 합)을 적어, 비용이 단계마다 줄어드는지 확인한다.
3. 최종 클러스터와 중심을 적는다.
