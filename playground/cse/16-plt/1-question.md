```text

<expr>   ::= <term> | <expr> "+" <term>

<factor> ::= "(" <expr> ")" | <number>

입력: 2 * 3 + 4
```

### 7. 같은 이름 `x` 가 두 곳에 있을 때 (예측)

```python

    print(x)
def g():
    x = 2
    f()

```

- 정적 스코프 언어라면 `f` 가 찍는 값은 무엇인가?
- 동적 스코프 언어라면 `f` 가 찍는 값은 무엇인가?

### 8. 시작값과 증가폭을 바꾼 카운터 (예측)

```python
# 질문용 발췌
def make_counter():
    count = 10
    def increment():
        nonlocal count
        count += 5
        return count
    return increment

counter = make_counter()
counter()
counter()
counter()
```

- 세 번의 `counter()` 호출은 차례로 무엇을 돌려주는가?
- `make_counter()` 가 이미 리턴했는데도 `count` 가 살아 있는 까닭은 무엇인가?

## 실습

### 실습 1. 괄호가 들어간 식의 AST 와 값

**문제** — 3.1 절의 BNF 문법(`<expr>` · `<term>` · `<factor>` · `<number>`)으로 두 식 `2 * (3 + 4)` 와 `2 * 3 + 4` 를 분석한다.

**요구 조건**
1. 두 식 각각의 AST 를 `text` 그림으로 그린다(연산자 노드와 숫자 잎만 남긴다).
2. 각 AST 를 아래에서 위로 계산한 값을 적는다.
3. 두 식에서 뿌리 노드가 서로 다른 까닭을 문법 규칙의 계층으로 한두 문장 설명한다.

### 실습 2. 순환 참조가 있는 힙에서 쓰레기 찾기

**문제** — 객체 A · B · C 가 있다.
루트(전역 변수)가 A 를 가리키고, A → B, B → C, C → B 참조가 있다.
이제 루트가 A 를 가리키던 참조를 지운다.

**요구 조건**
1. 참조를 지우기 전 A · B · C 의 참조 수를 적는다.
2. 참조를 지운 뒤 참조 카운팅만 쓸 때 각 객체의 참조 수 변화와 해제 여부를 단계별로 적는다.
3. 같은 상황에서 Mark-and-Sweep 을 돌리면 어느 객체가 마킹되고 어느 객체가 해제되는지 적는다.

### 실습 3. 상태를 따라가며 사후 조건 확인하기

**문제** — 빈 상태 `{}` 에서 세 문장 `x = 2` · `y = x * 3` · `x = x + y` 를 차례로 실행한다.

**요구 조건**
1. 조작적 의미론의 꼴 `<문장, 상태> → 상태'` 로 세 단계를 모두 적는다.
2. 호어 삼중쌍 `{x = 2} y = x * 3; x = x + y {x = 8}` 이 참인지 판정하고 근거를 적는다.
3. 두 번째 문장 `y = x * 3` 에 `x = 2` 가 알려져 있을 때 상수 폴딩을 적용한 결과를 적는다.
