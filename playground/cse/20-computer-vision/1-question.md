## 실습

### 실습 1. 수직 엣지 필터로 특징 맵을 만들고 풀링하기
**문제** — 아래 4 × 4 그레이스케일 입력에 장 본문 3.1 의 수직 엣지 필터 `[1,0,-1; 1,0,-1; 1,0,-1]` 를 stride 1, 패딩 없이 슬라이딩한다.
그다음 나온 특징 맵 전체에 2 × 2 Max Pooling 을 한 번 건다.

```text
8  8  0  0
8  8  0  0
8  8  8  0
0  0  0  0
```

**요구 조건**
1. 필터가 놓이는 자리가 몇 개인지 세고, 특징 맵의 크기(행 × 열)를 적는다.
2. 자리마다 원소별 곱의 합을 계산 과정과 함께 적어 특징 맵을 완성한다.
3. 가장 큰 값이 나온 자리를 고르고, 그 자리에서 값이 큰 까닭을 입력의 밝기 분포로 설명한다.
4. 특징 맵에 2 × 2 Max Pooling 을 건 결과를 적는다.

### 실습 2. 두 경우의 IoU 를 구하고 「맞음」을 판정하기
**문제** — 좌표 평면에서 예측 박스는 x 0~4, y 0~4 인 정사각형이다.
(가) 정답 박스가 x 2~6, y 2~6 일 때와 (나) 정답 박스가 x 1~5, y 0~4 일 때의 IoU 를 구한다.

**요구 조건**
1. 경우마다 교집합 넓이와 합집합 넓이를 따로 적는다.
2. IoU 를 분수와 소수(둘째 자리까지)로 적는다.
3. 「0.5 이상이면 맞음」 기준으로 각 경우를 판정한다.

### 실습 3. 파라미터 수 비교하기
**문제** — 장 본문의 두 비교를 직접 계산해 확인한다.
(가) 224 × 224 × 3 입력을 뉴런 100 개에 완전연결할 때의 가중치 수와, 3 × 3 필터 하나의 파라미터 수.
(나) 5 × 5 필터 하나와 3 × 3 필터 두 개의 파라미터 수(장 본문처럼 채널 · 편향은 빼고 센다).

**요구 조건**
1. (가)의 두 수를 곱셈 과정과 함께 적고, 몇 배 차이인지 적는다.
2. (나)의 두 수를 적고, 3 × 3 두 개가 몇 개 적은지 적는다.
3. (나)에서 파라미터 말고 3 × 3 두 개가 더 얻는 것 하나를 장 본문에서 찾아 적는다.
