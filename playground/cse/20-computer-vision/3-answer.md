## 퀴즈 정답

### 1. 이미지는 숫자 배열일 뿐이고, 같은 물체도 픽셀이 완전히 달라진다
컴퓨터가 받는 이미지는 픽셀값이 놓인 2차원 배열이다.
그 배열 어디에도 「여기가 고양이」라는 표시가 없다.
같은 물체도 각도 · 조명 · 크기 · 가림에 따라 픽셀값이 완전히 달라진다.
거꾸로 다른 물체가 비슷한 픽셀 패턴을 보일 수도 있고, 배경과 물체를 나눠야 하는 문제도 있다.
그래서 픽셀값 자체가 아니라 「패턴」과 「구조」를 알아봐야 하며, 이 일을 CNN 이 엣지 → 질감 → 물체 순으로 해낸다.

근거: 장 본문 「1. 출발점: 왜 컴퓨터에게 "보는 것"이 어려운가」

### 2. 50,176 개와 150,528 개 — 그래서 특징 추출이 필요하다
그레이스케일은 H × W 행렬이므로 224 × 224 = 50,176 개다.

이 수를 그대로 입력으로 쓰면 차원이 너무 높다.
그래서 의미 있는 패턴만 뽑아내는 특징 추출이 반드시 필요해진다.

### 3. 오른쪽 자리의 값은 0, 출력은 1 × 2 = 2 칸
오른쪽으로 한 칸 옮긴 자리는 입력의 2~4 열이다.

```text
겹치는 영역      필터
2  3  0          1  0 -1
1  2  1          1  0 -1
0  1  2          1  0 -1
```

원소별 곱의 합은 다음과 같다.
2×1 + 3×0 + 0×(-1) + 1×1 + 2×0 + 1×(-1) + 0×1 + 1×0 + 2×(-1)
= 2 + 0 + 0 + 1 + 0 - 1 + 0 + 0 - 2 = 0

입력이 3 행이라 필터는 세로로 한 자리에만 놓인다.
가로로는 4 열 안에서 3 열 폭의 필터가 1~3 열, 2~4 열 두 자리에 놓인다.
따라서 출력은 1 × 2 이고, 값은 `[-2, 0]` 이다.

(직접 계산한 값 — 실행하지 않음)

**왜 그런가**
이 필터는 왼쪽 열을 더하고 오른쪽 열을 빼는 수직 엣지 검출기다.
겹친 영역의 왼쪽 열 합(2+1+0=3)과 오른쪽 열 합(0+1+2=3)이 같으므로 결과가 0 이다.
왼쪽이 밝고 오른쪽이 어두운 경계가 없다는 뜻이다.

근거: 장 본문 「3.1 왜 컨볼루션인가」

### 4. 같은 작은 필터를 이미지 전체에 다시 쓰기 때문이다(파라미터 공유)
완전연결은 입력의 숫자 하나하나와 뉴런 하나하나 사이에 따로 가중치를 둔다.
224 × 224 × 3 입력을 뉴런 100 개에 이으면 약 1,500 만 개의 파라미터가 생긴다.
컨볼루션은 3 × 3 필터 하나(9 개 값)를 이미지의 모든 자리에 똑같이 슬라이딩해 쓴다.
그래서 이미지가 커져도 파라미터 수는 필터 크기로 정해진다.
여기에 물체의 특징이 국소적이라는 지역성과, 같은 필터가 어디서든 패턴을 잡는 이동 불변성이 함께 CNN 의 세 장점을 이룬다.

### 5. `[[5, 2], [2, 7]]` — 칸 수는 4 분의 1
2 × 2 영역마다 최댓값만 남긴다.

```text
왼쪽 위   {5, 1, 3, 4} → 5
오른쪽 위 {0, 2, 1, 1} → 2
왼쪽 아래 {0, 2, 1, 1} → 2
오른쪽 아래 {7, 3, 2, 6} → 7
```

결과는 아래와 같다.

```text
5  2
2  7
```

입력 16 칸이 4 칸이 되었으므로 칸 수는 1/4 이다.
가로 · 세로가 각각 절반이 되어 이후 연산량도 1/4 로 준다.

(직접 계산한 값 — 실행하지 않음)

### 6. 최댓값이 풀링 창 밖으로 넘어가면 깨진다
Max Pooling 은 2 × 2 창 안의 최댓값만 본다.
그래서 가장 큰 값이 같은 창 안에서 자리만 바꾸면 결과가 그대로다.
그러나 이동이 창의 경계를 넘어 최댓값이 이웃 창으로 옮겨 가면, 원래 창의 결과도 이웃 창의 결과도 바뀔 수 있다.
장 본문이 「1~2 픽셀」이라고 작은 이동으로 한정한 것도 이 때문이다.
큰 이동까지 견디는 것은 풀링 하나가 아니라, 같은 필터가 이미지 어디서든 패턴을 잡는 컨볼루션의 이동 불변성과 층을 쌓으며 넓어지는 수용장의 몫이다.
(원본에 근거 없음 — 추론: 창 경계를 넘는 경우의 설명)

근거: 장 본문 「3.2 풀링」의 (2) · (3), 「3.1」의 (3)

### 7. 시각 세계 자체가 「조합의 조합」으로 되어 있기 때문이다
물체는 부분들의 조합이고, 부분은 패턴들의 조합이며, 패턴은 엣지들의 조합이다.
첫 층의 필터는 작은 영역만 보므로 엣지 같은 단순 패턴을 잡는다.
다음 층은 앞 층의 결과를 조합하므로 질감 · 모서리를 잡고, 더 위 층은 눈 · 코 · 바퀴 같은 부분과 물체 전체를 잡는다.
CNN 은 이 계층 구조를 사람이 설계하지 않아도 필터 값을 학습하며 자연스럽게 익힌다.

근거: 장 본문 「4.1 왜 층을 깊게 쌓는가」, 「3.1」의 「필터의 값을 학습한다」

### 8. 같은 수용장을 더 적은 파라미터와 더 많은 비선형성으로 얻는다
3 × 3 필터 두 개를 겹쳐 쌓으면 5 × 5 필터 하나와 같은 넓이를 본다.
파라미터는 5 × 5 하나가 25 개, 3 × 3 두 개가 9 + 9 = 18 개로 더 적다(채널 · 편향을 빼고 센 값).
층이 둘이므로 사이에 비선형 함수가 한 번 더 들어가 더 복잡한 패턴을 표현할 수 있다.
VGGNet 은 이 블록을 반복해 「깊이의 힘」을 보였다.

근거: 장 본문 「4.2 대표 아키텍처」의 VGGNet

### 9. y = x 가 되어 블록이 항등 함수가 된다
F(x) = 0 이면 `y = 0 + x = x` 다.
블록 하나가 아무것도 바꾸지 않고 입력을 그대로 넘긴다는 뜻이다.
그러므로 층을 더 쌓아도 최소한 성능이 떨어지지 않는다.
망은 출력 전체가 아니라 입력에서 얼마나 바꿀지(잔차)만 배우면 되므로 학습이 쉬워진다.
역전파 때 그래디언트도 skip connection 을 따라 곧바로 흘러가 기울기 소실을 막는다.
그 결과 100 층이 넘는 망이 가능해졌다.

(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「4.2 대표 아키텍처」의 ResNet

### 10. 라벨 하나 → 박스 + 라벨 → 픽셀마다 라벨, 난이도는 그 순서로 오른다
분류는 이미지 전체에 라벨 하나를 붙인다(「고양이가 있는가?」).
객체 탐지는 물체마다 바운딩 박스와 라벨을 낸다(「어디에 있는가?」).
세그멘테이션은 모든 픽셀에 라벨을 붙인다(「어떤 픽셀이 고양이인가?」).
난이도는 분류 < 탐지 < 세그멘테이션 이다.
뒤로 갈수록 「무엇」에 더해 「어디」를 더 잘게 맞혀야 하기 때문이다.

근거: 장 본문 「5.1 이미지 분류 → 객체 탐지 → 세그멘테이션」

### 11. R-CNN 계열은 CNN 을 수천 번, YOLO 는 한 번 돌린다
R-CNN 계열은 먼저 물체가 있을 만한 영역을 제안하고, 각 영역을 따로 CNN 에 통과시킨다.
그래서 CNN 실행이 수천 번에 이르러 느리다.
YOLO 는 이미지를 그리드로 나누고 전체 이미지를 한 번 CNN 에 통과시켜, 모든 그리드 셀에서 바운딩 박스와 클래스를 동시에 예측한다.
그래서 초당 30 장 이상을 처리하는 실시간 탐지가 가능하다.

근거: 장 본문 「5.1」의 「객체 탐지 — YOLO」

### 12. 둘 다 앞의 정보를 뒤로 곧장 넘기지만, 넘기는 것과 목적이 다르다
U-Net 의 스킵 연결은 인코더(축소) 쪽에서 뽑은 세부 특징을 같은 해상도의 디코더(확대) 쪽에 넘긴다.
축소하며 잃은 세밀한 위치 정보를 되살려 정밀한 경계를 복원하는 것이 목적이다.
ResNet 의 skip connection 은 블록의 입력 x 를 출력 F(x) 에 그대로 더한다.
블록이 잔차만 배우게 하고 그래디언트가 곧장 흐르게 해서 깊은 망의 학습을 돕는 것이 목적이다.
공통점은 「중간 층을 건너뛰는 지름길」이 정보 손실을 막는다는 점이다.

근거: 장 본문 「5.1」의 「세그멘테이션 — U-Net」, 「4.2」의 ResNet

### 13. 단일 네트워크라 안정적이지만, 여러 단계를 반복해 느리다
GAN 은 생성자와 판별자 두 네트워크가 서로 겨루므로 둘의 균형을 지키기 어렵고 모드 붕괴 같은 문제가 생긴다.
Diffusion 은 네트워크 하나가 「노이즈 제거」만 배우므로 학습이 안정적이다.
대가는 생성 속도다.
완전한 노이즈에서 깨끗한 이미지까지 수십~수백 단계를 거꾸로 밟아야 한다.
DDIM · LCM 같은 방법이 이 단계 수를 줄인다.

근거: 장 본문 「6. 이미지 생성」

### 14. CNN 은 편향을 내장했고, 전이 학습은 공통인 낮은 층을 재사용한다
CNN 은 지역성 · 이동 불변성이라는 귀납적 편향을 구조에 담고 있다.
이미지에 대한 가정이 이미 들어 있으니 적은 데이터로도 잘 배운다.
ViT 는 그런 편향 없이 패치 사이의 관계를 Self-Attention 으로 처음부터 배워야 하므로, 대규모 데이터에서는 CNN 을 앞서지만 적은 데이터에서는 밀린다.
전이 학습이 통하는 까닭은 엣지 · 질감 같은 낮은 층의 특징이 거의 모든 이미지에 공통이기 때문이다.
높은 층만 새 태스크에 맞추면 되므로, 분류기만 바꾸는 feature extraction 이나 일부 · 전체를 더 학습하는 fine-tuning 으로 의료 영상처럼 데이터가 부족한 분야에서도 높은 성능을 낸다.
이것은 NLP 에서 BERT 를 사전학습한 뒤 가져다 쓰는 것과 같은 원리다.

## 실습 정답

### 실습 1. 수직 엣지 필터로 특징 맵을 만들고 풀링하기

**1단계 — 특징 맵의 크기**
4 행 안에 3 행 폭의 필터는 1~3 행, 2~4 행 두 자리에 놓인다.
4 열 안에서도 같은 까닭으로 두 자리다.
그래서 특징 맵은 2 × 2 다.

**2단계 — 자리마다 계산**
필터가 「왼쪽 열 × 1, 가운데 열 × 0, 오른쪽 열 × (-1)」 이므로 값 = (겹친 영역의 왼쪽 열 합) − (오른쪽 열 합) 이다.

```text
(1행,1열) 자리: 1~3행, 1~3열
  왼쪽 열 8+8+8 = 24, 오른쪽 열 0+0+8 = 8 → 24 - 8 = 16
(1행,2열) 자리: 1~3행, 2~4열
  왼쪽 열 8+8+8 = 24, 오른쪽 열 0+0+0 = 0 → 24 - 0 = 24
(2행,1열) 자리: 2~4행, 1~3열
  왼쪽 열 8+8+0 = 16, 오른쪽 열 0+8+0 = 8 → 16 - 8 = 8
(2행,2열) 자리: 2~4행, 2~4열
  왼쪽 열 8+8+0 = 16, 오른쪽 열 0+0+0 = 0 → 16 - 0 = 16
```

특징 맵은 다음과 같다.

```text
16  24
 8  16
```

**3단계 — 가장 큰 값**
가장 큰 값은 (1행,2열) 자리의 24 다.
이 자리에서는 왼쪽 열(입력 2열)이 세 칸 모두 밝고(8), 오른쪽 열(입력 4열)이 세 칸 모두 어둡다(0).
「왼쪽이 밝고 오른쪽이 어두운」 수직 경계가 필터 한가운데를 온전히 가로지르므로 값이 가장 크다.
다른 자리는 오른쪽 열에 밝은 칸(3행 3열의 8)이 끼거나 아래쪽 어두운 행이 들어와 값이 줄었다.

**4단계 — 2 × 2 Max Pooling**
특징 맵 전체가 2 × 2 창 하나이므로 결과는 최댓값 `24` 한 칸이다.

(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「3.1 왜 컨볼루션인가」(원소별 곱의 합, 수직 엣지 검출기), 「3.2 풀링」(Max Pooling)

### 실습 2. 두 경우의 IoU 를 구하고 「맞음」을 판정하기

예측 박스의 넓이는 4 × 4 = 16 이다.
합집합 넓이는 「두 넓이의 합 − 교집합 넓이」로 센다(겹친 부분을 두 번 세지 않도록).

**(가) 정답 박스 x 2~6, y 2~6**
1. 정답 박스 넓이: 4 × 4 = 16
2. 교집합: x 2~4, y 2~4 → 2 × 2 = 4
3. 합집합: 16 + 16 − 4 = 28
4. IoU = 4 / 28 = 1/7 ≈ 0.14
5. 0.5 미만이므로 「맞음」이 아니다.

**(나) 정답 박스 x 1~5, y 0~4**
1. 정답 박스 넓이: 4 × 4 = 16
2. 교집합: x 1~4, y 0~4 → 3 × 4 = 12
3. 합집합: 16 + 16 − 12 = 20
4. IoU = 12 / 20 = 3/5 = 0.60
5. 0.5 이상이므로 「맞음」이다.

(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「5.1」의 평가 지표 — IoU = (예측 ∩ 정답) / (예측 ∪ 정답), 0.5 이상이면 「맞음」

### 실습 3. 파라미터 수 비교하기

**(가) 완전연결 대 3 × 3 필터**
1. 입력 숫자 수: 224 × 224 × 3 = 50,176 × 3 = 150,528
2. 뉴런 100 개에 모두 이으면: 150,528 × 100 = 15,052,800 — 장 본문의 「1500만 파라미터」와 맞는다.
3. 3 × 3 필터 하나: 3 × 3 = 9
4. 차이: 15,052,800 ÷ 9 = 1,672,533.3… → 약 167 만 배

**(나) 5 × 5 하나 대 3 × 3 두 개**
