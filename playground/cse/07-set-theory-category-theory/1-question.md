## 실습

### 실습 1. 세 원소 집합의 멱집합과 「목록에 없는 부분집합」
**문제** — `A = {1, 2, 3}` 이다.
멱집합 `P(A)` 의 원소를 모두 적고 크기를 센다.
이어서 함수 `f: A → P(A)` 가 `f(1) = {1, 2}`, `f(2) = ∅`, `f(3) = {1, 3}` 으로 주어졌을 때, 분리 공리 꼴의 집합 `D = {x ∈ A | x ∉ f(x)}` 를 구한다.
**요구 조건**
1. `P(A)` 의 원소 전부와 `|P(A)|` 를 적는다.
2. `|A|` 와 `|P(A)|` 를 비교해 칸토어 정리 `|A| < |P(A)|` 와 맞는지 적는다.
3. `D` 를 원소마다 판정하는 과정으로 구한다.
4. `D` 가 `f(1)`, `f(2)`, `f(3)` 중 어느 것과도 같지 않음을 확인하고, 대각선 논법의 어떤 생각과 같은지 한 줄로 적는다.

### 실습 2. 정수에 번호 매기기
**문제** — 장 본문 3.2 는 정수 `ℤ` 를 `0, 1, -1, 2, -2, 3, -3, …` 의 차례로 번호 매긴다.
첫 항의 번호를 1 로 한다.
**요구 조건**
1. 번호 1 부터 10 까지 어떤 정수가 오는지 표로 적는다.
2. 정수 `-3` 의 번호와, 번호 10 에 오는 정수를 적는다.
3. 정수 `n` 의 번호를 `n > 0` 일 때와 `n ≤ 0` 일 때로 나눈 식으로 적고, 2번의 두 값으로 검산한다.
4. 이 번호 매김이 왜 전단사인지(빠짐없이 · 겹침없이) 한두 줄로 적고, `|ℤ|` 가 무엇인지 결론을 적는다.

### 실습 3. List 함자의 법칙을 손으로 검증하기
**문제** — List 함자에서 `fmap` 은 리스트의 각 원소에 함수를 적용한다.
`f = (+1)`, `g = (*2)`, 입력 리스트는 `[1, 2, 3]` 이다.
**요구 조건**
1. 합성 보존 `F(g ∘ f) = F(g) ∘ F(f)` 의 양변, 곧 `fmap (g ∘ f) [1, 2, 3]` 과 `fmap g (fmap f [1, 2, 3])` 을 각각 계산한다.
2. 순서를 바꾼 `fmap (f ∘ g) [1, 2, 3]` 도 계산해 1번 결과와 같은지 비교한다.
3. 항등 보존 `F(id) = id` 를 `fmap id [1, 2, 3]` 으로 확인한다.
