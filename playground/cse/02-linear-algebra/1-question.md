## 실습

### 실습 1. 같은 연립방정식을 두 길로 풀기

**문제** — 연립방정식 `x + 2y = 5`, `3x + 4y = 11` 을 `Ax = b` 꼴로 쓰고, 가우스 소거법과 2×2 역행렬 공식으로 각각 푼다.

**요구 조건**
1. 행렬 `A` 와 벡터 `b` 를 적는다.
2. `det(A)` 를 구하고, 해가 하나뿐인지 판정한다.
3. 첨가행렬 `[A | b]` 에 행 연산을 써서 사다리꼴로 만들고 역대입으로 `x`, `y` 를 구한다.
4. `A⁻¹ = (1/det(A))·[d, -b; -c, a]` 로 `A⁻¹` 를 구하고 `A⁻¹b` 를 계산해 3번과 같은지 확인한다.

### 실습 2. 대각화로 행렬의 세제곱 구하기

**문제** — `A = [3, 1; 0, 1]` 을 대각화하고 `A³` 를 구한다.

**요구 조건**
1. 특성방정식으로 고유값 둘을 구한다.
2. 각 고유값의 고유벡터를 하나씩 구한다.
3. `P`, `D`, `P⁻¹` 를 적는다.
4. `A³ = PD³P⁻¹` 로 계산하고, `A·A·A` 를 직접 곱한 결과와 비교한다.

### 실습 3. 그람-슈미트로 정규직교 기저를 만들고 좌표 구하기

**문제** — `v₁ = (1, 1)`, `v₂ = (1, 0)` 에서 정규직교 기저 `{e₁, e₂}` 를 만들고, 벡터 `w = (3, 1)` 의 그 기저에 대한 좌표를 구한다.

**요구 조건**
1. `u₁ = v₁`, `u₂ = v₂ - [(v₂·u₁)/(u₁·u₁)]·u₁` 로 `u₂` 를 구하고, `u₁ · u₂ = 0` 인지 확인한다.
2. `u₁`, `u₂` 를 각자의 L2 노름으로 나눠 `e₁`, `e₂` 를 만든다.
3. `cᵢ = w · eᵢ` 로 좌표 `c₁`, `c₂` 를 구한다.
4. `c₁e₁ + c₂e₂` 가 `w` 로 돌아오는지 확인한다.
