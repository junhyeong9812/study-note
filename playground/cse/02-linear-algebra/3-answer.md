## 퀴즈 정답

### 1. 선형이 아니다 — 가산성도 동차성도 깨진다

가산성을 확인하면 `T(u + v) = 2u + 2v + 1` 이고 `T(u) + T(v) = 2u + 2v + 2` 다.
둘이 다르므로 가산성이 깨진다.
동차성에 `c = 0` 을 넣으면 `T(0) = 0·T(u) = 0` 이어야 하는데, `T(0) = 1` 이다.
그래프가 직선이어도 원점을 지나지 않으면(상수항 `+1` 이 있으면) 선형의 정의를 만족하지 못한다.
「선형」은 그래프 모양이 아니라 `T(c₁u + c₂v) = c₁T(u) + c₂T(v)` 라는 성질로 정의되기 때문이다.

근거: 2-summary 「1.1 "선형"이란 무엇인가」. `T(0) = 0` 이라는 귀결은 동차성에 `c = 0` 을 넣어 끌어낸 것이다 (원본에 근거 없음 — 추론).

### 2. `u · v = 0` 이라 직교하고, `u · w = -10` 이라 정반대 방향이다

`u · v = 1·2 + 2·(-1) = 0` 이다.
내적이 0이면 `cos(θ) = 0`, 곧 `θ = 90°` 이므로 `u` 와 `v` 는 직교한다.
`u · w = 1·(-2) + 2·(-4) = -10` 이다.
`‖u‖ = √5`, `‖w‖ = √20 = 2√5` 이므로 `cos(θ) = -10 / (√5 · 2√5) = -10/10 = -1` 이다.
코사인 유사도가 -1이면 `θ = 180°` 로 정반대 방향이다(실제로 `w = -2u` 다).

근거: 2-summary 「2.3 내적」의 `u · v = ‖u‖‖v‖cos(θ)` 와 코사인 유사도 공식.

### 3. L2 = 5, L1 = 7, L∞ = 4 — L1 의 마름모 꼭짓점이 축 위에 있다

L2 노름은 `√(3² + (-4)²) = √25 = 5` 다.
L1 노름은 `|3| + |-4| = 7` 이다.
L∞ 노름은 `max(|3|, |-4|) = 4` 다.
L1 정규화가 0을 만드는 까닭은 L1 의 등고선이 마름모라서 꼭짓점(축 위)에서 만나기 쉽기 때문이다.
축 위의 점은 어떤 성분이 0인 점이므로 가중치가 0이 된다.
L2 의 등고선은 원이라 축 위에서 만날 특별한 까닭이 없다.

근거: 2-summary 「2.4 노름」.

### 4. `A = [2, -1; 1, 3]`, `T(1, 1) = (1, 4)`, `T(2, -1) = (5, -1)`

행렬의 각 열은 각 단위벡터가 가는 곳이다.
그래서 `T(1,0) = (2, 1)` 이 첫 열, `T(0,1) = (-1, 3)` 이 둘째 열이 되어 `A = [2, -1; 1, 3]` 이다.
선형성으로 `T(1, 1) = T(1,0) + T(0,1) = (2, 1) + (-1, 3) = (1, 4)` 다.
`T(2, -1) = 2·(2, 1) - 1·(-1, 3) = (4, 2) + (1, -3) = (5, -1)` 이다.
행렬 곱으로 확인하면 1행은 `2·2 + (-1)·(-1) = 5`, 2행은 `1·2 + 3·(-1) = -1` 로 같다.

근거: 2-summary 「3.1 행렬의 진짜 정체」. 단위벡터에 대한 결과만 알면 모든 벡터의 결과를 안다.

### 5. 행렬 곱은 변환의 합성이라 순서가 결과를 바꾼다

행렬 곱은 「변환을 차례로 하는 것」이다.
`AB` 는 「먼저 `B`, 그다음 `A`」이고 `BA` 는 그 반대 순서다.
양말을 신고 신발을 신는 것과 신발을 신고 양말을 신는 것이 다르듯, 순서가 중요한 작업은 교환할 수 없다.
반면 세 변환을 차례로 한 최종 결과는 괄호를 어디에 치든 하나다.
「양말 → 신발 → 코트」를 어떻게 묶어도 마지막 모습이 같으므로 `(AB)C = A(BC)` 다.

근거: 2-summary 「3.2 행렬 곱셈 — 왜 AB ≠ BA인가」.

### 6. `u · v = uᵀv` 이고, `(AB)ᵀ = BᵀAᵀ` 로 순서가 뒤집힌다

열벡터 `u` 를 전치하면 행벡터 `uᵀ` 가 된다.
`uᵀv = u₁v₁ + u₂v₂ + u₃v₃` 이므로 내적은 `uᵀv` 라는 행렬 곱이다.
`(AB)ᵀ = BᵀAᵀ` 로 순서가 뒤집힌다.
양말을 신고 신발을 신은 것을 되돌리려면 신발을 먼저 벗고 양말을 벗어야 한다.
「합성을 되돌리면 순서가 거꾸로 된다」는 같은 원리가 전치에도 적용된다.

근거: 2-summary 「3.3 전치」.

### 7. 양변에 같은 연산을 하면 해가 그대로다 — 세 경우는 한 점 · 겹침 · 평행

방정식의 양변에 같은 수를 더하거나 같은 수를 곱해도 해는 변하지 않는다.
가우스 소거법은 이 원리를 체계적으로 되풀이해 변수를 하나씩 없애 사다리꼴로 만든 뒤 역대입하는 것이다.
해의 세 경우는 다음과 같다.
- 유일한 해: 두 직선이 한 점에서 만난다.
- 무수히 많은 해: 두 직선이 완전히 겹친다(실질적으로 같은 식).
- 해 없음: 두 직선이 평행해 만나지 않는다(모순).

근거: 2-summary 「4.2 가우스 소거법」 · 「4.3 해의 존재와 유일성」.

### 8. `det(A) = 4`, `det(B) = -1`, `det(AB) = -4`

`det(A) = 3·2 - 1·2 = 4` 다.
`A` 는 넓이를 4배로 늘린다.
`det(B) = 0·0 - 1·1 = -1` 이다.
`B` 는 넓이를 그대로 두지만 방향을 뒤집는다(거울 반사).
`det(AB) = det(A)·det(B) = 4·(-1) = -4` 다.
합성은 넓이를 4배로 늘리면서 방향을 뒤집는다.

근거: 2-summary 「5.1 행렬식의 기하학적 의미」 · 「5.2 2×2 행렬식」 · 「5.3 행렬식의 성질」의 `det(AB) = det(A)·det(B)`. (직접 계산한 값 — 실행하지 않음)

### 9. nullity 는 2이고, 랭크는 4가 될 수 없다

rank-nullity 정리에서 `n` 은 열의 수다.
`rank(A) + nullity(A) = 5` 이므로 `nullity(A) = 5 - 3 = 2` 다.
5차원 입력 가운데 3차원만 살아남고 2차원은 0으로 찌그러진다.
랭크는 독립인 열의 최대 개수이면서 독립인 행의 최대 개수와 같다.
행이 3개뿐이므로 랭크는 3을 넘을 수 없다.

근거: 2-summary 「6.4 랭크」. 「행이 3개라 랭크 ≤ 3」은 열 랭크 = 행 랭크에서 끌어낸 것이다 (원본에 근거 없음 — 추론).

### 10. 원소가 1000 안팎으로 커져 수치가 불안정해진다 — 고유값 0은 있을 수 없다

`det(A) = 1·1.001 - 1·1 = 0.001` 이다.
`A⁻¹ = (1/0.001)·[1.001, -1; -1, 1] = [1001, -1000; -1000, 1000]` 이다.
`det(A)` 가 작을수록 `A⁻¹` 의 원소가 커져 수치적으로 불안정하다.
실무에서 역행렬을 직접 구하지 않고 LU 분해 · QR 분해 · 반복법을 쓰는 까닭 가운데 하나다.
핵심 정리에서 「`det(A) ≠ 0`」과 「고유값 중 0이 없다」는 동치다.
그래서 `det(A) ≠ 0` 인 행렬에는 고유값 0이 있을 수 없다.

근거: 2-summary 「7.2 2×2 역행렬」 · 「12. 선형대수의 핵심 정리」. (직접 계산한 값 — 실행하지 않음)

### 11. 고유값은 4와 2 — 고유벡터는 `(1, 0)` 방향과 `(1, -2)` 방향

`det(A - λI) = (4 - λ)(2 - λ) - 1·0 = 0` 이므로 `λ = 4` 또는 `λ = 2` 다.
`λ = 4` 이면 `A - 4I = [0, 1; 0, -2]` 이다.
두 행 모두 `y = 0` 을 요구하므로 고유벡터는 `c(1, 0)` 이다.
`λ = 2` 이면 `A - 2I = [2, 1; 0, 0]` 이다.
`2x + y = 0` 이므로 고유벡터는 `c(1, -2)` 다.
확인하면 `A(1, -2) = (4 - 2, -4) = (2, -4) = 2·(1, -2)` 다.

근거: 2-summary 「8.2 고유값을 찾는 법」 (본문의 `[2, 1; 0, 3]` 예와 같은 절차). (직접 계산한 값 — 실행하지 않음)

### 12. `A^k = PD^kP⁻¹` — 대각행렬만 거듭제곱하면 된다

`A^k = PDP⁻¹·PDP⁻¹·…` 에서 가운데 `P⁻¹P` 가 `I` 로 사라져 `A^k = PD^kP⁻¹` 가 된다.
`D^k = diag(λ₁^k, …, λₙ^k)` 라서 대각 원소만 거듭제곱하면 된다.
그래서 비용이 `O(n³·k)` 에서 `O(n³)` 로 줄어 `k` 에 무관해진다.
PageRank 는 거대한 링크 행렬을 거듭제곱했을 때 수렴하는 벡터, 곧 주요 고유벡터를 「중요한 페이지」로 본다.
마르코프 체인의 정상 분포는 전이 행렬의 고유값 1에 대응하는 고유벡터다.

근거: 2-summary 「8.3 대각화」. `P⁻¹P` 가 지워지는 전개는 정의에서 끌어낸 것이다 (원본에 근거 없음 — 추론).

### 13. 정규직교면 좌표 = 내적 한 번이고, 투영을 빼면 그 방향 성분이 0이 된다

정규직교 기저는 서로 직교하고 크기가 모두 1이다.
`v = c₁e₁ + c₂e₂` 에 `e₁` 을 내적하면 `e₁ · e₂ = 0`, `e₁ · e₁ = 1` 이라 `c₁ = v · e₁` 만 남는다.
그래서 정규직교 기저에서는 내적 한 번으로 좌표가 나온다.
정규직교가 아니면 연립방정식을 풀어야 좌표를 구할 수 있다.
투영은 한 방향의 성분만 뽑아내는 것이다.
원래 벡터에서 `u₁` 방향 투영을 빼면 `u₁` 방향 성분이 0이 되고, 남은 벡터는 `u₁` 에 수직이다.

근거: 2-summary 「9.1 직교란」 · 「9.2 그람-슈미트 과정」.

### 14. SVD 는 언제나 되고, 압축은 약 10만 개, 제1주성분은 고유값이 가장 큰 고유벡터

대각화는 정사각 행렬이면서 선형독립인 고유벡터가 `n` 개일 때만 된다.
SVD 는 직사각이든 정사각이든 어떤 행렬에든 언제나 된다.
SVD 는 어떤 선형 변환이든 「회전 → 늘림 → 회전」으로 나눈다.
상위 50개 특이값만 남기면 `50 × (1000 + 1000 + 1) ≈ 10만` 개를 저장한다.
원래 100만 개와 견주면 약 10배 압축이다.
PCA 의 제1주성분은 공분산 행렬의 고유값 `λ` 가 가장 큰 고유벡터다.
`vᵀCv = λ` 가 그 방향으로 투영한 분산이고, 그 값이 가장 큰 방향이 데이터가 가장 많이 퍼진 방향이다.

근거: 2-summary 「10.1 SVD란」 · 「10.2 저랭크 근사」 · 「11.1 PCA란」.

## 실습 정답

### 실습 1. 같은 연립방정식을 두 길로 풀기

**1단계 — 행렬 꼴**
`A = [1, 2; 3, 4]`, `b = (5, 11)` 이다.

**2단계 — 행렬식**
`det(A) = 1·4 - 2·3 = 4 - 6 = -2` 다.
0이 아니므로 역행렬이 있고, 해는 하나뿐이다.

**3단계 — 가우스 소거법**

```text
[ 1  2 |  5 ]   2행 - 3×1행   [ 1  2 |  5 ]   2행 ÷ (-2)   [ 1  2 | 5 ]
[ 3  4 | 11 ]  ───────────→  [ 0 -2 | -4 ]  ──────────→  [ 0  1 | 2 ]
```

`y = 2` 다.
역대입하면 `x + 2·2 = 5` 이므로 `x = 1` 이다.

**4단계 — 역행렬 공식**
`A⁻¹ = (1/-2)·[4, -2; -3, 1]` 이다.
`[4, -2; -3, 1]·(5, 11) = (20 - 22, -15 + 11) = (-2, -4)` 다.
`(1/-2)·(-2, -4) = (1, 2)` 다.
가우스 소거법의 결과 `x = 1`, `y = 2` 와 같다.

기대는 절: 「4.1 왜 연립방정식이 행렬과 관련되는가」 · 「4.2 가우스 소거법」 · 「5.2 2×2 행렬식」 · 「7.2 2×2 역행렬」.

### 실습 2. 대각화로 행렬의 세제곱 구하기

**1단계 — 고유값**
`det(A - λI) = (3 - λ)(1 - λ) - 1·0 = 0` 이므로 `λ₁ = 3`, `λ₂ = 1` 이다.

**2단계 — 고유벡터**
`λ = 3` 이면 `A - 3I = [0, 1; 0, -2]` 이고 `y = 0` 이므로 `v₁ = (1, 0)` 이다.
`λ = 1` 이면 `A - I = [2, 1; 0, 0]` 이고 `2x + y = 0` 이므로 `v₂ = (1, -2)` 다.

**3단계 — P, D, P⁻¹**
`P = [1, 1; 0, -2]`, `D = diag(3, 1)` 이다.
`det(P) = 1·(-2) - 1·0 = -2` 다.
`P⁻¹ = (1/-2)·[-2, -1; 0, 1] = [1, 1/2; 0, -1/2]` 다.

**4단계 — A³**
`D³ = diag(27, 1)` 이다.
`PD³ = [1·27, 1·1; 0·27, -2·1] = [27, 1; 0, -2]` 다.
`PD³P⁻¹` 의 1행은 `[27·1 + 1·0, 27·(1/2) + 1·(-1/2)] = [27, 13]` 이다.
2행은 `[0·1 + (-2)·0, 0·(1/2) + (-2)·(-1/2)] = [0, 1]` 이다.
그래서 `A³ = [27, 13; 0, 1]` 이다.

**직접 곱해 확인**
`A² = [3, 1; 0, 1]·[3, 1; 0, 1] = [9, 4; 0, 1]` 이다.
`A³ = [9, 4; 0, 1]·[3, 1; 0, 1] = [27, 13; 0, 1]` 이다.
두 결과가 같다.

기대는 절: 「8.2 고유값을 찾는 법」 · 「8.3 대각화」 · 「7.2 2×2 역행렬」.
(직접 계산한 값 — 실행하지 않음)

### 실습 3. 그람-슈미트로 정규직교 기저를 만들고 좌표 구하기

**1단계 — 직교화**
`u₁ = (1, 1)` 이다.
`v₂ · u₁ = 1·1 + 0·1 = 1`, `u₁ · u₁ = 2` 이므로 투영은 `(1/2)·(1, 1) = (0.5, 0.5)` 다.
`u₂ = (1, 0) - (0.5, 0.5) = (0.5, -0.5)` 다.
`u₁ · u₂ = 0.5 - 0.5 = 0` 이라 직교한다.

**2단계 — 정규화**
`‖u₁‖ = √2` 이므로 `e₁ = (1/√2, 1/√2)` 다.
`‖u₂‖ = √(0.25 + 0.25) = √0.5 = 1/√2` 이므로 `e₂ = (0.5·√2, -0.5·√2) = (1/√2, -1/√2)` 다.

**3단계 — 좌표**
`c₁ = w · e₁ = (3 + 1)/√2 = 4/√2 = 2√2` 다.
`c₂ = w · e₂ = (3 - 1)/√2 = 2/√2 = √2` 다.

**4단계 — 되돌려 확인**
`c₁e₁ = 2√2·(1/√2, 1/√2) = (2, 2)` 다.
`c₂e₂ = √2·(1/√2, -1/√2) = (1, -1)` 다.
더하면 `(3, 1) = w` 다.

기대는 절: 「2.4 노름」 · 「9.1 직교란」 · 「9.2 그람-슈미트 과정」.
(직접 계산한 값 — 실행하지 않음)
