## 퀴즈 정답

### 1. 전단사 원리 — 원소마다 「포함 1 / 불포함 0」

전단사 원리 덕분이다.
두 집합 사이에 전단사가 있으면 크기가 같고, 한쪽을 훑으면 다른 쪽도 빠짐없이 한 번씩 훑게 된다.
각 원소를 비트 하나에 대응시켜 포함하면 1, 빼면 0 으로 적으면 부분집합 하나가 n비트 문자열 하나와 정확히 짝지어진다.
n비트 문자열은 0 부터 `2ⁿ - 1` 까지의 정수와 같으므로 정수를 순회하면 모든 부분집합을 순회하게 된다.

근거: 장 본문 「2.2 전단사 원리」의 예시와 「🔵 CS 연결 — 비트마스크」.

### 2. 이중 계산 — 간선 하나가 차수 두 개를 만든다

같은 양(간선 끝점의 총수)을 두 방법으로 세었기 때문이다.
정점 쪽에서 세면 각 정점의 차수를 더한 `Σ deg(v)` 가 된다.
간선 쪽에서 세면 간선 하나는 양 끝 두 정점에 하나씩 기여하므로 `2|E|` 가 된다.
세는 대상이 하나이니 두 결과는 같아야 하고, 그래서 `Σ deg(v) = 2|E|` 다.

근거: 장 본문 「2.3 이중 계산」.

### 3. 24가지

원순열의 수는 `(n-1)!` 이다.
5명을 일렬로 세우는 `5! = 120` 가지 가운데, 원형에서는 한 배치를 5번 회전한 것이 모두 같으므로 5로 나눈다.
`5!/5 = 4! = 24`.
한 명을 고정하고 나머지 4명을 배열한다고 봐도 `4! = 24` 다.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「3.1 순열 — 원순열」.

### 4. 60개

같은 것이 있는 순열 공식 `n! / (n₁! · n₂! · … · nₖ!)` 을 쓴다.
"BANANA" 는 6글자이고 B 1개, A 3개, N 2개다.
`6! / (1! · 3! · 2!) = 720 / (1 · 6 · 2) = 720 / 12 = 60`.
같은 A 끼리, 같은 N 끼리 자리를 바꿔도 구별되지 않으므로 그 교환 수만큼 나누는 것이다.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「3.1 순열 — 같은 것이 있는 순열」(MISSISSIPPI 예와 같은 방법).

### 5. 특정 원소 x 를 넣느냐 빼느냐로 나눈다

n개에서 k개를 고르는 방법을 원소 x 를 기준으로 두 무리로 가른다.
x 를 포함하면 남은 n-1개에서 k-1개를 더 고르므로 `C(n-1, k-1)` 가지다.
x 를 포함하지 않으면 남은 n-1개에서 k개를 모두 고르므로 `C(n-1, k)` 가지다.
두 경우는 겹치지 않으므로 합의 법칙으로 더한다.
이것이 파스칼 삼각형에서 「각 수 = 바로 위 두 수의 합」인 원리다.

근거: 장 본문 「3.2 조합 심화 — 파스칼 항등식」.

### 6. 8개

`x = 1`, `y = -1` 을 넣으면 `Σ (-1)ᵏ C(4, k) = (1 + (-1))⁴ = 0` 이다.
풀어 쓰면 `1 - 4 + 6 - 4 + 1 = 0` 이다.
즉 (짝수 크기 부분집합 수) − (홀수 크기 부분집합 수) = 0 이라 둘은 같다.
`x = 1`, `y = 1` 을 넣으면 전체 부분집합 수는 `2⁴ = 16` 이다.
따라서 짝수 크기 부분집합은 `16 / 2 = 8` 개다.
직접 더해도 `C(4,0) + C(4,2) + C(4,4) = 1 + 6 + 1 = 8` 이다.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「4. 이항 정리 — 유용한 특수한 경우들」.

### 7. 세 겹 교집합의 원소가 0번으로 세어졌기 때문이다

`A∩B∩C` 에 든 원소는 `|A| + |B| + |C|` 에서 3번 더해진다.
두 겹 교집합 세 개를 빼면서 3번 빠진다.
그러면 `3 - 3 = 0` 번 세어진 셈이 되어 아예 빠져 버린다.
한 번은 세어야 하므로 `|A∩B∩C|` 를 다시 한 번 더해 `3 - 3 + 1 = 1` 로 맞춘다.
일반적으로 m개 집합에 속한 원소는 `C(m,1) - C(m,2) + C(m,3) - … = 1` 이 되어 정확히 한 번 세어진다.

근거: 장 본문 「5.1 왜 포함-배제가 필요한가」 · 「5.2 일반적 포함-배제」.

### 8. 9가지 — 확률 9/24 = 0.375 로 1/e ≈ 0.368 에 가깝다

공식 `Dₙ = n! · Σ_{k=0}^{n} (-1)ᵏ / k!` 에 `n = 4` 를 넣는다.

```text
D₄ = 24 · (1 - 1/1! + 1/2! - 1/3! + 1/4!)
   = 24 - 24 + 12 - 4 + 1
   = 9
```

전체 순열은 `4! = 24` 이므로 교란일 확률은 `9 / 24 = 0.375` 다.
`1/e ≈ 0.368`(36.8%)과 차이가 약 0.007 이라, 네 개만 섞어도 이미 `1/e` 에 꽤 가깝다.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「5.3 교란」의 공식 · 유도와 「🔵 CS 연결 — 랜덤 셔플이 완전한 교란일 확률 ≈ 1/e」.

### 9. 쓸 수 없다 — `(A + Bn)·rⁿ` 꼴로 바뀐다

`A·r₁ⁿ + B·r₂ⁿ` 은 서로 다른 두 근이 있을 때의 꼴이다.
근이 하나로 겹치면 `A·rⁿ + B·rⁿ` 은 사실상 `(A+B)·rⁿ` 하나라, 상수 하나로 초기 조건 두 개를 맞출 수 없다.
그래서 중근일 때는 `aₙ = (A + Bn)·rⁿ` 꼴을 쓰고, `A`, `B` 를 초기 조건으로 정한다.

근거: 장 본문 「6.2 선형 점화식 풀이 — 특성방정식」. (상수 하나로 두 조건을 맞출 수 없다는 설명은 원본에 근거 없음 — 추론)

### 10. 대수 방정식으로 바뀐다 — `1/(1-x)` 는 기하급수 공식이다

`Fₙ = Fₙ₋₁ + Fₙ₋₂` 를 생성함수에 넣으면 `G(x) = x + x·G(x) + x²·G(x)` 가 된다.
이것은 `G(x)` 에 대한 일차 대수 방정식이고, 풀면 `G(x) = x / (1 - x - x²)` 다.
그 뒤 부분분수 분해 → 계수 추출로 `Fₙ = (φⁿ - ψⁿ)/√5` 에 이른다.
`1/(1-x) = 1 + x + x² + …` 는 Ch.01 의 기하급수 공식 `Σ xⁿ = 1/(1-x)` (`|x| < 1`)이며, 수열 `(1, 1, 1, …)` 을 생성한다.

근거: 장 본문 「7.1 생성함수란」 · 「7.2 생성함수로 점화식 풀기」.

### 11. 14개

n쌍의 올바른 괄호 배열 수는 카탈란 수 `Cₙ` 이다.
공식으로: `C₄ = C(8, 4) / (4 + 1) = 70 / 5 = 14`.
점화식으로도 확인한다: `C₄ = C₀C₃ + C₁C₂ + C₂C₁ + C₃C₀ = 5 + 2 + 2 + 5 = 14`.
처음 몇 항 `1, 1, 2, 5, 14, 42` 의 다섯째 항과 같다.
(직접 계산한 값 — 실행하지 않음)

### 12. 둘 다 「재귀적으로 두 부분으로 나누는 구조」다

괄호 배열은 첫 `(` 와 짝이 되는 `)` 를 기준으로 안쪽(왼쪽)과 바깥쪽(오른쪽)으로 갈라진다.
이진 트리는 루트를 기준으로 왼쪽 서브트리와 오른쪽 서브트리로 갈라진다.
두 분할 모두 남은 크기를 i 와 n-1-i 로 나누므로 같은 점화식 `Cₙ = Σ Cᵢ·Cₙ₋₁₋ᵢ` 를 만든다.
구조가 같으니 전단사 원리에 따라 수도 같다.
그래서 BST 형태 수, 행렬 체인 곱셈의 괄호 치는 방법 수, 파싱 트리 형태 수도 카탈란 수로 세어진다.

근거: 장 본문 「8.1 카탈란 수란 — 왜 이것들이 같은 수인가」 · 「🔵 CS 연결」 · 「2.2 전단사 원리」.

### 13. `μ(12) = 0`, `μ(30) = -1` — 소수의 제곱을 인수로 가지면 0

`12 = 2² · 3` 은 소수의 제곱 `4` 를 인수로 가지므로 `μ(12) = 0` 이다.
`30 = 2 · 3 · 5` 는 서로 다른 소수 3개의 곱이므로 `μ(30) = (-1)³ = -1` 이다.
정리하면 `μ` 는 `μ(1) = 1`, 서로 다른 소수 k개의 곱이면 `(-1)ᵏ`, 어떤 소수의 제곱으로 나누어떨어지면 0 이다.

근거: 장 본문 「9. 뫼비우스 반전」의 `μ(n)` 정의.


## 실습 정답

### 실습 1. 1부터 100까지에서 2·3·5 중 하나로 나누어지는 수 세기

**1단계 — 한 집합씩**
`|A|` = 100 이하 2의 배수 = 50.
`|B|` = 100 이하 3의 배수 = 33 (3·33 = 99).
`|C|` = 100 이하 5의 배수 = 20.

**2단계 — 교집합**
`|A∩B|` = 6의 배수 = 16 (6·16 = 96).
`|A∩C|` = 10의 배수 = 10.
`|B∩C|` = 15의 배수 = 6 (15·6 = 90).
`|A∩B∩C|` = 30의 배수 = 3 (30, 60, 90).

**3단계 — 포함-배제**

```text
|A ∪ B ∪ C| = (50 + 33 + 20) - (16 + 10 + 6) + 3
            = 103 - 32 + 3
            = 74
```

답: 74개.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「5.1 왜 포함-배제가 필요한가」의 세 집합 공식.
두 겹 교집합을 빼지 않으면 6의 배수 등이 두 번 세어지고, 30의 배수는 마지막 덧셈이 없으면 0번 세어진다.

### 실습 2. 세 가지 색으로 칠한 정삼각형 꼭짓점 (회전만 같게 본다)

**1단계 — 전체 칠하기**
꼭짓점 셋에 각각 3가지 색을 독립으로 고르므로 곱의 법칙으로 `3³ = 27` 이다.

**2단계 — 원소별 고정점**
대칭군 `G` = {항등, 120°, 240°} 이므로 `|G| = 3` 이다.
`Fix(항등) = 27` — 아무것도 움직이지 않으니 모든 칠하기가 고정된다.
`Fix(120°) = 3` — 세 꼭짓점이 한 바퀴 돌며 서로 자리를 바꾸므로 셋이 모두 같은 색이어야 한다.
`Fix(240°) = 3` — 같은 이유다.

**3단계 — 번사이드**

```text
|X/G| = (27 + 3 + 3) / 3 = 33 / 3 = 11
```

답: 11가지.
검산으로 직접 나눠 세면 한 색만 쓴 것 3 + 두 색(2개·1개) 쓴 것 3·2 = 6 + 세 색 모두 쓴 것 2 = 11 로 같다.
(직접 계산한 값 — 실행하지 않음)

### 실습 3. 특성방정식으로 점화식의 닫힌 형태 구하기

**1단계 — 특성방정식**
`aₙ = rⁿ` 을 넣으면 `r² = 5r - 6`, 곧 `r² - 5r + 6 = 0` 이다.
인수분해하면 `(r - 2)(r - 3) = 0` 이라 근은 `r₁ = 2`, `r₂ = 3` (서로 다른 근)이다.

**2단계 — 일반해와 상수**
서로 다른 근이므로 `aₙ = A·2ⁿ + B·3ⁿ` 이다.
`a₀ = 1` → `A + B = 1`.
`a₁ = 4` → `2A + 3B = 4`.
첫 식에 2를 곱해 빼면 `B = 2`, 따라서 `A = -1` 이다.

```text
aₙ = 2·3ⁿ - 2ⁿ
```

**3단계 — 확인**

```text
점화식:  a₂ = 5·4 - 6·1 = 14      닫힌 형태: 2·9 - 4 = 14
점화식:  a₃ = 5·14 - 6·4 = 46     닫힌 형태: 2·27 - 8 = 46
```

두 값이 일치한다.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 「6.2 선형 점화식 풀이 — 특성방정식」(서로 다른 근의 일반해, 초기 조건으로 A·B 결정)과 같은 절의 피보나치 예.
`|3| > |2|` 이므로 n 이 커지면 `3ⁿ` 항이 성장을 좌우한다는 점도 피보나치에서 `φⁿ` 이 지배하는 것과 같은 구조다.
