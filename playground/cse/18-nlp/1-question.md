h u g     : 3

## 실습

### 실습 1. 작은 말뭉치로 BPE 두 번 돌리기

**문제** — 아래 말뭉치를 문자 단위로 쪼갠 상태에서 시작해 BPE 병합을 두 번 한다.

```text
c a t   : 4
c a r   : 3
b a t   : 2
```

**요구 조건**
1. 처음 상태에서 이웃한 문자 쌍마다 등장 횟수를 표로 센다.
2. 첫 병합으로 만들 토큰을 고르고, 병합 뒤 다시 쌍을 세어 두 번째 병합 토큰을 고른다.
3. 두 번 병합한 뒤 세 단어가 각각 어떤 토큰들로 쪼개지는지, 어휘(초기 문자 + 새 토큰)의 크기가 몇인지 적는다.

### 실습 2. 크로스 엔트로피와 Perplexity 오가기

**문제** — `PPL = 2^{H(P,Q)}` 를 써서 아래를 계산한다(H 의 단위는 비트).

**요구 조건**
1. 크로스 엔트로피가 2비트인 모델과 5비트인 모델의 Perplexity 를 각각 구한다.
2. Perplexity 가 16 인 모델의 크로스 엔트로피를 구한다.
3. Perplexity 8 인 모델 A 와 32 인 모델 B 가운데 어느 쪽이 나은지, 「평균 몇 가지 선택지에서 고민하나」라는 해석으로 한 줄 적는다.

### 실습 3. 손으로 하는 Scaled Dot-Product Attention

**문제** — `d_k = 4` 일 때 query 하나에 대해 attention 출력을 구한다.

```text
q  = [1, 1, 0, 0]
k1 = [2, 2, 0, 0]    v1 = [1, 0]
k2 = [0, 0, 1, 1]    v2 = [0, 1]
k3 = [1, 1, 0, 0]    v3 = [1, 1]
```

**요구 조건**
1. `q·k1`, `q·k2`, `q·k3` 을 구하고 `√d_k` 로 나눈다.
2. softmax 로 가중치 셋을 소수 셋째 자리까지 구한다(`e ≈ 2.718`, `e² ≈ 7.389`, `e⁴ ≈ 54.598`).
3. 가중치로 `v1`, `v2`, `v3` 을 가중 합산해 출력 벡터를 구한다.
4. `√d_k` 로 나누지 않았을 때의 가중치도 구해, 어느 쪽이 원핫에 더 가까운지 적는다.
