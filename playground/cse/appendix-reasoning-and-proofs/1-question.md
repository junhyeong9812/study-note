## 실습

### 실습 1. 대우로 「n³ 이 짝수이면 n 도 짝수」 증명하기

**문제** — 정수 n 에 대해 「n³ 이 짝수이면 n 도 짝수이다」를 증명한다.
직접 증명은 n³ = 2k 에서 n 을 바로 구하기 어렵다.

**요구 조건**
1. 원래 명제의 대우를 한 문장으로 적는다.
2. 대우의 가정을 n = 2k + 1 꼴로 쓰고, n³ 을 전개해 `2(정수) + 1` 꼴로 정리한다.
3. 대우가 참이면 왜 원래 명제도 참인지 한 줄로 적고, 끝에 □ 를 붙인다.
4. 검산으로 n = 3 일 때 n³ 이 홀수인지 계산해 적는다.

### 실습 2. 수학적 귀납법으로 합 공식 증명하기

**문제** — 모든 자연수 n ≥ 1 에 대해 1 + 2 + … + n = n(n+1)/2 임을 수학적 귀납법으로 증명한다.

**요구 조건**
1. 명제 P(n) 을 적는다.
2. 기저 단계 P(1) 을 계산으로 확인한다.
3. 귀납 단계: P(k) 를 가정하고 P(k+1) 의 좌변을 정리해 (k+1)(k+2)/2 가 됨을 보인다.
4. 검산으로 n = 4 일 때 좌변과 우변을 각각 계산해 적는다.

### 실습 3. 비둘기집 원리로 같은 달 생일 찾기

**문제** — 한 반의 학생들 가운데 생일이 같은 달인 두 사람이 반드시 있으려면 학생이 최소 몇 명이어야 하는가.

**요구 조건**
1. 무엇이 「상자」이고 무엇이 「물건」인지 적는다.
2. 13명일 때 같은 달 생일인 두 사람이 반드시 있음을 비둘기집 원리로 보인다.
3. 12명일 때는 왜 보장되지 않는지 반례 배치 하나로 보인다.
4. 이 증명이 「어느 달인지」를 알려 주는지 적는다.
