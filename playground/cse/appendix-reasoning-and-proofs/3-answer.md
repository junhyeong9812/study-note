## 퀴즈 정답

### 1. 귀추다 — 확실성은 「추측적」이다

규칙(버그가 있으면 마지막 원소가 빠진다)과 결과(마지막 원소가 빠졌다)에서 사례(이 함수에 그 버그가 있다)를 끌어낸다.
장 본문의 정리대로 `규칙 + 결과 → 사례` 는 귀추다.
귀추는 「가장 그럴듯한」 설명을 고를 뿐이라 추측적이다 — 다른 버그가 같은 증상을 만들 수 있다.
형식만 떼어 보면 `p → q, q ∴ p` 로, §2.3 의 후건 긍정과 같은 꼴이라 연역적으로는 무효다.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 §1.4 「연역·귀납과의 관계」 · §1.5 표 · §2.3 (1).

### 2. 귀납적 주장이라 하나의 반례로 무너질 수 있다

통과한 사례(관찰)들에서 「버그가 없다」는 일반 원칙을 끌어내는 것이므로 과학적 귀납이다.
귀납은 개연적일 뿐이라, 1000마리 흰 백조가 검은 백조 하나로 무너지듯 101번째 입력에서 실패할 수 있다.
Dijkstra 의 말대로 테스팅은 버그의 존재는 보일 수 있지만 부재는 보일 수 없다.

근거: 장 본문 §1.3 「CS 연결 — 테스팅」 · §3.7.

### 3. 과학적 귀납이며, 과적합은 성급한 일반화와 같은 꼴이다

훈련 데이터(관찰)에서 일반 패턴(모델)을 학습하는 것은 귀납이다.
훈련 데이터에 없는 입력에서 실패할 수 있는 것이 귀납의 한계이고, 이것이 과적합이다.
훈련 데이터의 특성을 전체로 일반화하는 것은 「3명이 안경을 썼으니 모든 프로그래머가 안경을 쓴다」는 성급한 일반화와 같은 오류다.

근거: 장 본문 §1.3 「CS 연결 — 머신러닝」 · §2.3 (3).

### 4. 형식이 올바른가(유효성)와 전제가 실제로 참인가(건전성)가 갈린다

유효성은 형식의 문제다 — 전제가 참이었다면 결론도 반드시 참이 되는 구조인가.
이 논증은 「모든 A 는 B, 모든 B 는 C ∴ 모든 A 는 C」 꼴이라 유효하다.
건전성은 유효성에 더해 전제가 실제로 참이어야 한다.
「고양이는 파충류」라는 전제가 거짓이므로 건전하지 않고, 결론의 참도 보장되지 않는다.

근거: 장 본문 §2.1 · §1.2 「한계: 전제가 거짓이면 결론도 보장 못 함」.

### 5. (가) 무효 · (나) 유효 · (다) 유효 · (라) 무효

- (가) `p → q, q ∴ p` — 후건 긍정의 오류, 무효다. 빌드는 다른 이유로도 실패할 수 있다.
- (나) `p → q, ¬q ∴ ¬p` — 후건 부정(Modus Tollens), 유효하다.
- (다) `p ∨ q, ¬p ∴ q` — 선언적 삼단논법, 유효하다.
- (라) `p → q, ¬p ∴ ¬q` — 전건 부정의 오류, 무효다. 테스트 실패가 배포를 멈추는 유일한 원인이라는 가정이 없다.

(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 §2.2 (2)(4) · §2.3 (1)(2).

### 6. `p → q` 는 대우 `¬q → ¬p` 와 동치이기 때문이다

`p → q ≡ ¬q → ¬p` 이므로 첫 전제를 `¬q → ¬p` 로 바꿔 쓸 수 있다.
여기에 `¬q` 가 주어지면 전건 긍정(Modus Ponens)으로 `¬p` 가 나온다.
즉 후건 부정은 대우에 전건 긍정을 적용한 것이다.

근거: 장 본문 §2.2 (2) · §3.2.

### 7. 후건 긍정의 오류이며, 귀추가 확실하지 않은 까닭과 같다

「버그 → 증상, 증상 ∴ 버그」는 `p → q, q ∴ p` 꼴의 후건 긍정이다.
다른 버그도 같은 증상을 만들 수 있으므로 무효다.
디버깅은 결과에서 원인을 추측하는 귀추이고, 귀추가 「추측적」인 까닭이 바로 여러 원인이 같은 결과를 만들 수 있다는 데 있다.
그래서 귀추의 결론은 단정이 아니라 다른 증거와 종합해 고르는 「가장 그럴듯한 설명」이어야 한다.

근거: 장 본문 §2.3 (1) 「디버깅에서의 함정」 · §1.4.

### 8. 대우 쪽은 더 구체적인 가정에서 출발할 수 있기 때문이다

원래 가정 「n² 이 짝수」에서는 n² = 2k 를 얻어도 n 에 대해 아는 것이 적다.
대우 「n 이 홀수이면 n² 도 홀수」의 가정은 n = 2k + 1 로 구체적으로 쓸 수 있다.
그러면 n² = 2(2k² + 2k) + 1 로 바로 홀수임이 보인다.
대우와 원래 명제는 동치라 하나를 증명하면 다른 것도 증명된다.

근거: 장 본문 §3.2 「왜 대우가 더 쉬운 경우가 있는가」.

### 9. 「a/b 는 기약분수(gcd(a,b) = 1)」라는 가정과 「a, b 가 모두 짝수」라는 결과가 부딪친다

a² = 2b² 에서 a² 이 짝수 → (대우 증명의 결과로) a 가 짝수 → a = 2c 로 둔다.
대입하면 b² = 2c² 이라 b 도 짝수가 된다.
a 와 b 가 모두 짝수면 gcd(a,b) ≥ 2 인데, 처음에 기약분수라고 가정했으므로 모순이다.
부정 가정이 모순을 낳았으니 그 가정은 거짓이고, √2 는 무리수다.

근거: 장 본문 §3.3 예시 1.

### 10. P(k) → P(k+1) 을 모든 k 에 대해 증명하므로 연역이고, 정렬성 공리가 받친다

과학적 귀납은 관찰한 사례에서 일반화하지만, 수학적 귀납법은 기저 단계와 「모든 k 에 대한 P(k) → P(k+1)」을 증명한다.
관찰이 아니라 증명에서 결론이 나오므로 확실하다.
받치는 공리는 자연수의 정렬성 공리 — 비어 있지 않은 자연수 집합에는 최소 원소가 있다.
P(n) 이 거짓인 n 이 있다면 그 가운데 최소인 n 이 있다.
기저가 참이니 그 n 은 기저보다 크고, n 이 최소이니 P(n−1) 은 참이며, 귀납 단계로 P(n) 도 참이 되어 모순이다.

근거: 장 본문 §3.4 「주의」 · 「왜 이것이 유효한가」 · §1.3 「주의」.

### 11. 기저 = 크기 1 배열 · 귀납 단계 = 반으로 나눈 절반들에 귀납 가정을 적용

기저 단계: 크기 1 배열은 이미 정렬되어 있다.
귀납 단계: 크기 k 이하에서 올바르다고 가정하고, 크기 k+1 배열을 반으로 나누면 각 절반은 크기 ≤ k 다.
귀납 가정으로 각 절반이 올바르게 정렬되고, merge 가 두 정렬된 배열을 올바르게 합치면(별도 증명) 크기 k+1 에서도 올바르다.
재귀 호출의 종료 조건이 기저, 작은 문제로의 재귀 호출이 귀납 가정에 해당한다 — 두 구조가 정확히 일치한다.
덧붙여, 「크기 k 이하」 전부를 가정하므로 이 증명은 강한 귀납의 꼴이다.

근거: 장 본문 §3.4 「CS 연결」 · §3.5.

### 12. 15 = 3 · 5 를 다루려면 P(14) 가 아니라 P(3) 과 P(5) 가 필요하다

일반 귀납은 P(k) 하나, 여기서는 P(14) 만 가정한다.
그런데 15 가 합성수라 15 = 3 · 5 로 쪼개면 3 과 5 가 소수의 곱이라는 사실이 필요하다.
강한 귀납은 P(2), …, P(k) 를 모두 가정하므로 P(3) · P(5) 를 쓸 수 있고, 15 도 소수의 곱임이 따라 나온다.

근거: 장 본문 §3.5 「왜 일반 귀납으로는 안 되는가」.

### 13. 비구성적이다 — 구성적 증명은 Curry-Howard 대응으로 알고리즘이 된다

물건(약 1000만 명)이 상자(최대 약 150,000 가지 머리카락 수)보다 많으니 겹치는 상자가 존재한다는 것만 보인다.
누가 그 두 사람인지는 알려 주지 않으므로 비구성적 존재 증명이다.
반대로 구성적 증명은 대상을 실제로 만들어 보이므로, 그 증명 과정 자체가 해를 찾는 알고리즘이 된다.
이것이 Curry-Howard 대응(증명 ↔ 프로그램, 명제 ↔ 타입)으로 이어진다.

근거: 장 본문 §3.6 · §3.8.

### 14. 가장 작은 반례는 n = 2 이고, 반례는 하나면 충분하다

n = 1: 2¹ = 2, 1² = 1 → 2 > 1, 참.
n = 2: 2² = 4, 2² = 4 → 4 > 4, 거짓.
따라서 가장 작은 반례는 n = 2 다(n = 3 에서도 8 > 9 가 거짓이다).
「모든 n」에 대한 주장은 예외가 하나라도 있으면 거짓이므로 반례 하나로 반증이 끝난다.
(직접 계산한 값 — 실행하지 않음)

근거: 장 본문 §3.7.

## 실습 정답

### 실습 1. 대우로 「n³ 이 짝수이면 n 도 짝수」 증명하기

1. 대우: 「n 이 홀수이면 n³ 도 홀수이다.」
2. n = 2k + 1 (k 는 정수)로 둔다.
   n³ = (2k+1)³ = 8k³ + 12k² + 6k + 1 = 2(4k³ + 6k² + 3k) + 1.
   4k³ + 6k² + 3k 는 정수이므로 n³ 은 `2(정수) + 1` 꼴, 곧 홀수다.
3. `p → q ≡ ¬q → ¬p` 이므로 대우가 참이면 원래 명제도 참이다. □
4. 검산: n = 3 → n³ = 27 = 2 · 13 + 1, 홀수다. 위 식에 k = 1 을 넣어도 2(4 + 6 + 3) + 1 = 27 로 맞는다.

(직접 계산한 값 — 실행하지 않음)

장 본문 §3.2 대우 증명(「n² 이 짝수이면 n 도 짝수」)과 같은 방법에 기댄다.

### 실습 2. 수학적 귀납법으로 합 공식 증명하기

1. P(n): 1 + 2 + … + n = n(n+1)/2.
2. 기저: P(1) 의 좌변 = 1, 우변 = 1 · 2 / 2 = 1. 같으므로 참.
3. 귀납 단계: P(k) 곧 1 + … + k = k(k+1)/2 를 가정한다.
   1 + … + k + (k+1) = k(k+1)/2 + (k+1)
   = (k+1)(k/2 + 1)
   = (k+1)(k+2)/2.
   이것은 P(k+1) 의 우변과 같으므로 P(k) → P(k+1) 이 성립한다.
   기저와 귀납 단계로 모든 n ≥ 1 에 대해 P(n) 이 참이다. □
4. 검산: n = 4 → 좌변 1 + 2 + 3 + 4 = 10, 우변 4 · 5 / 2 = 10.

(직접 계산한 값 — 실행하지 않음)

장 본문 §3.4 수학적 귀납법의 구조(기저 + 귀납 단계)에 기댄다.

### 실습 3. 비둘기집 원리로 같은 달 생일 찾기

1. 상자 = 1월~12월의 12개 달, 물건 = 학생.
2. 13명(= 12 + 1)을 12개 상자에 넣으면 비둘기집 원리에 따라 적어도 한 상자에 두 명 이상이 들어간다. 곧 같은 달 생일인 두 사람이 반드시 있다.
3. 12명은 1월부터 12월까지 한 명씩 배치할 수 있다. 이 배치에서는 겹치는 달이 없으므로 보장되지 않는다. 따라서 최소 인원은 13명이다.
4. 알려 주지 않는다. 겹치는 달이 「존재한다」는 것만 보이는 비구성적 존재 증명이다.

(직접 계산한 값 — 실행하지 않음)

장 본문 §3.8 비둘기집 원리(n+1개를 n개 상자에) · §3.6 비구성적 증명에 기댄다.
