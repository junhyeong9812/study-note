## ① 목표·대상

`database·java·js·network·python·rust·web` 7개 history repo의 콘텐츠 md **79편(15,192줄)**을 study-note의 `history/` 섹션으로 이관한다.
그냥 옮기는 게 아니라 **초보자가 읽을 수 있는 형태로 다시 쓴다** — 도식으로 단순화하고, 전문용어는 쓰되 등장 자리에 설명을 붙인다.

구조(사용자 확정: 8주제):

```text
history/
├── README.md · index.md
├── java/ (28편)  spring/ (13편)      ← java-history를 둘로 분리
├── database/ js/ network/ python/ rust/ web/ (각 6편)
└── <주제>/README.md = 그 주제의 목차 + 타임라인
```

문서 골격: `한눈에 → 시대 배경 → 무엇이 바뀌었나(도식) → 왜 → 남긴 것 → 원본 출처`

## ② 경계·불변식

- **방식 = 재서술**(사용자 확정 2026-09-18). 원문 문장을 그대로 옮기지 않고 쉬운 말로 다시 쓴다.
- 다만 아래는 **원형 그대로 옮긴다** — 재서술 대상이 아니다:
  - 코드블록 596개(java 183·python 53·rust 52 등)
  - 인명·연도·논문/표준명·JEP/RFC 번호·버전·수치
- 전문용어를 없애지 않는다. 쓰되 **처음 등장한 자리 바로 아래** `> **용어(영문)** — 정의.\` + `> 예: …` 블록을 단다.
- 원본 repo는 **읽기만** 한다(수정·삭제 금지). 원본이 정본이고 깊이가 필요하면 링크로 간다.
- mermaid 40파일은 ASCII(```text)로 형식 변환하되 노드 문구는 보존한다.
- 작성 원칙은 `reference/study-note-guide.md` — 특히 §3 도식화, §4 가독성(한 문장 한 줄), §6 수치 날조 금지.
