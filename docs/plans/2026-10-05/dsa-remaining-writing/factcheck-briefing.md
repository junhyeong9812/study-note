## 3. 실험 재현 (V1b — 필수)

- 편마다 실험 **최소 1개를 다시 돌린다**(집필자 코드·명령 그대로, briefing §6 규칙: 공용 컨테이너 없음 — 모든 실험은 자기 전용 `sn-dsa-f<묶음>-*` 일회용 컨테이너, 끝나면 확인).
- 결정적 출력은 일치해야 한다. 비결정적 값(시간·순서·무작위)은 범위·경향이 맞는지 본다. 노트가 범위를 너무 좁게 단정하면 고친다.
- 재현이 실패하거나 출력이 다르면 노트를 실제 결과에 맞게 고치고 packet에 적는다.
- briefing §6 그대로: 자기 전용 `sn-dsa-f<묶음>-*` 일회용 컨테이너(`--rm --pull never --cpus=2 -u $(id -u):$(id -g) -e HOME=/tmp`, 가능하면 `--network none`), 호스트 gcc·python3·gzip·zstd·xz 가능, 새 패키지·이미지 금지. 집필자 폴더를 복사해 쓰고 원본 out 파일은 덮어쓰지 않는다. 재실행 산출물은 `scratchpad/dsa/fc-<묶음>/`.
