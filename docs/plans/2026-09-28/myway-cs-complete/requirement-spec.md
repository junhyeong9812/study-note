## 1. 목표·대상 (필수)

대상: `cs/algorithm/01~30`, `cs/data-structure/01~35`, `cs/domain-modeling/basic/01~30`, `cs/domain-modeling/advanced/01~30`, `cs/ops-patterns/01~19`, `cs/api-design/01~06` — 합계 150편. 아래 세 가지를 하면 끝이다.

1. **빈 곳 채우기**: data-structure 35편의 「전체 흐름」(ASCII 워크플로우)과 「핵심 문장」(3~5문장)을 채우고, 템플릿 주석과 빈 불릿을 없앤다.
2. **양식 통일 + 골격 보강(2-summary)**: 150편 모두 최상위 헤딩을 같은 순서로 맞춘다 — `## 해결하는 문제` → `## 동작·원리` → `## 쓰이는 자료구조·알고리즘`(data-structure·algorithm은 `## 쓰이는 곳`) → `## 적용 — 풀어나가는 법` → `## 장애 시나리오와 대처` → `## 핵심 문장` → `## 관련 주제·근거`. 기존 절은 내용 그대로 해당 절 아래 하위 헤딩(`###`)으로 옮기고(예: 전체 흐름·구현 → 동작·원리, 문제·과제 → 적용, 관련 자료·용어 풀이 → 관련 주제·근거), 빈 절만 새로 쓴다.
   - 추가할 절:
     - 「해결하는 문제」
     - 「쓰이는 자료구조·알고리즘」(data-structure·algorithm은 「쓰이는 곳」 — 이 구조·기법이 다른 시스템 어디에 쓰이나)
     - 「장애 시나리오와 대처」(현상 → 보이는 형태 → 원인 → 대처)
     - 「관련 주제·근거」(cs 노트·영역 표 링크, 교재·원본)
   - 헤더에 `2026-09-28: 통일 골격 보강(Claude 작성)` 한 줄을 추가한다.
3. **질문·정답 추가**
   - 1-question에 `### C. 통일 골격 (Claude 초안 2026-09-28)`: 새 절마다 질문 1~2개, 합계 4~6개
   - 3-answer에 같은 번호의 정답을 추가한다.

## 2. 경계·불변식 (필수)

- **I1 보존**: 기존 문장·그림·코드·질문·정답은 **삭제·재작성하지 않는다** — 허용되는 변경은 (a) 새 골격 절 아래로 **이동**, (b) 기존 헤딩의 **레벨 내림**(`##`→`###` 등), (c) 새 절·새 질문·정답 **추가**, (d) DS 35편 빈 절의 템플릿 주석·빈 불릿 → 내용 교체. 1-question·3-answer는 기존 A·B절을 그대로 두고 C절만 추가한다.
- **I2 근거**: 사실 주장은 myway 원본(`/home/jun/project/myway/<폴더>/` — README·impl·src)과 기존 노트 본문을 근거로 한다. 일반 CS 지식은 교재 수준으로만 쓴다. 확인하지 못한 수치·출처는 `[?]`로 표시한다.
- **I3 정합**: 1-question C절의 질문 수와 3-answer C절의 정답 수·번호가 일치한다.
- **I4 형식**
  - 코드 스니펫은 Java·JS·TS를 쓴다. myway 원본은 Java다.
  - 그림은 단순 ASCII로 그린다.
  - 줄바꿈 규칙(줄 끝 `\`)은 기존 문서의 관례를 따른다.
  - 리프 폴더에는 md만 둔다.
- **I5 링크**: 새로 깨지는 링크 0
