# codex 지적 판정·반영 브리핑 — 네트워크 새 노트 (2026-09-30)

## 1. 입력

- 담당 노트마다 codex 지적 파일: `/tmp/claude-1000/-home-jun-project-study-note/16696510-853f-4d10-82ba-64d9eb37bcc8/scratchpad/codexnet/out-<NN>.md`
- 노트: `cs/network/<NN>-*/` 3파일(2-summary·3-answer 중심, 1-question은 질문 문구가 영향받을 때만)

## 2. 지적마다 판정

1. 노트의 해당 줄을 찾는다(문구가 이미 바뀌었으면 현재 문구로 판단).
2. codex가 댄 근거를 **직접 연다**(rfc-editor.org txt curl+grep, man7.org, docs.kernel.org, 소스). codex 근거가 틀렸거나 없으면 스스로 1차 출처를 찾는다.
3. 판정
   - **채택**: 노트가 틀렸거나 조건이 빠졌다 → 고친다. 조건을 붙이는 최소 수정을 우선한다(문단 재작성 금지).
   - **부분 채택**: 방향은 맞지만 codex 정정문도 과하다 → 출처에 맞게 고친다.
   - **기각**: 노트가 맞거나, 학습 노트 수준에서 오해를 부르지 않는 단순화다(예: "보통"·"기본적으로"가 이미 붙어 있음). 사유 한 줄.
4. **노트 내부 모순**(요약 vs 정답, 그림 vs 식)은 반드시 해소한다.

## 3. 수정 규칙

- 쉬운 문체·그림 우선·용어 즉석 풀이를 유지한다. 조건은 짧게 붙인다("리눅스 기본값에서는", "~인 경우").
- 구조(헤딩·질문 수·번호)와 "Claude 초안" 표기는 바꾸지 않는다.
- 확인 못 한 구체 사실은 삭제하거나 `[?]`. 지어내서 메우지 않는다.
- 담당 폴더 밖은 수정 금지. git 조회만. 하위 에이전트 금지.
