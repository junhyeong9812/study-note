## 5. 실험 근거 (명세 I7 — 필수)

- 편마다 실행으로 보일 수 있는 핵심 주장 1개 이상(종합 16·17 선택). 예:
  - 01: 권한 조건 `!(a && b)` vs `!a && !b` 진리표 전수로 다른 경우 찾기, 단락 평가에 기댄 null 검사.
  - 02: 이진 탐색·투 포인터의 루프 불변식을 `assert`로 매 반복 검사(-ea), off-by-one 판이 불변식을 깨는 순간.
  - 03: `equals` 비대칭 클래스 → `HashSet` 중복, 추이성 깨진 비교자 → `Comparison method violates its general contract!`(n≥32), 동치류 = union-find.
  - 04: 의존 그래프 위상정렬(Kahn)과 사이클 탐지, 사이클이 있으면 재귀 해석이 `StackOverflowError`.
  - 05: 32비트·48비트·64비트 랜덤 ID k개의 충돌 실측 vs `1 − exp(−k²/2N)`, 비둘기집(짧은 해시 prefix).
  - 06: 점화식 호출 수 측정(T(n)=2T(n/2)+n vs T(n)=T(n−1)+T(n−2)), 마스터 정리 세 경우 예.
  - 11: `-7 % 3` Java −1 / Python 2, `Math.floorMod`, `Math.abs(Integer.MIN_VALUE)`, 빠른 거듭제곱 vs BigInteger.modPow, 모듈러 역원.
  - 07: 기저율 시뮬레이션 — 민감도 99%·특이도 99%·유병률 0.1%일 때 양성 중 진짜 비율, 블룸 필터 FP 공식 vs 실측.
  - 08: 기댓값 선형성(쿠폰 수집), 마르코프·체비셰프·체르노프 한계 vs 실측 꼬리, 상관된 장애(같은 AZ)로 가용성 곱셈이 틀리는 시뮬레이션.
  - 09: 포아송 vs 버스트 도착, Zipf 접근에서 캐시 크기별 적중률, 지수 백오프 대기 분포.
