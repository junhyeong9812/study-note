# 2단계 배치 계획 — 3파일 작성

1단계 리스트업 완료: **13개 언어 723주제**(+ `web-api` 갈래 진행 중).
2단계는 이 목록을 3파일(질문·서머리·정답)로 쓰는 일이다.

## 배치 순서를 정하는 축

1. ★ **실행 검증이 되는가** — 이 저장소의 실패 모드는 「돌려보지 않은 것을 이렇게 된다고 적는 것」이다.
   검증이 되는 언어를 앞에 두어 **형식이 검증과 함께 굳게** 한다.
2. **사용자 주력** — Java/Spring 이 주력이고, SQL 은 사용자가 먼저 든 언어이며 이 저장소에 처음 들어온다.
3. **선행 뿌리가 깨끗한가** — SQL 01(논리적 질의 처리 순서)·CSS 01(캐스케이드) 처럼
   뿌리 주제가 분명한 언어는 앞쪽부터 순서대로 쓰기 좋다.
4. **완주 대 횡단** — 처음 두세 언어는 **완주**한다(하나가 끝나야 형식이 증명되고 사이트에 올릴 게 생긴다).
   그다음은 A 우선순위 횡단으로 넓힌다.

## 배치 단위 (파일럿 후 확정)

가안: **한 배치 = 한 언어의 A 주제를 5~8주제씩** 워커에 맡기고, 배치마다
- 작성 워커 ≠ 검증 워커 (컨텍스트 분리)
- 검증은 **실행 결과 재현** + **공식 문서 접지 대조** + **질문↔정답 1:1** + 형식 린트
- 배치 끝마다 커밋
