# 요구사항 명세서 — 노트 본문의 지어낸 말을 통용어로

1. 목표·대상: 노트 본문에서 영어 개념을 지어낸 말로 옮긴 낱말을 통용어로 바꾼다. 1차 대상은 `cs/reliability/`(시범), 낱말은 뜻이 하나로 쓰이는 것만(격벽 -> 벌크헤드, 꼬리 지연 -> 테일 레이턴시, 무음 실패·스킵 -> 조용한 실패·스킵). 사용자 지시(2026-11-18, resume 세션): "스터디 노트쪽 작업 진행".
2. 경계·불변식: 코드 블록, 인라인 코드, 링크 대상, 파일·폴더 이름은 바꾸지 않는다. 비유로 쓴 본뜻(예: "배의 격벽")과 본인 답변 기록의 평범한 한국어는 둔다. 같은 낱말이 여러 뜻이면(기준선, 어긋남, 문턱, 바퀴, 손잡이, 안전망) 이번 범위에서 뺀다.
3. 기준소스: `agent-discipline/rules/writing/principles.md` 낱말 절, `wording-table.md`.
4. 금지영역: `docs/plans`(작업 기록), `issue/` 카드의 인용 원문, 배포 설정.
5. 검증 방법: 바뀐 줄 전부를 diff로 읽는다. 표와 줄 끝 `\` 줄바꿈이 깨지지 않았는지 확인한다.
6. stakes: 낮음(git으로 되돌릴 수 있음). push는 배포를 일으키므로 사용자 확인 뒤에만 한다.
