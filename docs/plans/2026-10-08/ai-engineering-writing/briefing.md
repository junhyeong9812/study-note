## 5. 실험 근거 (명세 I6 — 필수)

- 편마다 실행으로 보일 수 있는 핵심 주장 1개 이상(종합 25·26 선택). 시드 고정·반복 수 기록. **실제 LLM·외부 API 없음** — 모형으로 보인다:
  - 01~03: 작은 데이터의 학습/검증 분리·누설로 점수 부풀기, 경사 하강 손 구현, 교차 엔트로피 = 평균 NLL·perplexity 계산.
  - 04: 미니 BPE(작은 말뭉치 병합)로 한글·영문 토큰 수 차이, 바이트 수 대비 토큰 수.
  - 05: 코사인 vs 내적(정규화 유무)으로 순위가 바뀌는 예, 두 "임베딩 공간"(다른 무작위 투영) 혼합 시 최근접 붕괴.
  - 06: 소형 셀프 어텐션 수치 계산(인과 마스크 유무). 07: temperature·top-p 샘플링 분포 시뮬레이션(같은 로짓, 다른 출력 빈도).
  - 08: 모델 설정표로 KV 캐시 바이트 계산(MHA vs GQA), 동시 요청 수 상한. 09: 정적 vs 연속 배칭 이산 사건 시뮬레이션(처리량·대기).
  - 10: 로컬 SSE 모형 서버(Python `http.server`·Java `HttpServer`)로 TTFT·TPOT·E2E 측정, 도구별 정의 차이.
  - 11: Java `HttpClient` 스트리밍 클라이언트 — 429 + `Retry-After`, 스트림 중간 끊김, 전체 타임아웃 vs 첫 토큰 타임아웃, 토큰 한도 `finish_reason`/`stop_reason` 처리(모형 서버).
  - 12: 정확 일치 프리픽스 캐시 vs 의미 캐시(유사도 임계값)의 적중·오적중 표. 13: 라우터·폴백·서킷 상태 기계 시뮬레이션.
  - 14: JSON 스키마(작은 부분집합) 검증 실패 → 재요청/거부 흐름, 도구 계약 검증(Java).
  - 15: TF-IDF 임베딩 미니 RAG(청크 크기에 따른 검색 적중 변화), 출처 표기.
  - **16: `pgvector/pgvector:pg17`로 전수 탐색 vs HNSW(`m`·`ef_construction`·`hnsw.ef_search`) vs IVFFlat(`lists`·`ivfflat.probes`)의 recall@10–지연**(합성 벡터, 차원·개수 기록, `EXPLAIN ANALYZE`).
  - 17: BM25(간이) + 밀집 점수 RRF 합성, 재순위 효과. 18: 임베딩 모델 교체 중 옛/새 벡터 혼합 검색 품질 하락, 버전 열.
  - 19: 평가셋 크기와 정확도 신뢰구간, judge 위치 편향 모형(순서 바꿔 두 번), 회귀 게이트. 20: 에이전트 루프 턴 예산·종료 조건, 멱등 키 있는/없는 도구 재시도.

## 6. 실행 환경과 안전 규칙

- **자기 전용 일회용 컨테이너만**: 이름 `sn-ai-w<NN>-*`, `--rm --pull never --cpus=2`. python·java·node는 `--network none -u $(id -u):$(id -g) -e HOME=/tmp -v <scratchpad 절대경로>:/w -w /w`. pgvector는 바인드 마운트 없이 `docker run -d --rm --pull never --name sn-ai-w16-pg -e POSTGRES_PASSWORD=x pgvector/pgvector:pg17` → `docker exec -i … psql -U postgres` (`CREATE EXTENSION vector;`), 끝나면 `docker stop`. **이미 있는 이미지만**(`pgvector/pgvector:pg17`·`postgres:17`·`eclipse-temurin:21-jdk`·`python:3.12-slim`·`node:22-alpine`·`node:22-bookworm-slim`) — pull·build·rmi·prune 금지. 볼륨 만들지 않기. 끝나면 `docker ps -a --filter name=sn-ai-w<NN>` 비었는지 확인.
- **Java**: 호스트 java는 8 — 위 temurin 21 컨테이너로(`java X.java` 단일 파일 실행). 외부 라이브러리 없음(JDK만).
- **호스트**: python3 표준 라이브러리만. sudo·패키지 설치 금지(pip·npm install 포함). **외부 LLM API·모델 다운로드 금지**(네트워크·비용·비밀값). 실험은 몇 분·1GB 이내.
- **데이터**: 합성만. **개인정보 금지**: 요청·파일·노트 어디에도 사용자 식별 정보를 넣지 않는다.
- **파일 위치**: `/tmp/claude-1000/-home-jun-project-study-note/16696510-853f-4d10-82ba-64d9eb37bcc8/scratchpad/ai/<담당 첫 번호>/`에만. 저장소 루트·노트 폴더에 파일을 만들지 않는다.
- 프로세스는 자기 PID만 종료(`pkill -f` 금지). 이 작업이 만들지 않은 컨테이너·볼륨·네트워크·이미지는 건드리지 않는다.
