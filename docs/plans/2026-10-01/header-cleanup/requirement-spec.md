## 0. 요구사항 원문 (인터뷰)

- 원문: "study-note에서 cs와 history에 최상단에 [복습 안내·주제 요약·환경 설명 머리말] 이런 요약 문장들 다 제거좀 해줘. 아니다 그냥 모든 문서에 저런 헤더 요약인지 설명 같은데 저거 다 제거해줄래? 이거 제거하는 작업 진행하면서 작성하자"
- Q/A (2026-10-01)
  - 범위: **저장소 전체**의 md
  - 지울 줄: **제목(H1) 바로 아래 `>` 인용문 머리말 전부** — 복습 안내, 주제 요약, 환경 설명, 표식 줄이 모두 포함된다. 본문 중간의 인용문은 그대로 둔다.
  - 상태 표식(Claude 초안 / 검수 완료): 사용자 제안 "폴더 단위로 관리하니 각 폴더에 **metadata.md**를 만들어 초안/검수/학습 단계와 날짜를 기록" → 형식은 **단계 + 날짜**
  - metadata.md를 둘 곳: **학습 노트 폴더 전부**(1-question.md가 있는 폴더). 표식이 없던 폴더는 단계 `원고`
  - 생성 문서(영역 README·커리큘럼 표)의 머리말: **남긴다**
  - 순서: **별도 브랜치로 병행**한다. 진행 중인 DB 57편은 마무리 때 새 형식으로 맞춘다.

## 1. 목표·대상 (필수)

1. 저장소 전체 md에서 H1 바로 아래 인용문 블록을 제거한다. 대상 약 3,970개 파일이다(생성 문서는 제외).
2. 1-question.md가 있는 폴더마다 `metadata.md`를 만든다.

   ```
   # metadata

   | 항목 | 값 |
   |---|---|
   | 단계 | 초안 |          ← 원고 / 초안 / 검수 / 학습
   | 초안 | 2026-09-30 (Claude) |
   | 검수 | — |
   | 학습 | — |
   ```

   - 단계 판정은 기존 표식을 옮긴다: 3파일 모두 `✅ 검수 완료(날짜)`면 `검수`(날짜 기록), `Claude 초안(날짜)`가 있으면 `초안`, 표식이 없으면 `원고`.
3. 도구를 새 형식에 맞춘다.
   - `gen_area_readme.py`: 상태를 metadata.md의 단계로 읽는다. 원고 → `원고 있음`, 초안 → `초안(Claude)`, 검수·학습 → `검수 완료`. metadata.md가 없으면 기존 표식으로 대신 판정한다.
   - `check_new.py`: 초안 표기 검사를 "metadata.md가 있고 단계 칸이 있다"로 바꾸고, H1 아래 인용문 머리말이 없음을 검사하도록 바꾼다.
4. 규칙 문서를 갱신한다.
   - `cs/README.md` 「작성 규칙」의 표식 조항을 metadata.md 방식으로 바꾼다.
   - 이후 집필에 쓸 브리핑 템플릿에서 머리말을 없앤다.
   - 기존 작업 폴더의 기록 문서는 역사 기록이라 고치지 않는다. 단 H1 아래 인용문은 1번에 따라 지운다.

## 2. 경계·불변식 (필수)

- **I1 지우는 것만 지운다**: 파일마다 지운 줄은 모두 `>`로 시작하거나 빈 줄이어야 한다. H1과 본문의 첫 줄 이후는 바이트 단위로 같다. 스크립트가 파일마다 이를 단언한다.
- **I2 상태 보존**: 생성기를 다시 돌렸을 때 영역별 상태 합계(미작성/원고 있음/초안/검수 완료)가 제거 전과 같다.
- **I3 생성 문서 제외**: `> **생성 문서**` 줄이 있는 파일(영역 README·curriculum.md)은 건드리지 않는다.
- **I4 링크**: 노트가 새로 깨는 링크가 0이다(metadata.md는 새 파일일 뿐이다).
- **I5 DB 작업 비간섭**: 작업은 별도 worktree에서만 한다. 메인 작업 트리(DB 57편 집필 중)는 건드리지 않는다.
