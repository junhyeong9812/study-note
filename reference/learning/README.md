# learning — 내 공부 방법론

이 폴더는 **"나는 어떻게 공부하는가"를 감이 아닌 말로 적어 둔 곳**이다. 루트 [README](../README.md)의 「공부 루프」·「복습 규칙」은 *무엇을 하라*는 규칙이고, 여기는 *왜 그 규칙인가*와 *그 규칙이 남들이 정리한 방법론과 어디서 겹치는가*를 적는다. 규칙 본체는 루트 README 한 곳에만 둔다 — 여기서 규칙을 새로 만들지 않는다. [reference/writing/](../writing/README.md)이 "문서를 어떻게 쓰는가"의 근거 폴더인 것과 같은 자리다.

## 파일 구성

세 종류의 문서를 섞지 않는다. 역할이 다르다.

| 파일 | 누가 쓰나 | 내용 |
|------|-----------|------|
| `README.md` (이 문서) | 나 | 방법론 정본 + 출처와의 대응표 |
| `source-N-<출처>.md` | 나 | 그 출처를 보며 **직접 쓴 원고** — 출처가 말한 것, 겹치는 것, 달랐던 것 |
| `source-N-<출처>-대본.md` | Claude | 자막·녹취를 정리한 **대본 초안** — 원고 쓸 때 확인용. 베끼지 않는다 |

출처가 늘면 `source-2-…`로 붙인다.

### [Claude 초안] source-1 박문호 ↔ 이 저장소의 규칙

> 원고가 없어서 **"내 방식"이 아니라 "이 저장소에 이미 적혀 있는 규칙"**과만 대응시켰다. 오른쪽 열은 루트 README·cs/README에서 실제 문장을 가져온 것. 원고를 쓰고 나면 이 표를 내 말로 다시 쓰고 이 절은 지운다.

| 박사가 말한 것 (대본 절) | 이 저장소에 이미 있는 규칙 | 겹침 정도 |
|---|---|---|
| **대칭화** — 형태가 제각각인 것을 내가 정한 단순한 하나의 형태로 바꿔라 (§1) | cs/README 융합 규칙 3 「골격을 하나로 통일한다 — 같은 종류의 항목은 같은 순서로 서술한다 (원칙류: 먼저 알아야 할 것 → 정의 → 왜 → 나쁜 예 → 좋은 예 → 위반 신호 → 현장)」 | 강함 — 항목 골격 통일이 곧 모듈 |
| **모듈 → 자동 연결·확장** — 한 가구만 알면 단지가 찍힌다 (§1) | 모든 챕터가 `1-question / 2-summary / 3-answer` 3파일 한 틀, 템플릿 복사로 시작 | 강함 — 챕터가 모듈 |
| **순서화** — 순서 없으면 만들어라, 순서 없으면 인출이 안 된다 (§1, 유럽 강 열 개) | 챕터 번호 `01~35`·원본 파일명 순서 대응 · 융합 규칙 4 「사전 지식은 필요해지는 자리에 푼다」 · 융합 규칙 5 「예제는 2단으로 — 쉬운 예 먼저, 같은 구조를 실무로」 | 강함 |
| **같은 것 찾기** — 다르게 보이는 두 현상이 같은 것임을 아는 게 학문 (§2) | 융합 규칙 5 「두 예제 사이는 "똑같은 구조다"로 명시적으로 잇는다」 | 강함 |
| **맥락 기억 → 맥락을 잘라 의미 기억** — 지식은 시간·장소가 붙은 경험에서 출발해 그것을 잘라낸 것 (§3) | cs/README 「따라 친 원본 노트(맥락 있음) → 순수 서머리」 · 융합 규칙 7 「프로젝트 맥락은 일반화한다 — 지우는 게 아니라 누구나 겪는 형태로 다시 쓴다」 | 강함 — 노트→서머리가 정확히 맥락 절단 |
| **새 사건에 시간·공간을 붙이면 안 잊는다** (§3) | 복습 기록 표(날짜·결과·틀린 질문) · 세미나 후기(날짜·장소) | 부분 — 기록은 있으나 "붙여서 기억"을 의도한 규칙은 없음 |
| **숲을 보라, 나무 공부는 나중에** — 맥락의 플랫폼을 높여라 (§4) | 루트 README 「질문은 지도 수준으로 — 세부 암기가 아니라 왜·예측·경계·연결」 · 융합 규칙 검증 「소제목만 읽어 구조와 결론이 재구성되면 합격」 | 강함 |
| **안 늘면 스톱, 메타사고** (§1 끝) | 복습 기록의 「틀린 질문 → 다음 회차 우선」 | 약함 — 회차 단위 피드백은 있으나 "멈추고 조망"은 없음 |
| **뇌는 근육이 아니다 — 부하를 줄여라, 최소 노력** (§1) | 루트 README 「약간 힘들게, 잊기 직전에 꺼낼수록 세게 굳는다」 | **충돌처럼 보임** — 아래 참고 |

**충돌로 보이는 한 곳(판단은 내가):** 박사는 "부하를 단계적으로 줄여라"고 하고, 루트 README는 "약간 힘들게"라고 한다. 대본을 다시 보면 박사가 줄이라는 부하는 *표현의 부하*(제각각인 형태를 외우는 비용 — 사각형으로 바꿔 없애라)이고, README가 유지하라는 부하는 *인출의 부하*(기억에서 꺼내는 노력)다. 다른 층의 이야기라 양립할 수 있어 보이지만, 이건 원고를 쓰면서 내가 확정할 것.
