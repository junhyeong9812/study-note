# source-1 대본 — 박문호 「빅퀘스천」 1부 (자동 자막 기반 Claude 초안)

> **이 문서는 내 글이 아니다.** 영상 자동 자막을 받아 Claude가 강연 순서대로 정리한 **대본 초안**이다. 내 원고는 [source-1-박문호-빅퀘스천-1부.md](source-1-박문호-빅퀘스천-1부.md)에 따로 쓴다. 원고를 쓸 때 기억이 안 나는 대목을 확인하는 용도 — 원고를 여기서 베끼지 않는다(루트 README 「정답은 기억에서 먼저 쓴다」와 같은 이유).
> 출처·영상 정보는 원고 문서 상단에 있다.

## 박사가 말한 것 — 강연 순서대로

> **작성 방식**: 2026-08-29, 유튜브 자동 생성 한국어 자막(917세그먼트)을 yt-dlp로 받아 정리. 자동 자막이라 오인식이 많아 문맥으로 교정했다 — 교정 목록: 박문화→박문호 · 모두 순수화→모듈화·순서화 · 채워넣기=타일링(tiling) · 일하 기억→일화 기억 · 탈명락→탈맥락 · 그걸인가 법칙→인과 법칙 · 셀프 어런스→self-awareness · 동교화→동기화 · 런센서→nonsense · 야/얘→브레인 · 포항→포도당 · 팬노즈→펜로즈. 교정 확신이 없는 곳은 `(자막 불명확)`으로 남겼다. 원고가 채워지면 이 문서는 보조 자료다.

### 1. 원리 — 대칭화 → 모듈 → 순서화 (00:56~17:40)

**계기: 신경세포 그림 (01:09)**
- 뇌과학 25년 중 초기 10년 이야기. 다른 건 다 설명되고 축적되는데 신경세포 연결 전체가 머리에 확 떠오르지 않았다. 원인을 보니 **신경세포 자체를 안 그리고 있었다.**
- 왜 안 그렸나: 신경세포는 풍선 같아서 정해진 형태가 없다. 교과서·논문마다 다르다. "항상 바뀌는 형태니 굳이 그릴 필요 없다" → 안 그림 → 연결 전체는 더더욱 안 그림. 악순환.
- 해법: **"내가 정해서 그리겠다. 가장 단순하게."** 처음엔 오각형, 지금은 **사각형(벽돌처럼)**. 원이든 삼각형이든 무조건 사각형으로 바꿔 놓았더니 **자동으로 연결**되고 공부가 가속됐다. "한 달 공부했는데 (자막 불명확) 효과가 나타나는 거예요. 내가 왜 진작 이걸 안 했을까."
- 이걸 용어로 정리한 것이 **대칭의 원리**.

**대칭화 = 곡선을 사각형으로 (02:50~05:02)**
- 기차: 동일한 차량이 20개 붙은 것 → 하나만 알면 된다. 아파트 단지: 한 동 100가구, 실내 구조는 동일 → **한 가구만 알면 가로·세로·위로 찍어내면 단지가 완성된다.** "100개 지식을 다 가질 필요 없다. 딱 하나. 왜? 동일한 모듈의 공간적 반복이니까."
- 수학의 타일링(펜로즈): 바닥을 빈 구멍 없이 무한히 채우는 것. 가장 단순한 도형은 삼각형이지만 삼각형만으로는 채우기가 어렵고, 삼각형을 180도 뒤집어 붙이면 **직사각형** — 이것이 모듈. 3차원이면 정육면체.
- **곡선은 허용하지 않는다.** 흙집은 단층밖에 못 짓는다. 100층 빌딩·지구상 아파트의 99.99%는 직육면체.

**모듈성의 세 속성 (05:02~06:41)**
1. **단위성** — 화폐가 10진법 단위(100원·1,000원·10,000원)라서 교환이 된다. 7진법 화폐로 계산해 보라, 못 한다. 단위 = 중간값이 없다, 딱 하나로 결정돼 있다. 단위성이 없으면 주고받을 수는 있어도 어마어마한 계산이 든다.
2. **연결성** — "모듈성이 확립된 연결성은 **자동 연결성**이 된다. 거의 노력을 안 해도, 생각을 거의 안 해도 된다."
3. **자동 확장성** — 그래서 빌딩이 되고 레고 블록으로 비행기가 된다.
- 자연물(나무·구름·바위)은 대칭이 아니다. 세포도 아니었다. **"대칭이 안 보일 때는 무조건 대칭을 만들어라. 그걸 대칭화라 한다."**

**순서화 (06:41~07:15)**
- 기차 모듈은 1차원(앞뒤) 연결. 빌딩은 반드시 1층 짓고 2층 — 3층을 먼저 지을 수 없다. **그게 순서다. "순서가 없으면 순서를 만들어라."**
- 대칭만 알면 자동으로 탄탄 나온다. "노력이 안 듭니다. 들어도 최소화됩니다. 최소 노력으로."
- 시간·에너지를 많이 들이면 뭐든 만들 수는 있다. 그러나 한 번 하고 탈진한다. **공부는 평생 하는 것이라 시작할 때부터 최소 노력이 드는 최소 단위를 찾아내야 한다.**

**브레인은 근육이 아니다 (07:15~09:29)**
- 근육을 키우는 대원칙은 부하(로드)를 단계적으로 높이는 것. **브레인은 정확히 반대 — 부하·스트레스를 단계적으로 줄여 줘야 한다.**
- 집중을 계속 강요하면 강박이 된다(스마트폰). 집중이 다 좋은 게 아니다 — 70% 상황에서 좋고, 모든 것에 확장하면 편집증·스토커가 된다. **브레인은 강화보다 편하게 해 줘야 한다.**
- 반론 예상("열심히 해야 성공하는 것 아니냐")에 대한 답: 세상에 삼각형 건물이 있나? 피라미드 하나. 99.99%는 직사각형 면. **그게 브레인이 요구하는 패턴 — 가장 편안하고, 싫증 안 나고, 100년 두고 볼 수 있는 것.** 그 대칭 하나를 결정한 것이 모듈, 모듈이 입체가 되면 레고 블록. "대칭화·모듈화·순서화는 한 몸이다. 딱 하나만 알면 돼요. 대칭화만."

**곁가지: 죽어 있는 사각형 안에 생성이 있다 (09:29~11:44)**
- 사각형은 안정 = 변화 없음. 그런데 직사각형을 대각선으로 자르면 직각삼각형 둘 → 삼각함수 → 사인·코사인 곡선 = 연속 = 무한. 그리고 주기함수라 360도마다 반복. **"무한을 생성하고 무한을 반복한다. 삼각형 속에 다 있다."** 대칭은 구조를 갖고, 변환되고, 작용(action = 에너지×시간 = 플랑크 상수의 차원)을 생성한다.
- 중고생이라면 어렵게 생각하지 말 것: **"지금 단계에서는 노트에다가 사각형을 그린다. 곡선을 싫어한다. 요게 핵심입니다."**

**적용 예: 유럽사를 강 열 개로 (12:17~14:31)** ← 내가 본 지점
- 중국사 정보량이 1이면 유럽사는 3. 대칭의 관점에서 접근하면 그게 가장 간단해진다.
- 사람은 2차원 지형에서 산다 → 산에는 거의 안 산다(평면이 없어서) → 평지는 강이 만든다 → **"인간의 삶은 강을 따라서다."** 그러면 유럽 강 열 개만 찾으면 된다.
- 유럽 해안선은 복잡하다 — 그렇게 그리지 마라. **유럽을 직사각형으로 그리고**, 오른쪽 위 코너(발트해)부터 시계 방향으로 순서를 매긴다: 오데르 → 엘베 → 라인 → 센 → (수직으로 꺾어 대서양 쪽) 루아르 → 가론 → 타구스(스페인) → (지중해) 론 → 포(이탈리아) → (흑해 쪽 셋) 다뉴브 → 드네프르 → 볼가. "게임 끝."
- **"이렇게 순서화하지 않으면 열 배 시간이 든다. 그리고 열 배 드는 게 중요한 게 아니고 인출이 안 된다. 뒤죽박죽이 돼 버린다."** 직사각형에 기준점 잡고 쫙 하면 평생 안 잊는다. 국사 배우고 남는 게 '태정태세문단세'뿐인 이유 — 순서가 돼 있기 때문.
- 정리: 공부는 대칭. 대칭이 안 보이면 대칭을 만들어라(대칭화). 정화된 2차원 사각형 패턴 = 모듈. 모듈이 되면 자동 생성. 순서가 없으면 순서를 만들어라. 그러면 확장되고, **더 중요하게는 에너지가 최소화된다.**

**에너지가 최소화되면 자꾸 하고 싶어진다 (15:04~16:12)**
- 왜 대학 졸업하면 공부를 놓나 — 힘들어서. **브레인은 에너지 절약 머신.** 재미없는 강의에 조는 건 현명한 것. 시간당 포도당 4g(자막 기준)만 쓴다. 뇌의 관심은 하나 — 에너지를 줄이는 쪽.
- "이 원리를 하면 창의성으로 가는 고속도로를 깔 수 있다." 공부의 원리는 어려운 것에 매달리는 쪽이 아니라 — (댓글 반론 조심하면서) — **문제가 어려우면 항상 '이 문제를 푸는 데 에너지가 가장 적은 방식이 뭔가'부터 찾아라.** 정답은 하나가 아니다(피타고라스 증명 200가지). 나한테 맞는 길을 찾는 게 뇌에서 가장 중요.

**실력이 안 늘면 스톱 — 메타사고 (16:12~17:40)**
- 몇 년을 했는데 실력이 안 늘면 **스톱**. "내가 지금 뭐 하고 있지, 어떻게 하고 있지"를 메타사고 — self-awareness.
- 브레인은 근육이 아니라 힘들면 싫증 나서 떠나 버린다. 오래·즐기며·평생 하려면 **뇌를 달래야** 하고, 달래는 법은 뇌한테 물어보는 것: "너 많이 힘들었지? 시간 쏟았는데 결과가 신통찮지? 계속하지 말고 잠깐 쉬어 봐. 왜 다른 분야는 늘었는데 이 분야는 안 늘었지? 조망을 한번 해 봐. 숲을 봐."
- 1부 요약: **대칭화·모듈화·순서화. 브레인은 근육이 아니므로 최소 단위를 찾고 자동 연결하면 에너지가 최소화되고, 그래야 오래 한다.**

### 2. 맥락 (17:41~23:18)

**일상에서 '맥락'이 쓰이는 네 장면**
- "말이 돼?" = 상대 이야기가 내 맥락과 연결되는 게 하나도 없다.
- "글쎄" = 70%는 이해하겠는데 30%, 특히 5%는 동의 못 하겠다 — 두 사람 맥락의 **중첩도**.
- "아하!" = 설명할 맥락을 찾았을 때.
- 가스라이팅(=세뇌) = 가까운 사람이 오랜 시간 교묘하게 **내 맥락을 타인에게 옮겨 심는 것.** 내 맥락엔 내 욕구·본능·목적이 들어 있어서 범죄가 된다.

**맥락 세 종류와 각각의 다른 이름**

| 맥락 | 다른 이름 | 내용 |
|------|-----------|------|
| 공간적 맥락 | **패턴** | 타일링처럼 공간을 채웠을 때 생기는 무늬. 주식 변화 패턴, 사기꾼 말의 패턴을 읽는 것 |
| 시간적 맥락 | **인과 법칙** | 원인이 먼저, 결과는 반드시 나중 |
| 사회적 맥락 | **분위기** | 끊임없이 바뀌는 인간 욕망의 집합체. 공통부를 빨리 찾아야 함. 못 읽으면 "센스 없다" |

**맥락은 왜 이렇게 중요한가 — 다른 이름을 찾아라**
- 이렇게 "다른 이름이 뭔가"를 찾는 게 공부고, **능동적 학습** — 레고처럼 내가 만들어 가는 것.
- 아리스토텔레스의 천재 정의: **비슷한 것·같은 것을 찾아내는 사람.** 다른 건 금방 안다(우리는 차이에 민감). 비슷해지면 찾기 어렵다(그래서 위장이 통한다). "완전히 다르게 보이는 두 현상이 사실은 같은 현상의 다른 측면임을 깨닫는 것" — 그게 학문.
- 맥락과 같은 것 = **예측.** 깜깜한 계단을 10m 못 내려간다 — 예측 없이는 한 발도 못 나간다. 매 순간 예측을 던지고, 행동조차 예측을 증명하는 과정(최근 뇌과학). 예측의 근거 = 내가 살아온 방식·가고 있는 길 = 맥락. **그래서 맥락은 기억을 만든다.**

### 3. 한 번 보고 들은 것도 영원히 기억하는 법 (23:19~27:14)

**맥락 기억 vs 탈맥락 기억**
- **맥락 기억 = 사건 기억 = 일화 기억.** 언제·어디서·누가 + 내 감정이 붙어 있다. 낮에 일할 땐 맥락에 맞는 기억만 불러온다. "오늘 하루 한 일 적어 보라, A4 여러 장 나온다." 공포영화는 기억하기 싫어도 기억된다 — **용량 무제한.**
- 그런데 중고등학교 공부는 왜 자동으로 안 되나 — 글자로 표현된 기억은 대부분 **의미 기억 = 탈맥락 기억**이라서.
- 모든 출발은 경험(맥락 기억). 지금 이 스튜디오·이 시간·이 분위기·이 느낌은 우주에 하나뿐 = 특수 = 유일. **유일한 건 다른 것과 공통점이 없어서 모으거나 결합할 수 없다.** 그런데 우리 기억은 많은 것이 연결돼 있다. 어떻게? **특수성의 가시(시간·공간)를 잘라 버리면 공통 패턴만 남는다.**
- 예: "링컨은 미국 16대 대통령"은 팩트 — 시간·공간 맥락이 없다. 그 맥락은 원래 울진 후포의 중학교 세계사 시간에 있었는데, 장소·시간은 잊고 팩트만 남았다. 맥락이 없으니 언제든 접근 가능 — 지금 강의 중에도 그냥 떠올랐다.
- **생각하기 vs 생각나기.** 모래사장에 동그라미 그리다 옛 애인이 떠오르는 것 — 인위적으로 생각한 게 아니라 떠오른 것. 그게 탈맥락 기억. 초등~대학의 모든 공부 기억은 탈맥락화되어 의미 기억으로 장기 저장되고, 그래서 문득문득 떠오른다.
- **모든 지식은 반드시 맥락 기억에서 시작해 맥락을 잘라낸 것.** 가장 강한 맥락 = 감정의 맥락 — 끝까지 남는다(패턴은 잊어도 그 분위기에 가면 싫다).
- 핵심 문장: **"새로운 사건 만날 때마다 시간하고 공간을 붙이면 영원히 있지 않아요(=안 잊혀요)."**
- 맥락을 벗어나면 물고기가 물 밖에 나온 것 = nonsense, 당혹.

### 4. 성공하는 사람은 세 가지가 다르다 (27:15~끝)

- 현실에서 가장 중요한 맥락 = 사회적 맥락(분위기). 분위기에 민감 = 나와 반대 성향인 사람과도 화합할 원리를 찾아낼 수 있다. 어디서든 일할 수 있는 사람 = 투명한 사람. 답답한 사람을 만나면 엄청난 로드가 걸린다.

1. **'나'라는 주어를 생략한다** — "나는 이렇게 생각한다"는 "내 감정의 맥락에 충실하겠다"는 말. 상대도 "나도 다른 생각 있어" → 각자 맥락 → 싸운다. 주어를 빼면 내 경계가 없어지고 타인이 들어온다. 대화 중 '나'를 몇 번 썼는지 체크하라.
   > **[Claude 주석 — 2026-08-29 대화에서의 재해석]** "나를 생략하라"를 문자 그대로 받으면 애매하다. ① 한국어는 주어 생략이 기본이라 박사가 겨냥한 건 *강조된* '나는'(= 입장 선언)이지 주어 전부가 아니다 ② 주어를 지우면 주장이 사실처럼 들리고 출처·책임이 흐려진다 ③ 차이가 안 보이면 "다름을 장점으로 배치"하는 다음 단계가 없어진다(동창회 예시가 그 한계 — 싸움은 없는데 얻는 것도 없다). 살릴 알맹이는 **"입장을 소유하지 말고, 입장이 나온 맥락을 공개하라"**다. 비교: "**나는** 캐시를 넣어야 한다고 생각해"(입장 소유 → 상대도 입장으로 맞섬) vs "**내 쪽**에서 본 건 p99 800ms 대시보드라 캐시가 먼저 보여 — 너희 쪽엔 뭐가 보여?"('나'가 더 많은데 덜 충돌 — 맥락을 내놓으니 상대도 맥락을 내놓는다). 이 재해석은 1번을 부정하는 게 아니라 3번(숲 맥락) 안의 **발화 기법**으로 위치를 낮추는 것이다. 내 흐름은: 내 맥락 · 상대 맥락 → 공통점 → 동기화 → 다름 이해 → 각각의 장점으로 배치 — 박사의 1·2·3이 이 흐름 안의 단계·기법으로 들어간다.

2. **동기화** — 사회적 맥락은 리듬을 갖고 흐른다. 욕망의 동기화: 월드컵 선수들이 손 모으고 "하나 둘 파이팅" = 각자 이기고 싶은 마음을 '우리 팀이 이겨야 한다'는 더 큰 맥락으로. 대화에서 경청·공감보다 첫째는 **동기화 — 속도를 맞추는 것.** 다리 묶고 달리기 — 한쪽이 빠르면 넘어지고 질질 끌려간다. 동창회에서 옛 싸움을 안 다투는 건 나이 들어 실망도 많이 해 본 더 큰 맥락 속에 있어서.
3. **맥락의 범위 — 숲을 보라** — 논쟁의 90%는 "저 사람이 숲 맥락에서 말하나 나무 맥락에서 말하나"가 안 맞아서 생긴다. 군수(자기 군) < 도지사(도 전체) < 대통령(나라 전체) — 최대 다수의 행복 = 숲의 맥락을 따르면 된다. **"공부는 숲도 보고 나무도 본다? 착각. 오직 숲만 보라."** 조망 = 내 분야를 꿰뚫어 보기 = 더 높은 맥락으로 올라가기.
   - 에베레스트: 1950년엔 1년에 한두 명, 지금은 수백 명 — **베이스캠프를 높여서**(2,000m → 5,000m). 8,000m에 치면 100m만 올라가면 된다. 공간적 맥락을 높여 준 것.
   - **"점진적으로 성공하고 싶으면 훈련해야 되는 건 딱 하나 — 맥락의 플랫폼을 높여라. 맥락을 확장하라. 군수가 아니라 도지사·대통령 관점에서 보라."**
   - 맥락을 짧게 쓰는 사람은 낚시꾼(1차원, 한두 마리). 맥락을 넓히면 그물(수만 마리).
   - 마무리: 숲을 보고 나면 개별 행동 강령까지 만들어 낼 수 있다. **"나무를 보는 공부는 없다고 생각하라. 있긴 한데 나중에 해도 된다. 90% 훈련은 숲을 보는 훈련. 그러면 나무는 자동으로 생성된다. 맥락을 넓혀라."**

#### [Claude 추가] 소프트웨어 공학은 이걸 어떻게 말하나

> 위 재해석("입장이 아니라 맥락을 내놓아라")에 대응하는 이름들. 제 기억 기반이라 연도·문구는 원고 확정 시 링크로 확인할 것 — 특히 [불확실] 표시.

| 이름 | 출처 | 무엇을 말하나 | 박사 항목 |
|------|------|---------------|-----------|
| **Egoless programming** | Weinberg, *The Psychology of Computer Programming* (1971) | 코드와 작성자를 분리한다 — 리뷰는 코드에 대한 것이지 사람에 대한 것이 아니다. 후대 요약 "You are not your code", "Critique code instead of people" (Lamont Adams, *Ten Commandments of Egoless Programming*, TechRepublic 2002 [불확실: 연도]) | 1번 — "경계가 없어져 타인이 들어온다"의 원형 |
| **Tie notes to principles, not opinions** | Michael Lynch, *How to Do Code Reviews Like a Human* (2019) | "이건 별로다"(입장) 대신 "이 함수는 두 가지 책임을 가지니 SRP상 나누자"(원칙=공개된 맥락). "Frame feedback as requests, not commands"도 같은 글 | 재해석의 직역 |
| **Ask questions; don't make demands** · comments about the code, not the developer | Thoughtbot *Guides: Code Review*; Google eng-practices *How to write code review comments* | 질문형은 상대 맥락을 초대하고, 명령형은 입장 충돌을 부른다 | 1번 |
| **Conventional Comments** | conventionalcomments.org | `suggestion:` `nitpick:` `question:` + `(non-blocking)` 라벨로 발화의 무게를 앞에 표시 → 상대가 같은 속도로 받게 한다 | 2번 동기화(속도 맞추기) |
| **Blameless postmortem** | Google SRE Book ch.15 *Postmortem Culture* (2016) | 장애 원인을 "누가"가 아니라 시스템·맥락에서 찾는다. 사람을 지목하면 정보가 숨는다 | 1번 + 3번(숲에서 원인 보기) |
| **Psychological safety** | Edmondson (1999); Google Project Aristotle (2015) — 팀 효과성 1위 요인 | 입장을 내놓아도 처벌받지 않는다는 믿음. 박사의 "투명한 사람·타인이 들어온다"의 **팀 단위** 이름 | 1·2번의 전제 조건 |
| **ADR** (Architecture Decision Record) | Michael Nygard (2011) | 결정을 "누가 원했나"가 아니라 **맥락(Context) → 결정 → 결과**로 기록. 입장이 아니라 맥락을 남기는 문서 형식 그 자체 | 재해석의 문서판 |
| **RFC** 프로세스 | IETF 관행 → Rust·React 등 OSS의 RFC 저장소 | 이름부터 "코멘트 요청" — 제안을 소유물이 아니라 검토 대상으로 내놓는 틀 | 1번 |
| **Disagree and commit** | Intel(Grove) → Amazon 리더십 원칙 | 다름을 **다 드러낸 뒤** 결정에 동기화한다 — 다름을 지우는 게 아니라 배치하는 것 | 2번 + 내 흐름의 "다름 이해 → 배치" |
| **Strong opinions, weakly held** | Paul Saffo (2008 [불확실: 연도]) | 입장은 가지되 소유하지 않는다 — 반증이 오면 놓는다 | 1번 |
| **C4 model** 의 줌 레벨 | Simon Brown | 논쟁의 90%가 맥락 크기 불일치라는 박사의 말 = 한 사람은 Context 다이어그램, 한 사람은 Code 다이어그램을 보며 싸우는 것. 같은 줌 레벨에 서라 | 3번 맥락의 범위 |

한 줄로: 소프트웨어 공학은 박사의 1번을 **"사람과 산출물의 분리"**(egoless·blameless)로, 2번을 **"발화 무게의 명시와 결정 후 동기화"**(Conventional Comments·disagree and commit)로, 3번을 **"같은 추상화 레벨에서 말하기"**(C4)로 이미 이름 붙여 두었다. 공통 구조는 하나 — **입장을 소유물에서 떼어내 맥락으로 바꿔 놓으면, 상대의 맥락이 들어올 자리가 생긴다.**

### 한 줄 요약

**대칭이 안 보이면 만들고(대칭화), 그 단위를 모듈로 삼아 순서를 매기면 연결이 자동이 되어 에너지가 최소화된다 — 뇌는 근육이 아니라 부하를 줄여야 오래 간다. 지식은 맥락 기억(시간·장소·감정)에서 출발해 맥락을 잘라낸 것이므로, 새 것을 배울 땐 시간·공간을 붙이고, 볼 땐 나무가 아니라 숲(더 높은 맥락)을 보라.**
