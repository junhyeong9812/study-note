# 작성 워커 공통 브리핑

배정받은 흐름(또는 구조 편)의 본문을 소스 기준으로 쓴다. 이 문서의 `<도구>`·`<소스>`·`<태그>`·`<커밋>`·`<워크트리>` 자리는 배정 메시지가 채운다.

## 목표

Elasticsearch·MySQL 지도와 **같은 형식·같은 밀도**로, **도식화(ASCII 그림) 위주**로 쓴다.

## 경로

- 쓰기 대상: `<워크트리>/opensource/<도구>/architecture/flows/<slug>/` 또는 `structure/<slug>/` **안쪽만**.
- 소스(읽기 전용): `<소스>` — 태그 `<태그>`, 커밋 `<커밋>`. checkout·fetch·쓰기 금지.
- db-engine(읽기 전용): `~/project/db-engine/impl/*.md`

## 먼저 읽을 것

1. `reference/writing/README.md` — 문체(산문, 절마다 topic sentence, 결론 먼저, 이모지 금지, ASCII 다이어그램 허용). 화살표는 `->` `-->` `v` `|` `+--` 만 쓴다.
2. 형식 본보기: `opensource/mysql/architecture/flows/connection-thread/`(README 와 `03_handle_connection`), `flows/mtr-redo/`, 구조 편은 `opensource/mysql/architecture/structure/tablespace-page/`.
3. 배정 도구의 지도: `opensource/<도구>/architecture/README.md` — 흐름 표·연결 그림·흐름별 함수 목록이 출발점. 소스를 보고 더 나은 분할이면 바꿔도 되지만 이유를 packet 에 적는다.

## 파일 형식

### 흐름 README `flows/<slug>/README.md`

`# 흐름 이름` / `상위: [<도구> 아키텍처 지도](../../README.md)` / 요지 문단 / 기준 태그 줄(커밋 링크) /
`## 전체 그림`(`[01] 함수  L줄` 트리) / `## 어디에서 쓰이는가` / `## db-engine 에서는`(대응 챕터가 있을 때만 — impl 을 읽고 비교 ASCII 그림 1개 + 2~4줄, 링크 `../../../../../project/db-engine/<챕터>/`) / `## 단계`(함수 문서 링크) / `## 결과가 쓰이는 곳` / `## 다루지 않는 것` / `## 하위 메서드`

### 함수 문서 `flows/<slug>/NN_<함수>/README.md`

폴더명 `NN_함수` (`A::b` 는 `A.b`, 템플릿 인자는 뺀다).
`# 함수 이름` / `상위: [흐름 이름](../README.md)` / 요지 1~2문장 /
`## 위치` — 디렉터리 / 파일 / `L시작-L끝` + GitHub blob 링크(`#Lx-Ly`) /
`## 실제 코드` — 소스 언어 펜스, 첫 줄 `// 파일명 L시작-L끝`. **소스에서 그대로**(스크립트로 잘라 넣기 권장). 생략은 `// ... (Lx-Ly 생략: 이유)` 한 줄 /
`## 동작 흐름` — **ASCII 그림이 주인공** 1~4개, 산문은 그림 사이 1~3줄 /
`## 결과가 쓰이는 곳` / `## 다루지 않는 것`

### 구조 편 `structure/<slug>/README.md`

`# 이름` / 상위 / 요지 / 기준 태그 줄 / `## 전체 그림`(레이아웃·바이트 배치·필드 표) / 주제별 절(구조체 정의는 실제 코드 + 위치) / `## db-engine 에서는`(해당 시) / `## 어디에서 쓰이는가` / `## 다루지 않는 것`

## 규칙

- 모든 `L줄`·코드 블록은 **실제로 연 소스**에서 온다. 기억·추측 금지. 확인 못 한 것은 쓰지 않는다.
- "왜"(설계 이유)는 소스 주석·코드 근거가 있을 때만.
- 예시 그림의 숫자는 소스 규칙으로 계산해 맞춘다. 불가능한 시나리오를 그리지 않는다.
- 코드 블록 헤더 파일명이 레포에서 유일하지 않으면 `dir/file` 로 쓰거나 같은 문서 GitHub 링크에 경로가 있어야 한다.
- ASCII 표에 한글이 섞이면 한글을 마지막 열에 둔다.
- 짧은 곁가지 함수는 가까운 함수 문서에 포함해도 된다(packet 에 기록).
- 한국어, 식별자는 원문. 커밋 금지. 배정 폴더 밖 쓰기 금지. 템플릿 렌더를 쓰면 끝나기 전 `@@` 같은 자리표시자가 0 인지 확인.

## 끝나기 전 자체 점검

```text
 (a) python3 reference/tools/arch-map/check-code-blocks.py <소스> <네 폴더>   -> bad=0
 (b) grep -rn '@@' <네 폴더>                                                   -> 0
 (c) 상대 링크 실존 (아직 없는 slug 는 목록으로 보고)
```
